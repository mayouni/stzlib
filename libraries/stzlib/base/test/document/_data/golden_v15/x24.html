1. Purpose

This runbook describes how to deploy release 7.4 of the warehouse management system to the production cluster at Kestrel Point. The release introduces wave picking for chilled goods and replaces the label printer gateway.

2. Pre-checks

  • Confirm the change is approved in the change calendar
  • Check the state of the cluster
    • All nodes report Ready
    • No pods in CrashLoopBackOff
    • Disk usage on database volumes below 70 %
  • Notify the shift supervisor
    • Picking stops at 21:45
    • Trucks scheduled after 22:00 are loaded manually
  • Take a database snapshot and record its identifier

3. Deployment

3.1 Update the release values

Set the image tags and the feature flag in the environment file before running the pipeline.

release: "7.4.0"
images:
  wms-api: registry.internal/wms/api:7.4.0
  wms-picking: registry.internal/wms/picking:7.4.0
  label-gateway: registry.internal/wms/label-gateway:2.0.3
features:
  chilled_wave_picking: true
  legacy_label_spooler: false
replicas:
  wms-api: 4
  wms-picking: 3

3.2 Run the deployment

  1. Put the site into maintenance mode from the operations console.
  2. Run the database migration job and wait for it to complete.
  3. Deploy the services with the commands below.
  4. Take the site out of maintenance mode.
kubectl config use-context kpdc-prod
kubectl -n wms apply -f release-7.4.0.yaml
kubectl -n wms rollout status deploy/wms-api --timeout=10m
kubectl -n wms rollout status deploy/wms-picking --timeout=10m

If a rollout does not finish within ten minutes, stop and go to section 5.
