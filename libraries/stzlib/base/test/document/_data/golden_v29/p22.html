1. Summary

All core services met their availability targets this quarter. The service desk resolved tickets faster than in any quarter since 2024.

3. Monitoring changes

Alerts now page the on-call engineer only when a user-facing service degrades. The new latency rule for the tenant portal is shown below.

groups:
  - name: tenant-portal
    rules:
      - alert: PortalHighLatency
        expr: histogram_quantile(0.95, sum by (le) (rate(portal_request_seconds_bucket[5m]))) > 1.5
        for: 10m
        labels:
          severity: page
        annotations:
          summary: "Portal p95 latency above 1.5 s for 10 minutes"
