Betriebshandbuch LV-Server 5

Version 5.4 · für Systemadministratoren

Dieses Handbuch beschreibt Installation, Konfiguration und Betrieb des Lagerverwaltungsservers. Es richtet sich an Administratoren, die mit Linux und PostgreSQL vertraut sind.

Die Beschreibung der Lagerprozesse selbst finden Sie im Anwenderhandbuch.

1 Systemvoraussetzungen

Für einen Standort mit bis zu 40 Handscannern gelten die folgenden Werte.

Komponente Mindestens Empfohlen
Prozessor 4 Kerne, 2,4 GHz 8 Kerne, 3,0 GHz
Arbeitsspeicher 8 GB 32 GB
Festplatte 120 GB SSD 500 GB NVMe, gespiegelt
Betriebssystem Debian 12 oder Ubuntu 24.04 LTS Debian 12
Datenbank PostgreSQL 15 PostgreSQL 16 auf eigenem Host

2 Installation

2.1 Paket einspielen

  1. Melden Sie sich als Benutzer mit Administratorrechten am Server an.
  2. Prüfen Sie vor der Installation:
    1. ob die Datenbank vom Server aus erreichbar ist,
    2. ob Port 8443 in der Firewall freigegeben ist,
    3. ob die Lizenzdatei lizenz.lvk vorliegt.
  3. Kopieren Sie das Installationspaket in ein temporäres Verzeichnis.
  4. Führen Sie die folgenden Befehle nacheinander aus:
sudo dpkg -i lv-server_5.4.2_amd64.deb
sudo systemctl enable lv-server
sudo systemctl start lv-server
systemctl status lv-server --no-pager

Nach dem Start meldet der Befehl systemctl status den Zustand „active (running)“.

2.2 Dienst einrichten

Die zentrale Konfigurationsdatei liegt unter /etc/lv-server/lv-server.conf. Ein vollständiges Beispiel:

[datenbank]
host     = db01.lager.intern
port     = 5432
name     = lagerwerk
benutzer = lv_dienst

[server]
bind_adresse = 0.0.0.0
port         = 8443
worker       = 8
protokoll    = /var/log/lv-server/server.log

2.2.1 Parameter der Datei lv-server.conf

Parameter Standardwert Bedeutung
port 8443 TCP-Port der Weboberfläche und der REST-Schnittstelle.
worker Anzahl der Kerne Zahl der parallelen Arbeitsprozesse.
Werte über 16 bringen keinen messbaren Gewinn.
protokoll /var/log/lv-server/server.log Pfad der Protokolldatei. Das Verzeichnis muss dem Dienstkonto gehören.
bind_adresse 127.0.0.1 Netzwerkadresse, an die sich der Dienst bindet.
Für den Zugriff aus dem Lagernetz 0.0.0.0 eintragen.
Hinweis: Nach jeder Änderung an der Konfiguration muss der Dienst neu gestartet werden.

3 Datensicherung

Der Server bringt ein eigenes Sicherungswerkzeug mit. Die Sicherung umfasst:

– vollständige Sicherung der Datenbank jede Nacht,

– Kopie der Konfigurationsdateien unter /etc/lv-server/,

– Aufbewahrung der letzten 14 Sicherungen auf einem getrennten Datenträger.

Zur Einrichtung genügt ein Eintrag in der Crontab des Dienstkontos:

# Tägliche Sicherung um 02:15 Uhr
15 2 * * * /opt/lv-server/bin/lv-backup --ziel /mnt/sicherung --behalte 14

Prüfen Sie mindestens einmal im Quartal, ob sich eine Sicherung tatsächlich wiederherstellen lässt.

4 Fehlerbehebung

Die folgende Tabelle nennt die häufigsten Fehlercodes im Protokoll.

Fehlercode Ursache Maßnahme
LV-101 Datenbank nicht erreichbar Host und Port im Abschnitt [datenbank] prüfen.
LV-204 Lizenzdatei abgelaufen Neue Lizenz im Kundenportal anfordern und nach /etc/lv-server/ kopieren.
LV-310 Scanner meldet unbekannte Lagerplatznummer Stammdaten des Lagerplatzes anlegen oder Etikett neu drucken.
LV-415 Sicherungsziel voll Ältere Sicherungen auslagern oder --behalte verringern.

Lässt sich ein Fehler nicht beheben, wenden Sie sich mit dem Protokollauszug an den Support.

5 Aktualisierung

Aktualisierungen werden als neues Paket ausgeliefert und über das vorhandene installiert:

  1. Erstellen Sie eine vollständige Sicherung wie in Kapitel 3 beschrieben.
  2. Beenden Sie den Dienst mit systemctl stop lv-server.
  3. Installieren Sie das neue Paket mit dpkg -i.
  4. Starten Sie den Dienst und prüfen Sie das Protokoll auf Warnungen.

Die Datenbankstruktur wird beim ersten Start der neuen Version automatisch angepasst. Der Vorgang kann bei großen Beständen einige Minuten dauern.
