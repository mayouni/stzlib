３．審議事項

（１）夏季の熱中症対策の振り返り
アWBGT計の設置場所を2か所増やしたことで、作業中断の判断が早くなった。
イ経口補水液の配布は好評であり、来年度も継続する。
（２）腰痛予防の取り組み
ア出荷場の台車を軽量タイプに順次更新する。
イ産業医による腰痛予防講習を11月に実施する。
ウ重量物の取り扱いについて、二人作業とする基準を20kg以上から15kg以上に改める案を、次回までに総務部が作成する。
（３）ストレスチェックの実施時期
ア繁忙期を避け、12月第1週に実施することで合意した。
