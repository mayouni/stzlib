Tallyhook 4.2 Release Notes

Tallyhook 4.2 is a feature release. It adds scheduled exports, replaces the legacy queue driver and drops support for PostgreSQL 12. Read the breaking changes before you upgrade a production installation.

1 Highlights

  • Scheduled exports can now be defined per workspace.
    • Exports run in the background worker and never block the web process.
    • Failed runs are retried three times with exponential back-off.
  • The new queue driver uses Redis streams instead of lists, which removes the duplicate-delivery problem reported in 4.1.
  • The audit log now records the user agent of every API call.

2 Breaking changes

2.1 Configuration keys renamed

Four keys in tallyhook.yml have new names. The old names are rejected at start-up with an explicit error message.

Old keyNew keyNotes
queue.backendqueue.driverThe value redis-list is no longer accepted.
export.direxports.pathRelative paths resolve against the data directory.
mail.fromnotifications.senderFormat unchanged.
api.rateapi.rate_limit.per_minuteDefault raised from 60 to 120.

2.2 Database requirements

PostgreSQL 13 or later is required. Run the built-in check before upgrading:

$ tallyhook doctor --check database
Checking database version ...... 15.4 (ok)
Checking pending migrations .... 3 pending
Checking free disk space ....... 41.2 GB (ok)

If the check reports an older server, upgrade PostgreSQL first and keep Tallyhook on 4.1 until that is done.

3 Upgrade procedure

1. Stop the web and worker processes.
2. Back up the database and the data directory.
2.1 Use pg_dump with the custom format so that tables can be restored one by one.
2.2 Copy the data directory to a separate disk.
3. Update the configuration file as shown below.
4. Run the migrations and start the services again.

5 Known limitations

Scheduled exports cannot yet write to object storage. Support is planned for release 4.3.

Supported platforms

  • Ubuntu 22.04 and 24.04
  • Debian 12
  • Container image on any OCI runtime

Deprecated in this release

  • The XML export format
  • API tokens without an expiry date
  • The tallyhook-legacy command
