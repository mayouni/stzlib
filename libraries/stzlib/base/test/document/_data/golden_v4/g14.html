Rotating Log Files

The script below rotates every log file in a folder and keeps a fixed number of old copies. It was written for the quarry weighbridge, which writes a new log each day.

import os
import shutil

def rotate(folder, keep=7):
    names = sorted(os.listdir(folder))
    logs = [n for n in names if n.endswith(".log")]
    for name in logs:
        path = os.path.join(folder, name)
        for i in range(keep - 1, 0, -1):
            older = f"{path}.{i}"
            if os.path.exists(older):
                shutil.move(older, f"{path}.{i + 1}")
        shutil.move(path, path + ".1")
    return len(logs)

if __name__ == "__main__":
    import sys
    count = rotate(sys.argv[1])
    print(f"rotated {count} log files")

Running the script

The transcript shows a run on the test machine. Each log was moved to a copy ending in .1, and no new log had been written yet.

$ python rotate_logs.py /var/log/weighbridge
rotated 3 log files
$ ls /var/log/weighbridge
gate.log.1  scale.log.1  tickets.log.1

Run the script from the scheduler once a day, shortly after midnight.
