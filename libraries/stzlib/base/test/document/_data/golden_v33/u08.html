1. 수업 개요

이 과목은 배열, 연결 리스트, 트리, 그래프와 같은 기본 자료구조를 배우고 정렬과 탐색 알고리즘의 효율을 분석한다. 수강생은 이론 수업과 실습을 통해 문제에 알맞은 자료구조를 선택하는 능력을 기른다.
