Шлюз телеметрии ТМ-200: руководство по настройке

1. Назначение

Шлюз телеметрии ТМ-200 предназначен для сбора данных с датчиков и передачи их на сервер по защищённому каналу. Настоящее руководство описывает подключение устройства и настройку его параметров.

2. Подготовка к работе

2.1 Комплектность

В комплект поставки входят следующие изделия:

а)шлюз ТМ-200 — 1 шт.;
б)блок питания 12 В — 1 шт.;
в)антенна — 1 шт.;
г)кабель Ethernet длиной 1,5 м — 1 шт.

2.2 Подключение

Для подключения устройства выполните следующие действия.

1)Закрепите шлюз на DIN-рейке.
2)Подключите антенну к разъёму на верхней панели:
а)вкрутите разъём до упора вручную;
б)не используйте инструмент для затяжки.
3)Подключите кабель Ethernet к порту LAN1.
4)Подайте питание и дождитесь свечения индикатора.

3. Файл конфигурации

Параметры хранятся в текстовом файле config.ini. Пример файла приведён ниже.

[network]
address = 192.168.10.20     # адрес шлюза
netmask = 255.255.255.0
gateway = 192.168.10.1

[mqtt]
broker = mqtt.example.net
port = 8883
topic = site/tm200/data
interval_s = 30             # период опроса, с

После изменения файла перезапустите службу командой:

sudo systemctl restart tm200

4. Диагностика

Состояние устройства определяется по индикатору на передней панели. Значения индикатора указаны в таблице 2.

Таблица 2 — Индикация
ИндикаторСостояниеДействие
Зелёный, горит постоянноНормальная работаДействий не требуется
Зелёный, мигаетНет связи с серверомПроверьте кабель и адрес брокера
Красный, горит постоянноВнутренняя ошибкаПерезапустите устройство
Не горитНет питанияПроверьте блок питания

Перед обращением в сервисный центр проверьте:

  • правильность адреса и маски подсети;
  • доступность брокера с другого компьютера сети;
  • уровень сигнала антенны в журнале устройства.

5. Гарантийные обязательства

Изготовитель гарантирует соответствие шлюза техническим характеристикам в течение 24 месяцев со дня продажи. Гарантия не распространяется на устройства, имеющие механические повреждения или следы вскрытия корпуса.

6. Контакты

Служба технической поддержки работает по рабочим дням с 9:00 до 18:00. Заявки принимаются по адресу support@severny-pribor.example.
