Meridian Sync 4.2 — Release Notes

Version4.2.0
Release date23 April 2026
Supported until30 April 2028
Compatible withMeridian Server 3.8 and later

Meridian Sync 4.2 is a feature release that makes synchronisation faster and easier to monitor. Please read the upgrade instructions before installing the package on a production host.

Highlights

•Faster transfers
–Delta compression reduces upload size by up to 60 percent.
–Parallel chunking is now enabled by default.
•Better monitoring
–New metrics endpoint compatible with common dashboards.
–Sync history is kept for 90 days.
•Improved conflict resolution for files edited on two devices.

Upgrade instructions

Stop the service, install the new package and run the migration. A dry run shows what will change without touching any data.

$ meridian stop
$ sudo apt install ./meridian-sync_4.2.0_amd64.deb
$ meridian migrate --dry-run
$ meridian migrate
$ meridian start

Configuration changes

The new compression and retry settings live in the sync section of the configuration file:

{
  "sync": {
    "interval": "30s",
    "retries": 5,
    "compression": "zstd",
    "chunk_mb": 8
  }
}

Known issues

1.Large folders with more than 200,000 files may take several minutes to show their first sync result.
2.The metrics endpoint is not available when the service runs in read-only mode.
3.Renaming a folder on two devices at the same time creates a conflict copy.

Deprecations

The following features will be removed in version 5.0:

  • the legacy XML configuration format;
  • the --force-full command-line flag;
  • support for Meridian Server 3.5 and earlier.

Getting help

If you run into a problem, collect the diagnostics bundle and attach it to your support request. The bundle contains logs and configuration without any file contents.

$ meridian diagnostics --output /tmp/meridian-diag.zip
