ТЕХНИЧЕСКОЕ ЗАДАНИЕ
на разработку системы учёта посетителей складского комплекса

1. Общие сведения

1.1. Наименование системы

Полное наименование: автоматизированная система учёта посетителей складского комплекса «Ладога-3». Краткое наименование: АСУП.

1.2. Заказчик и исполнитель

Заказчиком является ООО «Северный терминал», исполнителем — ООО «Кедр Софт». Работы выполняются на основании договора № 41/26 от 5 октября 2026 г.

2. Назначение и цели создания системы

2.1. Назначение системы

Система предназначена для регистрации посетителей, водителей и сотрудников подрядных организаций на контрольно-пропускном пункте складского комплекса. Она заменяет бумажный журнал посетителей, который ведётся в настоящее время.

2.2. Цели создания системы

Создание системы должно обеспечить:

а) сокращение времени оформления пропуска до двух минут;
б) достоверный учёт времени пребывания посетителей на территории;
в) оперативное формирование отчётов для службы безопасности;
г) исключение повторного ввода данных постоянных посетителей.

3. Требования к системе

3.1. Требования к функциям

Система должна выполнять следующие функции:

  • регистрация посетителя по документу, удостоверяющему личность;
  • печать разового пропуска со штрихкодом;
  • фиксация времени входа и выхода при сканировании пропуска;
  • ведение списка лиц, которым запрещён доступ;
  • выгрузка данных в учётную систему заказчика.

3.3. Формат обмена данными

Сведения о посещениях передаются в учётную систему заказчика в формате JSON один раз в час. Пример записи о посещении приведён ниже.

{
  "visit_id": "L3-2026-104882",
  "person": {"last_name": "Смирнова", "doc_type": "passport"},
  "gate": "KPP-1",
  "time_in": "2026-11-16T08:42:10+03:00",
  "time_out": "2026-11-16T11:05:37+03:00",
  "purpose": "delivery"
}

4. Порядок контроля и приёмки

1) Предварительные испытания проводятся исполнителем на тестовом стенде.
2) Опытная эксплуатация длится не менее одного месяца на КПП № 1.
3) Приёмочные испытания проводит комиссия, назначенная приказом заказчика.
4) По результатам испытаний подписывается акт о приёмке системы в постоянную эксплуатацию.
