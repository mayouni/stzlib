一、产品概述

KJ-360是一款面向20至45平方米居室的家用空气净化器。本机采用三层复合滤网，可同时去除颗粒物、甲醛和异味。整机噪声在睡眠模式下不高于28分贝，适合卧室和儿童房使用。

三、主要功能

  1. １．三档风速与睡眠模式自动切换：
    1. ①睡眠模式下指示灯自动熄灭；
    2. ②风速根据空气质量传感器读数自动调整。
  2. ２．滤网寿命提醒，剩余寿命低于10%时指示灯变为红色。
  3. ３．童锁功能，长按锁定键3秒即可启用或解除。

五、安全注意事项

  1. 请勿在浴室等潮湿场所使用本机。
  2. 清洁或更换滤网前务必拔下电源插头。
  3. 请勿遮挡进风口和出风口。
  4. 儿童须在成人监护下使用。
  5. 电源线破损时，须由专业维修人员更换。

六、保修政策

自购买之日起，整机享受一年免费保修，电机享受三年免费保修。滤网属于耗材，不在保修范围之内。保修期内因人为损坏或擅自拆机造成的故障，不享受免费维修服务。

部件保修期服务方式
整机1年上门或送修
电机3年送修
空气质量传感器2年送修
复合滤网不保修按耗材价格购买

如需维修，请拨打客服电话或通过官方网站提交服务申请。
