3. התחייבויות השוכרת

  1. לשמור על הדירה ועל המתקנים שבה במצב תקין.
  2. לא לבצע שינויים במבנה ללא אישור בכתב מהמשכיר.
  3. לאפשר כניסה לדירה לצורך תיקונים, בתיאום מראש של 48 שעות לפחות:
    • בימים ראשון עד חמישי, בין השעות 8:00 ל-18:00;
    • ובמקרה חירום בכל עת.
  4. להחזיר את הדירה בתום התקופה כשהיא נקייה ופנויה.

4. הוראות כלליות

יתר תנאי החוזה המקורי נותרים בתוקף ללא שינוי. בכל סתירה בין נספח זה לבין החוזה המקורי יגברו הוראות הנספח.
