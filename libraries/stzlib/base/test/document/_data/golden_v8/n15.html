Description du cours

Ce cours initie les étudiants aux méthodes statistiques utilisées pour décrire et analyser des données économiques. Il met l’accent sur l’interprétation des résultats plutôt que sur les démonstrations mathématiques.

Objectifs d’apprentissage

  1. Décrire une distribution à l’aide d’indicateurs de position et de dispersion
  2. Construire et interpréter un intervalle de confiance
  3. Mettre en œuvre un test d’hypothèse et en discuter les limites
  4. Estimer et interpréter un modèle de régression linéaire simple

Préalables

Le cours ECO 1101 (Mathématiques pour économistes) doit avoir été réussi. Une connaissance élémentaire d’un tableur est souhaitable, mais aucune expérience de programmation n’est exigée.

Les travaux dirigés se font avec le logiciel libre R, installé dans toutes les salles informatiques. Avant la deuxième séance, installez les extensions nécessaires :
