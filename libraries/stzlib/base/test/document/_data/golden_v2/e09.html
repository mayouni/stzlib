Guide de démarrage de l'imprimante Orvane P20

Ce guide décrit les étapes à suivre avant la première impression. Suivez les étapes dans l'ordre indiqué.

Étapes

  1. Retirez tous les rubans adhésifs orange.
    • Vérifiez aussi l'intérieur du capot avant.
    • Conservez le carton pour un éventuel retour.
  2. Branchez le câble d'alimentation et allumez l'imprimante.
  3. Installez les cartouches d'encre.
    • Commencez par la cartouche noire.
    • Attendez que le voyant cesse de clignoter.
  4. Lancez une page de test depuis le menu Entretien.

Après l'installation

Si la page de test est pâle, répétez l'étape c. En cas de problème, consultez la section Dépannage du manuel.
