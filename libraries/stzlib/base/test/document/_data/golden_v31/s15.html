Ανακοίνωση για τα έργα οδοποιίας στο κέντρο της πόλης

Ο Δήμος ενημερώνει τους κατοίκους ότι από τη Δευτέρα 2 Νοεμβρίου θα ξεκινήσουν εργασίες ανακατασκευής του οδοστρώματος στο κέντρο της πόλης. Οι εργασίες αναμένεται να ολοκληρωθούν σε έξι εβδομάδες, εφόσον ο καιρός το επιτρέψει.

Κυκλοφοριακές ρυθμίσεις

α)Η οδός Ελευθερίας θα είναι κλειστή για τα οχήματα από τις 7:00 έως τις 17:00.
β)Η κυκλοφορία θα διεξάγεται από παρακαμπτήριες διαδρομές, οι οποίες θα επισημανθούν με πινακίδες:
i.οδός Αγίου Νικολάου
ii.οδός Πλατάνων
γ)Οι στάσεις των λεωφορείων μεταφέρονται προσωρινά στην πλατεία Δημαρχείου.

Οι πεζοί θα μπορούν να κινούνται με ασφάλεια σε ειδικούς διαδρόμους που θα προστατεύονται με κιγκλιδώματα.

Χρονοδιάγραμμα εργασιών

ΦάσηΟδόςΔιάρκειαΠαρατηρήσεις
Φάση 1Ελευθερίας (βόρειο τμήμα)2 εβδομάδεςΑντικατάσταση του ασφαλτοτάπητα
Φάση 2Ελευθερίας (νότιο τμήμα)2 εβδομάδεςΝέα πεζοδρόμια και ράμπες
Φάση 3Πλατεία Δημαρχείου2 εβδομάδεςΤοποθέτηση νέου φωτισμού

Παρακαλούμε τους κατοίκους να μην σταθμεύουν στους δρόμους που θα επισημανθούν, ώστε να μην καθυστερήσουν οι εργασίες.

Πώς θα ενημερώνεστε

Η πρόοδος των εργασιών θα ανακοινώνεται κάθε Παρασκευή στην ιστοσελίδα του Δήμου.
