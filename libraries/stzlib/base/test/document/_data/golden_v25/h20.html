บริษัท สยามเกษตรรุ่งเรือง จำกัด
เลขที่ ๔๑ ถนนพหลโยธิน ตำบลหนองแค อำเภอเมือง จังหวัดสระบุรี

ประกาศรับสมัครพนักงาน

บริษัทมีความประสงค์จะรับสมัครบุคคลเพื่อบรรจุเป็นพนักงานประจำในตำแหน่งต่าง ๆ รวม ๕ อัตรา ดังรายละเอียดต่อไปนี้

ตำแหน่งจำนวนสถานที่ปฏิบัติงานเงินเดือน (บาท)
เจ้าหน้าที่บัญชี๑สำนักงานใหญ่ สระบุรี๑๘,๐๐๐–๒๒,๐๐๐
พนักงานขายภาคสนาม๒สาขานครราชสีมา๑๕,๐๐๐ และค่าคอมมิชชัน
ช่างซ่อมบำรุงเครื่องจักร๑โรงงานหนองแค๑๖,๐๐๐–๒๐,๐๐๐
เจ้าหน้าที่คลังสินค้า๑โรงงานหนองแค๑๓,๐๐๐–๑๕,๐๐๐

คุณสมบัติทั่วไปของผู้สมัคร

  1. มีสัญชาติไทย อายุระหว่าง ๒๒ ถึง ๔๐ ปี
  2. สำเร็จการศึกษาในสาขาที่เกี่ยวข้องกับตำแหน่งที่สมัคร
  3. มีความรู้ด้านคอมพิวเตอร์ขั้นพื้นฐาน
  4. สามารถเริ่มงานได้ภายในเดือนธันวาคม ๒๕๖๙

สวัสดิการ

  • • ประกันสังคมและประกันสุขภาพกลุ่ม
  • • โบนัสประจำปีตามผลประกอบการ
  • • ชุดยูนิฟอร์มและรถรับส่งพนักงาน
  • • วันหยุดพักผ่อนประจำปี ๑๐ วัน

เอกสารประกอบการสมัคร

  1. ๑) ใบสมัครที่กรอกข้อความครบถ้วน พร้อมรูปถ่ายขนาด ๑ นิ้ว
  2. ๒) สำเนาบัตรประจำตัวประชาชนและสำเนาทะเบียนบ้าน
  3. ๓) สำเนาวุฒิการศึกษาและหนังสือรับรองการทำงาน (ถ้ามี)

ผู้สนใจสามารถยื่นใบสมัครได้ที่ฝ่ายบุคคล สำนักงานใหญ่ หรือส่งทางไปรษณีย์อิเล็กทรอนิกส์ได้ตั้งแต่บัดนี้จนถึงวันที่ ๓๐ พฤศจิกายน ๒๕๖๙ บริษัทจะติดต่อกลับเฉพาะผู้ที่ผ่านการคัดเลือกเบื้องต้นเท่านั้น

การพิจารณาคัดเลือกประกอบด้วยการสอบข้อเขียนและการสัมภาษณ์
