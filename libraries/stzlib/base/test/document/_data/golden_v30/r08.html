一、产品概述

TH-200 智能温控器适用于电地暖、电热膜和小型壁挂炉等采暖设备，支持本地按键操作，也可以通过手机应用远程控制。产品采用高精度数字传感器，能够保持室内温度稳定。

三、安装步骤

  • 1. 切断电源，并用验电笔确认线路无电。
  • 2. 取下旧面板，并记录各根导线的接线位置。
    • （1） 电源线接 L 端子和 N 端子。
    • （2） 加热设备接 1 号端子和 2 号端子。
  • 3. 将温控器底座用螺丝固定在墙面接线盒上。
  • 4. 扣合面板，恢复供电后检查屏幕是否正常显示。

四、使用方法

  • （一） 开机与关机：长按电源键三秒，屏幕亮起或熄灭。
  • （二） 设定温度：按上键或下键调节目标温度，每次变化 0.5 ℃。
  • （三） 定时功能：在应用中设置工作日和周末的不同时段，温控器会自动执行。

注意：安装必须由具有资质的电工完成，通电状态下严禁拆装本产品。

五、常见问题

现象处理方法
屏幕不亮检查电源接线是否牢固，并确认断路器已经合上。
无法连接网络确认路由器工作在 2.4 GHz 频段，然后重新进行配网。
温度显示偏差在设置菜单中进行温度校准，每次可校准 ±3 ℃。
加热设备不工作检查负载是否超过 16 A，并确认加热设备接线端子无松动。
