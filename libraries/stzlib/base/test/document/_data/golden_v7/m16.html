Question 3

The following algorithm is intended to search a sorted list for a target value using a binary search. It contains one logic error.

FUNCTION search(items, target)
    low <- 0
    high <- LEN(items) - 1
    WHILE low <= high
        mid <- (low + high) DIV 2
        IF items[mid] = target THEN
            RETURN mid
        ELSE IF items[mid] < target THEN
            high <- mid - 1
        ELSE
            low <- mid + 1
        ENDIF
    ENDWHILE
    RETURN -1
ENDFUNCTION
(a) Complete the trace table for the call search([3, 8, 11, 15, 21, 30], 21). [4]
low high mid items[mid]
0 5
(b) Identify the logic error and write the corrected lines. [2]
(c) State the maximum number of comparisons needed to find a value in a sorted list of 1,000 items. [1]
