Quillstack 4.2 Release Notes

Released 27 October 2026 · Build 4.2.0-1

Highlights

Quillstack 4.2 adds offline editing, a faster search index and a new permissions model for shared spaces. Most installations can upgrade in place without downtime.

New features

Offline editing

Pages you have opened in the last 30 days stay editable when the connection drops. Changes are kept as drafts and merged when you are back online.

Full list of changes

  • Editor
    • Offline drafts are stored in the browser and synchronised on reconnect.
    • Tables can now be pasted from spreadsheets with their formatting kept.
      • Merged cells are preserved.
      • Formulas are pasted as values.
  • Search
    • The index is rebuilt incrementally, which cuts reindexing time by about 70%.
    • Results can be filtered by space and by author.
  • Administration
    • Space owners can delegate permissions to groups.
    • The audit log can be exported as CSV.

Breaking changes

1.The configuration key search.engine has been renamed to search.backend.
2.Support for PostgreSQL 13 has been removed; use version 14 or later.
3.The legacy endpoint /api/v1/export now returns 410 Gone.

Upgrading

Back up the database and the attachments folder before you upgrade. The commands below assume a Debian-based server.

$ quillstack backup --output /var/backups/qs-$(date +%F).tar.gz
$ sudo systemctl stop quillstack
$ sudo apt install quillstack=4.2.0-1
$ quillstack migrate --check
$ sudo systemctl start quillstack

Configuration

After upgrading, update quillstack.yaml as shown below.

search:
  backend: tantivy        # was: engine
  index_path: /var/lib/quillstack/index
  rebuild: incremental

offline:
  enabled: true
  max_draft_age_days: 30

permissions:
  delegate_to_groups: true
