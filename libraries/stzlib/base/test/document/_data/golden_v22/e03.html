Installationsanleitung für den Druckserver PS-400

Ausgabe Oktober 2026 – gültig ab Firmware 3.1

1 Einleitung

Diese Anleitung beschreibt die Erstinstallation des Druckservers in einem Firmennetzwerk. Sie richtet sich an Administratorinnen und Administratoren mit Grundkenntnissen in Linux.

Hinweis: Lesen Sie vor Beginn das Kapitel zu den Systemvoraussetzungen vollständig durch.

3 Installation

Die Installation erfolgt in fünf Schritten.

  1. Laden Sie das Installationspaket aus dem Händlerportal herunter.
  2. Prüfen Sie die Prüfsumme des Pakets.
  3. Installieren Sie das Paket mit dem Paketmanager.
  4. Passen Sie die Konfigurationsdatei an:
    1. Tragen Sie den Hostnamen des Servers ein.
    2. Legen Sie den Port für die Weboberfläche fest.
    3. Aktivieren Sie bei Bedarf die Verschlüsselung.
  5. Starten Sie den Dienst neu.

3.1 Befehle für die Schritte 2 und 3

sha256sum ps400-server_3.1.2_amd64.deb
sudo apt install ./ps400-server_3.1.2_amd64.deb
sudo systemctl enable --now ps400

4 Konfiguration

Die zentrale Konfigurationsdatei liegt unter /etc/ps400/server.conf. Kommentarzeilen beginnen mit einem Semikolon.

4.1 Beispielkonfiguration

[server]
hostname   = druck01.intern.example
web_port   = 8631
log_level  = info

[tls]
enabled    = true
zertifikat = /etc/ps400/tls/server.pem
schluessel = /etc/ps400/tls/server.key

[warteschlange]
max_auftraege     = 500
aufbewahrung_tage = 14

4.2 Wichtige Parameter

ParameterStandardwertBedeutung

5 Fehlerbehebung

–Der Dienst startet nicht: Prüfen Sie die Protokolldatei unter /var/log/ps400/server.log.
–Die Weboberfläche ist nicht erreichbar: Kontrollieren Sie die Firewall-Regeln für Port 8631.
–Drucker werden nicht gefunden: Aktivieren Sie die automatische Erkennung in der Weboberfläche.

Nach einem Neustart übernimmt der Dienst alle Änderungen an der Konfiguration automatisch. Weitere Informationen finden Sie im Administrationshandbuch.
