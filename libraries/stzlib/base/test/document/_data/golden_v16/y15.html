Field Deployment Guide: GX-7 Fibre Gateway

Applies to firmware 4.2.x · Revision C · Approved 9 October 2026

1 Purpose and Scope

This guide describes how field technicians install, provision and verify the GX-7 fibre gateway at residential and small business premises. It covers the physical installation, the provisioning file, the first boot and the acceptance tests that must pass before a job is closed.

Before you start

  • Confirm the work order shows an active GPON port.
  • Check that the optical light level at the wall box is between -8 dBm and -27 dBm.
  • Make sure the customer is present to choose the gateway location.

Tools required

  • Optical power meter with SC/APC adapter
  • Laptop with a terminal client and an Ethernet port
  • Fibre cleaning pen and inspection scope

2 Physical Installation

Mount the gateway on a wall or shelf at least one metre away from microwave ovens and cordless phone bases. Keep the fibre patch lead bend radius above 15 mm at all times.

  1. Clean and inspect the SC/APC connector on the patch lead.
  2. Connect the patch lead to the PON port on the rear panel.
  3. Connect the power adapter and wait until the PWR light is steady green.
  4. Check that the PON light turns steady green within three minutes.
  5. Record the gateway serial number and MAC address on the work order.

3 Provisioning

The gateway downloads its provisioning file from the auto-configuration server during first boot. If the download fails, the technician can load the same file locally from the laptop.

3.1 Provisioning file

A typical provisioning file for a residential internet and voice service looks like this:

# gx7-provision.yaml
device:
  model: GX-7
  firmware: 4.2.3
wan:
  mode: gpon
  vlan: 101
  pppoe: false
lan:
  subnet: 192.168.20.0/24
  dhcp_range: [192.168.20.100, 192.168.20.199]
voice:
  enabled: true
  lines: 1
  sip_server: sip.core.brightline.example

3.3 Loading the file locally

Connect the laptop to LAN 1, open a terminal session to the gateway and enter the commands below. The gateway reboots automatically when the commit succeeds.

gx7> login field
Password: ********
gx7# config load usb:/gx7-provision.yaml
gx7# config validate
Validation passed: 0 errors, 1 warning
gx7# config commit
Committing configuration... done
gx7# reboot

Never commit a provisioning file that reports validation errors, because the gateway may lose its management VLAN and require a site revisit.
