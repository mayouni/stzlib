Техническое задание

на разработку информационной системы учёта заявок на ремонт оборудования

1. Общие сведения

1.1. Наименование системы

Полное наименование системы: информационная система учёта заявок на ремонт оборудования. Краткое наименование системы: ИС «Заявка».

1.2. Заказчик и исполнитель

Заказчиком работ является общество с ограниченной ответственностью «Северная линия». Исполнитель определяется по результатам конкурсного отбора.

2. Назначение и цели создания системы

Система предназначена для приёма, регистрации и контроля исполнения заявок на ремонт производственного оборудования. Основными целями создания системы являются:

  • –сокращение среднего времени простоя оборудования;
  • –повышение прозрачности работы ремонтных служб;
  • –накопление статистики отказов для планирования закупок запасных частей.

3. Требования к системе

3.1. Функциональные требования

Система должна обеспечивать выполнение следующих функций:

  1. а) регистрацию заявки с указанием оборудования, характера неисправности и срочности;
  2. б) назначение ответственного исполнителя и контроль сроков;
  3. в) уведомление заявителя об изменении статуса заявки;
  4. г) формирование ежемесячных отчётов по подразделениям.

3.2. Требования к надёжности

Система должна сохранять работоспособность при отказе одного из серверов. Время восстановления после сбоя не должно превышать четырёх часов.

5. Порядок контроля и приёмки

Приёмка каждого этапа осуществляется комиссией, назначенной приказом директора. По результатам приёмки подписывается акт сдачи работ.

Замечания комиссии устраняются исполнителем в течение десяти рабочих дней без дополнительной оплаты.

6. Требования к документации

По окончании работ исполнитель передаёт заказчику следующие документы:

  • –руководство пользователя;
  • –руководство администратора;
  • –программу и методику испытаний.

Вся документация предоставляется на русском языке в печатном и электронном виде.
