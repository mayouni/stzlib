Einrichtung des zentralen Druckservers

Betriebsanleitung für Administratorinnen und Administratoren

1 Zweck

Diese Anleitung beschreibt die Einrichtung des zentralen Druckservers für alle Verwaltungsstandorte. Sie ersetzt die bisherige Fassung vom Oktober 2024. Abweichungen vom beschriebenen Verfahren sind mit der Leitung des Rechenzentrums abzustimmen.

2 Voraussetzungen

Vor Beginn der Arbeiten müssen folgende Bedingungen erfüllt sein:

  • ein virtueller Server mit mindestens 4 GB Arbeitsspeicher
    • zwei Prozessorkerne
    • 40 GB freier Speicherplatz
  • eine feste IP-Adresse im Verwaltungsnetz
  • Zugang zum zentralen Verzeichnisdienst mit einem Dienstkonto
  • die aktuellen Treiberpakete der eingesetzten Druckermodelle

3 Installation

3.1 Pakete installieren

Melden Sie sich mit einem Administratorkonto an und führen Sie die folgenden Befehle aus.

sudo apt update
sudo apt install --yes cups cups-filters printer-driver-gutenprint
sudo systemctl enable --now cups

3.2 Konfiguration anpassen

  1. Sichern Sie die mitgelieferte Konfigurationsdatei.
  2. Öffnen Sie die Datei /etc/cups/cupsd.conf in einem Texteditor.
  3. Ersetzen Sie die Abschnitte für Port und Zugriff durch den unten gezeigten Auszug.
  4. Starten Sie den Dienst neu und prüfen Sie das Protokoll auf Fehlermeldungen.

Der folgende Auszug zeigt die geänderten Abschnitte der Konfiguration.

Port 631
ServerAlias druck.verwaltung.local
DefaultEncryption Required

<Location />
  Order allow,deny
  Allow from 10.20.0.0/16
</Location>

<Location /admin>
  AuthType Default
  Require group druckadmins
</Location>

Hinweis: Ohne verschlüsselte Verbindung lehnen die Arbeitsplätze ab dem Sommer jede Druckanfrage ab.

5 Betrieb und Wartung

5.1 Tägliche Kontrolle

Prüfen Sie jeden Morgen die Warteschlangen auf hängende Aufträge. Aufträge, die älter als 24 Stunden sind, werden automatisch gelöscht.

5.2 Störungen

Bei einem Ausfall des Servers drucken die Arbeitsplätze nicht über einen Ersatzweg. Melden Sie Störungen deshalb sofort an die Leitstelle unter der internen Rufnummer 4711.
