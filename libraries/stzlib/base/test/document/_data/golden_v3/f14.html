Build Notes for the Ledger Service

PROJECT SETUP

The ledger service is built from a single repository. Install the toolchain before cloning the sources.

git clone https://example.org/ledger.git
cd ledger
make deps
make test VERBOSE=1
CONFIGURATION

The service reads its settings from a small file at start-up.

[server]
port = 8085
log_level = "info"

[storage]
path = "/var/lib/ledger"
    # keep the path absolute
RELEASE PROCESS

Releases are cut from the main branch every second Tuesday.

Never tag a release while the nightly build is red.

The release manager signs the tag and publishes the notes.
