Ledgerline 4.2 Release Notes

Released 9 June 2025 · Applies to self-hosted installations

Version 4.2 is a feature release that also changes how Ledgerline is configured. Hosted customers are upgraded automatically during the maintenance window of 15 June.

Highlights

  • Bank feeds can now be reconciled in bulk, with suggested matches ranked by confidence.
  • Multi-currency revaluation runs as a scheduled job instead of only at month end.
  • The audit trail records the client address and the API token used for every change.
  • PDF exports of reports are about three times faster on large ledgers.

Breaking changes

Read this section before upgrading, because two of these changes require action on your part.

  • 1. The configuration file is now YAML; the old INI format is no longer read.
  • 2. PostgreSQL 13 is the minimum supported database version.
  • 3. The /api/v1 endpoints have been removed; use /api/v2 instead.

Upgrading from 4.1

The upgrade takes about ten minutes for a ledger of one million postings. Always take a full database backup before you begin.

  1. Stop the Ledgerline service.
  2. Back up the database and the existing configuration file.
    1. Use pg_dump with the custom format.
    2. Copy ledgerline.ini to a safe place.
  3. Convert the configuration file to YAML, as in the example below.
  4. Install the new package and run the database migration.
  5. Start the service and check the log for the line “Ledgerline ready”.

Example configuration

server:
  port: 8080
  base_url: https://ledger.example.org
database:
  url: postgresql://ledgerline@db01/ledger
  pool_size: 20
jobs:
  revaluation: "0 2 * * *"
audit:
  retain_days: 2555
exports:
  workers: 4

Migration commands

sudo systemctl stop ledgerline
pg_dump -Fc -f ledger-4.1.dump ledger
sudo dpkg -i ledgerline_4.2.0_amd64.deb
sudo -u ledgerline ledgerline migrate --to 4.2
sudo systemctl start ledgerline

Known issues

Reports with more than 200 columns may be cut off in the PDF export. A fix is planned for version 4.2.1. Please report other problems through the support portal.
