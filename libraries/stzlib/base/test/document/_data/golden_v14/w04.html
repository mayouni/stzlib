Installationsanleitung MDS 4 Messdatenserver

Diese Anleitung beschreibt die Erstinstallation des Messdatenservers MDS 4 unter Linux. Sie richtet sich an Administratorinnen und Administratoren mit Grundkenntnissen der Kommandozeile.

1 Systemvoraussetzungen

1.1 Hardware

KomponenteMindestanforderungEmpfehlung
Prozessor4 Kerne, 2,0 GHz8 Kerne, 3,0 GHz
Arbeitsspeicher8 GB32 GB
Datenträger250 GB SSD1 TB NVMe im RAID 1
Netzwerk1 Gbit/s2 × 10 Gbit/s

1.2 Software

  • Debian 12 oder Ubuntu Server 24.04 LTS (64 Bit)
  • PostgreSQL 16 mit der Erweiterung TimescaleDB
  • OpenSSL 3.0 oder neuer
  • ein gültiges Serverzertifikat für den vorgesehenen Hostnamen

2 Installation

Melden Sie sich als Benutzer mit sudo-Rechten an und führen Sie die folgenden Schritte der Reihe nach aus.

1.Laden Sie das Installationspaket aus dem Kundenportal herunter.
2.Prüfen Sie die Prüfsumme des Pakets mit dem Befehl sha256sum.
3.Installieren Sie das Paket und aktivieren Sie den Dienst:
sudo apt update
sudo apt install ./mds4-server_4.2.1_amd64.deb
sudo systemctl enable --now mds4
systemctl status mds4
4.Legen Sie die Datenbank an und vergeben Sie ein sicheres Passwort für den Benutzer mds4.

Das Installationsprogramm legt den Systembenutzer, die Verzeichnisse unter /var/lib/mds4 und eine Beispielkonfiguration an. Bestehende Konfigurationsdateien werden bei einer Aktualisierung nicht überschrieben.

3 Konfiguration

Die zentrale Konfigurationsdatei liegt unter /etc/mds4/server.toml. Änderungen werden erst nach einem Neustart des Dienstes wirksam.

[server]
bind = "0.0.0.0:8443"
workers = 8

[database]
url = "postgresql://mds4@localhost:5432/messdaten"
pool_size = 20

[tls]
certificate = "/etc/mds4/tls/server.crt"
private_key = "/etc/mds4/tls/server.key"

3.1 Wichtige Parameter

ParameterStandardwertBedeutung
bind127.0.0.1:8443Adresse und Port, an denen der Server Verbindungen annimmt
workersAnzahl der KerneZahl der parallelen Verarbeitungsprozesse
pool_size10Höchstzahl gleichzeitiger Datenbankverbindungen
certificate—Pfad zum Serverzertifikat im PEM-Format

4 Inbetriebnahme prüfen

Rufen Sie nach dem Start die Statusseite unter https://<hostname>:8443/status im Browser auf. Wird die Seite nicht angezeigt, prüfen Sie das Protokoll mit journalctl -u mds4.

Hinweis: Öffnen Sie Port 8443 in der Firewall nur für die Netze, aus denen Messgeräte Daten senden.
