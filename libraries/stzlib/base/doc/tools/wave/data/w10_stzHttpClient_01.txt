init | Builds a client with no headers, no cookies, the user agent Softanza-HTTP/1.0 and the engine default timeouts. | nothing; the object is built | | SetHeader, Get_ | | every field starts from its declared default
SetUserAgent | Sets the User-Agent header sent with every later request, replacing Softanza-HTTP/1.0. | the client itself, so calls chain | cAgent=the User-Agent text | SetHeader, SetCookie | |
SetHeader | Adds one request header, sent with every later request, after the headers already added. | the client itself, so calls chain | cName=the header name; cValue=the header value | SetHeaders, SetUserAgent, SetBearer | | adding the same name twice sends both lines; a header named Authorization reaches the server (a loopback /auth answered 200)
SetHeaders | Replaces all the custom headers with a list of ready-made Name: Value lines. | the client itself, so calls chain | aHeaders=a list of texts, each Name: Value; an empty list removes every custom header | SetHeader | | headers added earlier through SetHeader are dropped
SetCookie | Adds one name=value cookie, sent in a single Cookie header with every later request. | the client itself, so calls chain | cName=the cookie name; cValue=the cookie value | SetCookies, SetCookieFile | | two cookies are joined as sid=abc; k=v (a loopback /checkcookie answered that text)
SetCookies | Replaces all the cookies with a list of ready-made name=value texts. | the client itself, so calls chain | aCookies=a list of texts, each name=value | SetCookie | | cookies added earlier through SetCookie are dropped
SetTraceParent | Sets the W3C traceparent header so a downstream service can place the request in the caller's trace. | the client itself, so calls chain | cTraceParent=a traceparent value such as 00-<trace id>-<span id>-01 | StartTrace, SetHeader | | the value is not validated, it is sent as given
StartTrace | Starts a fresh sampled trace, adds it as the traceparent header and returns its value. | a text, the new traceparent value | | SetTraceParent | | each call makes a new trace id, and the header is added, not replaced, so a second call sends two traceparent lines
SetTimeout | Sets the overall request timeout in seconds, so that Timeout and RequestTimeout both report it. | the client itself, so calls chain | nSeconds=the timeout in seconds, stored in milliseconds for the engine | SetRequestTimeout, SetConnectTimeout | | SetTimeout(5) makes RequestTimeout answer 5000
SetConnectTimeout | Sets how long the client waits to open a connection, in milliseconds. | the client itself, so calls chain | nMs=the connect timeout in milliseconds, 0 keeps the engine default of 5 seconds | ConnectTimeout, SetRequestTimeout | |
SetRequestTimeout | Sets how long one whole request may take, in milliseconds. | the client itself, so calls chain | nMs=the request timeout in milliseconds, 0 keeps the engine default of 30 seconds | RequestTimeout, SetTimeout | | a request that outlives it ends with ResponseCode -1 (loopback test 73_http_loopback_narrated)
ConnectTimeout | Returns the connect timeout this client was given, in milliseconds. | a number; 0 when the engine default applies | | SetConnectTimeout
RequestTimeout | Returns the request timeout this client was given, in milliseconds. | a number; 0 when the engine default applies | | SetRequestTimeout, SetTimeout
SetDefaultTimeouts | Sets the engine-wide default connect, request and idle timeouts for every client in the process. | the client itself, so calls chain | nConnectMs=the default connect timeout in milliseconds; nRequestMs=the default request timeout in milliseconds; nIdleMs=the idle timeout of pooled connections in milliseconds | SetConnectTimeout, SetRequestTimeout | | a value of 0 leaves that default unchanged, and the change outlives this client | it is process-wide, so a test that changes it should set the old values back
Shutdown | Closes the idle keep-alive connections held in the engine pool and counts them. | a number, how many idle sockets were closed | | PoolStats | | requests in flight are not touched, and 0 is the normal answer when every server closed its connection after the reply
PoolStats | Returns the connection pool counters as a hash list of opens, reuses, idle and active connections. | a hash list with the keys opens, reuses, idle and active, all numbers | | Shutdown | | the counters are process-wide, not per client
FollowRedirects | Switches the following of 3xx redirects on or off for later requests; it is on by default. | the client itself, so calls chain | bFollow=TRUE to follow redirects, FALSE to receive the 302 itself | VerifySSL, Get_ | | with it off, a 3-hop redirect chain answers 302, with it on 200
VerifySSL | Switches the check of the server's TLS certificate on or off for later requests; it is on by default. | the client itself, so calls chain | bVerify=TRUE to check certificates, FALSE to accept any | SetClientCert | | not run against a TLS server: only plain loopback HTTP was called, where it changes nothing
SetProxy | Routes later requests through a proxy, given as host:port. | the client itself, so calls chain | cProxy_=the proxy address such as 127.0.0.1:3128, an empty text removes the proxy | SetProxyAuth | | pointing at a port with nothing listening makes the request fail with ResponseCode -1
SetProxyAuth | Stores the user and password the client presents to its proxy, sent as user:password. | the client itself, so calls chain | cUser=the proxy user name; cPass=the proxy password | SetProxy | | it matters only while a proxy is set, and no authenticating proxy was available to run it against
SetAuth | Sets the user and password for HTTP authentication, Basic unless SetAuthType says otherwise. | the client itself, so calls chain | cUser=the user name; cPass=the password | SetAuthType, SetBearer | | a loopback /auth endpoint that wants any Authorization header answered 401 without it and 200 with it
SetAuthType | Chooses the HTTP authentication scheme that SetAuth uses. | the client itself, so calls chain | cType=basic, digest, ntlm, negotiate or any, in any case | SetAuth | | the text is stored in lower case, and only basic was run because the other schemes need a server that asks for them
SetBearer | Sets an OAuth2 bearer token sent as the Authorization header of later requests. | the client itself, so calls chain | cToken=the bearer token | SetAuth, SetHeader | | the token travels in clear on plain HTTP, and a loopback /auth endpoint answered 200
SetClientCert | Sets the client certificate and private key used for mutual TLS. | the client itself, so calls chain | cCertPath=the path of the PEM certificate file; cKeyPath=the path of the PEM private key file | VerifySSL | | not run against a TLS server: on plain HTTP with missing files the request still answered 200, so the paths are not read there
SetCookieFile | Sets a Netscape cookie file from which later requests read their cookies. | the client itself, so calls chain | cPath=the path of the cookie file | SetCookieJar, SetCookie | | give SetCookieJar the same path to keep cookies between requests
SetCookieJar | Sets the cookie file in which cookies received from servers are saved. | the client itself, so calls chain | cPath=the path of the file to write | SetCookieFile | | with the same path as SetCookieFile, a cookie set by /setcookie came back on the next request
AcceptEncoding | Asks servers for compressed answers and decompresses them, for the encodings named. | the client itself, so calls chain | cEnc=the encodings to advertise such as gzip, an empty text advertises every one the engine supports | AcceptGzip | | compression is off until this or AcceptGzip is called, and the loopback server never compresses, so only the call was checked
AcceptGzip | Asks servers for compressed answers in every encoding the engine supports and decompresses them. | the client itself, so calls chain | | AcceptEncoding | | the loopback server never compresses, so only the call was checked
Get_ | Sends a GET request and keeps the answer in the client. | the client itself, so read the answer with ResponseCode and ResponseBody | cUrl=the address to fetch | Post, ResponseBody, ResponseCode, GetMany | a transport failure gives ResponseCode -1 and sets LastError, while a 4xx or 5xx status is not an error, only a code | the name ends in an underscore because Get is taken by the language
Post | Sends a POST request with a body, content type application/octet-stream, and keeps the answer. | the client itself, so read the answer with ResponseBody | cUrl=the address to post to; cData=the request body as text | PostForm, PostJson, Put_ | | a loopback /echo answered with the same body
Put_ | Sends a PUT request with a body, content type application/octet-stream, and keeps the answer. | the client itself, so read the answer with ResponseBody | cUrl=the address to put to; cData=the request body as text | Post, Delete | | the name ends in an underscore because Put is taken by the language
Delete | Sends a DELETE request and keeps the answer. | the client itself, so read the answer with ResponseCode | cUrl=the address to delete | Get_, Head | |
Head | Sends a HEAD request, which returns the status and headers but no body. | the client itself, so read the answer with ResponseHeaders | cUrl=the address to ask about | Get_, ResponseHeaders | | ResponseBody stays empty
Options | Sends an OPTIONS request and keeps the answer. | the client itself, so read the answer with ResponseHeaders | cUrl=the address to ask about | Head, ResponseHeaders | |
PerformRequest | Does nothing and returns the client; it exists only so that older code that calls it still runs. | the client itself | | Get_, Post | | it sends no request, because it does not know which verb to use
Response | Returns the last answer as a hash list with its body, status code, header text and connection info. | a hash list with the keys body, code, headers and info | | ResponseBody, ResponseCode, ResponseHeaders | | before any request the code is 0 and the body is empty, and after a failed request the code is -1
ResponseCode | Returns the HTTP status of the last request. | a number; 0 before any request, -1 when no server was reached or the request timed out | | Response, Get_ | | a body over the 4 MB engine buffer gives -2
ResponseBody | Returns the body of the last answer. | a text; empty for HEAD and for a failed request | | ResponseCode, Response | |
ResponseHeaders | Returns the header block of the last answer as one text, status line first. | a text with CRLF between the lines | | ResponseBody, Response | |
ResponseTime | Returns 0 whatever happened, because the engine does not report how long a request took. | a number, always 0 | | Response | | it is a placeholder, so time the call yourself
PostForm | Sends a POST with the pairs as a URL-encoded form, content type application/x-www-form-urlencoded. | the client itself, so read the answer with ResponseBody | cUrl=the address to post to; aFormData=a flat list of key, value, key, value texts | Post, PostJson | | a space becomes + and an ampersand becomes %26 (the loopback echo returned a=1+2&b=x%26y)
PostJson | Sends a POST whose body is the given JSON text, content type application/json. | the client itself, so read the answer with ResponseBody | cUrl=the address to post to; cJson=the JSON text to send, which is not checked | Post, PostForm | |
DownloadFile | Fetches an address with a GET and writes the body to a local file. | the client itself | cUrl=the address to fetch; cLocalPath=the path of the file to write | Get_ | the file is overwritten if it exists | only a transport failure stops the write, an answer with status 404 is still written to the file
GetMany | Fetches several addresses in one parallel call, each with this client's headers, options and timeouts. | a list of hash lists, each with body, code, headers and info | aUrls=a list of at most 32 addresses | GetManySequential, Get_ | a bearer token set on the client is sent to every address | the answers come in the order of the addresses, headers is always empty and info an empty list, and an empty list of addresses gives an empty list
GetManySequential | Fetches several addresses one after the other and returns one full answer for each. | a list of hash lists as Response gives, with the real header text | aUrls=a list of addresses | GetMany, Response | | slower than GetMany and not limited to 32 addresses
