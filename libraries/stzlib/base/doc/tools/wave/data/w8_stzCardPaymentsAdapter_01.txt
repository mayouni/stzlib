init | Builds a card-gateway double with its own empty ledger, that approves everything until a rule says otherwise. | nothing; the object is built | | IsSandbox, Authorize | build it with parentheses or with StzCardPaymentsAdapterQ(): a paren-less new skips this step, and every object built that way shares one gateway and one ledger | its state lives in a global table, so a copy of the object (w = o) is the same gateway; money is in whole minor units, 4200 for 42.00
IsSandbox | Returns 1, the way a service double declares itself so that the registry can refuse it in production. | the number 1, always | | Authorize | | there is no live card adapter in the library: the Stripe, PayPal or Adyen side is yours to write behind the same verbs
ApproveUnder | Sets an approval ceiling: an authorization strictly below it is approved and one at or above it is declined; 0 removes the ceiling. | nothing; use ApproveUnderQ to chain | pnMinorUnits=the ceiling in minor units, 0 for none | DeclineOver, Authorize | | ApproveUnderQ is the same call and returns the object
DeclineOver | Sets a decline ceiling: an authorization at or above it is declined; 0 removes the ceiling. | nothing; use DeclineOverQ to chain | pnMinorUnits=the ceiling in minor units, 0 for none | ApproveUnder, Authorize | | DeclineOverQ is the same call and returns the object
DeclineToken | Adds a payment token that always declines, like the published test card of a real gateway; the rule lasts as long as the object. | nothing; use DeclineTokenQ to chain | pcToken=the token text to refuse, compared as text | Authorize, NumberOfDeclines | | DeclineTokenQ is the same call and returns the object
FailNext | Makes the next Authorize, Capture or Refund fail as if the gateway were unreachable; only that one call fails. | nothing; use FailNextQ to chain | | Authorize, Capture, Refund | the failure is taken by the next of those calls even if that call would have been refused anyway, and it is not recorded in the ledger | an outage is not a decline: the answer carries ok = 0, status refused and no id, and nothing was recorded
Authorize | Asks the gateway to approve an amount against a payment token and answers approved or declined, recording the movement. | a list [ ok, id, status, amount, why ]: status is authorized or declined, id is auth_1, auth_2 and so on, why says the cause of a decline | pnAmount=the amount in minor units, a positive whole number; pcToken=the payment token the customer presented | Capture, DeclineToken, ApproveUnder | an amount that is zero, negative, fractional or not a number is refused with ok = 0, status refused and an empty id; a decline is an answer that takes an id and counts in NumberOfDeclines, and the rules apply in the order token, decline ceiling, approval ceiling | nothing is captured yet: Capture takes the money
Capture | Takes the whole amount that was approved on an authorization; the money can be taken only once. | a list [ ok, id, status, amount, why ]: status is captured, or refused with the cause in why | pcId=the id returned by Authorize | CaptureAmount, Refund, StatusOf | a declined, unknown or already captured authorization is refused and the ledger does not move
CaptureAmount | Takes part of an authorization, or all of it when the amount is 0; a capture may not exceed what was authorized and happens once. | a list [ ok, id, status, amount, why ]: status is captured, or refused with the cause in why | pcId=the id returned by Authorize; pnAmount=the amount to take in minor units, 0 for the whole authorization | Capture, Refund | capturing less than the authorized amount closes the authorization: the rest cannot be captured later
Refund | Gives back the rest of what was captured on an authorization. | a list [ ok, id, status, amount, why ]: status is refunded, or refused with the cause in why | pcId=the id returned by Authorize | RefundAmount, NetCaptured | an authorization with nothing left to refund is refused, but the reason says an amount must be a positive whole number, which is true and is not the cause | StatusOf still reads captured after a refund; the refunded sum is read with RefundedOf
RefundAmount | Gives back part of the captured money, or all that is left when the amount is 0; the total refunded never exceeds what was captured. | a list [ ok, id, status, amount, why ]: status is refunded, or refused with the cause in why | pcId=the id returned by Authorize; pnAmount=the amount to give back in minor units, 0 for what is left | Refund, RefundedOf | an authorization that was never captured, or an amount over what is left, is refused and the ledger does not move
StatusOf | Returns the state of an authorization: authorized, declined or captured. | a text; empty for an unknown id | pcId=the id returned by Authorize | AmountOf, CapturedOf | | a refund does not change it: the state stays captured
AmountOf | Returns the amount that was asked for in the authorization. | a number in minor units; 0 for an unknown id | pcId=the id returned by Authorize | CapturedOf, StatusOf
CapturedOf | Returns how much of an authorization was captured. | a number in minor units; 0 when nothing was captured or the id is unknown | pcId=the id returned by Authorize | RefundedOf, AmountOf
RefundedOf | Returns how much of an authorization has been given back. | a number in minor units; 0 when nothing was refunded or the id is unknown | pcId=the id returned by Authorize | CapturedOf, NetCaptured
NumberOfAuthorizations | Returns how many authorizations the gateway holds, declined ones included. | a number | | NumberOfDeclines, NumberOfMovements | | a call refused before an id was given, such as a bad amount or an outage, is not counted
TotalAuthorized | Returns the sum asked for by the authorizations that were approved, whether or not they were captured since. | a number in minor units | | TotalCaptured, NumberOfAuthorizations | | declined authorizations are left out, and a refund does not lower it
TotalCaptured | Returns the sum captured across every authorization. | a number in minor units | | TotalRefunded, NetCaptured | | a refund does not lower it: NetCaptured does
TotalRefunded | Returns the sum given back across every authorization. | a number in minor units | | TotalCaptured, NetCaptured
NetCaptured | Returns what the merchant keeps: the captured sum less the refunded sum. | a number in minor units | | TotalCaptured, TotalRefunded
NumberOfDeclines | Returns how many authorizations were declined, by a token or by a ceiling. | a number | | DeclineToken, NumberOfAuthorizations
Movements | Returns the ledger of what happened to the money, oldest first, one record per authorize, decline, capture or refund. | a list of records [ seq, kind, id, amount ] where kind is authorize, decline, capture or refund | | NumberOfMovements, NetCaptured | | a refused call leaves no record: a test asserts on what the money did, not on the return value
NumberOfMovements | Returns how many records the ledger holds. | a number | | Movements
Show | Prints one summary line of the gateway: how many authorizations, and the captured, refunded and net sums. | nothing; it prints a line | | NetCaptured, TotalCaptured | | the line begins with stzPaymentsSandbox, whatever the class used
