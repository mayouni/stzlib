init | Builds an empty constellation of worlds with its own graph, its own governance and a shared Commons. | nothing; the object is built | pcName=the constellation's name, kept as text | AddWorld, Bond
Name_ | Returns the constellation's name. | a text | | init
Why | Returns the reason given by the last CallAcross, whether it was allowed or refused. | a text; empty before any call | | CallAcross, Crossings | a failure in the Commons, such as a user already registered, is explained by CommonsQ().Why(), not here
GraphQ | Returns the constellation graph: one node per world and one bond edge per bonded pair. | a stzGraph object | | AddWorld, Bond
GovernanceQ | Returns the ambient governance that clears cross-world calls. | a stzGovernance object | | GovDeclareRisk, GovGrant, GovSetAuthority | configure it through the Gov methods of the constellation, not through this copy
CommonsQ | Returns the shared Commons, the stzPlatform that holds identities, sessions and the key-value store. | a stzPlatform object | | OpenCommonsOn, RegisterIdentity
AddWorld | Registers an app as a named, active world and adds a node for it to the graph. | the constellation itself, so calls chain | pcName=the world's name, which must be new here; poApp=the world object, usually a stzApp | AddConstellation, WorldQ, Retire | raises an error when a world of that name is already registered
AddConstellation | Registers another constellation as a named, active world, so constellations nest. | the constellation itself, so calls chain | pcName=the world's name, which must be new here; poSuper=the inner stzSuperApp | AddWorld, KindOf | raises an error when the name is taken | the world's kind then reads super
WorldQ | Returns the live object registered under a name. | the world object; an empty text when the name is unknown | pcName=the world's name | KindOf, Swap | the name is matched exactly, letter case included
KindOf | Returns whether a world is a plain app or a nested constellation. | app or super as text; an empty text when the name is unknown | pcName=the world's name | WorldQ, AddConstellation
WorldNames | Returns the names of all registered worlds, in the order they joined, retired ones included. | a list of text | | NumberOfWorlds, HasWorld
NumberOfWorlds | Returns how many worlds are registered, retired ones included. | a number | | WorldNames
HasWorld | TRUE if a world of that name is registered, active or not. | TRUE or FALSE | pcName=the world's name | IsActive, WorldNames
IsActive | TRUE if the world is registered and not retired. | TRUE or FALSE; FALSE for an unknown name | pcName=the world's name | Retire, Revive
Retire | Switches a world off, so that every call to or from it is refused until it is revived. | the constellation itself, so calls chain | pcName=the world's name | Revive, IsActive, CallAcross | raises an error for an unknown name | the world's bonds and node stay
Revive | Switches a retired world back on. | the constellation itself, so calls chain | pcName=the world's name | Retire, IsActive | raises an error for an unknown name
Swap | Replaces a world's object with a new one, switches it on and keeps its node and its bonds. | the constellation itself, so calls chain | pcName=the name of an existing world; poNewApp=the object that takes its place | WorldQ, Retire | raises an error for an unknown name | the kind recorded for the world is not changed
OpenCommonsOn | Backs the shared Commons with an open database, creating its tables. | the constellation itself, so calls chain | poDb=an open stzDatabase, such as one made on :memory: | RegisterIdentity, StorePut | keep the database open for as long as the constellation uses the Commons
RegisterIdentity | Stores a user in the Commons with a salted hash of the secret, never the secret itself. | TRUE if registered, FALSE when the user already exists | pcUser=the user name; pcSecret=the secret to hash | OpenSession, CommonsQ | raises an error until OpenCommonsOn has run | the reason for a FALSE is in CommonsQ().Why()
OpenSession | Checks a user's secret and, when right, opens a session in the Commons. | a text, the session token beginning with sess_; an empty text when refused | pcUser=the user name; pcSecret=the secret to check | RegisterIdentity | raises an error until OpenCommonsOn has run
StorePut | Saves a text under a key in the Commons' shared store, replacing an older value. | the constellation itself, so calls chain | pcKey=the key; pcValue=the text to keep | StoreGet | raises an error until OpenCommonsOn has run
StoreGet | Returns the text saved under a key in the Commons' shared store. | a text; empty for an unknown key | pcKey=the key | StorePut | raises an error until OpenCommonsOn has run
GovDeclareRisk | Declares how risky an action is, on a scale from 1 to 4; an undeclared action is never cleared. | the constellation itself, so calls chain | pcAction=the action's name; nTier=the risk, 1 low to 4 critical | GovGrant, GovSetAuthority, CallAcross | a tier outside 1 to 4 raises an error
GovGrant | Gives a world the permission to attempt an action. | the constellation itself, so calls chain | pcActor=the name of the calling world; pcAction=the action's name | GovDeclareRisk, GovSetAuthority, CallAcross
GovSetAuthority | Sets how far a world may act on its own: advisory, delegated, autonomous or emergencyoverride. | the constellation itself, so calls chain | pcActor=the name of the calling world; pcType=:Advisory, :Delegated, :Autonomous or :EmergencyOverride | GovGrant, CallAcross | any other word raises an error | the level must reach the action's risk tier, tier 2 needing :Delegated
Bond | Declares that one world may attempt an action on another, and draws a bond edge between them. | the constellation itself, so calls chain | pcFrom=the calling world; pcTo=the target world; pcAction=the action's name | AreBonded, CallAcross | raises an error unless both worlds are registered | a bond runs one way, the target and the action are stored in lower case, and the graph gets one edge per pair however many actions are bonded
AreBonded | TRUE if a bond declares that action from the first world to the second. | TRUE or FALSE | pcFrom=the calling world, matched exactly; pcTo=the target world; pcAction=the action's name | Bond, CallAcross | the target and the action are matched without regard to case, the calling world exactly
CallAcross | Decides whether one world may act on another: both must be active, a bond must declare the action and governance must clear the caller. | TRUE if allowed, FALSE if refused | pcFrom=the calling world; pcTo=the target world; pcAction=the action's name | Why, Crossings, Bond, GovGrant | it only decides and records, it calls nothing in the target; every outcome is timed and logged, and a refusal also enters the incident evidence | Why says which of the four checks refused
Crossings | Returns the log of decisions made by CallAcross, oldest first, the newest 256 at most. | a list of rows [ from, to, action, allowed, durationMs ], allowed being 1 or 0 | | CrossingCount, LastCallMs | the target and the action are in lower case
CrossingCount | Returns how many decisions the log holds, at most 256. | a number | | Crossings
LastCallMs | Returns how long the last CallAcross took, in milliseconds. | a number, often a fraction; 0 before any call | | Crossings
