init | Compiles a formula of named variables, such as "x^2 + 3*x*y", so its value and exact derivatives can be asked at any point. | nothing; the object is built | pcExpression=the formula as text, with + - * / ^ , parentheses and the functions exp, log, sqrt, sin, cos, tan, tanh, abs, min, max, pow, and the constants pi and e; pacVariables=the names of the variables, in the order points will be given | ValueAt, GradientAt | an empty formula, an empty variable list, a formula with a character it cannot use, or a name that is not a listed variable raises an error saying why |
Expression | Returns the formula text as it was given. | a text | | Variables | |
Variables | Returns the variable names in the order they were declared, which is the order of every point and gradient. | a list of texts | | NumberOfVariables | |
NumberOfVariables | Returns how many variables the formula has. | a number | | Variables | |
ValueAt | Returns the value of the formula at a point, without computing derivatives. | a number | paPoint=the values of the variables, one per variable in declared order, such as [ 2, 3 ] | GradientAt, ValueAndGradientAt | a point with the wrong number of values raises "This function has 2 variable(s); the point has 1."; a point outside the domain gives inf, -inf or nan, not an error; after Free it answers 0 | "x^2 + 3*x*y" at [ 2, 3 ] is 22
GradientAt | Returns the exact partial derivatives at a point, one per variable in declared order, by reverse-mode automatic differentiation. | a list of numbers | paPoint=the values of the variables, one per variable in declared order | DerivativeAt, ValueAndGradientAt | | not a finite difference: the derivatives are exact; at [ 2, 3 ] the gradient of x^2 + 3*x*y is [ 13, 6 ]
ValueAndGradientAt | Returns the value and the gradient at a point from one backward pass, cheaper than asking for each. | a hash list [ :value = number, :gradient = list of numbers ] | paPoint=the values of the variables, one per variable in declared order | ValueAt, GradientAt | |
DerivativeAt | Returns the partial derivative with respect to one named variable at a point. | a number | pcVar=the name of the variable, in any case; paPoint=the values of all the variables, in declared order | GradientAt | | a name that is not a variable raises an error listing the variables
Free | Releases the compiled formula held by the engine, which Ring cannot do by itself. | nothing | | init | | after it the object answers 0 to ValueAt instead of raising: do not use it again
