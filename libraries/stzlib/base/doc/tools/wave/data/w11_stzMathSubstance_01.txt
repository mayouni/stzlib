init | Builds an empty body of content, objects and relations, to be written in a given domain. | nothing; the object is built | poDomain=the stzMathDomain the content is written in; anything that is not an object raises an error | Declare, Assert
DomainQ | Returns the domain object the substance is written in. | a stzMathDomain | | init
Declare | Declares an object of a type under a name. | the substance itself, so calls chain | pcType=a type of the domain; pcName=the object's name: a letter or underscore, then letters, digits and underscores, because it heads every path a style writes | DeclareAll, TypeOf, Assert | an unknown type, an empty name, a name that starts with a digit or holds a space, and a name declared twice raise errors; names are case sensitive, but ToGraph refuses two that differ only by case | DeclareQ is the same call
DeclareAll | Declares several objects of one type, one for each name. | the substance itself, so calls chain | pcType=a type of the domain; pacNames=the list of names | Declare | a bad name stops the loop, after the earlier names were declared
HasObject | TRUE if an object of that name is declared. | TRUE or FALSE | pcName=the object's name, matched with its case | Declare, TypeOf | | u is found, U is not
TypeOf | Returns the type an object was declared with. | a text; empty for an undeclared name | pcName=the object's name, matched with its case | Declare, ObjectsOfType | | the declared type, even when it is a subtype
Objects | Returns the declared objects as [ name, type ] pairs, in the order declared. | a list of pairs | | ObjectNames, ObjectsOfType
ObjectNames | Returns the names of the declared objects, in the order declared. | a list of text | | Objects
ObjectsOfType | Returns the names of the objects whose type is a given type or a kind of it. | a list of text, in the order declared | pcType=the type to ask for | Objects, TypeOf | | asking for Vec returns the objects declared as Unit too, when Unit is a kind of Vec
Assert | States a relation over declared objects, checked against the domain's predicate. | the substance itself, so calls chain | pcPredicate=a predicate of the domain, in any case; pacArgs=the object names in order, or one name for a one-argument predicate; each must match the predicate's type, a kind of it being accepted | Holds, Relations, Declare | an unknown predicate, a wrong count, an undeclared object or a wrong type raises an error naming which; the same relation can be asserted twice and is then held twice | AssertQ is the same call
Relations | Returns the stated relations as [ predicate, arguments ] pairs, in the order stated. | a list of pairs | | Assert, Holds
Holds | TRUE if the substance states a predicate over exactly these objects. | TRUE or FALSE | pcPredicate=the predicate's name, in any case; pacArgs=the object names in order | Assert, Relations | the order matters unless the domain declared the predicate symmetric; the objects are matched with their case | a relation stated for u and v does not hold for v and u unless it is symmetric
Define | Declares an object as the result of a function applied to declared objects, and remembers the definition. | the substance itself, so calls chain | pcName=the new object's name, which takes the function's output type; pcFunction=a function of the domain; pacArgs=the argument objects in order | Definitions, IsDefinedAs, Declare | an unknown function, a wrong count, an undeclared object or a wrong type raises an error | DefineQ is the same call
Definitions | Returns the definitions as [ name, function, arguments ] triples, in the order made. | a list of triples | | Define, IsDefinedAs
SetData | Puts a number on an object under a key, which a style can read as name.key to drive a position or a colour. | the substance itself, so calls chain | pcName=the object, which should be declared; pcKey=the key: a letter or underscore, then letters, digits and underscores; pnValue=the number; a text raises an error | DataOf, HasData, SetDataFrom | an undeclared object raises no error and the number is lost: HasData and DataOf then do not find it, which is a defect, seen with ghost and phantom; setting a key again replaces its value | SetDataQ is the same call
SetDataFrom | Puts a list of numbers on the objects named prefix1, prefix2 and so on, one each, under a key. | the substance itself, so calls chain | pcPrefix=the name prefix, such as e for e1, e2; pcKey=the key; paValues=the numbers in order | SetData, Declare | an object that is not declared gets no error and its number is lost, as in SetData | the objects must have been declared as e1, e2, and so on
HasData | TRUE if an object carries a number under a key. | TRUE or FALSE | pcName=the object's name; pcKey=the key | SetData, DataOf
DataOf | Returns the number an object carries under a key. | a number | pcName=the object's name; pcKey=the key; a missing key raises an error | SetData, HasData
ToGraph | Returns the substance as a stzGraph: each object a node, each relation an edge, each definition edges to its arguments. | a stzGraph | | Relations, Definitions | a relation that would repeat an existing edge, and any relation over three or more objects, becomes a node named rel_ plus the predicate and a number, with an edge to each argument; two names that differ only by case raise an error, because the graph folds ids to lower case | ToGraphXT takes the option projectConstructors; a one-argument predicate is not an edge but is listed in the node's unary property
IsDefinedAs | TRUE if an object was defined by a function over exactly these arguments, in order. | TRUE or FALSE | pcName=the defined object; pcFunction=the function's name, in any case; pacArgs=the argument names in order | Define, Definitions | | an object that was declared and not defined answers FALSE
Label | Gives an object the text a diagram writes for it. | the substance itself, so calls chain | pcName=a declared object, else an error is raised; pcLabel=the text | LabelOf, AutoLabelAll | LabelQ is the same call
AutoLabelAll | Makes every object without a label of its own carry its name as its label. | the substance itself, so calls chain | | Label, LabelOf
LabelOf | Returns the label of an object: the one given, else its name when automatic labels are on, else an empty text. | a text | pcName=the object's name | Label, AutoLabelAll
