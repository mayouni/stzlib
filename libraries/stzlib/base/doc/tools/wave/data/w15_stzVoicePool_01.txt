# w15 stzVoicePool -- Start opens a sound card, so the started pool was NEVER run: Start, Fire after Start, the gain after Start, Stop and the transport clock are read from the code and marked not run; nothing was heard (UNPERCEIVED)
init | Builds an empty voice pool and its audio graph, stereo at a sample rate, without opening a device. | nothing; the object is built | pnRate=the sample rate in hertz; a value of 0 or less gives 48000 | AddVoice, Start | | StzVoicePoolOfQ builds the same object; nothing is audible until Start
AddVoice | Adds a voice made from an existing sound, with a number of slots so it can overlap itself. | nothing; the voice is added. AddVoiceQ returns the pool for chaining | pName=the voice name, matched in lower case; poSound=the stzSound to fire; pnSlots=how many shots may sound at once, 1 or more | AddToneVoice, Fire | adding to a pool that is already started counts a refusal and sets LastError to AddVoice: the pool is already started -- build it first | a slot count below 1 gives 1; the sound is built into the graph once and Fire plays that one sound: there is no pitch or volume for each shot and no panning
AddToneVoice | Adds a voice made from an oscillator and a short envelope, such as a blip or a coin. | nothing; the voice is added. AddToneVoiceQ returns the pool for chaining | pName=the voice name, matched in lower case; pWave=the waveform, such as :Square or :Sine; pnHz=the pitch in hertz; pnSeconds=how long one shot lasts; pnSlots=how many shots may sound at once, 1 or more | AddVoice, Fire | adding to a started pool counts a refusal as AddVoice does | a slot count below 1 gives 1; each slot has its own oscillator and an envelope with a 4 ms attack
Start | Mixes every voice through its own gain bus, opens the device and starts the render, silent until a voice is fired. | the pool itself, so calls chain | | Fire, Stop, IsStarted | not run: it opens a sound card; with no voice it counts a refusal and sets LastError to Start: the pool has no voices, which was run, and a pool that cannot start is left not started with the device error in LastError | from here the graph shape is frozen; every voice starts spent, rendered past its longest shot and discarded, so the pool makes no noise when it opens; StartQ is the same call
Fire | Sounds a voice now, returning at once; the render picks the shot up at its next block. | the pool itself, so calls chain; FireQ is the same call | pName=the voice name | Start, StealsOf, FiresOf | an unknown name counts a refusal and sets LastError to no voice is named ...; a pool not started counts a refusal and sets LastError to Fire: call Start() first, both run; the started path was not run: it posts a trigger to the render thread | slots are taken in turn, so a voice with four slots can sound four times at once and the fifth shot steals the oldest; a steal is counted from the clock only when the slot had not finished, so a shot that lands on a spent slot is not a steal
SetVoiceGain | Ramps the gain of one voice bus, so one voice can be turned down without touching another. | the pool itself, so calls chain; SetVoiceGainQ is the same call | pName=the voice name; pnGain=the gain to reach, 1 for unchanged; pnRampMs=the length of the ramp in milliseconds | VoiceGain, Fire | an unknown name, or a call before Start, counts a refusal and sets LastError to no voice is named ... or SetVoiceGain: the bus does not exist until Start(), both run | the gain is ramped and never assigned, because a step is a click; the write is one atomic store the render reads each block, so nothing is allocated; the ramp after Start was not run
VoiceGain | Returns the gain the render is applying to a voice right now. | a number, between the old and the new value during a ramp; -1 for an unknown voice or before Start | pName=the voice name | SetVoiceGain, BusNodeOf | | -1 before Start was run; read afresh from the engine, not remembered, so a guard can see a ramp both move and arrive
BusNodeOf | Returns the graph node of a voice's gain bus. | the node number; 0 for an unknown voice or before Start | pName=the voice name | VoiceGain, Graph | | the bus exists only after Start
Stop | Stops the transport and marks the pool as not started. | the pool itself, so calls chain | | Start, Release | not run with a started pool: it stops the sound card; before Start it only clears the flag |
Release | Stops the pool and frees the transport and the graph. | nothing | | Stop | | before Start it frees the graph only; run that way, it did nothing visible
IsStarted | TRUE if the pool has been started. | TRUE or FALSE, as 1 or 0 | | Start, Stop |
Transport | Returns the stzSoundTransport that plays the pool, the one device clock of the plane. | the transport; an empty text before Start | | PositionInSeconds, Underruns | | before Start it was an empty text
Graph | Returns the audio graph the voices are built into. | a stzSoundGraph | | Transport, AddVoice | | the voices' slot nodes are private to the pool
LastError | Returns the reason of the last refusal. | the reason as text; an empty text when nothing was refused | | Refusals |
Refusals | Returns how many calls were refused. | a number | | LastError | | it counts an add after Start, a start with no voice, a fire of an unknown voice or before Start, and a gain of an unknown voice or before Start
VoiceNames | Returns the names of the voices in the order they were added. | a list of text; [ ] for an empty pool | | SlotsOf, AddVoice |
SlotsOf | Returns how many slots a voice has. | a number; 0 for an unknown voice | pName=the voice name, matched in lower case | VoiceNames, FiresOf | | an added voice with 0 slots has 1
FiresOf | Returns how many times a voice was fired. | a number; 0 for an unknown voice or a voice never fired | pName=the voice name | StealsOf, Fire |
StealsOf | Returns how many shots landed on a slot that was still sounding. | a number; 0 for an unknown voice | pName=the voice name | FiresOf, SlotsOf | | not an error, it is the pool doing its job: a number to read before deciding a voice needs more slots
PositionInSeconds | Returns the time on the transport's clock. | a number of seconds; 0 before Start | | Transport, Underruns | not run after Start: it reads the device clock | the same clock the rest of the plane reads
Underruns | Returns how many blocks the device wanted and the render did not have. | a number; 0 before Start | | PositionInSeconds, Transport | not run after Start: it reads the device | the counter tells delivery, not whether anything sounded right, which only a person can say
