init | Loads a font from a file path or from its own bytes; raises an error when nothing is given or the engine cannot read it as TTF or OTF. | nothing; the font is built | pcPathOrBytes=A path to a TTF or OTF file, or the bytes of one; a text shorter than 512 characters that names an existing file is read as a path | Source, GlyphCount | | the bytes route lets a font come from a resource bundle or a database blob; Source then answers "(bytes)"
Id_ | Returns the engine's number for the loaded font, 0 once the font has been released. | a number | | IsAlive, Free
Source | Returns the file path the font was loaded from, or "(bytes)" when it was built from bytes. | text | | init, Id_
IsAlive | TRUE if the font is still loaded in the engine; FALSE once it has been released. | TRUE or FALSE | | Free, GlyphCount
GlyphCount | Returns how many glyphs the font file holds, or -1 once the font has been released. | a number | | IsAlive
AddFallback | Appends a font to the fallback chain, to supply the glyphs this font lacks; raises an error for a non-font, itself or a ninth link. | the font itself, so calls can be chained | poFont=The stzFont to add behind this one | FallbackCount, ClearFallbacks, CoverageOf | | adding the same font twice does nothing and raises nothing; the font itself is always asked first; the chain holds at most eight fonts
FallbackCount | Returns how many fonts stand in the fallback chain behind this one. | a number; -1 once the font has been released | | AddFallback, HasFallbacks
HasFallbacks | TRUE if at least one fallback font has been added. | TRUE or FALSE | | FallbackCount, AddFallback
ClearFallbacks | Empties the fallback chain, leaving this font to draw alone. | the font itself | | AddFallback, FallbackCount
CoverageOf | Reports what the chain did to a text: how many glyphs came from a fallback font and how many no font could draw. | a list of two numbers [ fallback, notdef ] | pcText=The text to measure; pnSize=The font size, in pixels | DrawsEveryGlyphOf, AddFallback | | the notdef glyphs are the hollow boxes that appear on screen
DrawsEveryGlyphOf | TRUE if every character of the text has a real glyph in this font or its fallbacks, so no hollow box would appear. | TRUE or FALSE | pcText=The text to test; pnSize=The font size, in pixels | CoverageOf, AddFallback | a freed font answers TRUE, because it counts no missing glyph | for the Korean word 안녕 in Segoe UI the answer is FALSE until a Korean font is added as a fallback
WidthOf | Returns the shaped advance width of a text in pixels, the number to centre or right-align a label by; 0 for an empty text. | a number of pixels | pcText=The text to measure; pnSize=The font size, in pixels | RunCountOf, InkOf, LineHeightOf | | the width comes from the real shaper, so it is right for Arabic and other joined scripts as well as for Latin
RunCountOf | Returns how many visual runs the text breaks into: 1 for pure Latin or pure Arabic, 3 for Arabic between Latin words. | a number | pcText=The text to analyse; pnSize=The font size, in pixels | IsRtlParagraph, GlyphsOf | | 0 for an empty text or a freed font
GlyphsOf | Returns the positioned glyphs of a text in visual order, one list of nine numbers per glyph. | a list of lists [ gid, x, y, byteCluster, pen, advance, clusterEnd, bidiLevel, fontId ]; [ ] for an empty text | pcText=The text to shape; pnSize=The font size, in pixels | WidthOf, RectsOfRange | | x is where the glyph is drawn and [pen, pen + advance) is its hit-test box, two different numbers; the ninth number, the id of the font that supplied the glyph, is not in the source comment, which says eight
MetricsOf | Returns the vertical metrics of the font at a size: ascender and descender, both positive from the baseline, and line gap. | a list of three numbers [ ascender, descender, lineGap ]; [ 0, 0, 0 ] for an empty text | pcText=Any text; only an empty one changes the answer, to zeros; pnSize=The font size, in pixels | LineHeightOf, InkOf | | the metrics are the font's, the same for every text
LineHeightOf | Returns the full line height in pixels: ascender plus descender plus line gap at the size. | a number of pixels | pcText=Any text; only an empty one changes the answer, to 0; pnSize=The font size, in pixels | MetricsOf, CapHeightOf | | 31.92 for Segoe UI at size 24
InkOf | Returns how far the shaped ink of a text reaches above and below the baseline, which is tighter than the font's em box. | a list of two numbers [ above, below ] in pixels, both positive; [ 0, 0 ] for an empty text | pcText=The text whose ink is measured; pnSize=The font size, in pixels | CapHeightOf, MetricsOf | | an H reaches the cap height and 0 below, a g reaches its x-height above and its descender below
CapHeightOf | Returns the height in pixels of a capital H at the size, measured from its ink; the number a label centred by eye should be centred on. | a number of pixels | pnSize=The font size, in pixels | InkOf, LineHeightOf
IsRtlParagraph | TRUE if the base direction of the text is right to left, which decides on which side of the last character the caret ends. | TRUE or FALSE | pcText=The text to test; pnSize=The font size, in pixels | RunCountOf | | FALSE for an empty text or a freed font
RectsOfRange | Returns the screen rectangles covered by a range of bytes of the text; a range crossing a direction change comes in several pieces. | a list of [ x, top, width, height ] rectangles, x from the text origin and y measured down from the baseline at 0; [ ] for an empty range | pcText=The text; pnSize=The font size, in pixels; pnStart=The byte offset where the range starts, 0 for the first byte; pnEnd=The byte offset where the range ends, not included | CaretRectAt, GlyphsOf | | the offsets count bytes, so an Arabic letter takes two
CaretRectAt | Returns the zero-width, full-line-height rectangle where a caret sits at a byte offset; an input method places its window by it. | a list of four numbers [ x, top, 0, height ] | pcText=The text; pnSize=The font size, in pixels; pnIndex=The byte offset of the character the caret is at; pbTrailing=1 for the trailing edge of that character, 0 for the leading edge | IndexAtPoint, RectsOfRange | | at a direction change one offset has two screen positions, and the trailing flag picks between them; pass back the flag IndexAtPoint gave for an exact round trip
IndexAtPoint | Returns which character lies under a horizontal position of the text, the reverse of the caret query. | a list of three numbers [ index, trailing, caretByte ]; [ 0, 0, 0 ] for a freed font | pcText=The text; pnSize=The font size, in pixels; pnX=The horizontal position in pixels from the text origin | CaretRectAt | | index is the first byte of the character, trailing is 1 when the point lies in its second half, and caretByte is the index already resolved through trailing
Free | Releases the loaded font in the engine and sets its id to 0; later measurements answer 0 or an empty list. | nothing | | IsAlive, Id_ | | a copy of the object made earlier keeps the old id but answers FALSE to IsAlive; freeing twice is harmless
