# stzGeoProjection -- 44 kinds; Project takes (lon, lat) and answers paper units, y growing DOWN
init | Builds the projection called pKind (case ignored) with default parameters; raises an error naming all 44 kinds when pKind is unknown. | nothing; the object is built | pKind=the projection's name as text or a symbol, such as :Mercator, :EqualEarth or :Orthographic | Name, StzGeoProjectionKinds | | The defaults are scale 150, translation 480, 250, no rotation. The conics start with parallels 30 and 30; the others with 0 and 0
Name | Returns the canonical name of the projection, as the engine spells it. | text, for example "Mercator" | | KindNumber, Caption| | 
KindNumber | Returns the engine's own index of the projection, counted from 0 in the order StzGeoProjectionKinds lists them. | a number from 0 to 43, 1 for Mercator | | Name, Params| | 
Params | Returns the eleven numbers that define the projection, in the order the engine reads them. | a list [ kind, yaw, pitch, roll, parallel1, parallel2, scale, translateX, translateY, clipAngle, precision ] | | Rotate, Scale, Translate, ClipAngle, Precision | | The object holds nothing else, so this list is the whole truth about it
DistortionAt | Returns how the projection distorts the map at one place: scales along and across, area scale and bending. | a hash list [ :h, :k, :a, :b, :areal, :angular, :crossing ]: meridian and parallel scale, greatest and least scale, area scale, largest angle bent in degrees, angle at which they cross | pnLon=longitude in degrees east; pnLat=latitude in degrees north | ArealScaleAt, AngularDistortionAt, Distortion | | On Mercator at 70 N the area scale is 8.55 and no angle is bent. 1 means true
ArealScaleAt | Returns how many times larger or smaller than on the ground a small area at this place is drawn. | a number, 1 where true, 8.55 for Mercator at 70 degrees north, 0 when the place has no image | pnLon=longitude in degrees east; pnLat=latitude in degrees north | DistortionAt, AngularDistortionAt | | Equal-area projections answer 1 everywhere
AngularDistortionAt | Returns the largest angle, in degrees, that the projection bends at this place. | a number of degrees, 0 for a conformal projection and 0 when the place has no image | pnLon=longitude in degrees east; pnLat=latitude in degrees north | DistortionAt, ArealScaleAt| | 
Distortion | Returns the area and angle distortion of the whole map, weighted by the ground each cell covers, over a 72 by 36 grid. | a hash list [ :arealMin, :arealMax, :arealMean, :angularMax, :angularMean, :sampled ] | | HoldsItsClaim, DistortionAt | | Mercator: mean area x3.11 and largest x58.7; EqualEarth: area 1 everywhere and mean bend 29.1 degrees
HoldsItsClaim | TRUE if the measured distortion agrees with what the projection claims: area scale 1 for equal-area, no bend for conformal. | TRUE or FALSE | | Distortion, IsEqualArea, IsConformal | | A check on the formulas, not on a map
IndicatrixAt | Returns the projected outline of a small circle of true radius pnRadiusDeg around a place, Tissot's indicatrix, 48 points. | a flat list of 96 numbers x, y, x, y, ... in paper units, to draw as a closed polygon | pnLon=longitude in degrees east of the circle's centre; pnLat=latitude in degrees north of the circle's centre; pnRadiusDeg=radius of the circle on the ground, in degrees of arc | DrawTissotOn, DistortionAt | | Built by projecting the circle, so it shows the bending an ellipse could not
IsEqualArea | TRUE if the projection preserves areas, so a region of the ground has the same area on paper everywhere. | TRUE or FALSE | | IsConformal, HoldsItsClaim | | A choropleth of a density wants this
IsConformal | TRUE if the projection preserves angles, so small shapes keep their form. | TRUE or FALSE | | IsEqualArea| | 
IsAzimuthal | TRUE if the projection is azimuthal, drawing the sphere around one centre point. | TRUE or FALSE | | ClipAngle, CenterOn| | 
IsConic | TRUE if the projection is a cone developed on two standard parallels, whose name starts with Conic. | TRUE or FALSE | | Parallels | | Polyconic is not counted
Rotate | Turns the sphere under the map by yaw, pitch and roll, in degrees, as d3 does; a missing roll is 0. | nothing; the rotation is stored | paLPG=the rotation as [ yaw, pitch, roll ] in degrees, or [ yaw, pitch ] | CenterOn, RotationOf | | To put a place at (lon, lat) in the middle rotate by [ -lon, -lat, 0 ]. A roll puts north somewhere other than up
CenterOn | Rotates the sphere so the place at (pnLon, pnLat) sits in the middle of the map. | nothing; the rotation is stored | pnLon=longitude in degrees east of the new centre; pnLat=latitude in degrees north of the new centre | Rotate, Center | | The same as Rotate([ -pnLon, -pnLat, 0 ])
Parallels | Sets the standard parallels, in degrees north; a single number serves for both. | nothing; the parallels are stored | paP=a list with one or two latitudes in degrees | IsConic | | Used by the conics and the cylindrical equal-area; Equirectangular ignores them
Scale | Sets the scale factor, in paper units per radian of the unit sphere; the default is 150. | nothing; the scale is stored | pn=the scale factor | Translate, ScaleOf, FitToSphere | | A Fit method overwrites it
Translate | Sets where the centre of the projection falls on the paper; the default is 480, 250. | nothing; the translation is stored | paXY=the paper position of the centre as [ x, y ] | Scale, TranslateOf | | It REPLACES the translation a Fit just computed instead of adding to it
ClipAngle | Sets the angle from the centre, in degrees, beyond which an azimuthal map shows nothing. | nothing; the angle is stored | pn=the clip angle in degrees, 0 for no clipping | IsAzimuthal | | Defaults seen: 90 for Orthographic, 142 for Stereographic, 0 for Mercator. With 60, a place 70 degrees from the centre has no image
Precision | Sets how closely lines follow curves: the tolerance, in paper units, below which the engine stops adding points. | nothing; the precision is stored | pn=the tolerance, 0.7 by default and smaller for a smoother line | Line, Ring | | A straight parallel on Mercator needs no extra point whatever the value
ScaleOf | Returns the scale factor set by Scale or by a Fit method. | a number | | Scale, FitToSphere| | 
TranslateOf | Returns where the centre of the projection falls on the paper. | a list [ x, y ] | | Translate| | 
RotationOf | Returns the rotation as it is stored. | a list [ yaw, pitch, roll ] in degrees | | Rotate, CenterOn| | 
FitToSphere | Sets the scale and translation so the whole sphere fills a box of pnW by pnH at the origin, leaving pnPad of air. | nothing; scale and translation are stored | pnW=width of the box in paper units; pnH=height of the box in paper units; pnPad=the empty margin kept on each side | FitSphereIn, FitToPoints | | Raises an error when nothing of the sphere projects. FitSphereIn | Sets the scale and translation so the whole sphere fills the box x0, y0, x1, y1 on a larger sheet. | nothing; scale and translation are stored | pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box; pnPad=the empty margin kept on each side | FitToSphere, FitFeaturesIn | | Raises an error when nothing of the sphere projects
FitToPoints | Sets the scale and translation so the given places fill a box of pnW by pnH at the origin. | nothing; scale and translation are stored | paLonLat=the places as one flat list lon, lat, lon, lat, ...; pnW=width of the box in paper units; pnH=height of the box in paper units; pnPad=the empty margin kept on each side | FitPointsIn, FitToFeatures | | Raises an error when none of the points projects. Use it before Translate, never after
FitFeaturesIn | Sets the scale and translation so all the features of a set fill the box x0, y0, x1, y1: what drawing one country means. | nothing; scale and translation are stored | poFeatures=a stzGeoFeatures holding the boundaries; pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box; pnPad=the empty margin kept on each side | FitToFeatures, FitFeatureIn, FitSphereIn | | The sheet shows only the fitted extent: one feature that lies far from the rest, such as an island across the antimeridian, shrinks the rest to a speck
FitPointsIn | Sets the scale and translation so the given places fill the box x0, y0, x1, y1 of a larger sheet. | nothing; scale and translation are stored | paLonLat=the places as one flat list lon, lat, lon, lat, ...; pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box; pnPad=the empty margin kept on each side | FitToPoints, FitFeaturesIn | | The way to fit a window of the world on a Mercator, which runs to infinity at the poles
FitToFeatures | Sets the scale and translation so all the features fill a box of pnW by pnH at the origin. | nothing; scale and translation are stored | poFeatures=a stzGeoFeatures holding the boundaries; pnW=width of the box in paper units; pnH=height of the box in paper units; pnPad=the empty margin kept on each side | FitFeaturesIn, FitToFeature | |
FitToFeature | Sets the scale and translation so one feature fills a box of pnW by pnH at the origin: zoom to a country. | nothing; scale and translation are stored | poFeatures=a stzGeoFeatures holding the boundaries; pnI=the position of the feature, from 1; pnW=width of the box in paper units; pnH=height of the box in paper units; pnPad=the empty margin kept on each side | FitFeatureIn, FitToFeatures | |
FitFeatureIn | Sets the scale and translation so one feature fills the box x0, y0, x1, y1 of a larger sheet. | nothing; scale and translation are stored | poFeatures=a stzGeoFeatures holding the boundaries; pnI=the position of the feature, from 1; pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box; pnPad=the empty margin kept on each side | FitToFeature, FitFeaturesIn | | Raises an error when the feature projects nowhere
Project | Returns the paper position of the place at longitude pnLon and latitude pnLat. | a list [ x, y ] in paper units with y growing downward, or [ ] when the place is behind a globe or has no image | pnLon=longitude in degrees east; pnLat=latitude in degrees north | Invert, Line | | LONGITUDE FIRST.
