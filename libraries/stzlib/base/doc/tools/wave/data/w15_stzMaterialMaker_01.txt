# w15 stzMaterialMaker
init | Builds an empty material description with no colours, scalars, textures or body. | nothing; the object is built | | TakesColor, ForEachFragment | | StzMaterialMakerQ builds the same object; no device is needed to author a material
TakesColor | Declares a colour the material carries, usable by bare name in the body. | nothing; the name is added in lower case. TakesColorQ returns the maker for chaining | pcName=the name of the colour, in any letter case | TakesScalar, ColorNames, ParamsFrom | | the name is appended even if already declared, and the generated shader is cleared so ToWGSL builds it again
TakesScalar | Declares a number the material carries, usable by bare name in the body. | nothing; the name is added in lower case. TakesScalarQ returns the maker for chaining | pcName=the name of the scalar, in any letter case | TakesColor, ScalarNames, ParamsFrom | |
TakesTexture | Declares a picture the material reads, to be bound to an image when the material is set. | nothing; the name is added in lower case. TakesTextureQ returns the maker for chaining | pcName=the name of the texture, in any letter case | TakesColor, TextureNames, TexturesFrom | | the body reads it with sample(name, @uv) and never names the sampler
ForEachFragment | Sets the body that computes the colour of each pixel, one assignment of the form @out = expression. | nothing; the body is stored. ForEachFragmentQ returns the maker for chaining | pcW=the body text, with the declared colours and scalars by bare name, numbers, the operators + - * / % and parentheses, the whitelisted functions and the builtins @normal, @position, @uv, @lambert and @color | ToWGSL, Spec | | the text is kept as given and judged only by ToWGSL
ColorNames | Returns the colours declared so far, in declaration order. | a list of lower-case names; [ ] when none | | ScalarNames, TextureNames | |
ScalarNames | Returns the scalars declared so far, in declaration order. | a list of lower-case names; [ ] when none | | ColorNames, TextureNames | |
TextureNames | Returns the textures declared so far, in declaration order. | a list of lower-case names; [ ] when none | | ColorNames, ScalarNames | | the order is the order the shader's bindings are laid out in
Spec | Returns the declarations collapsed into the engine's spec text, one color, scalar or texture line each, then the body. | a multi-line text; an empty text for an empty maker | | ToWGSL, ForEachFragment | | exposed for transparency and for guards; the body line is body followed by the text
ToWGSL | Asks the engine to turn the description into a complete WGSL shader, and keeps the answer. | the shader source as text | | Spec, ParamsFrom | an empty body raises error stzMaterialMaker: no body (ForEachFragment missing); a name that is neither declared nor a whitelisted function, such as zork, raises error stzMaterialMaker: unknown name ... with the offender named | the shader declares the frame, instance and material structures and one binding for each declared texture and its sampler; no device is needed to produce it, only to run it
ParamsFrom | Returns the values of the declared colours and scalars flattened as the shader's structure expects them. | a list of numbers: four per colour in declaration order, red, green, blue and alpha from 0 to 1, then one per scalar | paBindings=a hash list giving a value for every declared name, colours as hex text such as #e0a030 and scalars as numbers | TexturesFrom, TakesColor | a colour or a scalar with no binding raises error stzMaterialMaker: colour ... has no value (or scalar ... has no value), instead of answering the 0 that a missing hash key would give | #e0a030 gives 0.88, 0.63, 0.19 and 1; the alpha of a colour with no alpha is 1
TexturesFrom | Returns the engine handles of the declared textures, in declaration order. | a list of numbers, one per texture | paBindings=a hash list giving a handle above 0 for every declared texture, such as [ :albedo = oImage.Handle() ] | ParamsFrom, TakesTexture | a texture with no binding, or one that is not a handle above 0, raises error stzMaterialMaker: texture ... has no image | binding handle 0 would only fail later, as a panic at submit
