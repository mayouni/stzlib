# w15 stzRuleGovernance
init | Builds a governance with a name, no rules and no cases. | nothing; the object is built | pcName=the name of the governance | AddRule, AddCase | | StzRuleGovernanceQ and StzPlasticGovernance build the same object
Name_ | Returns the name the governance was built with. | the name as text | | Rules | |
Rules | Returns the rules added so far, in the order they were added. | a list of stzScopedRule objects | | AddRule, ScopeTable | |
Findings | Returns the findings of the last CheckRules or CheckAll. | a list of findings; [ ] before either has run | | CheckAll, IsSound | | CheckCases does not store its findings here
AddRule | Adds a rule to judge, in the order it will be listed. | the governance itself, so calls chain | poRule=a stzScopedRule | AddCase, CheckRules | |
AddCase | Adds a case the rules are judged against, under a name, whatever kind of object it is. | the governance itself, so calls chain | pcName=the name of the case, shown in findings; poSubject=the case, such as a rendered diagram, a code graph or any object the scopes understand | AddPicture, CheckCases | | the case must already be in the state the scopes read: nothing is solved or rendered for it
AddPicture | Adds a diagram as a case after solving its layout in place, so copies of it carry the solution. | the governance itself, so calls chain | pcName=the name of the case; poDg=the diagram; only a math diagram is solved, any other object is added as it is | AddCase, CheckCases | | solving before the copy avoids a second layout when the first scope asks
DeclarePrecedence | Declares which of two rules wins where both govern one subject, with the reason. | the governance itself, so calls chain | pcWins=the name of the rule that wins; pcYields=the name of the rule that yields; pcWhy=the reason, kept with the declaration | CheckRules, AddRule | | it silences subject_contested for that pair in either order; a pair that write nothing in common is never reported as contested
CheckCases | Judges every case against every rule and returns the findings of the rules. | a list of findings, each a hash list with rule, subject, where, severity and message; [ ] when all hold | | CheckRules, CheckAll | | where reads case name, a slash, then the subject; CheckPictures is the same call
CheckRules | Asks the questions a rule cannot ask of itself, over the cases, and returns the findings about the rules. | a list of findings whose rule is scope_empty, scope_vacuous, boundary_unwitnessed, claim_unstated, subject_contested or read_is_stale | | CheckCases, CheckAll | | the findings are kept for Findings and IsSound; where is the rule's name; scope_empty and claim_unstated are errors, the rest warnings except read_is_stale, an error
CheckAll | Runs the questions about the rules, then the rules over the cases, and returns every finding. | a list of findings, those about the rules first | | CheckRules, CheckCases | | the whole list is kept for Findings and IsSound
IsSound | TRUE if the last CheckRules or CheckAll found nothing of severity error. | TRUE or FALSE, as 1 or 0; 1 before either has run | | CheckAll, Findings | | warnings do not make it false
ScopeTable | Returns for each rule how much it governs and how much it excludes over the cases. | a list of rows [ name, subjects governed, subjects excluded, cases where it governs something, number of cases ] | | CheckRules, Rules | | it calls every scope and counter again, so it costs a pass over the cases
