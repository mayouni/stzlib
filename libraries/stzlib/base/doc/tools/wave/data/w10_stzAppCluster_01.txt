init | Builds an empty fleet with a worker pool, a reactor, latency telemetry and a rate limiter, and starts no process. | nothing; the object is built | | AddProfile, Start | | the worker program is later run with the interpreter that is running the script
AddProfile | Declares a number of worker processes for a profile, a capability tag with its capabilities, without starting them. | nothing; use AddProfileQ to chain | pcTag=the profile name, kept in lower case; paCaps=the list of capabilities of that profile; nWorkers=how many processes to declare, at least 1 | WithFacet, Start, WorkersOf | it raises an error for fewer than one worker | declaring the same tag again adds to its worker count, and every row waits with port 0 until Start
SetMaxTries | Sets how many workers one routed request may try before giving up; it starts at 3. | the cluster itself, so calls chain | n=the number of workers to try, a value below 1 being taken as 1 | Route, SetCircuitBreaker |
SetCircuitBreaker | Sets how many consecutive failures open a worker's circuit and for how long it then stays skipped; it starts at 3 and 5000 ms. | the cluster itself, so calls chain | nThreshold=the number of failures that open the circuit, a value below 1 being taken as 1; nCooldownMs=how long the circuit stays open, in milliseconds | CircuitOpenCount, Route | | after the cooldown one probe request decides whether the circuit closes again
SetRateLimit | Limits how many requests per second a facet accepts at the front door, so that the excess is refused before any worker is reached. | the cluster itself, so calls chain | pcFacet=the facet name; nRatePerSec=the sustained requests per second; nBurst=the largest burst absorbed at once | TokensAvailable, RateLimitedCount, Route | | a facet with no limit is unlimited, and a refused request gives RouteLastStatus -429
RegisterExternalWorker | Adds a worker that already runs somewhere, as a ready member of a facet's pool, without spawning anything. | the cluster itself, so calls chain | pcFacet=the facet name; pcHost=the worker's host; nPort=the worker's port | AddProfile, Route, HealthCheck | | it is counted as ready at once and is not verified until HealthCheck or a failed request, and Stop and ForceKill leave it alone
WithFacet | Declares workers for any facet of the cluster's catalog, taking its capabilities and modules from that catalog. | the cluster itself, so calls chain | pcFacet=a facet name present in the catalog, such as nlp, math, graph or vision; n=how many worker processes to declare | CatalogQ, AddProfile | it raises an error for a facet that is not in the catalog | the catalog of this machine held 18 facets, from text and list to vision

SetWorkerTTL | Sets how long each worker process lives before it ends by itself, in milliseconds; it starts at 30000. | the cluster itself, so calls chain | nMs=the lifetime in milliseconds | Start, Stop | | it applies to workers started afterwards
SetBasePort | Sets the first port of the fleet; later workers take the next ports in order. | the cluster itself, so calls chain | nPort=the first port, 47100 by default | Start, Ports |
SetRingExe | Sets the Ring program that launches each worker. | the cluster itself, so calls chain | pcPath=the path of the Ring executable | Start | | by default it is the interpreter running the script, or ring
Start | Writes the worker script, spawns one process per declared worker on consecutive ports and records their jobs. | the cluster itself, so calls chain | | WaitReady, Stop, SetBasePort | it starts real processes and was not run | a second call raises an error, and rows added with RegisterExternalWorker are not spawned
WaitReady | Polls every worker's health address until all answer or the time runs out, and reports how many are ready. | a number, the workers ready | nTimeoutMs=how long to wait in milliseconds | Start, ReadyCount, HealthCheck | it sends requests to the workers' ports, so it was run only on a cluster with no worker, where it returned 0 at once |
Route | Sends a path to a ready worker of a facet and returns the body, trying other workers of the facet when one fails. | a text, the response body; empty when refused or when every try failed, with Why and RouteLastStatus saying why | pcTag=the facet name; pcPath=the path and query to request, which must start with a slash and hold no line break | RouteLastStatus, Why, SetMaxTries, RouteRequest | the success path sends HTTP to a worker and was not run | an unsafe path gives status -1, no ready worker gives -1, a rate limit gives -429, and each call gets a trace id that is also sent to the worker as the _trace parameter
RouteLastStatus | Returns the HTTP status of the last routed request, or a negative code when none was sent. | a number: the status, -1 for no worker or an unsafe path or an undecidable request, -429 for a rate-limited one | | Route, Why
Why | Returns the reason of the last Route. | a text such as ok via host:port (attempt 1), no routable worker for facet, or rate limited; empty before any Route | | Route | | RouteRequest does not update it when it cannot classify the request, so it can then show an older reason
TelemetryQ | Returns the telemetry object that holds the latency histograms and recent traces. | a stzClusterTelemetry | | LatencyStats, RecentTraces
LastTraceId | Returns the trace id given to the last Route. | a text; empty before any Route | | RecentTraces, Route
LatencyP50 | Returns the median latency of a facet's routed requests in milliseconds, as a histogram bucket bound. | a number; 0 when no request was timed | pcFacet=the facet name | LatencyP90, LatencyP99, LatencyStats | | a rate-limited request is not timed
LatencyP90 | Returns the 90th-percentile latency of a facet's routed requests in milliseconds. | a number; 0 when no request was timed | pcFacet=the facet name | LatencyP50, LatencyP99
LatencyP99 | Returns the 99th-percentile latency of a facet's routed requests in milliseconds. | a number; 0 when no request was timed | pcFacet=the facet name | LatencyP50, LatencyP90
LatencyStats | Returns a facet's request count and latency percentiles as a hash list. | a hash list with the keys facet, count, p50, p90, p95 and p99 | pcFacet=the facet name | LatencyP50, RecentTraces
RecentTraces | Returns the last records of routed requests. | a list of lists, each with the trace id, the facet, the endpoint, the status, the duration in milliseconds and the number of attempts | n=how many of the latest records to return | LastTraceId, LatencyStats | | a refused request is recorded too, with the endpoint ratelimited or none

RateLimitedCount | Returns how many requests of a facet were refused for exceeding its rate limit. | a number | pcFacet=the facet name | SetRateLimit, TokensAvailable
TokensAvailable | Returns how many requests a facet can still admit right now. | a number; -1 for a facet with no limit | pcFacet=the facet name | SetRateLimit, RateLimitedCount | | the bucket refills with time, so the figure drifts between two reads
CircuitOpenCount | Returns how many workers currently have an open circuit, and so are skipped. | a number | | SetCircuitBreaker, Route
FleetSize | Returns how many workers are declared, ready or not. | a number | | ReadyCount, WorkersOf

RouteRequest | Classifies a request to a facet, then routes its path to a worker of that facet. | a text, the response body; empty when the request cannot be classified or no worker is ready | pcMethod=the HTTP method; pcPath=the request path; pcContentType=the content type; pcBody=the request body | Route, ClassifierQ | an unclassified request leaves RouteLastStatus at -1 | the classifier returned math for /math/solve and nothing for /work?q=hello, and no worker was ready in the run
HealthCheck | Asks every started worker for its health again and refreshes whether it is ready. | a number, the workers ready now | | WaitReady, DeadCount, RestartDead | it sends requests to the workers' ports and was run only on a cluster with no started worker, where it returned 0 | a worker that stops answering turns not ready
DeadCount | Returns how many started workers are not answering and are not being drained. | a number | | HealthCheck, RestartDead
ScaleUp | Spawns one more worker of a profile on a fresh port. | a number, the new port | pcTag=the profile name | ScaleDown, WaitReady | it starts a real process, so only the error for an unknown profile was run | the new worker is not ready until WaitReady or HealthCheck sees it answer
ScaleDown | Marks one ready worker of a profile as draining, so it receives no new requests and ends on its own lifetime. | a number, the drained worker's port; 0 when no ready worker is left to drain | pcTag=the profile name | ScaleUp, ForceKill | | it does not stop the process: only the nothing-to-drain case was run
RestartDead | Respawns every dead worker on a fresh port, killing the old process first. | a number, how many workers were restarted | | HealthCheck, DeadCount | it starts real processes when a worker is dead, and only the case with none dead was run |
ForceKill | Kills every spawned worker of a facet at once and marks it not ready. | a number, how many processes were killed | pcTag=the facet name | ScaleDown, KilledCount | it ends real processes, and only a facet with no spawned worker was run | workers added with RegisterExternalWorker are skipped
KilledCount | Returns how many worker processes were forcibly killed over the cluster's life. | a number | | ForceKill, Stop
FleetMetrics | Returns, for each profile, how many workers are declared, ready, draining and dead. | a list of hash lists with the keys tag, total, ready, draining and dead | | HealthCheck, DeadCount
