init | Builds the bridge to the real disk, the only door by which the file twin reaches reality. | nothing; the bridge is built | pcRoot=the root folder the bridge reports as its constraint | Root, ExecuteOperation | the root is only reported by Constraints: it does not confine the paths an operation names
Root | Returns the root folder the bridge was built with. | a text | | Constraints
RealExists | TRUE if a real file exists at that path. | TRUE or FALSE | pcPath=the real path | RealContent, RealSize | | it reads the disk and changes nothing
RealContent | Returns the content of a real file. | a text; an empty text when the file is absent | pcPath=the real path | RealExists, RealSize
RealSize | Returns the size of a real file. | a number of bytes; -1 when the file is absent | pcPath=the real path | RealContent
CurrentRealityState | Returns a new tree holding the files of one real folder, each with its content and marked as mirrored. | a stzFileTree; an empty tree when the folder is absent | pcDir=the real folder to read, one level only; subfolders are not included | stzVirtualFileSystem, RealContent
Constraints | Returns the facts that bound what the bridge acts on, which is its root. | a list [ [ root, folder ] ] | | Root, Capabilities
Capabilities | Returns the operation types the bridge can commit. | a list of text: create_file, write_file, create_folder, delete_file, delete_folder, copy_file, move_file | | ExecuteOperation, Constraints
ExecuteOperation | Commits one file operation to the real disk. | TRUE if the disk call succeeded, FALSE if it failed or the type is not a file operation | oOp=the stzVirtualOperation to commit | VerifyOutcome, stzUpdatePlan | not run on a real folder: it writes and deletes real files, so reach it only through a plan that was narrated and reviewed; tried only on a scratch folder, where deleting a folder that still holds a file returned FALSE | a move copies the file and then deletes the source
VerifyOutcome | Checks after a commit that the disk is as the operation asked. | TRUE or FALSE; checked for create, write, copy, move and delete, and always TRUE for a folder creation | oOp=the stzVirtualOperation that was committed | ExecuteOperation, RealExists
