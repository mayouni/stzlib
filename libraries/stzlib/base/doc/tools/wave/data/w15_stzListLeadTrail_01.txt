init | Builds a lead-and-trail helper over a list or over a stzList object, working on its own copy, so the list passed in is never changed. | nothing; the object is built | pListOrObj=a list, or a stzList object, whose beginning and end are examined | Content | any other kind of value raises "Can't create stzListLeadTrail! Parameter must be a list or stzList object." |
Content | Returns the items the helper holds, after any removal made through it. | a list | | NumberOfItems | |
NumberOfItems | Returns how many items the list holds now. | a number | | Content | |
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE | | NumberOfItems | |
HasRepeatedLeadingItems | TRUE if the list begins with a run of two or more equal items, compared case-sensitively. | TRUE or FALSE | | HasRepeatedLeadingItemsCS, RepeatedLeadingItems | | HasRepeatedLeadingItemsCS(0) ignores case: a a A counts as a run
RepeatedLeadingItems | Returns the run of equal items that opens the list, all of them; [ ] when the list does not open with a run of two or more. | a list; [ ] when there is no run | | RepeatedLeadingItem, NumberOfRepeatedLeadingItems | | a single first item is not a run; RepeatedLeadingItemsCS(0) ignores case, so a a A gives all three
RepeatedLeadingItem | Returns the item that opens the list in a run of two or more, or an empty text when none does. | an item; "" when the list opens with no run | | RepeatedLeadingItems | | "" is also what a list of empty texts would answer, so test HasRepeatedLeadingItems first
NumberOfRepeatedLeadingItems | Returns how long the run of equal items at the start of the list is; 0 when there is none. | a number | | RepeatedLeadingItems | | a run of 1 is not counted: a b c answers 0, not 1
HasRepeatedTrailingItems | TRUE if the list ends with a run of two or more equal items, compared case-sensitively. | TRUE or FALSE | | HasRepeatedTrailingItemsCS, RepeatedTrailingItems | | HasRepeatedTrailingItemsCS(0) ignores case: c c C counts as a run
RepeatedTrailingItems | Returns the run of equal items that closes the list, all of them; [ ] when the list does not end with a run of two or more. | a list; [ ] when there is no run | | RepeatedTrailingItem, NumberOfRepeatedTrailingItems | | a single last item is not a run; RepeatedTrailingItemsCS(0) ignores case
RemoveRepeatedLeadingItems | Shortens the run of equal items at the start of the list to one item, in place. | nothing; use RemoveRepeatedLeadingItemsQ to chain | | RepeatedLeadingItemsRemoved, RemoveRepeatedTrailingItems | | the run stays one item, not none: 1 1 1 2 becomes 1 2; the list given to init is untouched
RemoveRepeatedTrailingItems | Shortens the run of equal items at the end of the list to one item, in place. | nothing; use RemoveRepeatedTrailingItemsQ to chain | | RepeatedTrailingItemsRemoved, RemoveRepeatedLeadingItems | | the run stays one item, not none: 3 3 3 becomes 3
RemoveRepeatedLeadingAndTrailingItems | Shortens both the opening run and the closing run to one item each, in place. | nothing; use RemoveRepeatedLeadingAndTrailingItemsQ to chain | | RemoveRepeatedLeadingItems, RemoveRepeatedTrailingItems | | a list made only of one repeated item, 4 4 4, ends up as 4
RepeatedLeadingItemsRemoved | Returns a copy of the list with the opening run shortened to one item, leaving the object unchanged. | a list | | RemoveRepeatedLeadingItems | |
RepeatedTrailingItemsRemoved | Returns a copy of the list with the closing run shortened to one item, leaving the object unchanged. | a list | | RemoveRepeatedTrailingItems | |
StartsWith | TRUE if the first item equals the given item, compared case-sensitively. | TRUE or FALSE; FALSE for an empty list | pItem=the item expected first | EndsWith, StartsWithCS | | StartsWithCS(pItem, 0) ignores case
EndsWith | TRUE if the last item equals the given item, compared case-sensitively. | TRUE or FALSE; FALSE for an empty list | pItem=the item expected last | StartsWith, EndsWithCS | | EndsWithCS(pItem, 0) ignores case
