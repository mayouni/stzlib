init | Creates a named number sequence in the engine, from a start value, a step and a mode: 0 counts on, 1 repeats, 2 bounces. | nothing; the sequence now exists in the engine under its name | cName=the unique name of the sequence, a non-empty text; nStart=the first value; nStep=the amount added each time; nMode=0 for step, 1 for repeat, 2 for bounce | SetBounds, NextValue, Destroy | A start or a step that has a fraction is silently cut to a whole number: start 2.5 gives 2, step 0.5 gives 0 so the value never moves, step 1.5 gives 1; a name that is empty or a value that is not a number raises an error | the engine keeps the sequence until Destroy; a second object built with a name already in use shares that counter and its own start and step are ignored (start 100 on a counter standing at 20 still answers 20)
Name | Returns the name the sequence was created with. | a text | | init | |
SetBounds | Sets the lowest and highest values a repeating or bouncing sequence moves between. | nothing; use SetBoundsQ to chain | nMin=the lowest value; nMax=the highest value | init, NextValue | | bounds act in modes 1 and 2 only: a mode-0 sequence given bounds 2 and 4 from 1 still counts 1 to 5; mode 1 with bounds 1 to 3 gives 1 2 3 1 2 3 and mode 2 gives 1 2 3 2 1 2 3 2
NextValue | Returns the value the sequence stands on and then moves it by one step, so the first call answers the start. | a number | | Current, NextNValues | | Advance is the same method; Current shows the value the next call will return
Current | Returns the value the next NextValue will return, without moving the sequence. | a number | | NextValue, Iteration | | Value is the same method; after Destroy it answers 0
Iteration | Returns how many times the sequence has been moved since its creation or last Reset. | a number | | Current, Reset | | IterationNumber is the same method
NextNValues | Returns the next n values in order and moves the sequence n steps. | a list of n numbers | n=how many values to take, at least 1 | NextValue | | n below 1 raises "Incorrect param! n must be a positive number."
Reset | Puts the sequence back at its start value and its iteration count at 0, keeping its bounds. | nothing; use ResetQ to chain | | NextValue, Destroy | |
Destroy | Removes the sequence from the engine, which Ring cannot do by itself. | nothing | | Reset | | afterwards Current and NextValue answer 0 and SetBounds is silent: do not use the object again
