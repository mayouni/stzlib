init | Parses a pattern written in mini-notation, such as 'red ~ blue [green green]', into a tree of steps. | nothing; the object is built | pcText=the pattern in mini-notation: words, ~ for a rest, [ ] groups, < > alternation, * and / for speed, ? ! @ | IsValid, LastError | a text that does not parse leaves the object invalid instead of raising: read IsValid and LastError
IsValid | TRUE if the text parsed into a pattern. | TRUE or FALSE | | LastError, Text
Text | Returns the mini-notation the pattern was built from, as given. | a text | | Tree
LastError | Returns the message of the last parse error or refused verb, empty when there was none. | a text | | Refusals, IsValid | the message of a refused verb (Fast with 1.5, Off with 2) replaces the parse message
Refusals | Returns how many times a verb refused its argument since the pattern was built. | a number | | LastError | a refused verb leaves the pattern unchanged and does not raise
Tree | Returns the parsed pattern as nested lists, each node tagged seq, atom, rest, fast, slow, rev, every or off. | a list; NULL when the text did not parse | | Text, CycleEvents
CycleEvents | Returns the events of one cycle, each as [ onset, length, kind, value ], sorted by onset; onset and length are fractions of the cycle. | a list of lists; empty when the pattern is invalid | pnCycle=the cycle number, counted from 0 | DistinctValues, Period | rests give no event; the events of a cycle are computed from its number, so cycle 100000 costs the same as cycle 0
DistinctValues | Returns the distinct [ kind, value, length ] triples that occur over the first pnCycles cycles. | a list of lists | pnCycles=how many cycles to scan, starting at cycle 0 | CycleEvents, Period
Period | Returns after how many cycles the pattern repeats exactly, at most 64; 1 for an invalid pattern. | a number | | CycleEvents | '<a b c>' has period 3, a plain sequence has period 1
Fast | Plays the pattern pnFactor times faster, in place, so its events squeeze into 1/pnFactor of a cycle and repeat. | the pattern itself, so calls chain | pnFactor=a whole number of 1 or more | Slow, Every | a fractional factor is refused and counted in Refusals | the pattern is changed in place
Slow | Plays the pattern pnFactor times slower, in place, so one cycle shows 1/pnFactor of it. | the pattern itself, so calls chain | pnFactor=a whole number of 1 or more | Fast, Every | a fractional factor is refused and counted in Refusals | the pattern is changed in place
Rev | Reverses the order of the events inside each cycle, in place. | the pattern itself, so calls chain | | Every | the pattern is changed in place
Every | Applies a transformation to the pattern on every pnN-th cycle, in place, and plays it unchanged on the others. | the pattern itself, so calls chain | pnN=a whole number of cycles, 1 or more; pXform=:Rev, [ :Fast, n ] or [ :Slow, n ] | Fast, Slow, Rev | an unknown transformation or a pnN below 1 is refused and counted in Refusals | the transformed cycle is the first of each group: Every(2, :Rev) reverses cycles 0, 2, 4
Off | Layers a copy of the pattern shifted later by a fraction of a cycle on top of it, in place. | the pattern itself, so calls chain | pnCycles=the shift, strictly between 0 and 1; pArg=a value the subclass uses to alter the shifted copy, NULL for none | Every | a shift of 0 or of 1 and more is refused and counted in Refusals | the pattern is changed in place
