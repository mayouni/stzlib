init | Builds an empty multi-objective problem, with no variable, constraint or objective and the generator seed set to 42. | nothing; the object is built | | clear, addVariable, addObjective, solve
clear | Empties the problem: variables, constraints, objectives, the front found so far and the status are dropped, and the seed returns to 42. | nothing; the problem is empty again | | init, SetSeed | | the NSGA-II settings made with setNSGAParameters are kept
addVariable | Adds a continuous variable with a lower and an upper bound, in declaration order. | the solver itself, so calls chain | varName=the variable's name, as text; lowerBound=the smallest value the variable may take; upperBound=the largest value it may take, never below the lower bound | addIntegerVariable, addBinaryVariable, VariableNames | all three arguments must be given (R19 otherwise); a name that is not text, bounds that are not numbers and an upper bound below the lower bound each raise an error |
addIntegerVariable | Adds a variable marked integer, with the same arguments and checks as a continuous one. | the solver itself, so calls chain | varName=the variable's name, as text; lowerBound=the smallest value the variable may take; upperBound=the largest value it may take | addVariable, addBinaryVariable | the genetic search floors the values it draws for such a variable, but the epsilon-constraint method does not enforce the mark |
addBinaryVariable | Adds a variable bounded between 0 and 1 and marked binary. | the solver itself, so calls chain | varName=the variable's name, as text | addVariable, addIntegerVariable
Variables | Returns the declared variables in order, each as a list of name, lowerbound, upperbound and type pairs. | a list with one list of [ key, value ] pairs per variable; [ ] when none is declared | | VariableNames, addVariable | | the keys are lower case
Vars | Returns the same list of declared variables as the longer accessor does. | a list with one list of [ key, value ] pairs per variable | | Variables, VariableNames
VariableNames | Returns the names of the declared variables, in declaration order. | a list of text | | Variables, addVariable
addConstraint | Adds one linear constraint: an expression such as "x + y", a comparison and a number. | the solver itself, so calls chain | expression=the left side, as text; operator=the comparison: "<=", ">=" or "="; value=the number the expression is compared with | constraints, solveWithEpsilonConstraint | a value that is not a number, even the text "5", raises an error; the NSGA-II method refuses to run when any constraint exists |
constraints | Returns the declared constraints in order, each as a list of expression, operator and value pairs. | a list of lists of [ key, value ] pairs; [ ] when none is declared | | addConstraint
addObjective | Appends one objective: an expression and the goal to maximize or minimize it. | the solver itself, so calls chain | expression=the objective, as text, such as "3*x + 2*y"; type=the goal: "maximize" or "minimize" | maximize, minimize, objectives | an expression that is not text, or any other goal, raises an error |
maximize | Appends an objective to make as large as possible; earlier objectives are kept. | the solver itself, so calls chain | expression=the objective, as text | minimize, addObjective, objectives | | unlike the single-objective solver, calling it twice gives two objectives
minimize | Appends an objective to make as small as possible; earlier objectives are kept. | the solver itself, so calls chain | expression=the objective, as text | maximize, addObjective, objectives
objectives | Returns the declared objectives in order, each as a list of expression and type pairs. | a list of lists of [ key, value ] pairs; [ ] when none is declared | | addObjective
setNSGAParameters | Sets the population size, the number of generations and the mutation and crossover rates of the genetic search. | the solver itself, so calls chain | populationSize=how many individuals each generation holds, 50 by default; generations=how many generations to breed, 100 by default; mutationRate=the chance, from 0 to 1, that a variable is redrawn, 0.1 by default; crossoverRate=the chance, from 0 to 1, that a child takes a variable from the first parent, 0.9 by default | solveWithNSGAII, solve | nothing is checked: any value is stored |
solve | Finds a set of trade-off solutions with the named method, "nsga_ii" (the default) or "epsilon_constraint", and keeps it. | the solver itself, so calls chain | cMethod=the method's name, an empty text selects nsga_ii | paretoSolutions, bestCompromiseSolution, status | the argument cannot be left out (R19), pass an empty text for the default; no variable, no objective, a single objective or an unknown method raise an error; the status becomes optimal in every case | maximize x and maximize -x on 0..10 with 8 individuals and 3 generations gives a front of 8, since no point beats another
solveWithNSGAII | Returns the non-dominated individuals of a genetic search that breeds a seeded population for the set number of generations. | a list of individuals, each a list of solution, objectives, rank, crowdingdistance, dominatedsolutions and dominationcount pairs | | solve, setNSGAParameters, SetSeed | raises an error when the problem has any constraint, because the search does not enforce them; the front can hold several copies of one point; it is approximate | the same seed gives the same front (three runs agreed), and another seed gives another; the objectives of a maximize goal are stored negated
solveWithEpsilonConstraint | Returns one solution per combination of bounds on the secondary objectives, each found by the greedy solver on the first objective. | a list of individuals, each a list of solution, objectives and rank pairs | | solve, calculateEpsilonRanges | the front collapses: for maximize x and maximize y with x + y <= 10 all eleven solutions are x = 10 and y = 0 (the true trade-off is the line x + y = 10), and with minimize x + y and maximize x - y most solutions repeat, because the greedy solver reads ">=" bounds as "<=" and always raises a variable to its maximum; only the first two secondary objectives are used | the iteration count is set to 10 per objective
initializePopulation | Returns the starting population: one random solution per individual, with no objective values yet. | a list of individuals, each a list of solution, objectives, rank and crowdingdistance pairs | | solveWithNSGAII, generateRandomSolution | | rank starts at 0 and objectives is empty
SetSeed | Sets the state of the pseudo-random generator that drives the genetic search. | the solver itself, so calls chain | n=the starting state, a positive whole number, zero or less is replaced by 42 when numbers are drawn | Seed, solveWithNSGAII
Seed | Returns the state of the pseudo-random generator, 42 until it is set or numbers are drawn. | a number | | SetSeed | | the state moves each time a number is drawn, so it differs after a run
generateRandomSolution | Returns one random solution within the bounds, whole numbers for integer and binary variables. | a list of [ name, value ] pairs, one per variable | | initializePopulation, mutate | | continuous values come in steps of 0.01
evaluateObjectives | Returns the value of every objective for a solution, with maximize goals negated so that smaller is always better. | a list of numbers, one per objective | _aSolution_=a list of [ name, value ] pairs | calculateObjectiveValue, dominates | | x = 3 and y = 4 under maximize x, minimize x + y and maximize y gives -3, 7 and -4
calculateObjectiveValue | Returns the value of an expression for a solution. | a number | cExpression=the expression, as text; _aSolution_=a list of [ name, value ] pairs | evaluateObjectives, extractCoefficient | | 3*x + 2*y with x = 3 and y = 4 gives 17
nonDominatedSort | Returns the fronts of a population as lists of positions, and writes each individual's rank and domination data into the population itself. | a list of fronts, each a list of positions in the population, the last one empty | _aPopulation_=a list of individuals, each with an objectives list, it is changed in place | dominates, calculateCrowdingDistance | | three individuals with objectives (-1,-1), (-2,-2) and (-3,0) give the fronts [ [ 2, 3 ], [ 1 ], [ ] ] and the ranks 2, 1 and 1
dominates | TRUE if the first individual is no worse than the second on every objective and better on at least one. | TRUE or FALSE | _individual1_=an individual with an objectives list; _individual2_=an individual with an objectives list | nonDominatedSort, evaluateObjectives | | objectives are compared as smaller is better; an individual never dominates itself
calculateCrowdingDistance | Returns the population with a crowding distance set on each individual: 999999 at the ends of a front, the spread of its neighbours inside. | the population, a list of individuals | _aFronts_=the fronts returned by nonDominatedSort; _aPopulation_=the population those fronts index | nonDominatedSort, tournamentSelection |
sortFrontByObjective | Returns the positions of a front ordered from the smallest to the largest value of one objective. | a list of positions | _front_=a list of positions in the population; objIndex=the number of the objective to sort by; _aPopulation_=the population the positions index | calculateCrowdingDistance | | the sort is a bubble sort
createNewPopulation | Returns the next generation: one child per individual of the population size, made by tournament selection, crossover and mutation. | a list of individuals with no objective values yet | _aPopulation_=the current population, each individual with solution and objectives | tournamentSelection, crossover, mutate | with fewer than two usable individuals it prints a warning line and returns a fresh random population |
tournamentSelection | Returns the better of two distinct usable individuals drawn at random: the lower rank, or on a tie the larger crowding distance. | an individual; [ ] when fewer than two individuals have a solution and objectives | _aPopulation_=a list of individuals | createNewPopulation, calculateCrowdingDistance | | the draw uses the seeded generator
crossover | Returns a child that takes each variable from the first parent with the crossover rate and from the second otherwise. | an individual with a solution, no objectives and rank 0 | parent1=an individual with a solution; parent2=an individual with a solution | mutate, createNewPopulation, setNSGAParameters
mutate | Returns the individual after redrawing each variable at random between its bounds, with the mutation rate as the chance for each. | the same individual, changed | individual=an individual with a solution | crossover, setNSGAParameters
calculateEpsilonRanges | Returns every combination of eleven evenly spaced bounds for the secondary objectives, for the epsilon-constraint method. | a list of lists of numbers: 11 rows of one bound with two objectives, 121 rows of two bounds with three or more | | solveWithEpsilonConstraint, calculateObjectiveBound | only the first two secondary objectives are used: four objectives still give 121 rows of two bounds | each range runs from the objective's lowest to its highest value over the variable bounds
calculateObjectiveBound | Returns the lowest or the highest value an expression can reach over the variable bounds. | a number | cExpression=the expression, as text; cType="min" for the lowest value, anything else for the highest | calculateEpsilonRanges | | 3*x - 2*y with x and y between 0 and 10 gives -20 and 30
extractCoefficient | Returns the coefficient of one variable in an expression. | a number; 0 when the variable does not appear | cExpression=the expression, as text; cVarName=the variable's name | calculateObjectiveValue | | in 3*x + 2*y the coefficient of y is 2
getSolutionValue | Returns the value of one variable in a list of [ name, value ] pairs. | a number; 0 when the name is not in the list | _aSolution_=a list of [ name, value ] pairs; cVarName=the variable's name | calculateObjectiveValue
paretoSolutions | Returns the trade-off solutions kept by the last solve. | a list of individuals; [ ] before any solve | | solve, bestCompromiseSolution
bestCompromiseSolution | Returns the stored solution whose objective values have the smallest sum of absolute values. | one individual; [ ] before any solve | | paretoSolutions, solve | | the values are not normalised, so an objective with large numbers dominates the choice
status | Returns how the last solve ended. | the text optimal after a solve; "" before | | solve
iterations | Returns the work counted by the last solve: the number of generations for nsga_ii, ten per objective for the epsilon method. | a number; 0 before any solve | | solve, status
solveTime | Returns the time the last solve took, in seconds. | a number; 0 before any solve | | solve

exportParetoFrontCSV | Raises error R41 today instead of writing the front to a file, one row per solution. | nothing; raises R41 Invalid numeric string | cFileName=the path of the file to write | paretoSolutions, show | a variable value, a number, is joined to a comma with + and Ring cannot add a number to a text; it raises for the front of every problem tried (two problems, epsilon-constraint method) |
