Value | Returns the aggregate of one cell: a row and a column of the pivot. | a number; the null value of an empty cell (0 by default); the empty text when the row or column is not in the pivot | paRowValues=the row label value, or a list of values with several row labels; paColValues=the column label value | RowTotal, ColumnTotal, GrandTotal, SetNullValue | | generates the pivot first when needed
RowTotal | Returns the total of one row of the pivot. | a number; the empty text when the row is unknown or the total column is hidden | paRowValues=the row label value, or a list of values with several row labels | ColumnTotal, GrandTotal, SetShowTotals | for any function other than SUM and COUNT it is the sum of the row's cells, not the function over the rows
ColumnTotal | Returns the total of one column of the pivot. | a number; the empty text when the column is unknown or the total row is hidden | paColValues=the column label value | RowTotal, GrandTotal, SetShowTotals | for any function other than SUM and COUNT it is the sum of the column's cells, not the function over the rows
GrandTotal | Returns the cell where the total row and the total column meet. | a number; the empty text when either total is hidden | | RowTotal, ColumnTotal | for any function other than SUM and COUNT it is a sum of cells, not the function over all rows
