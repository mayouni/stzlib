# w14 stzListSplits -- Name | brief | returns | params | see | warning | note
init | Builds a splitter over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to cut, or a stzList whose content is copied, any other value raises an error | Content, SplittedAt | | the splitter works on its own copy and never changes the list or the stzList you passed in
Content | Returns the list as it stands now, which is a list of parts after an in-place split. | a list | | NumberOfItems, SplittedAt
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
Split | Cuts the list into parts at an item or a position, in place, so the content becomes a list of parts. | nothing; the content changes. SplitQ returns the splitter for chaining | pItemOrPos=an item to cut at, a position, or a pair such as [ :After, 3 ] or [ :Before, 3 ] | SplitAt, SplitBefore, SplitAfter, SplittedAt | a number is always read as a position, never as an item: Split(30) on 10 20 30 40 50 cuts nothing and answers one part, even though 30 is an item; the call changes the content and returns an empty text, so print Content afterwards; a second call on the cut list works on its parts and wraps them again | the cut item starts the next part and is kept, and an item that is absent leaves one part holding everything
SplitAtPositions | Cuts the list so that a new part starts at each given position, in place. | nothing; the content changes. SplitAtPositionsQ returns the splitter for chaining | panPos=the positions where a new part starts, each from 1 | SplittedAtPositions, SplitAtPosition | | position 1 and positions past the end are ignored, and positions given in any order or twice are cut once, so [ 4, 2 ] on 1 to 5 gives the parts [ 1 ], [ 2, 3 ] and [ 4, 5 ]; an empty list of positions gives one part
SplitAtThesePositions | Cuts the list so that a new part starts at each given position, in place. | nothing; the content changes | panPos=the positions where a new part starts, each from 1 | SplitAtPositions, SplittedAtPositions | | the same call as SplitAtPositions
SplittedAtPositions | Returns the list cut into parts, a new part starting at each given position, leaving the splitter as it was. | a list of lists | panPos=the positions where a new part starts, each from 1 | SplitAtPositions, SplittedAt | | position 1 and positions past the end are ignored; [ 3, 6 ] on a b - c d - e gives the parts [ a, b ], [ -, c, d ] and [ -, e ]
SplitBeforePosition | Cuts the list in two just before a position, in place. | nothing; the content changes. SplitBeforePositionQ returns the splitter for chaining | _n_=the position that starts the second part, from 1 | SplittedBeforePosition, SplitAfterPosition | | a position below 2 or past the end leaves one part
SplittedBeforePosition | Returns the list cut in two just before a position, leaving the splitter as it was. | a list of two lists | _n_=the position that starts the second part, from 1 | SplitBeforePosition, SplittedAfterPosition | | a position below 2 or past the end gives one part
SplitBefore | Cuts the list just before each occurrence of an item, in place, keeping the item at the start of its part. | nothing; the content changes. SplitBeforeQ returns the splitter for chaining | pItem=the item to cut before; a number is read as a position | SplitAfter, SplitAt, SplitBeforePosition | | an absent item leaves the list flat, as it was, where SplitAt wraps it as one part; SplitBeforeCS(pItem, 0) ignores case
SplitAfterPosition | Cuts the list in two just after a position, in place. | nothing; the content changes. SplitAfterPositionQ returns the splitter for chaining | _n_=the position that ends the first part, from 1 | SplittedAfterPosition, SplitBeforePosition | | a position at or past the last item leaves one part
SplittedAfterPosition | Returns the list cut in two just after a position, leaving the splitter as it was. | a list of two lists | _n_=the position that ends the first part, from 1 | SplitAfterPosition, SplittedBeforePosition | | a position at or past the last item gives one part
SplitAfter | Cuts the list just after the LAST occurrence of an item, in place, so it makes two parts at most. | nothing; the content changes. SplitAfterQ returns the splitter for chaining | pItem=the item to cut after; a number is read as a position | SplitBefore, SplitAfterPosition | | unlike SplitBefore it does not cut at every occurrence: a b - c d - e cut after - gives the parts [ a, b, -, c, d, - ] and [ e ]; SplitAfterCS(pItem, 0) ignores case; an absent item leaves the list as it was
SplitAtPosition | Cuts the list in two just before a position, in place. | nothing; the content changes. SplitAtPositionQ returns the splitter for chaining | _n_=the position that starts the second part, from 1 | SplitBeforePosition, SplitAtPositions | | the same cut as SplitBeforePosition
SplitAt | Cuts the list at each occurrence of an item, in place, so the item starts a new part and is kept. | nothing; the content changes. SplitAtQ returns the splitter for chaining | pItem=the item to cut at; a number is read as a position | SplittedAt, SplitBefore, SplitAfter | | a b - c d - e cut at - gives the parts [ a, b ], [ -, c, d ] and [ -, e ]; an absent item gives one part holding everything, where SplitBefore leaves the list flat; SplitAtCS(pItem, 0) ignores case
SplittedAt | Returns the list cut at each occurrence of an item, leaving the splitter as it was. | a list of lists | pItem=the item to cut at; a number is read as a position | SplitAt, SplittedAtPositions | | the item starts the next part and is kept; SplittedAtCS(pItem, 0) ignores case, so X and x both cut
SplitToNParts | Cuts the list into n consecutive parts of nearly equal size, in place. | nothing; the content changes. SplitToNPartsQ returns the splitter for chaining | _n_=how many parts to make | SplittedToNParts, SplitToPartsOfNItems | | 7 items in 3 parts give 3, 2 and 2 items, the extra items going to the first parts; an n larger than the count gives one part per item, and 0 gives [ ]
SplittedToNParts | Returns the list cut into n consecutive parts of nearly equal size, leaving the splitter as it was. | a list of lists | _n_=how many parts to make | SplitToNParts, SplittedToPartsOfNItems | | 7 items in 3 parts give 3, 2 and 2 items; an n larger than the count gives one part per item, and 0 or an empty list gives [ ]
SplitToPartsOfNItems | Cuts the list into consecutive parts of n items each, the last one possibly shorter, in place. | nothing; the content changes. SplitToPartsOfNItemsQ returns the splitter for chaining | _n_=how many items each part holds | SplittedToPartsOfNItems, SplitToNParts | | 7 items in parts of 3 give 3, 3 and 1 items; 0 gives [ ]
SplitToPartsOf | Cuts the list into consecutive parts of n items each, the last one possibly shorter, in place. | nothing; the content changes | _n_=how many items each part holds | SplitToPartsOfNItems, SplittedToPartsOfNItems | | the same call as SplitToPartsOfNItems
SplittedToPartsOfNItems | Returns the list cut into consecutive parts of n items each, leaving the splitter as it was. | a list of lists | _n_=how many items each part holds | SplitToPartsOfNItems, SplittedToNParts | | 7 items in parts of 3 give 3, 3 and 1 items; 0 gives [ ]; SplittedToPartsOf is the same call
SplittedW | Returns the list cut just before each item that satisfies a condition, leaving the splitter as it was. | a list of lists | pcCondition=the test, written with @item for the current item, such as "@item % 3 = 0" | SplittedAt, SplittedAtPositions | | the item that satisfies the test starts the next part and is kept; 1 to 7 with "@item % 3 = 0" gives the parts [ 1, 2 ], [ 3, 4, 5 ] and [ 6, 7 ]; SplitW cuts in place
SplitAtPacer | Cuts the list at a start position and then every given number of positions after it, in place. | nothing; the content changes. SplitAtPacerQ returns the splitter for chaining | nPace=the distance between two cuts; nStart=the first position where a part starts | SplittedAtPacer, SplitAtPositions | a pace of 0 never ends: the code adds positions in a loop that does not advance (read from the code, not run, since it would fill the memory) | 1 to 7 with pace 3 from 3 gives the parts [ 1, 2 ], [ 3, 4, 5 ] and [ 6, 7 ]
SplittedAtPacer | Returns the list cut at a start position and then every given number of positions after it, leaving the splitter as it was. | a list of lists | nPace=the distance between two cuts; nStart=the first position where a part starts | SplitAtPacer, SplittedAtPositions | a pace of 0 never ends, as in SplitAtPacer (read from the code, not run) | 1 to 7 with pace 2 from 2 gives the parts [ 1 ], [ 2, 3 ], [ 4, 5 ] and [ 6, 7 ]
