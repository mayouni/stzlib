init | Builds an empty flow of that name, with an empty stzGraph of its own to hold the stages. | nothing; the object is built | pcName=the flow's name, shown in findings and in the trace of its parcels | StzFlowQ, AddStage | | a flow is built stage by stage with AddStage and ConnectStages, and is checked before it runs
Name | Returns the name the flow was built with. | a text | | StzFlowQ, Explain | |
Graph | Returns the stzGraph the flow composes, with one node per stage and one edge per connection. | an stzGraph | | AddStage, ConnectStages | | cycle detection and reachability of the graph apply to the flow unchanged
Stages | Returns the stage rows in the order they were added. | a list of rows, each a list of [ key, value ] pairs: id, faculty, params, impl, floor, set | | StageIds, AddStage, PinStage | after a run the params of a stage hold the faculty's defaults merged in, because the run writes the merge back into the stage's list | impl, floor and set hold the pins of the stage: the registry decides when all three are empty
StageIds | Returns the ids of the stages in the order they were added. | a list of text | | Stages, TopologicalOrder | | the order added is not the order run: TopologicalOrder gives the order of the data flow
Edges | Returns the connections between stages, in the order they were made. | a list of [ from, to ] pairs of stage ids | | ConnectStages, Predecessors | |
NumberOfStages | Returns how many stages the flow holds. | a number | | StageIds, AddStage | |
AddStage | Adds a stage that runs a declared faculty; the flow names faculties and never models. | nothing; use AddStageQ to chain | pcId=the stage's id, unique in the flow; pcFaculty=the name of a faculty already declared, folded to lower case; paParams=call parameters of the stage, merged over the faculty's defaults, where any value that is not a list counts as an empty list | ConnectStages, PinStage, StzFacultyQ | raises an error for an id the flow already has and for a faculty that is not declared, naming the declared ones | the stage also becomes a node of the flow's stzGraph
ConnectStages | Connects the output of one stage to the input of another, in the order given. | nothing; use ConnectStagesQ to chain | pcFrom=the id of the producing stage; pcTo=the id of the consuming stage | AddStage, Predecessors, CheckRules | raises an error when either stage is not in the flow; nothing is checked about types, cycles or fan-in here, those are findings of CheckRules | the stage with no predecessor receives the input of Run
PinStage | Pins a stage to one implementation by id, or to its floor with floor; the registry never overrides a pin. | nothing; use PinStageQ to chain | pcId=the id of the stage; pImpl=the id of an implementation of the stage's faculty, or the word floor in any case | PinStageToSet, UnpinStage, UseFloorEverywhere | the id is not checked when pinned: an unknown one is refused only when the flow runs, with an unknown-implementation finding naming the stage, and a pinned implementation that is not installed is refused too, never replaced | pinning an implementation clears a floor pin and the reverse; a service can only be reached by pinning it by name
PinStageToSet | Restricts the registry's choice for a stage to the implementations listed, still by measured quality. | nothing; use PinStageToSetQ to chain | pcId=the id of the stage; pacImpls=a list of implementation ids the registry may choose among | PinStage, UnpinStage, ResolvePlan | an id outside the faculty is simply never chosen, and when no listed id qualifies the floor answers; listing a service without pinning it is an error finding of CheckRules | the other implementations appear in the plan as rejected, not in the pinned set
UnpinStage | Removes every pin from a stage, so the registry chooses for it again. | nothing; use UnpinStageQ to chain | pcId=the id of the stage | PinStage, PinStageToSet | raises an error when the stage is not in the flow | it clears the implementation pin, the floor pin and the set
UseFloorEverywhere | Puts every stage on its deterministic floor, whatever the pins and the measurements say. | nothing; use UseFloorEverywhereQ to chain | | UseRegistryChoice, IsOnFloorEverywhere | it beats an implementation pin of a stage, because resolution looks at the floor pin first | meant for a machine with no model, or a test; the pins are kept and apply again after UseRegistryChoice
UseRegistryChoice | Gives the choice back to the registry and the stage pins, undoing UseFloorEverywhere. | nothing; use UseRegistryChoiceQ to chain | | UseFloorEverywhere, IsOnFloorEverywhere | |
IsOnFloorEverywhere | TRUE if the flow was told to run every stage on its floor. | TRUE or FALSE | | UseFloorEverywhere, UseRegistryChoice | | the process-wide model policy is separate: StzModelPolicy(:deterministic) also puts every faculty on its floor
Predecessors | Returns the ids of the stages that feed into a stage. | a list of text; [ ] for a first stage and for an id the flow does not have | pcId=the id of the stage | Edges, ConnectStages | | more than one predecessor is a fan-in finding, because this slice has no merge faculty
TopologicalOrder | Returns the stage ids in an order where every stage comes after the stages feeding it. | a list of text; [ ] for an empty flow and for a flow with a cycle | | CheckRules, Run | | stages that do not depend on each other keep the order they were added in
CheckRules | Returns the findings about the flow's wiring, without running anything. | a list of findings, each [ rule, subject, where, severity, message ] with subject model-flow; [ ] when nothing is wrong | | IsSound, ResolvePlan, Run | | the rules are empty-flow, cycle, floor-missing, fan-in, type-mismatch-on-edge and service-not-pinned as errors, and golden-set-missing as a warning
IsSound | TRUE if the flow has no finding of error severity, so Run will try it; warnings do not count. | TRUE or FALSE | | CheckRules, Run | |
ResolvePlan | Returns, stage by stage in run order, the implementation each stage would use and why; nothing runs. | a list of [ key, value ] pairs: stages, one plan per stage with its stage id added; findings from CheckRules; memory, the largest memory in MB among the chosen implementations | | Why, CheckRules, stzModelPlan | a flow with a cycle plans no stage, and a stage whose plan is a refusal counts nothing toward memory | memory is the largest resident model and not the sum, because the engine holds one model at a time
Why | Returns, one line per stage in run order, which implementation the stage would use and the first reason. | a text starting with the flow's name, then a line per stage | | ResolvePlan, Explain | | this plans and runs nothing; the reason shown is the first line of the stage's plan
Explain | Returns the flow as declared: its stages with faculty, payload types and pin, then its connections. | a text, one line per stage and per connection | | Why, Stages, Edges | | it says how each stage is pinned, not which implementation the registry would pick: Why does that
Run | Runs the flow on an input and returns the value of the last stage in run order. | the value of the last stage, which for a refusal is the list of findings | pInput=the value handed to every stage that has no predecessor | StageParcelQ, CheckRules, ResolvePlan | a flow with an error finding is refused before any stage runs; the first stage that refuses stops the run and its findings, prefixed with the stage id, come back as the value; the run rewrites the stages' params with the merged defaults; not exercised with a real model: the answer shape is read from the code | RunQ returns the parcel with the whole provenance chain; the value is that of the last stage in order even when the flow has several branches
StageParcelQ | Returns the parcel a stage produced in the last run of the flow. | an stzParcel; a refusal parcel with the rule stage-not-run when the stage did not run | pcId=the id of the stage | Run, stzParcel | |
