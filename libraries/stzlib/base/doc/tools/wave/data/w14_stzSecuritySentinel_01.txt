init | Builds a sentinel that judges the ledger with the given detection set. | nothing; the object is built | poDetectionSet=the detection set whose findings the sentinel turns into alerts, such as the one StzDefaultDetectionSet returns | Watching, Check | | without Watching, the process-wide ledger is the one watched
Name | Returns the sentinel's name, security-sentinel until it is renamed. | a text | | SetName, Name_
Name_ | Returns the sentinel's name, the way an agent host asks for it. | a text | | Name, Cycle
SetName | Gives the sentinel a name, which an agent host uses to tell its agents apart. | the sentinel itself, so calls chain | pcName=the new name; an empty text or a non-text is ignored | Name, Cycle
Watching | Points the sentinel at a given ledger instead of the process-wide one. | the sentinel itself, so calls chain | poLedger=the ledger to judge on every check | Check, SetName
OnDetection | Sets the function called once for each detection that starts firing. | the sentinel itself, so calls chain | pfCallback=a function that receives the finding, a hash list with the keys rule, severity, where and message | OnClear, Check | | a detection already firing does not call it again until it has cleared
OnClear | Sets the function called once for each detection that stops firing. | the sentinel itself, so calls chain | pfCallback=a function that receives the where text of the detection that cleared | OnDetection, Check
SetChannels | Sets the two event-bus channels on which firings and clearings are announced. | the sentinel itself, so calls chain | pcDetection=the channel name for a detection that starts; pcClear=the channel name for one that clears | DetectionChannel, ClearChannel | | the defaults are sec.detection and sec.clear; the channels are process-wide, so other code can wait on them
DetectionChannel | Returns the event-bus channel on which new detections are announced. | a text | | SetChannels, ClearChannel
ClearChannel | Returns the event-bus channel on which cleared detections are announced. | a text | | SetChannels, DetectionChannel
Every | Sets the cadence of Tick, in milliseconds. | the sentinel itself, so calls chain | pnMs=the minimum time between two ticks that check; a value below 1 or a non-number is ignored | Tick, Cycle | | the default is 1000
Check | Judges the ledger once and fires only what changed since the last pass: new detections start, ended ones clear. | a number, how many detections started firing in this pass | | Tick, ActiveDetections, OnDetection | | the identity of a detection is its where text, such as credential-stuffing/victim, so two accounts under attack are two alerts and one account still under attack is not a new alert; each start also records a case
Tick | Checks the ledger when the cadence says it is due, and does nothing before. | a number, how many detections started firing, or 0 when the tick was not due | | Check, Every, Cycle | | the clock is monotonic, so a change of the wall clock does not disturb it
CheckCount | Returns how many passes have judged the ledger. | a number | | Check
ActiveDetections | Returns the where text of every detection that is firing now. | a list of texts, empty when quiet | | IsFiring, Check
IsFiring | TRUE if at least one detection is firing. | TRUE or FALSE | | ActiveDetections
AlertLog | Returns the sentinel's own log of starts and clears, oldest first. | a list of entries, each a list of the monotonic time in milliseconds, the kind detection or clear, the where text and the message | | LastAlert | | the log keeps the newest 256 entries; it is not written to the ledger, so detections over detections cannot feed back
LastAlert | Returns the newest entry of the alert log, or an empty list when nothing has fired. | a list of time, kind, where and message | | AlertLog
Cases | Returns the snapshots taken when detections started firing, oldest first. | a list of hash lists, each with the keys at, where, rule, severity, message, ledgercount, headdigest and recent | | LastCase | | only the newest 16 are kept; the keys are lower case: ledgercount, headdigest
LastCase | Returns the newest case snapshot, or an empty list when nothing has fired. | a hash list with the keys at, where, rule, severity, message, ledgercount, headdigest and recent | | Cases | | headdigest is a 64-character digest committing to the whole ledger history at that moment, and recent holds the events nearest the firing
Explain | Returns the sentinel's state as lines of text: its name, its check count and one line for each firing detection. | a list of texts | | Show, ActiveDetections
Show | Prints the lines of Explain. | nothing; it prints lines | | Explain
