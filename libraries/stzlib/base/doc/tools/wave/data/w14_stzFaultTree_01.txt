init | Builds an empty fault tree that draws top-down with the fault notation, with a title. | nothing; the object is built | pcTitle=the title of the diagram | AddTop, Develop
AddTop | Declares the top event, the undesired event the whole tree explains. | the tree itself, so calls chain | pcId=the event's identifier, which must be new in the tree; pcName=the event's name, shown in its box | AddEvent, TopEvent | a second top is accepted here and refused by the rule one_top_event; an identifier already in the tree raises an error
AddEvent | Declares an intermediate event, one that a gate develops into its causes. | the tree itself, so calls chain | pcId=the event's identifier, which must be new in the tree; pcName=the event's name, shown in its box | AddTop, Develop, AddBasic | an identifier already in the tree raises an error
AddBasic | Declares a basic event, a leaf, whose probability is not known yet; AddBasicXT gives it one. | the tree itself, so calls chain | pcId=the event's identifier, which must be new in the tree; pcName=the event's name, shown beneath its circle | AddUndeveloped, ProbabilityOf | AddBasicXT(id, name, p) takes the probability as a number from 0 to 1 and raises an error outside that range; without a probability the rule basic_event_has_probability reports the leaf, the drawing shows a question mark in its circle, and ProbabilityOf raises an error for it
AddUndeveloped | Declares an event the analyst chose not to develop and says so, drawn as a diamond. | the tree itself, so calls chain | pcId=the event's identifier, which must be new in the tree; pcName=the event's name, shown beneath its diamond | AddBasic, AddEvent | it owes no probability and the rules leave it alone, but ProbabilityOf raises an error for it
AddNote | Adds a free note to the drawing; it is not an event of the tree. | the tree itself, so calls chain | pcId=the note's identifier; pcText=the text of the note | AddEvent | the rules and the numbers ignore a note
AddGate | Declares a gate, And or Or, not yet attached to any event. | the tree itself, so calls chain | pcId=the gate's identifier, which must be new in the tree; pcKind=And or Or, in any letter case, as a text or a symbol | Under, Feed, Develop | any other kind, such as Xor, raises an error saying it is not a gate
Under | Attaches a gate beneath an event, so the gate develops that event. | the tree itself, so calls chain | pcEvent=the identifier of the event to develop; pcGate=the identifier of the gate that develops it | Feed, Develop | an unknown event or an unknown gate raises an error; an event given two gates is reported by the rule event_is_developed
Feed | Makes an event an input of a gate, one of the causes the gate combines. | the tree itself, so calls chain | pcGate=the identifier of the gate; pcInput=the identifier of the event that feeds it | Under, Develop, InputsOf | an input that is a gate raises an error, give it an event of its own; the same event may feed several gates, which is what makes the cut sets differ from the gate arithmetic
Develop | Adds a gate beneath an event and feeds it a list of events, in one call. | the tree itself, so calls chain | pcEvent=the identifier of the event to develop; pcKind=And or Or; pacInputs=the identifiers of the events that feed the gate | AddGate, Under, Feed | the gate is named after the event, event.gate; developing the same event twice raises an error because that name is taken | DevelopQ is the same call
Events | Returns the events of the tree, in the order they were added. | a list of hashlists with the keys id, name, kind (top, event, basic or undeveloped) and p; p is -1 where no probability was given | | Gates, Inputs
Gates | Returns the gates of the tree, in the order they were added. | a list of hashlists with the keys id, kind (and or or) and event; event is empty for a gate that develops nothing | | Events, Inputs
Inputs | Returns every feed of the tree, one entry per gate and input pair. | a list of hashlists with the keys gate and input | | InputsOf, Gates
GateOf | Returns the identifier of the gate that develops an event. | a text; empty when the event has no gate | pcEvent=the identifier of the event, without regard to case | InputsOf, Under
InputsOf | Returns the identifiers of the events that feed a gate, in the order added. | a list of text; empty for an unknown gate | pcGate=the identifier of the gate, without regard to case | GateOf, Feed
TopEvent | Returns the identifier of the top event. | a text; empty when no top was declared | | AddTop, TopProbability | with several tops it answers the first one declared
ProbabilityOf | Returns the probability of an event or a gate, computed up from the basic events. | a number from 0 to 1 | pcId=the identifier of an event or a gate | TopProbability, CutSetProbability | an AND gate multiplies its inputs and an OR gate takes 1 minus the product of their complements, both assuming the inputs independent; it raises an error for a basic event with no probability, for an undeveloped event, for an event with no gate, for a gate with no input, for an unknown identifier and for an event among its own causes | with a basic event repeated under two gates the answer is an approximation; CutSetProbability is exact
TopProbability | Returns the probability of the top event, computed up the tree. | a number from 0 to 1 | | ProbabilityOf, CutSetProbability, MinimalCutSets | it raises an error when no top is declared, and for every cause ProbabilityOf refuses
MinimalCutSets | Returns the smallest sets of basic events that bring the top event about. | a list of lists of identifiers, the smallest sets first, each set in the order its events were added | | CutSetProbability, TopProbability | it raises an error when no top is declared or an event is among its own causes; an undeveloped event or an event with no gate counts as a leaf of a set | found by expansion: an OR unites the sets of its inputs, an AND crosses them, then a set that holds another is dropped
CutSetProbability | Returns the exact probability of the top event, summed over the minimal cut sets by inclusion and exclusion. | a number from 0 to 1; 0 when there is no cut set | | TopProbability, MinimalCutSets | it raises an error beyond twelve minimal cut sets and when no top is declared; every basic event is taken independent of the others | it differs from TopProbability when a basic event appears under two gates: 0.044 against 0.0494 for a sensor repeated under two branches
AsRuleGraph | Returns the tree as a plain graph that the five fault rules read. | a stzGraph with the events, gates and notes as nodes carrying kind, name and p, and the develop and feed lines as edges | | GovernanceFindings
GovernanceFindings | Returns what the five fault rules find wrong with the tree, warnings included. | a list of findings, each a hashlist with the keys rule, where, severity and message; empty when the tree is sound | | GovernanceIsSound, AsRuleGraph | the rules are one_top_event, gate_has_two_inputs, basic_event_has_probability, event_is_developed and no_event_causes_itself | CheckRules is the same call
GovernanceIsSound | TRUE if the rules found no error; warnings do not count against it. | TRUE or FALSE | | GovernanceFindings | RulesAreSound is the same call
RenderProbabilities | Returns what the last drawing wrote inside each basic event. | a list of [ id, p, x, y ] rows, p being -1 where none was declared; empty before the first drawing | | ProbabilityOf
