init | Builds a comparison of several executed plans from their names and their [ name, result ] pairs, which the planner supplies. | nothing; the comparison is built | poPlanner=The stzGraphPlanner the plans belong to; pacPlanNames=The names of the plans asked for, as a list; paResults=The [ plan name, result ] pairs of the plans that were found and executed | RankBy, CompareAll | usually reached through stzGraphPlanner.CompareManyQ
RankBy | Ranks the plans by cost or by route length, smallest first. | a list of [ plan name, value ] pairs | _cCriterion_=cost, or steps or length for the number of route nodes; case is ignored | BestBy, RankingTable | any other word gives every plan the value 0
RankingTable | Returns a table of the plans ranked by cost, with a header row and the rank, plan, cost and steps of each. | a list of rows, the first being the header | | ShowRankingTable, RankBy | steps counts route nodes
ShowRankingTable | Prints the ranking table as a boxed table. | nothing; a table is printed | | RankingTable
BestBy | Returns the name of the plan with the smallest value of a criterion; raises an error when no plan was compared. | text | _cCriterion_=cost, or steps or length for the number of route nodes; case is ignored | WorstBy, RankBy | with a tie the plan listed first wins
WorstBy | Returns the name of the plan with the largest value of a criterion; raises an error when no plan was compared. | text | _cCriterion_=cost, or steps or length for the number of route nodes; case is ignored | BestBy, RankBy | with a tie the plan listed last is the worst
CompareAll | Returns every plan's cost, route length and route, with the best plan by cost and by length. | a hash list [ :total_plans, :plans, :best_by_cost, :best_by_steps ] | | RankBy, BestBy | total_plans counts the names asked for, even those left out for not being executed; raises when no plan was compared
