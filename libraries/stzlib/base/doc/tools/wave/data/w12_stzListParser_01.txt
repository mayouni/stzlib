# w12 stzListParser -- Name | brief | returns | params | see | warning | note
init | Builds a parser over a non-empty list and parses it from the first position to the last, one step at a time. | nothing; the object is built, with the cursor on position 1 | paList=the list to walk through, which must not be empty, a text or an empty list raises an error | List, Parse |  | the parser keeps the list as given; stzParser.Source of a stzListParser answers an empty text, so read the list with List
List | Returns the list being parsed. | a list |  | ParsedItems, ParsedPositions
ParsedPositions | Returns the positions the current parse visits, in order. | a list of numbers, positions in the list counted from 1 |  | ParsedItems, Parse |  | after Parse(3, 8, 2) on a list of 8 it is [ 3, 5, 7 ]
StartPosition | Returns the position the current parse starts at. | a number |  | EndPosition, Parse
EndPosition | Returns the position the current parse was asked to stop at. | a number |  | StartPosition, Parse |  | after Parse(3, 8, 2) it is 8, though the last position visited is 7
NumberOfSteps | Returns the step of the current parse: the distance between two visited positions. | a number |  | Parse, SetNumberOfSteps |  | it is a step length, not a count of positions; use len(ParsedPositions()) for the count
Parse | Chooses which positions to visit, from a start to an end by a step, and puts the cursor on the first one. | nothing; the parser is re-parsed | pnStart=the first position, a number or :First, also accepted as :From = n; pnEnd=the last position, a number or :Last, also accepted as :To = n; pnStep=the distance between two positions, a negative number walks backwards, also accepted as :Step = n | ParsedPositions, Reset, SetStartPosition |  | Parse(5, 2, -1) on abcde visits 5, 4, 3, 2; no check is made against the list, so Parse(1, 20, 1) on a list of 5 gives 20 positions and ParsedItems then raises an error
SetStartPosition | Changes the position the parse starts at and parses again, keeping the end and the step. | nothing; the parser is re-parsed and the cursor goes to the first position | pnStart=the new first position | SetEndPosition, SetNumberOfSteps, Parse
SetEndPosition | Changes the position the parse stops at and parses again, keeping the start and the step. | nothing; the parser is re-parsed and the cursor goes to the first position | pnEnd=the new last position | SetStartPosition, SetNumberOfSteps, Parse
SetNumberOfSteps | Changes the step of the parse and parses again, keeping the start and the end. | nothing; the parser is re-parsed and the cursor goes to the first position | pnSteps=the new distance between two positions | SetStartPosition, SetEndPosition, Parse
SetCurrentPosition | Moves the cursor to a position that belongs to the parse, or back to the default one with :Default. | nothing; a position outside the parse, or any other value, is ignored without an error | n=the position to move to, a number in ParsedPositions, or :Default for the default current position | CurrentPosition, ResetCurrentPosition |  | SetCurrentPosition(5) on a parse of 4, 6 leaves the cursor where it was
CurrentPosition | Returns the position the cursor is on. | a number |  | CurrentItem, SetCurrentPosition
ResetCurrentPosition | Puts the cursor back on the default current position when the parse contains it, otherwise on the first parsed position. | nothing; the cursor moves |  | SetCurrentPosition, Reset
NextNthPosition | Moves the cursor forward by n visited positions and returns the position it lands on. | a number, the new cursor position | n=how many visited positions to advance, counted in the parse, not in the list | NextPosition, PreviousNthPosition, NextNthItem | moving past the last visited position raises an error (R2, array access out of range) instead of answering 0, and the cursor stays where it was; NextNthPosition(9) on 5 positions and NextPosition on the last one both raise | with a step of 2, NextNthPosition(2) advances four list positions; NthNextPosition is the same call
NextPosition | Moves the cursor to the next visited position and returns it. | a number, the new cursor position |  | NextNthPosition, PreviousPosition, NextItem | moving past the last visited position raises an error (R2, array access out of range) and leaves the cursor in place
PreviousNthPosition | Moves the cursor back by n visited positions and returns the position it lands on. | a number, the new cursor position | n=how many visited positions to go back, counted in the parse, not in the list | PreviousPosition, NextNthPosition, PreviousNthItem | moving before the first visited position raises an error (R2, array access out of range) instead of answering 0, and the cursor stays where it was | NthPreviousPosition is the same call
PreviousPosition | Moves the cursor to the previous visited position and returns it. | a number, the new cursor position |  | PreviousNthPosition, NextPosition, PreviousItem | moving before the first visited position raises an error (R2, array access out of range) and leaves the cursor in place
ParsedItems | Returns the items at the visited positions, in the order visited. | a list of items |  | ParsedPositions, List |  | with positions beyond the list it raises an error (R2, array access out of range)
CurrentItem | Returns the item under the cursor, without moving it. | the item at CurrentPosition |  | CurrentPosition, NextItem
NextNthItem | Moves the cursor forward by n visited positions and returns the item it lands on. | the item at the new position | n=how many visited positions to advance | NextNthPosition, NextItem | moving past the last visited position raises an error, as NextNthPosition does | NthNextItem is the same call
NextItem | Moves the cursor to the next visited position and returns the item there. | the item at the new position |  | NextNthItem, PreviousItem, CurrentItem | moving past the last visited position raises an error (R2, array access out of range) | the cursor moves, so two calls give two different items
PreviousNthItem | Moves the cursor back by n visited positions and returns the item it lands on. | the item at the new position | n=how many visited positions to go back | PreviousNthPosition, PreviousItem | moving before the first visited position raises an error, as PreviousNthPosition does | NthPreviousItem is the same call
PreviousItem | Moves the cursor to the previous visited position and returns the item there. | the item at the new position |  | PreviousNthItem, NextItem, CurrentItem | moving before the first visited position raises an error (R2, array access out of range)
Reset | Parses again with the default start, end and step, and puts the cursor back to its default. | nothing; the parser is re-parsed |  | Parse, ResetCurrentPosition, SetDefaultStartPosition |  | it returns to the defaults (1, :End, 1), not to the last Parse
SetDefaultStartPosition | Sets the start position Reset will use. | nothing; takes effect at the next Reset | pnStart=the default first position | DefaultStartPosition, Reset
DefaultStartPosition | Returns the start position Reset uses. | a number; 1 until changed |  | SetDefaultStartPosition, Reset
SetDefaultEndPosition | Sets the end position Reset will use. | nothing; takes effect at the next Reset | pnEnd=the default last position, a number or :End | DefaultEndPosition, Reset
DefaultEndPosition | Returns the end position Reset uses. | a number, or the word end until changed |  | SetDefaultEndPosition, Reset
SetDefaultNumberOfSteps | Sets the step Reset will use. | nothing; takes effect at the next Reset | pnSteps=the default distance between two positions | DefaultNumberOfSteps, Reset
DefaultNumberOfSteps | Returns the step Reset uses. | a number; 1 until changed |  | SetDefaultNumberOfSteps, Reset
SetDefaultCurrentPosition | Sets the position the cursor returns to on Reset and ResetCurrentPosition, when the parse contains it. | nothing; takes effect at the next reset | n=the default cursor position | DefaultCurrentPosition, ResetCurrentPosition
DefaultCurrentPosition | Returns the position the cursor returns to on Reset. | a number; 1 until changed |  | SetDefaultCurrentPosition, ResetCurrentPosition
