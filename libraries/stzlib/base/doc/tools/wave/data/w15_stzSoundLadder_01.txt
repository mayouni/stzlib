# w15 stzSoundLadder -- a drawing of numbers, no audio is involved; the SVG was rendered to a picture by a headless browser and read by a model, not by a person (UNPERCEIVED)
init | Reads one mode of a declared universe and prepares to show its degrees as a ladder. | nothing; the ladder is usable if the universe and a mode with degrees were found | pUniverse=the universe name or object, such as :tunisian or :maqam; pMode=the name of a mode of that universe, or an empty text for its first | IsUsable, Rungs | an unknown universe is not raised: the ladder is not usable and LastError lists the declared universes; a mode name the universe does not declare is not refused either: the ladder shows the universe default mode instead, without any error, so :tunisian with :rast and :maqam with :zzz gave the modes dhil and rast with IsUsable 1 | StzSoundLadderQ builds the same object
Tonic | Sets the note the ladder is built on. | the ladder itself, so calls chain | pcNote=a note name such as D4 | Rungs, TonicName | | the cents stay the same and the hertz of every rung move with the tonic: for the dhil mode on D4 the first rung is 293.66 hertz
IsUsable | TRUE if the ladder has a mode with degrees to show. | TRUE or FALSE, as 1 or 0 | | LastError, init |
LastError | Returns why the ladder is not usable. | the reason as text; an empty text when it is usable | | IsUsable |
ModeName | Returns the name of the mode on show. | the mode name as text, in lower case | | TonicName, init | | it is the default mode of the universe when the requested name was not found
TonicName | Returns the note the ladder is built on. | the note as text, such as C4 | | Tonic, ModeName | | C4 until Tonic or the mode sets another
Rungs | Returns every degree of the mode as a rung, the octave included, with its pitch and the step to the next rung. | a list of [ degree, name, cents above the tonic, hertz, step to the next rung in cents ]; the last, octave rung has a step of 0 | | DescendingRungs, Steps | | rungs are spaced by cents, so a half-flat third sits half way between the minor and the major third; for the dhil mode on C4 the degrees are at 0, 200, 350, 500, 700, 900 and 1050 cents and the third is 320.24 hertz, checked by hand as 261.63 times 2 to the power of 350 over 1200; a mode that declares no names shows its degree numbers
DescendingRungs | Returns the degrees of the descending form of the mode, when it differs from the ascending one. | the same rows as Rungs; [ ] when the mode declares no descending form or it equals the ascending one | | Rungs, ToText | | in the maqam rast the seventh degree is 1050 cents going up and 1000 coming down
Steps | Returns the distances between neighbouring rungs, in cents. | a list of numbers, one fewer than the rungs | | Rungs | | for the dhil mode 200, 150, 150, 200, 200, 150, 150
Ajnas | Returns the ajnas, the small scales a mode is built from, with the cents each spans. | a list of [ name, lowest cents, highest cents, the list of its cents above the tonic ] | | Rungs, ToText | | a jins counts its cents from its own first degree, unless they begin below zero, when the declaration counted them from the tonic; the dhil mode has a rast on the tonic, 0 to 500, and one below it, minus 500 to 0
ToText | Returns the ladder as plain text, the highest rung first, with the cents, the hertz and the steps. | a multi-line text | | ToSVG, Rungs | | a step is named when it falls on the quarter-tone grid, such as 150 (3/4 tone), and a step off the grid has no name; descending forms and ajnas are listed after the rungs
SaveAs | Writes the ladder to a file: SVG when the name ends in .svg, an HTML page otherwise. | the number of characters written | pcPath=the path of the file | ToSVG, ToHTML | | an existing file is overwritten
ToHTML | Returns the ladder as a complete HTML page with the SVG inside. | the HTML text, starting with the doctype | | ToSVG, SaveAs |
ToSVG | Returns the ladder as SVG text: rails, rungs spaced by cents, a faint quarter-tone grid, steps, and brackets for the ajnas. | the SVG text, starting with <svg | | ToHTML, ToText | | a degree the mode lowers going down is a dashed rung, a degree the sources disagree on is dotted with its source named, and a degree left out going down is marked; seen in a rendered picture of the dhil mode on D4: eight rungs from 0 to 1200 cents, the half-flat third between two dotted variants at 300 and 400, the steps beside the rails and the rast bracket
