# w15 stzProfiler
init | Builds a frame profiler whose frame stack and path table live in the engine, bounded to a number of distinct paths. | nothing; the engine handle is made when the object is built | pnMaxPaths=the most distinct paths kept, 2 or more, otherwise 256 | Enter, Leave | | StzProfiler builds the same object; beyond the bound, paths fold into an _overflow path that stays visible, so with a bound of 2 only one path of its own fits; frames deeper than 32 fold into their parent
Enter | Opens a frame, a named piece of work whose time is measured until the matching Leave. | the profiler itself, so calls chain | pcFrameName=the name of the frame | Leave, Depth | | frames nest, and a frame's path is its name joined to its parents' with semicolons; a call costs one engine call; a destroyed profiler is made again by it
Leave | Closes the innermost open frame and adds its time to its path. | the profiler itself, so calls chain | | Enter, Depth | | leaving with no frame open does nothing and leaves the depth at 0; a path is recorded when its frame is left, so a child path is listed before its parent
Depth | Returns how many frames are open now. | a number | | Enter, Leave |
StartSampling | Starts the engine's sampler thread, which photographs the active frame path at a fixed interval. | the profiler itself, so calls chain | pnIntervalMs=the interval between photographs, in milliseconds | StopSampling, Ticks | | the cost is constant and does not depend on how often frames are entered; without a running reactor Windows rounds a short interval up to about 15.6 ms, so there are fewer samples with the same statistics
StopSampling | Stops the sampler thread. | the profiler itself, so calls chain | | StartSampling, IsSampling | |
IsSampling | TRUE if the sampler thread is running. | TRUE or FALSE | | StartSampling, StopSampling | |
Ticks | Returns how many times the sampler woke up, in a frame or idle. | a number; 0 before sampling | | StartSampling, Paths | | the samples of the paths add up to no more than the ticks; the count is live, so assert ranges and signs
PathCount | Returns how many distinct paths have been recorded. | a number | | Paths, Reset | |
Paths | Returns every recorded path with its instrumented and sampled numbers. | a list of hash lists with the keys path, calls, totalms, selfms and samples, in the order the frames were left; times are in milliseconds | | HotSpots, Folded | | total includes the children and self does not; instrumented numbers are exact for what was bracketed and sampled numbers are statistical
HotSpots | Returns the paths that spent the most time in themselves, children excluded. | a list of the same hash lists as Paths, longest self time first, at most pnHowMany | pnHowMany=how many paths to return | Paths, Folded | | asking for more than exist returns them all
Folded | Returns the paths in the folded-stacks format that flame-graph tools read, one line per path as the path then a weight. | a text of lines such as checkout;charge 42 | | WriteFoldedTo, HotSpots | | the weight is the sample count when sampling ran and otherwise the self time in milliseconds rounded up; a path of weight 0 is left out
WriteFoldedTo | Writes the folded stacks to a file, ready for flamegraph.pl or speedscope. | the profiler itself, so calls chain | pcPath=the path of the file to write | Folded | | an existing file is overwritten
Explain | Returns the call tree as lines of text: a header, then each path with its calls, total and self time, and its samples if any. | a list of text lines | | Show, Paths | | a deeper path is indented, and because children are recorded first they appear before their parent
Show | Prints the call tree to the console, one line per line. | nothing | | Explain | | it prints with the ? statement
Reset | Clears the recorded paths and the open frames. | the profiler itself, so calls chain | | Destroy, Paths | |
Destroy | Stops the sampler and frees the engine handle. | the profiler itself, so calls chain | | Reset, init | | a later call that needs the engine makes a new handle, so a destroyed profiler starts again empty
