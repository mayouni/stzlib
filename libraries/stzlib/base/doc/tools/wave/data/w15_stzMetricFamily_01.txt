# w15 stzMetricFamily
init | Builds a family of one metric name over declared labels, with an engine registry for its children and a reserved overflow child. | nothing; the engine registry and the overflow child exist when the object is made | pcName=the metric name, such as http.checkout.ms; pcKind=Counter, Gauge or Timer, in any letter case; paLabelNames=the label names, a non-empty list of text; pnWindow=how many samples each child keeps, 1 or more, otherwise 1024; pnMaxChildren=the most children, overflow included, 2 or more, otherwise 64 | Child, StzMetricFamily | a kind other than counter, gauge or timer raises error stzMetricFamily: kind must be :Counter, :Gauge or :Timer; an empty list of label names raises error ... a family WITHOUT labels is a plain stzMetric | StzMetricFamily builds it with window 1024 and at most 64 children, StzMetricFamilyXT sets both; the reserved overflow child uses one of the slots, so a family of at most 3 holds 2 label sets of its own
Name | Returns the metric name. | the name as text, as given | | PromName, Kind | |
Kind | Returns the kind of every child. | counter, gauge or timer, in lower case | | Name | |
IsFamily | TRUE if the object is a family rather than one metric. | always 1 | | Kind | | a stzMetric answers 0
LabelNames | Returns the declared label names. | a list of text, in declared order | | Child, MaxChildren | |
MaxChildren | Returns the bound on the number of children. | a number, overflow child included | | ChildCount, HasOverflowed | |
SetHelp | Sets the help text written in the exposition. | the family itself, so calls chain | pcText=the description | Help, PromText | |
Help | Returns the help text. | the text; an empty text until SetHelp is called | | SetHelp | |
Child | Returns the child metric for one combination of label values, creating it on first sight. | a stzMetric that records for those values; a full family returns the overflow child instead of dropping data | paValues=the label values, a list with one value for each label in declared order; a bar character inside a value is replaced by an underscore | LabelNames, ChildCount, HasOverflowed | a list of another length raises error stzMetricFamily ...: Child() takes N value(s), one per label | every call with the same values reaches the same engine stores, even from a copy of the family; once the family is full, new label sets all land in the child whose labels are all _overflow
ChildCount | Returns how many children the family holds. | a number; a new family already holds 1, the reserved overflow child | | Keys, MaxChildren | | the count is the engine's, so every copy of the family agrees
Keys | Returns the keys of the children, in the order they were created. | a list of text, each the label values joined with a bar; the first is always the overflow key | | ChildCount, Child | | for labels route and method the key of GET on /menu is the two values joined by a bar
HasOverflowed | TRUE if the overflow child exists. | TRUE or FALSE, as 1 or 0; 1 from the moment the family is built | | Keys, MaxChildren | the overflow child is created when the family is built, so this answers 1 for a new family that has never overflowed, whatever its children: on a family of 3 holding two children of its own it answered 1 before any label set was refused; whether overflow data exists has to be read from the overflow child's own count | the intended meaning, that some label set was routed to overflow, is not what it tests
Value | Refuses with an error telling you to pick a child, since a family has no single value. | nothing; it always raises error stzMetricFamily ...: a family has no single Value() -- pick a Child([...]) and ask it | | Child, Mean | | by design: a family never impersonates one metric
Mean | Refuses with an error telling you to pick a child, since a family has no single mean. | nothing; it always raises error ... a family has no single Mean() | | Child, Value | | by design
Percentile | Refuses with an error telling you to pick a child, since a family has no single percentile. | nothing; it always raises error ... a family has no single Percentile() | nP=the percentile that was asked for, ignored | Child, Value | | by design; ask a child, whose Percentile reads its own samples
PromName | Returns the metric name in a form Prometheus accepts. | the name as text with dots and dashes replaced by underscores, such as http_checkout_ms | | PromText, Name | |
PromText | Returns the family in the Prometheus text format: one header, then every child's sample lines with its labels. | a multi-line text; a counter is named with _total, a gauge as it is, and a timer is a summary with quantile 0.5, 0.95 and 0.99 lines, a sum and a count for each child | | OtelMetricJson, SetHelp | | the overflow child is listed like any other, so a growing overflow bucket shows in the exposition; a help line is written only when SetHelp was called
OtelMetricJson | Returns the family as one OpenTelemetry metric with one data point for each child, the labels as attributes. | a JSON text | | PromText, Explain | | a counter is a sum, a gauge a gauge and a timer a summary
Explain | Returns the family as lines of text: a header with the counts, then each child with its value and its sample count. | a list of text lines | | Show, Keys | | the header reads Metric family name (:kind) over [labels] -- N child(ren), max M
Show | Prints the explanation to the console, one line per line. | nothing | | Explain | | it prints with the ? statement
Destroy | Frees the engine registry and every child. | the family itself, so calls chain | | ChildCount, init | | after it ChildCount answers 0 and the family must not be used again
