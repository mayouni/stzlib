init | Builds a concatenation helper over a text or over a stzString object. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, to extend, repeat or join | Concat, Repeat | Given a stzString object, the first in-place edit (Concat, Prepend, Append, ConcatMany, RepeatNTimes, JoinWith) leaves that stzString EMPTY while the helper holds the result; the passive forms (Concatenated ...) do not. Pass the text, os.Content(), to be safe | any other kind of value raises "Can't create stzStringConcat! Parameter must be a string or stzString object."

IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
Concat | Adds a text at the end of the text held, in place. | nothing; use ConcatQ to chain | pcStr=the text to add at the end | Concatenated, Append, Prepend | | Append is the same method
Concatenated | Returns the text with another text added at its end, leaving the helper unchanged. | a text | pcStr=the text to add at the end | Concat, Prepended | | a number is turned into its text: "x" with 5 gives "x5"
ConcatenatedWithMany | Returns the text with several texts added at its end, in order, leaving the helper unchanged. | a text | pacStrings=the list of texts to add | Concatenated | | "abc" with 1 2 3 gives "abc123"
