init | Creates an empty application model, with a name, that will hold datasets, part roles and device models. | nothing; the object is built | pcName=the model's name | AddDataset, SetPartRole
AddDataset | Adds a named dataset of rows, or replaces the one of that name; names are stored in lower case. | nothing; use AddDatasetQ to chain | pcName=the dataset's name, matched without regard to case; paRows=the rows, a list of lists, such as [ dish, qty ] for orders or [ name, description, price ] for a menu | SetPartRole, Dataset | replacing a dataset keeps its place in the order of declaration
SetPartRole | Gives a part of the solution an app role and the dataset it works over, replacing any earlier role of that part. | nothing; use SetPartRoleQ to chain | pcPart=the part's name, stored in lower case; pcRole=the role, such as menu, dashboard, api or device; pcDataset=the name of the dataset the part works over | RoleOf, DatasetOf | the dataset name is not checked: a part pointing at a missing dataset reads an empty list
SetDatasetColumns | Declares the column names of a dataset, which the live backend needs to build its table. | nothing; use SetDatasetColumnsQ to chain | pcName=the dataset's name; paCols=the column names, a list of texts | ColumnsOf | optional: without it ColumnsOf derives c1 to cN | declared for a dataset that does not exist yet, the names are still kept
Name | Returns the name of the model. | a text | | init
DatasetNames | Returns the dataset names in the order they were declared, lower-cased. | a list of texts | | Dataset, PartNames
PartNames | Returns the parts that have a role, in the order they were declared, lower-cased. | a list of texts | | RoleOf, DatasetNames
ColumnsOf | Returns the declared column names of a dataset, or c1 to cN derived from its widest row. | a list of texts | pcName=the dataset's name, matched without regard to case | SetDatasetColumns, Dataset
Dataset | Returns the rows of a dataset; an empty list when there is none of that name. | a list of lists | pcName=the dataset's name, matched without regard to case | DatasetOf, AddDataset
HasRoleFor | TRUE if the part has been given a role. | TRUE or FALSE | pcPart=the part's name, matched without regard to case | RoleOf, SetPartRole
RoleOf | Returns the role of a part, such as menu or dashboard; an empty text when it has none. | a text | pcPart=the part's name, matched without regard to case | HasRoleFor, DatasetNameOf
DatasetNameOf | Returns the name of the dataset a part works over; an empty text when the part has no role. | a text | pcPart=the part's name, matched without regard to case | DatasetOf, RoleOf
DatasetOf | Returns the rows of the dataset a part works over; an empty list when the part has no role. | a list of lists | pcPart=the part's name, matched without regard to case | DatasetNameOf, Dataset
DashboardOf | Computes the dashboard of a part from its orders joined with the menu prices: revenue per row, the total, the top dish and its revenue. | a list [ rows, total, topDish, topRevenue ], each row [ dish, qty, revenue ] | pcPart=the name of a part whose dataset holds [ dish, qty ] rows | ApiEndpointsFor, Dataset | needs a dataset named menu with prices; with none, or for an unknown part, it answers [ [ ], 0, empty, 0 ]; the engine does the sums, a row per order and not per dish | the top dish is the single largest order row
ApiEndpointsFor | Returns the endpoints a backend part serves over the data: GET for each dataset, plus GET /stats when orders and menu exist. | a list of [ request, count, stats ] entries; the stats entry has count -1 and holds [ total, topDish, topRevenue ] | pcPart=the name of the api part; it does not change the list | DashboardOf | the answer is the same for every part name: the part is not looked up
AddDevice | Adds a firmware part with its pins, or replaces the pins of a part already there. | nothing; use AddDeviceQ to chain | pcPart=the part's name, stored in lower case; paPins=the pins, a list of [ pinNumber, label, role, value ] with role sensor or actuator | SetRule, DeviceOf | replacing the pins keeps the rule
SetRule | Sets the automation rule of a firmware part: the actuator goes on when the sensor reads under the threshold. | nothing; use SetRuleQ to chain | pcPart=the part's name; pcSensor=the label of the sensor pin; pnThreshold=the reading under which the actuator goes on; pcActuator=the label of the actuator pin | AddDevice, DeviceOf | for a part with no device it creates one with no pins
HasDevice | TRUE if the part has a device model. | TRUE or FALSE | pcPart=the part's name, matched without regard to case | AddDevice, DeviceOf
DeviceOf | Returns [ pins, rule ] for a device part, with the rule as [ sensor, threshold, actuator ]; [ [ ], [ ] ] when it has none. | a list of two lists | pcPart=the part's name, matched without regard to case | AddDevice, SetRule
