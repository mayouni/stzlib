Id | Returns the identifier of the plan. | a text; empty until WithId is called | | WithId
ProposedBy | Sets the name of whoever proposes the plan, an agent or a person. | the plan itself, so calls chain | pcName=the proposer's name, as text | Proposer, Visa | | a policy built with ProposerCannotVisa refuses a plan whose proposer is among its visas
Proposer | Returns the name of whoever proposed the plan. | a text; empty until ProposedBy is called | | ProposedBy
Paying | Adds one payment to the plan, kept with the order behind it so that the commit can release exactly that order. | the plan itself, so calls chain | poOrder=the stzPaymentOrder to pay, whose id and amount are read | PayingBulk, TotalAmount, Items | a value that is not an object raises error R13 at once | the item is recorded as kind pay, keyed by the order's transaction id
PayingBulk | Adds a whole bulk of payments to the plan as one item whose amount is the sum of the batch. | the plan itself, so calls chain | poBatch=the stzPaymentBatch to pay, whose instruction id and total are read | Paying, TotalAmount | a value that is not an object raises error R13 at once | the item is recorded as kind bulk, keyed by the batch's instruction id
Returning | Adds the return of a payment that was received, by its end-to-end id and the amount the hub holds for it. | the plan itself, so calls chain | pcEnd2EndId=the end-to-end id of the payment received; pnAmount=the amount the hub holds for it, in francs | AcceptingRequest, Paying | | the port refuses the movement at the commit if this amount differs from the hub's (payout-amount-differs); the plan still commits and the refusal is that item's result
AcceptingRequest | Adds the acceptance of a request to pay somebody sent us, which is money out, by its end-to-end id and amount. | the plan itself, so calls chain | pcEnd2EndId=the end-to-end id of the request received; pnAmount=the amount of the request, in francs | Returning, AcceptingCancellation | | at the commit the desk answers the request with acceptance through the port
AcceptingCancellation | Adds the acceptance of a cancellation request, which returns funds, by its end-to-end id and amount. | the plan itself, so calls chain | pcEnd2EndId=the end-to-end id of the payment to cancel; pnAmount=the amount to return, in francs | Returning, AcceptingRequest | | refusing a cancellation is not money out and needs no plan
Items | Returns what the plan pays, one record per item, in the order they were added. | a list of [ kind, key, amount ] where kind is pay, bulk, return, answer-request or answer-cancellation | | Objects, NumberOfItems, Document
Objects | Returns the order or batch behind each item, in the same order as Items. | a list with the stzPaymentOrder or stzPaymentBatch for a pay or bulk item, and an empty text for the other kinds | | Items
NumberOfItems | Returns how many items the plan pays. | a number | | Items, TotalAmount
TotalAmount | Returns the weight of the plan: the sum of every item it pays. | a number, in francs | | Items, NumberOfItems | | a policy judges this sum, so a payroll cannot be cut into small lines to slip under a threshold
Visa | Records the role and the name of a person who approves the plan; the same person signing twice counts once. | the plan itself, so calls chain | pcRole=the role of the signer, such as comptable or DG; pcName=the signer's name | Visas, NumberOfDistinctVisas | | visas added after a rehearsal do not reach the desk until the plan is rehearsed again
Visas | Returns every visa recorded, in the order given. | a list of [ role, name ] | | Visa, NumberOfVisas
NumberOfVisas | Returns how many visas were recorded, signatures and not people. | a number | | NumberOfDistinctVisas, Visas
NumberOfDistinctVisas | Returns how many different people gave a visa; the same name in another case is one person and an empty name counts for none. | a number | | NumberOfVisas, Visa
