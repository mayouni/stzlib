init | Opens an exercise folder and reads what is needed to judge a program against it: the promises, the facts and the optional harness. | nothing; the object is built | pcFolder=the exercise folder, with or without a trailing slash; its last segment is the exercise's id | Id, Promises, HasHarness | raises an error naming the exercise when the folder has no promise.ring, and another when promise.ring holds no #--> line; exercise.zknw and check.ring are optional | a check.ring turns the exercise into a harness exercise, where the learner hands in a file that is not a program
Id | Returns the exercise's id, the last segment of its folder path. | a text such as ex-01-01 | | Folder
Folder | Returns the exercise's folder path, without a trailing slash. | a text | | Id
Promises | Returns the values the learner's program must print, the text after each #--> line of promise.ring. | a list of text, in the order they must appear | | ForbiddenWords, Check | these are the expected values, the teacher's side: never show them to the learner, whose Why() never repeats them
NeededSteps | Returns the steps of the mental model the exercise needs, from its needs-step facts. | a list of text such as finds and applies; [ ] when exercise.zknw names none | | StepWords, GapText
Task | Returns the task text a learner reads, in one language, with carriage returns removed so that a CRLF checkout reads like an LF one. | a text | pcLang=the language code of the task.<lang>.md file | HasTaskIn | raises an error naming the exercise and the language when there is no task file in that language; the fr, ar and ha tasks are drafts, 0 of 35 units reviewed by a person
HasTaskIn | TRUE if the exercise has a task file in one language. | TRUE or FALSE | pcLang=the language code of the task.<lang>.md file | Task
Check | Runs a learner's program in a fresh Ring process with the library loaded and returns the verdict on it as a stzExerciseCheck. | a stzExerciseCheck: Passed() says whether every promise was kept, Why() says in the learner's terms what to look at; the call itself does not raise when the program fails | pcCode=the learner's program, as text; for a harness exercise the content of the submitted file, not its path | CheckFile, ProveItself | one process per call, so it takes seconds: the child loads the whole library; temporary _edu_run_ files are written in the current folder and removed; CheckMany does the same for a list of programs, at most 4 side by side; a line number in an error counts two library lines the learner never wrote | the program is judged by running it, never by reading it or comparing strings; the cells and checks run on the desktop only
HasHarness | TRUE if the exercise has a check.ring, so that it judges a submitted file with the library's own court instead of running it as a program. | TRUE or FALSE | | SubmissionExtension, Check
SubmissionExtension | Returns the extension of what a learner hands in for this exercise. | .ring for a program; for a harness exercise the extension its submits fact names, such as .pia | | HasHarness, WrongAnswers
CheckFile | Reads a file and returns the verdict on its content, as Check does. | a stzExerciseCheck | pcFile=the path of the file to read; its text is the learner's program | Check | raises a file error when pcFile cannot be opened
WrongAnswers | Returns the paths of the known wrong answers, the files of the wrong subfolder. | a list of text, sorted by name and limited to files with the submission extension; [ ] when there is no wrong folder | | RightAnswers, ProveItself
RightAnswers | Returns the paths of the known right answers, the files of the right subfolder. | a list of text, sorted by name and limited to files with the submission extension; [ ] when there is no right folder | | WrongAnswers, ProveItself
ProveItself | Runs every known wrong and right answer through the checker and counts the ones it judged correctly. | a hash list with wrong, wrongrefused, right, rightaccepted, failures and checks; failures names each wrong answer that passed and each right answer that failed, and checks holds a file and its verdict for every answer | | IsProven, WrongAnswers, RightAnswers | one fresh process per answer, at most 4 side by side; an exercise that accepts a wrong answer or refuses a right one is a red guard
IsProven | TRUE if the exercise has at least one wrong and one right answer and the checker refuses every wrong one and accepts every right one. | TRUE or FALSE; FALSE for an exercise with no wrong answer or no right answer | | ProveItself
ForbiddenWords | Returns the words a tutor must not say before the learner passes: the names the right answers call and the promised values. | a list of text without repeats; the promised values are normalized, with their spaces removed | | Promises, Check | names are the words of four characters or more written right before "(" in the right answers
