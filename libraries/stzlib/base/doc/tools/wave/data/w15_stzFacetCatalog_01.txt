init | Builds a catalog seeded with the 18 standard Softanza facets, such as text, graph, nlp and vision. | nothing; the object is built | | Names, Define
Define | Adds an engine-native facet, or replaces the one of that name, with its capabilities and the modules that realize it. | the catalog itself, so calls chain | pcName=the facet's name, stored in lower case; paCaps=the capabilities the facet offers, as a list of names; paModules=the base modules that realize it, as a list of texts, empty for a purely logical facet | DefinePolyglot, Drop, MappingKindOf | the catalog belongs to its own instance: a facet defined here is unknown to every other catalog
DefinePolyglot | Adds a facet served by an external tool run off-process, or replaces the one of that name. | the catalog itself, so calls chain | pcName=the facet's name, stored in lower case; paCaps=the capabilities the facet offers, as a list of names; pcTool=the external tool, such as python | Define, IsPolyglot, ToolOf | a polyglot facet has no module
Drop | Removes a facet by name; an unknown name changes nothing. | the catalog itself, so calls chain | pcName=the facet's name, matched without regard to case | Define, Has
Has | TRUE if the catalog knows a facet of that name. | TRUE or FALSE | pcName=the facet's name, matched without regard to case | Names, Define
Names | Returns the names of all facets, in the order they were defined. | a list of texts | | NumberOf, Has
NumberOf | Returns how many facets the catalog holds. | a number | | Names
CapabilitiesOf | Returns the capabilities a facet offers; an empty list for an unknown facet. | a list of texts | pcName=the facet's name, matched without regard to case | ModulesOf, Define
ModulesOf | Returns the base modules that realize a facet; an empty list for an unknown, external or purely logical facet. | a list of texts | pcName=the facet's name, matched without regard to case | MappingKindOf, CapabilitiesOf
ToolOf | Returns the external tool that serves a facet; an empty text for an engine-native or unknown facet. | a text | pcName=the facet's name, matched without regard to case | IsPolyglot, DefinePolyglot
IsPolyglot | TRUE if the facet is served by an external tool off-process. | TRUE or FALSE | pcName=the facet's name, matched without regard to case | ToolOf, DefinePolyglot
MappingKindOf | Returns how a facet maps onto code: :external, :logical, :grounded for one module or :composed for two or more. | a text among external, logical, grounded and composed | pcName=the facet's name, matched without regard to case | ModulesOf, IsPolyglot | an unknown name answers logical, as a facet with no module does; test Has first when the difference matters | in the standard catalog only vision is external, and text is composed from three modules
