# w15 stzUiBindings
init | Reads every {name} placeholder out of the text declarations of a document, ready to be given values. | nothing; the placeholders are harvested when the object is built | poDoc=the stzUiDocument whose CONTENT strings hold placeholders; poPanel=the stzPanel made from it | Names, Set | an argument that is not a document and a panel raises error stzUiBindings: give an stzUiDocument and its stzPanel | a placeholder is a name of lower-case letters, digits and underscores in braces; a lone brace, an empty pair of braces and braces round anything else, such as {Bad Name}, stay as written
Names | Returns every placeholder name the document mentions, in the order first met. | a list of text; [ ] when the document has none | | Unset, IsBound, BoundElements | | a screen can say what it needs before anything is set; a name used in two texts is listed once
BoundElements | Returns the text elements that carry at least one placeholder. | a list of element names in declaration order | | Names, RenderOf | |
IsBound | TRUE if the document mentions a placeholder with a name. | TRUE or FALSE, as 1 or 0 | pcName=the placeholder name, without braces | Names, ValueOf | | a name that is not a plain lower-case name, such as Bad Name, is never bound
Unset | Returns the placeholders that have not been given a value yet. | a list of text in the order of Names | | Names, Set | | an unset placeholder renders as empty text, a blank field rather than a screen that refuses to appear
ValueOf | Returns the value last given to a placeholder. | the value as text; an empty text for a name never set | pcName=the placeholder name, without braces | Set, Unset | |
Set | Gives a placeholder a value and re-renders every element whose text mentions it. | TRUE when every affected element was updated; TRUE also for a name no element mentions, which changes nothing. SetQ returns the bindings for chaining | pcName=the placeholder name, without braces; pValue=the value, turned into text | SetMany, Apply, RenderOf | | the value is kept as text, so 7 reads back as 7; SetMany takes a list [ :name = value, ... ] and updates each affected element once, so a line built from three values is set once and not three times
Apply | Pushes every bound element to the panel again, whatever changed. | TRUE when every element was updated | | Set, TimesApplied | | what to call after loading a screen, to fill it in one go; ApplyQ returns the bindings for chaining
TimesApplied | Returns how many element updates have been pushed to the panel. | a number, starting at 0; each text element updated and each style change adds one | | Set, Apply | | an honest counter: a binding that matched nothing leaves it unchanged, as Set of a name no element mentions does
RenderOf | Returns what a bound element's text would be right now, without touching the panel. | the text with the current values put in; an empty text for an element that is not bound | pcElement=the name of the text element | Set, BoundElements | | a placeholder with no value reads as empty text, and braces that are not placeholders are left as written
SetStyle | Sets one style property of an element in the panel, directly. | TRUE when the panel took it, FALSE for an element it does not know. SetStyleQ returns the bindings for chaining | pcElement=the name of the element; pcProperty=the style property, such as color; pcValue=the value, such as #ff0000 | ClearStyle, Set | | a style change is surgical: unlike a text change it does not re-shape the whole document; each success adds one to TimesApplied
ClearStyle | Hands a style property of an element back to the stylesheet. | TRUE when the panel took it, FALSE for an element it does not know | pcElement=the name of the element; pcProperty=the style property to give back | SetStyle | | it sets the property to an empty text
