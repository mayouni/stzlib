# w15 stzSla
init | Builds an empty service-level agreement under a name, to which expectations are added. | nothing; the object is built | pcName=the name of the SLA, written into every finding | Expect, CheckAgainst | | StzSla builds the same object
Name | Returns the name the SLA was built with. | the name as text | | Explain |
Expect | Opens an expectation on one of the well-known measured subjects, to be closed with a bound. | the SLA itself, so the closer can follow | pcSubject=ResponseTimeP50, ResponseTimeP95, ResponseTimeP99, ResponseTimeMean, Throughput, ErrorRate, Availability, CpuUtilization, MemoryRss, MemoryGrowthPerHour or SystemMemoryFree, in any letter case | Under, AtLeast, ExpectP95 | a subject that is not in the list, such as Happiness, raises error stzSla: unknown subject ... with the list; opening a second expectation before closing the first raises error stzSla.Expect: the expectation on ... is still open -- close it with Under()/AtMost()/AtLeast()/Over() first | the subjects are resolved against the monitor's metrics, such as http.request.ms for the response times and process.cpu.utilization for the CPU
ExpectP95 | Opens an expectation on the 95th percentile of a metric of your own, to be closed with a bound. | the SLA itself, so the closer can follow | pcMetric=the name of a metric on the monitor, such as shop.checkout.ms | ExpectMean, Under | an expectation still open raises error ... is still open | a metric the monitor does not carry gives an error finding saying NOT MEASURED, never a silent pass
ExpectMean | Opens an expectation on the mean of a metric of your own, to be closed with a bound. | the SLA itself, so the closer can follow | pcMetric=the name of a metric on the monitor | ExpectP95, Under | an expectation still open raises error ... is still open | an unmeasured metric is an error finding
ExpectValue | Opens an expectation on the current value of a metric of your own, to be closed with a bound. | the SLA itself, so the closer can follow | pcMetric=the name of a counter or gauge on the monitor, such as queue.depth | ExpectRate, Under | an expectation still open raises error ... is still open | an unmeasured metric is an error finding
ExpectRate | Opens an expectation on the measured rate per second of a metric of your own, to be closed with a bound. | the SLA itself, so the closer can follow | pcMetric=the name of a counter on the monitor, such as shop.orders | ExpectValue, AtLeast | an expectation still open raises error ... is still open | a rate is live: judge it by range, never by an exact number
ExpectStable | Declares that a metric must have no outlier: its newest sample must lie within 3 standard deviations of the window before it. | the SLA itself; it closes itself and takes no bound | pcMetric=the name of a metric on the monitor | ExpectValue, CheckAgainst | an expectation still open raises error ... is still open | with fewer than 8 samples it passes and says stability is not judgeable yet; a jump off a perfectly flat window is judged infinitely surprising; the rule is named stable- followed by the metric
Under | Closes the open expectation: it passes when the measured value is at most the bound. | the SLA itself, so calls chain | pnBound=the largest value that passes, in the unit of the subject: milliseconds for response times, a fraction for CPU, bytes for memory | AtMost, AtLeast, AsWarning | closing when nothing is open raises error stzSla: no open expectation to close -- say Expect(...) first | the rule is named from the subject, the closer and the bound, such as response-time-p95-under-200; AtMost is the same call
AtMost | Closes the open expectation: it passes when the measured value is at most the bound. | the SLA itself, so calls chain | pnBound=the largest value that passes | Under, AtLeast | closing when nothing is open raises error stzSla: no open expectation to close | the same call as Under
AtLeast | Closes the open expectation: it passes when the measured value is at least the bound. | the SLA itself, so calls chain | pnBound=the smallest value that passes, such as 99.9 for an availability in percent | Over, Under, AsWarning | closing when nothing is open raises error stzSla: no open expectation to close | the rule name carries atleast; Over is the same call
Over | Closes the open expectation: it passes when the measured value is at least the bound. | the SLA itself, so calls chain | pnBound=the smallest value that passes | AtLeast, Under | closing when nothing is open raises error stzSla: no open expectation to close | the same call as AtLeast, so the bound itself passes
AsWarning | Softens the last closed expectation to an advisory one, which does not fail the gate. | the SLA itself, so calls chain | | Under, CheckAgainst | calling it before any expectation is closed raises error stzSla.AsWarning: no expectation closed yet | its findings carry the severity warning, which stzRuleReport.IsSound ignores; Passed and BreachCount still count them
NumberOfExpectations | Returns how many expectations have been closed. | a number; an expectation still open is not counted | | Expect, CheckAgainst |
CheckAgainst | Judges every expectation against the monitor's measured numbers and returns the breaches. | a list of findings in the unified shape, each a hash list with rule, subject perf, where, severity and message; [ ] when everything is met | poMonitor=the stzPerfMonitor whose metrics are read | Verdicts, Findings, Explain | an expectation over a metric the monitor does not carry is an error finding whose message says NOT MEASURED and what to watch, never a pass | the finding is ready for stzRuleReport.Ingest; where reads the SLA name, a slash, and the metric; a call replaces the verdicts of the call before
Findings | Returns the breaches of the last check again, in the unified shape, without measuring anything. | a list of findings; [ ] before any check or when all were met | | CheckAgainst, Verdicts | |
Verdicts | Returns the verdict of every expectation from the last check, the passes too. | a list of hash lists with the keys rule, ok, actual, bound and message | | Findings, Passed | | an unmeasured expectation has ok 0 and actual 0
Passed | TRUE if the last check found no breach, of any severity. | TRUE or FALSE, as 1 or 0; 1 before any check | | BreachCount, Findings | | an advisory breach makes it 0 though the gate stays sound: with only a warning it answered 0 while stzRuleReport.IsSound answered 1
BreachCount | Returns how many expectations breached in the last check. | a number, the advisory ones and the not-measured ones included | | Passed, Findings | |
Explain | Returns the last check as lines of text: a verdict line, then each expectation marked MET or BREACH with its message. | a list of text lines | | Show, Verdicts | | the first line gives the number of expectations and MET or BREACHED with the count
Show | Prints the explanation to the console, one line per line. | nothing | | Explain | | it prints with the ? statement
