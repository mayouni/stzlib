init | Builds a skill with a name and no precondition, action or check; its kind is pi. | nothing; the object is built | pcName=the skill's name, quoted in the why of Apply | SetWhen, SetDoes, SetVerifiedBy
Name_ | Returns the name the skill was built with. | a text | | init, Kind
SetWhen | Sets the precondition: a function of the memory that must answer true before the skill may run. | the skill itself, so calls chain | fPrecondition=a function taking the memory and returning 1 or 0 | PreconditionHolds, Apply
SetDoes | Sets the action the skill performs on the memory when it runs. | the skill itself, so calls chain | fAction=a function taking the memory; its result is ignored | SetVerifiedBy, Apply
SetVerifiedBy | Sets the check run after the action to confirm that it had the intended effect. | the skill itself, so calls chain | fCheck=a function taking the memory and returning 1 when the effect is confirmed | SetDoes, Apply | | without a check the result counts as verified
AsLLMSkill | Marks the skill as prompted rather than algorithmic; the interface and the gates are the same. | the skill itself, so calls chain | | Kind | | it changes the posture reported by Kind, not the way Apply runs
Kind | Returns the skill's posture: pi for an algorithmic skill, llm after AsLLMSkill. | the text pi or llm | | AsLLMSkill, Name_
PreconditionHolds | Runs the precondition on a memory and returns its answer; a skill with no precondition always holds. | what the precondition function returned, 1 when none is set | poMemory=the agent's memory (a stzAgentMemory) | SetWhen, Apply | | Apply tests the answer against 0, so any other value, such as 2, counts as holding
Apply | Runs the action only if the precondition holds, then checks the result, and reports what happened. | a hash list [ :ran, :verified, :why ]; why is a sentence naming the skill | poMemory=the agent's memory, which the action may change | SetDoes, SetVerifiedBy, PreconditionHolds | a skill with no action reports ran 0 even when its precondition holds; a check must answer exactly 1 to verify | the action runs before the check, and a failed check does not undo it
