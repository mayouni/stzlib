init | Builds a site with the given name, of kind localrepo, with no endpoint, storage, auth, capacity or provider. | nothing; the object is built | pcName=the site's name | SetKind, SetEndpoint
SetKind | Sets the kind of the site, which decides how it is reached: localrepo, server, gitrepo, registry, device or objectstore. | nothing; use SetKindQ to chain | pcKind=the kind, trimmed and lowered | KindName, Protocol, Store | | an unknown kind is accepted and then behaves like a site with no backend
SetEndpoint | Sets the address of the site, such as a user@host:path or a repository path or URL. | nothing; use SetEndpointQ to chain | pcUrl=the address | EndpointOf, SetProtocol |
SetProtocol | Sets the access protocol, instead of the default of the kind. | nothing; use SetProtocolQ to chain | pcProtocol=the protocol such as ssh, file, git, https or serial, trimmed and lowered | Protocol, SetKind |
SetAuthRef | Sets how the site authenticates: a plain reference text, or a stzSecret that the site then keeps behind a redacted descriptor. | nothing; use SetAuthRefQ to chain | pRef=a reference text such as env/DEPLOY_KEY, or a stzSecret | SetAuthFromStore, ResolveAuth, AuthReference | anything else raises an error | with a secret, the key never appears in Config, ConfigText or ConfigJson, only its descriptor
SetAuthFromStore | Sets the authentication to a secret held by name in a central secret store, so every reveal is audited by that store. | nothing; use SetAuthFromStoreQ to chain | poStore=the stzSecretStore that holds the secret; pcName=the secret's name in that store | ResolveAuthVia, SetAuthRef, IsStoreBacked | it raises an error when poStore is not an object and when the store has no secret of that name | the site keeps the name and the redacted descriptor, never the store or the value
SetStoreAt | Sets the staging location where artifacts are stored: the folder of a local site, or the staging folder before a copy to a server. | nothing; use SetStoreAtQ to chain | pcLocation=the folder path | StorageLocation, Store |
SetLaunchWith | Sets the command that starts the deployed solution on the site. | nothing; use SetLaunchWithQ to chain | pcCmd=the command line | LaunchCommandLine, Launch | | on a server the command is wrapped in ssh to the host
SetStatusWith | Sets the command that reports the state of the deployed solution, kept in the config. | nothing; use SetStatusWithQ to chain | pcCmd=the command line | Config, Status | | Status does not run it: it is only recorded and shown
SetCapacity | Declares what the host provides, as a resource spec, so that feasibility can be checked against what parts need. | nothing; use SetCapacityQ to chain | poSpec=a stzResourceSpec of memory in MB, vCPU and storage in GB | CapacityOf, HasCapacity, SetProvider |
SetProvider | Declares which cloud or hypervisor, aws or proxmox, can create this host, which makes the site scriptable. | nothing; use SetProviderQ to chain | pcName=the provider name, trimmed and lowered | ProviderName, IsScriptable, ProvisionCommandFor |
Name | Returns the name the site was given. | a text | | init
KindName | Returns the kind of the site in lower case. | a text, localrepo by default | | SetKind
EndpointOf | Returns the address of the site. | a text; empty when none was set | | SetEndpoint
Protocol | Returns the access protocol: the one set, or the default of the kind. | a text: file for localrepo and unknown kinds, ssh for server, git for gitrepo, https for registry and objectstore, serial for device | | SetProtocol, SetKind
AuthReference | Returns the authentication reference shown for the site. | a text: the plain reference, or the redacted descriptor of a secret; empty when none | | SetAuthRef, ResolveAuth
AuthSecret | Returns the stzSecret the site holds directly. | a stzSecret; an empty text when the site has a plain reference, a store-backed secret or nothing | | HasAuthSecret, SetAuthRef
HasAuthSecret | TRUE if the site holds a stzSecret directly. | 1 or 0 | | HasSecretAuth, AuthSecret | | a store-backed secret answers 0 here
IsStoreBacked | TRUE if the authentication is a secret held by name in a central store. | 1 or 0 | | SetAuthFromStore, AuthStoreName
AuthStoreName | Returns the name of the store-held secret used for authentication. | a text; empty when the site is not store-backed | | SetAuthFromStore, IsStoreBacked
HasSecretAuth | TRUE if the authentication is a secret, held directly or by name in a store, rather than a plain reference. | 1 or 0 | | HasAuthSecret, IsStoreBacked
ResolveAuth | Returns the live authentication value: the secret revealed to an actor that may see it, or the plain reference as it is. | a text | poActor=the actor asking, which must be effectful and not sandboxed to reveal a secret | ResolveAuthVia, SetAuthRef | it raises an error for a store-backed site, telling you to use ResolveAuthVia, and a language-model actor is refused when the site holds a secret | the reveal of a directly held secret is not recorded in a store's access log
ResolveAuthVia | Returns the live authentication value through the shared secret store, so the store's gate applies and the access is logged. | a text | poStore=the stzSecretStore that holds the secret; poActor=the actor asking | ResolveAuth, SetAuthFromStore | it raises an error when the site is store-backed and poStore is not an object | for a site that is not store-backed the store is ignored and the answer is that of ResolveAuth
StorageLocation | Returns the staging location. | a text; empty when none was set | | SetStoreAt
IsLocal | TRUE if the site is a local folder, kind localrepo or local. | 1 or 0 | | KindName, Store
CapacityOf | Returns the capacity the host was declared to have. | a stzResourceSpec; an empty text when none was declared | | SetCapacity, HasCapacity
HasCapacity | TRUE if a capacity was declared. | 1 or 0 | | SetCapacity, CapacityOf
ProviderName | Returns the provisioning provider in lower case. | a text; empty when none | | SetProvider
IsScriptable | TRUE if a provider is named, so that the host can be created by a command. | 1 or 0 | | SetProvider, ProvisionCommandFor
Config | Returns the access configuration as a nested list of the name, kind, connection, storage, control, capacity and provider. | a list of pairs; the connection and control entries are lists of pairs, and capacity is a text or (undeclared) | | ConfigText, ConfigJson | | a secret appears only as its descriptor
ConfigText | Returns the configuration as readable lines, naming the site and its kind first. | a text with one line per set item: connection, storage, and launch, status, capacity and provider when set | | Config, Show
ConfigJson | Returns the configuration as JSON text, with the capacity as numbers or null. | a text | | SaveConfigTo, Config | quotes and backslashes in a value are not escaped, so a launch command or path containing them gives invalid JSON | a secret appears only as its descriptor
SaveConfigTo | Writes the JSON configuration to a file, overwriting it. | the site itself, so calls chain | pcPath=the file path to write | ConfigJson | the file is overwritten if it exists |
Reachable | TRUE if the site can be reached: a local site needs a storage location, a git site answers to git ls-remote, any other needs an endpoint. | 1 or 0 | | Status, Store | for a git site it starts a git process against the endpoint, and it was run only against a path that is not a repository |
Store | Sends artifacts to the site: writes them to the local folder, or commits and pushes them for git, or stages and copies them for a server. | 1 if stored, 0 if it failed or the kind has no store backend | paArtifacts=a list of pairs, each a relative file name and its content | Launch, Status, Commands | it writes files and runs git, scp or similar, so only the refusal for a site with no storage was run, and registry, device and objectstore sites return 0 although Commands lists a command for the first two | this was read from the code and not run against a target
Launch | Starts the deployed solution: marks a local site as launched, nothing more for git, and runs the launch command over ssh for a server. | 1 if launched, 0 if it could not be or the kind has no launch backend | | Store, Status, SetLaunchWith | it changes the target, so only the refusal for a site with nothing stored was run |
Status | Returns the state of the site as a word: absent, stored, launched or rolledback. | a text; absent for a site with no record and always for server, registry, device and objectstore | | Store, Launch, Rollback | | a local site reads it from its marker file, and a git site is launched when its main branch exists
Rollback | Withdraws the deployment from a local site by removing its manifest and marking it rolledback. | 1; it also returns 1 for other kinds, where it does nothing | | Store, Status | it writes into the storage folder, so it was not run on a local site, and reading the code shows that with no storage location the paths become /deploy.json and /.stzsite at the root of the drive |
Provision | Runs the provider command that creates or resizes the host to meet a requirement. | 1 if the command ran and exited with 0, 0 if there is no command or it failed | poReq=a stzResourceSpec of what the host must provide | ProvisionCommandFor, SetProvider | it runs a provider command line and creates real resources, so only the case with no command was run | the command to be run is shown first by ProvisionCommandFor
Commands | Returns the store and launch commands that would be run, without running them. | a list of pairs, each a step name (store or launch) and its command line; empty for a local site with no launch command | | TransferCommand, LaunchCommandLine
TransferCommand | Returns the command that sends artifacts to the site. | a text: git push for gitrepo, scp for server, docker push for registry, esptool for device; empty for other kinds | | Commands, Store | | registry and device commands are generated only: Store does not run them
LaunchCommandLine | Returns the command that starts the solution, wrapped in ssh for a server. | a text; empty when no launch command was set | | SetLaunchWith, Commands |
ProvisionCommandFor | Returns the provider command that would create a host of the required size, without running it. | a text; empty when the provider is not aws or proxmox, or poReq is not an object | poReq=a stzResourceSpec giving memory, vCPU and storage | Provision, SetProvider | | the aws command picks t3.micro up to 1024 MB, t3.small to 2048, t3.medium to 4096 and t3.large above
Show | Prints the configuration text to the console. | nothing | | ConfigText
