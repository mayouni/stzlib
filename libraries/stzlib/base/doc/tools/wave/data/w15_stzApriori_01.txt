init | Builds a basket analyser from a list of transactions, each a list of items, folded to lower case with repeats dropped. | nothing; the object is built | paTransactions=a list of lists of items; an item is trimmed and lower-cased, and an empty one is dropped | FrequentItemsets, Rules | an argument that is not a list builds an analyser with no transactions
NumberOfTransactions | Returns how many transactions were kept. | a number | | init
FrequentItemsets | Returns every set of one, two or three items that occurs in at least that many transactions, with its count. | a list of [ items, count ] pairs, the items a list in alphabetical order; larger sets are not searched | nMinCount=the smallest number of transactions an itemset must appear in | Rules | | itemsets come in the order they were first counted, not by size or count
Rules | Returns if-then rules from the frequent pairs and triples, keeping those whose confidence reaches the threshold. | a list of hash lists [ :if, :then, :support, :confidence ]; :if is a list of items, :then one item, :support the itemset's count, :confidence its count divided by the count of the :if items | nMinCount=the smallest number of transactions an itemset must appear in; nMinConf=the smallest confidence, from 0 to 1 | FrequentItemsets | | every item of a frequent set takes a turn as the consequent, so a pair gives two candidate rules
