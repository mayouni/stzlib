# w15 stzPerfSentinel
init | Builds a sentinel that judges an SLA against a monitor on a cadence and turns verdict changes into alerts. | nothing; the object is built with its own event bus and no breach | poSla=the stzSla to judge; poMonitor=the stzPerfMonitor whose metrics it reads | Check, Tick, OnBreach | | StzPerfSentinel builds the same object; the SLA is copied at birth, the monitor copy shares the engine-backed metrics, and the sentinel's own transition state lives in Ring, so one copy should drive Check and Tick
Name | Returns the sentinel's name. | the name as text, perf-sentinel until SetName changes it | | SetName, Name_ | |
Name_ | Returns the sentinel's name, the form an agent host asks for. | the name as text, the same as Name | | Name, Cycle | |
SetName | Sets the sentinel's name. | the sentinel itself, so calls chain | pcName=the new name, a non-empty text; anything else is ignored | Name | |
OnBreach | Sets the function called once when a rule newly breaches. | the sentinel itself, so calls chain | pfCallback=a function taking the finding, a hash list with rule, subject, where, severity and message | OnClear, Check | | it is edge-triggered: a rule that stays broken does not call it again
OnClear | Sets the function called once when a breached rule recovers. | the sentinel itself, so calls chain | pfCallback=a function taking the name of the rule that recovered | OnBreach, Check | |
SetChannels | Sets the names of the process-wide event channels the alerts are also published on. | the sentinel itself, so calls chain | pcBreach=the channel for breaches; pcClear=the channel for recoveries | BreachChannel, ClearChannel | | the defaults are perf.breach and perf.clear, so an agent supervised on a channel wakes when the SLA breaks
BreachChannel | Returns the channel breaches are published on. | the channel name as text, perf.breach by default | | SetChannels, ClearChannel | |
ClearChannel | Returns the channel recoveries are published on. | the channel name as text, perf.clear by default | | SetChannels, BreachChannel | |
Every | Sets the cadence of Tick. | the sentinel itself, so calls chain | pnMs=the interval in milliseconds, 1 or more; a smaller value or a non-number is ignored | Tick, Check | | the default is 1000
Check | Judges the SLA once and fires alerts for the changes since the last judgment only. | the number of new breaches in this pass | | Tick, OnBreach, ActiveBreaches | | a new breach logs, photographs the process in the black box, publishes on the breach channel and calls OnBreach; a recovery logs, publishes on the clear channel and calls OnClear; a breach that persists does nothing, which is the flap suppression; an unmeasured expectation counts as a breach
CheckCount | Returns how many judgments have been made. | a number | | Check, Tick |
Tick | Judges the SLA if the cadence says it is due, for any loop to call. | the number of new breaches; 0 when it was not due | | Check, Every | | the first call is always due, then the next one waits for Every milliseconds on the monotonic clock; Cycle is the same call, which makes the sentinel hostable by a stzAgentHost
ActiveBreaches | Returns the rules in breach as of the last judgment. | a list of rule names | | IsBreached, Check |
IsBreached | TRUE if any rule is in breach as of the last judgment. | TRUE or FALSE, as 1 or 0 | | ActiveBreaches | |
AlertLog | Returns the alerts so far, breaches and recoveries, oldest first. | a list of [ time in milliseconds, breach or clear, rule, message ]; at most the newest 256 | | LastAlert, BlackBox | | the time is on the monotonic clock; a recovery's message is recovered
LastAlert | Returns the newest alert. | a list [ time, breach or clear, rule, message ]; [ ] when there is none | | AlertLog |
Explain | Returns the state as lines of text: the name, the number of checks and whether expectations are met, then each breached rule. | a list of text lines | | Show, ActiveBreaches | raises error R41 Invalid numeric string whenever a rule is in breach, because the state text adds the number of breaches to a text; it answers well only while nothing is breached | with no breach the single line reads Sentinel name -- N check(s), all expectations met.
Show | Prints the explanation to the console, one line per line. | nothing | | Explain | raises the same error R41 as Explain while a rule is in breach | it prints with the ? statement
BlackBox | Returns the flight-recorder snapshots, one taken at each new breach. | a list of hash lists, the newest 16 | | LastBlackBox, AlertLog | | each holds at, rule, message, rssBytes, peakBytes, cpuMs, sysFreeBytes, the current value of every metric and the recent trace ids; the values are live, so assert ranges and signs
LastBlackBox | Returns the newest flight-recorder snapshot. | a hash list with the keys at, rule, message, rssBytes, peakBytes, cpuMs, sysFreeBytes, metrics and traces; [ ] when there is none | | BlackBox | | metrics is a list of [ name, kind, value ]; traces is [ ] when the monitor does not trace
