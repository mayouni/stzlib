init | Builds a what-if simulation over an org chart by copying its positions, people and departments into a second chart. | nothing; the simulation is built | poOrgChart=The stzOrgChart to simulate changes on | ApplyChanges, SimulatedChartQ | the copy is named after the original with _sim added and holds no graph nodes, so only the records are copied
ApplyChanges | Applies a list of changes to the copy, never to the original, then records the before and after spans and vacancy rates. | nothing; the results are stored | paChanges=A list of hash lists, each with :type, one of reassign (:person, :newPosition), remove_position (:position), add_position (:id, :title) or change_reporting (:subordinate, :supervisor) | Results, SimulatedChartQ | known defect: a change_reporting change raises "Cannot add edge: one or both nodes do not exist!", since the copy has no nodes; an unknown :type is skipped without a word
Results | Returns the before and after average span of control and vacancy rate, and the changes applied; [ ] before ApplyChanges. | a hash list [ :before, :after, :changes ], or [ ] | | ApplyChanges
SimulatedChartQ | Returns the what-if chart the changes were applied to; the original chart is not touched. | a stzOrgChart | | ApplyChanges, Results | the copy has records but no graph nodes
