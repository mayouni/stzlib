init | Builds a reporter over an org chart, taking a snapshot of it at that moment for every later report. | nothing; the reporter is built | poOrgChart=The stzOrgChart to report on | Generate, SummaryReport | a position added to the chart afterwards is not in the reports: build the reporter last
Generate | Returns the five standard reports in a list: summary, vacancy, succession, compliance and span of control. | a list of five hash lists | | SummaryReport, VacancyReport, SuccessionReport, ComplianceReport, SpanOfControlReport
SummaryReport | Returns the summary report: totals, vacancy rate, average span and the position ids by level. | a hash list [ :title, :date, :metrics ] | | Generate, VacancyReport | metrics holds totalPositions, filledPositions, vacancyRate, avgSpan and levels
VacancyReport | Returns the vacancy report: how many positions are vacant, the rate, and the title and department of each. | a hash list [ :title, :vacancyCount, :vacancyRate, :details ] | | Generate, SummaryReport | known defect: the level of each detail is always staff, since it is read from a key that is never written
SuccessionReport | Returns the succession report: each filled position without a successor, with its title and the incumbent's name. | a hash list [ :title, :date, :highRiskCount, :details ] | | Generate, ComplianceReport | every filled position is listed today, because no successor is ever found; each is marked with risk level high
ComplianceReport | Returns the compliance report: the BCEAO, span-of-control and segregation verdicts and the overall status. | a hash list [ :title, :date, :checks, :overallStatus, :failedChecks ] | | Generate, SpanOfControlReport | overallStatus is compliant or non-compliant
SpanOfControlReport | Returns the span report: each supervisor with its direct report count and a status of underutilized, optimal or excessive. | a hash list [ :title, :date, :details ] | | Generate, ComplianceReport | fewer than 3 reports is underutilized and more than 9 excessive; a position with no report is not listed
