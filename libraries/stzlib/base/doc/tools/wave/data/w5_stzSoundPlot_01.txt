init | Builds an empty dark plate of a width and a height in pixels, ready for one of the Draw methods, and looks for a system font. | nothing; the plate is built | pnWidth=The width of the plate, in pixels; pnHeight=The height of the plate, in pixels | Canvas, DrawSpectrogram | A non-number or a size outside 1 to 16384 raises the stzCanvas error, and with no font found the plate is drawn without any text | the plot area leaves 64 pixels at the left, 22 at the right, 74 at the top and 62 at the bottom
Canvas | Returns the stzCanvas the plate is drawn on, so extra shapes can be added to the picture. | the stzCanvas of the plot | | ToSVG, SaveAsPNG | | a shape added through it shows in the plot only after the canvas's Flush has posted it
SetTitle | Sets the title and the subtitle written at the top left of the next picture drawn; one called after a Draw method changes nothing. | nothing; the next picture changes | pcTitle=The title, drawn at 17 pixels in white; pcSubtitle=The subtitle under it, drawn at 12 pixels in grey | SetNote | | call it before the Draw method and SetTitleQ answers the plot for chaining
SetNote | Sets the sentence written under the plot to say what the picture means; one called after a Draw method changes nothing. | nothing; the next picture changes | pcNote=The sentence, wrapped to the plate width | ToNoteLines, SetTitle | Only the first two wrapped lines are drawn, the rest are dropped without a message | call it before the Draw method and SetNoteQ answers the plot for chaining
ToNoteLines | Returns the note cut into the lines it will be laid out in, ready to be checked without reading the picture. | a list of text, empty when there is no note | | SetNote | The plot draws only the first two lines of the list | the line length follows the plate width at about 5.6 pixels a character
SetDynamicRange | Sets how many decibels below the loudest cell of a spectrogram still get ink; a value of zero or less is ignored. | nothing; the next spectrogram changes | pnDb=The range in decibels | DrawSpectrogram | Only DrawSpectrogram reads it, since DrawSpectra always spans 72 dB | the default is 70, and a tighter range hides a broadband floor
SaveAsPNG | Draws the picture on the graphics device and writes it to a PNG file. | nothing; the file is written | pcPath=The file to write | SaveAsSVG, ToSVG | With no graphics device no file is written, and the answer is empty either way | use SaveAsSVG on a machine without a GPU
SaveAsSVG | Writes the picture to an SVG file, with no graphics device needed. | nothing; the file is written | pcPath=The file to write | SaveAsPNG, ToSVG | | text reaches the file as glyph outlines, not as characters
ToSVG | Returns the picture as SVG text, with no graphics device needed. | the SVG document as a string | | SaveAsSVG | | an undrawn plate gives a bare background of about 160 characters
DrawSpectrogram | Draws a spectrogram from an analysis grid, with time across, frequency up and loudness as brightness, in the inferno colour ramp. | nothing; the picture is drawn | poGrid=The analysis grid of a sound, from its ToSpectrogram; pnMaxHz=The highest frequency to show, or 0 to show them all | SetDynamicRange, MarkTimeAt, SaveAsPNG | A silent or empty grid draws only the title, with no axes | the time axis ends at the grid's own span (0.96 s for a one second sound), so give MarkTimeAt that span
DrawSpectra | Draws one or more spectra as lines on a log frequency axis in decibels, all measured against the loudest point of any of them. | nothing; the picture is drawn | paSeries=The spectra, as pairs [ label, one-row grid ] where the grid comes from a sound's ToSpectrumOf; pnFromHz=The lowest frequency shown, which must be above 0; pnToHz=The highest frequency shown | MarkFrequencyAt, SetTitle | A starting frequency of 0 raises R51 because its logarithm is undefined | the first series is drawn on top, a legend appears from two series and the hues cycle after five
DrawWave | Draws the waveform of a sound's first channel as a band between its lowest and highest sample in each pixel column. | nothing; the picture is drawn | poSound=The sound to draw, any object answering Frames, SampleAt and Duration | MarkTimeAt, DrawSpectrogram | A sound of fewer than two frames draws only the title | the axis shows the time from 0 to the sound's duration and the amplitude from -1 to 1
MarkTimeAt | Draws a red vertical line with a label at a moment of the picture, to point at where something happens. | nothing; the marker is added | pnSeconds=The moment to mark, in seconds; pnTotalSeconds=The time span the horizontal axis shows; pcLabel=The text written beside the line | MarkFrequencyAt, DrawWave | A moment past the span is drawn outside the plot area without an error | call it after the Draw method
MarkFrequencyAt | Draws a red vertical line with a label at a frequency on the log axis of DrawSpectra, to point at a corner or a fundamental. | nothing; the marker is added | pnHz=The frequency to mark; pnFromHz=The lowest frequency of the axis, as given to DrawSpectra; pnToHz=The highest frequency of the axis, as given to DrawSpectra; pcLabel=The text written beside the line | MarkTimeAt, DrawSpectra | A frequency outside the axis is skipped without a message | call it after the Draw method with the same two limits
