Issuer | Returns the issuer URL that the provider signs into every token. | a text | | DiscoveryJson, SigningKeyId

UseRsaKey | Switches signing to RS256 with an RSA private key you supply; only its public parts reach the JWKS. | nothing; use UseRsaKeyQ to chain | pcPem=the RSA private key in PEM text | UseNewRsaKey, RotateKey, JwksJson | raises an error when the text is not a readable PEM key | the key in use before stays published when it has signed something
UseNewRsaKey | Generates an RSA key pair for development and switches signing to RS256 with it. | nothing; use UseNewRsaKeyQ to chain | nBits=the key size in bits, from 2048 to 4096 | UseRsaKey, RotateKey | raises an error for a size outside 2048 to 4096 | generation takes a few seconds at 2048
RotateKey | Starts signing with a new ES256 key, keeping the outgoing key published when it has signed anything. | nothing; use RotateKeyQ to chain | pcSeedHex=a 64-hex-character seed that makes the key reproducible, or an empty text for a random one | UseRsaKey, NumberOfPublishedKeys, JwksJson | | a key that never signed is dropped rather than published, so rotating twice in a row adds no key
NumberOfPublishedKeys | Returns how many keys the JWKS publishes: the current one plus the retired ones. | a number | | JwksJson, RotateKey
JwksJson | Returns the JSON key set that a relying party fetches from the jwks_uri, public halves only. | a text holding a JSON object with a keys list | | DiscoveryJson, RotateKey
DiscoveryJson | Returns the JSON discovery document served at the well-known openid-configuration path. | a text holding a JSON object | | JwksJson, Issuer | | it announces the code flow only, PKCE method S256, and the current signing algorithm
RegisterClient | Registers an application with its secret, stored hashed, and the exact redirect URIs a code may go to. | nothing; use RegisterClientXT to chain and to add a display name | pcClientId=the application identifier; pcSecret=the client secret, kept only as a hash; paRedirectUris=the list of redirect URIs registered for it | RegisterClientXT, HasClient, Authorize | raises an error for an empty id, for an empty list of redirect URIs and for an id already registered
HasClient | TRUE if an application with that id is registered. | TRUE or FALSE | pcClientId=the application identifier, trimmed before the comparison | RegisterClient, ClientIds
ClientIds | Returns the ids of the registered applications, in registration order. | a list of text | | HasClient, RemoveClient
RedirectUrisOf | Returns the redirect URIs registered for an application. | a list of text; [ ] for an unknown id | pcClientId=the application identifier | RegisterClient, Authorize
RemoveClient | Removes an application by id; an unknown id changes nothing. | the provider itself, so calls chain | pcClientId=the application identifier | RegisterClient, HasClient | | codes already issued to that client stay pending until they expire and then fail at exchange
Authorize | Issues a single-use authorization code for an already authenticated user, bound to the client, redirect URI, nonce and PKCE challenge. | a hash-list [ :ok, :code, :redirectTo, :state, :why, :error ]; :ok is 0 and :why and :error say the reason when refused | paReq=the request, a hash-list with clientId, redirectUri, state, nonce, codeChallenge and scope; pcUser=the signed-in user name, which becomes the token subject | AuthorizeAt, ExchangeCode, Why, ErrorCode | refuses with unauthorized_client for an unknown client, invalid_request when the redirect URI is not an exact match for a registered one, and login_required for an empty user; each refusal is also noted to the security ledger as oauth.client.rejected | :redirectTo is the redirect URI with code and state appended, using & when it already holds a query
AuthorizeAt | Issues an authorization code as Authorize does, at a clock reading you give, which makes expiry testable. | a hash-list [ :ok, :code, :redirectTo, :state, :why, :error ] | paReq=the request, a hash-list with clientId, redirectUri, state, nonce, codeChallenge and scope; pcUser=the signed-in user name; pnNow=the current time in epoch seconds, from which the code lifetime counts | Authorize, ExchangeCodeAt
ExchangeCode | Redeems a code from the application server for a signed ID token and access token, after checking client, code, redirect URI and PKCE. | a hash-list [ :ok, :idToken, :accessToken, :tokenType, :expiresIn, :subject, :why, :error ]; :ok is 0 with :error invalid_client or invalid_grant when refused | pcClientId=the application identifier; pcClientSecret=the secret the client registered with; pcCode=the code that Authorize issued; pcRedirectUri=the redirect URI the code was issued for; pcCodeVerifier=the PKCE verifier, or an empty text when the authorization sent no challenge | ExchangeCodeAt, Authorize, PkceChallengeOf, Why | a wrong client secret refuses without using up the code, but any later failure (expired, other client, other redirect URI, bad PKCE) has already consumed it, so a code is never usable twice; presenting a spent code is noted as oauth.code.replayed, an unknown one gives the same answer | the access token is a signed JWT as well, with typ access
ExchangeCodeAt | Redeems a code as ExchangeCode does, at a clock reading you give, which makes expiry testable. | a hash-list [ :ok, :idToken, :accessToken, :tokenType, :expiresIn, :subject, :why, :error ] | pcClientId=the application identifier; pcClientSecret=the secret the client registered with; pcCode=the code that Authorize issued; pcRedirectUri=the redirect URI the code was issued for; pcCodeVerifier=the PKCE verifier, or an empty text; pnNow=the current time in epoch seconds | ExchangeCode, AuthorizeAt
IssueIdToken | Signs an ID token for a subject and audience, without going through the code flow. | a text, the signed JWT of three dot-separated parts | pcSubject=the user the token is about; pcAudience=the application the token is for; pcNonce=the nonce to echo, or an empty text for none | IssueIdTokenAt, ExchangeCode, TokenTTL | subject, audience and nonce are written into the payload without JSON escaping, so a quote or backslash in them gives invalid JSON, and a nonce such as x","sub":"y adds a second sub claim; the nonce reaches this call from the request unchecked
IssueIdTokenAt | Signs an ID token as IssueIdToken does, with the issue time you give, so that exp is pnNow plus the token lifetime. | a text, the signed JWT | pcSubject=the user the token is about; pcAudience=the application the token is for; pcNonce=the nonce to echo, or an empty text for none; pnNow=the issue time in epoch seconds | IssueIdToken, SetTokenTTL | same escaping defect as IssueIdToken
