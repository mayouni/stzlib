init | Creates an empty finite state machine in the engine, identified by a name. | nothing; the object is built | cName=the machine's name, a non-empty text | AddState, AddTransition | a name that is empty or not a text raises an error
Name | Returns the name the machine was created with. | a text | | init
AddState | Adds a state to the machine; the first state added becomes the current one. | nothing; use AddStateQ to chain | cState=the name of the state, a non-empty text | AddStates, SetState, NumberOfStates | adding a name twice counts it twice in NumberOfStates | an empty or non-text name raises an error
AddStates | Adds several states in the order given, by calling AddState for each. | nothing | paStates=a list of state names, each a non-empty text | AddState
AddTransition | Adds a transition that moves the machine from one state to another when an event is sent. | nothing; use AddTransitionQ to chain | cFrom=the state the transition leaves; cEvent=the event that triggers it; cTo=the state it arrives in | AddTransitions, Send | a transition naming a state that was not added is silently dropped: NumberOfTransitions does not grow and nothing is raised | all three must be texts, else an error is raised
AddTransitions | Adds several transitions, each given as a [ from, event, to ] list. | nothing | paTransitions=a list of [ cFrom, cEvent, cTo ] lists | AddTransition
SetState | Forces the machine into a state without going through a transition. | nothing; use SetStateQ to chain | cState=the name of the state to enter | CurrentState, Send | an unknown state is silently ignored and the current state stays: the error the code intends is never raised
CurrentState | Returns the name of the state the machine is in; empty before any state is added. | a text | | SetState, Send
Send | Feeds an event to the machine, which follows the matching transition from its current state, and returns the state it is in after. | the name of the current state, a text | cEvent=the event to send, a non-empty text | CurrentState, AddTransition | an event with no transition from the current state is silently ignored and the state stays: the error the code intends is never raised; checked with two unmatched events | an empty or non-text event raises an error
NumberOfStates | Returns how many states were added. | a number | | AddState
NumberOfTransitions | Returns how many transitions were accepted by the engine. | a number | | AddTransition
Destroy | Frees the engine machine and marks the object unusable. | nothing | | init | afterwards CurrentState answers an empty text
