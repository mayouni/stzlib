init | Builds an empty vocabulary for a field of mathematics: no type, no predicate and no function yet. | nothing; the object is built | pcName=the domain's name; it is trimmed and kept in lower case | AddType, AddPredicate
Name_ | Returns the domain's name, trimmed and in lower case. | a text | | init
AddType | Declares a type of object, such as Set or Atom, and returns the domain so calls chain. | the domain itself, so calls chain | pcType=the type's name, which must not be empty or already declared in any case | AddSubtype, HasType, Types | an empty name or a type declared twice raises an error | AddTypeQ is the same call
AddSubtype | Declares a type that is a kind of an earlier one, so that wherever the earlier is expected the new one is accepted. | the domain itself, so calls chain | pcType=the new type's name; pcSuper=the type it is a kind of, which must be declared already, else an error is raised | AddType, TypeMatches | the subtype can itself be the super of another, to any depth | Hydrogen is declared a kind of Atom, so a rule over Atom draws a Hydrogen
HasType | TRUE if the domain declares a type, in any case. | TRUE or FALSE | pcType=the type's name | AddType, Types | | ATOM finds Atom
Types | Returns the names of the declared types, as written, in the order declared. | a list of text | | HasType, AddType | | subtypes are in the same list
TypeMatches | TRUE if an object of one type may stand where another type is asked for: the same type, or a kind of it at any depth. | TRUE or FALSE | pcActual=the type of the object; pcWanted=the type that is asked for | AddSubtype, HasType | | Hydrogen matches Atom, Atom does not match Hydrogen, and two kinds of Atom do not match each other
AddPredicate | Declares a relation over objects of given types, such as Subset over two Sets. | the domain itself, so calls chain | pcName=the predicate's name, not empty and not declared already; pacArgTypes=the types of its arguments in order, or one type name for a one-argument predicate; every type must be declared, else an error is raised | AddSymmetricPredicate, PredicateArity, HasPredicate | a name declared twice raises an error | the number of types is the arity, so Joins over Bond, Atom, Atom has arity 3
AddSymmetricPredicate | Declares a two-argument relation whose arguments may be swapped, such as Disjoint. | the domain itself, so calls chain | pcName=the predicate's name; pacArgTypes=exactly two types, both the same | AddPredicate, IsSymmetric | one type, or two different types, raises an error | the substance's Holds then answers TRUE for either order
HasPredicate | TRUE if the domain declares a predicate, in any case. | TRUE or FALSE | pcName=the predicate's name | AddPredicate, Predicates
PredicateArity | Returns how many arguments a predicate takes. | a number; -1 for a predicate the domain does not have | pcName=the predicate's name, in any case | AddPredicate, HasPredicate
IsSymmetric | TRUE if the predicate was declared symmetric. | TRUE or FALSE; FALSE for a predicate the domain does not have | pcName=the predicate's name, in any case | AddSymmetricPredicate, AddPredicate
Predicates | Returns the names of the declared predicates, as written, in the order declared. | a list of text | | HasPredicate, AddPredicate
AddFunction | Declares a function from objects of given types to an object of an output type. | the domain itself, so calls chain | pcName=the function's name, not empty and not declared already; pacArgTypes=the argument types in order, or one type name; pcOutType=the type of the result; every type must be declared, else an error is raised | AddConstructor, FunctionArity, FunctionOutputType | AddFunctionQ is the same call | a substance applies it with Define
AddConstructor | Declares a function whose name is also the type it makes, such as Pair made from two Atoms. | the domain itself, so calls chain | pcName=the function's name and the output type's name; the type must be declared before, else an error is raised; pacArgTypes=the argument types in order | AddFunction | a constructor of an undeclared type raises an error naming the missing type |
HasFunction | TRUE if the domain declares a function or a constructor, in any case. | TRUE or FALSE | pcName=the function's name | AddFunction, FunctionArity
FunctionOutputType | Returns the type a function makes. | a text; empty for a function the domain does not have | pcName=the function's name, in any case | AddFunction, FunctionArity
FunctionArity | Returns how many arguments a function takes. | a number; -1 for a function the domain does not have | pcName=the function's name, in any case | AddFunction, FunctionOutputType
