init | Opens a learner's folder, creating it with its work folder when absent, and reads the progress file if there is one. | nothing; the object is built | pcFolder=the learner's folder: its last segment becomes the learner's id and a trailing slash is dropped | Id, Folder, Reload, Submit | the facts are read once, here: another stzLearner on the same folder is not seen until Reload, and Submit then writes the whole file from memory, so the object that did not Reload erases the other's passes (shown: a pass of ex-01-01 was lost) | a learner is a folder holding work/ (what they submitted) and progress.zknw (facts, plain text, git-diffable)
Id | Returns the learner's identifier, which is the last segment of the folder's path. | a text such as ada | | Folder, ProgressFile
Folder | Returns the path of the learner's folder as it was given, without a trailing slash. | a text | | Id, WorkFile, ProgressFile
ProgressFile | Returns the path of progress.zknw, the plain-text file of facts that only the checker writes. | a text; the file may not exist yet | | Facts, Reload
WorkFile | Returns the path where the learner's submission for an exercise is kept, exactly as they wrote it. | a text; nothing is read, so the file may not exist | pcExerciseId=the exercise's id, such as ex-01-01 | Submit, HasTried
Facts | Returns the progress facts held in memory, as [ subject, predicate, object ] triples of text. | a list of three-item lists; [ ] for a learner with no progress | | Reload, LastVerdict | | the list is a copy: changing it changes nothing in the learner, and it shows only what init, Reload and this object's own submissions put there
Submit | Runs the checker on a submitted program, records its verdict and evidence in the progress file, and returns the check. | the stzExerciseCheck of that run; Passed() says whether every promise was kept | poExercise=the stzExercise to judge the program against; pcCode=the learner's program, as text | SubmitFile, HasPassed, LastVerdict, ChapterOn | the checker runs the program in a fresh Ring process with Softanza loaded, on the desktop only, and each submission takes seconds; the newest verdict replaces the older one, so a wrong submission after a pass makes HasPassed FALSE although the old evidence stays in the file; two stzLearner objects on one folder overwrite each other (see init) | the one writer of progress: a verdict is written only after a check that ran; a pass also records the sha256 of the program as evidence and the time of the check in milliseconds; a program that stopped with an error is recorded as error, one that ran but missed a promise as diverged
SubmitFile | Reads a program from a file and submits its text exactly as a typed submission, then returns the check. | the stzExerciseCheck of that run | poExercise=the stzExercise to judge the program against; pcFile=the path of the file holding the learner's program | Submit, WorkFile | | the text is copied to the learner's work folder under the exercise's id
HasTried | TRUE if the learner has submitted for that exercise and the work file is still on disk. | TRUE or FALSE | pcExerciseId=the exercise's id | Submit, WorkFile, LastVerdict | | a project id answers FALSE: a project has no work file, use HasPassedProject
LastVerdict | Returns the checker's verdict on the newest submission for an exercise or a project. | passed, diverged (it ran but a promise was missed) or error (it stopped with an error); an empty text when nothing was submitted | pcExerciseId=the exercise's or project's id | HasPassed, Submit | | the verdict alone is not proof of a pass: HasPassed also compares the evidence
HasPassed | TRUE if the checker passed the exercise and the work file still hashes to the evidence it recorded then. | TRUE or FALSE | pcExerciseId=the exercise's id | LastVerdict, Submit, HasEarned | | a passed line typed by hand into progress.zknw, or a work file edited after the pass, answers FALSE: the claim is refused, not trusted (law 9)
ChapterOn | Returns the first chapter of the course, in course order, that still has an exercise not passed with evidence. | the chapter's id, a text; an empty text once every chapter is passed | poCourse=the stzCourse the learner follows | HasPassed, MissingFor | | this is what the tutor's rule 2 means by where the learner is
ProjectFolder | Returns the path where the learner keeps the work for a level project, under projects/. | a text; nothing is created | pcProjectId=the project's id, such as project-s0 | SubmitProject, HasPassedProject
SubmitProject | Runs a project's guard on the learner's project folder and records the verdict, with the folder's hash as evidence. | the stzExerciseCheck of the guard's run | poProject=the stzProject to judge the folder against | HasPassedProject, ProjectFolder, HasEarned, Submit | raises an error naming the learner and the project when the learner has no folder for it yet (create ProjectFolder first); the verdict is passed or diverged, never error; the guard runs on the desktop only | the evidence is the hash of every file in the folder, so any file added or changed after the pass makes HasPassedProject FALSE until the folder is submitted again
HasPassedProject | TRUE if the project's guard passed and the learner's whole project folder still hashes to the recorded evidence. | TRUE or FALSE | pcProjectId=the project's id | SubmitProject, HasEarned | | adding even a harmless file to the folder after the pass makes it FALSE (shown with an extra file)
HasEarned | TRUE if every exercise of the chapters a level needs is passed and its project has passed, each with evidence that still matches. | TRUE or FALSE; FALSE too for a level that names no project | poProgram=the stzProgram that defines the levels; poCourse=the stzCourse whose chapters count; pcLevel=the level's id, such as s0 | MissingFor, HasPassed, HasPassedProject | | nothing else earns a level: not a score, not a teacher
MissingFor | Returns what still stands between the learner and a level: the exercises not passed, then the project if it has not passed. | a list of ids, exercises first and the project last; [ ] once the level is earned | poProgram=the stzProgram that defines the levels; poCourse=the stzCourse whose chapters count; pcLevel=the level's id, such as s0 | HasEarned, ChapterOn
Reload | Re-reads progress.zknw from disk, replacing the facts held in memory by what is written there now. | nothing | | Facts, Submit | | call it before a submission when another object, or a person, may have written the folder
