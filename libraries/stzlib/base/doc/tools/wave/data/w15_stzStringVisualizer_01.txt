init | Builds a visualizer over a text or over a stzString object, to print it, mark things in it or frame it. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, to display | Show, Boxed | any other kind of value raises "Can't create stzStringVisualizer! Parameter must be a string or stzString object."; the visualizer only reads, so a stzString passed in is never changed |
Content | Returns the text the visualizer holds. | a text | | Stringify | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
Show | Prints the text on the console. | nothing | | ShowShort, ShowNL | |
ShowShort | Prints the text on the console, cut to its first 47 characters followed by three dots when it is longer than 50. | nothing | | Show | | a text of exactly 50 characters is printed whole, one of 51 is cut
ShowNL | Prints the text on the console followed by an extra empty line. | nothing | | Show | |
VizFindChar | Returns the text in quotes with a second line of carets under every place the given character occurs. | a text of two lines; "" when the argument is not a single character | _c_=the one character to mark | VizFind, VizFindCharCS | | VizFindCharCS(c, 0) ignores case; the carets line starts with a space to sit under the opening quote
VizFind | Returns the text in quotes with a second line of carets under every character covered by an occurrence of a substring. | a text of two lines | pcSubStr=the substring to mark | VizFindChar, Highlight | | "banana band" with "an" marks the 2nd to 5th and the 9th to 10th characters; overlapping matches are all marked; an absent or empty substring marks nothing; VizFindCS(s, 0) ignores case
Boxed | Returns the text in a box drawn with plain ASCII characters, with round corners drawn as dots. | a text of three lines | | BoxedXT, BoxedRounded, EachCharBoxed | | a text with a line break keeps its break inside the box instead of framing each line, and the width is the whole character count; for Unicode lines see stzStringBoxed
BoxedRounded | Returns the text in a box of plain characters with round corners, the same as Boxed. | a text of three lines | | Boxed | |
EachCharBoxed | Returns a list holding one small box per character of the text, in order. | a list of three-line texts; [ ] for an empty text | | Boxed | | a space gets a box too
Stringify | Returns the text as a Ring literal, in quotes and with embedded quotes kept in view. | a text | | Content | | a text that holds a double quote is wrapped in single quotes: he said "hi" gives 'he said "hi"'; a text that holds both kinds is not escaped
Highlight | Returns the text with every occurrence of a substring wrapped in a marker, case-sensitively. | a text | pcSubStr=the substring to mark; pcMarker=the text put before and after each occurrence | VizFind | | "banana band" with "an" and "*" gives b*an**an*a b*an*d; an empty marker or an absent substring changes nothing; HighlightCS(s, m, 0) ignores case
