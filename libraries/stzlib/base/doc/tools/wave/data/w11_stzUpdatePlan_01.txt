init | Builds a plan from rehearsed operations and the bridge that would commit them; nothing is committed until Execute. | nothing; the plan is built | paOps=the list of stzVirtualOperation, in the order they were rehearsed; poBridge=the reality bridge that Validate asks and Execute commits through | Execute, stzVirtualSystem | | a twin builds it for you with GenerateUpdatePlan
Operations | Returns the operations the plan holds, rejected ones included. | a list of stzVirtualOperation | | NumberOfOperations, RejectOperation
NumberOfOperations | Returns how many operations the plan holds, rejected ones included. | a number | | NumberOfActiveOperations, Operations
NumberOfActiveOperations | Returns how many operations would still be committed, which is those not rejected. | a number | | NumberOfOperations, RejectOperation
SetScope | Sets the bound on what the plan may commit. | the plan itself, so calls chain | poScope=the stzCommitScope that checks each operation | Scope, Execute
Scope | Returns the scope set on the plan. | the stzCommitScope; an empty text when none is set | | SetScope
SetExecutor | Sets who commits the plan, whose capability kinds gate the crossing. | the plan itself, so calls chain | poActor=the stzSystemActor that commits; an actor without the effectful kind, such as a language model, cannot commit anything | Executor, MayCommit | | without an executor the plan is unguarded, as a human at the keyboard
Executor | Returns who commits the plan. | the stzSystemActor; an empty text when none is set | | SetExecutor
SetGovernance | Sets an optional governance that demands a declared trust posture of the executor and keeps the decision lineage. | the plan itself, so calls chain | poGov=the stzGovernance to consult | Governance, Execute | | the plan keeps a copy, so read its lineage through Governance
Governance | Returns the governance set on the plan. | the stzGovernance; an empty text when none is set | | SetGovernance
AuditTrail | Returns the decisions the plan took when it was executed. | a list of [ index, outcome, type, actor ] rows, the outcome committed or refused | | NumberOfAuditEntries, Execute | | an operation refused by a scope, or rejected by a reviewer, leaves no row
NumberOfAuditEntries | Returns how many decisions the audit trail holds. | a number | | AuditTrail
RejectOperation | Marks one operation as rejected by a reviewer, so Execute skips it. | the plan itself, so calls chain | pnIndex=the position of the operation in the plan, from 1; pcBecause=the reason for rejecting it | IsRejected, NumberOfActiveOperations | | the reason is kept with the rejection, and the narration shows the operation with an x
IsRejected | TRUE if the operation at that position was rejected. | TRUE or FALSE | pnIndex=the position of the operation, from 1 | RejectOperation
Narration | Returns the plan as a plain-language story, one numbered line per operation, rejected ones marked. | a text, several lines | | ShowNarration, Risks
ShowNarration | Prints the narration of the plan. | nothing; it prints | | Narration
Risks | Returns the operations that deserve a second look: deletions, moves, removed variables and spawned commands. | a list of [ index, warning ] rows; an empty list when none is risky | | ShowRisks, Validate
ShowRisks | Prints the risks of the plan, one line each. | nothing; it prints | | Risks
Validate | Re-checks the plan against reality as it is now, because reality may have moved since the rehearsal. | a list of [ index, warning ] rows for a delete, copy or move whose target or source is absent; an empty list when all is present | | Risks, MayCommit | | it reads reality through the bridge and changes nothing
MayCommit | Tells whether the executor could commit this plan at all, without touching anything. | a list [ 1 or 0, reason ] | | SetExecutor, Execute
Execute | Commits every active operation through the bridge after the reviewer, scope and capability gates, and returns a summary with the log. | a list [ [ committed, n ], [ skipped, n ], [ log, rows ] ], each row [ index, status, text ] with a status COMMITTED, FAILED, REJECTED, REFUSED-BY-SCOPE or REFUSED-BY-GOVERNANCE | | MayCommit, AuditTrail, Validate | this is the one place reality changes, and with a file or environment bridge it writes the disk or the process: rehearse in the twin and read Narration and Risks first; a governance that finds no declared posture refuses the whole plan with a single row of index 0 | refusals reach the security ledger as scope.refused, capability.refused and posture.refused
ExecuteStepByStep | Commits the plan as Execute does, printing each row of the log as it comes. | the same summary as Execute | | Execute | the same warning as Execute: it commits for real
