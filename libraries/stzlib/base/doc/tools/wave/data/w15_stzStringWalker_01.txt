init | Builds a walker over a text or over a stzString object, to visit its characters from a start to an end with a step. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, whose characters are visited | CharsFromTo, AddWalker | any other kind of value raises "Can't create stzStringWalker! Parameter must be a string or stzString object."; the walker only reads, so a stzString passed in is never changed |
Content | Returns the text the walker holds. | a text | | Chars | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
AddWalker | Registers a named walker, a start, an end and the steps to repeat, to be read back by name. | nothing; use AddWalkerQ to chain | pcWalkerName=the name to read it back by, case-sensitive; _nStart_=the number the walk starts from; _nEnd_=the number it stops at; nStep=a LIST of the steps taken in turn, such as [ 2 ], not a single number | Walker, RemoveWalker | A single number for nStep, as the parameter name suggests, raises "the steps must be a non-empty list of numbers"; a name used twice is kept twice and Walker finds the first | the walker walks numbers (positions) and does not read the text
Walker | Returns the numbers that the named walker visits, from its start to its end. | a list of numbers | pcWalkerName=the name given to AddWalker, case-sensitive | AddWalker, Walkers | An unknown name, or a different case, raises "pcWalkerName must be a valid walker name." | AddWalker("w", 1, 10, [2]) gives 1, 3, 5, 7, 9
Walkers | Returns the registered walkers as a list of [ name, stzWalker ] pairs, in the order added. | a list of pairs | | AddWalker, Walker | | the items are objects, so printing the list with @@ fails; ask len() or a name
RemoveWalker | Removes the first walker that has the given name. | nothing | pcWalkerName=the name of the walker to remove | RemoveWalkers, AddWalker | | an unknown name changes nothing and raises nothing
RemoveWalkers | Removes every registered walker. | nothing | | RemoveWalker | |
Chars | Returns the characters of the text as a list of one-character texts. | a list of texts | | UniqueChars, CharAt | | "שלום😀ب" gives six items; CharsQ answers a stzList
UniqueChars | Returns the different characters of the text, each once, in order of first appearance. | a list of texts | | Chars | | "aabbb" gives a and b; the comparison goes through Ring's text equality
CharAt | Returns the character at a position, counted from 1. | a one-character text | n=the position, from 1 | FirstChar, LastChar | | position 0 or beyond the length raises "Index out of range!"
FirstChar | Returns the first character of the text. | a one-character text | | LastChar, CharAt | | an empty text raises "Index out of range!"
LastChar | Returns the last character of the text. | a one-character text | | FirstChar, CharAt | | an empty text raises "Index out of range!"
WalkAndYield | Visits the characters from a start to an end with a step, runs a piece of code on each, and returns the characters as the code left them. | a list of texts | _nStart_=the first position, raised to 1 if smaller; _nEnd_=the last position, lowered to the length if larger; nStep=the amount added to the position each time, above 0; pcCode=Ring code run for each character, where @char is the character, which it may change, and @position its position; "" does nothing | CharsFromTo, CharsWithStep | A step of 0 never ends and a negative step does not go backwards either (the loop keeps its test on the end): both were read from the code and not run | the code can set @char: '@char = upper(@char)' on "abcdefghij" from 1 to 10 step 3 gives A, D, G, J
CharsFromTo | Returns the characters from one position to another, forwards or backwards, as a list. | a list of texts; [ ] when a position is outside the text | n1=the first position, from 1; n2=the last position, from 1 | CharsWithStep, WalkAndYield | | CharsFromTo(5, 2) on "abcdefghij" gives e, d, c, b; positions 0 or past the length give [ ] without an error
CharsWithStep | Returns every nth character from a start position, forwards or backwards, as a list. | a list of texts; [ ] when the start is outside the text | _nStart_=the first position, from 1; nStep=the step, positive to go forward, negative to go back | CharsFromTo, WalkAndYield | A step of 0 never ends (read from the code, not run) | CharsWithStep(1, 3) on "abcdefghij" gives a, d, g, j and CharsWithStep(10, -3) gives j, g, d, a
