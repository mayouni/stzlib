init | Builds a virtual authenticator for a domain, with no credential yet and its counter at 0. | nothing; the object is built | pcRpId=the domain its credentials are bound to | CreateCredential, IsSandbox
IsSandbox | TRUE if the object is a test double; here it always is, so it never passes for a real device. | TRUE | | stzServiceRegistry
RpId | Returns the domain the authenticator is bound to, trimmed. | a text | | init
CredentialId | Returns the id of the credential made last. | a text; empty before CreateCredential | | CreateCredential
SignCount | Returns the signature counter, which each Assert advances. | a number | | Assert, AssertAtCount | | an Assert that raises for lack of a credential has already advanced it
CreateCredential | Makes a credential as a security key would, with a real P-256 key and attestation object, and returns what the browser passes on. | a hash list [ :attestationObject, :clientData, :credentialId ]; the first two are base64url | pcChallenge=the challenge the server issued; pcOrigin=the origin the browser would report | Assert, ClientData | | a new key is generated each time unless the XT form is given a 32-byte hex seed; it replaces the earlier credential and resets the counter to 0; only invented sandbox keys, never real ones
Assert | Signs a challenge as the login ceremony does, advancing the counter by one. | a hash list [ :credentialId, :authenticatorData, :clientData, :signature ] | pcChallenge=the challenge the server issued; pcOrigin=the origin the browser would report | AssertAtCount, AssertForOrigin | raises an error telling to call CreateCredential first when there is no credential
AssertAtCount | Signs a challenge with a chosen counter value, which is how a cloned authenticator behaves when it does not advance. | a hash list [ :credentialId, :authenticatorData, :clientData, :signature ] | pcChallenge=the challenge the server issued; pcOrigin=the origin to report; pnCount=the counter to write into the authenticator data | Assert | raises the no-credential error when there is no credential | the stored counter is not changed
AssertForOrigin | Signs for another origin, as a phishing site would obtain, and advances the counter. | a hash list [ :credentialId, :authenticatorData, :clientData, :signature ] | pcChallenge=the challenge the server issued; pcPhishingOrigin=the origin to report in its place | Assert | raises the no-credential error when there is no credential | the relying party's origin check must refuse the result
ClientData | Builds the client data JSON a browser would build, base64url-encoded. | a text, base64url | pcType=webauthn.create or webauthn.get; pcChallenge=the challenge; pcOrigin=the origin | CreateCredential, Assert | the challenge and the origin are written into the JSON without escaping, so a value holding a quote can add keys or break the JSON, which is useful for testing and wrong for real input | it is a test double: real client data comes from the browser
Show | Prints one line with the domain, the credential id and the counter. | nothing; it prints | | CredentialId
