init | Builds an index, embedding and adding each text of the list when one is given. | nothing; the object is built | paTexts=a list of texts to index now, or an empty list | AddText, AddEmbedded | a non-empty list needs a loaded embedding model, and raises AddText: no embedding model is loaded without one
AddText | Embeds a text with the model the engine holds and stores both; the model must be loaded already. | the index itself, so calls chain | pcText=the text to index, not empty | AddEmbedded, AddTexts, Search | raises for an empty or non-text argument, when no model is loaded, and when the embedding size changes
AddEmbedded | Stores a text with an embedding the caller already has, so no model is needed; the vector must have unit length. | the index itself, so calls chain | pcText=the text to index; paVec=its embedding, a list of numbers of the index's size and of norm 1 | AddText, SearchByVectorXT | raises for an empty text, an empty vector and a size different from the first one | the norm is not checked, and the score is only a cosine for unit vectors
AddTexts | Adds each text of a list with AddText. | the index itself, so calls chain | paTexts=the list of texts | AddText | raises for a non-list; each text needs the loaded model
Count | Returns how many texts the index holds. | a number | | Texts
Texts | Returns the indexed texts in the order they were added. | a list of text | | Count, Vectors
EmbeddingDim | Returns the size of the embeddings, 0 while the index is empty. | a number | | Vectors, AddEmbedded
Vectors | Returns the stored embeddings, one row per text, in the order added. | a list of lists of numbers | | Texts, EmbeddingDim
UsesGpu | TRUE if the corpus is resident on the graphics card now; a small corpus never is. | 1 or 0, numbers | | SearchByVectorXT | the route is chosen by a measured threshold and none is seeded for this seam, so it stays 0 until a calibration finds a win
SearchByVectorXT | Returns the n texts closest in meaning to a query embedding, best first, each with its cosine score and position. | a list of [ text, cosine, position ] rows; [ ] for an empty index | paQ=the query embedding, of the index's size; n=how many hits to return, 1 or more | Search, AddEmbedded | raises when the size of paQ differs from the index's or n is below 1 | the score is exact, from the unit-vector distance as 1 minus half its square
Search | Returns the 5 best matches for a query text, or n with SearchXT; the query is embedded with the loaded model. | a list of [ text, cosine, position ] rows, best first | pcQuery=the query text, not empty; n=how many hits for SearchXT, 1 or more | SearchByVectorXT, Closest | with no model loaded it answers [ ] without a message, where AddText raises | the score is 1 for the same meaning, near 0 for unrelated texts
Closest | Returns the single best matching text for a query, an empty text when there is no hit. | a text | pcQuery=the query text, not empty | Search | with no model loaded it answers an empty text without a message
Close | Frees the resident dataset and empties the index, since Ring has no destructors. | nothing | | init | a closed index is empty and can be fed again; a search by vector on it raises about 0 dims
