OnError | Sets the handler that receives each error the object catches instead of printing it, and returns the object. | the object itself, so calls chain | fCallback=a function taking two arguments, the place that failed and the message | Errors, LastError, ErrorCount | | without a handler the error is printed as [stzReactiveObject.place] message, and recorded either way
Errors | Returns the errors recorded so far, as pairs of the place that failed and its message, oldest first. | a list of [ place, message ] pairs; at most 50 are kept | | LastError, ErrorCount, ClearErrors | | the places look like Watch:name, Watcher:name, Computed:name, Binding:name->target or Batch
LastError | Returns the message of the newest recorded error. | a text; empty when nothing was recorded | | LastErrorWhere, Errors
LastErrorWhere | Returns the place of the newest recorded error, such as Watch:age or Batch. | a text; empty when nothing was recorded | | LastError, Errors
ErrorCount | Returns how many errors were seen, including the ones dropped once 50 were kept. | a number | | ErrorsDropped, HasErrors, Errors
ErrorsDropped | Returns how many errors were counted but not kept, because the record holds 50. | a number | | ErrorCount, Errors
HasErrors | TRUE if at least one error was recorded since the last ClearErrors. | 1 or 0 | | ErrorCount, ClearErrors
ClearErrors | Empties the error record and its counters, then returns the object. | the object itself, so calls chain | | Errors, HasErrors
Init | Builds the reactive object around an existing object, or around nothing when given an empty text, and keeps the engine that serves it. | nothing; the object is built | existingObject=the object to wrap, or an empty text for an object made of attributes only; reactiveEngine=the stzReactive system that serves timers and streams | Reactivate, SetAttribute | the wrapped object is stored as a copy: changing the original afterwards does not reach the reactive object, and setting through the reactive object does not change the original | the attributes of a wrapped object are read into the storage and the cache when it is built
BraceStart | Runs when Ring opens a brace block on the object, and does nothing today. | nothing | | BraceEnd, BraceError
BraceEnd | Runs when Ring closes a brace block on the object, and notifies the changes queued during the block. | nothing | | BraceStart, ProcessPendingReactions
BraceError | Runs when a call in a brace block fails, and hands the error text to the failure function of every SetAsync made so far. | nothing | | SetAsync, OnError | the SetAsync records are never removed, so a later failed brace call reaches the failure handlers of earlier, finished SetAsync calls as well
SetAttribute | Sets an attribute, creating it when new, and on a real change runs its watchers, dependent attributes and bindings. | the object itself, so calls chain | _cAttribute_=the attribute's name, which is lowercased; _newValue_=the value to store | GetAttribute, Watch, Computed, Batch | inside Batch the notifications are queued and the value is stored at once; an equal value triggers nothing | the name is lowercased, so :Name and :name are one attribute
@ | Sets an attribute from a pair of its name and its value, so that a set reads like an assignment. | nothing | paAttr=a list of two items, the attribute's name and its value | SetAttribute | | it calls SetAttribute and, unlike it, does not return the object
GetAttribute | Returns the current value of an attribute, matched without regard to case. | the value; an empty text when the attribute is unknown | _cAttribute_=the attribute's name | SetAttribute, GetAttributeValue
GetAttributeValue | Returns the value of an attribute, reading the cache first, then the wrapped object, then the storage. | the value; an empty text when the attribute is unknown | _cAttribute_=the attribute's name | GetAttribute, SetAttributeValue, UpdateAttributeCache | a value written with SetAttributeValue is not read back while the cache holds an older one
SetAttributeValue | Writes a value into the storage, the wrapped object and the object's own attribute, without any notification and without touching the cache. | nothing | _cAttribute_=the attribute's name; _value_=the value to write | SetAttribute, UpdateAttributeCache | GetAttribute keeps answering the older value for an attribute already in the cache; use SetAttribute to set and notify | it is the call a binding makes on its target
Watch | Registers a function called as f(object, name, oldValue, newValue) each time the attribute changes, and returns the object. | the object itself, so calls chain | _cAttribute_=the attribute to watch; fCallback=a function taking four arguments: the reactive object, the attribute's name, the old value and the new value | Computed, WaitForAttributetoSettle, OnError | a value that is not a function is refused: nothing is stored and the error Watch callback is not a function is recorded | the function runs on every real change, in order of registration; an error inside it is recorded as Watcher:name
Computed | Creates an attribute whose value is calculated by a function from other attributes, now and again each time one of them changes. | the object itself, so calls chain | _cAttribute_=the name of the calculated attribute; _fnComputer_=a function taking the reactive object and returning the value; _aDependencies_=the names of the attributes it depends on, as a list | Watch, SetAttribute, ComputeAttribute | a function that is not one, or dependencies that are not a list, are refused and recorded, and nothing is created | a watcher on the calculated attribute also fires when it is recomputed
BindTo | Binds an attribute to an attribute of another reactive object, copying its current value to the target at once. | the object itself, so calls chain | oTargetObject=the reactive object that receives the value; _cSourceAttribute_=the attribute of this object to follow; _cTargetAttribute_=the attribute to write in the target, or an empty text for the same name | UpdateBoundAttributes, Watch | a later change of the source does not reach the target object you passed, because the binding keeps a copy of the target: the target holds the value of the moment of binding; a target that is not an object is refused and recorded | the starting value is written to the object you passed
SetAsync | Sets an attribute at once, completes a task with the value, calls the success function, and returns the task. | a stzReactiveTask, already completed or failed | _cAttribute_=the attribute's name; _newValue_=the value to set; fnSuccess=a function taking the value, or an empty text; fnError=a function taking the error text, or an empty text | SetAttribute, BraceError | the name suggests a deferred update, but nothing waits: the value is set before the call returns | the error is also recorded as SetAsync:name
Batch | Runs a function in which attribute changes are stored at once but notified together afterwards, then returns the object. | the object itself, so calls chain | fnUpdates=the function with no argument that makes the changes | SetAttribute, ProcessBatchChanges | the watcher receives the first change of an attribute, with its old value and the value it had then, not the last: after sets of 1, 2 and 3 on an attribute that held 10 it is told 10 and 1 while the attribute holds 3; an error in the function is recorded as Batch and the changes already made stay | each changed attribute is notified once
StreamAttribute | Returns a stream that never emits, because the watcher behind it fails at every change; the failure is recorded, not raised. | a stream object; it stays empty | _cAttribute_=the attribute to follow | Watch, SetAttribute | the watcher raises error R24 Using uninitialized variable: _stream_, because the function it registers reads a local of the method; the error is recorded as Watcher:name and nothing reaches the stream |
WaitForAttributetoSettle | Calls a function once an attribute has stopped changing for the given delay, with the last change, and returns the object. | the object itself, so calls chain | _cAttribute_=the attribute to watch; nDelay=the quiet time in milliseconds; fCallback=a function taking three arguments: the name, the old value and the new value | OnSettleChange, Watch | the timer is run by the reactive loop, so nothing fires until the loop runs | after three quick sets, the function ran once, with the second value as old and the last as new; DebounceAttribute is the same call
OnSettleChange | Restarts the settle timer of an attribute each time it changes, so that the function fires only when the changes stop. | nothing | cAttr=the attribute that changed; oldVal=its old value; newVal=its new value | WaitForAttributetoSettle | internal: the object registers it for you

GetAttributeFromStorage | Returns the value of an attribute from the storage only, ignoring the cache and the wrapped object. | the value; an empty text when absent | _cAttribute_=the attribute's name | SetAttributeInStorage, GetAttributeValue
SetAttributeInStorage | Writes a value into the storage only, adding the attribute when absent. | nothing | _cAttribute_=the attribute's name; _value_=the value to store | GetAttributeFromStorage, UpdateAttributeCache
UpdateAttributeCache | Writes a value into the cache that GetAttribute reads first, adding the attribute when absent. | nothing | _cAttribute_=the attribute's name; _value_=the value to cache | FindAttributeInCache, SetAttributeInStorage
FindAttributeInCache | Returns the position of an attribute in the cache, or 0 when it is not cached. | a number | _cAttribute_=the attribute's name | UpdateAttributeCache
ProcessAttributeChange | Notifies one change: runs the watchers, recomputes the calculated attributes that depend on it, and updates the bound targets. | nothing | _cAttribute_=the attribute that changed; oldValue=its previous value; _newValue_=its new value | TriggerAttributeWatchers, UpdateDependentComputedAttributes, UpdateBoundAttributes | calling it directly notifies without changing any value
ProcessPendingReactions | Notifies the changes queued by Batch, if any. | nothing | | ProcessBatchChanges, BraceEnd
ProcessBatchChanges | Notifies each attribute queued by Batch once, using its first queued change, then empties the queue. | nothing | | Batch, ProcessAttributeChange

UpdateBoundAttributes | Writes a new value to the target of each binding that follows the attribute. | nothing | _cAttribute_=the source attribute; _newValue_=the value to write | BindTo | the targets written are the copies kept by BindTo, so the object you passed to BindTo does not see the value
