init | Creates a retry budget: a token bucket of pnBudget retries that refills over a window of pnWindowSeconds. | nothing; the object is built | pnBudget=how many retries the bucket holds; pnWindowSeconds=the seconds over which the budget refills, raised to 1 if smaller | Allow, RefillPerSecond | the refill rate is floor(pnBudget / pnWindowSeconds) tokens a second, with a minimum of 1
Allow | Takes one retry from the budget and answers whether the retry may go ahead. | TRUE or FALSE | | AllowN, Available, Spend | refuses once the budget is spent and recovers as the window refills
Spend | Takes one retry from the budget and answers whether it may go ahead, as the call with the other name does. | TRUE or FALSE | | Allow, AllowN
AllowN | Takes n retries from the budget at once and answers whether they may all go ahead. | TRUE or FALSE | n=how many retries to take | Allow, Available | a refused request takes nothing; n of 0 is allowed
Available | Returns how many retries are left in the budget, as a decimal. | a number | | Allow, Budget | the budget refills continuously, so a reading just after a spend is slightly above the exact remainder
Budget | Returns the size of the budget, as given at construction. | a number | | Window, Available
Window | Returns the refill window in seconds, with a minimum of 1. | a number | | Budget, RefillPerSecond
RefillPerSecond | Returns how many retries the budget regains each second. | a number | | Window, Budget | floor(budget / window), never below 1
Destroy | Frees the engine bucket and marks the object unusable. | the budget itself, so calls chain | | init | a later call builds a new full bucket
