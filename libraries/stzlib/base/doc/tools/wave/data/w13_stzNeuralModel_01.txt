init | Builds a model object, and loads the GGUF file at the given path when the path is a non-empty text. | nothing; the object is built | pcPath=the path of a GGUF model file, or an empty text to build the object without loading | LoadFrom, IsLoaded | | an unrecorded model digest refuses the load without an error: ask IsLoaded afterwards
LoadFrom | Loads a GGUF model file into the engine single active model slot, if its SHA-256 digest was recorded as trusted. | TRUE if the model loaded, FALSE if refused | pcPath=the path of a GGUF model file | LoadStatus, IsLoaded, Unload | a refusal gives FALSE and no error; LoadStatus says why (-1 unreadable, -2 digest mismatch, -3 no digest recorded), and a path that is not text gives FALSE | the path is kept even when the load was refused; trust a model first with StzTrustModel or StzExpectModelDigest
LoadStatus | Returns why the last load was accepted or refused. | a number: 0 loaded, -1 unreadable or not a GGUF, -2 digest differs from the recorded one, -3 no digest recorded | | LoadFrom, IsLoaded
IsLoaded | TRUE if a model is loaded in the engine slot. | TRUE or FALSE | | LoadFrom, Unload | | the slot is shared by the whole process, so it answers for any model loaded, not only this object
Unload | Frees the model from the engine slot and forgets the path. | the model object itself, so calls chain | | LoadFrom, IsLoaded | | the slot is shared by the whole process, so it frees whatever model is loaded
Path | Returns the path given to the last LoadFrom. | a text; empty before any load and after Unload | | LoadFrom
Arch | Returns the architecture name of the loaded model, such as bert. | a text; empty when no model is loaded | | Content, EmbeddingDim
EmbeddingDim | Returns the width of the sentence embedding the loaded model produces. | a number; 0 when no model is loaded, 384 for all-MiniLM-L6-v2 | | EmbeddingOf, Content
NumberOfLayers | Returns how many transformer layers the loaded model has. | a number; 0 when no model is loaded | | NumberOfHeads, Content
NumberOfHeads | Returns how many attention heads each layer of the loaded model has. | a number; 0 when no model is loaded | | NumberOfLayers, Content
ContextLength | Returns the longest token sequence the loaded model accepts. | a number; 0 when no model is loaded | | Tokenize, Content
VocabSize | Returns how many tokens the vocabulary of the loaded model holds. | a number; 0 when no model is loaded | | Tokenize, Content
NumberOfTensors | Returns how many weight tensors the loaded model file holds. | a number; 0 when no model is loaded | | Content
Content | Returns the model architecture and hyperparameters as data. | a list of [ key, value ] rows: arch, embedding_dim, layers, heads, context_length, vocab_size and tensors | | Show, Arch
Show | Prints a one-line summary of the loaded model, or says that none is loaded. | the model object itself, so calls chain | | Content, IsLoaded
EmbeddingOf | Runs the forward pass and returns the sentence embedding of a text, unit length. | a list of EmbeddingDim numbers; [ ] when no model is loaded, for a text that is not text and for an empty text | pcText=the sentence to embed | SemanticSimilarityBetween, Tokenize, EmbeddingDim | | the vector has length one, so the dot product of two of them is their cosine
Tokenize | Returns the WordPiece token ids of a text, with the start and end markers. | a list of numbers; [ ] when no model is loaded or the text is not text | pcText=the text to split into tokens | EmbeddingOf, VocabSize | | an embedding model gives ids such as 101 first and 102 last
IsGenerative | TRUE if the loaded model can generate text, which an embedding model cannot. | TRUE or FALSE | | Generate, AnswerTo
Generate | Continues a raw prompt greedily with the loaded generative model, up to a number of new tokens. | a text; empty when no generative model is loaded | pcPrompt=the raw prompt text to continue; pnMaxNewTokens=the most tokens to add, 64 when not a positive number | AnswerTo, IsGenerative
AnswerTo | Asks the loaded instruct model a question, wrapped as a ChatML prompt, answering greedily. | a text; empty when no generative model is loaded | pcQuestion=the question; pnMaxNewTokens=the most tokens to add, 64 when not a positive number | Generate, IsGenerative | | AnswerToQ gives the answer as a stzString
SemanticSimilarityBetween | Returns the cosine similarity of the embeddings of two texts, from -1 to 1. | a number; 0 when no model is loaded | pcA=the first text; pcB=the second text | EmbeddingOf, StzSemanticSimilarity | | for all-MiniLM-L6-v2, a sentence with itself gives 1, two paraphrases about 0.6 and unrelated sentences near 0
