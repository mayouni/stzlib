init | Builds a k-nearest-neighbours classifier over a training set; nothing is trained and k starts at 3. | nothing; the object is built | poDataset=a stzTrainingSet; the classifier keeps its own copy | SetK, Classify
TrainingSetQ | Returns the training set the classifier holds, the one to grow if more examples are wanted. | a stzTrainingSet | | Classify | growing the set you passed to the constructor does not reach the classifier, because it keeps a copy; grow it here, and the next Classify sees it
SetK | Sets how many nearest examples vote. | the classifier itself, so calls chain | n=the number of neighbours, 1 or more | K, Classify | | a value below 1 is ignored without a message and the earlier k stays
SetApproximate | Switches between exact search and an approximate one through a projection forest in the engine. | the classifier itself, so calls chain | bFlag=1 for approximate search, 0 for exact | IsApproximate, AgreementWithExact | raises an error unless the flag is exactly 1 or 0 | off by default: it pays only above a few thousand examples and many queries, and it can change an answer; AgreementWithExact measures that on your queries
IsApproximate | TRUE if approximate search is on. | TRUE or FALSE; FALSE by default | | SetApproximate
SetApproximateTrees | Sets how many trees the approximate index uses: more trees give better recall and a larger, slower index. | the classifier itself, so calls chain | n=the number of trees, 1 or more | ApproximateTrees, SetApproximateBudget | raises an error for a number below 1 | the default is 24
SetApproximateBudget | Sets how many candidates the approximate search examines per query before true distances decide. | the classifier itself, so calls chain | n=the candidate count, 0 or more; 0 lets the engine choose from k | ApproximateBudget, SetApproximateTrees | raises an error for a negative number | it is the recall dial
ApproximateTrees | Returns the number of trees set for the approximate index. | a number; 24 by default | | SetApproximateTrees
ApproximateBudget | Returns the candidate budget set for the approximate search. | a number; 0 means the engine chooses | | SetApproximateBudget
AgreementWithExact | Returns the share of the given queries on which approximate and exact search give the same label. | a number from 0 to 1 | paQueries=a non-empty list of feature lists, each as wide as the training examples | SetApproximate, Classify | raises an error for an empty list or a query of the wrong width, naming it | the honest measure for a classifier: a vote often survives a swapped neighbour, so the label is compared and not the neighbour list
K | Returns how many neighbours vote. | a number; 3 by default | | SetK
Classify | Returns the majority label among the k training examples nearest to a feature list, by Euclidean distance. | a text, the label | paFeatures=the numbers describing the thing to classify, as many as the training examples have | Why, SetK | raises an error for an empty training set and for a query of the wrong width; a tie goes to the label that appeared first in the training set | the search runs in the engine and rebuilds when examples were added
Why | Returns the neighbours behind the last answer, each with its number and distance, and the vote. | a text such as the 3 nearest examples were: #3 'setosa' (d=0), ... -- majority: 'setosa' (3/3); empty before the first Classify | | Classify
