init | Builds a goal with no requirement yet, which any knowledgebase satisfies. | nothing; the object is built | | RequireEach, RequireOne
RequireEach | Adds the schema requirement that every entity of a type bears a relation; both names are trimmed and lowercased. | the goal itself, so calls chain | pcType=the entity type, such as dish; pcRel=the relation every entity of that type must bear, such as contains | RequireOne, Gaps
RequireOne | Adds the requirement that one named subject bears a relation; both names are trimmed and lowercased. | the goal itself, so calls chain | pcSubject=the entity that must bear the relation; pcRel=the relation, such as run-by | RequireEach, Gaps
Requirements | Returns the requirements added so far, the each pairs and the one pairs. | a list [ [ each, pairs ], [ one, pairs ] ], every pair being [ name, relation ] | | RequireEach, RequireOne
Gaps | Returns the slots of the goal that a knowledgebase does not fill yet, each with the reason, so the next question can be asked. | a list of [ subject, relation, why ] rows; empty when nothing is missing | poKB=the stzKnowledgeGraph to read, passed in and never stored | IsSatisfied, RequireEach | raises an error when the argument is not a stzKnowledgeGraph; a subject missing under both RequireEach and RequireOne is listed twice, once with each reason | the order is the schema rows first, then the one-subject rows
IsSatisfied | TRUE if the knowledgebase leaves no gap, which an empty goal always does. | 1 or 0, numbers | poKB=the stzKnowledgeGraph to read | Gaps
