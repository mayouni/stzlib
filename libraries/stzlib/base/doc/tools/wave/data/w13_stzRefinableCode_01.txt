init | Reads source code for its refinement points, the tags that mark a value as an adjustable knob, and keeps the text. | nothing; the object is built | pcSource=the code as text, holding tags such as <R:PARAM name="vat" value="0.20" min="0" max="0.9"> or <R:ALGO name="sort" value="quick" options="quick|merge|heap"> | RefinementPoints, Refine | text without any tag gives a code with no points, and a value that is not text is turned into text
Source | Returns the code as it stands now, with the current value of every point in place. | a text | | Rendered, Save
Why | Returns the reason given by the last gate decision or timeline move. | a text such as admitted: 'vat' 0.20 -> 0.22, or the stage and cause of a refusal; empty text before any | | To, RevertTo
RefinementPoints | Returns the declared change surface: one triple of name, kind and current value for each point, in source order. | a list of triples such as [ "vat", "param", "0.20" ] | | NumberOfPoints, ValueOf, KindOf
NumberOfPoints | Returns how many refinement points the code declares. | a number | | RefinementPoints
ValueOf | Returns the current value of a point as text. | a text; empty text when the point does not exist | pcName=the name of the point, with the case it was declared in | KindOf, RefinementPoints
KindOf | Returns the kind of a point, in lowercase: param for a bounded value, algo or lib for a choice among options. | a text such as param; empty text when the point does not exist | pcName=the name of the point | ValueOf
Cascade | Previews what a change to a point touches: the line it sits on and any other point on the same line. | a hash-list with point, exists, lines and alsoTouches; exists is 0 and the lists are empty for an unknown point | pcName=the name of the point | Refine, RefinementPoints
DeclareDerivation | Adds a rule between points that every later change must satisfy, checked on the state the change would produce. | the code itself, so calls chain | pcName=the name of the rule, quoted in the refusal; fPredicate=a function taking the refinable code and returning 1 when the state is consistent; pcMessage=the text shown when the rule refuses a change | NumberOfDerivations, To | a change that breaks a rule is rolled back and refused with a derivation reason
NumberOfDerivations | Returns how many derivation rules are declared. | a number | | DeclareDerivation
GovernedBy | Returns the name of the governance object wired to this code, or empty text when there is none. | a text | | SetGovernedBy, Actor
SetGovernedBy | Wires a governance object, so that every change becomes the governed action refine-point and needs permission and authority. | the code itself, so calls chain | poGov=a stzGovernance, a copy of which is kept | SetRiskFor, SetAllowRefine, SetAuthorityLevel, GovernedBy | configure the governance through this code, not through the object you passed: the code keeps its own copy
Actor | Returns the name of the actor on whose behalf changes are judged by the governance; refiner by default. | a text | | SetActor
SetActor | Sets the actor on whose behalf changes are judged by the governance. | the code itself, so calls chain | pcActor=the name of the actor, such as release-bot | Actor, SetAllowRefine
As | Declares where the next change comes from, so the gate can compare it with a trust floor; it applies to the next To only. | the code itself, so calls chain | pcPosture=trusted, external, sandboxed or llm, in order of trust from highest to lowest | TrustFloor, To | an unknown posture counts as trusted and passes every floor (confirmed: a floor of trusted admitted a change made as weird); the posture goes back to trusted after each To | the posture is recorded in the timeline
TrustFloor | Sets the lowest posture allowed to change a point; changes from a lower posture are refused. | the code itself, so calls chain | pcPoint=the name of the point, in any case; pcMinPosture=trusted, external, sandboxed or llm | TrustFloorOf, As | an unknown posture sets the strictest floor, trusted, instead of none | setting it again replaces the earlier floor
TrustFloorOf | Returns the floor of a point as a rank: 3 trusted, 2 external, 1 sandboxed, 0 llm. | a number; -1 when the point has no floor | pcPoint=the name of the point, in any case | TrustFloor
SetRiskFor | Declares how risky it is to change a point, as a tier, in the governance wired to this code. | the code itself, so calls chain | pcPoint=the name of the point; nTier=the risk tier, a number such as 3 | SetAllowRefine, SetAuthorityLevel, SetGovernedBy | raises an error when no governance is wired yet | a point with no declared tier can never be changed under governance
SetAllowRefine | Grants the current actor the permission to change a point. | the code itself, so calls chain | pcPoint=the name of the point | SetRiskFor, SetActor | raises an error when no governance is wired yet
SetAuthorityLevel | Sets the authority of the current actor, which must cover the risk tier of a point for the change to pass. | the code itself, so calls chain | pcType=advisory, delegated, autonomous or emergencyoverride | SetRiskFor, SetActor | raises an error when no governance is wired yet | delegated is level 2 and autonomous is level 3
GovernanceQ | Returns the governance object wired to this code, as a copy for reading its decisions. | the stzGovernance; empty text when none | | SetGovernedBy
Refine | Sets the point that the next To will change, which opens a typed proposal. | the code itself, so calls chain | pcName=the name of the point to change | To, As, Cascade | nothing is checked until To
To | Sends the value to the point named by Refine through the gate and applies it only if every stage passes. | a hash-list with admitted, 1 or 0, and why | pValue=the new value, taken as text | Refine, Why, Revert | raises an error when Refine was not called first; the stages in order are the point exists, the value is within min and max or among the options, governance, trust floor, then the derivation rules; a refused change leaves the source untouched | an admitted change is recorded on the timeline and clears what could be redone
CanRevert | TRUE if at least one admitted change can be undone. | 1 or 0 | | Revert, CanRedo
Revert | Undoes the last admitted change and keeps it available to redo. | the code itself, so calls chain | | RevertTo, Redo, CanRevert | raises an error when there is nothing to revert
RevertTo | Rolls the source back to the state after exactly this many admitted changes, undoing the later ones in reverse. | the code itself, so calls chain | nStep=how many changes to keep, 0 for the original source; a negative number counts as 0 | Revert, Checkpoint, Redo | | the undone changes can be redone, the last undone first
CanRedo | TRUE if some undone change can be applied again. | 1 or 0 | | Redo, CanRevert
Redo | Applies again the change that was undone most recently. | the code itself, so calls chain | | Revert, CanRedo | raises an error when there is nothing to redo | the change is applied without passing the gate again
Checkpoint | Marks the current place on the timeline under a name, to come back to it later. | the code itself, so calls chain | pcName=the name of the checkpoint | RevertToCheckpoint
RevertToCheckpoint | Rolls the source back to the place marked by a checkpoint. | the code itself, so calls chain | pcName=the name given to Checkpoint | Checkpoint, RevertTo | raises an error naming the checkpoint when none has that name
History | Returns the applied changes in order, each as name, old value, new value and posture. | a list of lists such as [ "vat", "0.20", "0.22", "trusted" ] | | Timeline, NumberOfSteps
Timeline | Returns the applied changes in order, each as name, old value, new value and posture. | a list of lists such as [ "vat", "0.20", "0.22", "trusted" ] | | History
NumberOfSteps | Returns how many changes are applied now, which is the position on the timeline. | a number | | History, RevertTo
PostureOf | Returns the posture recorded for one applied change. | a text such as trusted or llm; empty text for a step that does not exist | nStep=the position of the change, from 1 | History, As
Rendered | Returns the source with every point's current value in place; the tags stay, so the points remain adjustable. | a text | | Source, Save
Save | Writes the source to a file with the extension zrfn, adding the extension when it is missing. | the path actually written, as text | pcFile=the path to write | Rendered
