init | Builds a host that owns a new reactor and supervises no agent yet. | nothing; the object is built | | SetReactor, Supervise, Shutdown
SetReactor | Shares another host's reactor, such as an app server's loop, instead of owning one; a reactor the host owned is destroyed. | the host itself, so calls chain | poReactor=the stzReactor to share | ReactorQ, Shutdown | | Shutdown leaves a shared reactor alone
ReactorQ | Returns the reactor the host waits on between ticks. | the stzReactor, or an empty text after Shutdown | | SetReactor, Shutdown
Why | Returns the host's last explanation: what a mount, a rescan, a run to quiet, a retirement or a quarantine did. | a text; empty until something is recorded | | Retire, Quarantine, RescanAgents
SetRetirementGovernance | Sets the governance whose decommission contracts gate Retire. | the host itself, so calls chain | poGov=the stzGovernance that holds the decommission contracts | DeclareDecommission, Retire | the host keeps a COPY of the governance, so declare and fulfil obligations through the host and never on the original | once a governance is set, an agent with no declared contract cannot retire
DeclareDecommission | Declares what an agent must fulfil before it may retire. | the host itself, so calls chain | pcName=the agent's name; pacObligations=the obligations to fulfil, as a list of text | FulfillObligation, Retire | | creates a governance named agent-host when none was set, which makes Retire require a contract for every agent
FulfillObligation | Marks one decommission obligation of an agent as fulfilled. | the host itself, so calls chain | pcName=the agent's name; pcObligation=the obligation to mark, as text | DeclareDecommission, Retire | | retirement is earned once every declared obligation is fulfilled
GovernanceQ | Returns the retirement governance the host holds. | the stzGovernance, or an empty text when none was set | | SetRetirementGovernance
Supervise | Registers an agent to be ticked on a timer, once every given number of milliseconds. | the host itself, so calls chain | poAgent=an agent that answers Name_ and Cycle, fully configured; nTickMs=the milliseconds between ticks, at least 1 | SuperviseOnEvent, RunFor, AgentQ | an interval below 1 raises an error; the host keeps a COPY of the agent, so configure it fully first and reach it afterwards through AgentQ | with the engine loop adopted the agent is registered with it at once, and the engine may refuse
SuperviseOnEvent | Registers an agent to be ticked once per event emitted on a channel of the engine event bus, not on a timer. | the host itself, so calls chain | poAgent=an agent that answers Name_ and Cycle, fully configured; pcChannel=the event bus channel to follow, created when absent | Supervise, ChannelOf | | events emitted before the call are not replayed
ChannelOf | Returns the channel an agent is supervised on. | a text; empty for a timer-supervised or unknown agent | pcName=the agent's name | SuperviseOnEvent, IsSupervising
NumberOfAgents | Returns how many agents the host has registered, whether active, cancelled, quarantined or retired. | a number | | NameAt, IsSupervising
NameAt | Returns the name of the nth supervised agent, so an observer can list agents without holding them. | a text; empty when the position is out of range | pnIndex=the position, 1 is the first agent supervised | NumberOfAgents, AgentQ
IsSupervising | TRUE if an agent of that name was registered, retired or not. | TRUE or FALSE | pcName=the agent's name | NumberOfAgents, IsActive
IsActive | TRUE if the agent is registered and not cancelled, quarantined or retired; the answer is the number 1 or 0. | 1 or 0; 0 for an unknown agent | pcName=the agent's name | IsRetired, IsQuarantined, Cancel | Resume on a retired agent sets this back to 1 although it never ticks again, so read IsRetired too |
TicksOf | Returns how many cycles the host has run for an agent. | a number; 0 for an unknown agent | pcName=the agent's name | Trace, TickDue
AgentQ | Returns the live supervised agent, the copy to read and not the reference given to Supervise. | the agent object, or an empty text for an unknown name | pcName=the agent's name | Supervise, NameAt
Trace | Returns the tick trace, one row per cycle the host ran. | a list of [ time in ms, agent name, firings, why ] rows | | TicksOf, TickDue | | the why reads tick N or event N (the engine loop can also say mail or nudge); a remade event channel adds a row of its own
UseAgentsFrom | Mounts every valid agent file of a folder on this host, each on the schedule its own file declares. | a number, how many agents were mounted | pcPath=the folder that holds the agent files | RescanAgents, AgentLoadRefusals | | a file the folder will not admit is not mounted and is reported through AgentLoadRefusals; Why says how many were mounted and refused; UseAgentsFromQ does the same and returns the host, so calls chain
AgentFolderQ | Returns the folder object mounted by UseAgentsFrom. | the stzAgentFolder, or an empty text when none was mounted | | UseAgentsFrom, IsUsingAgentFolder
IsUsingAgentFolder | TRUE if an agent folder was mounted; the answer is the number 1 or 0. | 1 or 0 | | UseAgentsFrom, AgentFolderQ
AgentLoadRefusals | Returns every file the folder would not admit, as findings in the unified rule shape. | a list of [ :rule, :subject, :where, :severity, :message ] findings; [ ] with no folder or no refusal | | CiteAgentLoadRefusals, UseAgentsFrom
CiteAgentLoadRefusals | Returns the refusals of the folder as readable text, one line each. | a text; empty with no folder or no refusal | | AgentLoadRefusals
RescanAgents | Re-reads the folder: supervises what arrived and cancels what vanished, and only reports a file that changed under a running agent. | a list [ :added, :changed, :removed ] of file names | | UseAgentsFrom, Cancel | raises an error when no folder was mounted: call UseAgentsFrom first | a vanished agent is cancelled and not retired, because retirement is earned; swapping a live agent is never done quietly
Declare | Declares an agent's coverage statement and reversibility class, which the engine loop demands before it schedules anything. | nothing; use DeclareQ to chain | pcName=the agent's name; pcCoverage=one sentence saying what the agent covers; pcReversibility=reversible, compensable or irreversible | SetPriority, UseEngineLoop | | needed only for an agent that does not answer CoverageStatement and ReversibilityClass itself (law 18); DeclareQ does the same and returns the host, so calls chain, and a second call for the same name replaces the first
SetPriority | Sets an agent's priority for the engine loop: a higher number runs first in a pass, and ties run in the order registered. | nothing; use SetPriorityQ to chain | pcName=the agent's name; pnPriority=the priority, a number | PriorityOf | | it works before the agent is supervised
PriorityOf | Returns the priority set for an agent. | a number; 0 when none was set | pcName=the agent's name | SetPriority
UseEngineLoop | Adopts the engine loop as this host's pump: the engine decides who ticks and in what order, Ring still runs the cycles. | nothing; use UseEngineLoopQ to chain | | UseRingLoop, Declare, EngineLoopWhy | raises an error carrying the engine's refusal when it will not schedule an agent, but the host then stays in engine mode with that agent unscheduled, so the agent never ticks until UseRingLoop is called | opt-in; UseEngineLoopQ does the same and returns the host, so calls chain; agents already supervised are registered now, so the order of calls does not matter
UseRingLoop | Returns the host to the Ring pump it ran before the engine loop was adopted. | the host itself, so calls chain | | UseEngineLoop, IsUsingEngineLoop
IsUsingEngineLoop | TRUE if the engine loop is this host's pump; the answer is the number 1 or 0. | 1 or 0 | | UseEngineLoop, UseRingLoop
EngineLoopWhy | Returns the engine's last refusal, verbatim: it names its code, its subject and what to do. | a text; empty until the engine refuses | | UseEngineLoop, Declare
EngineSlotOf | Returns the engine slot an agent occupies. | a number; -1 when the Ring pump drives it, after retirement, or for an unknown name | pcName=the agent's name | UseEngineLoop, Retire
TickDue | Runs one cycle of every active agent that is due: a timer agent when its interval has elapsed, an event agent once per new event. | a number, the skill firings run this pass | | RunFor, RunToQuiet, SetActionBudget | | the same call on either pump; every act is counted against its agent's budget, and an agent over it is quarantined in the middle of the pass
RunFor | Drives the loop for a number of milliseconds, ticking due agents and waiting on a real timer between ticks. | the host itself, so calls chain | nMs=how long to run, in milliseconds | TickDue, RunToQuiet
RunToQuiet | Runs rounds until a whole pass fires nothing, or until 200 rounds, whichever comes first. | the host itself, so calls chain | | RunFor, TickDue | an agent that fires on every cycle never goes quiet and stops at the 200-round cap, yet Why still reads ran to quiet | Why says how many rounds ran
Cancel | Stops ticking an agent without retiring it: a pause anyone can undo. | the host itself, so calls chain | pcName=the agent's name | Resume, Quarantine, Retire | raises an error for an agent that is not supervised | a quarantine is a containment act, and a cancel is an operator's pause
Resume | Makes a cancelled agent tick again, from now. | the host itself, so calls chain | pcName=the agent's name | Cancel, Release | raises an error for an unknown agent and for a quarantined one, which only Release lifts; on a retired agent it sets IsActive back to 1 although the agent never ticks again |
SetActionBudget | Caps the acts, which are skill firings, that an agent may take in a sliding window; an agent over the cap is quarantined. | the host itself, so calls chain | pcName=the agent as supervised; pnMaxActs=how many acts the window allows, at least 1; pnWindowMs=the window length, in milliseconds, at least 1 | ActionBudgetOf, Quarantine, Release | raises an error for an agent that is not supervised and for a value below 1; setting it again starts a fresh window | threat model R7, OWASP ASI08: both pumps account, and the reason names how far over it went (action_budget_narrated)
ActionBudgetOf | Returns the budget of an agent and the acts counted in the current window. | a list [ :max, :windowMs, :acts ]; [ ] when the agent has no budget | pcName=the agent's name, matched without regard to case | SetActionBudget | | the count starts again when the window ends or when Release lifts a quarantine
Quarantine | Stops an agent and keeps the reason; it stays stopped until an effectful actor releases it. | the host itself, so calls chain | pcName=the agent's name; pcReason=why it is contained, as text | IsQuarantined, Release, QuarantineOf | raises an error for an agent that is not supervised | writes agent.quarantined to the ledger when one is open; Resume refuses while it holds (quarantine_part_narrated)
IsQuarantined | TRUE if the agent is under quarantine. | TRUE or FALSE | pcName=the agent's name, matched without regard to case | Quarantine, QuarantineOf
QuarantineOf | Returns why and when an agent was quarantined. | a list [ :reason, :at ]; [ ] when it is not quarantined | pcName=the agent's name, matched without regard to case | Quarantine, IsQuarantined
Release | Lifts a quarantine and resumes the agent, on the word of an effectful, non-sandboxed actor only. | the host itself, so calls chain | pcName=the agent to release; poActor=the actor that releases it, an object that must be effectful and not sandboxed | Quarantine, Resume | an actor that is not allowed, a language-model actor or a text, raises an error and the refusal reaches the ledger; it also resumes an agent that was merely cancelled and records agent.released although nothing was quarantined | a released agent starts a fresh budget window
Retire | Retires an agent for good when every decommission obligation it declared is fulfilled; it never ticks again. | TRUE when retired, FALSE when refused, with Why saying what is pending | pcName=the agent's name | DeclareDecommission, FulfillObligation, IsRetired | raises an error for an agent that is not supervised; with a governance set, an agent that declared no contract is refused | with no governance at all any agent retires at once; a retired agent frees its engine slot
IsRetired | TRUE if the agent was retired; the answer is the number 1 or 0. | 1 or 0; 0 for an unknown agent | pcName=the agent's name | Retire, IsActive
Shutdown | Destroys the reactor the host owns; a reactor shared through SetReactor is left alone. | the host itself, so calls chain | | SetReactor, ReactorQ
