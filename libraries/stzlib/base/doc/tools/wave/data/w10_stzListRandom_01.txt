IsEmpty | TRUE if the list holds no item. | TRUE or FALSE | | NumberOfItems
RandomPosition | Returns a position drawn at random, each position of the list equally likely. | a number from 1 to the number of items; 0 for an empty list | | RandomItem, RandomPositionGreaterThan, RandomPositionLessThan
RandomPositionGreaterThan | Returns a position drawn at random among those after the given one. | a number from _n_ + 1 to the number of items; 0 when _n_ is already the last position or beyond | _n_=the position to stay after | RandomPositionLessThan, RandomPosition | a value that is not a number raises an error |
RandomPositionLessThan | Returns a position drawn at random among those before the given one. | a number from 1 to _n_ - 1; 0 when _n_ is 1 or less | _n_=the position to stay before | RandomPositionGreaterThan, RandomPosition | a value that is not a number raises an error |
RandomPositionExceptPositions | Returns a position drawn at random that is not in the list given. | a position that is free; 0 when every position is excluded | panPos=the positions to avoid | RandomPosition, RandomItemExceptPosition | a value that is not a list of numbers raises an error | with five items and 1, 2, 3 excluded it answers 4 or 5
NRandomPositions | Returns several different positions in random order. | a list of different positions; every position, shuffled, when _n_ exceeds the number of items | _n_=how many positions to draw | RandomPosition, NRandomItems | it never returns when _n_ is 0 (tried on lists of 5 and of 3 items), so do not pass 0 | NRandomPositions(8) on eight items always gave a permutation of 1 to 8
RandomItem | Returns an item drawn at random, each item equally likely. | one item of the list | | RandomPosition, RandomItemExceptPosition, NRandomItems | an empty list raises an error, index outside the list |
RandomItemExceptPosition | Returns an item drawn at random from the positions other than the one given. | one item of the list | _n_=the position to leave out | RandomItem, RandomPositionExceptPositions | a list of one item raises R2 Array Access (Index out of range), because no other position exists | with 10, 20, 30, 40, 50 and position 1 it never answered 10
NRandomItems | Returns several different items in random order. | a list of _n_ items; the whole list, shuffled, when _n_ exceeds its length; [ ] for 0 | _n_=how many items to draw | SomeItems, NRandomPositions, RandomItem | | the list itself is not changed
SomeItems | Returns a random number of items, from 1 to all of them, drawn at random without repeats. | a list of items | | NRandomItems, RandomItem
