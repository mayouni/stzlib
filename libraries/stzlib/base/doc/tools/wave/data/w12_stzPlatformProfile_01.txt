# Wave 12 -- stzPlatformProfile. Name | brief | returns | params | see | warning | note
init | Builds a solution profile with a name, no development system and no part. | nothing; the object is built | pcName=the solution's name, kept as given | DevelopedOn, WithApp, WithServer | | the profile only describes the solution; building and deploying belong to the platform that owns it
Name | Returns the solution's name. | a text | | SetName
SetName | Sets the solution's name. | the profile itself, so calls chain | pcName=the new name | Name
DevelopedOn | Declares the development system, from a friendly token or a system profile, and gives it the role development. | the profile itself, so calls chain | pTarget=a token such as :Windows, :LinuxServer, :Android, :ESP32, or a stzSystemProfile | DevelopmentSystem, WithPart | an unknown token is taken as an operating-system name with default capabilities | tokens map to a known operating system with its default capabilities: ESP32 gives espidf
DevelopmentSystem | Returns the declared development system. | a stzSystemProfile; the empty text before DevelopedOn | | DevelopedOn, CurrentSystem | | the declared system and the live machine should agree, but up-enabling is judged against the live one
CurrentSystem | Returns a profile of the machine running this code now, with the role runtime. | a stzSystemProfile | | DevelopmentSystem | | it reads the live machine, so its capabilities depend on where it runs
AddApp | Adds a ready-made part to the solution. | the profile itself, so calls chain | poApp=the stzAppProfile to add; it is copied in | WithPart, App | the profile keeps a copy: change the part through App afterwards, or before adding | AddAppQ is the same call
WithPart | Declares a part of the solution of a given kind and the system it deploys to. | the profile itself, so calls chain | pcKind=the kind, such as app, server or superapp, kept in lower case; pcName=the part's name, kept in lower case; pTarget=a deployment token such as :ESP32, or a stzSystemProfile | WithApp, WithServer, WithSuperApp, WithParts | | a modelling act only: nothing is built
WithApp | Declares a part of the kind app and the system it deploys to. | the profile itself, so calls chain | pcName=the part's name; pTarget=the deployment token or system profile | WithPart
WithServer | Declares a part of the kind server and the system it deploys to. | the profile itself, so calls chain | pcName=the part's name; pTarget=the deployment token or system profile | WithPart
WithSuperApp | Declares a part of the kind superapp and the system it deploys to. | the profile itself, so calls chain | pcName=the part's name; pTarget=the deployment token or system profile | WithPart
WithParts | Declares several parts at once from a list of triples. | the profile itself, so calls chain | paTriples=a list of [ kind, name, target ] triples | WithPart | a triple with fewer than three items is skipped without a message
Apps | Returns the parts of the solution, in the order declared. | a list of stzAppProfile objects | | App, NumberOfApps
Parts | Returns the parts of the solution, in the order declared. | a list of stzAppProfile objects | | Apps
NumberOfApps | Returns how many parts the solution declares. | a number | | Apps, HasApp
NumberOfParts | Returns how many parts the solution declares. | a number | | NumberOfApps
HasApp | TRUE if a part of that name is declared. | TRUE or FALSE | pcName=the part's name, matched without regard to case | App, Apps
App | Returns the part of that name, the receiver of a deployment scope. | a stzAppProfile | pcName=the part's name, matched without regard to case | HasApp, Apps | an unknown name raises an error | call System on the result in a chain: App(:x).System().ReadPin(4)
ReadPinIn | Authors a read of a pin in a part's feature code, checked against that part's target. | a text: native when the live machine can do it, rehearsed when only the target can | pcName=the part to author it in; pnPin=the pin number | WritePinIn, FeatureOpsFor, RehearsedFeatureOpsFor | a target without gpio raises an error naming the capability; an unknown part raises an error | the operation is recorded as plain data and nothing runs
WritePinIn | Authors a write of a value to a pin in a part's feature code, checked against that part's target. | a text: native or rehearsed | pcName=the part to author it in; pnPin=the pin number; pnVal=the value to write | ReadPinIn, FeatureOpsFor | the same errors as ReadPinIn | recorded as plain data
SpawnIn | Authors the start of a process in a part's feature code, checked against that part's target. | a text: native or rehearsed | pcName=the part to author it in; pcCmd=the command, as text | ReadPinIn, FeatureOpsFor | a target without processes, such as an ESP32, raises an error; an unknown part raises an error | recorded as plain data and never run
WriteFileIn | Authors the writing of a file in a part's feature code, checked against that part's target. | a text: native or rehearsed | pcName=the part to author it in; pcPath=the file path, as text | ReadPinIn, FeatureOpsFor | a target without a filesystem raises an error; an unknown part raises an error | recorded as plain data and never run
ConnectIn | Authors a network connection in a part's feature code, checked against that part's target. | a text: native or rehearsed | pcName=the part to author it in; pcHost=the host to connect to, as text | ReadPinIn, FeatureOpsFor | a target without network raises an error; an unknown part raises an error | recorded as plain data; no connection is made
UseIn | Authors the use of any named capability in a part's feature code, checked against that part's target. | a text: native or rehearsed | pcName=the part to author it in; pcCap=the capability name, such as threads or clock; pcDesc=what it is used for | ReadPinIn, FeatureOpsFor | a capability the target lacks raises an error; an unknown part raises an error | the operation is recorded with the verb use
FeatureOpsFor | Returns the feature operations authored for a part. | a list of [ capability, verb, arguments, description, status ] rows; [ ] for an unknown part | pcName=the part's name, matched without regard to case | RehearsedFeatureOpsFor, ReadPinIn
RehearsedFeatureOpsFor | Returns the operations of a part that only the target can do, the ones a lowering bridge turns into artifacts. | a list of [ capability, verb, arguments, description ] rows | pcName=the part's name | FeatureOpsFor, stzLoweringBridge
Validate | Checks the solution as a whole: a development system, at least one part, and a deployment target for every part. | a list of issue texts; [ ] when sound | | IsSound
IsSound | TRUE if Validate finds no issue. | TRUE or FALSE | | Validate
ToStzPlatform | Returns the solution in the .stzplatform text format. | a text: a header line, platform, developed_on and one line "kind: name -> target" per part | | Save, FromString
Save | Writes the .stzplatform text to a file. | the profile itself, so calls chain | pcPath=the file to write | LoadFrom, ToStzPlatform | the feature operations are not part of the format and are not saved
LoadFrom | Reads a .stzplatform file into this profile. | the profile itself, so calls chain | pcPath=the file to read | FromString, Save | it adds the parts to those already declared
FromString | Reads .stzplatform text into this profile: the name, the development system and the parts. | the profile itself, so calls chain | pcText=the text to read | LoadFrom, ToStzPlatform | it adds the parts to those already declared; comment lines and lines it does not understand are skipped
Show | Prints the solution: its name, development system and one line per part. | nothing; it prints | | ToStzPlatform
