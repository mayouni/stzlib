init | Builds and solves a figure from its kind and its declaration; an unknown kind, or an empty or non-list declaration, raises an error. | nothing; the figure is built | pcKind=The figure kind, as text, case ignored: function, numberline, fraction, matrix, complexplane, boxplot, surface, stemplot, residualplot or codedtable; paSpec=The declaration, a list of key = value pairs whose keys depend on the kind, such as [ :f = "sin(x)", :on = [ -6, 6 ] ] | Kind, Spec, Layout | the figure is already solved when init returns | StzMathFigureQ(kind, spec) builds the same object
Kind | Returns the figure kind in lowercase, such as function or boxplot. | text | | Spec, init
Spec | Returns the declaration the figure was built from, exactly as given. | a list of key = value pairs | | Kind, SetDatum
Diagram | Returns the solved picture, a stzMathDiagram, as a copy. | a stzMathDiagram | | Substance, SetTheme, SetDatum | the copy is detached: a theme or a datum set on it never reaches the figure, so change the figure itself through SetTheme and SetDatum
SetTheme | Chooses the colour theme the figure is drawn in, with no second solve; the figure is returned so calls can be chained. | the figure itself | pcTheme=A theme name, as text, such as light, dark, vibrant, pro, access, print or gray | Diagram, ToSVG | the name is stored lowercased without a check: an unknown name raises a stzColor error when the figure is next drawn, and the figure stays on it until a valid theme is set | SetThemeQ is the same call
Substance | Returns the content behind the picture, a stzMathSubstance, as a copy: its objects, data and definitions. | a stzMathSubstance | | Diagram, Fact
SetFont | Gives the figure a font and size to measure and draw its names with, so the next solve places them again; the figure is returned. | the figure itself | poFont=The stzFont to measure and draw names with; pnSize=The font size, as a number | Layout, ToSVG | without a font the geometry is solved and no text is drawn | SetFontQ is the same call
Layout | Solves the figure if it is not solved yet, then returns the figure; a figure is already solved when built. | the figure itself | | Relayout, IsSolved | LayoutQ is the same call
IsSolved | TRUE if every constraint of the figure holds after the solve. | TRUE or FALSE (1 or 0) | | Violations, Why
Violations | Returns the constraints the solve could not satisfy, each with the rule and a message; [ ] when the figure is lawful. | a list of hash lists [ :rule, :message ]; [ ] when none | | IsSolved, Why
LayoutMs | Returns how long the last solve took, in milliseconds. | a number | | Layout, Relayout
Why | Returns one sentence saying what was computed (samples, marks, quartiles...) and one saying how the solve went. | text | | Violations, Show | the first half is written by the figure kind, the second by the diagram
SampleCount | Returns how many points were sampled from the function; raises an error on any other figure kind. | a number | | PieceCount, RunCount | a function figure only: the other kinds raise an error naming the question
PieceCount | Returns into how many unbroken pieces the curve falls, cut where it is not finite or leaves the window; raises an error on any other kind. | a number | | SampleCount, RunCount | a function figure only; a piece of a single sample is dropped
RunCount | Returns how many polylines draw the curve, since a piece of more than 64 samples is several runs; raises an error on any other kind. | a number | | PieceCount, SampleCount | a function figure only; a figure under a live motion draws no curve and answers 0
Window | Returns the visible window in the author's own units; raises an error on any other figure kind. | a list [ xmin, xmax, ymin, ymax ] | | Marks, SampleCount | a function figure only
Marks | Returns every named mark of a function figure, each as [ kind, x, y ], where kind is zero, extremum or given. | a list of [ kind, x, y ] triples | | Zeros, Extrema | a function figure only; marks past the maxmarks limit are counted by Why but not listed
Zeros | Returns the [ x, y ] position of every zero of the function that was marked. | a list of [ x, y ] pairs | | Marks, Extrema | a function figure only, and only when the declaration asks for :zeros in :mark
Extrema | Returns the [ x, y ] position of every extremum of the function that was marked. | a list of [ x, y ] pairs | | Marks, Zeros | a function figure only, and only when the declaration asks for :extrema in :mark
SetDatum | Changes one number held by the content, such as a frame limit, then marks the figure to be solved again; the figure is returned. | the figure itself | pcObject=The name of a content object, such as fr for the frame; pcKey=The datum to change, as text; pnValue=The new value, as a number | Fact, Spec | the object and key are not checked; only the solved half is redone, so the sampled curve is not recomputed | the number read back by Fact with :datum
Pin | Raises an error today instead of holding a shape where it is during later solves: no shape of any figure kind has a free position to hold. | nothing today | pcPath=The path of a shape, such as ax.icon | Unpin, DragTo | the diagram refuses it because the rules fix every shape (checked on 35 sample figures of all ten kinds); an unknown path raises too
Unpin | Releases a shape held by Pin; an unknown shape is ignored and the figure is returned. | the figure itself | pcPath=The path of a shape, such as ax.icon | Pin, DragTo | since no shape can be pinned, it changes nothing
DragTo | Raises an error today instead of moving a shape to a position and re-solving around it: no shape has a free centre to move. | nothing today | pcPath=The path of a shape, such as ax.icon; pnX=The new x of the shape's centre, in pixels; pnY=The new y of the shape's centre, in pixels | Pin, MoveNoteTo | refused for every shape of 9 figures tried across the kinds; use MoveNoteTo to move a note
MoveNoteTo | Puts a note's centre at a pixel position, holds it there, and re-solves the rest of the figure around it; the figure is returned. | the figure itself | pcNote=The name of a note of the figure, such as n1; pnX=The x of the note's centre, in pixels; pnY=The y of the note's centre, in pixels | ReleaseNote, Relayout | an unknown note raises an error; the figure is solved first | the hold lasts until ReleaseNote
ReleaseNote | Lets go of a note held by MoveNoteTo, so the next solve may place it again; the figure is returned. | the figure itself | pcNote=The name of a note of the figure, such as n1 | MoveNoteTo, Relayout | the note stays where it was put until Relayout runs; an unknown note is ignored
Relayout | Solves the figure again from where it stands, so a datum or a held note takes effect, and returns the figure. | the figure itself | | Layout, LayoutMs | LayoutMs then reports this solve
Text | Returns the figure as text for a terminal or a log: the five numbers and box of a box plot, the rows of a stem plot, or a coded table. | text, several lines | | ToSVG, Rendition | any other kind raises an error saying which kinds have a text rendition
ToSVG | Returns the figure as SVG text, which needs no display device. | text, an <svg> document | | ToPNG, Rendition
ToPNG | Draws the figure to a PNG file at a path and returns the PNG bytes as text. | the PNG content, as a string of bytes | pcPath=The file to write, as text | ToSVG, RenditionAs | the file is written where the path says; a relative path means the current folder
Rendition | Returns the figure's natural rendition, its vector drawing, as a hash list carrying the SVG. | a hash list [ :kind, :mime, :content, :locator, :title ] | | RenditionAs, ToSVG | the kind is vector and the mime image/svg+xml
RenditionAs | Returns the figure as the kind of rendition asked: vector, image, graph or text. | a hash list [ :kind, :mime, :content, :locator, :title ] | pcKind=vector for SVG, image for a PNG file, graph for the content as Graphviz text, text for the solve's sentence | Rendition, ToPNG | image writes rendition_<kind>.png in the current folder and gives that name as :locator, so prefer ToPNG with a path; another word raises an error
Fact | Answers a question about the figure with a fact: a datum, a value, a distance, an angle, a position, a count or a verdict. | a hash list [ :kind, :subject, :value, :unit, :where, :message ] | pcKind=The fact asked: expr, value, distance, angle, datum, position, count, tapenodes, arg, term or verdict; paArgs=The arguments of that kind, as a list, such as [ "fr", "samples" ] for datum | ShapeOf, Substance | a name or shape the figure does not hold raises an error; the unit is px for geometry and none for a datum | the same fact object a narration quotes
ShapeOf | Returns the solved geometry of one shape of the picture; [ ] when the path names no shape. | a hash list such as [ :kind, :cx, :cy, :r ] or [ :kind, :x1, :y1, :x2, :y2 ] | pcPath=The path of a shape, such as ax.icon | Fact, Diagram | the keys depend on the shape kind: circle, ellipse, line, rect or text
Show | Prints the figure's explanation sentence and returns the figure; it draws nothing. | the figure itself | | Why, ToSVG
