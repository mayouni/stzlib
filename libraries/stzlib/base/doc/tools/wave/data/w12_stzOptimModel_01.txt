# Wave 12 -- stzOptimModel. Name | brief | returns | params | see | warning | note
init | Builds an empty model with no variable, no objective and no constraint. | nothing; the object is built | | Vars, Maximize, SubjectTo
Vars | Declares several variables at once from a list of name = spec pairs. | the model itself, so calls chain | paSpec=pairs such as [ :x = [0, 40], :y = [0, :integer] ]; a spec is a lower bound, [lb], [lb, ub], [lb, :integer], [lb, ub, :integer] or [lb, :binary] | AddVar, BoundsOf | a non-list, an entry that is not a pair, a name declared twice and an unknown qualifier raise an error | an omitted upper bound means unbounded above; names are kept in lower case
AddVar | Declares one variable with its bounds and whether it is whole-valued. | the model itself, so calls chain | pcName=the variable's name, lower-cased, never empty; pSpec=a number (the lower bound) or a list as for Vars: bounds, then :integer or :binary | Vars, BoundsOf, HasVar | an empty name, a name declared twice and a qualifier other than :integer, :int, :binary or :bool raise an error | :binary means integer with bounds 0 and 1; a variable declared after the constraints widens the earlier rows with zeros
HasVar | TRUE if a variable of that name is declared. | TRUE or FALSE | pcName=the variable's name, matched without regard to case | VarNames, NumberOfVars
NumberOfVars | Returns how many variables are declared. | a number | | VarNames, HasVar
VarNames | Returns the names of the variables, in lower case, in declaration order. | a list of text | | NumberOfVars, BoundsOf
BoundsOf | Returns the declared bounds and kind of one variable. | a list [ :lb, :ub, :bounded, :integer ]; [ ] for an unknown name | pcName=the variable's name | AddVar, VarNames | | :ub is 0 and :bounded is 0 when the variable has no upper bound
Maximize | Sets the objective to maximize, from a linear expression over the declared variables. | the model itself, so calls chain | pcExpr=a linear expression such as "3*x + 2*y + 1"; a constant is allowed | Minimize, ObjectiveCoefficients, SolveWith | raises an error when no variable is declared yet or when the expression names something that is not a variable | a second call replaces the objective
Minimize | Sets the objective to minimize, from a linear expression over the declared variables. | the model itself, so calls chain | pcExpr=a linear expression such as "2*p + 3*q" | Maximize, SolveWith | same errors as Maximize | a second call replaces the objective
Sense | Returns the direction of the objective. | a text: max, min, or the empty text before an objective is set | | Maximize, Minimize
ObjectiveCoefficients | Returns the coefficient of each variable in the objective. | a list of numbers, one per variable in declaration order; [ ] before an objective is set | | Maximize, VarNames | | the constant of the expression is not in it; it is added to Objective after solving
SubjectTo | Adds constraints from a list of relation texts, or one constraint from a single text. | the model itself, so calls chain | paList=a list of relations such as [ "x + y <= 50", "2*x + y <= 80" ], or one relation as text | AddConstraint, AddNamedConstraint | raises an error for anything else, when no variable is declared, and for a text with no <=, >= or = | the constraints are named c1, c2 and so on, in order added
AddConstraint | Adds one constraint from a relation text, named automatically. | the model itself, so calls chain | pcText=a relation such as "x + y <= 50", with <=, >= or = | AddNamedConstraint, SubjectTo | the same errors as SubjectTo | the name is c followed by the count of constraints added without a name
AddNamedConstraint | Adds one constraint from a relation text under a name of your choice. | the model itself, so calls chain | pcName=the constraint's name, kept in lower case; pcText=a relation such as "n <= 5" | AddConstraint, ConstraintAt | the same errors as SubjectTo | the variables are moved to the left side, so "2 >= x" is stored as the row -1 against -2
NumberOfConstraints | Returns how many constraints the model holds. | a number | | ConstraintAt
ConstraintAt | Returns one stored constraint. | a list [ name, coefficients, operator, right side, text ]; the operator is -1 for <=, 1 for >= and 0 for = | pnIndex=the position of the constraint, from 1 | NumberOfConstraints | an index outside 1 to NumberOfConstraints raises error R2, index out of range | the coefficients are one per variable, in declaration order
AST | Returns the model as a plain list that two descriptions can be compared by, rather than their answers. | a list [ :sense, :vars, :obj, :objconst, :cons ]; each var row is [ name, lb, ub, bounded, integer ] and each constraint row [ name, coefficients, operator, right side ] | | ASTCore, ASTSignature | | two different wrong models can give the same answer, so a guard compares the ASTs
ASTCore | Returns the same list as AST with the constraint names dropped. | a list of the same shape; each constraint row is [ coefficients, operator, right side ] | | AST, ASTSignature | | for comparing two descriptions that agree on the mathematics but label it differently
ASTSignature | Returns the model, without constraint names, as one canonical text. | a text such as sense=max;const=1;obj=3,2;vars=x[0,3,1,0]...;cons=(1,1<=4) | | ASTCore | | exists because Ring's = does not compare nested lists structurally; the texts can be printed side by side
Describe | Returns the model as it reads: the objective, the constraints and the bounds of the variables. | a text of several lines | | Show
Show | Prints the model as Describe returns it. | nothing; it prints | | Describe
SolveWith | Solves the model with a named tier of the solver and keeps the answer. | the model itself, so calls chain | pcTier=:auto, :floor or the empty text for the built-in simplex and branch-and-bound; :highs is refused | Solve, Why, IsOptimal, Solution | raises an error for :highs (not vendored), for any other tier, when no objective is set, and for a model with no constraint at all, which the engine refuses today although the code says it solves | whole-valued variables make the solver branch; Why names the engine that ran
Solve | Solves the model with the automatic tier. | the model itself, so calls chain | | SolveWith, Why | the same errors as SolveWith, including a model with no constraint
IsSolved | TRUE if a solve has run, whatever it found. | TRUE or FALSE | | IsOptimal, Status
Status | Returns the solver's status code. | a number: 0 optimal, 1 unbounded, 2 infeasible, 3 iteration limit, 4 node limit; -1 before any solve | | StatusWord, IsOptimal
StatusWord | Returns the status in words. | a text such as optimal, infeasible, unbounded or not solved | | Status, IsOptimal
IsOptimal | TRUE if a solve ran and found the optimum. | TRUE or FALSE | | Status, Solution
Objective | Returns the value of the objective at the answer, constant included. | a number; 0 before a solve | | Solution, Status | | meaningful only when IsOptimal is TRUE: for an unbounded or infeasible model it is the engine's placeholder
Solution | Returns each variable with its value at the answer. | a list of [ name, value ] pairs in declaration order | | ValueOf, Objective, IsOptimal | before any solve it raises error R2, index out of range | the values are placeholders when the model is infeasible or unbounded
ValueOf | Returns the value of one variable at the answer. | a number | pcName=the variable's name, matched without regard to case | Solution | raises an error for an unknown name and before any solve
Nodes | Returns how many branch-and-bound nodes the last solve explored. | a number; 0 before a solve | | Iterations, Branched
Iterations | Returns how many simplex iterations the last solve took. | a number; 0 before a solve | | Nodes
Branched | Returns 1 when the solve used branch-and-bound, which it does when a variable is whole-valued. | 1 or 0; 0 before a solve | | Nodes, Engine
Engine | Returns the name of the engine that ran the last solve. | a text such as "engine floor (Zig simplex + branch-and-bound)"; the empty text before a solve | | Why
Why | Returns the solver's account of itself: the tier chosen, the result, the objective and the point, and the work done. | a text; "nothing has been solved yet" before a solve | | ShowWhy, Engine | | for an infeasible or unbounded model it states the result and gives no point
ShowWhy | Prints what Why returns. | nothing; it prints | | Why
Violations | Checks the reported answer against every constraint, bound and whole-value requirement, to catch a confident wrong answer. | a list of [ name, left side, operator, right side ] rows, one per breach; [ ] when none, and also [ ] unless the status is optimal | | IsFeasibleAnswer, Solution | | a tolerance of 0.000001 is allowed
IsFeasibleAnswer | TRUE if Violations finds no breach. | TRUE or FALSE | | Violations | | it is also TRUE when nothing has been solved or the model is infeasible, because Violations is empty then
