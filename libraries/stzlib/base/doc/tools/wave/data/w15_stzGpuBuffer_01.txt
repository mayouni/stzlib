init | Wraps a buffer that lives on the GPU, given as its engine id and its element count. | nothing; the object is built | paIdCount=a list [ nEngineBufferId, nElementCount ], as stzGpu.UploadQ builds it | Id_, Count | the object holds only two numbers, so copies of it share the same device buffer
Id_ | Returns the engine id of the device buffer, 0 once the buffer was freed through this object. | a number | | Count, Free
Count | Returns how many numbers the buffer holds. | a number | | Download, Id_
IsAlive | TRUE if the engine still knows the buffer, which is not so after Free or an eviction. | TRUE or FALSE | | Free, Download | run only with ids the engine does not know, where it answered FALSE; no buffer was uploaded
Download | Reads the whole vector back from the device into a list of numbers. | a list of numbers | | Count, ApplyQ | raises an error when the buffer was freed, evicted or lost with the device | not run: it needs a buffer on the GPU, which sleeps on this machine
ApplyQ | Runs a one-input kernel over the buffer on the device and returns the result as a new resident buffer, leaving this one untouched. | a new stzGpuBuffer | oKernel=a stzKernelMaker with exactly one input vector | ApplyWithQ, Download | a kernel with more than one input raises an error that points to stzGpu.ApplyOnQ; a kernel that does not compile raises an error with the engine's message | not run: it dispatches on the GPU
ApplyWithQ | Does the same as the call without scalars, binding the kernel's scalars by name. | a new stzGpuBuffer | oKernel=a stzKernelMaker with exactly one input vector; paScalars=a list such as [ :alpha = 2.5 ] that gives each declared scalar a number | ApplyQ | a scalar missing from the list raises an error naming it instead of binding 0 | not run: it dispatches on the GPU
Free | Frees the device buffer and marks this object empty. | nothing | | IsAlive, Download | Ring has no destructors, so free what you upload; forgotten buffers are evicted first-in-first-out under VRAM pressure and counted | run only on an object with id 0, where it does nothing
