init | Builds a handle on a zip archive path; nothing is read or created until a method is called. | nothing; the object is built | cZipFileName=the path of the archive, existing or to be created | CreateFrom, Exists
CreateFrom | Creates the archive, replacing any existing one, from the files of a list that exist; a missing file is skipped without a message. | the archive path | _aFiles_=the list of file paths; each is stored under the path exactly as given | AddFiles, ExtractTo | raises Files parameter must be a list for anything else; a path given as absolute is stored as absolute, and extracting such an archive ends the Ring process (see ExtractTo) | give relative paths to get entries that extract anywhere
CreateFromSingleFile | Creates the archive from one file, as CreateFrom does for a list of one. | the archive path | cFileName=the file to store, under the path as given | CreateFrom, AddFile
CreateFromDirectory | Raises error R3 today instead of creating the archive from every file of a folder. | nothing; it raises | _cDirPath_=the folder meant to be zipped | CreateFrom | the call FilesInDir does not exist anywhere in the library, so an existing folder raises R3 Calling Function without definition: filesindir; a missing folder raises Directory does not exist | build the file list yourself and call CreateFrom
AddFile | Appends an existing file to an existing archive; the same file added twice is stored twice. | the archive path | cFileName=the file to add, stored under the path as given | AddFiles, CreateFrom | raises File does not exist for a missing file; on an archive that does not exist yet it returns the path and creates nothing, so no entry is added and no error is raised | use CreateFrom to start an archive
AddFiles | Appends the files of a list to an existing archive, skipping those that do not exist; a file already inside is stored a second time. | the archive path | _aFiles_=the list of file paths, each stored as given | AddFile, CreateFrom | raises Files parameter must be a list for anything else; like AddFile, it creates nothing on an archive that does not exist yet
AddString | Raises error R3 today instead of storing a text as an entry of the archive. | nothing; it raises | cEntryName=the entry name meant for the text; cContent=the text meant to be stored | AddFile | the zip_newentry function it calls does not exist (checked by calling it directly), so every call raises R3 Calling Function without definition: zip_newentry | write the text to a file and use CreateFrom
ExtractTo | Extracts every entry under a folder, keeping each entry's own relative path, and returns the folder. | the target folder path | _cTargetDir_=the folder to extract into | ExtractHere, ExtractToNewFolder, ListContents | raises Zip file does not exist for a missing archive; an archive whose entries have absolute paths ends the Ring process at once with exit 127 and no message when the folder already exists, and extracts nothing when it does not | create the archive with relative paths, as CreateFrom explains
ExtractHere | Extracts the archive into the folder that holds it. | the folder path, . when the archive path has none | | ExtractTo, ExtractToNewFolder | raises Zip file does not exist for a missing archive; the same absolute-path risk as ExtractTo
ExtractToNewFolder | Extracts the archive into a new folder beside it, named like the archive without its extension. | the folder path, such as here/nf for here/nf.zip | | ExtractTo, ExtractHere | raises Zip file does not exist for a missing archive; the same absolute-path risk as ExtractTo
ListContents | Returns the names of the entries, exactly as stored, in the order they were added. | a list of text | | FileCount, Contains | raises Zip file does not exist for a missing archive | a file stored twice is listed twice
FileCount | Returns how many entries the archive holds, 0 for a missing or unreadable archive. | a number | | ListContents, IsEmpty
Contains | TRUE if an entry has exactly this name, as stored: a file added by absolute path matches only by that path. | 1 or 0, numbers | cFileName=the entry name | ListContents | raises Zip file does not exist for a missing archive
IsEmpty | TRUE if the archive holds no entry, which is also true when it does not exist. | 1 or 0, numbers | | FileCount, Exists
Size | Returns the size of the archive file, but 0 for an archive that holds files. | a number; 98 for an archive with no entry, 0 today for a non-empty one | | FileName, Exists | the size is counted as characters of the file read as text, which gives 0 for the compressed bytes of a non-empty archive (a 478-byte archive reads 0, an empty one reads 98); use len(read(path)) for the byte count | 0 also means the archive does not exist
FileName | Returns the archive path given at birth, or the new path after a MoveTo. | a text | | MoveTo, Exists
Exists | TRUE if the archive file exists on disk. | 1 or 0, numbers | | FileName, Delete
Delete | Removes the archive file; an archive that is already gone is not an error. | nothing | | Exists, MoveTo
CopyTo | Copies the archive file to another path and tells whether the copy is there. | 1 or 0, numbers | cDestination=the path of the copy | MoveTo | raises Can't create/open the file (R35) when the archive does not exist
MoveTo | Copies the archive to another path, removes the original and makes the object point at the new path. | 1 if the copy exists, else 0 | cDestination=the new path | CopyTo, FileName | raises Can't create/open the file (R35) when the archive does not exist
