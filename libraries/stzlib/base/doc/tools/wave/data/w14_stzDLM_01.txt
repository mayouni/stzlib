init | Builds an empty domain language model for a named domain, to be filled by hand or forged from a knowledge graph. | nothing; the object is built | pcDomain=the domain name, which answers that are refused quote | SetDomain, ForgeFrom, Save | | StzDlmQ forges one straight from a stzKnowledgeGraph, taking the graph's id as the domain
SetDomain | Renames the domain the model answers for. | nothing | pcDomain=the new domain name | Domain, init
Domain | Returns the domain name. | a text | | SetDomain
ForgeFrom | Fills the model from a knowledge graph: is-a facts become entities, other facts become facts, constraints become laws, in lower case. | the model itself, so calls chain | poKG=the stzKnowledgeGraph to forge from | LearnEntity, LearnFact, LearnLaw | | the domain name is not changed; nothing already learned is duplicated
LearnEntity | Adds an entity of a given type, so the model can say what it is. | the model itself, so calls chain | pcName=the entity's name; pcType=its type | LearnFact, Lexicon, Ask | a name written with capitals is stored as written, but Ask and Complete lower-case what they are given, so Pizza learned by hand is never found: learn lower-case names | an entity may bear several types; the same pair twice is kept once
LearnRelation | Adds a relation name the model may be asked about. | the model itself, so calls chain | pcRel=the relation's name, such as contains | LearnFact, Lexicon | | LearnFact adds its relation by itself
LearnFact | Adds a fact of the form subject, relation, object, and the relation with it. | the model itself, so calls chain | pcS=the subject; pcP=the relation; pcO=the object | LearnEntity, LearnRelation, Ask | names written with capitals are stored as written and are not found by Ask or Complete, which lower-case their input | the same triple twice is kept once
LearnLaw | Records a law of a relation, such as transitive, which is saved with the model. | the model itself, so calls chain | pcRel=the relation the law governs; pcLaw=the law's name | ForgeFrom, Save | no method of the model reads the laws today: Ask answers from the recorded facts only, so a transitive law adds no chained answer | the same pair twice is kept once
Lexicon | Returns the model's vocabulary: its entities, their types and its relations. | a hash list with the keys entities, types and relations, each a list of texts | | LearnEntity, Tokenizer
Ask | Answers a question from the recorded facts, or refuses when it is outside the domain. | a text, the answer or the refusal | pcQuestion=the question, in lower or upper case | Why, Complete, AddGolden | a question that names no known entity gets a refusal that quotes the domain and the counts, not an invented answer; an entity learned with capitals is not recognized | what is X lists the types of X; X followed by a relation lists its objects; the reason of the last call is in Why
Complete | Returns what may follow a word: an entity's relations, a relation's objects, or the entities that start with a fragment. | a list of texts; an empty list when nothing matches | pcPartial=the entity, relation or fragment, lower-cased before matching | Ask, Lexicon | | the three readings are tried in that order and the first with a result wins
GenerateCorpus | Returns every entity and fact as a short sentence, the teacher-free training text of the neural rung. | a list of texts | | TrainNeuralRung, Tokenizer | | an entity gives name is a type, and a fact gives subject relation object
Tokenizer | Returns the closed vocabulary of the domain, with the unknown-word marker first. | a list of texts, the first being <unk> | | Tokenize, Lexicon
Tokenize | Returns the vocabulary position of each word of a text. | a list of numbers, one for each word | pcText=the text to split into words | Tokenizer | | a word outside the vocabulary gives 1, the position of <unk>; text is lower-cased and full stops are dropped
Why | Returns the reason behind the last Ask. | a text; empty before any question | | Ask
TrainNeuralRung | Trains a small bigram network on the domain's own sentences, so that it can predict which word follows which. | the model itself, so calls chain | nEpochs=the number of passes over the corpus; a value below 1 means 300 | NextToken, NeuralWhy, GenerateCorpus | raises an error when the domain holds nothing to learn | no remote teacher is used; the deterministic answers of Ask are not affected
IsNeuralTrained | TRUE if the neural rung has been trained. | TRUE or FALSE | | TrainNeuralRung
NeuralWhy | Returns a summary of the last training: pairs, vocabulary size, epochs and loss. | a text; empty before training | | TrainNeuralRung
NextToken | Returns the word the neural rung predicts to follow a word. | a text | pcWord=the word, lower-cased before use | NextTokenConfidence, NeuralGenerate | raises an error before TrainNeuralRung; a word outside the vocabulary is read as the unknown marker | a bigram sees one word, so it predicts the most frequent follower of the corpus
NextTokenConfidence | Returns the probability the neural rung gives to the word it predicts. | a number between 0 and 1 | pcWord=the word, lower-cased before use | NextToken | raises an error before TrainNeuralRung
NeuralGenerate | Returns a seed word followed by the words the neural rung predicts one after the other. | a text of words separated by spaces | pcSeed=the first word; nSteps=how many words to add; a value below 1 means 4 | NextToken | raises an error before TrainNeuralRung | the rung learns word transitions of the corpus and does not own the truth, which stays with Ask; the text can wander
ExportNeuralGguf | Writes the trained neural rung to a GGUF file. | the path of the file written | pcFile=the path of the file to write | TrainNeuralRung | raises an error before TrainNeuralRung
AddGolden | Records a question with the answer it must always give, to be checked by RunGoldens. | nothing; use AddGoldenQ to chain | pcQuestion=the question to ask; pcExpected=the exact answer expected | RunGoldens, Ask | | the same pair twice is kept twice
RunGoldens | Asks every recorded question and compares each answer with the expected one. | a hash list with the keys total, passed and failed, the last a list of hash lists with question, expected and got | | AddGolden, Ask
LoadFrom | Reads a saved bundle into this model, so it answers without the original graph. | the model itself, so calls chain | pcFile=the path of a bundle written by Save | Save | raises an error when the file cannot be opened | it adds to what the model already holds and sets the domain name from the file; a name with a vertical bar was not saved readable and is dropped silently
Save | Writes the domain, entities, relations, facts, laws and goldens to a text bundle. | the path written, with the .zdlm extension added when missing | pcFile=the path to write | LoadFrom | | a name that contains a vertical bar cannot be read back by LoadFrom; the neural rung is not saved
