# w14 stzListGetter -- Name | brief | returns | params | see | warning | note
init | Builds a getter over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to read from, or a stzList whose content is copied, any other value raises an error | Content, NthItem | | the getter works on its own copy and never changes the list or the stzList you passed in
Content | Returns the whole list the getter reads from. | a list | | List, NumberOfItems
List | Returns the whole list the getter reads from. | a list | | Content, NumberOfItems | | the same answer as Content
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
NthItem | Returns the item at a position, counting from 1. | the item found | _n_=the position of the item, from 1 | FirstItem, LastItem, ItemsAtPositions | a position outside the list raises error R2 Array Access (Index out of range) instead of answering an empty value; 0 and a negative position raise it too | the named form NthItem([ :At, 3 ]) is accepted
FirstItem | Returns the first item of the list. | the item found | | LastItem, NthItem, Head | on an empty list it raises error R2 Array Access (Index out of range)
LastItem | Returns the last item of the list. | the item found | | FirstItem, NthItem, Tail | on an empty list it raises error R2 Array Access (Index out of range)
CentralItem | Returns the item in the middle of the list, the left one of the two middle items when the count is even. | the item found | | FirstItem, LastItem, NthItem | on an empty list it raises error R2 Array Access (Index out of range) | the position is the count divided by 2, rounded up
NFirstItems | Returns the first n items, in their order. | a list | _n_=how many items to take from the start | NLastItems, Head, Section | an n larger than the list raises error R2 Array Access (Index out of range) instead of answering the whole list; 0 gives [ ] | NFirstItemsQ returns the answer as a stzList, and Head is the same call
NLastItems | Returns the last n items, in their order. | a list | _n_=how many items to take from the end | NFirstItems, Tail, Section | an n larger than the list raises error R2 Array Access (Index out of range) instead of answering the whole list; 0 gives [ ] | NLastItemsQ returns the answer as a stzList, and Tail is the same call
ItemsAtPositions | Returns the items found at the given positions, in the order the positions are given. | a list | panPositions=the positions to read, each from 1 | NthItem, Section | a position outside the list raises error R2 Array Access (Index out of range) | ItemsAt is the same call, and a position may be repeated
Section | Returns the items from one position to another, both included. | a list | _n1_=the first position; _n2_=the last position | Range, NFirstItems | | positions are forgiven: a start below 1 becomes 1, an end past the list becomes the last position, and a start larger than the end is swapped with it, so Section(4, 2) answers the same as Section(2, 4); ItemsBetween is the same call
Range | Returns a run of items given its first position and how many items it holds. | a list | pnStart=the first position; pnRange=how many items to take | Section, NFirstItems | a count of 0 does not give [ ]: Range(2, 0) on a b c answers a b, because the end position falls before the start and Section swaps them | a count that runs past the end is cut at the end of the list
UniqueItems | Returns the items without repeats, each kept at its first position. | a list | | Content, EveryNthItem | | UniqueItemsCS(0) also folds capital and small letters, so a and A count as one, while UniqueItems is case sensitive; the items stay in their first-seen order
RandomItem | Returns one item picked at random. | the item picked | | NRandomItems, NthItem | on an empty list it raises error R2 Array Access (Index out of range) | the answer changes from call to call
NRandomItems | Returns n different items picked at random, as a list. | a list | _n_=how many items to pick | RandomItem, NFirstItems | | an n equal to or larger than the list answers every item, in a shuffled order; 0 gives [ ]; the answer changes from call to call
EveryNthItem | Returns the items at positions n, 2n, 3n and so on. | a list | _n_=the step between two picked positions | Head, Tail, Section | | the first item is not picked unless n is 1; an n of 0 or larger than the list gives [ ]; EveryNth is the same call and EveryNthItemQ returns a stzList
OnlyStrings | Returns the items that are texts, in their order. | a list | | OnlyNumbers, OnlyLists, OnlyChars | | a text of Hebrew, Arabic or an emoji is a string like any other
OnlyNumbers | Returns the items that are numbers, in their order. | a list | | OnlyStrings, OnlyLists
OnlyLists | Returns the items that are lists, in their order. | a list | | OnlyStrings, OnlyNumbers
OnlyChars | Returns the texts that are made of a single character, in their order. | a list | | OnlyStrings | a single character that is not plain ASCII is missed: "é", "ש", "ا" and an emoji are left out, because a character counts as one only when its text is one byte long (["é", "😀", "x", "ا", "xy"] answers just "x") | read Hebrew, Arabic and accented single letters through OnlyStrings
Pairs | Returns each item together with the one after it, as two-item lists. | a list of pairs | | Triplets, SlidingWindow | | a list of n items gives n minus 1 pairs, and fewer than 2 items give [ ]; PairsQ returns a stzList
Triplets | Returns each run of three neighbouring items, as three-item lists. | a list of triplets | | Pairs, SlidingWindow | | a list of n items gives n minus 2 triplets, and fewer than 3 items give [ ]; TripletsQ returns a stzList
SlidingWindow | Returns every run of n neighbouring items, moving one position at a time. | a list of lists | _n_=the size of each window | Pairs, Triplets | | an n larger than the list or 0 gives [ ]; SlidingWindowQ returns a stzList
