# w15 stzGraphGoal
init | Builds a goal with a name and no pattern yet. | nothing; the object is built | pcName=the name of the goal | RequireEveryHas, FromMeans | | the goal holds only the declared pattern and never stores a graph; the graph is passed in when it is judged
Name_ | Returns the name the goal was built with. | the name as text | | Narrate, TypeName | |
Why | Returns the reason text of the goal. | the reason as text; always an empty text today | | Narrate | | nothing in the library sets a reason, so it answers an empty text whatever the goal holds
TypeName | Returns the type every instance must belong to, in lower case. | the type as text; an empty text before a pattern is set | | RelationName, RequireEveryHas | |
RelationName | Returns the label of the outgoing edge every instance must carry, in lower case. | the label as text; an empty text before a pattern is set | | TypeName, RequireEveryHas | |
RequireEveryHas | Sets the pattern directly: every instance of a type must have an outgoing edge with a label. | the goal itself, so calls chain | pcType=the type name, lowercased on the way in; pcRelation=the edge label every instance must carry, lowercased on the way in | FromMeans, GapOn | | an instance is a node with an edge labelled isa into the type's node
FromMeans | Reads a sentence of the form every :Type Has(:relation) and sets the pattern from it. | the goal itself, so calls chain | pcMeans=the sentence; text after the Has(:relation) clause is ignored | RequireEveryHas, GapOn | a sentence with no every :Type clause, no Has(:relation) clause or an unclosed Has(: raises error stzGraphGoal.FromMeans: ... naming the missing clause; a time qualifier such as Within(7) is skipped, not checked | the match is on lower-case text
GapOn | Returns the instances that break the goal: those with no outgoing edge carrying the required label. | a list of node ids; [ ] when every instance has the edge | poGraph=the live stzGraph to judge | SatisfiedOn, RequireEveryHas | a goal with no pattern raises error stzGraphGoal.GapOn: the goal ... has no pattern | an instance is a node with an edge labelled isa into the type's node; the label is compared in lower case
SatisfiedOn | TRUE if no instance breaks the goal on a graph. | TRUE or FALSE, as 1 or 0 | poGraph=the live stzGraph to judge | GapOn | a goal with no pattern raises the same error as GapOn |
Narrate | Returns the goal as one sentence, with its name, type and relation. | a text such as goal fed: every dish has(price) | | FromMeans, Name_ | | before a pattern is set the type and the relation read as empty text
