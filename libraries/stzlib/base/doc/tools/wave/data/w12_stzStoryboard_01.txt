init | Builds a storyboard of frames about one picture, named so that its frame files are named after it. | nothing; the object is built | pcName=the storyboard's name, which starts the name of every frame file; poPicture=the picture the frames are about, such as a stzMathDiagram; pcFolio=the folder that receives the frame files and the page, or an empty text for the current folder | Frame, Folio, PictureName | an empty name raises stzStoryboard: a storyboard needs a name, and a picture that is not an object raises give the picture the frames are about; the folder must already exist | the storyboard keeps its own copy of the picture, so changes must go through the storyboard
Frame | Closes the frame being built, if any, and opens a new one with its caption, whose {holes} are filled when it closes. | the storyboard itself, so calls chain | pcCaption=the sentence of the frame, with a hole written {name} wherever a number from a fact goes | FrameOf, Bind, Caption | the marks of earlier frames stay on the picture: use ClearMarks to start a frame clean; closing a frame draws the picture to a PNG file and prints the gate's line pictures judged | FrameQ is the same call; a frame closes by itself when another is opened or any question about the frames is asked
FrameOf | Closes the frame being built and opens a new one on a different picture, which becomes the picture of the storyboard. | the storyboard itself, so calls chain | poPicture=the picture this frame and the next ones are about; pcCaption=the sentence of the frame, with its holes | Frame, Bind | a picture that is not an object raises give the picture this frame is about | FrameOfQ is the same call
ExpectFindings | Says the open frame is about a picture the gate finds fault with, so the findings are its subject and not its failure. | the storyboard itself, so calls chain | | Judge, ExpectsFindings, FindingsOf | a frame that expects findings and gets none is itself reported by Judge, as expected_a_finding_and_got_none; with no frame open it raises open a frame first
Bind | Ties a hole of the open frame to a fact read from the picture when the frame closes, and returns the storyboard. | the storyboard itself, so calls chain | pcHole=the hole's name, as written between braces in the caption; pcKind=the kind of fact, such as :value or :distance; paArgs=the list of arguments of that fact, such as [ "B.icon.r" ] | BindFact, Fact, Caption | with no frame open it raises open a frame first; a hole the caption never quotes is reported by Judge as fact_bound_but_never_shown | BindQ is the same call; the number is read at close, so a later action in the same frame still moves it
BindFact | Ties a hole to a fact handed in whole, from another plane, and returns the storyboard. | the storyboard itself, so calls chain | pcHole=the hole's name, as written between braces in the caption; paFact=a fact, as Fact() answered it or StzFact() built it, with at least a value and a message | Bind, Judge | a list that is not a fact raises that is not a fact; with no frame open it raises open a frame first | BindFactQ is the same call; {name.message} and {name.unit} show the fact's sentence and unit
Show | Draws on the picture the boundary a rule states, such as the circle of a leash, for the open frame. | the storyboard itself, so calls chain | pcRule=words that appear in the rule's own line, such as disjoint or lessthan v111 | Region, Emphasis, ClearMarks | with no frame open it raises open a frame first; words that match no rule raise an error saying a rule is addressed by words from its own line | tested on a sets picture: a thin circle appeared around the smaller set
Region | Tints on the picture the area a clearance rule forbids, for the open frame. | the storyboard itself, so calls chain | pcRule=words that appear in the rule's own line, such as disjoint | Show, ClearMarks | with no frame open it raises open a frame first; words that match no rule raise the same error as Show | tested on a sets picture: a pink disc appeared around the smaller set
Measure | Draws on the picture a line between two things, with its length written beside it, for the open frame. | the storyboard itself, so calls chain | pcA=the first thing, such as A.icon; pcB=the second thing, such as B.icon; paOpts=the options list, or an empty list | Callout, Fact | with no frame open it raises open a frame first | the length is read from the picture; in the test the label was drawn far from the line, at the bottom of the larger set
Callout | Writes a short text with a leader line pointing at a thing on the picture, for the open frame. | the storyboard itself, so calls chain | pcTarget=the thing pointed at, such as B.icon; pcText=the text to write; paOpts=the options list, or an empty list | Measure, Emphasis | with no frame open it raises open a frame first; the gate may find the text overlapping a name, as it did in the test, and Judge then reports it
Emphasis | Marks a thing on the picture for the open frame, as a ring around it, a stronger stroke or a dimmed one. | the storyboard itself, so calls chain | pcTarget=the thing to mark, such as B.icon; pcMode=:ring, :focus or :dim | Callout, ClearMarks | with no frame open it raises open a frame first; any other mode raises an error naming the three | the ring was drawn in orange around the smaller set
ClearMarks | Removes every mark the picture carries, so the open frame starts clean. | the storyboard itself, so calls chain | | Emphasis, Callout, Show | with no frame open it raises open a frame first | marks stay from frame to frame until this call
WindowOn | Shows only a part of the picture for the open frame: the window centred on a thing, with some reach around it. | the storyboard itself, so calls chain | pcPath=the thing to centre on, such as B.icon; pnReach=how far around it to show, in pixels | SetWindow, ClearWindow | with no frame open it raises open a frame first; a mark outside the window is reported by Judge as mark_inside_the_window | in the test the window was scaled up to the whole canvas
SetWindow | Shows only a part of the picture for the open frame: a window given by its centre and its size. | the storyboard itself, so calls chain | pnCx=the x of the window's centre, in pixels; pnCy=the y of its centre; pnW=its width; pnH=its height | WindowOn, ClearWindow | with no frame open it raises open a frame first; a width or height that is not positive raises an error
ClearWindow | Shows the whole picture again for the open frame. | the storyboard itself, so calls chain | | WindowOn, SetWindow | with no frame open it raises open a frame first
Act | Changes the picture between two frames with one of its verbs, so the next frame shows what the change did. | the storyboard itself, so calls chain | pcVerb=DragTo, SetData or SetTheme; paArgs=the verb's arguments: a shape, an x and a y for DragTo; an object, a key and a number for SetData; the theme's name for SetTheme | Frame, ClearMarks | any other verb raises that it is not an action a frame takes, and too few arguments for DragTo or SetData raise an error naming what is needed; with no frame open it raises open a frame first | with SetTheme dark the paper was dark grey and the sets pale grey
NumberOfFrames | Returns how many frames were written, closing the open one first. | a number | | Caption, FileOf
Caption | Returns the sentence of a frame with its holes filled by the facts. | a text | pnI=the frame's position, from 1 | RawCaption, HolesOf | a position out of range raises an error | it closes the open frame first
RawCaption | Returns the sentence of a frame as it was written, with its holes still open. | a text | pnI=the frame's position, from 1 | Caption | a position out of range raises an error
FileOf | Returns the name of the PNG file of a frame, inside the folio. | a text such as sets_01.png | pnI=the frame's position, from 1 | Folio, Render | a position out of range raises an error
HolesOf | Returns the holes of a frame with the fact each one was filled from. | a list of [ hole, fact, shown text, expected texts ] | pnI=the frame's position, from 1 | Bind, NumberOfHoles | a position out of range raises an error
FindingsOf | Returns what the picture gate found against a frame, as findings. | a list of findings; empty when the frame is lawful | pnI=the frame's position, from 1 | Judge, ExpectsFindings | a position out of range raises an error
ExpectsFindings | TRUE if the frame was declared to be about something the gate finds. | 1 or 0 | pnI=the frame's position, from 1 | ExpectFindings, Judge | a position out of range raises an error
NumberOfHoles | Returns how many numbers the frames show, all of them read from facts. | a number | | HolesOf, Judge
Judge | Returns the faults of the storyboard: what the gate found in each frame, and each hole checked against its fact. | a list of findings; empty when every frame and every number holds | | IsClean, FindingsOf, ExpectFindings | the rules are hole_left_open, fact_bound_but_never_shown, hole_not_filled_from_its_fact and expected_a_finding_and_got_none, besides the gate's own findings | a frame declared with ExpectFindings does not fail for what the gate finds in it
IsClean | TRUE if Judge finds nothing. | 1 or 0 | | Judge
Render | Writes the page that puts the frames in order with their sentences and the verdict, and returns its path. | a text, the path of the HTML page | | ToNarration, Rendition | | the page is named after the storyboard and sits in the folio, beside the frame files
ToNarration | Writes the storyboard as a .narration document, with each caption as prose with its holes open and each number as a cell. | a text, the path written | pcPath=the file to write | Render | | the format is the sibling narration grammar v0; the document keeps no output
Rendition | Returns the storyboard as a value that says it is markup, the page of its frames. | a rendition of the kind markup | | RenditionAs, RenditionKinds
RenditionKinds | Returns the forms the storyboard can take as a value. | a list: markup and text | | RenditionAs
RenditionAs | Returns the storyboard as a value of the kind asked: markup, the HTML page, or text, the numbered captions. | a rendition value with its kind, its media type and its content | pcKind=markup or text | Rendition, Render | any other kind raises that it is not a way a storyboard shows itself | text gives one numbered line per caption
Fact | Reads a fact from the picture as it stands now, without changing it. | a fact, as a hashlist with its kind, subject, value, unit, where and message | pcKind=the kind of fact, such as :value or :distance; paArgs=the list of arguments of that fact | Bind, BindFact | | Fact(:value, [ "B.icon.r" ]) gave 46.40 px for the smaller set in the test
PictureName | Returns the storyboard's name. | a text | | Folio, FileOf
Folio | Returns the folder that receives the frame files and the page. | a text; a point when none was given | | FileOf, Render
