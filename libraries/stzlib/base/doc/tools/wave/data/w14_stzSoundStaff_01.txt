init | Builds a staff drawing of a score, in 4/4 and 1000 pixels wide until told otherwise. | nothing; the object is built | poScore=the stzSoundScore to draw | StzSoundStaffQ, ToSVG | nothing is drawn until ToSVG, ToHTML or SaveAs is called; the score is not changed
SetMeter | Sets the time signature of the drawing. | the staff itself, so calls chain | pnBeats=the number of beats in a bar, 1 to 32; pnUnit=the note value that counts a beat: 2, 4, 8 or 16 | MeterChangeAt, Meters | a bad meter is refused, with LastError set, and the old one stays
SetWidth | Sets the width of the drawing in pixels, which decides where systems break. | the staff itself, so calls chain | pnPixels=the width in pixels, 400 or more | Systems, ToSVG | a smaller value is ignored without a message; 500 pixels broke an eight-note score into 2 systems where 1000 gave 1
SetKey | Sets the key signature drawn, instead of reading it from the music. | the staff itself, so calls chain | pKey=auto to read it from the music, none, a key such as D, Bb, F#m or Ddor, or a number of fifths from -7 for seven flats to 7 for seven sharps | SetKeyOfMode, KeyChangeAt | a bad key is refused, with LastError set, and the old setting stays | the key also spells the notes: with one flat the note between A and B is written B flat
SetKeyOfMode | Sets the key signature from a declared mode, spelling its seven degrees on consecutive letters, quarter tones included. | the staff itself, so calls chain | pUniverse=the universe, such as maqam; pMode=the mode's name, or an empty text for the universe's own | SetKey, KeyChangeOfModeAt | a mode that does not have seven degrees, or a degree that no signature can write, is refused, with LastError set | maqam hijaz gives B flat, E flat and F sharp
MeterChangeAt | Asks for a new time signature from the barline at or after a beat. | the staff itself, so calls chain | pnBeat=the beat from which the new meter applies, 0 or later; pnBeats=the number of beats in a bar, 1 to 32; pnUnit=the note value that counts a beat: 2, 4, 8 or 16 | SetMeter, Meters | a bad beat or meter is refused, with LastError set; a beat inside a bar moves to the next barline | the change is drawn after the drawing is made
Meters | Returns the time signature of the first bar and of every bar where it changes. | a list of [ bar, beats, unit ] rows with bars counted from 1; [ ] before a drawing is made | | MeterChangeAt, SetMeter | filled by ToSVG, ToHTML or SaveAs
KeyChangeAt | Asks for a new key signature from the barline at or after a beat. | the staff itself, so calls chain | pnBeat=the beat from which the new key applies, 0 or later; pKey=a key such as E or F#m, a number of fifths from -7 to 7, or none | KeyChangeOfModeAt, SetKey | a bad beat or key is refused, with LastError set; a beat inside a bar moves to the next barline | a change is drawn with a double barline and the naturals that cancel the old key
KeyChangeOfModeAt | Asks for a new key signature taken from a declared mode, from the barline at or after a beat. | the staff itself, so calls chain | pnBeat=the beat from which the new key applies, 0 or later; pUniverse=the universe, such as maqam; pMode=the mode's name, or an empty text for the universe's own | KeyChangeAt, SetKeyOfMode | a bad beat, an unknown universe or a mode without seven degrees is refused, with LastError set
SetKeyChanges | Chooses whether key changes are looked for in the music when the key is read from it. | the staff itself, so calls chain | pbFind=TRUE to find changes, which is the default, FALSE to keep one key throughout | KeyChanges, SetKey | a change is found only where it saves more accidentals than it costs | measured on a 16-note score that climbs through sharps: with TRUE it was written in C major with a change to B major at bar 3, with FALSE in E major throughout
KeyChanges | Returns every key after the first, with the bar where it begins. | a list of [ bar, key text ] rows with bars counted from 1; [ ] when the key never changes or before a drawing is made | | KeyChangeAt, SetKeyChanges | filled by ToSVG, ToHTML or SaveAs
Key | Returns the key signature that was drawn, in drawing order. | a list of [ letter, alteration ] rows, the alteration -1 for a flat, 1 for a sharp and -0.5 for a half-flat; [ ] for none or before a drawing is made | | KeyName, SetKey | filled by ToSVG, ToHTML or SaveAs
KeyName | Returns the drawn key signature in words. | a text such as D major (2 sharps) or no key signature; an empty text before a drawing is made | | Key, SetKey | filled by ToSVG, ToHTML or SaveAs
Losses | Returns what the drawing could not show exactly. | a list of text, such as a pitch drawn at the nearest quarter tone with its distance in cents; [ ] when nothing was lost | | Model | filled by ToSVG, ToHTML or SaveAs | a pitch more than 5 cents from the nearest quarter tone is drawn there and counted here
LastError | Returns the reason the last setting was refused, or an empty text. | a text | | SetKey | it is never cleared by a later success
Model | Returns every mark of the drawing as data, before it is written as SVG. | a list of rows whose first item is the kind: lines, clef, keysig, meter, barline, dblbar, system, head, stroke, ledger, acc, dot, flag, beam, tie, rest or openmark; [ ] before a drawing is made | | ToSVG, Losses | a guard can hold the model to the rules of notation without reading pixels; for the score c e g c5 g e c ~ it holds 15 marks, 7 of them heads
Bars | Returns the number of bars of the drawing. | a number; 0 before a drawing is made | | Systems, Meters | an empty score still has 1 bar
Systems | Returns the number of systems, the lines of staves the drawing is broken into. | a number; 0 before a drawing is made | | SetWidth, Bars
Clefs | Returns one row per staff, the instrument and its clef. | a list of [ instrument, clef ] rows, such as piano with treble or drumkit with perc5; [ ] before a drawing is made | | Model | a second voice of the drum kit draws no staff of its own
SaveAs | Writes the drawing to a file, as SVG when the path ends in .svg and as an HTML page otherwise. | the number of characters written | pcPath=the file to write, overwritten; pcTitle=the title drawn above the staff and used as the page title | ToHTML, ToSVG | the drawing has not been seen by a musician (UNPERCEIVED) | measured: an eight-note score gave 2816 characters of SVG and 3105 of HTML
ToHTML | Returns a complete HTML page holding the drawing, to open in any browser. | a text starting with a doctype | pcTitle=the title drawn above the staff and used as the page title | ToSVG, SaveAs | the title is escaped; the page needs no font for any mark but the clefs, which use the Unicode musical symbols block
ToSVG | Lays the score out on the staff and returns the drawing as SVG. | a text starting with an svg element | pcTitle=the title drawn above the staff | ToHTML, Model | the layout is computed first and the SVG written second, so asking twice gives the same text; it fills Model, Bars, Key and the other readers
