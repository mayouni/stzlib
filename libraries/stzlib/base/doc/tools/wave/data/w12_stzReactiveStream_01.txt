Init | Builds a stream with an id, a kind of source and the system that serves it; an unknown source kind becomes manual. | nothing; the object is built | id=the stream's name, as text; sourceType=the kind of source: manual, libuv, timer, file, network or sensor; engine=the stzReactive system that created it | Start, Recieve | a stream built with new is inactive and ignores every value until Start is called; CreateStream of stzReactive starts it for you | the kind of source only labels the stream
Transform | Adds a step that replaces each value by the result of a function, then returns the stream; steps run in the order they were added. | the stream itself, so calls chain | mapFunction=a function taking one value and returning the new value | Filter, Accumulate, OnPassed | | Map is the same call
Filter | Adds a step that lets a value go on only when a function answers true for it, then returns the stream. | the stream itself, so calls chain | filterFunction=a function taking one value and returning TRUE to keep it | Transform, Accumulate, OnPassed | | Where is the same call
Accumulate | Adds a step that folds all the values into one running result, which the subscribers receive only when the stream concludes. | the stream itself, so calls chain | reduceFunction=a function taking the running result and the new value and returning the new result; initialValue=the result before the first value | Conclude, OnNoMore, Transform | with this step the subscribers get nothing per value; they get the final result once, at Conclude | Reduce is the same call
OnPassed | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | Transform, Filter, Accumulate | | OnRecieved, OnReceived, Subscribe, OnNext and OnPass are the same call
OnRecieved | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | OnPassed, Subscribe | | the same call as OnPassed
OnReceived | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | OnPassed, Subscribe | | the same call as OnPassed
Subscribe | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | OnPassed, OnNext | | the same call as OnPassed
OnNext | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | OnPassed, Subscribe | | the same call as OnPassed
OnPass | Registers a function called with each value that comes out of the steps, then returns the stream. | the stream itself, so calls chain | _Rf_=a function taking one value | OnPassed, Subscribe | | the same call as OnPassed
OnError | Registers a function called with the error text when CheckErrorHandling reports one, then returns the stream. | the stream itself, so calls chain | errorHandler=a function taking the error | CheckErrorHandling, Stop | an error raised inside a step or a subscriber is not routed here: it reaches the caller of Recieve
OnNoMore | Registers a function called, with no argument, when the stream concludes, then returns the stream. | the stream itself, so calls chain | concludeHandler=a function taking no argument | Conclude, Accumulate | | OnComplete is the same call
Recieve | Takes one value into the stream and, when no overflow strategy is set, runs it through the steps and the subscribers at once. | nothing | data=the value to take in, of any type | OnPassed, Transform, Conclude, SetOverflowStrategy | ignored without any error when the stream is stopped or concluded; with an overflow strategy set, the value is only buffered until ProcessAnItemFromBuffer or ProcessAllInBuffer runs | Feed, FeedWith, Emit, Send and Receive are the same call
SetAutoConclude | Turns automatic conclusion on or off and returns the stream; turning it off cancels a pending timer. | the stream itself, so calls chain | enabled=1 to conclude by itself after a quiet delay, 0 to conclude only by Conclude | SetAutoConcludeDelay, AutoConclude, Conclude | | on by default; SetAutoComplete is the same call
SetAutoConcludeDelay | Sets the quiet time, in milliseconds, that precedes automatic conclusion, and returns the stream. | the stream itself, so calls chain | pnMilliseconds=the delay, a number not below 0 | SetAutoConclude, ScheduleAutoConclude | a value that is not a number or is negative is ignored and the old delay stays | the default is 100
ScheduleAutoConclude | Starts, or restarts, the timer that concludes the stream when no value is pending after the quiet delay. | nothing | | SetAutoConcludeDelay, AutoConclude, Recieve | the timer is run by the reactive loop, so nothing happens until the loop runs; it acts on a copy of the stream taken now | Recieve calls it after every value
PendingDataCount | Returns how many values were received and not yet processed. | a number | | Recieve, ProcessAnItemFromBuffer
AutoConcludeEnabled | TRUE if the stream concludes by itself after a quiet delay. | 1 or 0 | | SetAutoConclude
ClearAutoConcludeTimer | Forgets the pending timer's id without cancelling it, and returns the stream. | the stream itself, so calls chain | | ScheduleAutoConclude, SetAutoConclude | | the timer calls it when it fires
ScheduleAutoComplete | Starts, or restarts, the timer that concludes the stream when no value is pending after the quiet delay. | nothing | | ScheduleAutoConclude | | the same call as ScheduleAutoConclude
AutoConclude | Concludes the stream if it has an accumulating step or a conclude function and is not already concluded; otherwise does nothing. | nothing | | Conclude, SetAutoConclude | | AutoComplete is the same call
AutoComplete | Concludes the stream if it has an accumulating step or a conclude function and is not already concluded; otherwise does nothing. | nothing | | AutoConclude | | the same call as AutoConclude
Conclude | Ends the stream once: hands the final accumulated result to the subscribers, calls the conclude functions and stops the stream. | nothing | | Accumulate, OnNoMore, Start | a second call does nothing; the stream accepts no value afterwards until Start is called | Complete is the same call
Start | Makes the stream accept values, clears its concluded state, and returns it. | the stream itself, so calls chain | | Stop, Conclude | | CreateStream of stzReactive has already called it
Stop | Makes the stream ignore values until Start is called, and returns it. | the stream itself, so calls chain | | Start, Cleanup
Cleanup | Stops the stream and releases its libuv handle, if it has one. | nothing | | Stop
CheckErrorHandling | Calls every error function with the error and stops the stream; ignored when the stream is stopped or concluded. | nothing | error=the error to report, usually a text | OnError, Stop
SetOverflowStrategy | Sets what happens to a value that arrives when the buffer is full, and the buffer's size, and returns the stream. | the stream itself, so calls chain | _strategy_=:BUFFER, :DROP, :BLOCK or :LATEST, and :BUFFER for any other word; maxBufferSize=how many values the buffer holds | OnOverflow, OverflowStats, ProcessAllInBuffer | once set, Recieve only buffers: nothing reaches the subscribers until ProcessAnItemFromBuffer or ProcessAllInBuffer runs; :LATEST evicts the oldest value, and the three other strategies refuse the new one, and every loss is counted as dropped | SetBackpressureStrategy is the same call
OnOverflow | Registers a function called as f(buffered, size) each time a value arrives while the buffer is full, then returns the stream. | the stream itself, so calls chain | handler=a function taking two arguments, how many values are buffered and the buffer's size | SetOverflowStrategy, OverflowStats | | OnBackpressure is the same call
OnBufferFull | Registers a function meant to be called when the buffer is full, then returns the stream. | the stream itself, so calls chain | handler=a function taking no argument | OnOverflow | the function is stored and never called: in the four strategies tested, a full buffer called OnOverflow handlers and no OnBufferFull handler
HandleOverflow | Calls the overflow functions, then drops the value that met a full buffer or evicts the oldest one, by strategy. | nothing | data=the value that did not fit | SetOverflowStrategy, OnOverflow | calling it directly also counts the value as dropped | HandleBackpressure is the same call
ProcessAnItemFromBuffer | Takes the oldest buffered value, runs it through the steps and hands it to the subscribers; does nothing when the buffer is empty. | nothing | | ProcessAllInBuffer, Recieve
ProcessAllInBuffer | Processes every buffered value, oldest first, and returns the stream. | the stream itself, so calls chain | | ProcessAnItemFromBuffer, SetOverflowStrategy | | DrainBuffer is the same call
OverflowStats | Returns the buffer's size, how many values it holds, whether it overflowed, how many values were lost, and the strategy. | a hashlist with the keys bufferSize, currentBuffer, isOverflowActive, droppedCount and strategy | | SetOverflowStrategy, HandleOverflow | | the keys are lower case when listed; reading o1.OverflowStats()[:droppedCount] works; BackpressureStats is the same call
