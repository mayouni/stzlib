init | Builds the layout of a console pivot table from its data: measures the content, then computes every width. | nothing; the object is built | aPivotTable=the pivot as a list of rows: a header row (the row labels, then one header per data column holding the two column values joined by a vertical bar, such as 2024 then Q1, then the total label), the data rows, and a last row of totals; aRowDims=the names of the row dimensions; aColDims=the names of the two column dimensions; cTotalLbl=the label of the total column and of the total row | MeasureContentDimensions, CalculateLayout | it needs exactly two column dimensions: one raises error R2, an empty pivot raises it too, and a third is ignored | the measures land in aContentDimensions and the final widths in aCalculatedLayout, two attributes you can read
MeasureContentDimensions | Measures the natural width of the row labels, column headers, data cells and totals, and stores them in aContentDimensions. | nothing | | CalculateLayout, Recalculate | the width kept for a data column is that of the LAST data row, not the widest: a column holding 20 and then 2 is stored as 1 wide; the test that should keep the maximum asks whether a number is a hashlist, which is always false
GetUniqueColumnDimensionValues | Returns the distinct values of each column dimension, read from the two-part headers of the pivot. | a list with one list of text per column dimension, in the order of first appearance | | MeasureContentDimensions, GetDimensionGroupWidth
CalculateLayout | Computes the final widths from the measures and the settings, and stores them in aCalculatedLayout. | nothing | | MeasureContentDimensions, Recalculate, SetSetting | the measured data-cell widths are never used: each data column gets the MinCellWidth setting grown by CellGrowthRatio plus padding, however wide its content, because the lookup asks whether a number is a hashlist; row labels and the total column do use their measures
GetDimensionGroupWidth | Raises error R5 today instead of returning the width of one group of columns. | nothing; it raises Can't access the list item, Object is not list | nDimIndex=the column dimension to measure, which the body does not read | GetCellWidth, CalculateLayout | it reads a variable that belongs to CalculateLayout and is empty here; the same error for 1 and for 2
GetCellWidth | Returns the MinCellWidth setting, whatever the pair of values, instead of the width computed for that data column. | a number: the MinCellWidth setting | _dim1_=the value of the first column dimension, such as 2024; _dim2_=the value of the second, such as Q1 | GetLayoutValue, CalculateLayout | the lookup asks whether a width, which is a number, is a hashlist, which is always false, so the fallback is always taken; with MinCellWidth 5 it answers 5 while the layout holds 8
SetSetting | Sets one display setting, then recomputes the layout. | the config itself, so calls chain | cSetting=the name of the setting, such as MinCellWidth or DefaultPadding; _value_=the new value | Recalculate, GetLayoutValue | the settings are in aSettings: MinCellWidth, MaxCellWidth, MaxHeaderWidth, DefaultPadding, CellGrowthRatio, RowLabelGrowthRatio, MaxTableWidth and others
GetLayoutValue | Returns one entry of the computed layout, but only when that entry is itself a hashlist. | the hashlist of data column widths for DataColumnWidths; an empty text for every other key, numbers and lists included | _cKey_=the layout key, such as DataColumnWidths or TableWidth | CalculateLayout, SetSetting | TableWidth, TotalColumnWidth, LeftPadding and RowLabelWidths all answer an empty text; read aCalculatedLayout directly for them
Recalculate | Measures the content again and recomputes the layout, after the data or a setting changed. | the config itself, so calls chain | | MeasureContentDimensions, CalculateLayout
DebugLayout | Prints the computed dimensions: row label widths, data column widths, total column, table width and left padding. | nothing; it prints | | CalculateLayout, GetLayoutValue | the Data Column Widths part prints no line today, for the same hashlist test as GetCellWidth
