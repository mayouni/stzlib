init | Opens the engine's timeline store, one list of named, timestamped events that every stzEngineTimeline object shares. | nothing; the object is built | | Clear | the store is global to the process: events added through one object are seen by every other
AddEvent | Appends an event with a label and a numeric timestamp to the timeline; the same label may be added twice. | nothing | cLabel=the event's name, a non-empty text; nTimestamp=when it happened, as a number in any unit you choose | EventCount, RemoveEvent | a label that is empty or not a text, and a timestamp that is not a number, raise an error | events keep the order in which they were added
EventCount | Returns how many events the timeline holds. | a number | | AddEvent, Clear
EventLabel | Returns the label of the event at a position, counted from 0 in the order the events were added. | a text; empty when the position is out of range | nIndex=the position of the event, starting at 0 | EventTime, EventCount
EventTime | Returns the timestamp of the event at a position, counted from 0 in the order the events were added. | a number; 0 when the position is out of range | nIndex=the position of the event, starting at 0 | EventLabel, EventCount
EventsBetween | Returns how many events have a timestamp from nStartTime to nEndTime, both included. | a number | nStartTime=the lower end of the time range; nEndTime=the upper end of the time range | EventsSorted, EventTime | a reversed range (end before start) is not refused: it counted every event | it answers a count, not the events themselves
EventsSorted | Returns how many events the timeline holds, after asking the engine to sort them by time. | a number | | EventCount | the labels read back by position keep their insertion order afterwards, so the sort is not visible through EventLabel or EventTime
Duration | Returns 0 on every call today, whatever the events are. | 0 | | EventTime | answered 0 for timestamps 100, 200, 300, then 1000 and 5000, then 2.5 and 9, then 1700000000 and 1700000060, sorted or not; the span between the first and the last event is not computed
RemoveEvent | Removes the event that has a given label. | nothing | cLabel=the label of the event to remove | AddEvent, Clear | an unknown label is silently ignored: the not-found error the code intends is never raised
Clear | Empties the timeline for every object that shares it. | nothing | | EventCount, RemoveEvent
