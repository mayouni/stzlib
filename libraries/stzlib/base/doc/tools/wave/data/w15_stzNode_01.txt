init | Starts a node: a reactor that listens for STZM messages on a TCP port, under a name, ready to dispatch each message to a handler. | nothing; the object is built | pcName=the node's name; 'indexer' binds the loopback address and 'indexer@10.0.0.7' binds that interface; pnPort=the port to listen on, 0 for any free port | Run, Port, On | binds a TCP port when it is built | not run: it opens a listening port, which this documentation pass does not do
Name_ | Returns the node's name, in lower case and without any @host part. | a text | | init
Port | Returns the port the node is actually bound to, which differs from the one asked for when 0 was given. | a number | | init | not run: it needs a node that is listening
SetInbox | Declares the bounded inbox: at most nCap queued messages, and what to do with the next one when it is full. | the node itself, so calls chain | nCap=the most messages the inbox may hold; cPolicy=the overflow policy, :DropOldest, :DropNewest or :Refuse | Overflow, Pending | call it before Run; every overflow is counted by the engine and never silent | not run: it needs a node that is listening
On | Declares the handler for a message tag; a handler's return value is sent back only when the sender asked for a reply. | the node itself, so calls chain | pcTag=the tag of the messages to handle, matched without regard to case; pfHandler=a function that takes the message list [ tag, args... ] and returns the reply | Unhandled, Processed | a handler that raises is not caught: the node dies loudly, on purpose, and its exit is visible from outside; a message with no handler is counted in Unhandled | run on a node built without a reactor, so only the registration was exercised
SecureWith | Makes the node verify signed messages against a signer's keyring. | the node itself, so calls chain | poSigner=a stzRequestSigner holding the shared keyring | RequireSigned, Rejected | a message that fails verification (bad signature, stale, replayed) is refused and counted in Rejected | read from the code, not run: it needs a signer and a live node
RequireSigned | Makes the node refuse every message that is not signed. | the node itself, so calls chain | bYes=1 to refuse unsigned messages, 0 to accept them | SecureWith, Rejected | a refused message is counted in Rejected, and an Ask gets a [ stz.denied, unsigned ] reply | run on a node built without a reactor, so only the flag was exercised
AddActor | Registers an actor identity, so the verified key id of a signed message names the actor whose capabilities gate the admitted tags. | the node itself, so calls chain | poActor=a stzSystemActor, whose Name() is matched to the key id of the sender | Admit, SecureWith | read from the code, not run
Admit | Requires the sender's actor to hold a capability kind before the node serves a tag. | the node itself, so calls chain | pcTag=the tag to protect, matched without regard to case; pcKind=the capability kind the actor must hold: effectful, sensing, compute or inference | AddActor, Denied | an unsigned sender or an unknown actor is denied; each denial is counted in Denied and, on an Ask, answered with [ stz.denied, capability ] | run on a node built without a reactor, so only the registration was exercised
Rejected | Returns how many messages were refused for authentication: a bad signature, a replay, or unsigned when signing is required. | a number | | SecureWith, RequireSigned, Denied
Denied | Returns how many messages were refused for lack of capability. | a number | | Admit, Rejected
Processed | Returns how many messages were handled, including the built-in stz.stop and stz.info. | a number | | Unhandled, Run
Unhandled | Returns how many messages were dropped because no handler matched their tag or because they did not unpack. | a number | | On, Processed
Overflow | Returns how many messages the engine's bounded inbox dropped or refused for lack of room. | a number | | SetInbox, Pending | not run: it needs a node that is listening
Pending | Returns how much unread data the node's server holds. | a number | | Overflow, SetInbox | not run: it needs a node that is listening
Run | Serves messages until stz.stop arrives, Stop is called or the time limit elapses, then stops the server and destroys the reactor. | nothing | nTtlMs=how long to serve at most, in milliseconds | Stop, On | blocks the process while it serves, and the node cannot be reused afterwards | not run: it blocks on a live port; read from the code
Stop | Asks a running node to finish after its current wait. | nothing | | Run | takes effect at the next 100 ms wait inside Run; it does not return the node | run on a node built without a reactor, so only the flag was set
