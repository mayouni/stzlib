init | Builds a claim, a statement with two sides and a domain, from a list of keys or from one written statement such as 3^2 + 4^2 = 5^2. | nothing; the object is built | paSpec=either keys kind, lhs, rhs, relation, over, vars, label and tactic, such as [ :kind = :Identity, :lhs = "3^2", :rhs = "9" ], or one text holding the statement | Check, ToLean, StzMathClaimQ | Raises an error naming the problem for an unknown key or kind, a relation that does not fit the kind, an expression outside the subset (sqrt, abs, exp, log, sin, cos, tan, pi, single-letter variables), a divisibility not declared over Integer or Natural, and text with no relation in it | kind defaults to identity and over to real; a written statement is labelled with its own text
Kind | Returns the kind of the claim, in lowercase. | a text: identity, inequality or divisibility | | Relation
Relation | Returns the relation between the two sides. | a text: =, !=, <, <=, >, >= or the bar of divisibility | | Kind, Statement | | an identity has =, a divisibility has the bar, and an inequality defaults to <
Lhs | Returns the expression on the left side. | a text such as 3^2 + 4^2 | | Rhs, Statement
Rhs | Returns the expression on the right side. | a text such as 5^2 | | Lhs, Statement
Over | Returns the domain the claim is stated over, in lowercase. | a text: natural, integer, rational or real | | Vars
Vars | Returns the names of the variables of the claim, which become the binders of the Lean theorem. | a list of text; [ ] for a closed statement | | SamplePoints, Over
Label | Returns the label given to the claim, which names its theorem. | a text | | TheoremName
Tactic | Returns the Lean tactic the author chose, or empty text when none was chosen. | a text such as decide; empty text by default | | LeanTactic
Statement | Returns the claim as one line: the left side, the relation and the right side. | a text such as 3^2 + 4^2 = 5^2 | | Lhs, Rhs, Relation
SamplePoints | Returns the points at which the numeric check evaluates both sides: one for a closed statement, sixteen otherwise. | a list of points, each a list with one number per variable | | Check, Vars | | integers are used when the domain is natural or integer
Check | Evaluates both sides at the sample points and returns the verdict, the first counterexample if any, and the evidence. | a hash-list with verdict (1 or 0), route, points, evidence and counterexample | | IsTrue, LastCheck, Why | a side that is infinite makes the claim hold at that point: 1/0 = 5 and 1/0 = 1 both give verdict 1 (confirmed on two claims), because the tolerance grows to infinity with the side; a side that is not a number at every point gives verdict 0 with the evidence that no point gave both sides a value | this is the numeric floor, not a proof: a claim that holds at the sampled points is only likely true
IsTrue | TRUE if the claim holds at every sampled point; a false claim fails with a counterexample. | 1 or 0 | | Check, Why | see Check for the infinite-side case
LastCheck | Returns the result of the most recent Check, without evaluating again. | a hash-list as Check returns; [ ] before any check | | Check
TheoremName | Returns the name of the Lean theorem, made from the label with underscores. | a text such as three_four_five | | Label, ToLean
LeanTactic | Returns the Lean tactic that will close the theorem: the author's, or ring, nlinarith or norm_num according to the kind and the variables. | a text | | Tactic, ToLean | | with variables an identity gets ring and an inequality nlinarith; a closed statement gets norm_num
LeanStatement | Returns the statement spelt for Lean, with the domain symbol attached to the left side. | a text such as ((3^2 + 4^2 : ℕ) = 5^2) | | ToLean
ToLean | Returns the whole theorem as one line of Lean 4 text, with binders for the variables and the tactic. | a text such as theorem three_four_five : ((3^2 + 4^2 : ℕ) = 5^2) := by norm_num | | LeanStatement, CheckWithLean, WriteLean
CheckWithLean | Runs the emitted theorem through Lean when it is installed on this machine, and returns the verdict beside the numeric check. | a hash-list with floor, route, proved, because and file | | ToLean, Check | proved is 0 with the reason in because when Lean fails or is stopped, and Lean with Mathlib can take minutes: one run on a cold machine was stopped after 5 minutes and answered proved 0 because lean exited with 143
Why | Explains the claim in one sentence: its kind and domain, the numeric verdict with its evidence, and whether the Lean door is open. | a text | | Check, ToLean
