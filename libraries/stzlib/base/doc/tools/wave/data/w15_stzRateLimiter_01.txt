init | Creates an empty rate limiter with a name, ready to receive one limit per key. | nothing; the object is built | pcName=the limiter's name, used in reports and refusal notes | SetLimit, Name_
Block | Blocks a key until it is unblocked, whatever its bucket holds, and notes the refusal reason. | the limiter itself, so calls chain | pcKey=the key to block, matched without regard to case; pcReason=why it is blocked, kept for BlockOf and the refusal note | BlockFor, Unblock, IsBlocked | blocking a key again replaces the earlier block and resets its refused count
BlockFor | Blocks a key for a number of milliseconds, after which the block lifts by itself; 0 or less blocks it without end. | the limiter itself, so calls chain | pcKey=the key to block, matched without regard to case; pcReason=why it is blocked; pnMs=how long the block lasts, in milliseconds | Block, Unblock, BlockOf | the end of the block is stored as wall-clock epoch milliseconds
Unblock | Lifts the block on a key; a key that is not blocked changes nothing. | the limiter itself, so calls chain | pcKey=the key to unblock, matched without regard to case | Block, IsBlocked | the bucket keeps whatever it held, so a key blocked for a long time may be refused right after
IsBlocked | TRUE if the key is blocked now. | TRUE or FALSE | pcKey=the key to test, matched without regard to case | Block, BlockOf
BlockOf | Returns the block on a key as [ :reason, :until, :refused ], or an empty list when it is not blocked. | a hashlist; [ ] when not blocked | pcKey=the key to look up, matched without regard to case | Block, BlockFor | :until is 0 for a block without end, else epoch milliseconds; :refused counts the Allow calls the block turned away
BlockedKeys | Returns the keys that are blocked now, lower-cased, after dropping the blocks whose time has run out. | a list of texts | | BlockOf, Block
Name_ | Returns the name the limiter was created with. | a text | | init
SetLimit | Gives a key its own token bucket: it holds nBurst tokens and refills at nRatePerSec tokens a second. | the limiter itself, so calls chain | pcKey=the key to limit, matched without regard to case; nRatePerSec=the sustained rate, in tokens a second; nBurst=the bucket size, the most tokens that can be spent at once | Allow, RateOf, BurstOf | a rate or burst below 1 is raised to 1; setting a key again replaces its bucket, which starts full | a key with no limit is unlimited
HasLimit | TRUE if the key has a bucket. | TRUE or FALSE | pcKey=the key to test, matched without regard to case | SetLimit, Keys
Keys | Returns the keys that have a bucket, lower-cased, in the order they were set. | a list of texts | | HasLimit, SetLimit
Allow | Takes one token from the key's bucket and answers whether the request may go ahead. | TRUE or FALSE | pcKey=the key making the request, matched without regard to case | AllowN, Available, Block | a key with no limit is always allowed; a blocked key is always refused, and its refusal is counted on the block and not in RejectedCount
AllowN | Takes n tokens from the key's bucket at once and answers whether the request may go ahead. | TRUE or FALSE | pcKey=the key making the request, matched without regard to case; n=how many tokens the request costs | Allow, Available | n of 0 is always allowed; a refused request takes nothing from the bucket
Available | Returns how many tokens are left in the key's bucket, as a decimal, or -1 for a key with no limit. | a number | pcKey=the key to read, matched without regard to case | Allow, SetLimit | the bucket refills continuously, so a reading just after a spend is already a little above the exact remainder
AllowedCount | Returns how many tokens were granted to the key so far; 0 for an unknown key. | a number | pcKey=the key to read, matched without regard to case | RejectedCount, AllowN | it counts tokens, not calls: AllowN(key, 2) adds 2
RejectedCount | Returns how many requests the key's bucket refused so far; 0 for an unknown key. | a number | pcKey=the key to read, matched without regard to case | AllowedCount, BlockOf | requests turned away by a block are not counted here
RateOf | Returns the key's sustained rate in tokens a second; 0 for a key with no limit. | a number | pcKey=the key to read, matched without regard to case | BurstOf, SetLimit
BurstOf | Returns the key's bucket size; 0 for a key with no limit. | a number | pcKey=the key to read, matched without regard to case | RateOf, SetLimit
Narrate | Returns a few lines of text that describe each limited key with its rate, burst and counts. | a text | | Keys, AllowedCount
Destroy | Frees the engine buckets of every key and forgets the limits. | the limiter itself, so calls chain | | SetLimit | the blocks are kept
