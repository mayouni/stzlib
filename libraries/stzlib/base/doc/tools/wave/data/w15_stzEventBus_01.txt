# w15 stzEventBus
init | Builds a handle on the engine's process-wide event bus; the handle holds no state of its own. | nothing; the object is built | | Channel, Emit | | StzEventBus builds the same object; two handles in one process see the same channels
Channel | Declares a channel by name, doing nothing if it already exists. | the bus itself, so calls chain | pcName=the name of the channel, such as orders | HasChannel, Emit, Subscribe | | Subscribe and Emit also declare a channel they are given
HasChannel | TRUE if a channel with a name exists. | TRUE or FALSE, as 1 or 0 | pcName=the name of the channel | Channel, NumberOfChannels | | a channel exists from its first declaration until DestroyChannel or ClearAll
Subscribe | Subscribes to a channel, declaring it if needed, and returns the subscriber's id. | a number above 0, the subscriber id | pcName=the name of the channel | Unsubscribe, SubscriberCount, Emit | | ids are unique and rise; the same caller may subscribe twice and is then two subscribers
Unsubscribe | Removes a subscriber by its id. | 0 when removed; -2 for an id that is not subscribed, including one already removed | nSubId=the id Subscribe gave | Subscribe, SubscriberCount |
Emit | Publishes a payload on a channel, declaring it if needed. | how many subscribers it was delivered to; 0 when there are none | pcName=the name of the channel; pcData=the payload, turned into text | EventCount, LastEvent, Subscribe | | the event is counted and kept as the last event even when nobody is subscribed
EventCount | Returns how many events were emitted on a channel since it was created. | a number; -2 for a channel that does not exist | pcName=the name of the channel | LastEvent, ChannelGeneration | | it rises while the channel lives but DestroyChannel and ClearAll put it back to 0 or remove it, so a consumer that only tests for a bigger number than last time must treat a smaller one as a new channel and compare ChannelGeneration
SubscriberCount | Returns how many subscribers a channel has. | a number; -2 for a channel that does not exist | pcName=the name of the channel | Subscribe, Unsubscribe |
LastEvent | Returns the most recent payload emitted on a channel. | the payload as text; an empty text when none was emitted or the channel does not exist | pcName=the name of the channel | EventCount, Emit | | a number emitted is read back as text, 42 as 42
ChannelGeneration | Returns which incarnation of a name a channel is, a number that never repeats in the process. | a number above 0; -2 when no channel has the name | pcName=the name of the channel | EventCount, DestroyChannel | | a channel destroyed and declared again has a different generation, which is exact where a falling count can be missed
NumberOfChannels | Returns how many channels exist. | a number | | HasChannel, ClearAll | | the bus is process-wide, so channels made by other parts of the process count
DestroyChannel | Removes a channel and its subscribers. | 0 when removed; -2 for a channel that does not exist | pcName=the name of the channel | ClearAll, ChannelGeneration | | its event count restarts from 0 if it is declared again
ClearAll | Removes every channel in the process. | the bus itself, so calls chain | | DestroyChannel, NumberOfChannels | | useful for test isolation, but it resets channels that other parts of the process are watching
