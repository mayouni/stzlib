init | Builds a scheduler over a score, with a renderer for its notes and nothing started. | nothing; the object is built | poScore=the stzSoundScore to perform | StzSoundSchedulerQ, Prepare | anything but an object is refused, with LastError set, and the scheduler then holds no score; a library without the sound engine does the same
SetLookahead | Sets how many frames ahead of the producer each note must be posted. | the scheduler itself, so calls chain | pnFrames=the lookahead in frames; 0 gives back the derived value | Lookahead, Late | a very small value is meant to prove that the engine counts notes that arrive after their frame
Lookahead | Returns how many frames ahead of the producer notes are posted. | a number of frames; the ring size plus half a second, 40384 at 48000 Hz, until SetLookahead changes it | | SetLookahead
SetGain | Sets the factor applied to every note when it is placed on the timeline. | the scheduler itself, so calls chain | pnGain=the gain per note, 0.6 by default | stzSoundScoreRenderer | it changes the renderer's gain, which is read each time a note is posted
Prepare | Renders every note of the score and builds the graph with its timeline, once. | TRUE if the scheduler is ready; FALSE for a score with no renderable note | | Plan, RenderThroughRing | asking again answers TRUE without rendering again; a score of no notes is refused, with LastError set | the notes are rendered first so that no instrument tunes itself while the performance runs
NotesRendered | Returns how many distinct notes the instruments have rendered. | a number | | SecondsRendering, Plan | a note that recurs counts once, but only after Prepare has run
SecondsRendering | Returns the wall time spent rendering the notes, in seconds. | a number | | NotesRendered
Play | Posts the first window of notes, starts the score on the audio device and returns at once. | the scheduler itself | | Tick, RunToEnd, RenderThroughRing | not run in this reference: it opens an audio device through a transport; a refusal by the transport is copied into LastError and counted | RunToEnd or Tick must follow to keep posting notes
Tick | Posts the notes that have come due, keeps the transport's clock and stops it after the last note has played out. | the scheduler itself | | RunToEnd, Play | does nothing unless Play has started a transport; its device path was not run in this reference | cheap enough to call as often as you like
IsPlaying | TRUE if a transport started by Play is still running. | TRUE or FALSE; FALSE before Play | | Play, Tick
RunToEnd | Ticks every 20 ms until the transport has stopped. | the scheduler itself | | Tick, Play | returns at once when nothing is running, which is the only case run in this reference | blocks the calling thread until the last note has played out
RenderThroughRing | Performs the score through the real-time path with no sound card and returns what came out as a sound. | a stzSound as long as the score's last note; NULL for a score with no renderable note | | Prepare, Late | a producer thread renders the graph into a ring while this thread posts notes ahead of it and drains the ring, so no audio device is opened; the result matched the offline render at every 97th sample | it runs faster than a device would, which is harder for the scheduler; the sound has not been heard by a person
Placed | Returns how many notes have been posted to the timeline. | a number; 0 before anything is posted | | Late, PostsRefused | read from the engine's timeline counters
Late | Returns how many notes reached the timeline after the producer had rendered their frame. | a number; 0 is the answer to want | | LateMaxInMs, SetLookahead | read from the engine's timeline counters
LateMaxInMs | Returns the worst lateness of any note, in milliseconds. | a number of milliseconds; 0 when no note was late | | Late
PostsRefused | Returns how many times the timeline refused a note because all its 512 slots were busy. | a number | | Placed | a refused note is retried on the next tick, not dropped
Underruns | Returns the frames the device asked for and the ring could not supply, as of the last Tick. | a number; 0 when nothing has played on a device | | Late | the producer falling behind, counted apart from a note posted late
Plan | Returns one row per event giving the frame it starts at and the buffer that holds its note. | a list of [ frame, bufferId ] rows in start order; [ ] for an empty score | | Renderer, Prepare | the rows come from the renderer, which renders on first use
Renderer | Returns the renderer that holds the score's notes. | a stzSoundScoreRenderer | | Plan, SetGain | it is the one the scheduler uses, not a copy to configure separately
LastError | Returns the reason the last failure gave, or an empty text. | a text | | Refusals
Refusals | Returns how many times the scheduler refused to go on. | a number | | LastError
Release | Stops any transport, frees the graph and frees the notes. | nothing | | Prepare, Play | call it only once nothing is playing, because the timeline reads the note samples directly
