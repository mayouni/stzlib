Parameter must be a list or stzList object." |

Section | Returns the items from one position to another, both included, as a flat list. | a list; [ ] for an empty list | _n1_=the first position, from 1; negative counts from the end, :First and :Last are accepted, and [ :From, 2 ] too; _n2_=the last position, from 1, in the same forms, [ :To, 3 ] included | Sections, Range, AntiSection | | positions are forgiving: past the end they are clipped (Section(5, 99) on 7 items gives items 5 to 7), 0 is read as 1, and a start after the end is swapped, so Section(4, 2) equals Section(2, 4)
Sections | Returns several sections at once, one list per pair of positions, in the order given. | a list of lists | paSections=a list of [ start, end ] pairs, each read as for Section | Section, Ranges | |
FindAntiSection | Returns the positions that lie outside a section, as one or two [ start, end ] pairs. | a list of pairs; [ ] when the section covers the whole list | _n1_=the first position of the section; _n2_=its last position, both numbers | AntiSection, Section | | FindAntiSection(2, 3) on 7 items gives [ [1,1], [4,7] ]
AntiSection | Returns the items that lie outside a section, as one list for the part before it and one for the part after it. | a list of one or two lists; [ ] when the section covers the whole list | _n1_=the first position of the section; _n2_=its last position, both numbers | FindAntiSection, Section | | a section that starts at 1 or ends at the last position leaves only one list
Range | Returns the section of a given length starting at a position, wrapped in a list; a negative length counts backwards from the start. | a list holding one list of items; "" when the start or the length is 0 | pnStart=the first position, from 1; negative counts from the end, :First and :Last are accepted; pnRange=how many items, or minus that many going backwards | RangeXT, Section, Ranges | | the answer is one list deeper than Section's: Range(2, 3) on a to g gives [ [ "b","c","d" ] ], and RangeXT gives the flat list; a length past the end is clipped; an empty list answers [ [ ] ]
Ranges | Returns several ranges at once, one answer of Range for each [ start, length ] pair. | a list of the lists Range returns | paRanges=a list of [ start, length ] pairs | Range, Sections | | each range stays wrapped in its own list, as Range does
ManyRanges | Returns several ranges at once, the same as Ranges. | nothing today: it raises error R24 | paSections=a list of [ start, length ] pairs | Ranges | Raises error R24 "Using uninitialized variable: paranges" today instead of the ranges; use Ranges | the alias passes paRanges on but its own parameter is named paSections
AntiRanges | Returns the parts of the list that lie outside the given ranges, each part as a list. | a list of lists | paRanges=a list of [ start, length ] pairs | RangesAndAntiRanges, AntiSection | | AntiRanges([ [2,2] ]) on a to g leaves a and d to g
RangesOtherThan | Returns the parts of the list that lie outside the given ranges, the same as AntiRanges. | nothing today: it raises error R19 | paRanges=a list of [ start, length ] pairs | AntiRanges | Raises error R19 "Calling function with less number of parameters" today instead of the parts outside the ranges; use AntiRanges | the alias calls AntiRanges without the ranges it was given
RangesAndAntiRanges | Returns the whole list cut into the given ranges and the parts between them, in list order. | a list of lists | paRanges=a list of [ start, length ] pairs | AntiRanges, Ranges | | RangesAndAntiRanges([ [2,2] ]) on a to g gives a, then b c, then d to g
