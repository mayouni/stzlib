init | Builds a words helper over a text or over a stzString object, to list, count, rank and replace its words. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, whose words are read | Words, NumberOfWords | Given a stzString object, the first in-place edit (ReplaceWord, RemoveWord) leaves that stzString EMPTY while the helper holds the result; the readers do not. Pass the text, os.Content(), to be safe | any other kind of value raises "Can't create stzStringWords! Parameter must be a string or stzString object."
Content | Returns the text the helper holds, after any ReplaceWord or RemoveWord. | a text | | Words | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | NumberOfWords | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
Words | Returns the words of the text in order, split by Unicode word rules, so punctuation is left out. | a list of texts; [ ] for an empty text | | NumberOfWords, UniqueWords | | "fox," gives fox; "well-known" gives well and known; an emoji is not a word; Hebrew and Arabic words come whole; WordsQ answers a stzList
NumberOfWords | Returns how many words the text holds, by the same rules as Words. | a number | | Words | | CountWords and HowManyWords are the same method
NthWord | Returns the word at a position in the list of words, counted from 1. | a text | _n_=the word number, from 1 | FirstWord, LastWord, WordAtPosition | position 0 or past the last word answers an empty text and raises nothing | Word is the same method
FirstWord | Returns the first word of the text. | a text; "" for an empty text | | LastWord, NthWord | |
LastWord | Returns the last word of the text. | a text; "" for an empty text | | FirstWord | |
NFirstWords | Returns the first n words as a list. | a list of texts; all the words when n is larger | _n_=how many words to take | NLastWords, Words | | n of 0 gives [ ]
NLastWords | Returns the last n words as a list, in text order. | a list of texts; all the words when n is larger | _n_=how many words to take | NFirstWords | | n of 0 gives [ ]
WordAtPosition | Returns the word that contains a character position, or an empty text if that position is a space. | a text | _n_=the character position, from 1 | NthWord | | words here are cut at white space only, so it answers "fox," with its comma where Words gives fox; a position outside the text raises "Position out of range!"
UniqueWords | Returns the different words once each, in order of first appearance, comparing case-sensitively. | a list of texts | | UniqueWordsCS, Words | | it cuts at spaces only, unlike Words: "fox," stays with its comma and an emoji counts as a word; UniqueWordsCS(0) folds case; WordsU is the same method
LongestWord | Returns the longest word by characters; the first one when several tie. | a text; "" for an empty text | | ShortestWord | |
ShortestWord | Returns the shortest word by characters; the first one when several tie. | a text; "" for an empty text | | LongestWord | |
AverageWordLength | Returns the mean number of characters per word. | a number; 0 for an empty text | | LongestWord | | "שלום עולם שלום ب ب" gives 2.8
WordFrequencies | Returns each different word with how many times it occurs, ignoring case, as [ word, count ] pairs. | a list of pairs, in order of first appearance | | MostFrequentWord, UniqueWords | | the case is folded: The, the and THE count as one word, written as it first appeared
MostFrequentWord | Returns the word that occurs most often, ignoring case; the first one when several tie. | a text; "" for an empty text | | WordFrequencies | |
ContainsWord | TRUE if the text has the given word as a whole word, case-sensitively. | TRUE or FALSE | pcWord=the word to look for | ContainsWordCS | | ContainsWordCS(w, 0) ignores case; "qui" in "quick" is FALSE and "fox," with its comma is FALSE
ReplaceWord | Replaces every occurrence of a word by another, case-sensitively, in place. | nothing; use ReplaceWordQ to chain | pcOldWord=the word to replace; pcNewWord=the word to put | RemoveWord, ReplaceWordCS | The text is rebuilt from its words, so all punctuation is lost and the spaces are reset to single ones, even when nothing is replaced: ReplaceWord("zzz", "x") on "Hello, world! It is 5.5 o clock." leaves "Hello world It is 5.5 o clock" | ReplaceWordCS(old, new, 0) ignores case
RemoveWord | Removes every occurrence of a word, case-sensitively, in place. | nothing; use RemoveWordQ to chain | pcWord=the word to remove | ReplaceWord, RemoveWordCS | The text is rebuilt from its words, so all punctuation is lost and the spaces are reset to single ones, even when nothing is removed | RemoveWordCS(word, 0) ignores case
