NumberOfSamples | Returns how many samples the job was built with. | a number | | NumberOfFeatures, Embedding

SetPerplexity | Sets the perplexity, roughly how many neighbours should count for each point; 30 by default. | nothing; use SetPerplexityQ to chain | n=the perplexity, a number above 0, anything else is ignored | Perplexity, Fit | Fit refuses to run when the perplexity is not smaller than the number of samples | small values show fine structure and can split a real cluster, large values show the broad shape and can merge two
Perplexity | Returns the perplexity in force. | a number; 30 by default | | SetPerplexity
SetDimensions | Sets how many coordinates each point gets in the embedding; 2 by default. | nothing; use SetDimensionsQ to chain | n=the number of output dimensions, 1 or more, anything else is ignored | Fit, Embedding
SetIterations | Sets how many optimisation steps the fit takes; 1000 by default. | nothing; use SetIterationsQ to chain | n=the number of iterations, above 0, anything else is ignored | Fit, KLHistory | | few iterations leave the layout unsettled, and the coordinates large
SetSeed | Sets the number that starts the random generator, so a run can be repeated or varied; 42 by default. | nothing; use SetSeedQ to chain | n=the starting number | Fit | | the same value gives the same embedding, a different one gives a different layout
ReduceWithPCA | Asks for a PCA down to n dimensions before the embedding, the usual first step; off by default. | nothing; use ReduceWithPCAQ to chain | n=the number of components to keep, 1 or more, anything else is ignored | SkipPCA, UsesPCA, PCAQ | when n is not below the number of features the data goes through unchanged and no PCA is run | it speeds up the distances and removes noise, at the cost of any structure the discarded components held
SkipPCA | Turns off the PCA step, so the fit uses the raw features. | nothing; use SkipPCAQ to chain | | ReduceWithPCA, UsesPCA
UsesPCA | TRUE if a PCA reduction has been requested. | TRUE or FALSE | | ReduceWithPCA, PCAQ
PCAQ | Returns the PCA that the last fit ran before embedding, so its explained variance can be read. | a stzPCA object; "" before a fit that used PCA | | ReduceWithPCA, UsesPCA
LearnMapping | Switches to the parametric variant, which trains a neural network from features to coordinates instead of moving free points. | nothing; use LearnMappingQ to chain | | SkipMapping, Transform, SetHiddenLayers | it trades some picture quality for the ability to place new points exactly | training rows transform back to their own embedding exactly (largest difference 0 on twelve points)
SkipMapping | Switches back to the ordinary t-SNE, where points move freely. | nothing; use SkipMappingQ to chain | | LearnMapping, IsParametric
IsParametric | TRUE if the parametric variant is switched on. | TRUE or FALSE | | LearnMapping, SkipMapping
SetHiddenLayers | Sets the widths of the hidden layers of the network of the parametric variant; 50 and 20 by default. | nothing; use SetHiddenLayersQ to chain | paWidths=the layer widths, a list of numbers, an empty list or another value is ignored | HiddenLayers, LearnMapping
HiddenLayers | Returns the hidden layer widths of the parametric variant. | a list of numbers; [ 50, 20 ] by default | | SetHiddenLayers
SetLearningRate | Sets the step size of the network of the parametric variant; 0.01 by default. | nothing; use SetLearningRateQ to chain | n=the learning rate, above 0, anything else is ignored | LearnMapping, SetHiddenLayers
Transform | Places new rows in the existing map, one forward pass of the network for the parametric variant, a constrained optimisation otherwise. | a list of coordinate rows, one per new row | paRows=the new samples, each with as many feature values as the training samples | LearnMapping, NewLocalRadii, LocalRadiiOf | it raises Fit() me first. before a fit, and an error naming the row when a row has the wrong width or the list is empty; for the ordinary variant the placement is approximate, near the right place rather than on it | the map does not rearrange for the new point: a point unlike the training data is still placed among the nearest training points
PreserveDensity | Turns on the density term (den-SNE) so denser regions are drawn tighter; the weight becomes 1, or 0.1 when parametric. | nothing; use PreserveDensityQ to chain | | IgnoreDensity, SetDensityWeight, DensityCorrelation | | it makes cluster size more readable, at the cost of some separation between clusters
IgnoreDensity | Turns the density term off. | nothing; use IgnoreDensityQ to chain | | PreserveDensity, IsDensityPreserving
IsDensityPreserving | TRUE if the density weight is above 0. | TRUE or FALSE | | PreserveDensity, DensityWeight
SetDensityWeight | Sets how hard the density term pushes; 0 turns it off exactly. | nothing; use SetDensityWeightQ to chain | n=the weight, 0 or more, a negative value is ignored | DensityWeight, PreserveDensity | | with 0 the embedding is identical to the ordinary fit, value for value (twelve points, same seed)
DensityWeight | Returns the weight of the density term. | a number; 0 by default | | SetDensityWeight, IsDensityPreserving
SetDensityPhase | Sets the last fraction of the iterations during which the density term is active; 0.3 by default. | nothing; use SetDensityPhaseQ to chain | n=the fraction, above 0 and at most 1, anything else is ignored | DensityPhase, SetDensityWeight
DensityPhase | Returns the fraction of the iterations during which the density term runs. | a number; 0.3 by default | | SetDensityPhase
DensityCorrelation | Returns how closely the drawn local radii follow the original ones at the end of a fit with the density term on. | a number from -1 to 1; 0 when the term is off or before a fit | | PreserveDensity, LocalRadii | | it is a correlation, not a percentage
LocalRadii | Returns the average distance of each sample to its neighbours in the original space, as measured by a fit with the density term on. | a list of numbers, one per sample; [ ] when the term is off | | DensityCorrelation, LocalRadiiOf
NewLocalRadii | Returns the local radii of the rows placed by the last Transform. | a list of numbers, one per placed row; [ ] before any Transform | | Transform, LocalRadiiOf | | a large value warns that a new row lies outside the region the map was fitted on
LocalRadiiOf | Returns how far each given row sits from its neighbours in the training data, without placing anything. | a list of numbers, one per row | paRows=the rows to measure, each with as many feature values as the training samples | NewLocalRadii, Transform | it raises before a fit and for rows of the wrong width |
LearnInverse | Trains a second network that maps points of the embedding back to rows of data. | nothing; use LearnInverseQ to chain | | Inverse, HasInverse, SetInverseLayers | it needs a fitted job; training is slow with the default 15000 epochs, so a small job sets SetInverseEpochs first |
HasInverse | TRUE if an inverse network has been trained. | TRUE or FALSE | | LearnInverse, Inverse
SetInverseLayers | Sets the hidden layer widths of the inverse network; 64 and 64 by default. | nothing; use SetInverseLayersQ to chain | paWidths=the layer widths, a list of numbers, an empty list or another value is ignored | LearnInverse, SetInverseEpochs
SetInverseEpochs | Sets how many epochs the inverse network trains for; 15000 by default. | nothing; use SetInverseEpochsQ to chain | n=the number of epochs, above 0, anything else is ignored | LearnInverse, SetInverseLayers
Inverse | Returns rows of data for points of the embedding, using the inverse network. | a list of rows, one per point | paPoints=points of the map, each with as many coordinates as the embedding | LearnInverse, HasInverse | it raises before LearnInverse, and for a point with the wrong number of coordinates | the rows come back in the space the fit saw, so with a PCA step they are PCA scores, not the original features
Fit | Runs the embedding of the samples, and stores the coordinates and the cost history. | nothing; use FitQ to chain | | Embedding, IsFitted, Why | it raises an error when the perplexity is too large for the number of samples, and when there are fewer than 3 samples |
