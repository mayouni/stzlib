init | Creates an empty 3D scene of the given size in pixels, with the camera at 0, 0, 5 looking at the origin. | nothing; the object is built | pnW=the width in pixels; pnH=the height in pixels | AddMesh, SetCamera, ToPNG | Raises an error when the width or height is not a number and when the engine refuses the size, as it does for 0 by 0
Id_ | Returns the engine's number for this scene, or 0 once it was freed. | a number | | Free
Width | Returns the width the scene believes it has, in pixels. | a number | | Height, Resize
Height | Returns the height the scene believes it has, in pixels. | a number | | Width, Resize
Resize | Adopts a new viewport size on the scene object, so that Project and screen-to-ray maths use the size of a resized window. | 1 when taken, 0 when a size is not a positive number | pnW=the new width in pixels; pnH=the new height in pixels | Project, Width | it changes only what the object reports; the engine retargets itself when the scene is drawn into a target of another size
Stats | Returns the counters of the scene: instances, meshes resident on the device, draw calls, geometry uploads and transform uploads. | a list of five numbers; [ ] once freed | | InstanceCount | | moving an instance and drawing again raises the transform uploads and leaves the geometry uploads where they were; before the first draw the last four are 0
InstanceCount | Returns how many instances, placed meshes, the scene holds. | a number | | Stats, AddMesh
SetBackground | Sets the colour the scene is cleared to before it is drawn. | nothing; SetBackgroundQ returns the scene | pColor=a colour name such as :Black or a hex text such as #0c0e14 | SetLight
SetCamera | Places the eye and the point it looks at, in scene units, keeping the lens that was set. | nothing; SetCameraQ returns the scene | pnEX=the eye's x; pnEY=the eye's y; pnEZ=the eye's z; pnTX=the target's x; pnTY=the target's y; pnTZ=the target's z | SetLens, Camera, Project | raises an error when the lens held is invalid, so a refused SetLens leaves every later SetCamera failing until the lens is repaired | the lens starts at 45 degrees from 0.1 to 200
SetLens | Sets the field of view in degrees and the near and far limits of the camera. | nothing; SetLensQ returns the scene | pnFovDegrees=the vertical field of view in degrees; pnNear=the nearest distance drawn, above 0; pnFar=the farthest distance drawn, above pnNear | SetCamera, Camera | raises an error for a near of 0 or less or a far not above near, yet the invalid values stay in Camera and are sent again by the next SetCamera (confirmed with 0 and 100, then 5 and 2) | repair it by calling SetLens again with valid numbers
Camera | Returns the camera as eye, target and lens in one list. | a list of nine numbers: the eye, the target, then the field of view, near and far | | SetCamera, SetLens
SetLight | Sets one directional light: the direction it shines in, its colour and the ambient light that fills the shadows. | nothing; SetLightQ returns the scene | pnDX=the x of the direction the light shines in; pnDY=the y of that direction, where 0, -1, 0 is noon; pnDZ=the z of that direction; pColor=the light's colour; pAmbient=the ambient colour | SetBackground, SetMaterial
AddMesh | Places a mesh in the scene at a position, as a new instance drawn white. | nothing; AddMeshQ returns the scene, and LastIndex gives the instance's number | poMesh=an stzMesh that is still alive; pnX=the x position; pnY=the y position; pnZ=the z position | LastIndex, SetColor, MoveTo | raises an error for anything that is not a mesh and for a mesh that was freed | all instances of one mesh are drawn in a single call
SetParent | Makes one instance the child of another, so that its transform becomes local to the parent and moving the parent moves the chain. | 1 when accepted, 0 when refused | pnIndex=the child's instance number; pnParentIndex=the parent's instance number | ClearParent, WorldPosition, HierarchyDepth | an instance parented to itself or to one that does not exist is refused; a loop made of two parents is accepted when set and broken, and counted by CyclesRefused, when the scene is resolved | numbers come from LastIndex
ClearParent | Detaches an instance from its parent, which keeps its local transform and becomes a root. | 1 when done, 0 when the instance does not exist | pnIndex=the instance's number | SetParent, HierarchyDepth
HierarchyDepth | Returns how many links the longest parent chain has. | a number; 0 for a flat scene | | SetParent, WorldPosition
CyclesRefused | Returns how many parent loops were broken instead of followed. | a number | | SetParent
WorldPosition | Returns where an instance really sits once its parents are applied, the number to assert on. | a list [ x, y, z ] | pnIndex=the instance's number | SetParent, MoveTo
LastIndex | Returns the number of the instance added most recently, which Color, Move, Rotate and Scale act on. | a number; 0 before any mesh is added | | AddMesh
MoveTo | Sets the position of an instance and leaves its rotation and scale as they are. | nothing; MoveToQ returns the scene | pnIndex=the instance's number, from 1; pnX=the new x; pnY=the new y; pnZ=the new z | RotateTo, ScaleTo, Move | raises an error for a number below 1 and for an instance that does not exist | it re-sends the transform and never the geometry
RotateTo | Sets the rotation of an instance as an angle around an axis, and leaves its position and scale as they are. | nothing; RotateToQ returns the scene | pnIndex=the instance's number, from 1; pnAX=the axis x; pnAY=the axis y; pnAZ=the axis z; pnDegrees=the angle in degrees | MoveTo, ScaleTo, Rotate | raises an error for an instance that does not exist
ScaleTo | Sets the scale of an instance along each axis, and leaves its position and rotation as they are. | nothing; ScaleToQ returns the scene | pnIndex=the instance's number, from 1; pnSX=the x factor; pnSY=the y factor; pnSZ=the z factor | MoveTo, RotateTo, Scale | raises an error for an instance that does not exist
SetColor | Sets the colour of one instance. | nothing; SetColorQ returns the scene | pnIndex=the instance's number; pColor=a colour name or a hex text | Color, AddMesh | raises an error naming the instance when it does not exist
Color | Sets the colour of the instance added most recently, so that AddMeshQ and ColorQ chain. | nothing; ColorQ returns the scene | pColor=a colour name or a hex text | SetColor, LastIndex
Move | Sets the position of the instance added most recently. | nothing; MoveQ returns the scene | pnX=the new x; pnY=the new y; pnZ=the new z | MoveTo, LastIndex
Rotate | Sets the rotation of the instance added most recently, as an angle around an axis. | nothing; RotateQ returns the scene | pnAX=the axis x; pnAY=the axis y; pnAZ=the axis z; pnDegrees=the angle in degrees | RotateTo, LastIndex
Scale | Sets the scale of the instance added most recently along each axis. | nothing; ScaleQ returns the scene | pnSX=the x factor; pnSY=the y factor; pnSZ=the z factor | ScaleTo, LastIndex
Project | Turns a point of the scene into a pixel of the picture, using the camera and the size the scene reports. | a list [ x, y, depth, visible ]; visible is 0 for a point behind the camera, and x and y are then 0 | pnX=the point's x; pnY=the point's y; pnZ=the point's z | Resize, Camera | the point 0, 0, 0 lands at the centre of the picture for a camera looking at the origin
SetMaterial | Replaces the built-in shading of the whole scene with a material written by the material maker, bound to colours and numbers. | nothing; SetMaterialQ returns the scene | poMaterial=an stzMaterialMaker; paBindings=the values of its inputs, such as [ :tint = "#e0a030" ] | ClearMaterial, HasMaterial, MaterialTextureCount | raises an error for anything that is not a material maker and when the engine or its textures are refused | the material applies to every instance, not to one
ClearMaterial | Removes the material so that the scene is shaded by the built-in forward lighting again. | nothing; ClearMaterialQ returns the scene | | SetMaterial, HasMaterial
HasMaterial | TRUE if the scene is shaded by a material set with SetMaterial. | 1 or 0 | | SetMaterial, ClearMaterial
MaterialTextureCount | Returns how many textures the material has bound. | a number | | SetMaterial
InstanceBuffer | Returns the engine's handle of the buffer that holds the instances' transforms, for a compute kernel to write. | a number; the buffer exists once the scene was drawn | | SetGpuDriven, InstanceStride
InstanceStride | Returns how many bytes one instance takes in the instance buffer. | a number, 36 | | InstanceBuffer
SetGpuDriven | Hands the instance buffer to a compute kernel, so that the scene draws whatever the kernel leaves there instead of its own transforms. | nothing; SetGpuDrivenQ returns the scene | pbOn=1 to let the kernel drive the transforms, 0 to take them back | IsGpuDriven, InstanceBuffer | draw the scene once first so that the buffer exists
IsGpuDriven | TRUE if the transforms are driven by a compute kernel. | 1 or 0 | | SetGpuDriven
ToPNG | Renders the scene and returns the PNG bytes, writing them to a file when a path is given. | the PNG as a binary text; empty text when this machine has no graphics device | pcPath=the file to write, or empty text to write nothing | ToPixels, Show | a scene has no vector fallback, so without a device nothing is drawn | the returned text is the picture itself, so do not print it
ToPixels | Renders the scene and returns its pixels. | a binary text of the pixels, four bytes each, such as 480000 bytes for 400 by 300 | | ToPNG, CanDrawPixels
CanDrawPixels | TRUE if this machine has a graphics device that can render the scene. | 1 or 0 | | ToPNG
Show | Renders the scene to a PNG named stzscene_show.png in the current folder and opens it in the system's viewer. | the path of the PNG | | ToPNG | raises an error when there is no graphics device
Free | Releases the scene in the engine, after which every query answers 0 or empty. | nothing | | Id_ | | call it when done, as the engine holds the scene until then
