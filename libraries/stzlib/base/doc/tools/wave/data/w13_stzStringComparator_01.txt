# w13 stzStringComparator -- Name | brief | returns | params | see | warning | note
init | Builds a comparator over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the text to compare, or a stzString to wrap; any other value raises an error | Content, IsEqualTo | | comparing never edits the text, so a stzString passed in stays intact (checked with keep me)
Content | Returns the text being compared. | a text | | NumberOfChars, IsEmpty
NumberOfChars | Returns how many characters the text holds, counting a Hebrew letter or an emoji as one. | a number | | Content, IsEmpty
IsEmpty | TRUE if the text holds no character at all. | TRUE or FALSE, as 1 or 0 | | NumberOfChars, Content
IsEqualTo | TRUE if the other text is identical to this one, character for character, case included. | TRUE or FALSE, as 1 or 0 | pcOtherStr=the text to compare with | IsNotEqualTo, IsEqualToOneOfThese, Compare | a number instead of a text ends the Ring process without any message (IsEqualTo(5) and Compare(5), exit code 1) | IsEqualToCS(other, 0) ignores case: Apple equals apple
IsNotEqualTo | TRUE if the other text differs from this one in at least one character, case included. | TRUE or FALSE, as 1 or 0 | pcOtherStr=the text to compare with | IsEqualTo | | IsNotEqualToCS(other, 0) ignores case
IsEqualToOneOfThese | TRUE if the text is identical to at least one text of the list. | TRUE or FALSE, as 1 or 0; FALSE for an empty list | pacOtherStr=the list of texts to compare with | IsEqualTo, ContainsOneOfThese | | IsEqualToOneOfTheseCS(list, 0) ignores case
IsLessThan | TRUE if the text sorts before the other one, comparing code points from the first character. | TRUE or FALSE, as 1 or 0 | pcOtherStr=the text to compare with | IsGreaterThan, Compare, IsBetween | | case counts: an upper-case letter sorts before every lower-case one, so Bandana is less than banana
IsGreaterThan | TRUE if the text sorts after the other one, comparing code points from the first character. | TRUE or FALSE, as 1 or 0 | pcOtherStr=the text to compare with | IsLessThan, Compare | | Hebrew sorts by code point, so עולם is greater than יפה
IsBetween | TRUE if the text sorts at or after the first bound and at or before the second. | TRUE or FALSE, as 1 or 0 | pcStr1=the lower bound, included; pcStr2=the upper bound, included | IsLessThan, IsGreaterThan | the bounds are not reordered: asking for z then a is FALSE for every text | IsBetweenCS(a, z, 0) ignores case, so M is between a and z
Compare | Returns -1, 0 or 1 according to whether the text sorts before, equal to or after the other one. | -1, 0 or 1 | pcOtherStr=the text to compare with | IsLessThan, IsGreaterThan, IsEqualTo | a number instead of a text ends the Ring process without any message | CompareCS(other, 0) ignores case: Apple against apple gives 0, while Compare gives -1
DiffWith | Returns the positions at which the two texts differ, position by position, including the tail of the longer one. | a list of numbers, 1-based; [ ] for identical texts | pcOtherStr=the text to compare with | CommonCharsWith, LevenshteinDistanceWith | always case-sensitive; there is no case flag | banana against Bandana gives [ 1, 4, 5, 6, 7 ]; positions count characters, not bytes
Contains | TRUE if the text holds the given fragment anywhere. | TRUE or FALSE, as 1 or 0 | pcSubStr=the fragment to look for | ContainsOneOfThese, ContainsAllOfThese | an empty fragment answers FALSE | ContainsCS(sub, 0) ignores case
ContainsOneOfThese | TRUE if the text holds at least one fragment of the list. | TRUE or FALSE, as 1 or 0; FALSE for an empty list | pacSubStr=the list of fragments | Contains, ContainsAllOfThese | | ContainsOneOfTheseCS(list, 0) ignores case
ContainsAllOfThese | TRUE if the text holds every fragment of the list. | TRUE or FALSE, as 1 or 0; TRUE for an empty list | pacSubStr=the list of fragments | Contains, ContainsOneOfThese | | ContainsAllOfTheseCS(list, 0) ignores case
CommonPrefixWith | Returns the beginning that the text shares with the other one, as text. | a text; an empty text when the first characters differ | pcOtherStr=the text to compare with | LongestCommonPrefixWith, CommonSuffixWith, PrefixCountWith | | hello against help gives hel; CommonPrefixWithCS(other, 0) ignores case; the result is a whole number of characters in Hebrew, Arabic and emoji text
CommonSuffixWith | Returns the ending that the text shares with the other one, as text. | a text; an empty text when the last characters differ | pcOtherStr=the text to compare with | LongestCommonSuffixWith, CommonPrefixWith | | banana against Bandana gives ana
CommonCharsWith | Returns the distinct characters of the text that also occur in the other one, in the order they first appear here, as one text. | a text | pcOtherStr=the text to compare with | DiffCharsWith, CommonalityWith | on Hebrew, Arabic and emoji text the case-sensitive form cuts characters into bytes and loses them: עולם against עיר gives an empty text, and a😀b😀 against a😀c😀 gives a instead of a😀; the case-ignoring form CommonCharsWithCS(other, 0) is right (ע, and a😀) | banana against Bandana gives an
CommonalityWith | Returns how many distinct characters the text shares with the other one. | a number | pcOtherStr=the text to compare with | CommonCharsWith, JaroSimilarityWith | on Hebrew, Arabic and emoji text the case-sensitive form counts bytes: עולם against עיר gives 2 where CommonalityWithCS(other, 0) gives 1 | banana against Bandana gives 2 (a and n), and 3 when case is ignored
DiffCharsWith | Returns the distinct characters of the text that do not occur in the other one, as one text. | a text; an empty text when every character is shared | pcOtherStr=the text to compare with | CommonCharsWith | on Hebrew, Arabic and emoji text the case-sensitive form returns cut bytes that are not valid text (עולם against עיר gives three broken characters); DiffCharsWithCS(other, 0) gives ולם | banana against Bandana gives b
LevenshteinDistanceWith | Returns the least number of single-character insertions, deletions and replacements that turn the text into the other one. | a number | pcOtherStr=the text to compare with | JaroSimilarityWith, DiffWith | | kitten against sitting gives 3; always case-sensitive; EditDistanceWith is the same call; counts characters, so Hebrew and emoji text is measured exactly (עולם against יפה gives 4)
PrefixCountWith | Returns how many times the other text repeats back to back at the start of the text. | a number; 0 when the text does not begin with it | pcOtherStr=the text that is repeated | SuffixCountWith, CommonPrefixWith | | ababab against ab gives 3, xxabab against ab gives 0; PrefixCountWithCS(other, 0) ignores case
SuffixCountWith | Returns how many times the other text repeats back to back at the end of the text. | a number; 0 when the text does not end with it | pcOtherStr=the text that is repeated | PrefixCountWith, CommonSuffixWith | | ababab against ab gives 3, xxabab gives 2; SuffixCountWithCS(other, 0) ignores case
LongestCommonPrefixWith | Returns the longest beginning that the text shares with the other one, as text. | a text; an empty text when the first characters differ | pcOtherStr=the text to compare with | CommonPrefixWith, LongestCommonSuffixWith | on Hebrew text it can end with half a character: עולם against עיר gives ע followed by a broken byte, where CommonPrefixWith gives ע (the case-ignoring form is right) | hello against help gives hel
LongestCommonSuffixWith | Returns the longest ending that the text shares with the other one, as text. | a text; an empty text when the last characters differ | pcOtherStr=the text to compare with | LongestCommonPrefixWith, CommonSuffixWith | | banana against Bandana gives ana
Soundex | Returns the four-character Soundex code of the text, a letter and three digits that match for similar English sounds. | a text such as R163 | | Metaphone, JaroSimilarityWith | only Latin letters are coded: Hebrew and Arabic text give a broken first character followed by 000 (שלום gives 4 bytes ending in 000), and an empty text gives an empty text | Robert and Rupert both give R163; Tymczak gives T520
Metaphone | Returns the Metaphone phonetic code of the text, the consonant skeleton of its English sound. | a text such as BNN | | Soundex | only Latin letters are coded: Hebrew and Arabic text give an empty text | banana gives BNN, hello gives HL, Thompson gives 0MPSN
JaroSimilarityWith | Returns the Jaro similarity of the two texts, scaled to 1000 for identical texts. | a number from 0 to 1000 | pcOtherStr=the text to compare with | JaroWinklerSimilarityWith, LevenshteinDistanceWith | JaroDistanceWith is the same call and is a similarity, not a distance: 1000 means identical | MARTHA against MARHTA gives 944, the published 0.944 times 1000; hello against help gives 783
JaroWinklerSimilarityWith | Returns the Jaro-Winkler similarity of the two texts, which favours a shared beginning, scaled to 1000. | a number from 0 to 1000 | pcOtherStr=the text to compare with | JaroSimilarityWith | JaroWinklerDistanceWith is the same call and is a similarity, not a distance | MARTHA against MARHTA gives 960 where the published value is 0.961; hello against help gives 848
