init | Builds a TCP client that is not connected and has no callbacks. | nothing; the object is built | | Connect
Connect | Opens a blocking TCP connection to a host and port, and fires the connect or the error callback. | the client itself, so calls chain | cHost=the host name or address; nPort=the port number | Send, Receive, IsConnected | a refusal or an unresolvable host does not raise: the client stays unconnected and LastError names the cause, such as connect failed: ConnectionRefused | the callbacks are names of functions, called with no argument
Send | Sends text on the open connection, reporting a failure through LastError and the error callback. | the client itself, so calls chain | cData=the text to send | Receive, Connect | without a connection it sets LastError to Not connected and sends nothing
Receive | Reads at most 8192 bytes from the connection into ReceivedData and fires the receive callback. | the client itself, so calls chain | | ReceiveWithMax, ReceivedData | it blocks until data arrives or the peer closes, with no timeout; an empty ReceivedData and no error means the peer closed
ReceiveWithMax | Reads at most that many bytes from the connection into ReceivedData and fires the receive callback. | the client itself, so calls chain | nMaxBytes=the most bytes to read in this call | Receive, ReceivedData | it blocks until data arrives or the peer closes, with no timeout; a message longer than the limit is read by several calls
ReceivedData | Returns what the last Receive read. | a text; empty before a read and after the peer closed | | Receive
Close | Closes the connection and fires the close callback; closing a client that is not connected does nothing. | the client itself, so calls chain | | Connect
OnConnect | Sets the function called after a successful Connect. | the client itself, so calls chain | cCallback=the name of a function that takes no parameter | OnReceive, OnClose, OnError | | choose a function name of your own: a name the library already defines as a function with parameters fails with a wrong-parameter error
OnReceive | Sets the function called after a Receive that read data. | the client itself, so calls chain | cCallback=the name of a function that takes no parameter | OnConnect, ReceivedData
OnClose | Sets the function called after Close shuts an open connection. | the client itself, so calls chain | cCallback=the name of a function that takes no parameter | OnConnect, Close
OnError | Sets the function called when a Connect, Send or Receive fails. | the client itself, so calls chain | cCallback=the name of a function that takes no parameter | OnConnect, LastError
IsConnected | TRUE if the connection is open. | TRUE or FALSE | | Connect, Close | | unlike the base class, it reports the socket, not whether a request has run
LocalAddress | Returns the local address, which is always the text 127.0.0.1. | the text 127.0.0.1 | | RemoteAddress | the value is a fixed placeholder: the engine does not report the real local address | do not rely on it
RemoteAddress | Returns the remote address, which is always the text 0.0.0.0. | the text 0.0.0.0 | | LocalAddress | the value is a fixed placeholder: the engine does not report the peer's address | do not rely on it
