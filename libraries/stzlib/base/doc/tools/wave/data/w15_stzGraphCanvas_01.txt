# w15 stzGraphCanvas
init | Lays a graph out and works out the size and colour of every node from the graph's own shape. | nothing; the layout is computed when the object is built | poGraph=the stzGraph to draw; paOptions=a hash list, such as :Layout = :Hierarchical (also :Force, :Ring, :Modes, :Sequence, :Mesh), :SizeBy and :ColorBy = :Impact, :Depth, :Degree, :InDegree or :OutDegree, :Width, :Height, :Background, :EdgeColor, :Font, :LabelSize and :LabelColor | Positions, ToCanvas, SetSize | a value that is not a graph raises error stzGraphCanvas: give me an stzGraph; a graph with no node raises error stzGraphCanvas: that graph has no nodes to draw; binding :Depth on a graph with a cycle raises an error saying a node cannot be deeper than itself | the size defaults to 1000 by 620 and both metrics to :Degree; nodes are circles, edges are straight lines, and labels are drawn only when a :Font is given
Width | Returns the width of the drawing, in pixels. | a number, 1000 unless :Width or SetSize gave another | | Height, SetSize | |
Height | Returns the height of the drawing, in pixels. | a number, 620 unless :Height or SetSize gave another | | Width, SetSize | |
EdgeRoutes | Returns the route each long edge takes through the ranks it crosses, in the same space as Positions. | a list of [ from, to, [ [ x, y ], ... ] ]; [ ] when every edge joins neighbouring ranks | | Positions | | an edge a to d over three ranks is one route with two bend points
RawSpanX | Returns how wide the layout was before it was fitted to the canvas. | a number in layout units; 1 for one minimum separation | | RawSpanY, IsUnitX | |
RawSpanY | Returns how tall the layout was before it was fitted to the canvas. | a number in layout units | | RawSpanX, LayerCount | |
LayerCount | Returns how many layers, ranks from top to bottom, the layout has. | a number; 1 for the layouts that have no layers | | RawSpanY, Positions | | the chain mine, smelt, chip, car has 4
IsUnitX | TRUE if the horizontal positions of the layout are in true slot units, not ordinal. | TRUE or FALSE, as 1 or 0 | | RawSpanX, RawPositions | | it is 1 for the hierarchical layout and 0 for the modes, sequence, mesh and ring layouts
LayoutCrossings | Returns how many edge crossings the drawn order contains. | a number; -1 when no hierarchical layout has run, as with the force layout | | LayerCount | | the count is of the order that is drawn, after the sweep and after clusters are compacted
SetSize | Changes the size of the drawing and lays the graph out again for it. | nothing; the layout is recomputed. SetSizeQ returns the object for chaining | pnW=the new width in pixels, at least 1; pnH=the new height in pixels, at least 1 | Width, Height | a size below 1, such as 0 by 5, raises error stzGraphCanvas.SetSize: refused ... a drawing needs area; a value that is not a number raises error stzGraphCanvas.SetSize: give a width and a height | a window reports 0x0 while minimised, so skip that frame rather than call it
MetricValues | Returns a property the graph computes about itself, one number per node, in node order. | a list of numbers: :Impact counts the nodes that fail downstream, :Depth the layer, :Degree the edges in or out, :InDegree and :OutDegree each side | cWhich=the property, one of :Impact, :Depth, :Degree, :InDegree or :OutDegree, in any letter case | Positions, init | any other name, such as betweenness, raises error stzGraphCanvas: I do not compute ...; :Depth on a cyclic graph raises an error, since no layering exists | for the chain mine, smelt, chip, car with a wheel branch, mine has an impact of 4
Positions | Returns where every node sits on the canvas. | a list of [ id, x, y ] in node order, in pixels | | RawPositions, EdgeRoutes | | positions are fitted into the canvas with a margin, so they change with SetSize
RawPositions | Returns the horizontal position each node had in the layout before it was fitted to the canvas. | a list of [ id, x ] in node order | | Positions, IsUnitX | | for the hierarchical layout this is the space a pin lives in
ToCanvas | Builds a stzCanvas of the picture, edges first, then nodes sized and coloured by their metrics, then labels. | a stzCanvas | | ToSVG, ToPNG | | labels need a :Font option; the colours run from green for a low value to red for a high one; ToCanvasQ is the same call
ToSVG | Returns the picture as SVG text; no graphics device is needed. | a text starting with <svg | | ToCanvas, ToPNG | |
ToPNG | Draws the picture on the graphics device and writes it to a PNG file. | the PNG bytes as text; empty when no graphics device is available | pcPath=the path of the file to write | ToSVG, ToCanvas | | it needs a device but opens no window, and the temporary canvas is freed; do not print the answer, it is binary
ModeOf | Returns the mode each node landed in, for the modes layout. | a list of mode numbers in node order; [ ] for the other layouts | | ModeCount | | a mode of two or more states is drawn as a region by the face
ModeCount | Returns how many modes the modes layout found. | a number; 0 for the other layouts | | ModeOf | | on the five-node supply chain with a branch the modes layout gave five modes of one node each
