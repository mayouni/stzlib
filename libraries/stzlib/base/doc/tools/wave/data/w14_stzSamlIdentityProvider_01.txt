init | Builds an identity provider with a fresh random P-256 signing key. | nothing; the object is built | pcEntityId=this provider's entity id, written as the issuer of every assertion | RegisterServiceProvider, TrustMeOn | raises an error when pcEntityId is empty or only spaces | the issuer is written into the assertion as given, without XML escaping
EntityId | Returns this provider's entity id, the issuer of its assertions. | a text | | init
UseSeed | Replaces the signing key with an ES256 key derived from a seed, so assertions can be reproduced in a test. | nothing; use UseSeedQ to chain | pcSeedHex=the 32-byte seed as 64 hex characters, or an empty text for a random key | UseRsaKey, PublicKey | raises an error when the seed is not valid hex | the same seed always gives the same public key
SigningAlgorithm | Returns the signature algorithm in use. | the text ES256, or RS256 after an RSA key was set | | UseSeed, UseRsaKey
UseRsaKey | Signs assertions RSA-SHA256 with a private key you supply, for service providers that accept RSA only. | nothing; use UseRsaKeyQ to chain | pcPem=the RSA private key as PEM text | UseNewRsaKey, SigningAlgorithm | raises an error when the PEM cannot be read | the EC key material is cleared, so KeyX and KeyY answer an empty text afterwards
UseNewRsaKey | Generates a fresh RSA key and signs with it from now on. | nothing; use UseNewRsaKeyQ to chain | nBits=the key size in bits, from 2048 to 4096 | UseRsaKey, PublicKey | raises an error for a size outside 2048 to 4096; generating a key takes a moment | for development and first runs
PublicKey | Returns the public half of the signing key, which is all a service provider needs to verify. | a hash list with kty EC and crv, x, y, or kty RSA and n, e | | TrustMeOn, KeyX
KeyX | Returns the x coordinate of the public EC key in base64url, or an empty text under RSA. | a text | | KeyY, PublicKey
KeyY | Returns the y coordinate of the public EC key in base64url, or an empty text under RSA. | a text | | KeyX, PublicKey
TrustMeOn | Makes a service provider trust this identity provider, passing it the entity id and the public key. | the identity provider itself, so calls chain | poServiceProvider=the stzSamlServiceProvider that is to trust this issuer | PublicKey, RegisterServiceProvider | | the key handed over is the one in use at the call: change the key and call it again to follow; the service provider's earlier trust is replaced
SetLifetime | Sets, in seconds, how long a new assertion stays valid. | nothing; use SetLifetimeQ to chain | pnSecs=the validity of each assertion in seconds | Lifetime, IssueAssertionXT | | the default is 300 seconds
Lifetime | Returns how long a new assertion stays valid, in seconds. | a number | | SetLifetime
RegisterServiceProvider | Registers a service this provider may vouch for. | the identity provider itself, so calls chain | pcEntityId=the service provider's entity id, trimmed; pcAcsUrl=its assertion consumer URL | HasServiceProvider, IssueAssertion | raises an error for an empty entity id and for one already registered | only a registered entity id can be the audience of an assertion
HasServiceProvider | TRUE if a service of that entity id is registered. | TRUE or FALSE | pcEntityId=the service provider's entity id, trimmed before the comparison | RegisterServiceProvider, ServiceProviderIds
ServiceProviderIds | Returns the entity ids of the registered services, in registration order. | a list of texts | | RegisterServiceProvider, AcsUrlOf
AcsUrlOf | Returns the consumer URL a service was registered with, or an empty text for an unknown service. | a text | pcEntityId=the service provider's entity id | RegisterServiceProvider
IssueAssertion | Returns a signed assertion XML vouching for a subject to a registered service, valid from now. | a text holding the signed XML | pcSubject=the subject name, trimmed; pcAudience=the entity id of a registered service | IssueAssertionAt, IssueAssertionXT, IssueResponse | raises an error for an empty subject, an empty audience, and an audience that is not registered | the subject is escaped for & < and > in the XML; a quote is left as it is, which element content allows
IssueAssertionAt | Returns a signed assertion XML whose validity starts at a given moment. | a text holding the signed XML | pcSubject=the subject name; pcAudience=the entity id of a registered service; pnNow=the start of validity in epoch seconds | IssueAssertion, IssueAssertionXT | raises the same errors as IssueAssertion | the window ends Lifetime seconds after pnNow
UnsignedAssertion | Returns the assertion XML before it is signed, with the subject and audience escaped for & < and >. | a text holding the XML, with no signature | pcSubject=the subject name; pcAudience=the audience entity id; pnNow=the start of validity in epoch seconds; pnLifetime=the length of validity in seconds | IssueAssertionXT | | the registration of the audience is not checked here; a subject such as a"b<c>&d gives a"b&lt;c&gt;&amp;d in the NameID element, so markup cannot be injected through the subject
IssueResponse | Returns a signed assertion encoded in base64url, ready to post to the service provider. | a text | pcSubject=the subject name; pcAudience=the entity id of a registered service | IssueResponseAt, IssueAssertion | raises the same errors as IssueAssertion | the encoding is url-safe base64, which stzSamlServiceProvider accepts
IssueResponseAt | Returns a signed assertion in base64url whose validity starts at a given moment. | a text | pcSubject=the subject name; pcAudience=the entity id of a registered service; pnNow=the start of validity in epoch seconds | IssueResponse, IssueAssertionAt | raises the same errors as IssueAssertion
Show | Prints the provider's entity id and how many services are registered. | nothing; it prints a line | | RegisterServiceProvider
