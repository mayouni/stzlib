init | Builds an item-in-a-text object from two texts, the item and the text it belongs to; it works for Item, List and CaseSensitive only. | nothing; the object is built | pItem=the item, which must be a text; paList=the text the item is looked for in, which must be a text too | Item, Positions | the object keeps the text as its list, and every method that needs a list (Positions, NumberOfOccurrence, FirstPosition, IsLowercased...) raises an error "paList must be a list"; the named form [ :In = text ] is rejected as not being a text; the case flag is fixed at 1 | use stzString.Find for an item in a text, or stzItemCS for an item in a list
