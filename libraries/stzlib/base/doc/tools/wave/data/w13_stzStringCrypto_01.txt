# w13 stzStringCrypto -- Name | brief | returns | params | see | warning | note
init | Builds a crypto helper over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the text to hash or encrypt, or a stzString to wrap; any other value raises an error | Content, Sha256 | with a stzString argument, the first in-place edit (ROT13, CaesarEncrypt, Atbash, Obfuscate...) leaves the stzString you passed reading as an empty text, while the helper keeps the right one (ROT13 and Atbash on keep me, both times) | pass a plain text and read the result with Content; the helper is not made by stzString itself, you build it over the same text
Content | Returns the text as it stands now, after any in-place cipher applied through this helper. | a text | | NumberOfChars, IsEmpty
NumberOfChars | Returns how many characters the text holds, counting an Arabic letter or an emoji as one. | a number | | Content, IsEmpty
IsEmpty | TRUE if the text holds no character at all. | TRUE or FALSE, as 1 or 0 | | NumberOfChars, Content
Hash | Returns the 64-bit FNV-1a hash of the text, a quick fingerprint that is not secure. | a number | | Sha256, Checksum | the value is held as a number, so the low digits above 2^53 are rounded: abc gives 16654208175385434112 where the exact hash is 16654208175385433931 | not for passwords or integrity checks; use Sha256 or Blake3
Entropy | Returns the Shannon entropy of the characters, in hundredths of a bit per character. | a number; 0 for a text of one repeated character, 158 for abc | | IsEncrypted, Hash | | the figure is already scaled by 100, so 158 means 1.58 bits
Sha256 | Returns the SHA-256 digest of the text as 64 lower-case hex characters. | a text of 64 hex characters | | Md5, Blake3, HmacSha256 | | the text is hashed as UTF-8 bytes; the digest of abc is ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad, the published test vector
Md5 | Returns the MD5 digest of the text as 32 lower-case hex characters. | a text of 32 hex characters | | Sha256, Blake3 | | MD5 is broken as a security hash; use it only for legacy checksums. The digest of abc is 900150983cd24fb0d6963f7d28e17f72, the published test vector
Blake3 | Returns the BLAKE3 digest of the text as 64 lower-case hex characters. | a text of 64 hex characters | | Sha256, Md5 | | the digest of abc is 6437b3ac38465133ffb63b75273a8db548c558465d79db03fd359c6cd5bd9d85, the published test vector
HmacSha256 | Returns the keyed HMAC-SHA256 of the text as 64 hex characters, so only the key holder can reproduce it. | a text of 64 hex characters; an empty text for an empty key | pcKey=the secret key, as text; an invented one in examples, never a real key | Sha256, XorEncrypt | an empty key returns an empty text instead of the HMAC under the empty key | HMAC of abc under the key key is 9c196e32dc0175f86f4b1cb89289d6619de6bee699e4c378e68309ed97a1a6ab, equal to Python hmac.new
XorEncrypt | Returns the text XORed byte by byte with a repeating key, encoded as base64 so it stays text. | a text in base64; an empty text for an empty key | pcKey=the passphrase that repeats along the text, as text | XorDecrypt, VigenereEncrypted | an empty key returns an empty text; a toy cipher, not secure | the result is base64 because raw cipher bytes are not valid UTF-8 text and the engine would drop them; the helper keeps its own text, and to undo you give the base64 result to XorDecrypt with the same key
XorDecrypt | Returns the plain text recovered from a base64 XOR result and the same key. | a text; an empty text for an empty key | pcKey=the same passphrase that was used to encrypt | XorEncrypt | | the helper must hold the base64 text that XorEncrypt returned; Hebrew, Arabic and emoji text round trips
Checksum | Returns the sum of the code points of every character, a very weak fingerprint. | a number | | ChecksumHex, Hash | | abc gives 294, and an emoji counts as its one code point
ChecksumHex | Returns the checksum written in hexadecimal. | a text, such as 126 for abc | | Checksum | | the text has no 0x prefix
Base64Encode | Returns the text encoded in base64 from its UTF-8 bytes. | a text; Base64Encoded is the same call | | Base64Decode, XorEncrypt | | abc gives YWJj
Base64Decode | Returns the text that a base64 text stands for. | a text; Base64Decoded is the same call | | Base64Encode | | the helper must hold base64; YWJj gives abc
ROT13 | Replaces the held text by its ROT13 form, in place, rotating each Latin letter by 13. | nothing; the text changes. ROT13Q returns the helper for chaining | | ROT13ed, CaesarEncrypt | | only A-Z and a-z move; Hebrew, Arabic and emoji pass through unchanged; applying it twice restores the text
ROT13ed | Returns the ROT13 form of the text, leaving the helper unchanged. | a text | | ROT13 | | Hello gives Uryyb
CaesarEncrypt | Replaces the held text by its Caesar shift of the Latin letters, in place. | nothing; the text changes | nShift=how many places each letter moves forward in the alphabet, 3 for Hello giving Khoor | CaesarEncrypted, CaesarDecrypt | | only A-Z and a-z move; any other script and emoji pass through unchanged; a shift of 26 changes nothing
CaesarDecrypt | Replaces the held text by the Caesar shift of the same size taken backwards, in place. | nothing; the text changes | nShift=the shift that was used to encrypt | CaesarEncrypt | | Khoor with 3 gives Hello; a shift of 29 is read as 3
CaesarEncrypted | Returns the text with each Latin letter moved forward by a shift, leaving the helper unchanged. | a text | nShift=how many places each letter moves forward; a negative shift moves backwards | CaesarEncrypt | | Hello with 3 gives Khoor and with -3 gives Ebiil
VigenereEncrypt | Replaces the held text by its Vigenere encryption under a key word, in place. | nothing; the text changes | pcKey=the key word whose letters give the successive shifts | VigenereEncrypted | an empty key leaves an empty text | the classic ATTACKATDAWN under LEMON gives LXFOPVEFRNHR; Hebrew, Arabic and emoji pass through unchanged
VigenereEncrypted | Returns the Vigenere encryption of the text under a key word, leaving the helper unchanged. | a text | pcKey=the key word whose letters give the successive shifts | VigenereEncrypt | an empty key returns an empty text | ATTACKATDAWN under LEMON gives LXFOPVEFRNHR; Hello World under key gives Rijvs Uyvjn
Atbash | Replaces the held text by its Atbash form, in place, mirroring each Latin letter in the alphabet. | nothing; the text changes | | Atbashed, ROT13 | | a becomes z and Hello becomes Svool; other scripts pass through unchanged; applying it twice restores the text
Atbashed | Returns the Atbash form of the text, leaving the helper unchanged. | a text | | Atbash | | Hello gives Svool
ROT47 | Replaces the held text by its ROT47 form, in place, rotating the printable ASCII characters by 47. | nothing; the text changes | | ROT47ed, ROT13 | | Hello gives w6==@; digits and punctuation move too; characters outside printable ASCII pass through unchanged; applying it twice restores the text
ROT47ed | Returns the ROT47 form of the text, leaving the helper unchanged. | a text | | ROT47 | | Hello gives w6==@
IsEncrypted | TRUE if the entropy figure of the text is above 4, which almost any text with two different characters passes. | TRUE or FALSE, as 1 or 0 | | Entropy | answers TRUE for ab, abab and a plain English sentence, and FALSE only for a text of one repeated character or an empty one: Entropy is scaled by 100 (hundredths of a bit) and is compared with 4 as if it were in bits, so the answer cannot tell cipher text from plain text today | do not use it to detect encryption
Obfuscate | Replaces the held text by its reversal XORed with the fixed key ZiN and written in base64, in place. | nothing; the text changes. ObfuscateQ returns the helper for chaining | | Obfuscated, Deobfuscate | | a fixed key, so it hides text from a glance and is not encryption
Obfuscated | Returns the obfuscated form of the text, leaving the helper unchanged. | a text in base64 | | Obfuscate, Deobfuscated | | Hello gives NQUiPyE=
Deobfuscated | Returns the plain text hidden by an obfuscation, leaving the helper unchanged. | a text | | Obfuscated, Deobfuscate | | the helper must hold the base64 text that Obfuscated returned
Deobfuscate | Replaces the held base64 text by the plain text it hides, in place. | nothing; the text changes. DeobfuscateQ returns the helper for chaining | | Obfuscate, Deobfuscated | | undoes Obfuscate
