init | Builds a desk that rehearses, judges and commits payout plans for one port under one policy, keeping its journal in a folder. | nothing; the object is built | poPort=the stzPaymentsPort that will be told what to allow and then release; poPolicy=the stzPayoutPolicy that judges every plan; pcDir=the folder where a committed plan is written as its journal file | Rehearse, Commit, StzDikoPayoutPolicyQ | | each desk has its own journal, and a plan is known only to the desk it was rehearsed on
PathOf | Returns where a plan is written, in the desk's folder: the rehearsed document in a workbench and the journal file once committed. | a text: <folder>/<plan id>.plan.json | pcPlanId=the plan's identifier | Rehearse, Commit
Rehearse | Writes a plan's document into a workbench, a twin of the disk, so it can be judged without anything real moving. | the desk itself, so calls chain | poPlan=the stzPayoutPlan to rehearse; pnBench=the workbench number returned by StzOpenAgentWorkbench | Judge, Commit | the desk keeps the plan as it is now: visas added to the plan afterwards are not seen until it is rehearsed again, and rehearsing again overwrites the document; one plan, one workbench | the proposer acts in the workbench under the plan's proposer name, and no real file exists yet
Judge | Returns the verdict of the policy on the plan document held in the workbench, in the house rule report. | a stzRuleReport: IsSound is 1 when no rule fails and Errors lists the failing ones, each naming its rule | pnBench=the workbench the plan was rehearsed into; pcPlanId=the identifier of the plan to judge | Rehearse, Commit | | a verdict is not a payment: a sound plan still pays nothing until a person commits it
Commit | Lets an actor who may change reality release a judged plan: its journal file is written, then each item is paid through the port. | a list [ committed, reason, detail, results, file ]: committed is 1 or 0, results holds one answer per item, file is the journal path | pnBench=the workbench the plan was rehearsed into; pcPlanId=the identifier of the plan to commit; poActor=the actor committing it, such as HumanActor("tresorier") | Rehearse, Judge, Journal | a refusal never raises: committed is 0 and reason is unknown-plan, already-committed, policy, rehearsal-differs, actor or crossing, with the cause in detail; a language-model actor, a sandboxed actor and a value that is not an object are all refused for actor; the checks run in that order and the policy is judged before the actor; a plan commits once; an item the port refuses is that item's error in results while the others still go | money out is a plan that a human commits: a refusal is a journal row and a payout.refused event, a commit is a journal row, a payout.committed event and a real file | the port is told exactly which payouts to allow and for how much, and refuses any other
Journal | Returns the desk's record of every commit attempt, oldest first, whether it was refused or went through. | a list of records [ seq, plan, outcome, reason, actor, total, visas ] where outcome is committed or refused | | Commit | | a second desk has its own empty journal
