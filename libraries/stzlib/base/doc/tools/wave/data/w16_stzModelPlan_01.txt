init | Wraps a plan produced by the registry so it can be read by name and explained. | nothing; the object is built | paPlan=a plan as the registry returns it: a list of [ key, value ] pairs faculty, chosen, kind, why, rejected, floor, refusal, findings, pinned | stzModelRegistry, Data | the list is not checked: an empty list is accepted and the readers then return empty values | the plan is kept as a copy, so changing the list afterwards does not change the object
Data | Returns the plan as the list of [ key, value ] pairs it was built from. | a list of pairs: faculty, chosen, kind, why, rejected, floor, refusal, findings, pinned and needle | | Why, Chosen | |
Faculty | Returns the name of the faculty the plan is for. | a text | | Chosen, Data | |
Chosen | Returns the id of the implementation the plan picked. | a text; an empty text when the plan is a refusal | | Kind, Floor, IsRefusal | |
Kind | Returns which kind of implementation the plan picked. | a text: floor, model, dlm or service; an empty text for a refusal | | Chosen, IsFloor | | the registry picks a service only when it was pinned by name
Floor | Returns the id of the faculty's floor, the fallback the plan keeps. | a text; an empty text when the faculty is unknown | | Chosen, IsFloor | | this is the floor's id and not its row: Floor of the faculty returns the row
IsRefusal | TRUE if the plan is a refusal: nothing can answer, or a pin cannot be honoured, or the requirement forbids the floor. | TRUE or FALSE | | Findings, Why | | a refusal plan has an empty chosen id and its findings say why
IsFloor | TRUE if the plan picked the faculty's floor, whether the registry fell back to it or it was pinned. | TRUE or FALSE | | Kind, Chosen | |
Rejected | Returns each implementation the plan turned down, with the reason. | a list of [ id, reason ] pairs; [ ] when nothing was rejected | | Why, Chosen | | reasons name the filter: not installed, not permissive, memory, language, determinism, unmeasured, not beating the floor, a lower rank, a service
Findings | Returns the findings of a refusal plan, in the house shape. | a list of findings, each [ rule, subject, where, severity, message ]; [ ] when the plan is not a refusal | | IsRefusal, Why | |
Why | Returns the whole explanation: the choice, one line per reason, then each rejection and each finding. | a text with one line per fact, starting with the faculty and the chosen implementation or REFUSED | | Rejected, Findings, Data | | the scores it quotes are measured by the registry on the golden set and are not judged by a person
