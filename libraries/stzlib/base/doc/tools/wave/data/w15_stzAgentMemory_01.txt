init | Builds an empty memory for the named agent, backed by its own knowledge graph called mem-<name>. | nothing; the object is built | pcAgentName=the owning agent's name, recorded as the source of every fact it learns | Learn, GraphQ
GraphQ | Returns the knowledge graph the memory holds, for queries the memory face does not offer. | a stzKnowledgeGraph | | Prove, Save
Learn | Stores one fact as a subject, predicate, object triple, in lower case, with the owning agent and the time as its provenance. | the memory itself, so calls chain | pcS=the subject; pcP=the predicate; pcO=the object | Fact, Forget | | learning a fact already held adds nothing; LearnXT takes the caller's own provenance, such as [ :source = "sensor-3", :confidence = 0.8 ], and defaults :source to agent:<name>
ProvenanceOf | Returns where a fact came from: the source, the learning time and any confidence recorded with it. | a hash list [ :source, :learnedat ] plus :confidence when given; an empty list for an unknown fact | pcS=the subject; pcP=the predicate; pcO=the object | Fact | | the source keeps the agent name as it was given
Fact | TRUE if the memory holds that exact triple; case is ignored. | TRUE or FALSE | pcS=the subject; pcP=the predicate; pcO=the object | Recall, Learn
Recall | Returns every object the memory holds for a subject and predicate, in the order learned. | a list of text; empty when nothing is known | pcS=the subject; pcP=the predicate | Fact, Learn
Forget | Removes one fact; forgetting a fact that is not held changes nothing. | the memory itself, so calls chain | pcS=the subject; pcP=the predicate; pcO=the object | Learn, NumberOfFacts
NumberOfFacts | Returns how many facts the memory holds. | a number | | Learn, Forget
Prove | Asks the graph to prove a triple from recorded facts and lawful chains, with the reasoning narrated. | a hash list [ :verdict, :goal, :steps, :narration, :certainty ]; verdict is 1 when proved, 0 when not derivable | paTriple=a list [ subject, predicate, object ], in lower case | Fact, GraphQ
Save | Writes the memory, provenance included, to a knowledge file, adding the extension .zknw when it is missing. | nothing; a file is written | pcFile=the path of the file to write | Restore, GraphQ | Restore needs the full name: a file saved as mem is written as mem.zknw, and Restore of mem raises error R13 Object is required because the name is read as the text of a knowledge file | pass a name ending in .zknw to both Save and Restore
Restore | Reads a saved memory back, provenance included, and merges its facts into this memory. | a hash list [ :merged, :refused ]; refused rows are [ s, p, o, why ] | pcFile=the path of a .zknw file; a name without that extension is read as the text of a file and raises error R13 | Save, Learn | | merged counts the facts read, including ones already held
