init | Builds a conversation session on a topic, with no goal, plain fluency and an empty transcript. | nothing; the object is built | pcTopic=the topic name, which also tags the source of every answer admitted | SetGoal, NextQuestion
Topic | Returns the topic the session was built with. | a text | | Save
SetGoal | Hands the session the one goal it is accountable for, and starts pursuing it. | the conversation itself, so calls chain | poGoal=the stzGoal to pursue, such as StzGoalQ().RequireEach(dish, contains) | GoalQ, MonitorGoal, RevokeGoal | raises an error for a value that is not a stzGoal and while another goal is still being pursued | after a goal is revoked or fulfilled a new one may be set
GoalQ | Returns the goal object the session is accountable for. | the stzGoal object | | HasGoal, SetGoal | raises an error while no goal is set, so test HasGoal first
HasGoal | TRUE if a goal was handed over. | TRUE or FALSE | | SetGoal, GoalState
GoalState | Returns where the goal stands: none, pursuing, fulfilled or revoked. | a text | | GoalWhy, MonitorGoal
GoalWhy | Returns why the goal ended as it did. | a text; empty while none or pursuing | | GoalState, RevokeGoal
IsPursuingGoal | TRUE if a goal is set and neither fulfilled nor revoked. | TRUE or FALSE | | GoalState
IsGoalFulfilled | TRUE if no gap remains for the goal in the space. | TRUE or FALSE | | GoalState, MonitorGoal
IsGoalRevoked | TRUE if the goal was abandoned on the record. | TRUE or FALSE | | GoalState, RevokeGoal
RevokeGoal | Abandons the goal with a reason, clearing the pending question. | the conversation itself, so calls chain | pcWhy=the reason, kept in GoalWhy and written to the transcript | GoalWhy, SetGoal | raises an error unless the goal is being pursued | a revoked goal asks nothing more and cannot be concluded
MonitorGoal | Re-reads the goal against the space and marks it fulfilled once no gap remains. | a text, the goal state after the check | poSpace=the stzKnowledgeGraph the conversation runs in | GoalState, Gaps | | NextQuestion and Reply call it themselves
History | Returns the transcript lines, in order. | a list of [ speaker, text, certainty ] rows, speaker being system, user or verdict | | Transcript
NumberOfTurns | Returns how many turns have passed: one for each question asked and each reply given. | a number | | History, Checkpoints
Gaps | Returns the facts the goal still lacks in the space. | a list of [ subject, relation, why ] rows; [ ] when the goal is met | poSpace=the stzKnowledgeGraph the conversation runs in | NextQuestion, MonitorGoal | raises an error while no goal is set
NextQuestion | Returns the next question, born from the first gap, and remembers it as the pending one. | a text, the question with its reason; empty when the goal is fulfilled or revoked | poSpace=the stzKnowledgeGraph the conversation runs in | Reply, Options, Force | raises an error while no goal is set | NextQuestionXT gives the same question as data: question, force, subject, relation, options and why
Options | Returns the values offered with the pending question. | a list of text; [ ] when the question is open | | Force, Reply | | values that the relation already takes elsewhere in the space become numbered options
Force | Returns the kind of the pending question: which for a closed choice, what for an open one. | a text; empty when nothing is pending | | Options, NextQuestion
SetFluency | Chooses plain or neural wording of the questions. | the conversation itself, so calls chain | pcMode=plain or neural, without regard to case | Fluency, IsFluencyNeural | raises an error for any other mode | neural wording needs a generative model loaded; without one the plain wording is kept
Fluency | Returns the fluency that was asked for. | a text, plain or neural | | SetFluency, IsFluencyNeural
IsFluencyNeural | TRUE if neural wording was asked for and a generative model is really loaded. | TRUE or FALSE | | SetFluency | | FALSE means the questions are on the deterministic floor
Reply | Answers the pending question; each value passes the space governed admission, and refusals become checkpoints. | a hash-list [ :admitted, :refused, :narration, :goalState ]; :refused holds [ value, reason ] rows | poSpace=the stzKnowledgeGraph that admits the values; pAnswer=a number or list of numbers that pick offered options, text such as X and Y, or a list of text | NextQuestion, Checkpoints, Why | raises an error when no question is pending; a number that matches no offered option is refused and checkpointed, not guessed | values are split at commas and the word and; one admitted value is enough to clear the pending question
Why | Returns the explanation of the last admission or refusal. | a text; empty before the first reply | | Reply, Checkpoints
SetCheckpointTTL | Sets for how many turns a refusal checkpoint stays live. | the conversation itself, so calls chain | nTurns=the number of turns, or 0 for never expiring | CheckpointTTL, Checkpoints | raises an error for a negative number | nothing is deleted; AllCheckpoints keeps the full record
CheckpointTTL | Returns for how many turns a checkpoint stays live. | a number; 0 means it never expires | | SetCheckpointTTL
Checkpoints | Returns the refusal checkpoints still live, which a human has yet to see. | a list of hash-lists with subject, relation, attempted, why and turn | | AllCheckpoints, NumberOfExpiredCheckpoints
AllCheckpoints | Returns every refusal checkpoint ever raised, expired or not. | a list of hash-lists with subject, relation, attempted, why and turn | | Checkpoints
NumberOfExpiredCheckpoints | Returns how many checkpoints have outlived the TTL. | a number | | Checkpoints, AllCheckpoints
Conclude | Writes the finished knowledge space to a file, once the goal has no gap left. | 1 when the file was written | poSpace=the stzKnowledgeGraph the session grew; pcKnowFile=the base path of the knowledge file, written as .zknw | Gaps, MonitorGoal | raises an error while no goal is set, when the goal was revoked, and when gaps remain
Save | Writes the topic and the transcript to a .zcnv file. | a text, the path written, with .zcnv added when missing | pcFile=the path to write | Transcript, Topic | | the goal state and checkpoints are not written, and the class has no Load
Transcript | Returns the transcript as dialogue text, SOFTANZA and YOU lines with each verdict under its answer. | a text | | History, Save
