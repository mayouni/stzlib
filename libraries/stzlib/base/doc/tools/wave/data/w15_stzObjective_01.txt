MathFunctionQ | Returns the stzMathFunction that holds the compiled formula, to ask its derivatives directly. | a stzMathFunction | | ValueAt, GradientAt | | there is no plain form because it would return an object; the Q is the name
ValueAt | Returns the value of the formula at a point. | a number | paPoint=the values of the variables, one per variable in declared order | GradientAt, MinimizeFrom | | the same as stzMathFunction.ValueAt; a point of the wrong length raises an error

SetMaxIterations | Sets how many iterations the search may take before it gives up; the default is 500. | nothing; use SetMaxIterationsQ to chain | n=the limit, a number above 0 | SetGradientTolerance, MinimizeFrom | | a value of 0 or less is ignored without a message and the limit stays as it was
SetGradientTolerance | Sets how small the gradient must become for the search to call itself done; unset, the engine's default applies. | nothing; use SetGradientToleranceQ to chain | n=the tolerance, a number above 0 | SetMaxIterations | | a value of 0 or less is ignored without a message; a large tolerance stops the search early, away from the minimum
MinimizeFrom | Searches downhill from a starting point with L-BFGS and returns the point it reached with a record of how the search ended. | a hash list with :point, :value, :status, :iterations, :evaluations, :gradientNorm and :why | paStart=the starting values of the variables, one per variable in declared order | MaximizeFrom, SetMaxIterations | | check :status, which is "converged", "settled", "maxiterations", "linesearchfailed" or "notfinite" (lowercase, since Ring folds the case of symbols): a point is returned even when the search did not converge; it finds a local minimum, so the start matters
MaximizeFrom | Searches uphill from a starting point and returns the record of MinimizeFrom, holding the formula's own value, not its negative. | a hash list with :point, :value, :status, :iterations, :evaluations, :gradientNorm and :why | paStart=the starting values of the variables, one per variable in declared order | MinimizeFrom | | a formula with no maximum ends with :status "linesearchfailed": maximising (x-1)^2 + (y-2)^2 from [ 0, 0 ] returns the start
