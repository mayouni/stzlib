init | Builds an inserter over a list or over a stzList object, working on its own copy, so the list passed in is never changed. | nothing; the object is built | pListOrObj=a list, or a stzList object, in which items will be inserted, moved or swapped | Content | any other kind of value raises "Can't create stzListInserter! Parameter must be a list or stzList object." |
Content | Returns the items the inserter holds, after the insertions made through it. | a list | | NumberOfItems | |
NumberOfItems | Returns how many items the list holds now. | a number | | Content | |
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE | | NumberOfItems | |
Insert | Inserts an item before a position, or after one when the place is written [ :After, n ]. | nothing; use InsertQ to chain | pItem=the item to insert; pWhere=a position (the item goes before it), or a named place such as [ :At, 2 ], [ :Before, 2 ] or [ :After, 2 ] | InsertBeforePosition, InsertAfterPosition | a position of 0, or a named place that is neither of those (such as [ :Foo, 1 ]), is ignored without a message; a position two or more past the end kills the process with R14 (ExtendToN), see InsertBeforePosition | a position one past the end appends
InsertItem | Inserts an item before a position, or after one when the place is written [ :After, n ], the same as Insert. | nothing | pItem=the item to insert; pWhere=a position (the item goes before it), or a named place such as [ :At, 2 ] or [ :After, 2 ] | Insert | |
InsertBeforePosition | Inserts an item so that it takes the given position, pushing the item there and the ones after it one place on. | nothing; use InsertBeforePositionQ to chain | _n_=the position to take, from 1; a position one past the end appends; a list of positions inserts one copy of the item at each; pItem=the item to insert | InsertAfterPosition, InsertBeforePositions | a position two or more past the end calls ExtendToN, which does not exist, and kills the process with error R14; a position of 0 or below is ignored without a message | positions in a list are all counted on the original list
InsertBefore | Inserts an item so that it takes the given position, the same as InsertBeforePosition. | nothing | _n_=the position to take, from 1; pItem=the item to insert | InsertBeforePosition | the same R14 process kill for a position two or more past the end; 0 or below is ignored without a message |
InsertAt | Inserts an item so that it takes the given position, handing the work to Ring's insert. | nothing; use InsertAtQ to chain | _n_=the position the item takes, from 1; a named [ :Position, n ] is accepted; pItem=the item to insert | InsertBefore | A position of 0 or below raises an error with no message (ERR-) and a position past the end plus one raises R2 today, where InsertBefore ignores 0 and appends one past the end; only 1 up to the length plus one works | one past the end appends
InsertAfterPosition | Inserts an item right after the given position, so it takes the position after it. | nothing; use InsertAfterPositionQ to chain | _n_=the position to insert after, from 1 to the length; pItem=the item to insert | InsertBeforePosition, InsertAfter | a position of 0, or past the length, is ignored without a message; a list of positions calls InsertAfterPositions, which does not exist, and kills the process with error R14 | the last position appends
InsertAfter | Inserts an item right after the given position, the same as InsertAfterPosition. | nothing | _n_=the position to insert after, from 1 to the length; pItem=the item to insert | InsertAfterPosition | an out-of-range position is ignored without a message; a list of positions kills the process with error R14, as in InsertAfterPosition |
InsertBeforePositions | Inserts a copy of an item before each of several positions, all counted on the original list. | nothing; use InsertBeforePositionsQ to chain | panPositions=the positions, in any order; a position listed twice inserts two copies there; pItem=the item to insert | InsertBeforePosition | the same R14 process kill if a position is two or more past the end |
MoveItem | Takes the item out of one position and puts it before the item that stood at another one. | nothing; use MoveItemQ to chain | _n1_=the position of the item to move; _n2_=the position it should go before; both from 1 to the length | SwapItems | Moving an item towards the end lands it one place short of the target: MoveItem(1, 3) on a b c d gives b a c d and MoveItem(1, 2) or MoveItem(2, 3) changes nothing; moving towards the start is exact, MoveItem(3, 1) gives c a b d. A position out of range raises "Position out of range!" | named places [ :From, 1 ] and [ :To, 3 ] are accepted
SwapItems | Exchanges the items at two positions. | nothing; use SwapItemsQ to chain | _n1_=the position of the first item; _n2_=the position of the second item; named places [ :Between, 1 ] and [ :And, 3 ] are accepted | Swap, MoveItem | a position past the end changes nothing and says nothing, and a position of 0 is read as 1: SwapItems(0, 2) on a b c d gives b a c d |
Swap | Exchanges the items at two positions, the same as SwapItems. | nothing | _n1_=the position of the first item; _n2_=the position of the second item | SwapItems | an out-of-range position is ignored without a message, and 0 is read as 1 |
