# Wave 12 -- stzJwt. Name | brief | returns | params | see | warning | note
init | Wraps one JSON Web Token given as text and cuts it at its dots into header, payload and signature. | nothing; the object is built | pcToken=the token, three base64url parts joined by dots; surrounding blanks are trimmed | IsWellFormed, SignatureIsValidWith | nothing is checked at construction: a malformed token is accepted and reads as empty
Token | Returns the token text this object wraps, trimmed. | a text | | init, SigningInput
IsWellFormed | TRUE if the token has exactly three dot-separated parts and the first two are not empty. | TRUE or FALSE | | SigningInput, SignatureIsValidWith | | it checks the shape only, not that the parts decode
SigningInput | Returns the text the signature covers, the header part and the payload part joined by a dot. | a text; the empty text when the token is not well formed | | SignatureB64, SignatureIsValidWith
SignatureB64 | Returns the third part, the signature, still base64url encoded. | a text; the empty text when the token has fewer than three parts | | SigningInput, SignatureIsValidWith
Header | Returns the decoded header of the token, normally a JSON text such as {"alg":"ES256","typ":"JWT","kid":"..."}. | a text; the empty text when there is no first part | | Payload, Algorithm, KeyId | | the part is decoded whatever it holds, so a part that is not base64url gives bytes that are not JSON
Payload | Returns the decoded payload of the token, normally the JSON text of its claims. | a text; the empty text when there is no second part | | Header, Claim, ClaimInt | | the claims are only data until SignatureIsValidWith has passed against a key you hold
Algorithm | Returns the algorithm the header declares, such as ES256. | a text; the empty text when the header is missing or not JSON | | KeyId, SignatureIsValidWith | | for information only: verify with the algorithm of the key you hold, never with this one
KeyId | Returns the kid the header names, the key that signed the token. | a text; the empty text when there is none | | Algorithm, Header
Claim | Returns the value of a claim of the payload as text. | a text; the empty text when the claim is absent or the payload is not JSON | pcName=the claim name, such as "sub" or "email" | ClaimInt, HasClaim, Subject
ClaimInt | Returns the value of a numeric claim of the payload, such as exp. | a number; 0 when the claim is absent or the payload is not JSON | pcName=the claim name, such as "exp" | Claim, HasClaim
HasClaim | TRUE if the payload carries a claim of that name. | TRUE or FALSE; FALSE when the payload is not JSON | pcName=the claim name to look for | Claim, ClaimInt
Subject | Returns the sub claim, the identity the token is about. | a text; the empty text when absent | | Claim, Issuer
Issuer | Returns the iss claim, the party that issued the token. | a text; the empty text when absent | | Claim, Subject, Audience
Audience | Returns the aud claim, the party the token was issued for. | a text; the empty text when absent | | Claim, Issuer
SignatureIsValidWith | TRUE if the token's signature verifies against one public key given as a JWK, EC with ES256 or RSA with RS256. | TRUE or FALSE; FALSE for a malformed token, a foreign key, an unknown key type or a malformed key | paJwk=the public key as a list of [ name, value ] pairs: [ :kty, :x, :y ] for EC or [ :kty, :n, :e ] for RSA | stzOidcClient, Algorithm | a TRUE proves only that the key's owner signed the token, not that it is meant for you, nor recent: check iss, aud and exp too, as VerifyIdToken does | the key type picks the algorithm; the alg of the header is ignored
Show | Prints a one-line summary: the declared algorithm, the subject and the issuer. | nothing; it prints | | Algorithm, Subject, Issuer
