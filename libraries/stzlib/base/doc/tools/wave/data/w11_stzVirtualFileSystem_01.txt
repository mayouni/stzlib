init | Builds a file twin with an empty in-memory tree, a bridge to the disk and no history. | nothing; the twin is built | | MirrorFrom, StzVirtualFileSystemQ
CreateFile | Rehearses creating a file with its content; the disk is not touched. | the twin itself, so calls chain | pcPath=the path of the file; pcContent=the content, as text | WriteFile, DeleteFile | | a path that already exists has its content replaced, without an error
WriteFile | Rehearses writing content into a file; the disk is not touched. | the twin itself, so calls chain | pcPath=the path of the file; pcContent=the content, as text | CreateFile, ContentOf | | it is recorded as a write, so the narration says write rather than create
CreateFolder | Rehearses creating a folder; the disk is not touched. | the twin itself, so calls chain | pcPath=the path of the folder | DeleteFolder, Exists | | the folder that holds it is not required to exist
DeleteFile | Rehearses deleting a file; the disk is not touched. | the twin itself, so calls chain | pcPath=the path of the file | CreateFile, GenerateUpdatePlan | | an absent path is recorded and changes nothing; the plan flags the delete as destructive and Validate flags a target absent from the disk
DeleteFolder | Rehearses deleting a folder; the disk is not touched. | the twin itself, so calls chain | pcPath=the path of the folder | CreateFolder, DeleteFile | the files below it stay in the twin; delete them first, as the real folder delete refuses a folder that is not empty
CopyFile | Rehearses copying a file to another path; the disk is not touched. | the twin itself, so calls chain | pcFrom=the path of the file to copy; pcTo=the path of the copy | MoveFile, ContentOf | a source the twin does not hold makes an empty file at the destination, which the disk would refuse; Validate catches it against the disk
MoveFile | Rehearses moving a file to another path; the disk is not touched. | the twin itself, so calls chain | pcFrom=the path of the file to move; pcTo=the path it moves to | CopyFile, DeleteFile | a source the twin does not hold makes an empty file at the destination, which the disk would refuse; the plan flags a move as removing its source
MirrorFile | Reads one real file into the twin, marked as mirrored, so a rehearsal starts from what the disk holds. | the twin itself, so calls chain | pcPath=the real path of the file | MirrorFrom, OriginOf | an absent file changes nothing | it reads the disk and changes nothing; the mirrored file is not counted in the history
MirrorFrom | Replaces the twin tree with the files of one real folder, each marked as mirrored. | the twin itself, so calls chain | pcDir=the real folder to read, one level only | MirrorFile, stzFileSystemBridge | it reads the disk and changes nothing; whatever the twin held before is dropped
Exists | TRUE if the twin holds a file or folder at that path. | TRUE or FALSE | pcPath=the path | ContentOf, Paths | | it answers from the twin, not from the disk
ContentOf | Returns the content the twin holds at that path. | a text; an empty text for a folder or an absent path | pcPath=the path | SizeOf, Exists
SizeOf | Returns the size of the content the twin holds at that path, in bytes. | a number; 0 for a folder or an absent path | pcPath=the path | ContentOf
OriginOf | Returns where a path of the twin came from. | mirrored for one read from the disk, virtual for one born in the twin; an empty text when absent | pcPath=the path | MirrorFile, Exists
Paths | Returns every path the twin holds, in the order added. | a list of text | | NumberOfNodes, TreeView
NumberOfNodes | Returns how many files and folders the twin holds. | a number | | Paths
TreeView | Returns the twin as text, one line per node with its type, its path and its origin. | a text, several lines | | Show, Paths
Show | Prints the number of nodes of the twin and its tree view. | nothing; it prints | | TreeView
