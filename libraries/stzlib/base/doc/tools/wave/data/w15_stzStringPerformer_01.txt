init | Builds a performer over a text or over a stzString object, to apply an expression to its characters. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, whose characters are visited | Yield, Perform | any other kind of value raises "Can't create stzStringPerformer! Parameter must be a string or stzString object."; nothing here changes the text, so a stzString passed in is safe |
Content | Returns the text the performer holds, which no method of this class changes today. | a text | | Yield | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
Perform | Leaves the text unchanged today instead of replacing every character by the result of an expression. | nothing; the text is unchanged | pcAction=the expression as text, where @char stands for the character, such as "upper(@char)" | Yield, PerformOn | Has no effect today: Perform("upper(@char)") on "abc" leaves "abc", because the result of the engine call is dropped and never written back; use Yield to get the results as a list |
PerformOn | Leaves the text unchanged today instead of replacing the characters at some positions by the result of an expression. | nothing; the text is unchanged | panPos=the positions, from 1; pcAction=the expression as text, where @char stands for the character | YieldOn, Perform | Has no effect today: PerformOn([1], "upper(@char)") on "abc" leaves "abc"; the positions are not even read; use YieldOn |
Yield | Returns the results of an expression applied to each character, in order, as a list. | a list with one result per character; [ ] for an empty text | pcYielder=the expression as text, where @char stands for the character and @i for its position, such as "upper(@char)" | YieldOn, Perform | | "abc" with "upper(@char)" gives A, B, C; len(@char) counts bytes, so שלום gives 2 for each letter and 😀 gives 4; the text is not changed
YieldOn | Returns the results of an expression for the characters at the given positions only, in the order of the positions. | a list of results; positions outside the text are skipped | panPos=the positions to read, from 1, in the order wanted; pcYielder=the expression as text, where @char stands for the character | Yield, YieldW | | [3, 1] on "abc" with "upper(@char)" gives C, A; 0 and 9 are skipped
