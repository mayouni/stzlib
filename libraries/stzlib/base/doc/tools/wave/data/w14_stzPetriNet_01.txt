init | Builds an empty Petri net that draws left to right with the Petri notation, with a title. | nothing; the object is built | pcTitle=the title of the diagram | AddPlace, AddTransition
AddPlace | Declares a place, a circle that holds tokens, with no token; AddPlaceXT gives it an initial marking. | the net itself, so calls chain | pcId=the place's identifier, which must be new in the net; pcName=the place's name, shown beside its circle; pnTokens=the initial number of tokens, a whole number from 0, taken by AddPlaceXT | AddTransition, SetTokens, Tokens | an identifier already in the net raises an error; a marking that is negative or not a whole number raises an error | AddPlaceQ and AddPlaceXTQ are the same calls
AddTransition | Declares a transition, the bar across the flow that moves tokens when it fires. | the net itself, so calls chain | pcId=the transition's identifier, which must be new in the net; pcName=the transition's name, shown beside its bar | AddPlace, Arc, Fire | an identifier already in the net raises an error | AddTransitionQ is the same call
AddNote | Adds a free note to the drawing; it is not a node of the net. | the net itself, so calls chain | pcId=the note's identifier; pcText=the text of the note | AddPlace | the rules and the token game ignore a note
Arc | Draws a token path from one node to another with weight 1; ArcXT gives the weight. | the net itself, so calls chain | pcFrom=the identifier of the place or transition the arc leaves; pcTo=the identifier of the place or transition it enters; pnWeight=how many tokens the arc moves, a whole number from 1, taken by ArcXT | Places, Transitions, Fire | a node that is not in the net raises an error; two places or two transitions are accepted here and reported by the rule arc_joins_place_and_transition; a weight above 1 is written on the arc | ArcQ and ArcXTQ are the same calls
Places | Returns the places, in the order they were added, with their current tokens. | a list of hashlists with the keys id, name and tokens | | Transitions, Marking, Tokens
Transitions | Returns the transitions, in the order they were added. | a list of hashlists with the keys id and name | | Places, Arcs
Arcs | Returns the arcs, in the order they were added. | a list of hashlists with the keys from, to and weight | | Arc, InputsOf, OutputsOf
Tokens | Returns how many tokens a place holds now. | a number | pcPlace=the identifier of the place, without regard to case | SetTokens, Marking | an identifier that is not a place raises an error
SetTokens | Sets the number of tokens in a place, replacing its marking. | the net itself, so calls chain | pcPlace=the identifier of the place; pnTokens=the new number of tokens, a whole number from 0 | Tokens, Fire | an unknown place, or a number that is negative or not whole, raises an error
Marking | Returns the marking: every place with its current tokens, the state of the net. | a list of [ place, tokens ] pairs, in the order the places were added | | Tokens, Places, Fire
InputsOf | Returns the input arcs of a transition: the places it takes tokens from and how many. | a list of [ place, weight ] pairs | pcTrans=the identifier of the transition, without regard to case | OutputsOf, WhyNotEnabled | it tests only that the arc leaves a place, so asked of a place that another place feeds it answers that arc
OutputsOf | Returns the output arcs of a transition: the places it gives tokens to and how many. | a list of [ place, weight ] pairs | pcTrans=the identifier of the transition, without regard to case | InputsOf, Fire
WhyNotEnabled | Returns the reason a transition cannot fire, naming the short place and by how much. | a text such as place 'Idle' holds 1 and the arc wants 2; empty when the transition can fire | pcTrans=the identifier of the transition | IsEnabled, Fire | an identifier that is not a transition raises an error
IsEnabled | TRUE if every input place of the transition holds at least its arc's weight. | TRUE or FALSE | pcTrans=the identifier of the transition | WhyNotEnabled, Enabled, Fire | an identifier that is not a transition raises an error
Enabled | Returns the identifiers of the transitions that can fire now. | a list of text, in the order the transitions were added | | IsEnabled, Fire
Fire | Fires a transition: takes each input arc's weight from its place and gives each output arc's weight to its place. | the net itself, so calls chain | pcTrans=the identifier of the transition to fire | IsEnabled, WhyNotEnabled, Marking | a transition that is not enabled raises an error naming the short place and the numbers, and changes nothing, so a net never goes negative | FireQ is the same call
AsRuleGraph | Returns the net as a plain graph that the five Petri rules read. | a stzGraph with the places, transitions and notes as nodes and the arcs as edges | | GovernanceFindings
GovernanceFindings | Returns what the five Petri rules find wrong with the net, warnings included. | a list of findings, each a hashlist with the keys rule, where, severity and message; empty when the net is sound | | GovernanceIsSound, AsRuleGraph | the rules are arc_joins_place_and_transition, transition_has_input, transition_has_output, place_can_be_marked and transition_can_fire | CheckRules is the same call
GovernanceIsSound | TRUE if the rules found no error; warnings do not count against it. | TRUE or FALSE | | GovernanceFindings | RulesAreSound is the same call
RenderTokens | Returns what the last drawing wrote inside each place. | a list of [ place, count, x, y ] rows; empty before the first drawing | | Marking | one to four tokens are drawn as dots, five or more as the number
