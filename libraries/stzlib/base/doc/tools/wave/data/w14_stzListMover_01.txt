# w14 stzListMover -- Name | brief | returns | params | see | warning | note
init | Builds a mover over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to reorder, or a stzList whose content is copied, any other value raises an error | Content, Reversed | | the mover works on its own copy: reordering it never changes the list or the stzList you passed in, so read the result with Content
Content | Returns the list as it stands now, after the in-place moves made so far. | a list | | List, Reversed
List | Returns the list as it stands now. | a list | | Content, NumberOfItems | | the same answer as Content
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
Move | Takes the item at one position and puts it at another, the items in between shifting by one, in place. | nothing; the content changes. MoveQ returns the mover for chaining | _n1_=the position to take the item from, or a pair such as [ :From, 2 ]; _n2_=the position the item must end at, or a pair such as [ :To, 5 ] | Swap, MoveToStart, MoveToEnd | | a position outside the list moves nothing and says nothing: Move(9, 1) leaves a b c d e as it was
Swap | Exchanges the items at two positions, in place. | nothing; the content changes. SwapQ returns the mover for chaining | _n1_=the first position, or a pair such as [ :Between, 2 ]; _n2_=the second position, or a pair such as [ :And, 3 ] | Move, SwapFirstAndLast | | a position outside the list exchanges nothing and says nothing: Swap(1, 9) leaves a b c as it was
MoveToStart | Takes the item at a position and puts it first, in place. | nothing; the content changes. MoveToStartQ returns the mover for chaining | n=the position of the item to move | MoveToEnd, Move, MoveItemToStart | | a position outside the list moves nothing; MoveToFirst is the same call
MoveToFirst | Takes the item at a position and puts it first, in place. | nothing; the content changes | n=the position of the item to move | MoveToStart, MoveToLast | | the same call as MoveToStart
MoveToEnd | Takes the item at a position and puts it last, in place. | nothing; the content changes. MoveToEndQ returns the mover for chaining | n=the position of the item to move | MoveToStart, Move, MoveItemToEnd | | a position outside the list moves nothing; MoveToLast is the same call
MoveToLast | Takes the item at a position and puts it last, in place. | nothing; the content changes | n=the position of the item to move | MoveToEnd, MoveToFirst | | the same call as MoveToEnd
SwapFirstAndLast | Exchanges the first and the last items, in place. | nothing; the content changes. SwapFirstAndLastQ returns the mover for chaining | | Swap, Move | | a list of one item or an empty list is left as it is
Reverse | Reverses the order of the items, in place. | nothing; the content changes. ReverseQ returns the mover for chaining | | Reversed, RotateLeft
Reversed | Returns the items in the opposite order, leaving the mover as it was. | a list | | Reverse, RotatedLeft
RotateLeft | Moves the first n items to the end, in place, the others shifting toward the start. | nothing; the content changes. RotateLeftQ returns the mover for chaining | n=how many items go from the front to the back | RotatedLeft, RotateRight | a negative n kills the whole Ring process with panic: integer part of floating point value out of bounds in stz_list.dll (RotatedLeft(-1) on 1 to 5, and RotateRight(-1) on x y z) | an n larger than the list wraps around, so 7 on 5 items is 2; 0 changes nothing
RotatedLeft | Returns the items with the first n moved to the end, leaving the mover as it was. | a list | n=how many items go from the front to the back | RotateLeft, RotatedRight | a negative n kills the whole Ring process, as in RotateLeft | an n larger than the list wraps around, so 7 on 5 items is 2
RotateRight | Moves the last n items to the front, in place, the others shifting toward the end. | nothing; the content changes. RotateRightQ returns the mover for chaining | n=how many items go from the back to the front | RotatedRight, RotateLeft | a negative n kills the whole Ring process, as in RotateLeft | an n larger than the list wraps around; 0 changes nothing
RotatedRight | Returns the items with the last n moved to the front, leaving the mover as it was. | a list | n=how many items go from the back to the front | RotateRight, RotatedLeft | a negative n kills the whole Ring process, as in RotateLeft | an n larger than the list wraps around
Shuffle | Puts the items in a random order, in place. | nothing; the content changes. ShuffleQ returns the mover for chaining | | Shuffled, Reverse | | the order is different on every call
Shuffled | Returns the items in a random order, leaving the mover as it was. | a list | | Shuffle, Reversed | | the order is different on every call
MoveItemToStart | Finds the first occurrence of an item and puts it first, in place. | nothing; the content changes | pItem=the item to move, looked up with case | MoveItemToEnd, MoveToStart | | an absent item changes nothing; only the first occurrence moves
MoveItemToEnd | Finds the first occurrence of an item and puts it last, in place. | nothing; the content changes | pItem=the item to move, looked up with case | MoveItemToStart, MoveToEnd | | an absent item changes nothing; only the first occurrence moves, so a b a becomes b a a
