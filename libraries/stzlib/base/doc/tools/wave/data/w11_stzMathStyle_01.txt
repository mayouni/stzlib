init | Builds an empty style with an 800 by 700 canvas, no rule, no start, margin 0 and the light theme. | nothing; the object is built | | SetCanvas, ForAll
SetCanvas | Sets the width and height of the paper the picture is drawn on. | the style itself, so calls chain | pnW=the width in pixels; pnH=the height in pixels | CanvasWidth, SetMargin | the numbers are not checked, so text or a negative value is accepted | SetCanvasQ is the same call
CanvasWidth | Returns how wide the paper is, in pixels. | a number, 800 by default | | SetCanvas, CanvasHeight
CanvasHeight | Returns how tall the paper is, in pixels. | a number, 700 by default | | SetCanvas, CanvasWidth
ForAll | Adds a rule: for every combination of objects the selector names, the rows say which shapes to draw and which constraints to hold. | the style itself, so calls chain | pcSelector=the types and variables, such as Set x for each Set, or two Set variables joined by a semicolon for each pair; paRows=the rows, each [ verb, path, ... ] with the verb shape, delete, unknown, field, override, ensure, encourage or layer | ForAllWhere, Rules | an empty selector, a body that is not a list, an unknown verb, a shape kind the drawer lacks, a layout function that does not exist, or a malformed row raises an error naming the row | the rows are data: [ :shape, x.icon, :circle, [ :r = 30 ] ] draws a circle for each Set
ForAllWhere | Adds a rule like ForAll, applied only to the combinations for which a condition over the substance holds. | the style itself, so calls chain | pcSelector=the types and variables, as for ForAll; pcWhere=the condition, such as Subset(x, y), taken from the substance's relations; paRows=the rows, as for ForAll | ForAll, Rules | it checks its rows as ForAll does | ForAllWhereQ is the same call; the Euler style draws containment with a rule where Subset(x, y)
Rules | Returns the rules added so far as [ selector, condition, rows ] triples, in order. | a list of triples; empty for a new style | | ForAll, ForAllWhere
StartPlanar | Asks for the solver to start from a planar placement of the objects that are vertices, joined by the objects that are edges. | the style itself, so calls chain | pcType=the type whose objects are the vertices; pcShape=the shape whose centre carries each vertex; pacCtors=the constructors that are edges, as a list or one name | StartLayout, StartTrying, PlanarStart | the same as StartTrying with the one start planar | StartPlanarQ is the same call
StartLayout | Asks for the solver to start from one of the graph plane's layouts of the vertices and edges. | the style itself, so calls chain | pcMode=planar, hierarchical, ring, force, mesh, sequence or random, in any case; pcType=the vertex type; pcShape=the shape that carries a vertex; pacCtors=the edge constructors, as a list or one name | StartTrying, Starts | any other mode raises an error | the same as StartTrying with one mode
StartTrying | Sets the starts the solver tries in order, the first that ends lawful being the picture. | the style itself, so calls chain | pacModes=a list of start modes, as for StartLayout; pcType=the vertex type; pcShape=the shape that carries a vertex; pacCtors=the edge constructors, as a list or one name | StartLayout, Starts | an unknown mode raises an error; a single mode given as text, not in a list, raises error R21 although the code tries to widen it, seen with mesh and ring; wrap it in a list | it replaces the starts set before
Starts | Returns the start modes to try, in lower case and in order. | a list of text; empty means one random start | | StartTrying, StartLayout
ClearPlanarStart | Removes every start, so the solver starts from a random placement again. | the style itself, so calls chain | | StartTrying, PlanarStart
PlanarStart | Returns what the start asked for names: the vertex type, the shape and the edge constructors. | a list [ type, shape, constructors ]; empty when no start is set | | StartTrying, ClearPlanarStart
SetMargin | Sets a margin inside the paper, in pixels, that shapes must keep from its edge. | the style itself, so calls chain | pnPx=the margin in pixels; the value is not checked | Margin, SetCanvas | SetMarginQ is the same call | a style whose vertices repel one another pushes them onto the edge without a margin
Margin | Returns the margin inside the paper. | a number, 0 by default | | SetMargin
SetTheme | Sets the colour theme that resolves the style's roles, kept in lower case. | the style itself, so calls chain | pcName=a theme name such as light or dark, trimmed; an empty text means the light theme | Theme | SetThemeQ is the same call | the Euler style under dark gives light strokes and white names on a dark paper
Theme | Returns the theme in force. | a text, light until another is set | | SetTheme
SolveLabelsAfter | Makes the solver place shapes first and the names afterwards, against the frozen shapes. | the style itself, so calls chain | | LabelsAfter | SolveLabelsAfterQ is the same call | right for a graph, where a name held off an edge would pull on the edge's ends
LabelsAfter | Returns whether names are solved after the shapes. | 1 when on, 0 by default | | SolveLabelsAfter
