init | Builds a supervisor for a cluster of worker processes; it reads the cluster's health and scales it, and does nothing until it is asked. | nothing; the object is built | poCluster=the cluster to supervise, an object with HealthCheck, FleetMetrics, RestartDead, ScaleUp and ScaleDown, such as a stzAppCluster | Policy, Supervise
Name_ | Returns the supervisor's name, 'cluster-supervisor' unless SetName changed it. | a text | | SetName, Cycle
SetName | Sets the name by which an agent host knows the supervisor. | the supervisor itself, so calls chain | pcName=the new name, as text | Name_
ClusterQ | Returns the cluster the supervisor was given. | the cluster object | | init
Policy | Sets how many workers a tag may have, at least nMin and at most nMax; the tag is matched without regard to case. | the supervisor itself, so calls chain | pcTag=the facet or profile tag the policy covers; nMin=the fewest workers to keep, raised to 1 if smaller; nMax=the most workers to start, raised to nMin if smaller | Decide, SetWaterMarks | a second call for the same tag replaces the bounds
SetWaterMarks | Sets the two load ratios that trigger scaling: below nLow the supervisor scales down, above nHigh it scales up. | the supervisor itself, so calls chain | nLow=the low-water load ratio, 0.25 by default; nHigh=the high-water load ratio, 0.75 by default | Decide, ReportLoad | one pair of marks serves every tag
ReportLoad | Records the demand observed for a tag, as a ratio from 0 to 1, replacing the earlier figure. | the supervisor itself, so calls chain | pcTag=the facet or profile tag, matched without regard to case; nRatio=the observed load from 0 to 1 | LoadOf, FeedLoadFrom, Decide
LoadOf | Returns the last load ratio reported for a tag; 0 when none was reported. | a number | pcTag=the tag to look up, matched without regard to case | ReportLoad
FeedLoadFrom | Reads the load ratio from a performance profile and reports it for a tag, so the signal is measured and not typed in. | the supervisor itself, so calls chain | pcTag=the tag the load belongs to; poProfile=an object that answers LoadRatio(), such as a stzPerfProfile | ReportLoad, LoadOf
Decide | Returns the actions the policy calls for given the fleet metrics, without touching the cluster. | a list of [ kind, tag ] pairs, kind being :restart, :scaleup or :scaledown | aMetrics=the fleet metrics, a list of hashlists such as [ :tag = 'nlp', :ready = 2, :dead = 1 ] | Supervise, Policy | a tag with a policy but no entry in the metrics is skipped; a dead worker gives a restart first, then the load decides; a tag at its bound gives no scaling | read from the code and run with invented metrics; no cluster was involved
Supervise | Runs one pass: checks the cluster's health, reads its metrics, decides, and applies the actions to the cluster. | the list of actions taken, as Decide returns it | | Decide, Cycle, LastActions | it calls HealthCheck, RestartDead, ScaleUp and ScaleDown on the cluster, so it changes a live fleet; it was run here only against an invented stand-in object, never a real cluster | one restart call heals every dead worker, however many restart actions there are
LastActions | Returns the actions taken by the last Supervise pass; empty before the first. | a list of [ kind, tag ] pairs | | Supervise
Cycle | Runs one Supervise pass and returns how many actions it took, so an agent host can tick the supervisor as a job. | a number; 0 when the fleet was quiescent | | Supervise, Name_ | same warning as Supervise: it acts on the cluster it was given | run here only against an invented stand-in object
