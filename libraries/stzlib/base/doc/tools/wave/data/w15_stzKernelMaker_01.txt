init | Creates an empty kernel description, to be filled with the vectors, scalars, output and body of an elementwise computation. | nothing; the object is built | | TakesVector, ToWGSL
TakesVector | Declares an input vector by name; a kernel takes up to 5. | the maker itself, so calls chain | pcName=the vector's name, stored in lower case and used as @Name in the body | TakesScalar, ForEachElement | declaring a vector clears the cached kernel text
TakesScalar | Declares a scalar parameter by name; a kernel takes up to 14. | the maker itself, so calls chain | pcName=the scalar's name, stored in lower case and used bare in the body | TakesVector, ForEachElement | declaring a scalar clears the cached kernel text
ReturnsVector | Declares the single output vector by name. | the maker itself, so calls chain | pcName=the output's name, stored in lower case and assigned as @Name in the body | ForEachElement, OutputName | a kernel without an output refuses at ToWGSL
ForEachElement | Sets the body: one assignment from an expression over the declared vectors, scalars, numbers and a fixed set of functions. | the maker itself, so calls chain | pcW=the body in braces, such as '{ @C = alpha * @A + @B }' | ToWGSL, Spec | the expression may call abs, min, max, sqrt, exp, log, sin, cos, tan, floor, ceil, pow, clamp, sign, fract and round; anything else refuses at ToWGSL naming the offender
InputNames | Returns the declared input vectors, lower-cased, in the order declared. | a list of texts | | TakesVector, ScalarNames
ScalarNames | Returns the declared scalars, lower-cased, in the order declared. | a list of texts | | TakesScalar, InputNames
OutputName | Returns the declared output vector, lower-cased; empty when none is declared. | a text | | ReturnsVector
Spec | Returns the declarations in the engine's spec format: one in, scalar or out line each, then the body. | a text of several lines | | ToWGSL | an empty maker gives an empty text
ToWGSL | Returns the WGSL compute kernel the engine generates from the declarations, after checking them; needs no GPU. | a text, the kernel source | | Spec, ForEachElement | raises an error with the engine's message for a missing output, an unknown name or a function outside the list; the text is cached until a declaration changes | run: only the text transpiler of the engine, no device was opened
