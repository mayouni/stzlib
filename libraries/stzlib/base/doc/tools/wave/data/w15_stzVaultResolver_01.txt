init | Builds an empty in-memory vault resolver with a name, the reference stand-in for a real secret manager. | nothing; the object is built | pcName=the resolver's name, quoted in its messages | Register, Resolve
Name | Returns the name the resolver was built with. | a text | | init
Register | Seeds a value under a vault locator, replacing the value already there. | the resolver itself, so calls chain | pcLocator=the locator, a path and a field joined by #, such as secret/data/prod/db#password; pcValue=the secret value | Resolve, Has | | for development and tests only: the value is held in memory in clear, and a real resolver fetches it from the vault instead; use invented values
Has | TRUE if a value is registered under that exact locator. | TRUE or FALSE | pcLocator=the locator to look for | Register, Resolve | | the match is exact, case and field included
NumberOfEntries | Returns how many locators hold a value. | a number | | Register
Resolve | Returns the value registered under a locator; this is the method the vault contract asks of every resolver. | a text, the secret value | pcLocator=the locator to read | Has, Register | raises an error naming the resolver and the locator when nothing is registered there | the locator is quoted in the error as given, so show the message as text and not as markup; the reveal itself is gated by the secret that calls RevealVia
Show | Prints the resolver's name and entry count, then each locator with its value masked. | nothing; it prints | | NumberOfEntries | | values are never printed
