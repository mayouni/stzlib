@ | Stores the R source text to run, as the call with the longer name does. | nothing | pcRCode=the R program text, which must assign its answer to a variable named res | SetCode, Execute

Run | Writes the source behind a translator and runs it with the R program, as the call with the other name does. | nothing; the answer is kept in a result file | | Execute, Result | same warning as Execute: it runs real code with a real program in the current folder
Exec | Writes the source behind a translator and runs it with the R program, as the call with the other name does. | nothing; the answer is kept in a result file | | Execute, Result | same warning as Execute: it runs real code with a real program in the current folder
Result | Reads the answer the R code saved and turns it into a Ring value: a number, a text or nested lists. | the value | | Execute, Log | evaluates the text of the result file as Ring code, so run only code you trust; reads the result file of the last run, which does not exist here because the run failed, so it raises an error that quotes the log | not run: needs a successful Execute
Code | Returns the source text that was set, or, when none is set, the source file left on disk by an earlier run. | a text | | SetCode, Execute | it returns your own code, not the wrapped source that is written to disk
Duration | Returns how long the last run took, in seconds; 0 before any run. | a number | | Execute, Trace
Log | Returns what the R program printed during the last run, errors included. | a text; empty when there is no log file | | Execute, Trace | on a new object it can return the log of an earlier run left in the current folder
Trace | Returns the history of runs of this object, oldest first, each a hashlist of language, timestamp, duration, log, exitcode and mode. | a list of hashlists | | Log, Duration | the exit code is always recorded as 0, even for a run that failed
