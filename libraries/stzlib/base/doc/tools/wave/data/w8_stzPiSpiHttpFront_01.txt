init | Builds a front over a new twin hub, with an application server that routes every GET, POST, PUT and DELETE path to the contract handler. | nothing; the object is built | | WithCredentials, Start, Hub | the front keeps its settings and its tokens in process-wide tables, so a second front in the same process shares the first one's credentials and counters and only takes over the hub; run one front per process, which is read from the code and not run | it moves no money, the twin holds virtual francs
WithCredentials | Sets the OAuth client and the API key the front demands before it serves a call. | the front itself, so calls chain | pcClientId=the client id the token endpoint accepts; pcClientSecret=the client secret it accepts; pcApiKey=the key every API call must send in x-api-key | WithScopePrefix, Start | with no API key set every API call is refused with a 401 problem | the values are test values the caller generates, never a participant's credentials
WithScopePrefix | Sets the text that every scope of a token must carry, which is piz/ in the BCEAO's sandbox. | the front itself, so calls chain | pcPrefix=the text such as piz/, an empty text for none | WithCredentials, WithBasePath | a call whose token lacks the prefixed scope its operation needs is refused with a 401 problem naming the scope
WithBasePath | Sets the path under which the contract is served, /piz/v1 unless changed. | the front itself, so calls chain | pcBase=the path prefix such as /piz/v1 | WithScopePrefix, Start | any other path, apart from the token endpoint and the control routes, answers a 404 problem
WithTokenLifetime | Sets how many seconds a token issued from now on stays valid, 3600 unless changed. | the front itself, so calls chain | pnSeconds=the lifetime in seconds, which the token response reports as expires_in | WithCredentials, EnableControl | the adapter refreshes a token a minute before it lapses, so a lifetime under a minute makes it fetch one for every call
EnableControl | Turns on the /_twin/ routes with which a test drives the twin behind the wire. | the front itself, so calls chain | | Hub, Start | those routes ask for no credential at all, so anyone who can reach the port can advance the clock, make the twin pay or ask, and revoke tokens, and loopback only is a matter of the host given to Start and is not enforced here | they advance the clock, settle what is pending, make a customer pay, ask or cancel, change how a customer answers, read the queued webhooks and the counters; a server that holds real money never enables them
Hub | Returns a face onto the twin the front serves, for a caller in the same process. | an stzPiSpiSandbox on the same hub | | stzPiSpiSandbox, Start | the face shares its state with the served twin, so a payment made through it is seen over HTTP
Start | Binds the front to a port and an address and returns 1, without serving anything until RunFor is called. | 1 | pnPort=the port to listen on, 0 for any free one; pcHost=the address to bind, an empty text meaning 127.0.0.1 | Port, RunFor, Stop, StartTls | raises an error when the port cannot be bound or the front already runs | UNPERCEIVED, for the live adapter this front is built to serve: stzPispiHttpAdapter is proven against this twin over real HTTP and has NOT been run against the BCEAO's sandbox, so a green run here says the adapter and the twin agree, not that a participant's hub agrees
StartTls | Binds the front to a port and an address behind TLS, with mutual TLS when a CA is given, and returns 1. | 1 | pnPort=the port to listen on, 0 for any free one; pcHost=the address to bind, an empty text meaning 127.0.0.1; pcCert=the server certificate PEM file; pcKey=the server private key PEM file; pcCa=the CA PEM file that checks client certificates, an empty text for none; pbRequireClient=TRUE to demand a client certificate, so that a client without one gets no response at all | Start, Port, RunFor | raises an error for a certificate, key or CA file that cannot be used, naming the code -13, -14 or -17; the token is not bound to the certificate it was fetched under, as the real hub's is, because the engine does not show the peer certificate to a handler | UNPERCEIVED: mutual TLS is proven only between the adapter and this twin with the engine's throwaway test certificates, never against the BCEAO's sandbox or a participant
Port | Returns the port the front listens on, the real one when 0 was asked for. | a number, 0 before the first start | | Start, StartTls
RunFor | Serves requests for the given time and then returns, the call that makes the front answer. | the front itself, so calls chain | pnMs=how long to serve, in milliseconds | Start, Stop | it blocks its caller, so an adapter running in the same process cannot be served: run the front in a process of its own, as the library's live-adapter guard does
Stop | Closes the listener and keeps the routes for a later start. | the front itself, so calls chain | | Start, RunFor | a front that is not running is left as it is
