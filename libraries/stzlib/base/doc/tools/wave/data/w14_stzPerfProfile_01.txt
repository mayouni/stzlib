init | Builds a profile of a performance monitor and anchors it there, so every answer covers the time since. | nothing; the object is built | poMonitor=the stzPerfMonitor whose request timer and CPU numbers are analysed | StzPerfProfile, Mark
Mark | Moves the anchor to now, so the next answers cover a fresh interval and forget the earlier one. | the profile itself, so calls chain | | IntervalMs, Snapshot
MonitorQ | Returns the monitor this profile reads. | the stzPerfMonitor given at birth | | init
IntervalMs | Returns how many milliseconds have passed since the anchor, on the monotonic clock. | a number | | Mark, Throughput
Requests | Returns how many requests the monitor counted since the anchor. | a number; 0 when the monitor has no http.requests counter | | Throughput, ServiceDemandMs
Throughput | Returns X, the requests completed per second over the interval. | a number; 0 when no time has passed | | Requests, MaxThroughput, LittleN
CpuMsUsed | Returns the CPU time the whole process consumed since the anchor, in milliseconds, all threads together. | a number | | Utilization, ServiceDemandMs | | Windows counts CPU in 15.625 ms ticks, so a short interval reads 0 or one tick: average over many ticks
Utilization | Returns U, the fraction of the whole machine's CPU this process used over the interval. | a number from 0 to 1; 0 when no time has passed | | CpuMsUsed, UtilizationCheck
ServiceDemandMs | Returns D, the CPU milliseconds each request consumed, the profile's most diagnostic number. | a number; 0 when no request completed | | Requests, MaxThroughput, Bottleneck | | D counts the whole process, so a quiet interval with few requests is quantized by the CPU tick
MaxThroughput | Returns the requests per second at which this machine saturates if the CPU is the constraint. | a number; 0 when D is 0 | | ServiceDemandMs, Headroom, LoadRatio
LoadRatio | Returns how close the workload is to its CPU ceiling, throughput over maximum throughput, capped at 1. | a number from 0 to 1; 0 when nothing is measurable yet | | MaxThroughput, Headroom
Headroom | Returns how much of the CPU ceiling remains, 1 minus throughput over maximum throughput. | a number from 0 to 1; 0 when nothing is measurable yet | | LoadRatio, MaxThroughput
UtilizationCheck | Compares the utilization computed from the anchors with the monitor's independently sampled CPU gauge. | a hashlist with the keys computed, sampled, consistent and message; sampled is -1 and consistent 0 when the monitor does not watch the CPU | | Utilization, LittleCheckAgainst | | the two agree when within a factor of 3; a disagreement means the measurement is broken, not the machine
LittleN | Returns N, the average requests in flight that Little's law implies from throughput and mean response time. | a number | | LittleCheckAgainst, Throughput, ResponseTimeMeanMs
LittleCheckAgainst | Compares the implied requests in flight with a concurrency you measured elsewhere, for example a worker pool's. | a hashlist with the keys implied, measured, consistent and message | pnMeasured=the concurrency you counted, as a number | LittleN, UtilizationCheck | | consistent means within a factor of 3, with both sides floored at 0.05 so tiny numbers agree
ResponseTimeMeanMs | Returns R, the mean response time in milliseconds of the requests completed since the anchor. | a number; 0 when none completed or the monitor has no http.request.ms timer | | ResponseTimeP95, WaitMsPerRequest
ResponseTimeP50 | Returns the median response time in milliseconds, over the timer's retained window. | a number; 0 when the monitor has no http.request.ms timer | | ResponseTimeMeanMs, ResponseTimeP95 | | a window percentile, not an interval one: it can include requests from before the anchor
ResponseTimeP95 | Returns the response time in milliseconds under which 95 percent of requests fall, over the timer's window. | a number; 0 when the monitor has no http.request.ms timer | | ResponseTimeP50, ResponseTimeP99
ResponseTimeP99 | Returns the response time in milliseconds under which 99 percent of requests fall, over the timer's window. | a number; 0 when the monitor has no http.request.ms timer | | ResponseTimeP95, ResponseTimeP50
WaitMsPerRequest | Returns the part of each request's mean response time that was not computation: waiting on IO, locks or queues. | a number of milliseconds, never below 0 | | Bottleneck, ResponseTimeMeanMs, ServiceDemandMs
Bottleneck | Answers whether the app is busy or blocked, by splitting each request's time into CPU computed and time waited. | a hashlist with the keys kind (cpu or waiting, whichever share is larger), cpuMsPerRequest, waitMsPerRequest and maxThroughput | | WaitMsPerRequest, ServiceDemandMs | | with no requests it answers cpu and zeros
MemoryTrendPerHour | Returns the bytes per hour by which the monitor's resident memory gauge is trending, positive when growing. | a number; 0 when the monitor does not watch memory | | HoursToMemoryCeiling, Explain
HoursToMemoryCeiling | Returns the hours until resident memory reaches a ceiling at the current trend. | a number of hours; 0 when memory is already at or past the ceiling, -1 when it is not growing or is not watched | pnCeilingBytes=the memory ceiling, in bytes | MemoryTrendPerHour
Snapshot | Records one point of the response-time-versus-throughput curve for the current interval and returns it. | a list [ atMs, X, U, D, Rp95 ] | | Curve, Mark | | only the newest 128 points are kept
Curve | Returns the points recorded by Snapshot, in recording order. | a list of [ atMs, X, U, D, Rp95 ] rows | | Snapshot
Explain | Returns a narration of the interval in lines: work done, CPU, service demand, response time, Little's law and the constraint. | a list of text lines | | Show, Bottleneck | | a monitor with no request instruments gets only the CPU line
Show | Prints the narration of the interval, one line per row. | nothing; it prints | | Explain
