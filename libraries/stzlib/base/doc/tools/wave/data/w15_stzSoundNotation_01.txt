# w15 stzSoundNotation -- written to text and bytes only; no audio device was opened and nothing was heard (UNPERCEIVED)
init | Builds a notation writer over a score; the formats are written from the score, which stays the source. | nothing; the object is built | poScore=the stzSoundScore to write out | Losses, ToABC | | StzSoundNotationQ builds the same object
Losses | Returns what the last format written could not carry. | a list of sentences; [ ] when nothing was lost | | ToABC, ToMusicXML | | each ToABC and ToMusicXML starts the list afresh; strokes are not written in ABC or MusicXML, so a score with a stroke leaves strokes are not written in ABC or MusicXML here (MIDI carries them); a pitch more than 5 cents from the nearest quarter tone, and a rounding of more than a hundredth of a beat, are counted too
ToABC | Writes the score as ABC 2.1 text, one voice per instrument. | the ABC text, with header lines X, T, M, L, Q and K, a V line naming each voice and one line of notes per voice | pcTitle=the title written on the T line | ToMusicXML, Losses | | a note is its letter, an octave mark and a length in sixteenths of a beat, so C4 is middle C lasting one beat; a quarter tone is written ^/A or _/B; a rest is z; long notes are tied across barlines; for a four-note piano score at 90 beats a minute it gives Q:1/4=90 and the line [V:1] C4 D4 E4 C4 followed by a closing bar
ToMusicXML | Writes the score as MusicXML text, with quarter tones as decimal alterations. | the MusicXML text, with one part for each instrument | pcTitle=the title written in the document | ToABC, Losses | | durations use four divisions to the quarter note; a quarter tone is an alter of 0.5 or -0.5; strokes are not written
ToMidiFile | Writes the score as a Standard MIDI File, type 1, to a file. | the number of bytes written | pcPath=the path of the file to write | ToMidiBytes, Losses | | the same bytes as ToMidiBytes; an existing file is overwritten
ToMidiBytes | Returns the score as the bytes of a Standard MIDI File, type 1, with 480 ticks to the quarter note. | the bytes as text, starting with MThd; for a four-note piano score 3 tracks and 569 bytes | | ToMidiFile, Losses | | every pitched note gets its own channel and a pitch bend, because MIDI has no quarter tones, with the bend range set to plus or minus 12 semitones; channels rotate and a note needing a channel when all fifteen are busy is counted in Losses; strokes go to the drum channel with General MIDI numbers; the note events for C4 D4 E4 C4 at velocity 0.8 were checked by hand: 60, 62, 64 and 60 at velocity 102
