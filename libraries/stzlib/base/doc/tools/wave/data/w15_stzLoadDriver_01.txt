# w15 stzLoadDriver -- the spawning methods were not run: they start Ring child processes and a local server, and write generated scripts under base/perf; read from the code
init | Builds a load driver with a reactor, the Ring executable found from the command line and the path of stzBase, and default settings. | nothing; the object is built and no process is started | | SpawnTarget, AimAt, DriveWith | | the defaults are a target cost of 3 ms per request, 30 requests per driver, the path /work and a 120000 ms lifetime for the target; StzLoadDriver builds the same object
SetBusyMs | Sets how many milliseconds of CPU the spawned target burns for each request, the service demand under study. | the driver itself, so calls chain | pnMs=the cost in milliseconds, 0 or more; a value below 0 or not a number is ignored | SetRequestsPerDriver, SpawnTarget | | it takes effect when SpawnTarget starts the target
SetRequestsPerDriver | Sets how many requests each driver process fires one after another. | the driver itself, so calls chain | pnM=the number of requests, 1 or more; a smaller value or a non-number is ignored | SetBusyMs, DriveWith | |
SetPath | Sets the path the drivers request. | the driver itself, so calls chain | pcPath=the path, such as /work | AimAt, DriveWith | | the target the driver spawns serves /work and /health
SetTtlMs | Sets how long the spawned target lives before it ends itself, so an orphan cannot outlive its use. | the driver itself, so calls chain | pnMs=the lifetime in milliseconds, 1000 or more; a smaller value or a non-number is ignored | SpawnTarget, Destroy | |
AimAt | Points the drivers at a server that is already running, instead of spawning one. | the driver itself, so calls chain | pcHost=the host name or address; pnPort=the port | SpawnTarget, DriveWith | | after it Destroy has no process to kill
SpawnTarget | Starts a child Ring process running a small stzAppServer whose /work handler burns CPU, and waits until it answers /health. | TRUE when the child answered its readiness probe within 15 seconds, FALSE otherwise | pnPort=the port to listen on, or 0 to pick one from the wall clock between 37000 and 37899 | WaitReady, Destroy | not run: it starts a child process, listens on a local port and writes a generated script to base/perf/.stzloadtarget_gen.ring | the target ends itself after the lifetime set by SetTtlMs
Port | Returns the port of the target. | a number; 0 before SpawnTarget or AimAt | | AimAt, SpawnTarget | |
WaitReady | Asks the target's /health until it answers 200, for up to a given time. | TRUE as 1 when it answered in time, FALSE as 0 otherwise | pnTimeoutMs=how long to keep asking, in milliseconds | SpawnTarget, AimAt | | aimed at a local port where nothing listens it answered 0 after the timeout, here 300 ms; the child needs a moment to load stzBase and bind, hence the retries
DriveWith | Fires one load level, a number of driver processes at once, and measures the response time each client sees. | a hash list with the keys drivers, requests, x, rmeanms, rp50ms, rp95ms and wallms: the throughput in requests per second and the response times in milliseconds | pnDrivers=how many driver processes to run at the same time | Curve, AimAt | a call with no target raises error stzLoadDriver: no target -- SpawnTarget() or AimAt() first; the real run was not run: it spawns one Ring process for each driver and writes a generated script to base/perf/.stzloaddriver_gen.ring | closed loop: each driver fires its next request when the previous answers, and the wait for the accept queue is counted, which a server-side timer cannot see; the row is also appended to CurveRows
Curve | Runs several load levels in turn and returns the response-time against throughput rows. | a list of the rows DriveWith gives, one for each level | paLevels=the numbers of drivers to try, such as [ 1, 6 ] | DriveWith, CurveRows | not run: each level spawns driver processes; it clears the rows kept so far before it starts | the values are live measurements, so a guard should assert ranges and signs and not exact values
CurveRows | Returns the rows gathered so far by DriveWith and Curve. | a list of hash lists; [ ] before any level was driven | | Curve, Explain | |
Explain | Returns the curve as lines of text: a header, one line per level, and a closing sentence about the knee when there are two levels or more. | a list of text lines | | Show, CurveRows | | with no level driven it is the header alone; for levels of 1 and 6 drivers reading 100 and 160 requests per second and 10 and 37 ms it says 6x the drivers bought 1.6x the throughput at 3.7x the response time, checked by hand
Show | Prints the narrated curve to the console, one line per line. | nothing | | Explain | | it prints with the ? statement
Destroy | Kills the target child that SpawnTarget started. | the driver itself, so calls chain | | SpawnTarget, AimAt | | it does nothing for a target the driver did not spawn, such as one given to AimAt
