# w15 stzFrameGraph
init | Builds an empty frame of a given size in pixels, to which render passes are added. | nothing; the object is built | pnW=the width of every render target, in pixels; pnH=the height of every render target, in pixels | AddPass, Compile | a width or height that is not a number raises error stzFrameGraph: give a width and a height in pixels; one below 1 raises error stzFrameGraph: a frame needs area | StzFrameGraphQ builds the same object
AddPass | Declares a render pass with the resources it reads and writes, and optionally the body that draws. | nothing; the pass is added and the graph must be compiled again. AddPassQ returns the frame graph for chaining | pcName=the name of the pass, unique in the frame, in any letter case; paSpec=a hash list with :Reads and :Writes, each a list of resource names, and :Body, a function called as fBody(oFrameGraph, cPassName) | Compile, Order, Execute | a name used twice, in any letter case, raises error stzFrameGraph: pass ... is declared twice; a pass that reads nothing and writes nothing raises error ... it cannot be scheduled, because it has no edges to anything | the body only draws: the graph decides when it runs and what it draws into
PassCount | Returns how many passes have been declared. | a number | | ResourceCount, AddPass | |
ResourceCount | Returns how many distinct resources the passes read or write. | a number | | PassCount, TargetsSaved | | a resource is counted once however many passes use it
Compile | Derives the execution order, the lifetimes and the aliasing from the declarations, and proves the frame sound. | the frame graph itself, so calls chain | | Order, Findings, AddPass | a frame with no pass raises error stzFrameGraph.Compile: no passes declared | the findings are an acyclic error when the passes form a cycle, a read_before_write error for a resource no pass writes, and a dead_resource warning for a resource written and never read, except one named screen; adding a pass afterwards makes every question refuse until the next Compile
Order | Returns the passes in the order they must run, derived so that a pass that reads a resource runs after the pass that writes it. | a list of pass names; [ ] when the passes form a cycle | | Lifetimes, Compile | calling it before Compile raises error stzFrameGraph: call Compile() first | the names come back as they were declared, and a name written as a symbol such as :Geometry is the lower-case text geometry
Lifetimes | Returns, for each resource, the step where it is first written and the step where it is last read. | a list of [ resource, first step, last step ] triples, steps counted from 1 in execution order | | Aliasing, Order | calling it before Compile raises error stzFrameGraph: call Compile() first | a resource never read is live for its one writing step
Aliasing | Returns which physical target each resource lives on, two resources sharing one when their lives do not overlap. | a list of [ resource, slot ] pairs, slots counted from 1 | | PhysicalTargets, Lifetimes | calling it before Compile raises error stzFrameGraph: call Compile() first | a greedy placement over the lifetimes; a slot is reused only by a resource that starts after the previous one ended
PhysicalTargets | Returns how many physical render targets the frame needs after aliasing. | a number | | TargetsSaved, Aliasing | calling it before Compile raises error stzFrameGraph: call Compile() first | for a chain a, b, c, d where each pass reads the previous pass's output it is 2 for 4 resources
TargetsSaved | Returns how many render targets the schedule saves against giving every resource its own. | a number, the resource count minus the physical targets | | PhysicalTargets, ResourceCount | calling it before Compile raises error stzFrameGraph: call Compile() first | it is the number the kill criterion of the design asks for: 0 means aliasing bought nothing
Findings | Returns the proofs that failed or warned, in the house finding shape. | a list of hash lists with rule, subject framegraph, where as widthxheight, severity and message; [ ] for a clean frame | | IsSound, Report | calling it before Compile raises error stzFrameGraph: call Compile() first | the rules are acyclic, read_before_write and dead_resource
IsSound | TRUE if the compiled frame has no finding of severity error. | TRUE or FALSE, as 1 or 0 | | Findings, Execute | calling it before Compile raises error stzFrameGraph: call Compile() first | a dead_resource warning does not make it false
Report | Returns the findings as a stzRuleReport, so the frame is judged by the same gate as code and security rules. | a stzRuleReport named framegraph | | Findings, IsSound | calling it before Compile raises error stzFrameGraph: call Compile() first |
Execute | Runs the passes in the derived order inside one frame, with one physical target for each alias slot. | 1 when the frame ran; 0 when no graphics device is available | | Order, TargetOf, FreeTargets | calling it before Compile raises error stzFrameGraph: call Compile() first; a frame with an error finding raises error stzFrameGraph.Execute: the frame has ERRORS | it needs a graphics device but opens no window; targets are made at each call, and a pass body asks TargetOf where its writes landed; release them with FreeTargets
TargetOf | Returns the physical target a resource lives on during a frame, for a pass body to draw into or sample. | the engine handle as a number; 0 before Execute, after FreeTargets, or for a name the frame does not know | pcResource=the resource name, matched as written | Execute, Aliasing | | two resources in one alias slot answer the same handle
FreeTargets | Releases the physical targets that Execute made. | nothing; TargetOf then answers 0 | | Execute, TargetOf | |
