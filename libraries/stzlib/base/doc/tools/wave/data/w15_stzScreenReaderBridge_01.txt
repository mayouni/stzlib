# w15 stzScreenReaderBridge -- not run against a real window: no window was opened, the live path is read from the code
init | Connects a window to the operating system's accessibility service, or records why it could not. | nothing; the bridge is live only if the platform accepted the window | poWindow=the stzWindow whose platform handle is handed to the accessibility runtime | IsLive, LastError, Announce | a value that is not an object raises error stzScreenReaderBridge: give an stzWindow | no runtime, a window with no platform handle, or a platform that refuses is not an error: the bridge is simply not live and LastError says why; read from the code, attaching hides and re-shows the window, so it blinks; StzScreenReaderAvailable tells beforehand whether a runtime exists; not run with a real window
IsLive | TRUE if the platform accepted the window and a tree can be handed over. | TRUE or FALSE, as 1 or 0 | | LastError, Announce | | it is 0 for an object whose window had no platform handle, as the one tried here
LastError | Returns why the bridge is not live, or why the last tree was refused. | the reason as text, such as the window has no platform handle or no accessibility runtime on this machine; an empty text when nothing went wrong | | IsLive, Announce | |
Announce | Hands the accessibility tree to the platform, to be called again whenever the interface changes. | TRUE if the platform took the tree, FALSE when the bridge is not live or the platform refused it; AnnounceQ returns the bridge for chaining | pTree=a stzAccessibilityTree, or its JSON as text | TimesAnnounced, IsLive | read from the code, a value that is neither a tree nor text raises error stzScreenReaderBridge.Announce: give a tree or its JSON, but only on a live bridge; not run on a live bridge | on a bridge that is not live it answers FALSE without looking at the argument and changes no count
TimesAnnounced | Returns how many times a tree was handed over and accepted. | a number; 0 on a bridge that is not live | | TimesRead, Announce | |
TimesRead | Returns how many times an assistive technology actually asked for the tree. | a number; 0 on a quiet machine or a bridge that is not live | | TimesAnnounced, IsBeingRead | | it is the number that tells a working bridge from a hopeful one
NodeCount | Returns how many nodes the platform currently holds. | a number; 0 on a bridge that is not live | | Stats, TimesAnnounced | |
Stats | Returns the three counters straight from the bridge. | a list [ announced, read, nodes ]; [ ] on a bridge that is not live | | TimesRead, NodeCount | |
IsBeingRead | TRUE if something has read the tree at least once. | TRUE or FALSE, as 1 or 0 | | TimesRead | | it is the only in-process evidence that a screen reader is there
Free | Detaches the bridge from the window. | nothing; the bridge is no longer live | | IsLive, init | | freeing a bridge that is not live does nothing
