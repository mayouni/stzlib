init | Builds an empty feed-forward network that takes a fixed number of inputs and has no layers yet. | nothing; the object is built | paSpec=a hash list [ :Inputs = n ] or a number n, the width of the input | AddDenseLayer, Predict | raises an error when the number of inputs is missing or below 1
SetSeed | Sets the seed of the generator that gives the layers their first weights, so a network can be rebuilt identically. | the network itself, so calls chain | n=the seed, a positive number; 42 by default | AddDenseLayer | | it acts on layers added afterwards; the same seed and the same layers give the same network
AddDenseLayer | Adds a fully connected layer after the last one, with weights and biases drawn from the seeded generator between -1 and 1. | nothing; use AddDenseLayerQ to chain | nUnits=the number of neurons in the layer; pcActivation=relu, sigmoid, tanh, linear or softmax, in any case | Layers, Predict | raises an error naming the choices for another activation | the layer reads as many inputs as the previous layer has units
NumberOfLayers | Returns how many layers the network has. | a number | | AddDenseLayer
NumberOfInputs | Returns the width of the input. | a number | | init
Layers | Returns the layers with their parameters. | a list of [ units, activation, weights, biases ] rows; the weights are units by previous width | | AdoptLayers, Predict
AdoptLayers | Replaces all the layers with the given ones, the way a trainer writes back what it learned. | the network itself, so calls chain | paLayers=a list in the shape that Layers returns | Layers | | nothing is checked: the shapes must match the inputs
ExportToGguf | Writes the weights and biases of every layer to a GGUF file, and returns the path written. | a text, the path, with .gguf added when missing | pcFile=the path of the file to write; pcName=the model name stored in the file | Layers | raises an error when there are no layers or the engine cannot write the file | the file holds one weight tensor and one bias tensor per layer
Predict | Returns the output of the last layer for an input, by a forward pass. | a list of numbers, one per unit of the last layer; the input itself when there are no layers | paInput=the list of input values | AddDenseLayer | an input longer than the network takes raises error R2, and a shorter one is accepted with the missing values counted as absent
