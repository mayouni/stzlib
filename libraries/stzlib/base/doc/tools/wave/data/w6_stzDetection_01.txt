init | Builds a detection of that name, which watches nothing yet and reports its findings at error severity. | nothing; the object is built | pcName=the detection's name, which becomes the rule of its findings | WhenKind, Explaining
Name | Returns the detection's name, the rule its findings carry. | a text | | Explain
Kind | Returns the event kind the detection watches, trimmed and in lower case. | a text; empty until WhenKind sets it | | WhenKind
Shape | Returns which shape the detection has: burst, sequence, any or unusual. | a text; empty until a declaring call sets it | | WhenKind, Repeats, ThenKind, Unusual
Severity | Returns the severity its findings carry, which is error until AsWarning or AsInfo changes it. | a text | | AsError, AsWarning, AsInfo
Meaning | Returns the sentence given by Explaining, which is added to every finding message. | a text; empty until Explaining sets it | | Explaining
WhenKind | Sets the event kind to watch, and makes the shape any when no shape was chosen yet. | the detection itself, so calls chain | pcKind=the event kind to watch, trimmed and put in lower case | ThenKind, Repeats, OnAnyOccurrence | the kind is not checked against the catalog, so a misspelled kind watches nothing and never fires | start every detection with it
Repeats | Makes the detection a burst: this many events of the watched kind inside the window fire it. | the detection itself, so calls chain | pnTimes=how many events make a burst | Within, PerActor | without Within the window is 0 ms, so only events stamped with the same millisecond count together | the BURST shape of stzDetection
Within | Sets the window of a burst or a sequence, in milliseconds of event wall time. | the detection itself, so calls chain | pnMs=the window length, in milliseconds | Repeats, ThenKind
PerActor | Counts events actor by actor instead of across all actors, for a burst or an unusual rate. | the detection itself, so calls chain | | Repeats, Unusual | | credential stuffing is per account, not per installation
ThenKind | Makes the detection a sequence: an event of this kind must follow one of the watched kind. | the detection itself, so calls chain | pcKind=the event kind that must follow, trimmed and put in lower case | WhenKind, Within, BySameActor | the kind is not checked against the catalog, so a misspelled kind never follows and the detection never fires
BySameActor | Requires both events of a sequence to come from the same actor. | the detection itself, so calls chain | | ThenKind | | without it the whole ledger counts as one actor and a sequence gives one finding in all
OnAnyOccurrence | Makes the detection fire on any single event of the watched kind, for kinds where one occurrence is already the story. | the detection itself, so calls chain | | WhenKind | | one finding per matching event, at most 16
Unusual | Makes the detection judge the newest window of the watched kind against the history of that same kind. | the detection itself, so calls chain | | Buckets, AgainstBaseline, Sigma, AtLeast | | the defaults are windows of 60000 ms, a baseline of 12 windows, 3 sigma and a floor of 3 (threat model R9)
Buckets | Sets the width of one window of the unusual shape, in milliseconds. | the detection itself, so calls chain | pnMs=the window width, in milliseconds, at least 1 | Unusual, AgainstBaseline | a width below 1 raises an error, and a value that is not a number raises R41 | the baseline is this width times AgainstBaseline
AgainstBaseline | Sets how many windows before the newest one form the baseline of the unusual shape. | the detection itself, so calls chain | pnBuckets=the number of baseline windows, at least 3 | Buckets, Sigma | fewer than 3 raises an error; until the ledger reaches back over 3 baseline windows nothing is said, because a cold start is not an anomaly | the newest window is judged against the windows before it, never against a baseline that includes itself
Sigma | Sets how many standard deviations above the baseline mean make a window unusual. | the detection itself, so calls chain | pnZ=the number of standard deviations | AtLeast, Unusual | | on a flat baseline, where the windows before all hold the same count, sigma is not used: any count above that mean and at or over the floor fires
AtLeast | Sets the floor of the unusual shape: a window with fewer events than this never fires. | the detection itself, so calls chain | pnCount=the smallest number of events in the newest window that can fire | Sigma, Unusual
AsOf | Judges the unusual shape at a given wall time instead of at the newest event, so a guard can be exact. | the detection itself, so calls chain | pnWallMs=the moment of judgement, in epoch milliseconds, 0 for the newest event | Unusual, Buckets
Corroborated | Marks the detection so that an error finding drops to a warning unless the matched events span two distinct kinds. | the detection itself, so calls chain | | AsError, CheckAgainst | | the corroboration law: one anomalous signal is a rumor, and the message says it is a single signal
Explaining | Sets the one-sentence meaning that is added to every finding message and to the explanation. | the detection itself, so calls chain | pcMeaning=what the detection means, as text | Meaning, Explain
AsError | Sets the severity of the findings to error. | the detection itself, so calls chain | | AsWarning, AsInfo, Corroborated
AsWarning | Sets the severity of the findings to warning. | the detection itself, so calls chain | | AsError, AsInfo
AsInfo | Sets the severity of the findings to info. | the detection itself, so calls chain | | AsError, AsWarning
CheckAgainst | Judges a ledger and returns the findings in the unified rule shape, ready for stzRuleReport. | a list of [ :rule, :subject, :where, :severity, :message ] findings; [ ] when nothing matches | poLedger=the stzSecurityLedger to judge, read through its retained window | LastEvidence, Corroborated, Explain | raises an error when nothing is watched, so call WhenKind first | the subject is security and where is the detection name, then a slash and the actor when there is one; at most 16 findings, so a storm reports and does not flood
LastEvidence | Returns the events that matched in the last check, so an incident can build its timeline from them. | a list of records; [ ] before any check or when nothing matched | | CheckAgainst
Explain | Returns the detection told as lines of text: its shape with its numbers, and its meaning when given. | a list of text | | Show, Explaining | | the first line reads Detection name [severity] followed by the shape
Show | Prints the lines Explain returns, one per line. | nothing; it prints | | Explain
