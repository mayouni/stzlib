init | Builds a conditional-code object from a Ring expression written in a string, with its outer braces and extra spaces removed. | nothing; the object is built | cCode=the conditional code as text, such as '{ This[@i] = This[@i-1] + 1 }' | Content | a non-string raises an error
Content | Returns the stored code as text, without the outer braces. | a text | | Update, Transpiled
Update | Replaces the stored code with a new text, kept exactly as given: braces and spacing are not cleaned up. | nothing; use UpdateQ to chain | _cNewCode_=the new code as text, or a named param such as [ :With = '...' ] | Updated, UpdateBy | a non-string raises an error when parameter checking is on | the code is stored as passed, so '{ x }' keeps its braces, unlike the text given to the constructor
UpdateWith | Replaces the stored code with a new text, as the call with the shorter name does. | nothing; use UpdateWithQ to chain | _cNewCode_=the new code as text | Update, UpdateBy, UpdateUsing
UpdateBy | Replaces the stored code with a new text, as the call with the shorter name does. | nothing; use UpdateByQ to chain | _cNewCode_=the new code as text | Update, UpdateWith, UpdateUsing
UpdateUsing | Replaces the stored code with a new text, as the call with the shorter name does. | nothing; use UpdateUsingQ to chain | _cNewCode_=the new code as text | Update, UpdateWith, UpdateBy
Updated | Hands back the text it was given and leaves the object untouched. | the text that was passed in | _cNewCode_=the text to hand back | Update | does not build a new stzCCode: it returns the argument itself, so it cannot be used to get an updated copy of the object
Copy | Returns a new stzCCode holding the same code, so changes to one do not reach the other. | a new stzCCode | | Content
Transpile | Rewrites the stored code in place, turning words such as @CurrentItem and @NextItem into the basic forms This[@i] and This[@i + 1]. | nothing; use TranspileQ to chain | | Transpiled, ExecutableSection | the stored code is changed; call Transpiled to keep the original
Transpiled | Returns the code with its sophisticated keywords turned into This[@i] forms, leaving the object itself unchanged. | a text | | Transpile
ExecutableSection | Returns the stretch of positions [ start, end ] of a list over which the code can run without reading outside it. | a list [ nStart, nEnd ] where nEnd is a number or the text last | | Transpile | raises an error when the code contains neither @i nor This[@i] | start moves up with the deepest look-behind (This[@i-2] gives 3) and end moves down with the deepest look-ahead (This[@i+2] gives -2, counted from the last position)
