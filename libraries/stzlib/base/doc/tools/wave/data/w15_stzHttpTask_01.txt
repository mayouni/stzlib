# w15 stzHttpTask -- the requests were not run: they reach the network; read from the code
Init | Builds a task for one HTTP request with its method, address and body, in the pending state. | nothing; the task is built and no request is made | id=the task's identifier, such as http_get; url=the address; method=GET, POST, PUT or DELETE as the HTTP_GET, HTTP_POST, HTTP_PUT and HTTP_DELETE constants; data=the body to send, or an empty text; engine=the reactive engine it belongs to | Execute, stzReactiveHttp | | the error mode is the default, ERROR_LOG
Execute | Sends the request by the blocking path and records the outcome on the task. | nothing; read the outcome with Status, Result and Error | | PerformHttpGet, Init | not run against a real address: it reaches the network; a method that is none of the four makes no request and ends the task in error with the message HTTP request failed, which was run | success is a 2xx status with a body: the status is completed, the body is the result and Then_ is called; anything else is an error whose message is HTTP request failed, with the status in parentheses when one was received, and Catch_ is called
PerformHttpGet | Sends a GET request through the engine and returns the body, or an empty text on failure. | the response body as text; an empty text for a status outside 200 to 299 or an empty body | url=the address to fetch | Execute, PerformHttpPost | not run: it reaches the network | the status of the response is kept on the task for the failure message; this blocking path is what the client uses when it has no reactor
PerformHttpPost | Sends a POST request with a body through the engine and returns the response body, or an empty text on failure. | the response body as text; an empty text for a status outside 200 to 299 or an empty body | url=the address to post to; data=the body to send, text | Execute, PerformHttpGet | not run: it reaches the network | a body that is not text is sent as an empty body
PerformHttpPut | Sends a PUT request with a body through the engine and returns the response body, or an empty text on failure. | the response body as text; an empty text for a status outside 200 to 299 or an empty body | url=the address to put to; data=the body to send, text | Execute, PerformHttpPost | not run: it reaches the network | a body that is not text is sent as an empty body
PerformHttpDelete | Sends a DELETE request through the engine and returns the response body, or an empty text on failure. | the response body as text; an empty text for a status outside 200 to 299 or an empty body | url=the address to delete | Execute, PerformHttpGet | not run: it reaches the network | a successful delete that answers with no body counts as a failure here
