# Wave 12 -- stzGovernance. Name | brief | returns | params | see | warning | note
init | Builds a governance of declared contracts under a name, with an empty regime and an empty decision lineage. | nothing; the object is built | pcName=the governance's name, as text | DeclareRisk, GrantPermission, SetAuthority, MayProceed | build it with parentheses: without them init is skipped and every table call raises | the regime and the lineage live in a shared table, so copies of the object see the same data; only Name_ and Why belong to each copy
SetName | Sets the name of the governance. | nothing | pcName=the new name, as text | Name_, Save
Name_ | Returns the governance's name. | a text | | SetName
Why | Returns the sentence that explains the last verdict this object gave. | a text such as "allowed: ..." or "refused: ..."; the empty text before any verdict | | MayProceed, MayExecute, MayRetire, MayRegister | | it is per object: a copy does not read the answer of another copy
DeclareRisk | Declares the risk tier of an action, from 1 (low) to 4 (critical), replacing an earlier tier. | the governance itself, so calls chain | pcAction=the action's name, kept in lower case; nTier=the tier, a number from 1 to 4 | RiskOf, MayProceed | a tier below 1 or above 4 raises an error | an action with no declared tier never proceeds
RiskOf | Returns the declared risk tier of an action. | a number from 1 to 4; 0 for an undeclared action | pcAction=the action's name, matched without regard to case | DeclareRisk
GrantPermission | Records that an actor can perform an action, which is not the same as being allowed to. | the governance itself, so calls chain | pcActor=the actor's name; pcAction=the action's name, both kept in lower case | HasPermission, SetAuthority, MayProceed | | granting twice is harmless
HasPermission | TRUE if the actor holds the permission to perform the action. | TRUE or FALSE | pcActor=the actor's name; pcAction=the action's name, both matched without regard to case | GrantPermission
SetAuthority | Sets how far the actor should be trusted to act on its own: advisory, delegated, autonomous or emergencyoverride. | the governance itself, so calls chain | pcActor=the actor's name; pcType=:Advisory (level 1), :Delegated (2), :Autonomous (3) or :EmergencyOverride (4) | AuthorityOf, MayProceed | any other word raises an error | the level must reach the action's risk tier for MayProceed to allow it
AuthorityOf | Returns the authority type declared for an actor. | a text such as autonomous or emergencyoverride; the empty text when none is declared | pcActor=the actor's name, matched without regard to case | SetAuthority
MayProceed | Decides whether an actor may perform an action: it needs a tier, a permission and an authority level that reaches the tier. | TRUE or FALSE; Why gives the sentence | pcActor=the actor's name; pcAction=the action's name | Why, DeclareRisk, GrantPermission, SetAuthority | an undeclared action is refused, as is an actor with no permission or no authority at all (level 0) | the checks run in that order and Why names the first one that failed
OpenCommitment | Opens a commitment in the exploratory state. | the governance itself, so calls chain | pcId=the commitment's identifier, kept in lower case | AdvanceCommitment, CommitmentStateOf | opening an identifier that is already open raises an error
AdvanceCommitment | Moves a commitment one step forward: exploratory, provisional, committed. | a text, the new state | pcId=the commitment's identifier | OpenCommitment, CommitmentStateOf | raises an error for an unknown identifier and for a commitment already committed, because the state is forward-only
CommitmentStateOf | Returns how far a commitment has advanced: exploratory, provisional or committed. | a text: exploratory, provisional or committed; the empty text for an unknown identifier | pcId=the commitment's identifier | OpenCommitment, AdvanceCommitment
DeclareDecommission | Declares the obligations an actor must fulfil before it may be retired. | the governance itself, so calls chain | pcActor=the actor's name; pacObligations=a list of obligation names, kept in lower case | FulfillObligation, MayRetire | declaring again for the same actor adds a second contract that is never read: the first one declared decides | an empty list declares a contract that is already met
FulfillObligation | Marks one declared obligation of an actor as fulfilled. | the governance itself, so calls chain | pcActor=the actor's name; pcObligation=the obligation's name, matched without regard to case | DeclareDecommission, MayRetire | raises an error for an actor with no contract and for an obligation that was not declared | fulfilling twice is harmless
MayRetire | Decides whether an actor may be retired: it needs a contract and every obligation fulfilled. | TRUE or FALSE; Why names the pending obligations or the missing contract | pcActor=the actor's name | DeclareDecommission, FulfillObligation, Why | an actor with no decommission contract never retires
RecordDecision | Adds a decision to the lineage, stamped with the wall clock in milliseconds. | the governance itself, so calls chain | pcId=the decision's identifier; pcRationale=why it was decided; pcActor=who decided; pcAction=the action it concerns | RecordDecisionAt, LineageOf, Decisions | the lineage keeps a bounded number of decisions: the oldest are dropped past the capacity | the actor's authority and the action's risk are stored as they are at this moment
RecordDecisionAt | Adds a decision to the lineage with a time you give, so an ordering can be fixed in a test. | the governance itself, so calls chain | pcId=the decision's identifier; pcRationale=why it was decided; pcActor=who decided; pcAction=the action it concerns; pnWallMs=the time in milliseconds since 1970 | RecordDecision, DecisionsBetween | the same bounded lineage as RecordDecision | the authority and the risk are those held now, or the empty text and 0 when none is declared
LineageCapacity | Returns how many decisions the lineage keeps, 512 by default. | a number | | LineageDropped, SetLineageCapacity
LineageDropped | Returns how many decisions were dropped because the lineage was full. | a number; 0 when the lineage is complete | | LineageIsComplete, LineageCapacity
LineageIsComplete | TRUE if no decision was ever dropped, so the lineage starts when the governance did. | TRUE or FALSE | | LineageDropped
LineageOf | Returns the decision recorded under an identifier, the latest one when it was recorded more than once. | a list [ :id, :rationale, :actor, :authorityattime, :riskattime, :at, :action ]; [ ] for an unknown identifier | pcId=the decision's identifier, matched without regard to case | LineageHistoryOf, Decisions
LineageHistoryOf | Returns every decision recorded under an identifier, oldest first. | a list of decision records, as LineageOf returns; [ ] for an unknown identifier | pcId=the decision's identifier | LineageOf
DecisionsOf | Returns the decisions made by an actor, in the order recorded. | a list of decision records | pcActor=the actor's name, matched without regard to case | DecisionsAbout, DecisionsSince
DecisionsAbout | Returns the decisions that concerned an action, in the order recorded. | a list of decision records | pcAction=the action's name, matched without regard to case | DecisionsOf
DecisionsSince | Returns the decisions made at or after a time. | a list of decision records | pnWallMs=the earliest time, in milliseconds since 1970 | DecisionsBetween
DecisionsBetween | Returns the decisions made inside a time window, both ends included. | a list of decision records | pnFromMs=the start of the window; pnToMs=the end, where 0 means no end | DecisionsSince | | times are wall-clock milliseconds since 1970
Lineage | Returns the stored rows of the lineage, raw. | a list of rows [ id, rationale, actor, authority, risk, time, action ], oldest first | | Decisions, NumberOfDecisions
Decisions | Returns the lineage as readable records, oldest first. | a list of decision records, as LineageOf returns | | Lineage, LineageOf
NumberOfDecisions | Returns how many decisions the lineage holds now. | a number | | Decisions, LineageCapacity
Release | Frees the table slot of this governance, regime and lineage, by explicit act of its owner. | the governance itself | | init | afterwards every read answers empty: RiskOf gives 0 and NumberOfDecisions gives 0; call it only from the owner, since every copy shares the slot | there is no destructor, so a governance built per request should release itself
DeclarePosture | Declares the trust posture of an executor: trusted, external or sandboxed. | the governance itself, so calls chain | pcExecutor=the executor's name; pcPosture=:Trusted (in-process), :External (out-of-process) or :Sandboxed (composed by a language model) | PostureOf, MayExecute, MayExecuteFor | any other word raises an error
PostureOf | Returns the posture declared for an executor. | a text; the empty text when none is declared | pcExecutor=the executor's name, matched without regard to case | DeclarePosture
MayExecute | Decides whether an executor may execute at all: it needs a declared posture. | TRUE or FALSE; Why gives the sentence | pcExecutor=the executor's name | DeclarePosture, MayExecuteFor | an executor with no posture never executes
DeclareReversibility | Declares how undoable the work of a subject is: reversible, compensable or irreversible. | the governance itself, so calls chain | pcSubject=an action or an actor, as text; pcClass=:Reversible, :Compensable or :Irreversible | ReversibilityOf, MayExecuteFor | any other word raises an error | it is independent of the risk tier
ReversibilityOf | Returns the reversibility class declared for a subject. | a text; the empty text when none is declared | pcSubject=the subject's name, matched without regard to case | DeclareReversibility
MayExecuteFor | Decides whether an executor, by its posture, may perform work of a given reversibility class. | TRUE or FALSE; Why gives the sentence | pcExecutor=the executor's name; pcRevClass=:Reversible, :Compensable or :Irreversible | MayExecute, DeclarePosture | refused without a posture; trusted covers all three classes, external covers reversible and compensable, sandboxed covers reversible only
MayRegister | Decides whether an actor may be registered in a loop at all: it must state what it covers and declare a reversibility class. | TRUE or FALSE; Why gives the sentence | pcActor=the actor's name; pcCoverage=one sentence saying what the actor covers; pcRevClass=:Reversible, :Compensable or :Irreversible | MayProceed, DeclareReversibility | an empty coverage and an unknown class are refused, with the AGENTLOOP-R4 and AGENTLOOP-R5 sentences | it judges the arguments only and records nothing
LoadFrom | Reads a .zgov file into this governance, adding its regime (risks to reversibility classes) and its decisions. | the governance itself, so calls chain | pcFile=the path of the file to read | Save | a missing file raises error R35 | it sets the governance's name from the file, keeps the decisions as saved (authority and risk as of the decision) and skips a section it does not know
Save | Writes the regime and the lineage to a .zgov text file. | a text, the path written, with .zgov appended when missing | pcFile=the path to write | LoadFrom | commitments and decommission contracts are not written, so they do not survive a reload | a line break inside a rationale is folded to a space
