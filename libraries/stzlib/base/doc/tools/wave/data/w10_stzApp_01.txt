init | Builds an empty world with the given name and a graph of the same name that holds its things and instances. | nothing; the object is built | pcName=the world's name | AddThing, GraphQ, Explain
Name | Returns the name the world was given. | a text | | init
GraphQ | Returns the graph that holds the world's things and instances. | a stzGraph | | AddThing, AddInstance, Relate | | the graph ids are in lower case, whatever the case of the names given
AddThing | Declares a kind of thing, or selects it if already declared, and makes it the one that Has, IsTrue, Owns and Of describe. | nothing; use AddThingQ to chain or to open a brace | pcName=the thing's name | Has, IsTrue, Owns, Of, Things | | calling it again with the same name selects the thing and adds no copy
Has | Sets the field names of the thing just added, replacing any set before. | the world itself, so calls chain | paFields=a list of field names | AddThing, Things | | with no thing added yet it does nothing
IsTrue | Adds a truth to the thing just added: a field name and the expression that holds for it. | the world itself, so calls chain | pcField=the field the truth is about; pcExpr=the expression that must hold, such as > 18 | Has, Explain | | Explain shows it as true when
Owns | Adds the relation owns toward another thing to the thing just added. | the world itself, so calls chain | pcThing=the thing that is owned | Of, AddRelation, Explain |
Of | Adds the relation of toward another thing to the thing just added. | the world itself, so calls chain | pcThing=the thing that this one belongs to | Owns, AddRelation, Explain |
AddRelation | Declares a free relation between two things, kept apart from the things' own Owns and Of. | nothing; use AddRelationQ to chain | pcFrom=the first thing; pcRelation=the relation's name; pcTo=the second thing | Owns, Relate, Explain | | it is shown by Explain only: it adds no edge to the graph, unlike Relate
AddInstance | Adds a named individual to the graph, linked to its kind of thing by an isa edge. | nothing; use AddInstanceQ to chain | pcInstance=the individual's name; pcThing=the thing it is an instance of | Relate, AddThing, Pursue | | the nodes are created if absent
Relate | Adds a labelled edge between two nodes of the graph, creating either node when absent. | the world itself, so calls chain | pcFrom=the source node, usually an instance; pcRelation=the label of the edge; pcTo=the target node | AddInstance, Pursue, Pulse | | goals and reactions are judged on these edges
AddFlow | Declares that an actor performs a verb on a thing, and makes it the flow that Require and Then complete. | nothing; use AddFlowQ to chain | pcActor=who acts; pcVerb=what is done; pcThing=what it is done to | Require, Then, Explain |
Require | Adds a required field to the flow just added. | the world itself, so calls chain | pcField=the field that must be present | AddFlow, Then | | with no flow added yet it does nothing
Keep | Returns the effect list that tells a flow to keep a thing, for Then to take. | a list of two items, the word keep and the thing | pcThing=the thing to keep | Then | | it records nothing by itself, and inside a SetBody brace the name Keep also reads as an attribute
Then | Adds an effect to the flow just added. | the world itself, so calls chain | paEffect=the effect, such as the list that Keep returns | Keep, Require, Explain | | Explain narrates any effect as then keep followed by the flow's thing
AddReaction | Declares a reaction of a kind of thing, and makes it the one that Unseen, Meets and Propose complete. | nothing; use AddReactionQ to chain | pcThing=the thing whose instances the reaction watches | Unseen, Meets, Propose, Pulse |
Unseen | Sets the condition of the reaction just added to an instance left unseen for a length of time. | the world itself, so calls chain | nQty=the length; pUnit=its unit, such as Days | AddReaction, Meets | | the condition is only narrated by Explain: Pulse does not test it
Meets | Sets the condition of the reaction just added to an expression that must hold. | the world itself, so calls chain | pcExpr=the expression, such as total > 100 | AddReaction, Unseen | | the condition is only narrated by Explain: Pulse does not test it
Propose | Adds to the reaction just added the thing it proposes when it fires. | the world itself, so calls chain | pcThing=the thing to propose | AddReaction, Pulse, Proposals | | Pulse proposes it for each instance that lacks a relation of that name
AddGoal | Declares a goal, and makes it the one that the brace assigns Means, ReachedBy, Within and Respecting to. | nothing; use AddGoalQ to chain or to open a brace | pcGoal=the goal's name | Goal, Pursue, GoalSatisfied | | the Means is read when the brace closes, so assign it inside AddGoalQ(name) { }
Goal | Returns a goal as plain data. | a hash list with the keys name, means, reachedby, within and respecting; an empty list for an unknown goal | pcGoal=the goal's name | GoalName, GoalNames, Pursue |
GoalName | Returns the goal's name if the goal is declared. | a text; empty for an unknown goal | pcGoal=the goal's name | Goal, GoalNames |
GoalNames | Returns the names of all declared goals in declaration order. | a list of texts | | Goal
Pursue | Measures the gap between the world graph and the goal, and turns each instance in the gap into a proposal. | a list of proposals such as propose Visit for bilal, empty when the gap is closed or the goal is unknown | pcGoal=the goal's name | GoalSatisfied, Proposals, Relate | it prints one pursuing line to the console, and it raises an error when the Means has no every :Thing clause | the proposal comes from the reaction that proposes for the goal's kind of thing, else the proposal is attend; the list also replaces Proposals
GoalSatisfied | TRUE if the world graph already meets the goal. | 1 or 0; 0 for an unknown goal | pcGoal=the goal's name | Pursue, Goal | it raises an error when the Means has no every :Thing clause |
SetBody | Declares where the world is kept, a kind or a list of kinds such as GraphDB, and opens a brace to name its paths. | the world itself, so calls chain | pBody=a kind or a list of kinds of body | Body, Save, Explain | | inside the brace, assign Graph, Files and Keep, which are read when the brace closes
Body | Returns the body as plain data. | a hash list with the keys label, graph, files and keep; an empty list when no body was set | | SetBody, Save
Save | Writes the world graph to its graph file when the body includes GraphDB, and does nothing otherwise. | the world itself, so calls chain | | SetBody, Body | a path defaults to .stzapp/world.stzgraf in the current folder, which is created if needed | with no body it writes nothing
AddScreen | Declares a screen, and makes it the one that the To verbs, Shows and Acts describe. | nothing; use AddScreenQ to chain | pcName=the screen's name | ToDiscover, Shows, Acts, ScreenNames | | its intent is understand until a To verb says otherwise
ToDiscover | Sets the screen just added to the intent discover, about a thing. | the world itself, so calls chain | pcThing=the thing the screen is about | ToUnderstand, ToFocus, ToSelect, ToAct |
ToUnderstand | Sets the screen just added to the intent understand, about a thing. | the world itself, so calls chain | pcThing=the thing the screen is about | ToDiscover, ToFocus |
ToFocus | Sets the screen just added to the intent focus, about a thing. | the world itself, so calls chain | pcThing=the thing the screen is about | ToDiscover, ToSelect |
ToSelect | Sets the screen just added to the intent select, about a thing. | the world itself, so calls chain | pcThing=the thing the screen is about | ToFocus, ToAct |
ToAct | Sets the screen just added to the intent act, about a thing. | the world itself, so calls chain | pcThing=the thing the screen is about | ToSelect, Acts |
Shows | Sets what the screen just added shows. | the world itself, so calls chain | paParts=a list of part names | AddScreen, Acts | | it replaces any parts set before
Acts | Adds an action of the screen just added, tied to a flow. | the world itself, so calls chain | pcAction=the action's name; pcFlow=the flow it triggers | Shows, AddFlow |
AddRefinement | Declares a knob that a person may tune, and makes it the one that Bounds and Options describe. | nothing; use AddRefinementQ to chain | pcKnob=the knob's name | Bounds, Options, Explain |
Bounds | Sets the lowest and highest value of the knob just added. | the world itself, so calls chain | pLow=the lowest value; pHigh=the highest value | AddRefinement, Options | | the values are stored as text and Explain narrates them as bounds [1..99]
Options | Sets the list of choices of the knob just added. | the world itself, so calls chain | paOpts=a list of the allowed values | AddRefinement, Bounds | | Explain shows the options only when no bounds were set
Surfaces | Returns the surfaces on which the world appears, as declared by AddReaches. | a list of surface names | | AddReaches, Things | | a surface added as a single text or symbol is stored wrongly today, see AddReaches
Things | Returns the declared things with their fields. | a list of lists, each with the thing's name and its list of field names | | AddThing, Has
ScreenNames | Returns the names of the declared screens in order. | a list of texts | | AddScreen
AddReaches | Declares the surfaces, such as web, desktop or mobile, on which the world appears. | nothing; use AddReachesQ to chain | paSurfaces=a list of surface names | Surfaces, AddReachesQ | a single text or symbol is stored as [ [ ] ] today, so give a list: Surfaces then holds an unusable entry and both Explain and a platform's Generate raise an error | the list is added to the surfaces already declared
BraceEnd | Writes the pending goal and body assignments of a brace into their records. | nothing | | AddGoal, SetBody | | it is called for you when a brace closes, and every builder verb does the same first
Live | Turns the world on, runs a first Pulse and prints a one-line summary of its things, flows, reactions, goals and proposals. | the world itself, so calls chain | | Pulse, IsLive, Proposals | it prints to the console |
IsLive | TRUE if Live was called. | 1 or 0 | | Live
Pulse | Fires every reaction against the graph, adding one proposal for each instance that lacks the relation the reaction proposes. | a number, how many proposals were added | | React, Proposals, Relate | | it is idempotent: a standing proposal is not repeated, and one clears on the next pulse once the instance gets the relation
Proposals | Returns the proposals now standing. | a list of lists such as propose Visit for bilal | | Pulse, Pursue
React | Fires the reactions for one instance only, as Pulse does for all. | a number, how many proposals were added | pcInstance=the instance's name | Pulse, Proposals | | it first drops the proposals that the graph now satisfies
Explain | Prints the world in plain words: its things, relations, flows, reactions, goals, screens, knobs and reaches. | the world itself, so calls chain | | Show, Things | it prints to the console | it raises an error when a surface was added as a single text, see AddReaches | thing and goal names appear in lower case when given as symbols
Show | Prints one thing with its fields, truths and relations. | the world itself, so calls chain | pcThing=the name of a declared thing | Explain, Things | it prints to the console | an unknown name prints a no such thing line instead of failing
