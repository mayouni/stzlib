# w15 stzReactiveTask
init | Builds a task with an id, the function it will run and the reactive engine it belongs to, in the pending state. | nothing; the task is built and not run | id=the task's identifier; f=the function to run, an anonymous func or a function name; engine=the reactive engine, kept for subclasses; errorMode=how a failure is reported: ERROR_LOG, ERROR_THROW, ERROR_CALLBACK or ERROR_IGNORE, or an empty text for the default ERROR_LOG | Execute, Then_, Catch_ | | the class is meant for subclasses such as stzHttpTask and stzFunctionTask and not for the final programmer
Then_ | Sets the function called with the result when the task completes. | the task itself, so calls chain | completeFunc=a function taking the result | Catch_, Execute | | an error in the callback itself is caught like any failure of the task
Catch_ | Sets the function called with the error message when the task fails. | the task itself, so calls chain | errorFunc=a function taking the message text | Then_, Execute | | it is called only in ERROR_CALLBACK mode
Execute | Runs the task's function once, records the outcome on the task and calls the handlers. | nothing; read the outcome with Status, Result and Error | | Status, Result, Error | | on success the status is completed and the result is kept; on failure the status is error and the real reason, such as Error (R1) : Can't divide by zero, is kept; the log mode prints the reason, throw raises it again, callback calls the Catch_ function, ignore stays silent
Status | Returns where the task is in its life. | pending, running, completed or error, as text | | Succeeded, HasFailed | |
Result | Returns what the task's function returned. | the result; an empty text before the task completes | | Status, Succeeded | |
Error | Returns the reason the task failed. | the message as text; an empty text when it has not failed | | HasFailed, WasReported | |
HasFailed | TRUE if the task ended in error. | TRUE or FALSE, as 1 or 0 | | Error, Succeeded | |
WasReported | TRUE if the failure reached somebody: a raise, a handler or the console. | 1 or 0; only the ignore mode answers 0 for a failed task | | HasFailed, Error | | in ERROR_CALLBACK mode with no Catch_ function the failure is printed, so it is still reported; a task that has not failed answers 0
Succeeded | TRUE if the task completed. | TRUE or FALSE, as 1 or 0 | | Status, HasFailed |
Complete | Records a successful outcome that was produced outside Execute. | the task itself, so calls chain | pResult=the result to keep | Fail, Result | | it sets the status to completed and clears the error, so a caller that did the work itself reports through the same surface
Fail | Records a failed outcome that was produced outside Execute. | the task itself, so calls chain | pcMsg=the reason, turned into text | Complete, Error | | it sets the status to error and marks the failure as reported
Cleanup | Releases task resources; the base task has none, subclasses may override it. | nothing | | Execute |
