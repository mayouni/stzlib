init | Builds a performer over a list or over a stzList object, working on its own copy, so the list passed in is never changed. | nothing; the object is built | pListOrObj=a list, or a stzList object, whose items are transformed or read | Content | any other kind of value raises "Can't create stzListPerformer! Parameter must be a list or stzList object." |
Content | Returns the items the performer holds, after any Perform made through it. | a list | | Yield | |
NumberOfItems | Returns how many items the list holds. | a number | | Content | |
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE | | NumberOfItems | |
Perform | Replaces every item by the result of an expression applied to it, in place. | nothing; use PerformQ to chain | pcAction=the expression as text, where @item stands for the item and @i for its position, such as "2*@item" | Yield, PerformOn | | Yield gives the same results without changing the list; inside an expression len() counts bytes, so len(@item) of the Hebrew שלום is 8
PerformOn | Replaces by the result of an expression only the items at the given positions, in place. | nothing; use PerformOnQ to chain | panPos=the positions to transform, from 1; one outside the list is skipped; pcAction=the expression as text, where @item stands for the item | Perform, PerformW | | the expression is computed over the whole list and only the results at panPos are kept
PerformOnPositions | Replaces by the result of an expression only the items at the given positions, the same as PerformOn. | nothing | panPos=the positions to transform, from 1; pcAction=the expression as text, where @item stands for the item | PerformOn | |
PerformAtW | Replaces by the result of an expression only the items that are both at one of the given positions and meet a W condition, in place. | nothing; use PerformAtWQ to chain | panPos=the positions allowed; pcCondition=the W condition as text, where @item stands for the item; pcAction=the expression as text, where @item stands for the item | PerformW, PerformOn | | an item at a listed position that fails the condition stays as it was
Yield | Returns the results of an expression applied to every item, as a list, leaving the list unchanged. | a list with one result per item | pcYielder=the expression as text, where @item stands for the item and @i for its position, such as "2*@item" | Perform, YieldOn | | YieldQ answers a stzList to chain on; len() inside the expression counts bytes; an item the expression cannot compute, such as 10 / @item for 0, gives an empty text and no error
YieldOn | Returns the results of an expression for the items at the given positions only, in the order of the positions. | a list of results; positions outside the list are skipped | panPos=the positions to read, from 1, in the order wanted; pcYielder=the expression as text, where @item stands for the item | Yield, YieldW | | the expression is computed over the whole list and only the results at panPos are kept
PerformOnEachItemAndItsPosition | Replaces every item by the result of an expression that can use both the item and its position, in place. | nothing; use PerformOnEachItemAndItsPositionQ to chain | pcAction=the expression as text, where @item stands for the item and @i for its position, such as "@item + @i" | Perform | | it is Perform under a longer name: the position is available as @i in Perform too
YieldPairs | Returns the results of an expression applied to every item, exactly as Yield does. | a list of results, not of pairs | pcYielder=the expression as text, where @item stands for the item | Yield | Does not return [ position, item ] pairs today, as its section title says: YieldPairs("2*@item") on 10 20 30 answers 20 40 60, the same list as Yield |
