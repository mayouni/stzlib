# w15 stzWorldGraph
init | Loads a world artifact, the declared symbols and references of a project, into a stzGraph and collects every refusal. | nothing; the object is built and never raises on a bad artifact, it records diagnostics | pSource=the path of a world.json file, or the JSON text itself starting with a brace | IsLawful, Diagnostics | text that is not JSON, an empty or unreadable path, and a value that is not text are not raised: they leave the graph empty and add an MALFORMED_WORLD or EMPTY_WORLD diagnostic | the class is not loaded by stzlib.ring: load graph/stzWorldGraph.ring first; a contract other than 1.0 adds CONTRACT_MISMATCH and the symbols are still read
World | Returns the name of the world the artifact declares. | the name as text; an empty text when the artifact has none or was refused | | ContractVersion, Graph | |
ContractVersion | Returns the contract version the artifact was emitted against. | the version as text, such as 1.0 | | World, IsLawful | | the loader implements 1.0
Graph | Returns the world as an ordinary stzGraph, one node per symbol and one edge per referenced pair. | a stzGraph of type semantic | | Refs, Symbols | | each node id is the lower-case kind:name; two references between one pair of symbols make ONE edge whose label is the first reference's kind and whose refs property holds every row
Symbols | Returns every lawful symbol, each with id, kind, name, type, file, line and rationale. | a list of hash lists in the order they were declared | | SymbolCount, Symbol, NamesOfKind | | a refused symbol, unknown kind, bad name or duplicate, is not in it
SymbolCount | Returns how many lawful symbols were read. | a number | | Symbols, RefCount | |
Refs | Returns every lawful reference, each with from, to, kind, file and line. | a list of hash lists in the order they were declared; both ends are lower case | | RefCount, ReferencesFrom, ReferencesTo | | a reference whose end nothing declares is refused and is not in it
RefCount | Returns how many lawful references were read. | a number | | Refs, SymbolCount | | two references between one pair count twice, though the graph holds one edge for them
HasSymbol | TRUE if a symbol with an id exists in the world. | TRUE or FALSE, as 1 or 0 | pcId=the id as kind:name, matched without regard to case | Symbol, IdsOfKind | |
Symbol | Returns one symbol by its id. | a hash list with id, kind, name, type, file, line and rationale; [ ] when the world has no such symbol | pcId=the id as kind:name, matched without regard to case | HasSymbol, Symbols | |
NamesOfKind | Returns the names of every symbol of one kind. | a list of text in declaration order; [ ] for a kind with none | pcKind=the kind, such as entity or flow, in any letter case | IdsOfKind, Kinds, ZuiSymbolTable | | the names are without the kind prefix
IdsOfKind | Returns the ids of every symbol of one kind. | a list of text such as entity:member, in declaration order; [ ] for a kind with none | pcKind=the kind, such as entity or flow, in any letter case | NamesOfKind, HasSymbol | |
Kinds | Returns the kinds of symbol that the world actually uses. | a list of text, each kind once, in the order first met | | NamesOfKind, StzWorldSymbolKinds | | the closed set of kinds is entity, field, type, actor, norm, flow, screen, process, element and state
ZuiSymbolTable | Returns the four lists of names that the zui verifier reads for its deeper checks. | a hash list with the keys entities, actors, state and elements, each a list of names | | NamesOfKind | | a world with no symbol of a kind gives [ ] for it
ReferencesFrom | Returns every reference site that leaves a symbol. | a list of reference rows, so two references to one target are two rows; [ ] when none | pcId=the id as kind:name, matched without regard to case | ReferencesTo, Refs | |
ReferencesTo | Returns every reference site that arrives at a symbol. | a list of reference rows; [ ] when none | pcId=the id as kind:name, matched without regard to case | ReferencesFrom, Refs | |
Diagnostics | Returns every refusal and warning found while loading, in the order found. | a list of hash lists, each a diagnostic with code, severity, message, span, cites and language world | | ErrorCount, IsLawful | | the codes are EMPTY_WORLD, MALFORMED_WORLD, CONTRACT_MISMATCH, UNKNOWN_SYMBOL_KIND, MALFORMED_NAME, MISSING_SPAN (a warning), DUPLICATE_SYMBOL, UNKNOWN_REFERENCE_KIND and DANGLING_REFERENCE
ErrorCount | Returns how many diagnostics have severity error. | a number | | Diagnostics, IsLawful | | a MISSING_SPAN warning does not count
IsLawful | TRUE if loading raised no diagnostic of severity error. | TRUE or FALSE, as 1 or 0 | | ErrorCount, Diagnostics | | it is the gate a build reads: every reference resolved and no symbol refused
