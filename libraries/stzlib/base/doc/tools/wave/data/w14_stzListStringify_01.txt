# w14 stzListStringify -- Name | brief | returns | params | see | warning | note
init | Builds a stringifier over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to write out, or a stzList whose content is copied, any other value raises an error | Content, ToCode | | the stringifier works on its own copy: Stringify and its kin never change the list or the stzList you passed in, so read the result with Content
Content | Returns the list as it stands now, after the in-place conversions made so far. | a list | | NumberOfItems, Stringified
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
ToCode | Returns the list written as Ring code, in one text. | a text | | ComputableForm, ToListInAStringInShortForm | | [ "a", 12, 2.5 ] gives the text [ "a", 12, 2.50 ], a number with decimals showing two of them; ToCodeQ returns the text as a stzString
Stringify | Turns every item into a text, in place: numbers as digits, sublists as code, objects by their variable name. | nothing; the content changes. StringifyQ returns the stringifier for chaining | | Stringified, StringifyLists, StringifyObjects | | [ "a", 12, 2.5, [ 1, "b" ] ] becomes "a", "12", "2.50" and the text [ 1, "b" ]; texts stay as they are; StringifyItems is the same call
StringifyItems | Turns every item into a text, in place: numbers as digits, sublists as code, objects by their variable name. | nothing; the content changes | | Stringify, Stringified | | the same call as Stringify
Stringified | Returns the list with every item turned into a text, leaving the stringifier as it was. | a list of texts | | Stringify, ListsStringified | | StringifiedItems is the same call
StringifyLists | Turns only the sublists into code texts, in place, leaving the other items as they are. | nothing; the content changes. StringifyListsQ returns the stringifier for chaining | | ListsStringified, Stringify | | [ "a", 12, [ 1, "b" ] ] keeps "a" and 12 and turns the sublist into the text [ 1, "b" ]
ListsStringified | Returns the list with only its sublists turned into code texts, leaving the stringifier as it was. | a list | | StringifyLists, Stringified
StringifyObjects | Turns only the objects of the list into texts, in place, leaving the other items as they are. | nothing; the content changes. StringifyObjectsQ returns the stringifier for chaining | | ObjectsStringified, Stringify | | an object is replaced by the name of the variable that holds it, which reads @noname when the object was created without a name, as a stzString held in a plain variable does
ObjectsStringified | Returns the list with only its objects turned into texts, leaving the stringifier as it was. | a list | | StringifyObjects, Stringified | | the objects read @noname when they have no variable name
Singlify | Collapses each run of identical neighbouring items into one item, in place. | nothing; the content changes. SinglifyQ returns the stringifier for chaining | | Singlified, Stringify | | only neighbours are compared, so 1 1 2 2 2 1 becomes 1 2 1 and not 1 2; case counts, so a a A becomes a A
Singlified | Returns the list with each run of identical neighbouring items collapsed into one, leaving the stringifier as it was. | a list | | Singlify | | 1 1 2 2 2 1 gives 1 2 1; sublists are compared by content
ComputableForm | Returns the list written as Ring code, in one text. | a text | | ToCode, ToListInAStringInShortForm | | the same answer as ToCode; ToListInString and ToListInAString are the same call
ToListInAStringInShortForm | Returns the list as a range literal when it is a run of whole numbers going up or down by one, and as code otherwise. | a text | | ToCode, ComputableForm | | [ 3, 4, 5, 6 ] gives 3:6 and [ 5, 4, 3 ] gives 5:3, while [ 1, 3, 5 ], [ 7 ] and [ "x", 5 ] fall back to the code form; ToListInStringInShortForm and ToListInShortForm are the same call
Join | Concatenates the items into one text, with a separator between two items. | a text | pcSep=the text put between two items | ToCode, Stringified | | numbers are written as digits; a sublist among the items becomes an empty text, so 1, [ 2, 3 ], 4 joined with + gives 1++4; an empty list gives an empty text; Joined and JoinWith are the same call and JoinQ returns a stzString
Lowercased | Returns the list with every text in lower case, leaving the other items as they are. | a list | | Uppercased, Stringified | | Hebrew and other scripts without case are unchanged and accented letters are folded (É becomes é); the stringifier is left as it was
Uppercased | Returns the list with every text in upper case, leaving the other items as they are. | a list | | Lowercased, Stringified | | accented letters are folded (é becomes É) and ß becomes SS, which lengthens the text; scripts without case are unchanged; the stringifier is left as it was
NumbersToStrings | Returns the list with every number written as a text, leaving the other items as they are. | a list | | StringsToNumbers, Stringified | | 2.5 becomes "2.50"; sublists are not touched, where Stringified writes them as code; the stringifier is left as it was
StringsToNumbers | Returns the list with every numeric text turned into a number, leaving the other items as they are. | a list | | NumbersToStrings | a text that is not numeric raises error R41 Invalid numeric string, instead of being left alone ("abc", "x" and "7x" were tried) | "12", "3.5" and "-2" become numbers; an empty text becomes 0; the stringifier is left as it was
