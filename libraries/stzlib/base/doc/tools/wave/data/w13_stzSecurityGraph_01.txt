init | Builds an empty security graph with a name, ready for actors, tools, secrets and the edges between them. | nothing; the object is built | pcName=the graph name | AddActor, GraphQ
GraphQ | Returns the underlying stzGraph, to draw or query directly. | the stzGraph object that holds the nodes and edges | | Tampering, Name | the graph can be edited through it around the governed doors; Tampering reports a changed posture
Name | Returns the name the graph was built with. | a text | | GraphQ
AddActor | Declares an actor node with a trust posture, and records the posture where gates read it. | the graph itself, so calls chain | pcId=the actor name, lower-cased and trimmed to make the node id; pcPosture=the posture, trusted, external or sandboxed | AddTool, Uses, MayAttach, Tampering | | declaring the same id again replaces its posture; the posture record is kept out of reach of GraphQ
Tampering | Returns the actors whose posture in the graph no longer equals the one AddActor recorded. | a list of [ actor, recorded, found ] rows; found is (removed) for a deleted node | | Violations, GraphQ | | [ ] when nothing was edited around the governed doors
AddTool | Declares a tool node, something an actor can use and that can grant a capability. | the graph itself, so calls chain | pcId=the tool name, lower-cased and trimmed to make the node id | Uses, Grants
AddSecret | Declares a secret node, by descriptor and never by value. | the graph itself, so calls chain | pcId=the secret name, lower-cased and trimmed to make the node id | StoredIn, References, BlastRadius
AddStore | Declares a store node, a place where secrets live. | the graph itself, so calls chain | pcId=the store name, lower-cased and trimmed to make the node id | StoredIn
AddSite | Declares a site node, an application surface that can reference secrets. | the graph itself, so calls chain | pcId=the site name, lower-cased and trimmed to make the node id | References
AddCapability | Declares a capability node, such as effectful, ahead of its first use. | the graph itself, so calls chain | pcId=the capability name, lower-cased and trimmed to make the node id | Holds, Grants | | Holds and Grants create the node themselves when it is missing
Holds | Adds the edge by which an actor directly holds a capability. | the graph itself, so calls chain | pcActor=the declared actor; pcCapability=the capability, created if missing | Uses, ReachesCapability | raises an error when the actor was not declared first | an existing edge between the same two nodes is kept, so no second edge is added
Uses | Adds the edge by which an actor uses a tool. | the graph itself, so calls chain | pcActor=the declared actor; pcTool=the declared tool | Grants, Delegates | raises an error when either node was not declared first
Grants | Adds the edge by which a tool confers a capability on whoever uses it. | the graph itself, so calls chain | pcTool=the declared tool; pcCapability=the capability, created if missing | Uses, ReachesCapability | raises an error when the tool was not declared first
Delegates | Adds the edge by which one actor may act as another, so trust passes along it. | the graph itself, so calls chain | pcFrom=the declared actor that delegates; pcTo=the declared actor that it may act as | Uses, ReachesCapability | raises an error when either node was not declared first
References | Adds the edge by which a site refers to a secret. | the graph itself, so calls chain | pcSite=the declared site; pcSecret=the declared secret | StoredIn, BlastRadius | raises an error when either node was not declared first
StoredIn | Adds the edge by which a secret lives in a store. | the graph itself, so calls chain | pcSecret=the declared secret; pcStore=the declared store | References, BlastRadius | raises an error when either node was not declared first
MayAttach | TRUE if attaching a secret to that actor keeps the surface sound: the actor exists and was not declared sandboxed. | TRUE or FALSE; FALSE for an actor that is not in the graph | pcActor=the actor name; pcSecret=the secret name, which is not looked at | AttachSecret, AddActor | | it reads the recorded posture, so editing the graph through GraphQ does not change the answer
AttachSecret | Adds the edge by which a live secret is attached to an actor, refusing it for a sandboxed actor. | the graph itself, so calls chain | pcActor=the declared actor; pcSecret=the declared secret | MayAttach, BlastRadius, Tampering | raises an error for a sandboxed actor, and the refusal is noted to the security ledger as posture.refused; also raises when either node was not declared | the escalation never enters the graph through this door
ReachesEffectful | TRUE if the actor can reach the effectful capability by any path: held, through a tool, or through a delegation. | TRUE or FALSE; FALSE for an actor that is not in the graph | pcActor=the actor name | ReachesCapability, PathToEffectful, AuditEscalations | | a flag check on the actor alone cannot see a path through a tool
ReachesCapability | TRUE if the actor can reach the named capability by any path. | TRUE or FALSE; FALSE when the actor or the capability is not in the graph | pcActor=the actor name; pcCapability=the capability name | ReachesEffectful, PathToCapability
PathToCapability | Returns the route by which the actor reaches a capability, shortest first, not just whether one exists. | a list of node names from the actor to the capability; [ ] when there is no route or a node is unknown | pcActor=the actor name; pcCapability=the capability name | PathToEffectful, ReachesCapability, CutCapability
PathToEffectful | Returns the route by which the actor reaches the effectful capability. | a list of node names from the actor to effectful; [ ] when there is none | pcActor=the actor name | PathToCapability, AuditEscalations
CutCapability | Removes every path by which the actor reaches a capability, by deleting the actor own first-hop edges that lead there. | a list of [ from, label, to ] rows, the edges removed; [ ] when there was nothing to cut | pcActor=the actor name; pcCapability=the capability name | PathToCapability, ReachesCapability | | other actors keep their own routes; a cut is noted to the ledger as capability.revoked
BlastRadius | Returns every node that can reach the secret, which tells what a leak of it exposes. | a list of node names, the secret itself excluded; [ ] for an unknown secret | pcSecret=the secret name | AttachSecret, References, StoredIn | | use it to plan a rotation
AuditEscalations | Returns every sandboxed actor that can reach the effectful capability with its route, and records each one in the ledger. | a list of [ actor, [ path ] ] rows | | NumberOfEscalations, PathToEffectful, Violations | | a deliberate audit, unlike the query methods, each finding is noted as graph.escalation_path_found
NumberOfEscalations | Returns how many sandboxed actors can reach the effectful capability. | a number | | AuditEscalations | | it runs the audit, so each finding is noted to the ledger
Violations | Returns the rule findings of the security surface, plus one for each posture changed around the gate. | a list of rows [ :rule, :subject, :where, :severity, :message ]; [ ] when sound | | IsSound, Tampering, AuditEscalations
IsSound | TRUE if the graph breaks no security rule and no posture was changed around the gate. | TRUE or FALSE | | Violations, Tampering
