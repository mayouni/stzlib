RegisterCredential | Judges the response of a device that creates a credential, and returns the credential to store. | a hash list [ :ok, :credentialId, :keyType, :key1, :key2, :signCount, :why ]; :ok is 1 only when every check passed, and :why says what failed | pcAttObjB64=the attestation object, base64url; pcClientDataB64=the client data JSON, base64url; pcExpectedChallenge=the challenge this server issued for this exchange | VerifyAssertion, NewChallenge | an empty expected challenge skips the challenge check, so a response to any earlier challenge is accepted; an empty server origin skips the origin check; it never raises, a refusal is returned | the checks are the ceremony type webauthn.create, the challenge, the origin and the user-presence flag
