init | Compiles a declaration of fields into a schema, judging it now so a faulty declaration never reaches a model. | nothing; the object is built | paFields=the declaration, a list of field hash-lists with field, type (string, number, boolean, oneof, list or structure) and optional choices, of, must and optional | Fields, Verify, ParseOutput | raises an error for an unknown field type, a mistyped key or an unknown operator, naming it | the operators are equals, not-equals, contains, greaterthan, lessthan, greaterequal and lessequal, and symbols such as >= are normalized
Name | Returns the schema name. | a text; output unless SetName changed it | | SetName, Describe
SetName | Sets the schema name, shown in descriptions and in the type a function reports. | nothing; use SetNameQ to chain | pcName=the new name; a blank text leaves the name as it was | Name, Describe
Fields | Returns the compiled fields, in declared order. | a list of hash-lists with name, type, required, choices, of, fields, must and note | | FieldNames, Field | | operators in must appear in their normalized spelling, such as greaterequal for >=
NumberOfFields | Returns how many top-level fields the schema declares. | a number | | Fields, FieldNames
FieldNames | Returns the names of the declared fields, in declared order. | a list of text | | RequiredFieldNames, HasField
RequiredFieldNames | Returns the names of the fields that must be answered. | a list of text; every field not declared optional | | FieldNames, HasField
HasField | TRUE if a field of that name is declared. | TRUE or FALSE | pcName=the field name, compared without regard to case | Field, FieldNames
Field | Returns the compiled declaration of one field. | a hash-list with name, type, required, choices, of, fields, must and note | pcName=the field name, compared without regard to case | HasField, Fields | raises an error for a name that is not declared, so test HasField first
RefusesUnknownFields | TRUE if an undeclared field in an answer refuses the whole answer. | TRUE or FALSE; FALSE by default | | RefuseUnknownFields, AllowUnknownFields
RefuseUnknownFields | Closes the schema, so that a field nobody declared refuses the answer instead of being reported and dropped. | nothing; use RefuseUnknownFieldsQ to chain | | AllowUnknownFields, RefusesUnknownFields
AllowUnknownFields | Reopens the schema, so that an undeclared field is reported as a warning and dropped. | nothing; use AllowUnknownFieldsQ to chain | | RefuseUnknownFields, RefusesUnknownFields
Verify | Judges an already parsed value against the declaration. | a hash-list [ :ok, :value, :findings ]; :value holds the declared fields in declared order with scalars coerced, and is [ ] when :ok is 0 | pvValue=the value to judge, a list of [ field, value ] rows | ParseOutput, Check, Holds | | no partial credit: one error finding refuses the whole value; a warning, such as a dropped extra field, does not
Check | Returns the findings of judging a value, as the family of rule checks does. | a list of rule rows [ :rule, :subject, :where, :severity, :message ]; [ ] when nothing is found | pvValue=the value to judge, a list of [ field, value ] rows | Verify, Holds | | the subject is always structured-output and the where is the field path; the rows go straight to stzRuleReport.Ingest
Holds | TRUE if the value satisfies every rule of the declaration. | TRUE or FALSE | pvValue=the value to judge, a list of [ field, value ] rows | Verify, Check
NumberOfFindings | Returns how many findings judging a value produces, warnings included. | a number | pvValue=the value to judge, a list of [ field, value ] rows | Check, Holds
ParseOutput | Reads raw model text as a structure and judges it, returning the validated whole or the refusal. | a hash-list [ :ok, :value, :findings, :shape ]; :shape is json or memo, and empty when the text could not be read | pcRaw=the raw reply text | Accepts, Verify, CiteFindings | | JSON is found inside prose and code fences, but the line form must hold only field: value lines, so a sentence before it refuses the answer; field names ignore case
Accepts | TRUE if raw model text reads as a structure that satisfies the declaration. | TRUE or FALSE | pcRaw=the raw reply text | ParseOutput, Holds
Agrees | TRUE if two values are equal, structures included, which the equals sign cannot say of two lists. | TRUE or FALSE | pvExpected=the expected value; pvGot=the value to compare | Diff, CiteFindings
Diff | Returns, field by field, how two values differ. | a list of rule rows with rule golden, one for each field that moved; [ ] when they agree | pvExpected=the expected value; pvGot=the value to compare | Agrees, CiteFindings
CiteFindings | Writes findings as one sentence each, naming the rule and the field, and cuts a long list to four, saying so. | a text | paFindings=the findings to write, as Check or Verify returns them | Check, ParseOutput | | an empty list gives a sentence saying nothing is to cite
PromptClause | Returns the instruction that asks a model for exactly this shape, ready to append to a prompt. | a text with one placeholder line per field | | ToGBNF, Describe | | it is kept short on purpose, since longer wording measured worse on a small model
ToGBNF | Returns the declaration compiled into a GBNF grammar, which the sampler can enforce to fix the shape of a reply. | a text, the grammar | | IsExpressibleAsGrammar, UnenforcedByGrammar, Verify | raises an error naming the construct for a declaration a grammar cannot express, such as a nested structure | a grammar fixes shape, never value or truth, so every must clause is dropped from it
IsExpressibleAsGrammar | TRUE if the declaration can become a grammar at all. | TRUE or FALSE; FALSE for a nested structure | | ToGBNF, UnenforcedByGrammar
UnenforcedByGrammar | Returns one line for each constraint that the grammar does not carry and the court still checks. | a text of lines, such as the must clauses; empty when the grammar carries everything | | ToGBNF, Verify | raises an error for a declaration that cannot be compiled to a grammar
IsDecodingConstrained | TRUE if the engine enforces a grammar at the sampler. | TRUE or FALSE | | DecodingStatus, ToGBNF | | the engine answers, not the schema
DecodingStatus | Returns what constrained decoding does and what it does not do. | a text | | IsDecodingConstrained, UnenforcedByGrammar
Describe | Returns the declaration read back as prose, one line per field, for a narrated test or a reader. | a text with a header and one line per field, ending with a note when the schema is closed | | Fields, PromptClause
