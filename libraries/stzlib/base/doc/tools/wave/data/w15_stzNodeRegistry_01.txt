init | Creates a registry of node addresses with one reactor that will carry every link to them. | nothing; the object is built | | Register, Send
LastStatus | Returns the outcome of the last Send or Ask: ok, timeout, down, unknown, badtimeout or denied, in lower case. | a text | | Send, Ask | it reads ok on a new registry
SecureWith | Makes the registry sign every outgoing message as a given key, so receivers can verify and refuse it. | the registry itself, so calls chain | poSigner=a stzRequestSigner holding the shared keyring; pcKeyId=the key id the messages are signed as | Send, Ask | a receiver that refuses a signed Ask is reported as the status denied | the signer was a stand-in during the run: only the storing was exercised
Register | Declares where a named node lives; registering a name again moves it, and the cached link is dropped so the next call dials the new place. | the registry itself, so calls chain | pcName=the node's name, matched without regard to case; pcHost=the node's host or interface address; pnPort=the node's port | Send, Ask | nothing connects here: the link is dialed on the first Send or Ask
Send | Hands a message to a node without waiting for an answer, and answers whether it reached the wire. | 1 if handed to the wire, 0 when the node is unknown or unreachable | pcAddr=the node's name, or name@host to override the host; pMsg=the message, a list [ tag, args... ] | Ask, LastStatus | at most once, with no retry; LastStatus tells unknown from down | run only with a name that is not registered, so no link was dialed
Ask | Sends a message to a node and waits up to a time limit for the reply, which it returns. | the reply value; an empty text on timeout, down, unknown, badtimeout or denied | pcAddr=the node's name, or name@host to override the host; pMsg=the message, a list [ tag, args... ]; nTimeoutMs=how long to wait, in milliseconds, which must be above 0 | Send, LastStatus | the limit is mandatory: 0 or less is refused with the status badtimeout and nothing is sent; delivery is at most once, so a timed-out Ask may still have been handled, and its late reply is dropped by correlation id | run only with a name that is not registered and with a refused limit, so no link was dialed
CloseAll | Closes every cached link; the registered names stay and the next call dials again. | the registry itself, so calls chain | | Register, Destroy
Destroy | Closes every link and destroys the registry's reactor. | nothing | | CloseAll | the registry cannot be used afterwards
