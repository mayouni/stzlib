init | Builds a twin with no state and no bridge; a specialization such as stzVirtualFileSystem supplies both. | nothing; the twin is built | | stzVirtualFileSystem, stzVirtualEnvironment | used directly it has no state, so ExecuteOperation raises an error: build a specialization
SetActor | Sets who is acting, which each operation rehearsed afterwards carries. | the twin itself, so calls chain | pcActor=the name of the human, script or agent | Actor, ExecuteOperation | | operations already rehearsed keep the actor they were stamped with
Actor | Returns who is acting. | a text; human until another is set | | SetActor
SetBridge | Sets the reality bridge that plans generated by the twin commit through. | the twin itself, so calls chain | poBridge=the bridge object, which is the only thing that touches reality | Bridge, GenerateUpdatePlan
Bridge | Returns the reality bridge of the twin. | the bridge object | | SetBridge
State | Returns the in-memory state the twin changes. | the state object, such as a stzFileTree | | ExecuteOperation
ExecuteOperation | Rehearses one operation: applies it to the in-memory state and records it, touching nothing real. | the twin itself, so calls chain | oOp=the stzVirtualOperation to rehearse; it is stamped with the twin's actor | History, UndoLast, GenerateUpdatePlan | | the verbs of a specialization, such as CreateFile, build the operation and call this
History | Returns the rehearsed operations, in order. | a list of stzVirtualOperation | | NumberOfOperations, HistoryText
NumberOfOperations | Returns how many operations the history holds. | a number | | History
UndoLast | Drops the last operations from the history and rebuilds the state from the base and the operations kept. | the twin itself, so calls chain | pnCount=how many operations to drop from the end; more than the history holds leaves it empty | RollbackTo, CreateSnapshot | a negative count raises an error; snapshots are not trimmed, so a RollbackTo to a snapshot taken after the dropped operations raises an error
CreateSnapshot | Keeps a copy of the current state and the length of the history under a name. | the twin itself, so calls chain | pcName=the name to find the snapshot by | RollbackTo | | a second snapshot of the same name does not replace the first: RollbackTo finds the first
RollbackTo | Restores the state of a snapshot and cuts the history back to its length. | the twin itself, so calls chain | pcName=the name given to CreateSnapshot | CreateSnapshot, UndoLast | an unknown name raises an error; a snapshot taken at more operations than the history holds now, because UndoLast dropped some, raises an array-index error instead of restoring
GenerateUpdatePlan | Returns a plan holding the history and the bridge, ready to narrate, validate and commit. | a stzUpdatePlan | | stzUpdatePlan, SetBridge | | the plan holds the same operations as the history, and nothing is committed until Execute
HistoryText | Returns the rehearsal as text: each operation numbered, with its actor and its intent when one was given. | a text, one line per operation | | ShowHistory, History
