init | Builds a rule with a name, as a validation rule of the custom domain, error severity and no clause. | nothing; the object is built | pcName=the rule's name, which must not be empty; an empty or blank name raises an error | SetDomain, When, Check
SetRuleType | Sets whether the rule validates a finished graph, guards an operation, or derives new edges and nodes. | nothing; use SetRuleTypeQ to chain | pcType=validation, constraint or derivation, in any case; any other text raises an error | RuleType, SetSeverity | SetRuleTypeQ is the same call and returns the rule | the type only changes the entry that Register writes to the registry
SetDomain | Sets the domain, the registry group the rule joins when registered, kept in lower case. | nothing; use SetDomainQ to chain | pcDomain=the group name, such as agentic or security; an empty text raises an error | Domain, Register | SetDomainQ is the same call and returns the rule | the domain is also the subject of each finding the rule reports
SetSeverity | Sets how serious a finding of this rule is. | nothing; use SetSeverityQ to chain | pcSeverity=error, warning or info, in any case; any other text raises an error | Severity, Check | SetSeverityQ is the same call and returns the rule | only error makes a rule set unsound
SetMessage | Sets the description of what the rule claims, which is also the message of a finding until ThenViolation gives one. | nothing; use SetMessageQ to chain | pcMsg=the description, as text | Message, ThenViolation | SetMessageQ is the same call and returns the rule |
When | Adds a clause that selects the nodes the rule looks at: a node property tested against a value; clauses are combined with AND. | nothing; use WhenQ to chain | pcProp=the node property to read; pcOp=the test: equals or =, not-equals or !=, contains, not-contains, exists, missing, greaterthan or >, lessthan or <, greaterequal or >=, lessequal or <=; pValue=the value to compare with | Then, Clauses, SubjectsIn | an empty property name or an unknown operator raises an error; the ordering operators compare numbers only: on a text greaterthan and lessthan never match but greaterequal and lessequal match every node, which is a defect; an unset property reads as 0, so exists fails and missing holds for it | WhenQ is the same call and returns the rule; with no Then clause, a node that matches every When clause is the violation
ThenViolation | Sets the message attached to each finding, in place of the rule's description. | nothing; use ThenViolationQ to chain | pcMsg=the message of a finding, as text | ViolationMessage, SetMessage | ThenViolationQ is the same call and returns the rule |
Then | Adds a requirement that every node selected by the scope clauses must satisfy, which turns the rule into an implication. | nothing; use ThenQ to chain | pcProp=the node property to read; pcOp=the test, as for When; pValue=the value to compare with | When, Requirements, IsImplication | an empty property name or an unknown operator raises an error | ThenQ is the same call and returns the rule; a node in scope that fails a requirement is the finding, and a rule with Then clauses only applies them to every node
Governs | Declares a function that lists the subjects the rule governs, for a rule that uses a checker and so has no readable scope. | nothing; use GovernsQ to chain | fFunc=a function taking the graph and returning a list of subject keys such as node:planner | SubjectsIn, Excludes, UseChecker | the function is read by governance and is not consulted when the rule runs; it wins over the clauses in SubjectsIn | GovernsQ is the same call and returns the rule
Excludes | Declares a function that lists the subjects the rule must not govern, the boundary that governance tests. | nothing; use ExcludesQ to chain | fFunc=a function taking the graph and returning a list of subject keys | CounterSubjectsIn, Governs | the function is read by governance and is not consulted when the rule runs | ExcludesQ is the same call and returns the rule
DeclareUniversal | Declares that the rule has no boundary because its claim covers the whole graph, with the reason. | nothing; use DeclareUniversalQ to chain | pcWhy=the reason the rule is universal, as text; an empty text leaves the rule not universal | IsUniversal, UniversalWhy, Governs | DeclareUniversalQ is the same call and returns the rule |
SetReadsQ | Declares the names of the things the rule reads, so an ordering defect is a fact about declarations. | the rule itself, so calls chain | pacNames=a list of names, as text | Reads, SetWritesQ, SetOrderQ | there is no plain SetReads: this is the only form
SetWritesQ | Declares the names of the things the rule writes. | the rule itself, so calls chain | pacNames=a list of names, as text | Writes, SetReadsQ, SetOrderQ | there is no plain SetWrites: this is the only form
SetOrderQ | Declares the position at which the rule runs among the rules of its set. | the rule itself, so calls chain | pnOrder=the position, as a number | Order, SetReadsQ | there is no plain SetOrder: this is the only form
SubjectsIn | Returns the keys of the nodes the rule looks at in a graph: those selected by its Governs function, else by its When clauses. | a list of keys such as node:planner, in lower case; empty for a rule with no clause and no Governs function | poGraph=the graph to look at | CounterSubjectsIn, Governs, When | | a rule with only a checker and no Governs answers an empty list
CounterSubjectsIn | Returns the keys of the nodes the rule looks at and does not take, the complement of its scope. | a list of keys such as node:writer; empty for a rule with no clause and no Excludes function | poGraph=the graph to look at | SubjectsIn, Excludes | | its Excludes function wins over the complement
Name_ | Returns the rule's name, exactly as given. | a text | | Name, init
Claim | Returns what the rule claims, as set by SetMessage. | a text; empty when none was set | | Message, ViolationMessage
Reads | Returns the names the rule declares it reads. | a list of text; empty when none was declared | | SetReadsQ, Writes
Writes | Returns the names the rule declares it writes. | a list of text; empty when none was declared | | SetWritesQ, Reads
Order | Returns the position the rule declares among the rules of its set. | a number; 0 when none was declared | | SetOrderQ
IsUniversal | TRUE if the rule was declared universal, with a reason. | TRUE or FALSE | | DeclareUniversal, UniversalWhy
UniversalWhy | Returns the reason given when the rule was declared universal. | a text; empty when the rule is not universal | | DeclareUniversal, IsUniversal
UseChecker | Gives the rule a function that decides for the whole graph, for a test the clauses cannot say. | nothing; use UseCheckerQ to chain | fChecker=a function taking the graph and returning a list of [ :where = id, :message = text ] rows, empty when the graph is fine | HasChecker, Check, Governs | a checker replaces the clauses: when both are set, only the checker runs; an empty :where means the whole graph | UseCheckerQ is the same call and returns the rule
Name | Returns the rule's name, exactly as given. | a text | | Name_, init
RuleType | Returns the rule's type, in lower case. | validation, constraint or derivation | | SetRuleType | | a new rule is a validation
Domain | Returns the domain, the registry group of the rule, in lower case. | a text; custom until another is set | | SetDomain, Register
Severity | Returns how serious a finding of the rule is. | error, warning or info | | SetSeverity | | a new rule is an error
Message | Returns the description of the rule. | a text; empty when none was set | | SetMessage, ViolationMessage
ViolationMessage | Returns the message of a finding: the one set by ThenViolation, else the rule's description. | a text | | ThenViolation, Message
Clauses | Returns the scope clauses added by When, in order. | a list of [ property, operator, value ] rows, the operator in its canonical form such as equals or not-contains; empty when none | | When, NumberOfClauses, Requirements
NumberOfClauses | Returns how many scope clauses the rule has. | a number | | Clauses, When
Requirements | Returns the requirements added by Then, in order. | a list of [ property, operator, value ] rows; empty when none | | Then, NumberOfRequirements, Clauses
NumberOfRequirements | Returns how many requirements the rule has. | a number | | Requirements, Then
IsImplication | TRUE if the rule has at least one requirement, so that it says every node in scope must satisfy it rather than that no node may match. | TRUE or FALSE | | Then, Requirements
HasChecker | TRUE if the rule was given a checker function. | TRUE or FALSE | | UseChecker, Check
Check | Runs the rule over a graph and returns one finding per offending node, in the house rule shape. | a list of rows [ :rule, :subject, :where, :severity, :message ]; empty when the rule holds; the subject is the domain, where is the node id, and the message is the violation message | oGraph=the graph to check, a stzGraph or a kind of one | Holds, NumberOfFindings, SubjectsIn | a rule with no clause, no requirement and no checker never finds anything | without a Then clause every node in scope is a finding, with one it is each node in scope that fails a requirement
Holds | TRUE if the rule finds nothing in the graph. | TRUE or FALSE | oGraph=the graph to check | Check, NumberOfFindings | | any severity counts here, a warning as well as an error
NumberOfFindings | Returns how many findings the rule has in the graph. | a number | oGraph=the graph to check | Check, Holds
Register | Compiles the rule down to an entry of the shared rule registry, in the group of its domain, so the existing engine runs it. | nothing; use RegisterQ to chain | | RegistryEntry, SetDomain, stzGraphRuleSet | RegisterQ is the same call and returns the rule | registering the same rule twice adds a second entry and does not replace the first
RegistryEntry | Returns the registry entry the rule would produce, without registering it. | a hash list with the keys name, in upper case, type, function, params, message and severity | | Register
Show | Prints three lines that describe the rule: its name, type, domain and severity, its clauses joined by AND, and its violation message. | the rule itself, so calls chain; it prints | | Clauses, ViolationMessage
