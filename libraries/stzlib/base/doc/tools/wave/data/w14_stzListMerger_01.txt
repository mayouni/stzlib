# w14 stzListMerger -- Name | brief | returns | params | see | warning | note
init | Builds a merger over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to work on, or a stzList whose content is copied, any other value raises an error | Content, Merged | | the merger works on its own copy and never changes the list or the stzList you passed in
Content | Returns the list as it stands now, after the in-place merges made so far. | a list | | NumberOfItems, Merged
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
Copy | Returns a new merger over a copy of the list. | a stzListMerger | | Content, Merged | | editing the copy leaves this merger alone
Update | Replaces the list held by the merger with another list. | nothing; the content changes | paNewContent=the list that becomes the content | UpdateWith, Content
UpdateWith | Replaces the list held by the merger with another list. | nothing; the content changes | paNewContent=the list that becomes the content | Update, Content | | the same call as Update
Add | Appends one item at the end of the list. | nothing; the content changes | pItem=the item to append, kept whole even when it is a list | MergeWith, Content | | to append the items of a list one by one, use MergeWith
Merge | Opens each sublist one level and puts its items in its place, in place. | nothing; the content changes. MergeQ returns the merger for chaining | | Merged, Flatten, MergeWith | | only one level is opened: [ 1, [ 2, 3 ], [ 4, [ 5, 6 ] ] ] gives [ 1, 2, 3, 4, [ 5, 6 ] ]; Flatten opens every level
Merged | Returns the list with each sublist opened one level, leaving the merger as it was. | a list | | Merge, Flattened | | only one level is opened, as in Merge
MergeWith | Appends the items of another list at the end of this one, in place. | nothing; the content changes. MergeWithQ returns the merger for chaining | paOtherList=the list whose items are appended one by one | MergedWith, Add, PrependWith | | a sublist inside the other list stays a sublist
MergedWith | Returns the list followed by the items of another list, leaving the merger as it was. | a list | paOtherList=the list whose items are appended | MergeWith, PrependedWith
AssociateWith | Returns each item paired with the item at the same position in another list. | a list of [ item, counterpart ] pairs | paOtherList=the list that supplies the counterparts | ZipWith, MergedWith | | when the other list is shorter the missing counterpart is an empty text, where ZipWith stops at the shorter list; AssociatedWith is the same call and AssociateWithQ returns a stzList
Flatten | Opens every sublist at every depth and puts its items in its place, in place. | nothing; the content changes. FlattenQ returns the merger for chaining | | Flattened, Merge | | [ 1, [ 2, 3 ], [ 4, [ 5, 6 ] ] ] gives [ 1, 2, 3, 4, 5, 6 ]
Flattened | Returns the list with every sublist opened at every depth, leaving the merger as it was. | a list | | Flatten, Merged
InterleaveWith | Alternates the items of the list with those of another list, in place. | nothing; the content changes. InterleaveWithQ returns the merger for chaining | paOtherList=the list whose items go between the held ones | InterleavedWith, ZipWith | | the held list leads, and when one list is longer its leftover items follow at the end
InterleavedWith | Returns the items of the list alternating with those of another list, leaving the merger as it was. | a list | paOtherList=the list whose items go between the held ones | InterleaveWith, ZippedWith | | the held list leads, and the leftover items of the longer list follow at the end
ZipWith | Returns each item paired with the item at the same position in another list. | a list of [ item, counterpart ] pairs | paOtherList=the list that supplies the counterparts | Unzip, AssociateWith, InterleaveWith | | the pairing stops at the shorter list; ZippedWith is the same call and ZipWithQ returns a stzList
Unzip | Splits a list of pairs into the list of their first items and the list of their second items. | a list of two lists | | ZipWith, Unzipped | | an item that is not a list of at least two items is skipped, and only the first two items of a longer sublist are read; UnzipQ returns a stzList
PrependWith | Puts the items of another list in front of the list, in place. | nothing; the content changes. PrependWithQ returns the merger for chaining | paOtherList=the list whose items go first | PrependedWith, MergeWith | | the other list keeps its own order
PrependedWith | Returns the items of another list followed by the list, leaving the merger as it was. | a list | paOtherList=the list whose items go first | PrependWith, MergedWith
DiffWith | Returns the items of the list that are not in another list. | a list | paOtherList=the list whose items are taken away | IntersectWith, UnionWith | | case counts, and there is no CS form here: A is not taken away by a; items that stay keep their repeats, so [ 1, 1, 2, 3, 3 ] minus [ 2 ] is [ 1, 1, 3, 3 ]; Minus is the same call and DiffWithQ returns a stzList
IntersectWith | Returns the items found both in the list and in another list, without repeats. | a list | paOtherList=the list to match against | DiffWith, UnionWith | | case counts, and there is no CS form here; CommonWith is the same call and IntersectWithQ returns a stzList
UnionWith | Returns every item found in the list or in another list, without repeats. | a list | paOtherList=the list whose items are added | IntersectWith, MergedWith | | case counts, and there is no CS form here; the items of the held list come first, in order; UnionWithQ returns a stzList
Partition | Cuts the list into consecutive groups of equal size, the last one possibly shorter. | a list of lists | n=the number of groups wanted | MergedWith, Unzip | | the group size is the count divided by n, rounded up, so the answer can hold fewer than n groups: 6 items and n = 4 give 3 groups of 2; n = 0 gives [ ]; PartitionQ returns a stzList and Partitioned is the same call
