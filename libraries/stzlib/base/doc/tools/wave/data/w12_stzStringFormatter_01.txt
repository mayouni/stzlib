# w12 stzStringFormatter -- Name | brief | returns | params | see | warning | note
init | Builds a formatter over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the text to format, or a stzString whose content is formatted, any other value raises an error | Content, Titlecased | with a stzString argument, the first edit (Apply..., an Align, Trim, Simplify, RepeatNTimes) leaves the stzString you passed reading as an empty text; the formatter itself keeps the right text | pass a plain text and read the result with Content; stzString does it safely by writing the formatter result back with Update
Content | Returns the text as it stands now, after the edits made so far. | a text |  | NumberOfChars, Lowercased
NumberOfChars | Returns how many characters the text holds, counting an emoji or a Hebrew letter as one. | a number |  | Content, IsEmpty
IsEmpty | TRUE if the text holds no character at all. | TRUE or FALSE, as 1 or 0 |  | NumberOfChars, Content
ApplyLowercase | Turns the held text to lower case, in place. | nothing; the text changes. ApplyLowercaseQ returns the formatter for chaining |  | Lowercased, ApplyUppercase |  | the past-tense twin Lowercased leaves the formatter alone
Lowercased | Returns the text in lower case and leaves the formatter unchanged. | a text |  | ApplyLowercase, Uppercased |  | LowercasedQ returns a new formatter over the result
ApplyUppercase | Turns the held text to upper case, in place; a German sharp s becomes SS. | nothing; the text changes. ApplyUppercaseQ returns the formatter for chaining |  | Uppercased, ApplyLowercase
Uppercased | Returns the text in upper case and leaves the formatter unchanged; a German sharp s becomes SS. | a text |  | ApplyUppercase, Lowercased |  | UppercasedQ returns a new formatter over the result
ApplyCapitalcase | Capitalizes the held text in place: its first character in upper case and everything after it in lower case. | nothing; the text changes. ApplyCapitalcaseQ returns the formatter for chaining |  | Capitalized, ApplyTitlecase |  | a text that starts with a space keeps its first letter unchanged, because the space is the first character
Capitalized | Returns the text with only its first character in upper case and the rest in lower case, leaving the formatter unchanged. | a text; an empty text for an empty one |  | ApplyCapitalcase, Titlecased |  | hello WORLD gives Hello world, where Titlecased gives Hello World; CapitalizedQ returns a new formatter over the result
ApplyTitlecase | Capitalizes the first letter of every word of the held text, in place. | nothing; the text changes. ApplyTitlecaseQ returns the formatter for chaining |  | Titlecased, ApplyCapitalcase
Titlecased | Returns the text with each word capitalized and leaves the formatter unchanged. | a text |  | ApplyTitlecase, Capitalized |  | TitlecasedQ returns a new formatter over the result
ApplyCaseFold | Replaces the held text by its caseless form, in place, ready to be compared. | nothing; the text changes |  | CaseFolded, ApplyLowercase |  | case folding is stronger than lower casing: a German sharp s becomes ss
CaseFolded | Returns the caseless form of the text, for comparing two texts without regard to case. | a text |  | ApplyCaseFold, Lowercased |  | the plain lower case of a German sharp s is itself, its case fold is ss
ApplyReverse | Reverses the order of the characters of the held text, in place. | nothing; the text changes. ApplyReverseQ returns the formatter for chaining |  | Reversed
Reversed | Returns the characters in reverse order and leaves the formatter unchanged. | a text |  | ApplyReverse |  | characters are reversed, not bytes, so Hebrew, Arabic and emoji stay whole; ReversedQ returns a new formatter over the result
LeftAlign | Pads the held text on its right with spaces up to a width, so the text sits on the left, in place. | nothing; the text changes. LeftAlignQ returns the formatter for chaining | nWidth=the width to reach, in characters, a text already that long is left as it is | LeftAligned, RightAlign, PadRight
LeftAligned | Returns the text padded on its right with spaces up to a width, leaving the formatter unchanged. | a text | nWidth=the width to reach, in characters, a text already that long is returned as it is | LeftAlign, RightAligned
RightAlign | Pads the held text on its left with spaces up to a width, so the text sits on the right, in place. | nothing; the text changes. RightAlignQ returns the formatter for chaining | nWidth=the width to reach, in characters, a text already that long is left as it is | RightAligned, LeftAlign, PadLeft
RightAligned | Returns the text padded on its left with spaces up to a width, leaving the formatter unchanged. | a text | nWidth=the width to reach, in characters, a text already that long is returned as it is | RightAlign, LeftAligned
CenterAlign | Pads the held text on both sides with spaces up to a width, in place; an odd remainder puts the extra space on the right. | nothing; the text changes. CenterAlignQ returns the formatter for chaining | nWidth=the width to reach, in characters, a text already that long is left as it is | CenterAligned, LeftAlign
CenterAligned | Returns the text padded on both sides with spaces up to a width; an odd remainder puts the extra space on the right. | a text | nWidth=the width to reach, in characters, a text already that long is returned as it is | CenterAlign, RightAligned
PadLeft | Pads the held text on its left with a chosen character up to a width, in place. | nothing; the text changes. PadLeftQ returns the formatter for chaining | nWidth=the width to reach, in characters; cChar=the padding character, exactly one character, otherwise an error is raised | PaddedLeft, PadRight, RightAlign |  | the same as RightAlign with a fill character instead of a space
PaddedLeft | Returns the text padded on its left with spaces up to a width, and does not use the padding character. | a text | nWidth=the width to reach, in characters; cChar=accepted but not used | PadLeft, RightAligned | the padding character is ignored: PaddedLeft(6, "-") on abc answers three spaces then abc, where PadLeft(6, "-") gives ---abc; the body returns RightAligned(nWidth) | use PadLeft for a chosen character, or RightAligned for spaces
PadRight | Pads the held text on its right with a chosen character up to a width, in place. | nothing; the text changes. PadRightQ returns the formatter for chaining | nWidth=the width to reach, in characters; cChar=the padding character, exactly one character, otherwise an error is raised | PaddedRight, PadLeft, LeftAlign |  | the same as LeftAlign with a fill character instead of a space
PaddedRight | Returns the text padded on its right with spaces up to a width, and does not use the padding character. | a text | nWidth=the width to reach, in characters; cChar=accepted but not used | PadRight, LeftAligned | the padding character is ignored: PaddedRight(6, "-") on abc answers abc then three spaces, where PadRight(6, "-") gives abc---; the body returns LeftAligned(nWidth) | use PadRight for a chosen character, or LeftAligned for spaces
Simplify | Collapses every run of white space in the held text to one space and drops it at both ends, in place. | nothing; the text changes. SimplifyQ returns the formatter for chaining |  | Simplified, Trim
Simplified | Returns the text with each run of white space collapsed to one space and none at its ends, leaving the formatter unchanged. | a text |  | Simplify, Trimmed |  | SimplifiedQ returns a new formatter over the result; tabs and new lines count as white space
Trim | Removes the white space at both ends of the held text, in place. | nothing; the text changes. TrimQ returns the formatter for chaining |  | Trimmed, TrimLeft, TrimRight, Simplify |  | inside the text nothing is touched
Trimmed | Returns the text without the white space at its two ends, leaving the formatter unchanged. | a text |  | Trim, Simplified |  | tabs and new lines are white space too
TrimLeft | Removes the white space at the start of the held text, in place. | nothing; the text changes. TrimLeftQ returns the formatter for chaining |  | TrimmedLeft, TrimRight
TrimmedLeft | Returns the text without the white space at its start, leaving the formatter unchanged. | a text |  | TrimLeft, TrimmedRight
TrimRight | Removes the white space at the end of the held text, in place. | nothing; the text changes. TrimRightQ returns the formatter for chaining |  | TrimmedRight, TrimLeft
TrimmedRight | Returns the text without the white space at its end, leaving the formatter unchanged. | a text |  | TrimRight, TrimmedLeft
RepeatNTimes | Replaces the held text by itself written n times in a row, in place; 0 gives an empty text. | nothing; the text changes. RepeatNTimesQ returns the formatter for chaining | n=how many times to write the text | RepeatedNTimes |  | no separator is inserted between the copies
RepeatedNTimes | Returns the text written n times in a row, leaving the formatter unchanged. | a text | n=how many times to write the text | RepeatNTimes |  | no separator is inserted between the copies
