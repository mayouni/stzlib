Parameter must be a string or stzString object."; the getter only reads, so a stzString passed in is never emptied |
Content | Returns the text the getter holds. | a text | | NumberOfChars | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | BytesPerChar | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
NthChar | Returns the character at a position, counted from 1, as a one-character text. | a one-character text | _n_=the position, from 1 | FirstChar, LastChar | position 0 answers the first character and a position past the end answers an empty text, with no error; CharAt and CharAtPosition are the same method | "e" is the 2nd of "hello World"
FirstChar | Returns the first character of the text. | a one-character text; "" for an empty text | | LastChar, NthChar | |
LastChar | Returns the last character of the text. | a one-character text; "" for an empty text | | FirstChar | | "ם" is one character
MiddleChar | Returns the character in the middle of the text, the left one when the length is even. | a one-character text; "" for an empty text | | NthChar | | "hello World" gives a space, "ab" gives a, "a😀ب" gives 😀
NFirstChars | Returns the first n characters of the text as a text. | a text | _n_=how many characters to take, from 1 to the length | NLastChars, NLeftChars | n of 0, below 0 or above the length raises "Indexes out of range!", and so does an empty text; NFirstCharsQ answers a stzString | the Hebrew "שלום עולם" gives "שלו" for 3
NLastChars | Returns the last n characters of the text as a text. | a text | _n_=how many characters to take, from 1 to the length | NFirstChars, NRightChars | n of 0, below 0 or above the length raises "Indexes out of range!"; NLastCharsQ answers a stzString |
NLeftChars | Returns the n characters at the left end of the text: the first ones for a left-to-right text, the last ones for a right-to-left text. | a text | _n_=how many characters to take, from 1 to the length | NRightChars, NFirstChars | Never takes the right-to-left branch today: the direction test answers TRUE for Hebrew and Arabic, so NLeftChars(3) of "مرحبا بالعالم" gives its first three letters, the same as NFirstChars | NLeftCharsAsString is the same method
NRightChars | Returns the n characters at the right end of the text: the last ones for a left-to-right text, the first ones for a right-to-left text. | a text | _n_=how many characters to take, from 1 to the length | NLeftChars, NLastChars | Same as NLeftChars: Hebrew and Arabic are treated as left-to-right, so it gives their last letters | NRightCharsAsString is the same method
Chars | Returns the characters of the text as a list of one-character texts. | a list of texts | | UniqueChars, BytesPerChar | | "a😀ب" gives three items, the emoji and the Arabic letter each one
UniqueChars | Returns the different characters of the text, each once, in the order of their first appearance, comparing case-sensitively. | a list of texts | | Chars | | UniqueCharsCS(0) folds case: "aAbB" gives a and b
Section | Returns the characters from one position to another, both included, as a text. | a text | n1=the first position, from 1; n2=the last position, from 1 | Range, NFirstChars | | "ell" for 2 to 4 of "hello World"; it is the stzString method
Range | Returns a run of characters given by its start and its length, as a text. | a text | nStart=the first position, from 1; nRange=how many characters | Section | | "ello" for 2 and 4 of "hello World"
CharNgrams | Returns every run of n consecutive characters of the text, as a list of texts. | a list of texts; [ ] for an empty text or an n above the length | _n_=the size of each run, in characters | WordNgrams, Chars | A text that contains a pipe character is cut wrongly, because the engine answer is split on that character: "a" + pipe + "b" with n = 1 answers a, two empty texts, b | "hello" with 2 gives he, el, ll, lo
WordNgrams | Returns every run of n consecutive words of the text, as a list of texts. | a list of texts; [ ] when n is above the number of words | _n_=how many words in each run | CharNgrams | | "the quick brown fox" with 2 gives "the quick", "quick brown", "brown fox"
BytesPerChar | Returns how many bytes each character takes in UTF-8, as one text of numbers separated by spaces. | a text such as "1 4 2", not a list | | Chars, NumberOfChars | | "a😀ب" gives "1 4 2"; "שלום עולם" gives "2 2 2 2 1 2 2 2 2"; an empty text gives ""
