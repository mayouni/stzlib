# w13 stzNumBuffer -- Name | brief | returns | params | see | warning | note
init | Builds a buffer of numbers held inside the engine, from a list of numbers or from a size. | nothing; the object is built | pInput=a list of numbers, copied into the engine, or a number n for a buffer of n zeros; anything else raises an error | Free, ToList, Sum | the engine memory is held until Free is called: Ring has no destructors | stzListOfNumbers.ToStzNumBuffer brings a list in; StzNumBufferQ, StzNumBufferOfSizeQ and StzNumBufferRangeQ build one; the values are f64
Handle | Returns the engine handle of the buffer, a number. | a number | | Free, IsFreed | | other buffers read it for AddBuffer, SubtractBuffer, MultiplyBuffer and Dot
Free | Releases the engine memory of the buffer. | nothing | | IsFreed, Resize | | call it when done with a large buffer; calling it twice is harmless; do not read the buffer afterwards
IsFreed | TRUE if the buffer has been freed. | TRUE or FALSE, as 1 or 0 | | Free, Handle |
Resize | Replaces the buffer by a new one of the given size filled with zeros, losing the numbers it held. | the buffer itself, so calls chain | pnSize=the new number of items | Free, FillWith | a negative size ends the Ring process: it panics inside stz_stats.dll with exit code 3 | the old memory is freed first
NumberOfItems | Returns how many numbers the buffer holds. | a number | | IsEmpty, Item | | Size and Count are the same call
IsEmpty | TRUE if the buffer holds no number. | TRUE or FALSE, as 1 or 0 | | NumberOfItems
Item | Returns the number at a position, counted from 1. | a number | n=the 1-based position | ToList, SetItem | a position of 0 or past the end answers 0 without any error, as a stored zero would; a negative position ends the Ring process (panic in stz_stats.dll, exit code 3) | NthItem is the same call
ToList | Returns all the numbers as a Ring list, one crossing. | a list of numbers | | ToStzList, ToStzListOfNumbers, Item | | Content is the same call; the buffer is unchanged and not freed
ToStzListOfNumbers | Returns the numbers as a stzListOfNumbers, to reach its list methods. | a stzListOfNumbers | | ToStzList, ToList | | the buffer stays yours and is not freed; ToListOfNumbers is the same call
ToStzList | Returns the numbers as a stzList. | a stzList | | ToStzListOfNumbers, ToList | | the buffer stays yours and is not freed
Copy | Returns an independent buffer holding the same numbers. | a new stzNumBuffer | | Resize, ToList | | changing the copy leaves the original alone: 99 in the copy, 2 still in the original
SetItem | Writes a number at a position, in place. | the buffer itself, so calls chain | n=the 1-based position; v=the number to write | Item, FillWith | a position of 0 or past the end changes nothing and raises no error; a negative position ends the Ring process | [ 2, 4, 6, 8 ] with 40 at 2 gives [ 2, 40, 6, 8 ]
FillWith | Sets every item to one number, in place. | the buffer itself, so calls chain | v=the number to write everywhere | RangeFrom, Resize | | FillWithQ is the same call
RangeFrom | Writes an arithmetic sequence over the buffer, in place. | the buffer itself, so calls chain | pnStart=the first number; pnStep=the difference between neighbours | FillWith, AddScalar | | 3 items from 10 with step 5 give 10, 15, 20; RangeFromQ is the same call
AddScalar | Adds one number to every item, in place. | the buffer itself, so calls chain | v=the number to add | Scale, AddBuffer | | 10, 15, 20 plus 1 give 11, 16, 21; AddScalarQ is the same call
Scale | Multiplies every item by one number, in place. | the buffer itself, so calls chain | v=the factor | AddScalar, MultiplyBuffer | | 11, 16, 21 times 2 give 22, 32, 42; ScaleQ is the same call
AddBuffer | Adds another buffer to this one item by item, in place. | the buffer itself, so calls chain | poOther=the other stzNumBuffer, of the same length | SubtractBuffer, MultiplyBuffer, Dot | a buffer of another length raises stzNumBuffer: the two buffers must have the same length, and nothing is changed | 1, 2, 3 plus 10, 20, 30 give 11, 22, 33; AddBufferQ is the same call
SubtractBuffer | Subtracts another buffer from this one item by item, in place. | the buffer itself, so calls chain | poOther=the other stzNumBuffer, of the same length | AddBuffer, MultiplyBuffer | a buffer of another length raises stzNumBuffer: the two buffers must have the same length | 11, 22, 33 minus 10, 20, 30 give 1, 2, 3; SubtractBufferQ is the same call
MultiplyBuffer | Multiplies this buffer by another item by item, in place. | the buffer itself, so calls chain | poOther=the other stzNumBuffer, of the same length | AddBuffer, Dot | a buffer of another length raises stzNumBuffer: the two buffers must have the same length | 1, 2, 3 times 10, 20, 30 give 10, 40, 90; MultiplyBufferQ is the same call
Sum | Returns the sum of all the numbers, with compensation for lost low digits. | a number; 0 for an empty buffer | | Mean, Dot | | 1e16 plus four 1s gives 10000000000000004 where a naive total stays at 1e16
Mean | Returns the arithmetic mean of the numbers. | a number; 0 for an empty buffer | | Sum, VariancePopulation | | 1, 2, 3, 4 give 2.5; Average is the same call
Min | Returns the smallest number. | a number; 0 for an empty buffer | | Max | an empty buffer answers 0, which cannot be told from a real zero
Max | Returns the largest number. | a number; 0 for an empty buffer | | Min | an empty buffer answers 0, which cannot be told from a real zero
Dot | Returns the dot product with another buffer, the sum of the products item by item. | a number | poOther=the other stzNumBuffer, of the same length | MultiplyBuffer, Sum | a buffer of another length answers 0 without any error, where AddBuffer raises | 10, 40, 90 with 10, 20, 30 gives 100 + 800 + 2700 = 3600; DotProduct is the same call
VarianceSample | Returns the sample variance, dividing by n minus 1. | a number | | VariancePopulation, StddevSample, Mean | a buffer of one item or none answers 0 instead of undefined | 2, 4, 4, 4, 5, 5, 7, 9 give 4.571; Variance is the same call
VariancePopulation | Returns the population variance, dividing by n. | a number | | VarianceSample, StddevPopulation | | 2, 4, 4, 4, 5, 5, 7, 9 give 4
StddevSample | Returns the sample standard deviation, the square root of VarianceSample. | a number | | StddevPopulation, VarianceSample | a buffer of one item or none answers 0 | 2, 4, 4, 4, 5, 5, 7, 9 give 2.138; Stddev and StandardDeviation are the same call
StddevPopulation | Returns the population standard deviation, the square root of VariancePopulation. | a number | | StddevSample, VariancePopulation | | 2, 4, 4, 4, 5, 5, 7, 9 give 2
Show | Prints one line saying how many numbers the buffer holds. | nothing; it prints | | NumberOfItems, ToList | | it prints stzNumBuffer(8 numbers, engine-resident) and shows no number
