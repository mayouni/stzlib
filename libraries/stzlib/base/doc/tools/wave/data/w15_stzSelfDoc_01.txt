init | Reads a class's methods and doc blocks from its source, including the ones it inherits, so it can answer questions about them. | nothing; the object is built | pcTarget=a class name, or the path of a .ring file for the class it names | ClassName, Ask | anything that is not a text raises an error; an unknown class name builds an object with no methods | a path harvests only that file's class, with no inherited methods
ClassName | Returns the class the object describes. | a text | | Source
Source | Returns the path of the source file the class was found in. | a text; empty when the class is unknown | | ClassName
NumberOfMethods | Returns how many methods were harvested, own and inherited. | a number | | MethodNames, NumberOfInheritedMethods
MethodNames | Returns the names of the harvested methods, in source order. | a list of text | | HasMethod, NumberOfMethods
HasMethod | TRUE if the class has a method of that name, own or inherited; case is ignored. | TRUE or FALSE | pcName=the method name | MethodNames, DescriptionOf
DescriptionOf | Returns the brief written above a method. | a text; empty for an unknown method or an undocumented one | pcName=the method name, in any case | ExplainMethod, RecordOf
DefiningClassOf | Returns the class that defines a method: this class or an ancestor it inherits from. | a text; empty for an unknown method | pcName=the method name | NumberOfInheritedMethods, DescriptionOf
NumberOfInheritedMethods | Returns how many harvested methods are defined by an ancestor and not by the class itself. | a number | | DefiningClassOf, NumberOfMethods
ExplainMethod | Explains a method in plain words: its brief, parameter roles, return, notes, see-also, example and the form its name implies. | a multi-line text; a sentence saying the method is absent for an unknown name | pcName=the method name | RecordOf, DescriptionOf | | everything is read from what the author wrote and from the tests; nothing is invented or generated
RecordOf | Returns what the author wrote in a method's doc block, field by field. | a hash list [ :name, :brief, :params, :fields, :returns, :notes, :see, :example, :since, :status ]; an empty list for an unknown method | pcName=the method name | ExplainMethod, DescriptionOf | | the record is read from the class's own source, so an inherited method answers from its owner's
Show | Prints one line with the class name and the number of methods. | the object itself | | NumberOfMethods
Ask | Returns the three methods whose meaning best matches a plain-English question, best first. | a list of [ name, score, description ] rows; empty when nothing shares a word with the question | pcQuestion=the question in plain English | AskFor, BestMethodFor | | the word match runs first and a loaded embedding or reranker model rescues questions that share no word, so a model can help and never hurt
AskFor | Returns the methods whose meaning best matches a question, up to a number asked for, best first. | a list of [ name, score, description ] rows | pcQuestion=the question in plain English; n=how many methods to return, 3 when below 1 | Ask, BestMethodFor | | a question about an entity of the world, such as what is X, puts a (world) row first
BestMethodFor | Returns the name of the single method that best matches a question. | a text; empty when nothing matches | pcQuestion=the question in plain English | Ask, HowTo | | it can pick a method whose words overlap the question rather than the one meant, such as init for a question about a precondition
HowTo | Turns a plain-English intent into a call template on this class, by grammar when the class has the method and by meaning otherwise. | a text such as Q(...).Forget("...", "...", "...") followed by how it was resolved | pcIntent=what is wanted, in plain English | MethodForIntent, Ask | | when nothing matches it says that no method in the class does
MethodForIntent | Returns the name of the method that an intent resolves to, by grammar first and then by retrieval. | a text; empty when nothing matches | pcIntent=what is wanted, in plain English | HowTo, BestMethodFor
