init | Builds a responder that cuts an actor's capability paths in a security graph, holding the graph by reference. | nothing; the responder is built | poSecurityGraph=the stzSecurityGraph whose paths are cut; it is held by reference, not copied | AddLiveActor, RevokeCapability
AddLiveActor | Registers a live actor whose effectful kind is revoked together with the graph paths, when the plan names it. | the responder itself, so calls chain | poActor=the live actor, passed as an argument one at a time, because an object inside a list literal is copied and revoking a copy changes nothing | RevokeCapability, Owns
Owns | TRUE if the verb is :RevokeCapability, the only one this responder answers. | TRUE or FALSE | pcVerb=the verb, matched without regard to case | RevokeCapability
RevokeCapability | Cuts the actor paths to effectful in the graph and revokes that kind from each registered live actor of the same name. | nothing; LastCut lists the edges removed | pcTarget=the actor name, matched without regard to case | LastCut, AddLiveActor | an actor with no path to effectful changes nothing and leaves LastCut empty | other actors that use the same tool keep their capability
LastCut | Returns the graph edges the last revocation removed. | a list of [ from, label, to ] rows; an empty list before any revocation | | RevokeCapability
