init | Builds an ordinal from a whole number, spelled in the language the library is set to when the object is made. | nothing; the object is built | _n_=the number to turn into an ordinal | SetLanguage, Ordinal | the language is read from the global $aOrdinalConfig at birth, so a later SetOrdinalLanguage does not reach an object already built | 
SetLanguage | Switches this ordinal to English ("en"), French ("fr") or Arabic ("ar"), and ignores any other code. | nothing; an unknown code leaves the language as it was | lang=the language code, one of "en", "fr" or "ar" | Language, ToString | an unknown code such as "xx" is silent: no error and no change | 
Language | Returns the language code this ordinal speaks. | a text: "en", "fr" or "ar" | | SetLanguage | 
ToString | Returns the ordinal as text in the language set on this object, such as 3rd, 3e or the Arabic word for third. | a text | | Value, SetLanguage, Ordinal | | English reads 11, 12 and 13 as th; French gives 1er and then e up to 9 and ème from 10; Arabic spells 1 to 5 as words and writes ال before any larger number; 0 and negatives get the th suffix in English and the ème suffix in French 
Value | Returns the number this ordinal was built from, unchanged. | a number | | Number, ToString | | 
Number | Returns the plain number behind the ordinal, the same answer as Value. | a number | | Value | | 
ToEnglish | Builds the English spelling of the number from the suffix table of the language, such as 21st or 12th. | a text | _aConfig_=the English entry of $aOrdinalConfig: its :suffixes and :special_cases | ToString | private: ToString calls it, and a call from outside raises error R26 | 
ToFrench | Builds the French spelling of the number from the suffix table of the language, such as 1er, 2e or 12ème. | a text | _aConfig_=the French entry of $aOrdinalConfig: its :suffixes | ToString | private: ToString calls it, and a call from outside raises error R26; the feminine form is never produced | 
ToArabic | Builds the Arabic spelling of the number: the ordinal word for 1 to 5, and ال followed by the digits for any other. | a text | _aConfig_=the Arabic entry of $aOrdinalConfig: its :suffixes list of ordinal words | ToString | private: ToString calls it, and a call from outside raises error R26 |
