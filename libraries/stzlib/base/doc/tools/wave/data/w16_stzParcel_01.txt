init | Builds a parcel of a payload type around a value, with a content key and no provenance yet. | nothing; the object is built | pcType=the payload type of the value, such as text or label; pValue=the value the parcel carries | StzParcelQ, StzRefusalParcelQ | nothing judges the value here: the courts judge it when a faculty makes the parcel, and a parcel built by hand has certainty unknown, no probability and an empty chain | the key is a SHA-256 of the type and the value, so two parcels of the same type and value share it until a run seals it over the chain
Type | Returns the payload type of the parcel, or refusal when it is a refusal. | a text such as label, number or refusal | | Value, IsRefusal | |
Value | Returns the payload the parcel carries. | the value, whatever its type; for a refusal, the list of findings | | Type, Findings | | a parcel has no setter, so the value cannot change after it is built
IsRefusal | TRUE if the parcel is a refusal: the court rejected the answer, or a stage or the registry could not answer. | TRUE or FALSE | | Findings, CiteFindings, Why | | a refusal is a parcel too, so a flow can carry it without raising
Findings | Returns the findings a refusal carries, in the house shape. | a list of findings, each [ rule, subject, where, severity, message ]; [ ] for a parcel that is not a refusal | | CiteFindings, IsRefusal | |
Certainty | Returns the evidential word the producer stated for the answer. | a text: unknown unless the implementation stated certain, probable or apparent | | P, Why | | the word is whatever the implementation declared and the class never invents one; it is not judged by a person, and a floor says unknown unless it states more
P | Returns the probability the producer stated for the answer, or -1 when it stated none. | a number from 0 to 1, or -1 | | Certainty, Cost | | it is the producer's own figure, kept as given; calibration is checked separately against the goldens, not by a person
Provenance | Returns one row for every step that made the parcel, oldest first. | a list of rows, each a list of [ key, value ] pairs: faculty, implementation, version, kind, detail; [ ] for a parcel built by hand | | Chain, Why | | the detail of a floor that answered after a model failed says it fell back and why
Chain | Returns the steps that made the parcel as faculty:implementation texts, oldest first. | a list of text such as clean:smart-clean | | Provenance, Why | | a parcel from the last stage of a flow lists every stage before it
Cost | Returns what producing the answer cost. | a list of [ key, value ] pairs: ms, tokens_in and tokens_out | | Provenance, P | the milliseconds are read from Ring's clock around the call, so a fast stand-in function reads 0 | the token counts are whatever the implementation stated, and 0 when it stated none
Key | Returns the content key of the parcel: a SHA-256 in hexadecimal. | a text of 64 characters | | Content, Chain | | once sealed by a run the key covers the type, the value and the chain, so the same value made by two implementations has two keys
Trace | Returns the flow and stage that produced the parcel, set only by a flow run. | a text such as tidy-sort-loud:sort; an empty text outside a flow | | Chain, Key | |
Why | Returns one sentence per step that made the parcel, with the certainty at the end; for a refusal, the findings. | a text such as conf -> m1 (model) [stand-in], ending with the certainty; for a refusal, REFUSED: followed by CiteFindings |  | CiteFindings, Provenance, Certainty |  | the certainty shown is the one the producer stated, not a judgment of quality
CiteFindings | Returns the findings written as one line each part, rule then place then message. | a text such as my-rule at stage x: something failed, parts joined by a slash; an empty text when there are none | | Findings, Why | |
Content | Returns a summary of what identifies the parcel, without its value. | a list of [ key, value ] pairs: type, refusal, certainty, chain and key | | Key, Chain, Type | |
