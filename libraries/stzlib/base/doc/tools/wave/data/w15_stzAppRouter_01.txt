AddRoute | Registers a handler for a method and a path pattern; the method is stored in upper case. | nothing | cMethod=the HTTP method in any case; cPath=the path or pattern, such as /user/:id or /static/*; fHandler=the handler to return on a match, a function or any value | Routes, MatchRoute, HasRoute
Routes | Returns every registered route as [ method, pattern, handler ], in registration order. | a list of three-item lists | | AddRoute, MatchRoute
HasRoute | TRUE if a route with exactly that method and exactly that path text was registered; a pattern is not matched, only compared. | 1 or 0, numbers | cMethod=the HTTP method in any case; cPath=the path text, compared as written | MatchRoute, GetHandler
GetHandler | Returns the handler registered for exactly that method and path text, an empty text when there is none; patterns are not matched. | the handler, or an empty text | cMethod=the HTTP method in any case; cPath=the path text, compared as written | MatchRoute, HasRoute
MatchRoute | Returns the route for a request: the exact path first, then :name and trailing * patterns, the first registered winning. | a list [ matched, handler, params ]: matched is 1 or 0, params the list of [ name, value ] pairs, with the key * for a wildcard | cMethod=the HTTP method in any case; cPath=the request path without its query | AddRoute, GetHandler | | the request path is read by its non-empty segments, so a trailing slash does not matter; a wildcard also matches nothing after its prefix and then captures an empty text
AddMiddleware | Stores a middleware function for a path prefix; nothing in the router or the server ever reads the list, so it never runs. | nothing; use AddMiddlewareQ to chain | cPath=the path the middleware should cover; fMiddleware=the function meant to run before the routes | AddStaticRoute | | stored and never applied; see stzAppServer.Use
AddStaticRoute | Stores a URL path and a folder for static files; nothing in the router or the server ever reads the list, so no file is served. | nothing; use AddStaticRouteQ to chain | cPath=the URL path meant to map to the folder; cDirectory=the folder of files | AddMiddleware | | stored and never applied; see stzAppServer.Static
