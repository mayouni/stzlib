init | Builds an empty sound graph, stereo at 48000 Hz, to which nodes are added by name. | nothing; the object is built | | StzSoundGraphQ, Reshape | a library without the sound engine leaves it empty and sets LastError
Reshape | Frees the graph and starts a new empty one with a different channel count and sample rate. | nothing; use ReshapeQ to chain | pnChannels=the number of channels, 1 for mono and 2 for stereo; pnRate=the sample rate in hertz | StzSoundGraphOfQ, Release | only legal before anything is added, since every node and name is forgotten
Release | Frees the engine graph and leaves the object empty. | nothing | | Reshape | afterwards GraphId and NodeCount answer 0
LastError | Returns the reason the last call failed, or the engine's last graph error when the face has recorded none. | a text | | Prepare | once the face has recorded an error it keeps returning that one, and a later success does not clear it
NodeCount | Returns how many nodes the graph holds. | a number | | AddOscillator, GraphId | 0 for a released graph
GraphId | Returns the engine's id of the graph, to hand to a transport or a stream. | a number; 0 for a released graph | | Release
SampleRate | Returns the sample rate of the graph, in hertz. | a number, 48000 until Reshape changes it | | Channels, Reshape
Channels | Returns the number of channels of the graph. | a number, 2 until Reshape changes it | | SampleRate, Reshape
OutputNode | Returns the index of the node the graph hands to the world. | a number; 0 when nothing has been added | | SetOutputTo, AddMasterGain | a node added after the graph was prepared can reset this to 0, see the defects file
AddMasterGain | Adds a gain node after the current output and makes it the output, so a pause can fade everything with one ramp. | the index of the new node; 0 when the graph has no output yet or is already prepared | | OutputNode, stzSoundTransport | the node is named master; a transport adds it by itself when built, before the graph is prepared | a refusal sets LastError
NameIt | Labels the last node added so that later calls can refer to it by name. | nothing; use NameItQ to chain | pcName=the label, kept in lower case | NodeNamed, HasNode | with nothing added it sets LastError and labels nothing
NodeNamed | Resolves a label or a raw node number to a node index. | a number; 0 and a LastError for an unknown label; a number is returned as it is, existing or not | pName=the label given to NameIt, matched without regard to case, or a node number | NameIt, HasNode
HasNode | TRUE if a label resolves to a node. | TRUE or FALSE | pName=the label to look for, or a node number | NodeNamed | a number is always TRUE, whether or not that node exists; an unknown label also sets LastError
AddOscillator | Adds a tone generator as a source and makes it the last node and the output. | nothing; use AddOscillatorQ to chain | pWave=the waveform: Sine, Triangle, Square or Saw; pnHz=the frequency in hertz; pnAmplitude=the peak level, 1 being full scale | NameIt, AddEnvelopeOn | an unknown waveform name sets LastError but still adds a sine | after the graph is prepared nothing is added, LastError says so, and the output index becomes 0
AddSound | Adds an existing sound as a source that plays once, and makes it the last node and the output. | nothing; use AddSoundQ to chain | poSound=a stzSound, or an engine buffer id | AddLoopingSound, NameIt | a refusal sets LastError
AddLoopingSound | Adds an existing sound as a source that repeats for as long as the graph is rendered. | nothing; use AddLoopingSoundQ to chain | poSound=a stzSound, or an engine buffer id | AddSound | the loop makes a 0.1 s sound fill any length asked of ToSound
AddTimeline | Adds a node whose output is the notes placed on it, each at the frame asked, and makes it the output. | the index of the timeline node; 0 with LastError set when refused | | stzSoundScheduler, stzSoundLive | the node has no input; the scheduler and live loops place notes on it through engine calls
AddGainOn | Adds a gain stage after a node and makes it the output. | nothing; use AddGainOnQ to chain | pName=the label or number of the node to act on; pnGain=the multiplier, 1 leaving the level unchanged | AddPanOn, AddEnvelopeOn | an unknown node sets LastError and adds nothing | it acts on the node the label names, not on the last one added: two calls on the same label branch from it, so label each new node with NameIt to chain them
AddFilterOn | Adds a filter after a node and makes it the output. | nothing; use AddFilterOnQ to chain | pName=the label or number of the node to act on; pKind=the filter type: LowPass, HighPass or BandPass; pnCutoff=the cut-off or centre frequency in hertz; pnQ=the resonance, above 0, 0.7 being a gentle slope | AddGainOn, AddEchoOn | an unknown filter name sets LastError but still adds a low-pass; a cut-off of 0 or at and above half the rate is refused by the engine and adds nothing | a low-pass at 300 Hz brought a 2000 Hz sine down to a peak of 0.01
AddEnvelopeOn | Adds a loudness envelope after a node and makes it the output. | nothing; use AddEnvelopeOnQ to chain | pName=the label or number of the node to act on; pnAttack=the rise time in seconds; pnDecay=the fall time in seconds from the peak to the sustain level; pnSustain=the held level from 0 to 1; pnRelease=the final fall time in seconds; pnHold=the time in seconds, counted from the start, at which the release begins; 0 or less holds for ever | AddEnvelopeOnAt, AddEchoOn | an unknown node sets LastError and adds nothing; a sustain above 1 or a negative time is refused by the engine and adds nothing | measured: with attack 0.1, decay 0.2, sustain 0.5, release 0.2 and hold 0.5 the level is 0.5 from 0.3 s to 0.5 s and silent after 0.7 s
AddEnvelopeOnAt | Adds a loudness envelope that starts a number of seconds into the sound, so a voice knows when it sounds. | nothing; use AddEnvelopeOnAtQ to chain | pName=the label or number of the node to act on; pnAttack=the rise time in seconds; pnDecay=the fall time in seconds from the peak to the sustain level; pnSustain=the held level from 0 to 1; pnRelease=the final fall time in seconds; pnHold=the time in seconds, counted from the start, at which the release begins; 0 or less holds for ever; pnStart=the time in seconds at which the envelope begins | AddEnvelopeOn | an unknown node sets LastError and adds nothing
AddEchoOn | Adds a single feedback delay after a node and makes it the output. | nothing; use AddEchoOnQ to chain | pName=the label or number of the node to act on; pnSeconds=the delay time in seconds; pnFeedback=the share of each echo fed back into the line, from 0 to below 1; pnWet=the share of the echoes in the output, 0 for none and 1 for echoes only, the dry sound being scaled by 1 minus pnWet | AddFilterOn, AddGainOn | a feedback of 1 or more, a delay over 60 s or a delay of 0 is refused by the engine and adds nothing; named an echo and not a reverb because one fading repeat is not a room
AddPanOn | Adds a stereo pan after a node and makes it the output. | nothing; use AddPanOnQ to chain | pName=the label or number of the node to act on; pnPan=the position from 0 for left to 1 for right, 0.5 being the centre; a value outside that is clamped | AddGainOn | an unknown node sets LastError and adds nothing | the pan is not -1 to 1: -0.5 plays left only and 2 plays right only
AddMixOf | Adds a mixer that sums several named nodes and makes it the output. | nothing; use AddMixOfQ to chain | paNames=the labels or numbers of the nodes to mix | SetOutputTo, NameIt | a name that is not a node is skipped and named in LastError, and the mixer is still added with the others
SetOutputTo | Chooses which node the graph hands to the world, instead of the last one added. | nothing; use SetOutputToQ to chain | pName=the label or number of the node to use as output | OutputNode | an unknown label changes nothing and sets LastError
Prepare | Freezes the graph with the chosen output so it can be rendered. | 1 if the graph is ready, 0 if not; an empty graph answers 0 and LastError says it has no nodes | | ToSound, ToFile | once prepared no node can be added, whatever the call; ToSound, ToFile and PlayFor call it themselves
ToSound | Renders a number of seconds of the graph into memory as a sound. | a stzSound at the graph's rate and channel count; an empty text with LastError set when the graph cannot be prepared | pnSeconds=how many seconds to render | ToFile, Rewind | no audio device is opened; rendering again carries on from where the last render stopped, so a spent envelope stays silent, unless Rewind is called first; the sound has not been heard by a person
ToFile | Renders a number of seconds of the graph into a 16-bit WAV file. | nothing; use ToFileQ to chain | pcPath=the file to write, overwritten; pnSeconds=how many seconds to render | ToSound | the rate and channel count are stored in the file; a failure sets LastError
Rewind | Takes every stateful node back to its start so the next render begins from the top. | nothing; use RewindQ to chain | | ToSound | a prepared graph stays prepared
PlayFor | Plays the graph on the audio device for a number of seconds, then closes the device. | nothing; use PlayForQ to chain | pnSeconds=how long to play | ToFile, Underruns | not run in this reference: it opens an audio device; with no device it sets LastError and returns | it blocks the calling thread for the whole time
Underruns | Returns how many frames the last PlayFor could not supply. | a number; 0 is the answer to want, and 0 before any PlayFor | | PlayFor
