Paths | Returns the path of every item in the nested list, parents before their children, as lists of 1-based positions. | a list of paths; [ ] for an empty list | | AllPaths, PathsAtDepth, ItemAtPath | | a sublist is itself an item, so [2] and [2,1] are both listed
DeepFind | Returns the paths of every item equal to the given one, at any depth. | a list of paths; [ ] when the item is absent | pItem=the item to look for, a text, a number or a list | DeepContains, DeepFindAt, ItemAtPath | | the comparison is case-sensitive: "X" does not find "x"; a sublist is found as a whole, as an item of its parent
DeepContains | TRUE if the item occurs anywhere in the nested list, at any depth. | TRUE or FALSE | pItem=the item to look for | DeepFind | |
DeepFindAt | Returns the path back if the item at that path equals the given item, and [ ] when it does not or when the path does not exist. | the path when the item is there, else [ ] | pItem=the item expected at the path; paPath=the path to test, as 1-based positions | DeepFind, ItemAtPath | |
ItemAtPath | Returns the item found by following a path of 1-based positions down the nested list. | the item; a list when the path ends on a sublist | paPath=the path, such as [2,3,1] for the 1st item of the 3rd item of the 2nd item | ItemsAtPaths, DeepFindAt, Paths | an unreachable path (a position past the end, 0, or a step below a plain item) raises "Invalid path! it goes deeper than the structure."; a path that is not a list raises "Incorrect param!" |
ItemsAtPaths | Returns the items at several paths at once, in the order of the paths, leaving out the paths that lead nowhere. | a list of items | paPaths=a list of paths, each a list of 1-based positions | ItemAtPath | | unlike ItemAtPath it never raises: a bad path is skipped silently, so the answer can be shorter than the list of paths
LongestPaths | Returns the paths that go deepest into the nested list, all of the same length. | a list of paths; [ ] for an empty list | | PathsAtDepth, Paths | |
PathsAtDepth | Returns the paths of exactly the given depth, a path of one position being depth 1. | a list of paths; [ ] when the depth is 0 or deeper than the list | nDepth=the number of positions in the paths wanted | Paths, LongestPaths | |
ExpandPath | Returns the given path followed by the paths of everything beneath it, as a list of paths. | a list of paths; just the given path when it is a plain item | paPath=the path of the item to open up | CollapsePath, Paths | | a path that does not exist answers itself unchecked, as the only path of the list
CollapsePath | Returns the one-position path of the top-level item that contains the given path. | a list holding the first position; [ ] for an empty path | paPath=a path of any depth | ExpandPath | |
