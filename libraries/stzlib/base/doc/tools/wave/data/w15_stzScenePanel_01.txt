# w15 stzScenePanel
init | Prepares a panel to hang as a quad in a 3D scene, copying the scene's camera and viewport for the click mapping. | nothing; the object is built and nothing is mounted yet | poPanel=the stzPanel to show; poScene=the stzScene it hangs in; pnSize=the width of the square quad in world units, above 0 | Mount, LooksThrough, UvAtScreen | an argument that is not a panel and a scene raises error stzScenePanel: give an stzPanel and an stzScene; a size that is not a number above 0 raises error stzScenePanel: the quad needs a positive size | StzScenePanelQ builds the same object; the quad lies flat in the x and z plane facing up, centred on the origin
Panel | Returns the panel the quad currently shows. | a stzPanel | | Shows, Scene | |
Scene | Returns the scene the panel hangs in. | a stzScene | | Panel, LooksThrough | | it is a copy taken when the object was made: the camera the click mapping uses is the one CameraInUse reports
Size | Returns the width of the quad in world units. | a number | | init | |
IsMounted | TRUE if the panel has been put on a quad in the scene. | TRUE or FALSE, as 1 or 0 | | Mount, Free | |
Mount | Puts the panel on a quad in the scene, as emitted light that does not dim with the sun. | TRUE once mounted, and again TRUE on a repeat call; FALSE when the machine cannot draw pixels | | Refresh, Shows, IsMounted | | it is idempotent: a second call hangs no second quad; it needs a graphics device but opens no window
Shows | Puts a different panel on the same quad, keeping the quad. | TRUE when the new pixels were uploaded, or when nothing is mounted yet; FALSE when the upload failed. ShowsQ returns the panel object for chaining | poPanel=the stzPanel to show instead | Mount, Refresh | a value that is not a panel raises error stzScenePanel.Shows: give an stzPanel | a panel of another size gets a new texture; use it when a click re-declares the interface and so produces a new panel
Refresh | Draws the panel again and pushes its pixels to the quad's texture. | TRUE when uploaded; FALSE when not mounted or when the device refused | | Mount, Shows | | call it after a click, a focus move or a reload; it needs a graphics device
LooksThrough | Copies the scene's camera and viewport into the panel, so the click mapping follows the camera. | nothing; the camera is stored. LooksThroughQ returns the panel object for chaining | poScene=the stzScene whose camera and size to copy | CameraInUse, ViewportInUse | a value that is not a scene raises error stzScenePanel.LooksThrough: give an stzScene | the camera is copied, not shared: after the scene's camera moves, call it again beside Refresh or the mapping keeps the old lens
CameraInUse | Returns the camera the click mapping is using. | a list of nine numbers: the eye x, y, z, the target x, y, z, the field of view in degrees, the near and the far distance | | LooksThrough, ViewportInUse | |
ViewportInUse | Returns the size of the screen the click mapping is using. | a list [ width, height ] in pixels | | LooksThrough, CameraInUse | |
UvAtScreen | Returns where a screen pixel lands on the quad, as a point of the texture. | a list [ u, v ] each from 0 to 1; [ ] when the ray through the pixel misses the quad, runs parallel to its plane or meets it behind the camera | pnScreenX=the pixel's x, from the left; pnScreenY=the pixel's y, from the top | PanelPointAtScreen, VerifyAgainstProjection | | u grows with x and v with z; looking through the centre of the screen at a camera aimed at the origin gives [ 0.5, 0.5 ]
PanelPointAtScreen | Returns where a screen pixel lands on the panel, in the panel's own pixels. | a list [ x, y ] from the top left of the panel; [ ] when the pixel misses the quad | pnScreenX=the pixel's x, from the left; pnScreenY=the pixel's y, from the top | UvAtScreen, ClickAtScreen | | the texture's bottom-left origin is flipped once into the panel's top-left
PointerMovedToScreen | Moves the panel's pointer to where a screen pixel lands on it, or tells it the pointer left. | TRUE when the pixel is on the quad; FALSE when it missed, and the panel is told the pointer left | pnScreenX=the pixel's x, from the left; pnScreenY=the pixel's y, from the top | ClickAtScreen, PanelPointAtScreen | |
ClickAtScreen | Clicks the panel at the point where a screen pixel lands on it. | TRUE when the pixel is on the quad and the click was delivered; FALSE when it missed | pnScreenX=the pixel's x, from the left; pnScreenY=the pixel's y, from the top | PointerMovedToScreen, PanelPointAtScreen | | the answer separates clicked nothing from clicked the background; a click on a focusable box gives it the focus
VerifyAgainstProjection | Checks the click mapping against the engine's own projection, over a grid of points of the quad, and returns the worst error. | a number: the largest difference in u or v, 0 when the two routes agree, and 999 when a point does not come back at all | pnSteps=the grid is pnSteps by pnSteps points inside the quad | UvAtScreen, LooksThrough | | the two routes share no code; after LooksThrough is fed a different lens it reports an error above 0.01
Free | Releases the quad's texture and marks the panel as not mounted. | nothing; the panel is no longer mounted | | Mount, IsMounted | | freeing twice does nothing the second time
