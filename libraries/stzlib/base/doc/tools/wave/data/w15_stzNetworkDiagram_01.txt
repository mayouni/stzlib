# w15 stzNetworkDiagram
init | Builds an empty network topology that draws top-down with the network notation, under a title. | nothing; the object is built | pcTitle=the title of the diagram | AddDevice, Link | | links are drawn undirected and with orthogonal lines
AddDevice | Declares a device of one of the seven kinds, drawn as the trade draws it with its name beneath. | the diagram itself, so calls chain | pcId=the device's identifier, which must be new in the diagram; pcName=the name drawn with the device; pcKind=cloud, firewall, router, switch, accesspoint, server or host, in any letter case, as a text or a symbol | AddNote, Link, KindOf | an identifier already in the diagram raises error stzNetworkDiagram: ... is already on this network; a kind such as toaster raises error stzNetworkDiagram: ... is not a device kind | AddDeviceXT takes a fourth argument, an IPv4 address; a bad address such as 999.1.1.1 raises error ... is not an IPv4 address
AddNote | Adds a free note to the drawing; it is not a device and is judged by no rule. | the diagram itself, so calls chain | pcId=the note's identifier; pcText=the text of the note | AddDevice | | a note is not in Devices() and needs no link
AddSubnet | Declares a subnet with an address range and draws it as a cluster around its member devices. | the diagram itself, so calls chain | pcId=the subnet's identifier; pcName=the name drawn at the top of the cluster; pcCidr=the range as an address and a prefix, such as 10.0.1.0/24; pacMembers=the identifiers of devices already added, a list of text | DevicesIn, SubnetOf, CidrOf | a range that is not an address and a prefix, such as 10.0.0.0/33, raises error stzNetworkDiagram: ... is not a subnet; a member that is not a device raises error stzNetworkDiagram: ... is not a device of this network | the rule address_in_its_subnet holds each member's address to the range
Link | Wires two devices together with an undirected link. | the diagram itself, so calls chain | pcA=the identifier of one device; pcB=the identifier of the other | NeighboursOf, IsReachable, Devices | an identifier that is not a device, or a device linked to itself, raises error stzNetworkDiagram: ... is not a device of this network, or ... cannot be linked to itself; linking the same pair again in the same order raises a stzGraph error saying parallel edges are refused, but only after the link was already added to Links() and NeighboursOf, so those two then list a link the drawing does not hold | LinkXT takes a third argument, a label drawn on the link, such as trunk; linking the pair in the other order is accepted and draws a second line
Devices | Returns the devices declared so far, each with its id, name, kind and address. | a list of hash lists with the keys id, name, kind and address; the address is an empty text when none was given | | Links, Subnets, KindOf | | the kind is stored in lower case; notes are not in it
Links | Returns the links declared so far, each with its two ends and its label. | a list of hash lists with the keys a, b and label; the label is an empty text when none was given | | Devices, NeighboursOf | | after a refused repeated Link it lists the repeat
Subnets | Returns the subnets declared so far, each with its id, name, range and members. | a list of hash lists with the keys id, name, cidr and members | | Devices, DevicesIn | |
KindOf | Returns the kind of a device. | the kind as text in lower case, such as switch; an empty text for an identifier that is not a device | pcId=the device's identifier | Devices, AddressOf | |
AddressOf | Returns the IPv4 address a device was given. | the address as text; an empty text when none was given or the identifier is not a device | pcId=the device's identifier | KindOf, SubnetOf | |
SubnetOf | Returns the identifier of the subnet a device is a member of. | the subnet's identifier as text; an empty text when it is in none | pcId=the device's identifier | CidrOf, DevicesIn | | the first subnet that lists the device is answered
CidrOf | Returns the address range of a subnet. | the range as text, such as 10.0.1.0/24; an empty text for an identifier that is not a subnet | pcSubnet=the subnet's identifier | SubnetOf, DevicesIn | |
DevicesIn | Returns the identifiers of the devices that belong to a subnet. | a list of text, in the order they were given; [ ] for an identifier that is not a subnet | pcSubnet=the subnet's identifier | SubnetOf, CidrOf | |
NeighboursOf | Returns the devices wired directly to a device, whichever end of the link it is. | a list of identifiers, in the order the links were declared; [ ] when none or when the identifier is not a device | pcId=the device's identifier | HopsBetween, Link | | after a refused repeated Link it lists the same neighbour twice
HopsBetween | Returns the fewest links on a path from one device to another. | a number; 0 for a device and itself, and -1 when no path joins them | pcA=the identifier of the device the path starts from; pcB=the identifier of the device it ends at | IsReachable, NeighboursOf | an identifier that is not a device raises error stzNetworkDiagram: both ends must be devices of this network | the search follows links in both directions
IsReachable | TRUE if some path of links joins one device to another. | TRUE or FALSE, as 1 or 0 | pcA=the identifier of the device the path starts from; pcB=the identifier of the device it ends at | HopsBetween | an identifier that is not a device raises the same error as HopsBetween |
AsRuleGraph | Returns the network projected onto a plain stzGraph that the rules read, with kind, address and subnet as node properties. | a stzGraph with one node per device and note, and one edge per pair of linked devices | | GovernanceFindings, Devices | | a pair linked in both orders makes two edges
GovernanceFindings | Returns every finding of the five network rules, such as a lone device or a duplicated address. | a list of findings, each a hash list with rule, subject, where, severity and message; [ ] when there is none | | GovernanceIsSound, AsRuleGraph | | CheckRules gives the same list; the rules are every_device_is_linked, addresses_are_unique, address_in_its_subnet, switches_form_no_loop and the_edge_is_guarded
GovernanceIsSound | TRUE if the network rules report no finding of severity error. | TRUE or FALSE, as 1 or 0 | | GovernanceFindings | | warnings such as an internet link that goes around the firewall do not make it false; RulesAreSound is the same call
