# w15 stzMaterialGraph
init | Builds an empty material graph with no declared values, no nodes and no output. | nothing; the object is built | | TakesColor, AddNode, Emits | | StzMaterialGraphQ builds the same object; the ops are listed by StzMaterialGraphOps
TakesColor | Declares a colour the material takes from outside, usable as a node input by name. | nothing; the name is added in lower case. TakesColorQ returns the graph for chaining | pcName=the name of the colour, in any letter case | TakesScalar, TakesTexture, AddNode | | the graph must be compiled again afterwards
TakesScalar | Declares a number the material takes from outside, usable as a node input by name. | nothing; the name is added in lower case. TakesScalarQ returns the graph for chaining | pcName=the name of the scalar, in any letter case | TakesColor, TakesTexture, AddNode | |
TakesTexture | Declares a picture the material reads, usable as the first input of a Sample node. | nothing; the name is added in lower case. TakesTextureQ returns the graph for chaining | pcName=the name of the texture, in any letter case | TakesColor, AddNode | |
AddNode | Declares a node, an operation on named inputs, in any order relative to the nodes it reads. | nothing; the node is added in lower case and the graph must be compiled again. AddNodeQ returns the graph for chaining | pcName=the name of the node, unique and not the name of a declared colour, scalar or texture; paSpec=a hash list [ :Op = the operation, :In = a list of inputs ], each input a node name, a declared value, a builtin such as @uv or @normal.y, or a number | Emits, Compile, TakesColor | an empty name raises error stzMaterialGraph.AddNode: a node needs a name; a name already used, or the name of a declared value, raises an error saying the node is declared twice or cannot shadow it; an unknown operation raises error ... is not an op, with the list of the ops; a wrong number of inputs raises error ... takes N input(s) | the ops are Sample, Multiply, Add, Subtract, Mix, Smoothstep, Step, Clamp, Pow, Fract, Abs, Sqrt, Sin, Cos, Dot, OneMinus, Fresnel and Lit; a whole number input is written with .0 in the shader
Emits | Sets which node supplies the final colour of the material. | nothing; the name is stored in lower case. EmitsQ returns the graph for chaining | pcName=the name of the output node | AddNode, OutputNode, Compile | |
NodeCount | Returns how many nodes have been declared. | a number | | OutputNode, AddNode | |
OutputNode | Returns the name of the node declared as the output. | the name as text in lower case; an empty text before Emits | | Emits, NodeCount | |
Compile | Derives the emission order and the reuse of the graph and proves its properties. | the graph itself, so calls chain | | Order, Findings, ToW | a graph with no node raises error stzMaterialGraph.Compile: no nodes declared; with no output, error ... no output -- say Emits(:node); with an output that is not a node, error ... the output node ... does not exist; a node that reads the same node in two of its inputs, such as Multiply with [ :a, :a ], raises the stzGraph error saying parallel edges are refused, because one edge is added for each input | the findings are an unresolved_input error for an input that is no node, no declared value and no builtin, an acyclic error for a cycle, and a dead_node warning for a node nothing reads other than the output; a graph with a cycle has an empty order
Order | Returns the nodes in the order they are emitted, derived so that a node comes after every node it reads. | a list of node names in lower case; [ ] after a cycle | | Uses, Compile | calling it before Compile raises error stzMaterialGraph: call Compile() first | declare the nodes in any order at all
Uses | Returns how many nodes read each node. | a list of [ node, consumers ] pairs in declaration order; the output has 0 | | ReuseSaved, Order | calling it before Compile raises error stzMaterialGraph: call Compile() first | a node read by two nodes is emitted once, as one let
ReuseSaved | Returns how many expressions the single emission of shared nodes saves over writing the graph out as a tree. | a number, each node's consumers beyond the first added up | | Uses, ToW | calling it before Compile raises error stzMaterialGraph: call Compile() first | 0 when no node is read twice
Affects | Returns every node downstream of a node, that is every node that depends on it, directly or not. | a list of node names, the node itself not included; [ ] for an output node or an unknown name | pcNode=the node to ask about, in any letter case | ImpactOf, Order | calling it before Compile raises error stzMaterialGraph: call Compile() first | it is a reachability query on the stzGraph the compile builds
ImpactOf | Returns how many nodes depend on a node, directly or not. | a number; 0 for an output node or an unknown name | pcNode=the node to ask about, in any letter case | Affects | calling it before Compile raises error stzMaterialGraph: call Compile() first | the length of the list Affects gives
Findings | Returns the proofs that failed or warned, in the house finding shape. | a list of hash lists with rule, subject materialgraph, where material, severity and message; [ ] for a clean graph | | IsSound, Report | calling it before Compile raises error stzMaterialGraph: call Compile() first |
IsSound | TRUE if the compiled graph has no finding of severity error. | TRUE or FALSE, as 1 or 0 | | Findings, ToW | calling it before Compile raises error stzMaterialGraph: call Compile() first | a dead_node warning does not make it false
Report | Returns the findings as a stzRuleReport, so the graph is judged by the same gate as code and security rules. | a stzRuleReport named materialgraph | | Findings, IsSound | calling it before Compile raises error stzMaterialGraph: call Compile() first |
ToW | Returns the material-language body the graph emits, one let for each node in order and then the output. | the text, such as { let n_a = abs(1.0); @out = (n_a + 2.0) } | | ToMaterial, Order | calling it before Compile raises error stzMaterialGraph: call Compile() first; a graph with an error finding raises error stzMaterialGraph.ToW: the graph has ERRORS | the text can be read and debugged; the output node has no let
ToMaterial | Builds a stzMaterialMaker with the declared colours, scalars and textures and this body, ready to give to a scene. | a stzMaterialMaker | | ToW, ToWGSL | the graph must have been compiled and be sound, as for ToW | rendering the material was not run here
ToWGSL | Returns the WGSL shader of the material, by way of the material maker the graph builds. | the shader source as text | | ToMaterial, ToW | the graph must have been compiled and be sound, as for ToW | no device is needed to produce it
