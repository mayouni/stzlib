init | Creates an empty recorder of request traces and per-facet latency histograms for a cluster, under a name. | nothing; the object is built | pcName=the recorder's name, shown in Narrate | RecordRequest, NewTraceId
Name_ | Returns the recorder's name. | a text | | init
NewTraceId | Returns a fresh trace id of the form t-<start time in ms>-<sequence number>, unique within this recorder. | a text | | RecordRequest, TraceById | the part after t- starts from the wall clock when the recorder is created, so the full id differs between runs
RecordRequest | Records one routed request as a trace and, if it was attempted at least once, adds its duration to the histogram of its facet. | nothing | pcId=the trace id of the request; pcFacet=the facet that served it, matched without regard to case; pcEndpoint=the endpoint that answered; pnStatus=the final status; pnDurMs=the total duration in milliseconds; pnAttempts=how many endpoints were tried, more than 1 meaning a failover | RecentTraces, FailoverTraces | a request with 0 attempts is kept as a trace but adds nothing to the latency histogram; only the latest 512 traces are kept, older ones are dropped
LatencyPercentile | Returns the latency, in milliseconds, under which a percentile of a facet's requests fall, as the upper bound of a histogram bucket. | a number; 0 for a facet never recorded | pcFacet=the facet, matched without regard to case; nP=the percentile, from 0 to 100 | LatencyP99, LatencyStats | approximate: two requests of 12 and 40 ms read p50 as 20 and p99 as 50
LatencyP50 | Returns the median latency of a facet, in milliseconds, as a bucket bound. | a number | pcFacet=the facet, matched without regard to case | LatencyPercentile, LatencyP99
LatencyP90 | Returns the latency under which 90 percent of a facet's requests fall, as a bucket bound. | a number | pcFacet=the facet, matched without regard to case | LatencyPercentile, LatencyP99
LatencyP95 | Returns the latency under which 95 percent of a facet's requests fall, as a bucket bound. | a number | pcFacet=the facet, matched without regard to case | LatencyPercentile, LatencyP99
LatencyP99 | Returns the tail latency of a facet, the one under which 99 percent of its requests fall, as a bucket bound. | a number | pcFacet=the facet, matched without regard to case | LatencyPercentile, LatencyP50
LatencyCount | Returns how many requests were added to a facet's histogram; 0 for a facet never recorded. | a number | pcFacet=the facet, matched without regard to case | LatencyStats
LatencyStats | Returns a facet's figures in one hashlist: facet, count, p50, p90, p95 and p99. | a hashlist | pcFacet=the facet, matched without regard to case | LatencyPercentile, LatencyCount | a facet never recorded gives the same keys with 0 in every figure
Facets | Returns the facets that have a histogram, lower-cased, in the order they first appeared. | a list of texts | | LatencyStats
NumberOfTraces | Returns how many traces are held, at most 512. | a number | | RecentTraces
RecentTraces | Returns the n latest traces, oldest first; each is [ id, facet, endpoint, status, duration, attempts ]. | a list of lists; empty when n is below 1 or nothing was recorded | n=how many traces to return | LastTrace, TraceById
LastTrace | Returns the most recent trace as [ id, facet, endpoint, status, duration, attempts ]; empty when there is none. | a list | | RecentTraces
TraceById | Returns the latest trace recorded under an id, or an empty list when none matches. | a list | pcId=the trace id to look for | NewTraceId, RecentTraces
FailoverTraces | Returns the traces of the requests that needed more than one attempt, oldest first. | a list of lists | | RecordRequest
Narrate | Returns a short text that gives the trace count and, per facet, the p50, p99 and count. | a text | | LatencyStats
Destroy | Frees the engine histograms and forgets the facets; the traces stay. | the recorder itself, so calls chain | | init | NumberOfTraces and RecentTraces still answer after it
