init | Builds a lines helper over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the multi-line text, or a stzString whose content is edited; any other value raises an error | Content, Lines | with a stzString argument, the first in-place edit (ReverseLinesOrder, SortLines, IndentLines...) leaves the stzString you passed reading as an empty text, while the helper keeps the right one | pass a plain text and read the result with Content; lines end at a line feed
Content | Returns the text as it stands now, after the in-place edits made so far. | a text | | NumberOfChars, Lines
NumberOfChars | Returns how many characters the text holds, counting line feeds and counting a Hebrew letter or an emoji as one. | a number | | Content, NumberOfLines
IsEmpty | TRUE if the text holds no character at all. | TRUE or FALSE, as 1 or 0 | | NumberOfChars, Content
Lines | Returns the lines of the text as a list of texts, cut at each line feed. | a list of text; empty lines are kept as empty texts | | NumberOfLines, NthLine, UniqueLines | a carriage return before a line feed stays at the end of its line (a CRLF text keeps the CR); an empty text answers a list of one empty text although NumberOfLines answers 0; a final line feed makes a last empty line | LinesQ returns a stzList for chaining
NumberOfLines | Returns how many lines the text has, a final line feed counting one more empty line. | a number; 0 for an empty text | | Lines, NthLine, NumberOfEmptyLines | | a\nb\n gives 3; CountLines and HowManyLines are the same call
NthLine | Returns the line at a position, counted from 1. | a text | n=the 1-based position of the line | FirstLine, LastLine, Lines | a position of 0, a negative one, or past the last line raises error Index out of range! | Line is the same call
FirstLine | Returns the first line of the text. | a text | | LastLine, NthLine | | an empty text gives an empty text
LastLine | Returns the last line of the text. | a text; an empty text when the text ends with a line feed | | FirstLine, NthLine | an empty text raises error Index out of range! | a\nb\n gives an empty text, since that is the last line
UniqueLines | Returns the lines with each repeated line kept once, at its first place, in order. | a list of text | | RemoveDuplicateLines, Lines | | b A c B a keeps all five, and UniqueLinesCS(0) keeps b A c; empty lines count as a line like another
RemoveEmptyLines | Deletes every blank line from the text, in place, a line holding only spaces counting as blank. | nothing; the text changes. RemoveEmptyLinesQ returns the helper for chaining | | EmptyLinesRemoved, HasEmptyLines | | the remaining lines keep their order
EmptyLinesRemoved | Returns the text with every blank line deleted, a line of spaces counting as blank, leaving the helper unchanged. | a text | | RemoveEmptyLines, NumberOfEmptyLines | | the result is a text, not a list of lines
NumberOfEmptyLines | Returns the line count minus the length in characters of the text left after blank lines are dropped, which is not a count of blank lines. | a number, often negative | | HasEmptyLines, EmptyLinesRemoved | it subtracts the length of a text from a number of lines: a and b on two lines give -1, a and b with two empty lines and a final line feed give 2 for 3 empty lines, and xx then a final line feed gives 0 for 1 | count the empty texts in Lines instead
HasEmptyLines | TRUE if at least one line is empty or holds only spaces. | TRUE or FALSE, as 1 or 0 | | NumberOfEmptyLines, RemoveEmptyLines | | a final line feed makes a last empty line, so a\nb\n answers TRUE
NFirstLines | Returns the first n lines as a list of texts. | a list of text; fewer than n when the text has fewer lines; [ ] for 0 or a negative n | n=how many lines to take from the start | NLastLines, FirstLine | | empty lines count as lines
NLastLines | Returns the last n lines as a list of texts. | a list of text, in text order; fewer than n when the text has fewer lines; [ ] for 0 or a negative n | n=how many lines to take from the end | NFirstLines, LastLine | | empty lines count as lines
LongestLine | Returns the line with the most characters, the first one when several tie. | a text; an empty text for an empty text | | ShortestLine, AverageLineLength | | length counts characters, so a Hebrew or Arabic line is measured in letters
ShortestLine | Returns the line with the fewest characters among the lines that are not blank, the first one when several tie. | a text; an empty text when every line is blank | | LongestLine | | blank lines (empty or only spaces) never win; length counts characters
AverageLineLength | Returns the mean number of characters per line, blank lines included. | a number; 0 for an empty text | | LongestLine, NumberOfLines | | x then yy gives 1.5; Hebrew and emoji lines are counted in characters
SortLines | Sorts the lines of the text in place, in ascending order of code point, an upper-case letter before a lower-case one. | nothing; the text changes. SortLinesQ returns the helper for chaining | | LinesSorted, ReverseLinesOrder | | SortLinesCS(0) ignores case: b A c B a gives A a b B c
LinesSorted | Returns the text with its lines sorted in ascending order of code point, leaving the helper unchanged. | a text, lines joined by line feeds | | SortLines | | b A c B a gives A B a b c; LinesSortedCS(0) gives A a b B c

IndentLines | Puts the given number of spaces in front of every line, blank lines included, in place. | nothing; the text changes. LinesIndented | Returns the text with the given number of spaces in front of every line, leaving the helper unchanged. | a text | n=how many spaces to add to each line | IndentLines | | a then b with 2 gives two spaces before each; a single line is indented too
