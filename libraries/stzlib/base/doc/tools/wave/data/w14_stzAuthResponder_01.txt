init | Builds a responder that performs the LockAccount and RevokeSession actions of a response plan on a stzAuth. | nothing; the object is built | poAuth=the stzAuth whose accounts and sessions are acted on, held by reference | Owns, LockAccount, RevokeSession | | keep the stzAuth alive as long as the responder is used
Owns | TRUE if the verb is LockAccount or RevokeSession, the two this responder answers. | TRUE or FALSE | pcVerb=the verb, matched without regard to case | LockAccount, RevokeSession
LockAccount | Closes the named account until UnlockAccount: every login path refuses it. | nothing; the stzAuth then answers IsAccountLocked | pcTarget=the user name of the account to lock | Owns, RevokeSession | an unknown user name is locked too and no error is raised; the sessions already open are kept and work again after UnlockAccount | the lock carries the reason locked by a containment plan, and the stzAuth notes it in the security refusal record
RevokeSession | Ends every session of the named user, so the user is logged out everywhere. | nothing; the stzAuth then counts fewer sessions | pcTarget=the user name whose sessions end | Owns, LockAccount | an unknown user name changes nothing and raises no error | the account itself stays open and the user can log in again
RotateSecret | Refuses by raising an error that names the responder to wire, because authentication owns accounts and sessions only. | nothing; it always raises | pcTarget=the secret the plan named | Owns | raises an error whatever the target, naming the target and the secret-store responder to wire
RevokeCapability | Refuses by raising an error that names the responder to wire, because this responder does not revoke capabilities. | nothing; it always raises | pcTarget=the actor the plan named | Owns | raises an error whatever the target, naming the target and the capability responder to wire
ShedSource | Refuses by raising an error that names the responder to wire, because this responder does not block sources. | nothing; it always raises | pcTarget=the source the plan named | Owns | raises an error whatever the target, naming the target and the rate-limiter responder to wire
QuarantinePart | Refuses by raising an error that names the responder to wire, because this responder does not quarantine parts. | nothing; it always raises | pcTarget=the part the plan named | Owns | raises an error whatever the target, naming the target and the quarantine responder to wire
