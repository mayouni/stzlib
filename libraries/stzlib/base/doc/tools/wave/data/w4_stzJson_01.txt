IsEmpty | TRUE if the object holds no key and no item, as after Clear or after a text that failed to parse. | | | IsNull, Size | | an empty object and an empty array are both empty
IsNull | TRUE if the object is empty and an error has been recorded, as after a text that is not valid JSON. | | | IsEmpty, HasError | | an empty object built from a valid text is not null

RemoveKey | Removes the key and its value from the object, in place; returns the object itself. | the stzJson itself, so calls chain | cKey=the key to remove, as text | TakeKey, SetValue | | an absent key changes nothing and records no error; an array records an error and changes nothing
TakeKey | Removes the key from the object, in place, and returns the value it held. | the value that was stored; an empty text when the key is absent | cKey=the key to take, as text | RemoveKey, Value | | an array answers an empty text and records an error
