init | Builds an offline HTTP double with no rules, no recordings, an empty journal and strict mode on. | nothing; the object is built | | Script, SeedResponse, SetStrict
IsSandbox | TRUE if the object is a fake, which is how a service registry tells it from a live client. | TRUE | | stzReactorHttpClient
Script | Adds a rule: requests with that method and a matching address get that status and body. | nothing; use ScriptQ to chain | pcMethod=the HTTP method, kept in upper case; pcUrlPattern=an exact address, a prefix ending in *, or a part between a * at each end; pnStatus=the status number to answer with; pcBody=the response body | NumberOfScripts, Request, SetStrict | rules are tried in the order added and the first match wins, so put a general rule last; a pattern with a * only at its start, such as */rates, is taken as an exact address and never matches; the method matches without regard to case but the address with it; a status given as text stays text | ScriptQ is the same call and returns the sandbox
ScriptFailureQ | Adds a rule that makes matching requests answer with a failure status and an empty body. | the sandbox itself, so calls chain | pcMethod=the HTTP method; pcUrlPattern=the address pattern, as for Script; pnStatus=the failure status, such as 503 | Script, Request | the way to test a service that fails, which a real vendor will not do on demand
NumberOfScripts | Returns how many rules the sandbox holds. | a number | | Script
SeedResponse | Keeps a recorded answer for an exact method, address and request body, replacing an earlier one for the same three. | nothing; use SeedResponseQ to chain | pcMethod=the HTTP method; pcUrl=the exact address; pcReqBody=the exact request body; pnStatus=the status to replay; pcRespBody=the body to replay | RecordFrom, HasRecording, Request | a recording is found only for the same body, and it wins over any rule | SeedResponseQ is the same call and returns the sandbox
RecordFrom | Sends a request to another client once and keeps the answer, so that the sandbox replays it from then on. | the answer of the client, a list with status, body and from | poClient=any object with a Request(method, url, body) method, such as a second sandbox or stzReactorHttpClient; pcMethod=the HTTP method; pcUrl=the address; pcReqBody=the request body | SeedResponse, HasRecording | an error raised by the client, such as a strict miss, passes through and nothing is recorded | the sandbox's own journal does not note the request, only the client's
NumberOfRecordings | Returns how many recorded answers the sandbox holds. | a number | | SeedResponse, HasRecording
HasRecording | TRUE if an answer is kept for exactly that method, address and body. | TRUE or FALSE | pcMethod=the HTTP method, matched without regard to case; pcUrl=the exact address; pcReqBody=the exact request body | SeedResponse, RequestKey
RequestKey | Returns the key a recording is filed under: a SHA-256 hash of the method in upper case, the address and the body. | a text of 64 hexadecimal characters | pcMethod=the HTTP method; pcUrl=the address; pcReqBody=the request body | SeedResponse, HasRecording | the same method in another letter case gives the same key
Request | Answers a request from a recording first, then from the first matching rule, and notes the request in the journal. | a hash list with status, body and from, from being replay, scripted or miss | pcMethod=the HTTP method, matched without regard to case; pcUrl=the address; pcReqBody=the request body | GetFrom, PostTo, Script, SeedResponse, SetStrict | in strict mode, which is the default, a request with no recording and no rule raises an error naming the method and address; it is still journalled | with strict mode off a miss answers status 501 with from miss
GetFrom | Sends a GET request with no body through Request. | a hash list with status, body and from | pcUrl=the address | Request, PostTo
PostTo | Sends a POST request with a body through Request. | a hash list with status, body and from | pcUrl=the address; pcBody=the request body | Request, GetFrom
SetStrict | Chooses whether a request that matches nothing raises an error (1) or answers a 501 miss (0). | nothing; use SetStrictQ to chain | pbOn=1 for strict, 0 to let misses through | IsStrict, Request | SetStrictQ is the same call and returns the sandbox
IsStrict | TRUE if a request that matches nothing raises an error. | TRUE or FALSE | | SetStrict
Calls | Returns the journal of every request made, oldest first, those that raised an error included. | a list of rows [ method, url, body ], the method in upper case | | LastCall, NumberOfCalls, ClearCalls
NumberOfCalls | Returns how many requests the journal holds. | a number | | Calls
LastCall | Returns the most recent request of the journal. | a hash list with method, url and body; an empty list when the journal is empty | | Calls
NumberOfCallsTo | Returns how many journalled requests asked for exactly that address, whatever the method. | a number | pcUrl=the exact address | WasCalled, Calls | the way to catch a request repeated too often
WasCalled | TRUE if the journal holds a request with that method and exact address. | TRUE or FALSE | pcMethod=the HTTP method, matched without regard to case; pcUrl=the exact address | NumberOfCallsTo, Calls
ClearCalls | Empties the journal; rules and recordings stay. | nothing; use ClearCallsQ to chain | | Calls | ClearCallsQ is the same call and returns the sandbox
Show | Prints one line giving the number of rules, recordings and journalled requests. | nothing; it prints | | NumberOfScripts, NumberOfRecordings, NumberOfCalls
