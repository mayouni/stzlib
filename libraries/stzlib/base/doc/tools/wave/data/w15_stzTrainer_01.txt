init | Builds a trainer with the learning rate at 0.1 and no history. | nothing; the object is built | | SetLearningRate, Train
SetLearningRate | Sets the step size of the gradient descent. | the trainer itself, so calls chain | n=the learning rate, above 0; 0.1 by default | Train | | a value of 0 or less is ignored without a message
Train | Trains a network in place by backpropagation in the engine, recording the loss of every epoch. | the trainer itself, so calls chain | poNet=the stzNeuralNetwork to train, which is changed; paInputs=a list of input lists; paTargets=a list of target lists, as wide as the output layer; nEpochs=the number of passes, at least 1 | LossHistory, Why | raises an error naming the cause when inputs and targets differ in number, the epochs are below 1, the network has no layers, or a sample or target has the wrong width | the update rule is the output-layer delta of a minus y, whatever the loss reported; a softmax output uses cross-entropy and the other outputs report squared error
LossHistory | Returns the loss at every epoch of the last Train, in order. | a list of numbers; empty before Train | | FinalLoss, Why
FinalLoss | Returns the loss at the last epoch of the last Train. | a number; 0 before Train | | LossHistory
Why | Returns a sentence with the epochs, the learning rate and the first and last loss of the last Train. | a text such as trained 2000 epoch(s), lr 0.50: loss 0.40 -> 0.00; empty before Train | | LossHistory, FinalLoss
