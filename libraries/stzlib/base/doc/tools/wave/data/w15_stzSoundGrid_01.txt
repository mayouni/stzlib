# w15 stzSoundGrid -- grids were made from sounds rendered to memory; no audio device was opened and nothing was heard (UNPERCEIVED)
init | Wraps the engine's table of analysis numbers, taking its handle. | nothing; the object is built | pnGridId=the engine's number for the grid, as a sound's ToSpectrum, ToSpectrogram or ToOnsets makes it | Release, Rows | | you rarely build one yourself; a spectrum is one row, a spectrogram has a row for each window, and an onset list is one row of seconds
GridId | Returns the engine's number for the grid. | a number above 0; 0 after Release | | Release, IsEmpty |
Release | Frees the grid in the engine. | nothing; every question answers its empty value afterwards | | IsEmpty, GridId | | releasing twice does nothing the second time; the sound's own buffer is not touched
IsEmpty | TRUE if the grid holds no rows. | TRUE or FALSE, as 1 or 0 | | Rows, Release | | it is TRUE after Release
Rows | Returns how many rows the grid has. | a number; 0 after Release | | Columns | | 1 for a spectrum, one for each window for a spectrogram, and 1 for onsets; a 0.9 second sound at 48000 hertz gave 81 windows of 2048 frames moving 512
Columns | Returns how many columns the grid has. | a number; 0 after Release | | Rows, HertzPerColumn | | 2049 for a spectrum of 4096 frames, 1025 for a spectrogram, and one for each onset in an onset list
SecondsPerRow | Returns what one row step means in time. | a number of seconds; 0 when a row is not a moment | | HertzPerColumn, Rows | | 512 over 48000, about 0.0107, for a default spectrogram; 0 for a spectrum and for onsets, whose numbers are already seconds
HertzPerColumn | Returns what one column means in frequency. | a number of hertz; 0 when a column is not a frequency | | SecondsPerRow, PeakFrequencyOfRow | | 11.72 for a default spectrum and 23.44 for a default spectrogram at 48000 hertz; 0 for onsets
At | Returns the value in one cell. | a number, 0 for a cell outside the grid or after Release | pnRow=the row, counted from 1; pnColumn=the column, counted from 1 | Max, ToList | | the values of a spectrum are magnitudes
Max | Returns the largest value in the whole grid. | a number; 0 after Release | | At, PeakColumnOfRow |
PeakColumnOfRow | Returns which column holds the largest value of a row, which frequency won. | the column, counted from 1; -1 for a row outside the grid or after Release | pnRow=the row, counted from 1 | PeakFrequencyOfRow, At | | for a rendered 1000 hertz note it was column 86
PeakFrequencyOfRow | Returns the frequency of the strongest column of a row, in hertz. | a number of hertz, the start of the bin; -1 for a row outside the grid or after Release | pnRow=the row, counted from 1 | PeakColumnOfRow, HertzPerColumn | | it is (column - 1) times HertzPerColumn, so a 1000 hertz note reads 996.09, the bin containing it, and in a spectrogram row 1007.81, since a bin is 23.44 wide and 1000 divided by it is 42.7
ToList | Returns one row as a plain Ring list. | a list of numbers, one for each column; [ ] after Release | pnRow=the row, counted from 1 | ToTimesList, At | | it crosses into the engine once for each value, so use it to look at a row, not at a whole spectrogram
ToTimesList | Returns the first row, which for an onset list is the list of times. | a list of numbers, in seconds for an onset grid | | ToList | | the onset times come from a detector with a window of 2048 frames and are not exact to the frame
ToCanvas | Draws the grid as a heat map on a stzCanvas of a given size, with low frequencies at the bottom. | a stzCanvas of rectangles, one for each cell of 3 by 3 pixels | pnWidth=the width in pixels; pnHeight=the height in pixels | ToCanvasOf, ToSVG, ToPNG | | the grid is reduced to the cells that fit, each taking the loudest value beneath it; colour runs from dark blue through cyan and yellow to white over 60 decibels below the peak; only the first 120 columns are drawn; a canvas that is background alone for an empty or silent grid
ToCanvasOf | Draws the grid as a heat map like ToCanvas, with a chosen number of frequency columns. | a stzCanvas of rectangles, one for each cell of 3 by 3 pixels | pnWidth=the width in pixels; pnHeight=the height in pixels; pnMaxBins=how many columns, from the lowest frequency up, to draw, or 0 for all | ToCanvas, ToSVG | | most musical energy sits in the lowest fraction of the range, so the default of 120 columns covers about 2.8 kilohertz at 48000 hertz
ToSVG | Draws the heat map as SVG text; no graphics device is needed. | the SVG text, starting with <svg | pnWidth=the width in pixels; pnHeight=the height in pixels | ToSVGFile, ToPNG | | the temporary canvas is freed
ToSVGFile | Draws the heat map and writes it to an SVG file. | nothing; the file is written | pcPath=the path of the file; pnWidth=the width in pixels; pnHeight=the height in pixels | ToSVG, ToPNG | | it works on a machine with no graphics device; an existing file is overwritten
ToPNG | Draws the heat map and writes it to a PNG file through the graphics device. | nothing; the file is written | pcPath=the path of the file; pnWidth=the width in pixels; pnHeight=the height in pixels | ToSVGFile, ToCanvas | | it needs a graphics device but opens no window; the picture of a 1000 hertz note showed a bright line at 1000 hertz and its second harmonic, ending where the note ends
