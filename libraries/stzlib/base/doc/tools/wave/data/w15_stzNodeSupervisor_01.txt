init | Creates a supervisor of node processes, one-for-one, with 3 restarts per 10 seconds and no heartbeat; starts nothing. | nothing; the object is built | | Child, StartAll
Name_ | Returns the supervisor's name, 'node-supervisor' unless SetName changed it. | a text | | SetName, Cycle
SetName | Sets the name by which an agent host knows the supervisor. | the supervisor itself, so calls chain | pcName=the new name, as text | Name_
Child | Declares a node process to supervise: its name, the Ring script that runs it and the port it listens on. | the supervisor itself, so calls chain | pcName=the node's name, stored in lower case; pcScript=the path of the Ring script the process runs; pnPort=the port passed to the script as its last argument | StartAll, SetChildHost | nothing is spawned until StartAll; the host defaults to 127.0.0.1
SetChildHost | Sets the host on which a child's name resolves on the node plane, so a deployment can move it. | the supervisor itself, so calls chain | pcName=the child's name, matched without regard to case; pcHost=the host or interface address | Child | an unknown child name changes nothing
KillChild | Kills the operating-system process of a child, for deployment or chaos tests; the next Cycle sees the death and handles it. | the supervisor itself, so calls chain | pcName=the child's name, matched without regard to case | Cycle, StartAll | does nothing for a child that is not running | run only while no child was started, where it does nothing
Strategy | Chooses what happens when a child dies: :OneForOne restarts that child, :AllForOne restarts every child. | the supervisor itself, so calls chain | pcStrategy=:OneForOne or :AllForOne | RestartBudget, Cycle | any other value selects :OneForOne
RestartBudget | Sets how many restarts are allowed within a sliding time window before the supervisor escalates. | the supervisor itself, so calls chain | nMax=the restarts allowed in the window, 3 by default; nWindowMs=the window length in milliseconds, 10000 by default | Escalated, Strategy | under :AllForOne one death counts as one restart per child
Heartbeat | Turns on heartbeats: the supervisor pings each running child and treats one that stays silent as dead. | the supervisor itself, so calls chain | nIntervalMs=the time between pings in milliseconds, 0 for none; nTolerance=how many consecutive misses make a child dead, 3 by default | Cycle | a silent child is killed before it is restarted, so that its port frees
Monitor | Subscribes a node to the death of a child: on each death it is sent [ node.down, child, restarts so far ]. | the supervisor itself, so calls chain | pcChildName=the child to watch, matched without regard to case; pcSubscriberAddr=the node address that receives the notice | Cycle | the notice is sent over the node plane
Escalated | TRUE if the restart budget was exceeded and the supervisor stopped restarting. | 1 or 0 | | EscalationReason, RestartBudget | after escalating, Cycle does nothing and the dead child stays down
EscalationReason | Returns the text that says which child exceeded which budget; empty before any escalation. | a text | | Escalated
RestartsOf | Returns how many times a child was restarted; -1 for an unknown name. | a number | pcName=the child's name, matched without regard to case | TotalRestarts
TotalRestarts | Returns the restarts of all children added together. | a number | | RestartsOf
JobOf | Returns the spawn job number of a child's current process, 0 when it is not running or unknown. | a number | pcName=the child's name, matched without regard to case | StartAll
StartAll | Spawns the process of every declared child and registers each name on the node plane. | the supervisor itself, so calls chain | | Cycle, StopAll | spawns operating-system processes and registers them on the node plane | not run: it starts child processes
Cycle | Runs one supervision tick: finds dead children, notifies monitors, and restarts them under the strategy and the budget. | the supervisor itself, so calls chain | | StartAll, Escalated | it never waits and never loops: past the budget it escalates and stops restarting | run only while no child was started, where it does nothing
StopAll | Kills every running child process and forgets their jobs. | the supervisor itself, so calls chain | | StartAll, Destroy | kills processes | run only while no child was started, where it does nothing
Destroy | Stops every child and destroys the supervisor's reactor. | nothing | | StopAll | the supervisor cannot be used afterwards
