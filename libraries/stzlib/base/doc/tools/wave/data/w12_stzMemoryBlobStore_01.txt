init | Builds an empty store that holds its objects in memory, numbered so that each store keeps its own. | nothing; the object is built | | Save, stzFileBlobStore | | two stores never see each other's objects

Remove | Deletes the object stored under a key; deleting an absent key also succeeds, as an S3 DELETE does. | 1 (TRUE), always | pcKey=the object key to delete | Clear, Exists | an empty key raises an error
Size | Returns the number of bytes stored under a key. | a number; 0 when the key is absent | pcKey=the object key to measure | Fetch, TotalBytes | an empty key raises an error

IsEmpty | TRUE if the store holds no object. | TRUE or FALSE | | NumberOfBlobs
TotalBytes | Returns the sum of the sizes of all stored objects, in bytes. | a number | | Size, NumberOfBlobs
