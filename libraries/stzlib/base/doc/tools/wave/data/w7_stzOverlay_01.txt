init | Opens an overlay folder and reads its overlay.zknw, whose is-a overlay fact gives the overlay its name. | nothing; the object is built | pcFolder=the overlay's folder: its last segment is the overlay's id | HasManifest, Check | a folder without overlay.zknw opens without error and has no name (HasManifest answers FALSE); a fact whose value holds a space, such as a brand of two words, raises the error Incorrect Id! pcNodeId must be one string without spaces nor new lines | an overlay adds and shadows the core program file by file, and never forks it
Folder | Returns the overlay's folder path, without a trailing slash. | a text | | Id, Files
Id | Returns the overlay's identifier, which is the last segment of its folder's path. | a text such as bank | | Name, Folder | | Name comes from the manifest and can differ
Name | Returns the name the manifest gives the overlay with its is-a overlay fact, or an empty text when there is none. | a text such as bank | | Id, HasManifest
HasManifest | TRUE if overlay.zknw names the overlay, which is the one thing an overlay cannot do without. | TRUE or FALSE | | Name, Check
Extends | Returns the ids of the programs the manifest says the overlay is laid over. | a list of text, such as softanza-education; [ ] when it says none | | Check, Languages | | Check demands that it names the id of the program it is judged against
Languages | Returns the languages the overlay says it speaks, in the order the manifest gives them. | a list of language codes, such as fr and en | | Check, Extends | | each must be a language of the core program: a new language is added to the natural pack, not declared here
Brand | Returns the brand the manifest gives the institution, or an empty text when there is none. | a text such as sahel-savings | | Name, ReplacedWorlds | | the brand is one word, since a value with a space cannot be read
ReplacedWorlds | Returns the ids of the core teaching worlds the manifest says the overlay replaces. | a list of text, such as workplace | | Check, Files | | Check requires worlds/<id>.zknw to be shipped for each
Files | Returns the relative path of every file under the overlay's folder, subfolders included. | a list of text, with forward slashes | | Folder, Check
Check | Judges the overlay against the program it is laid over and returns its findings, none of them an error when it is valid. | a list of findings, each [ :rule, :subject, :where, :severity, :message ]; [ ] when clean | poProgram=the stzProgram the overlay is laid over | IsValid, CiteFindings, stzRuleReport | it runs every added exercise and every world page to prove them, so the bank overlay takes about 45 seconds, and IsValid and CiteFindings each run it again; the runs happen on the desktop only | the rules are overlay-manifest, overlay-extends, overlay-language, overlay-world, overlay-world-page, overlay-course, overlay-chapter, overlay-exercise, overlay-governance and overlay-no-fork: an overlay may replace a world and add chapters and exercises, but a file that would replace a core chapter or exercise is a fork and is refused; an overlay without a manifest gets that one finding only
IsValid | TRUE if Check finds no error in the overlay. | TRUE or FALSE | poProgram=the stzProgram the overlay is laid over | Check, CiteFindings | | it runs the whole court, which is slow
CiteFindings | Returns the findings of the court as text, one line per finding as [rule @ where] message. | a text; an empty text when the overlay is clean | poProgram=the stzProgram the overlay is laid over | Check, IsValid | | it runs the whole court, which is slow
