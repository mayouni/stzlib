# w15 stzReactiveHttp -- the four verbs were not run: they reach the network; read from the code
Init | Builds an HTTP client for a reactive engine, with no reactor, so its requests are blocking until SetReactor gives one. | nothing; the client is built | engine=the reactive engine the blocking tasks are registered with | SetReactor, Get_ | |
SetReactor | Sets the reactor that makes requests asynchronous, or removes it. | the client itself, so calls chain | poReactor=a stzReactor, or NULL to go back to blocking requests; any other value is ignored | PendingCount, DrainPending | | with a reactor, http and https requests are submitted as jobs and return at once; without one, or for any other address, each verb runs a blocking task
PendingCount | Returns how many asynchronous requests have not been drained yet. | a number; 0 for a new client | | DrainPending, Get_ | |
Get_ | Sends a GET request and calls onSuccess with the body or onError with the failure text. | a stzHttpTask, already executed, on the blocking path; the job number on the asynchronous path, -1 when the reactor refused it | url=the address; onSuccess=a function taking the response body; onError=a function taking the failure text | Post, DrainPending, SetReactor | not run: it reaches the network | on the asynchronous path the callbacks run later, from DrainPending in the run loop; the failure text is HTTP request failed, with the status in parentheses when there is one
Post | Sends a POST request with a body and calls onSuccess with the response body or onError with the failure text. | a stzHttpTask on the blocking path; the job number on the asynchronous path | url=the address; data=the body to send; onSuccess=a function taking the response body; onError=a function taking the failure text | Get_, Put_ | not run: it reaches the network | success is a status from 200 to 299
Put_ | Sends a PUT request with a body and calls onSuccess with the response body or onError with the failure text. | a stzHttpTask on the blocking path; the job number on the asynchronous path | url=the address; data=the body to send; onSuccess=a function taking the response body; onError=a function taking the failure text | Post, Delete | not run: it reaches the network |
Delete | Sends a DELETE request and calls onSuccess with the response body or onError with the failure text. | a stzHttpTask on the blocking path; the job number on the asynchronous path | url=the address; onSuccess=a function taking the response body; onError=a function taking the failure text | Get_, Put_ | not run: it reaches the network | on the blocking path a delete answered with no body counts as a failure
DrainPending | Delivers every finished asynchronous request to its callback, for the run loop to call each tick. | the number of requests delivered; 0 when none was pending or none had finished | | PendingCount, SetReactor | | a 2xx status calls onSuccess with the body, any other status or a failed job calls onError; a job still in flight stays pending; run with nothing pending it answered 0
