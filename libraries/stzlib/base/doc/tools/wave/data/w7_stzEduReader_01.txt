init | Starts a reader for a course: an empty page to which observed chapters, world pages and questions are then added. | nothing; the object is built | poCourse=the stzCourse the page is about: its slug titles the page and its exercises are shown after the cells | AddChapter, AddWorldPage, AddQuestion, Html | | the page it builds loads nothing from the network and stores no output
AddChapter | Adds one edition of a chapter, already run and observed, to the reader, as an entry of its language's menu. | nothing; use AddChapterQ to chain | poChapter=a stzChapter on which ObserveWhere() has run, as the chapters returned by the course's RunChapterInQ | AddWorldPage, Html | raises an error saying a chapter enters the reader only after ObserveWhere() when it was not run: where a cell runs is observed, never assumed | each language of a chapter is added separately, one call per edition
AddWorldPage | Adds the page of a teaching world, listed after the chapters of its language under the word World. | nothing; use AddWorldPageQ to chain | poChapter=a stzChapter made from a world page, on which ObserveWhere() has run | AddChapter, NumberOfWorldPages | raises the same error as AddChapter for a page that was not run; adding the same page twice lists it twice (shown: 2 pages) | the page is the same article as a chapter
NumberOfWorldPages | Returns how many world pages the reader holds. | a number | | AddWorldPage
AddQuestion | Adds a question answered from the library's own documentation, for the page's Q&A section. | nothing; the question and its answer are stored | pcQuestion=the question, in words; pcClass=the class whose documentation answers it | QandA, Html | raises an error saying the library has no answer, when the class's documentation has none: a page may not invent one | the answer is the best match of the class's documentation, so it follows the doc blocks as they are written
QandA | Returns the questions added to the reader, each with the method that answers it. | a list of [ question, class, method, explanation ] lists; [ ] when none | | AddQuestion, Html
Html | Returns the whole reader as one self-contained HTML page of the chapters, world pages and Q&A added. | a text, the HTML of the page | | WriteTo, AddChapter | | each cell is labelled where it ran as the guard observed it, and carries a fixed sentence saying the page stores no output; every unreviewed translation carries a draft notice; the page is right to left for Arabic; with nothing added it is still a page, with an empty menu
WriteTo | Writes the HTML page to a file and returns the path written. | a text, the path | pcFile=the file to write, overwritten | Html | | to open the page, open the file in any browser: no server is needed
