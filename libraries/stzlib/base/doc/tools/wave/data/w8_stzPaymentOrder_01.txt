# Wave 8 -- stzPaymentOrder. Name | brief | returns | params | see | warning | note
init | Builds an empty order, which is then told who pays whom, how much and under which id. | nothing; the object is built | | WithTxId, AsBody
WithTxId | Sets the platform's own unique identifier of the payment, the key that makes a retry safe. | the order itself, so calls chain | pcTx=the platform's id, unique, kept to at most 35 characters by the hub | TxId, FromAlias, stzPaymentsPort | | a retry reuses this id: a new id is a new payment
FromAlias | Sets the platform's own alias, the account that is debited. | the order itself, so calls chain | pcAlias=the platform's PI-SPI alias, a UUID | ToAlias, WithTxId | | stzPaymentsPort Pay refuses an order without it
ToAlias | Sets the payee by PI-SPI alias, the usual route to a customer. | the order itself, so calls chain | pcAlias=the payee's PI-SPI alias, a UUID | ToIban, ToAccount, FromAlias | | if several routes are set the alias wins, then the IBAN, then the account
ToIban | Sets the payee by IBAN and by the participant that holds the account. | the order itself, so calls chain | pcIban=the payee's IBAN; pcParticipant=the code of the payee's participant, as Participants lists it | ToAlias, ToAccount, Participants
ToAccount | Sets the payee by account number and by the participant that holds the account. | the order itself, so calls chain | pcCompte=the payee's account number; pcParticipant=the code of the payee's participant, as Participants lists it | ToAlias, ToIban, AsItem | | in a bulk item the account number travels as payeOther, the hub's other name for it
WithAmount | Sets the amount from an amount built with its currency, kept in whole francs. | the order itself, so calls chain | poAmount=an amount built with StzAmountQ, in XOF | Amount, StzAmountQ | raises an error for a bare number, which carries no currency, and for any currency but XOF, before a request exists | 25000 francs is stored as 25000
Motive | Sets the free text the payee sees on the payment, such as an invoice number. | the order itself, so calls chain | pcMotif=the text shown to the payee, at most 140 characters | Documented | | the hub shows it to the payee
Documented | Attaches a reference document to the payment: its number and its type. | the order itself, so calls chain | pcNumber=the document's number, such as an invoice number; pcType=the document's type code | Motive
WithConfirmation | Makes the hub hold the payment until the platform confirms it. | the order itself, so calls chain | | WithoutConfirmation, ConfirmPayment | | the payment then starts as INITIE, not ENVOYE; either this or WithoutConfirmation must be set
WithoutConfirmation | Makes the hub send the payment at once, with no confirmation step. | the order itself, so calls chain | | WithConfirmation | | either this or WithConfirmation must be set
TxId | Returns the txId set on the order. | a text; an empty text when none was set | | WithTxId
Amount | Returns the amount set on the order, in whole francs. | a number; 0 when no amount was set | | WithAmount
AsBody | Returns the order as the message body the hub expects, a list of pairs, once every required part is set. | a list of [ key, value ] pairs: txId, payeurAlias, montant, confirmation, the payee route, then motif and the document when set | | AsItem, stzPaymentsPort | raises an error naming what is missing: the txId, the payer's alias, a payee, an amount, or the confirmation choice | stzPaymentsPort Pay calls it for you
AsItem | Returns the order as one item of a bulk, which has no payer and no confirmation because the batch carries them. | a list of [ key, value ] pairs: txId, montant, the payee route, then motif and the document when set | | AsBody, Add | raises an error when the txId, the amount or the payee is missing | stzPaymentBatch Add calls it for you
