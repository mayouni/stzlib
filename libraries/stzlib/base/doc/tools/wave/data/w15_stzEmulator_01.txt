init | Creates an emulator for a delivery plan: it will build a static web bundle in which each part of the solution renders its own app. | nothing; the object is built | poDelivery=the stzDelivery whose plan is emulated | Build, SetOutDir
SetOutDir | Chooses the folder in which the bundle is built, in place of the default <delivery name>_emulator in the current folder. | nothing; use SetOutDirQ to chain | pcDir=the folder to build in, created by Build if missing | BundleDir, Build | build into a scratch folder: Build writes there and replaces the files it finds
CompileEngine | Turns on or off the compilation of each mobile part's own engine subset, which invokes the Zig toolchain. | nothing; use CompileEngineQ to chain | pbOn=1 to compile each part's stz_<part>.wasm, 0 for wiring only | Build | on by default; with 0 Build is fast and needs no toolchain, and the page falls back gracefully without the wasm files | Build was run here only with 0
BundleDir | Returns the folder the bundle is or will be built in. | a text | | SetOutDir, ShellPath
Build | Writes the emulator bundle: index.html, the web assets, one app page per mobile part, the plan map, the app data and the manifest. | the emulator itself, so calls chain | | Files, IsBuilt, BundleDir | writes files into the bundle folder; with the engine on it also runs the Zig build for each distinct engine subset and writes stz_<part>.wasm; raises an error when the web assets are not found next to the library; the emulator stays a static page set that needs no server | run here with the engine off and the folder in a scratch area; the engine-on path was not run
Files | Returns the names of the files the last Build wrote, relative to the bundle folder, in the order written. | a list of texts | | Build, BundleDir | empty before the first Build; a wasm file appears only if it exists on disk
IsBuilt | TRUE if Build has run on this emulator. | TRUE or FALSE | | Build, Files | it is not reset if the bundle folder is deleted afterwards
ShellPath | Returns the path of the bundle's index.html, the page to open in a browser. | a text | | BundleDir, Build | the file exists only after Build
