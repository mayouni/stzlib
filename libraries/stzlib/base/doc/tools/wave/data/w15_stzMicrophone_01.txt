# w15 stzMicrophone -- the microphone was NEVER opened and no input device was queried: every method that reaches a device is read from the code and marked not run; nothing was recorded or heard (UNPERCEIVED)
init | Builds a recorder with one channel at 48000 hertz, noting whether the sound engine is loaded. | nothing; the object is built and no device is opened | | StartRecording, RecordFor | | StzMicrophoneQ builds the same object; without the sound engine LastError says stz_sound.dll is not loaded
IsAvailable | TRUE if there is an input to record with. | TRUE or FALSE, as 1 or 0; 0 on a machine with no input or no device library, a supported configuration | | DeviceCount, DeviceName | not run: it asks the operating system for its capture devices | CI machines answer 0
DeviceCount | Returns how many capture devices the machine has. | a number; 0 when there is no device library | | IsAvailable, DeviceName | not run: it asks the operating system for its capture devices |
DeviceName | Returns the name of the default input. | the name as text, which may be UTF-8 and not ASCII; an empty text when there is none | | DeviceCount, IsAvailable | not run: it asks the operating system for its capture devices | one machine of the plane reported a French name
IsRecording | TRUE if a recording is running. | 1 or 0 | | StartRecording, StopRecording | | 0 for a recorder that never started
SecondsRecorded | Returns how many seconds have been collected so far. | a number of seconds; 0 when no recording exists | | FramesRecorded, Collect | | frames divided by the sample rate; it grows only when Collect moves frames in
FramesRecorded | Returns how many frames have been collected so far. | a number; 0 when no recording exists | | SecondsRecorded, Collect |
Overruns | Returns how many frames the device had to drop because nobody collected in time. | a number; 0 is the answer you want, and 0 when no device is open | | Collect | | the ring holds about 250 ms; when full, the newest frames are dropped and counted, never written over unread audio
LastError | Returns the reason of the last failure. | the reason as text; an empty text when nothing went wrong | | StartRecording, StopRecording | | after StopRecording with nothing running it reads not recording
SetChannels | Sets how many channels the next recording has. | nothing; the number is stored. SetChannelsQ returns the microphone for chaining | pnChannels=the number of channels, 1 by default | SetSampleRate, StartRecording | | it is not checked; set it before StartRecording
SetSampleRate | Sets the sample rate the next recording is made at. | nothing; the number is stored. SetSampleRateQ returns the microphone for chaining | pnRate=the rate in hertz, 48000 by default | SetChannels, StartRecording | | it is not checked; set it before StartRecording, and SecondsRecorded divides by it
RecordFor | Records for a number of seconds, collecting as it goes, and returns the sound. | a stzSound of what was recorded; an empty text when no recording could start or nothing was captured | pnSeconds=how long to record, in seconds | StartRecording, StopRecording | not run: it opens the input device and records | it waits in steps of 50 ms and collects at each, so the ring does not overflow
StartRecording | Opens the input and starts filling a recording of a fixed maximum length. | 1 when recording began; 0 with the reason in LastError when it is already recording, there is no capture device or the device refused | pnMaxSeconds=the longest the recording can be, in seconds, which sizes its buffer up front | Collect, StopRecording | not run: it opens the input device | the buffer is sized at the start because growing it during capture is the pause that costs frames
Collect | Moves what the device has delivered into the recording; to be called often while recording. | the number of frames moved; 0 when no recording exists. CollectQ returns the microphone for chaining | | StartRecording, Overruns | | it is not optional: an undrained ring drops the newest frames and counts them as overruns
StopRecording | Stops the input, collects the last frames and returns the recording as a sound. | a stzSound; an empty text, with the error not recording, when nothing is running or nothing was captured | | StartRecording, CancelRecording | | the consumer stops before the ring is freed; an empty recording is reported as a failure and not as a buffer of zeros
CancelRecording | Gives up on a recording and discards what was captured. | nothing; the device is closed and the recording freed | | StopRecording | | calling it with nothing running does nothing
