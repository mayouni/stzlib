init | Builds a monitor with the given name, watching nothing yet, sampling every 1000 ms and with tracing off. | nothing; the object is built | pcName=the monitor's name, which becomes the service name in the OpenTelemetry output; text that is empty or not a text leaves perf-monitor | WatchMemory, Every, Sample
Name | Returns the monitor's name. | a text, such as shop | | Name_
Name_ | Returns the monitor's name under the spelling the agent-host contract expects. | a text, such as shop | | Name, Cycle
WatchMemory | Declares that every sample reads the process memory, and registers the gauges process.memory.rss and process.memory.peak. | the monitor itself, so calls chain | | WatchCpu, WatchSystemMemory, Sample | | calling it twice registers nothing more
WatchCpu | Declares that every sample reads the CPU use of the process, and registers the gauge process.cpu.utilization. | the monitor itself, so calls chain | | WatchMemory, Sample | | the first sample only sets the baseline, so the gauge is written from the second sample on
WatchSystemMemory | Declares that every sample reads the free physical memory of the machine, and registers the gauge system.memory.free. | the monitor itself, so calls chain | | WatchMemory, Sample
Every | Sets the interval, in milliseconds, that Tick and RunFor wait between two samples. | the monitor itself, so calls chain | pnMs=the interval in milliseconds, 1 or more | EveryMs, Tick, RunFor | a value below 1 or one that is not a number is ignored and the old interval stays
EveryMs | Returns the sampling interval in milliseconds. | a number; 1000 on a new monitor | | Every
EnableTracing | Starts keeping the last requests' traces in an engine ring, and does nothing if tracing is already on. | the monitor itself, so calls chain | pnCapacity=how many traces the ring keeps; 128 when it is missing or below 1 | RecordTrace, RecentTraces, IsTracing | | turn it on before handing the monitor to a server, which stores a copy at that moment
IsTracing | TRUE if tracing was turned on and not yet destroyed. | 1 or 0 | | EnableTracing, Destroy
RecordTrace | Adds one request trace to the ring, stamped with the wall clock; ignored when tracing is off. | the monitor itself, so calls chain | pcTraceId=the identifier of the trace; pcPath=the request path; pnStatus=the response status such as 200; pnDurMs=how long the request took in milliseconds | RecentTraces, TraceCount, EnableTracing
TraceCount | Returns how many traces were recorded since tracing started, or 0 when tracing is off. | a number | | RecordTrace, RecentTraces | | it counts every trace ever recorded, so it can exceed the ring's capacity; RecentTraces returns at most the capacity
RecentTraces | Returns the newest traces, oldest of them first, up to the number asked for. | a list of hash-lists with traceId, path, status, durMs and wallMs; [ ] when tracing is off | pnHowMany=how many of the newest traces to return | RecordTrace, TraceCount
NewCounter | Registers a counter of your own and returns it, ready to count up. | the metric object, a counter | pcName=the metric's name, unique in this monitor | NewGauge, NewTimer, MetricQ | raises an error when a metric of that name is already registered
NewGauge | Registers a gauge of your own and returns it, ready to hold a value that goes up and down. | the metric object, a gauge | pcName=the metric's name, unique in this monitor | NewCounter, NewTimer | raises an error when a metric of that name is already registered
NewTimer | Registers a timer of your own and returns it, ready to record durations in milliseconds. | the metric object, a timer | pcName=the metric's name, unique in this monitor | NewCounter, NewGauge | raises an error when a metric of that name is already registered
HasMetric | TRUE if a metric of this name is registered, among the watched ones or your own. | 1 or 0 | pcName=the metric's name | MetricQ, Metrics
MetricQ | Returns the registered metric of this name, a chainable object that shares its numbers with the registry. | the metric object | pcName=the metric's name | HasMetric, NewCounter | raises an error naming the metric when none is registered
Metrics | Returns the registry as data, one pair of name and kind for each metric, in registration order. | a list of pairs such as [ "queue", "gauge" ] | | NumberOfMetrics, MetricQ
NumberOfMetrics | Returns how many metrics are registered. | a number | | Metrics
Sample | Reads every declared sense now, whether due or not, and writes the gauges. | the number of gauge writes made, a number; 0 when nothing is watched | | Tick, SampleCount, SelfCost | | the first sample with the CPU watched writes one gauge fewer, as it only sets the baseline
SampleCount | Returns how many samples have been taken. | a number | | Sample, Tick
SelfCost | Returns what the sampling itself has cost, measured on the monotonic clock. | a hash-list with samples, totalMs and perSampleMs | | Sample | | totalMs and perSampleMs vary from run to run, so test them as ranges
Tick | Takes a sample only when the interval has passed since the last one, so any loop can call it freely. | 1 if it sampled, 0 if not yet due; the first call always samples | | Every, Sample, Cycle
Cycle | Runs one step of the agent contract, which is a Tick, so a host can supervise the monitor. | 1 if it sampled, 0 if not yet due | | Tick, Name_
RunFor | Keeps ticking for the given time, sleeping between samples, and blocks until it ends. | the monitor itself, so calls chain | pnMs=how long to run, in milliseconds | Tick, Every | meant for scripts and guards; a server should host the monitor instead
Prometheus | Renders every metric in the Prometheus text format served at /metrics. | a text of HELP and TYPE lines followed by the values; empty text with no metric | | OtelJson, Metrics | | a labeled family with no child yet prints one line with the label value _overflow
OtelJson | Renders every metric as one OpenTelemetry metrics envelope in JSON. | a text holding the JSON, with the monitor's name as service name | | Prometheus
Explain | Describes the monitor and each metric in plain lines of text. | a list of text, the first line giving the metric count, interval and sample count | | Show
Show | Prints the lines of the explanation on the console. | nothing | | Explain
Destroy | Frees the engine handles of every metric and of the trace ring, and empties the registry. | the monitor itself, so calls chain | | EnableTracing | | call it when done, as engine handles are not freed by Ring
