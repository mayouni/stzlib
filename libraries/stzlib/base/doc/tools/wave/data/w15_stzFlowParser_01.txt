init | Builds a parser for .stzflow text; it keeps no state between parses. | nothing; the object is built | | Parse, ParseFile | | one parser can read any number of texts and files
ParseFile | Reads a .stzflow file from disk and builds the workflow it describes. | a stzWorkflow; an empty text for an empty file | pcFilename=the path of the file to read | Parse, ToWorkflow | a path that cannot be opened raises error R35 Can't create/open the file; a file with no workflow header raises error R13 Object is required, as Parse does | it does not check the extension
Parse | Reads .stzflow text, a workflow header then steps, flow, actors and roles sections, and builds the workflow it describes. | a stzWorkflow; an empty text for an empty text | pcContent=the text, a header line such as workflow "order" followed by type: and the sections | ParseFile, ToWorkflow | text with sections but no workflow header raises error R13 Object is required; a duration or sla of two or more digits, such as 30, comes back as text "30" and not as a number, because the reader tests the whole value with isdigit, which looks at one character; a step line assignedTo: ana is not read, because the reader compares the key with assignedto and Ring compares text case by case, and the text that ToWorkflow writes spells it assignedTo, so a written and re-read workflow loses its assignments; the same line spelt assignedto: ana is read | blank lines and lines starting with # are ignored; actors are read after steps, so an assignment may name an actor not yet known, which the workflow does not check
