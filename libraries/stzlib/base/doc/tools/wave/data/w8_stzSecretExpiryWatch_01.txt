init | Builds a watch over the secrets of a store, to announce in the security ledger those about to expire or already expired. | nothing; the object is built | poStore=the stzSecretStore to read; the watch keeps a copy of the store as it is now | Cycle, Watch | | a secret registered after this call is not seen: hand the watch the current store with Watch before each cycle
Name_ | Returns the name under which a host schedules this watch on its tick. | the text secret-expiry | | Cycle
Watch | Replaces the store this object reads with the current one, keeping what it has already announced. | the watch itself, so calls chain | poStore=the stzSecretStore to read from now on | Cycle, init | | Ring copies an object on assignment, which is why a host calls this each cycle
WarnWithinDays | Sets how many days before its end a secret counts as expiring; thirty days when never set. | the watch itself, so calls chain | pnDays=the length of the warning window, in days | Cycle, AsOf
AsOf | Fixes the moment the watch judges against, so a test does not depend on the clock; 0 returns to the engine clock. | the watch itself, so calls chain | pnEpoch=the moment as epoch seconds, 0 for the engine clock | Cycle, WarnWithinDays
Cycle | Writes one security-ledger event for each secret whose state changed since the last run, and answers how many it wrote. | a number: 0 when nothing changed | | Watch, WarnWithinDays, AsOf | a secret with no expiry date, or of a kind that has none, is never judged; the state changes are expiring then expired, and the second cycle on an unchanged store writes nothing | an expiring secret goes in the ledger as secret.expiring, a lapsed one as secret.expired, by the secret's name and never its value; a renewed secret is forgotten, so its next lapse is announced afresh
