# Wave 7, stzProgram (39 roots). Every method was called once on education/program (and on the bank and university overlays, and a scratch overlay in the session scratchpad).
init | Opens the learning program stored in a folder, reading its program.zknw manifest. | nothing; the object is built | pcFolder=the program's folder, with or without a trailing slash; a backslash is read as / | CourseQ, WithOverlay | raises an error, Not a learning program, when the folder holds no program.zknw | a program is a folder: its courses, skills, levels, worlds and projects are read from it on demand
Core | Returns the program's own folder, with slashes forward and none at the end. | a text, such as education/program | | Name, Overlay
Name | Returns the last segment of the program's folder, the short name it is called by. | a text, such as program | | Id, Core
Id | Returns the identifier the manifest gives the program, the subject of its `is-a program` fact. | a text, such as softanza-education; an empty text when the manifest has no such fact | | Name, Courses
Languages | Returns the codes of the languages the program speaks, in the order its manifest lists them. | a list of text, such as [ "en", "fr", "ar", "ha" ] | | ReviewCoverage, SourceLanguage | | en is the source edition; fr, ar and ha are draft translations, 0 of 35 units of each reviewed by a person when this was written (ReviewCoverage gives the live figure)
Courses | Returns the slugs of the courses the manifest declares, in the order it lists them. | a list of text, such as [ "elementary-introduction", "zindara-missions", "governed-agents", "math" ] | | CourseQ, Languages | | a slug is the name of the course's folder under courses/; CourseQ takes it
WithOverlay | Lays an institution's overlay folder over the program, so each of its files is read before the core's. | nothing; use WithOverlayQ to chain | pcFolder=the overlay's folder, which must hold an overlay.zknw | WithoutOverlay, OverlayReport, FileFor | raises an error, Not an overlay, when the folder holds no overlay.zknw; an overlay set after CourseQ does not reach that course, because the course holds a copy of the program | an overlay shadows core files one by one and never writes into the core; the two overlays shipped, bank and university, are references: no institution has adopted the system
WithoutOverlay | Takes the overlay off, so every file is read from the core again. | nothing; use WithoutOverlayQ to chain | | WithOverlay, HasOverlay | | a course opened while the overlay was on keeps its own copy of the program, overlay included
Overlay | Returns the folder of the overlay laid over the program. | a text; an empty text when no overlay is laid on | | HasOverlay, WithOverlay
HasOverlay | TRUE if an overlay is laid over the program. | TRUE or FALSE | | Overlay, WithOverlay
OverlayReport | Returns every file an institution's folder brings, each paired with whether it adds, shadows or merges into a core file. | a list of [ path, "adds" ], [ path, "shadows" ] or [ path, "merges" ] pairs; [ ] when no overlay is laid on | | WithOverlay, FileFor | | merges is for a course.zknw or a reviews/ file that the core has too, so an institution never hides a core course or who signed a core page off; the bank overlay shadows only worlds/workplace.zknw
FileFor | Returns the path of a file of the program, the overlay's copy first and the core's after. | a text; an empty text when neither has the file | pcRel=the file's path inside the program, such as worlds/school.zknw | FolderFor, WorldFile, WithOverlay | | the lookup is file by file, so an overlay can replace one world and leave the rest
FolderFor | Returns the path of a folder of the program, the overlay's first and the core's after. | a text; an empty text when neither has it | pcRel=the folder's path inside the program, such as skills | FileFor, WithOverlay
WorldFile | Returns the path of the world file that chapters of a role reason over. | a text; an empty text when no world of that role exists | pcRole=the role a chapter names with uses-world, such as workplace | WithWorld, WorldIds, FileFor | | the order is fixed: an overlay that ships worlds/<role>.zknw wins, whatever the learner chose, then the world chosen with WithWorld, then the core's file of that role
WorldIds | Returns the names of the worlds the program and its overlay ship, sorted. | a list of text, such as [ "cooperative", "school", "workplace" ] | | WithWorld, WorldsWithPages
WithWorld | Chooses the teaching world a learner's chapters reason over, and refuses a world the program does not ship. | nothing; use WithWorldQ to chain | pcName=the world's name, one of WorldIds | World, WorldIds, WorldFile | raises an error naming the worlds the program ships, never quietly the default; an overlay that ships the role's own world file still wins over the chosen one | set it before CourseQ: a course holds a copy of the program
World | Returns the world a learner chose. | a text; an empty text when none was chosen | | WithWorld, HasWorld
HasWorld | TRUE if a learner has chosen a world with WithWorld. | TRUE or FALSE | | World, WithWorld
SourceLanguage | Returns the language the course is written in, the one that is never reviewed as a translation. | a text, en | | ReviewUnits, ReviewCoverage | | English is the source edition: only the translations are drafts until a native speaker has signed them off
ReviewUnits | Returns the names of every unit a native reviewer can sign off in a language, in course order. | a list of text; [ ] for the source language | pcLang=the language code, such as fr, ar or ha | ReviewCoverage, ReviewersOf, UnknownReviews | | a unit is a chapter with its exercises (chapter:<course>.<id>), a world page (world:<name>), the skills (skills) or the tutor's texts (tutor); fr, ar and ha each have 35 today, all drafts: 0 of 35 reviewed by a person
ReviewFacts | Returns the recorded sign-offs of a language, as [ reviewer, "reviewed", unit ] facts. | a list of three-word facts; [ ] when no file exists | pcLang=the language code | ReviewersOf, ReviewUnits | | they are read from reviews/<lang>.zknw in the core and in the overlay, merged, so an institution that reviews its own pages never hides who signed a core page off
ReviewersOf | Returns the names of the people who have signed a unit off in a language. | a list of text; [ ] when nobody has signed it | pcLang=the language code; pcUnit=the unit name, such as chapter:elementary-introduction.find-then-apply, compared without regard to case | IsReviewed, ReviewUnits | | no sign-off is recorded in the shipped program: the translations are drafts
IsReviewed | TRUE if at least one person has signed a unit off in a language. | TRUE or FALSE | pcLang=the language code; pcUnit=the unit name, as ReviewUnits names it | ReviewersOf, ReviewCoverage
ReviewCoverage | Returns how many units of a language a native speaker has signed off, and how many it has in all. | a list of two numbers, [ reviewed, total ] | pcLang=the language code | ReviewUnits, IsReviewed | | fr, ar and ha read [ 0, 35 ] today: the translations are drafts; the source language reads [ 0, 0 ]
UnknownReviews | Returns the units a sign-off names that are not units of the language, so a typo is reported, not ignored. | a list of text; [ ] when every sign-off names a real unit | pcLang=the language code | ReviewFacts, ReviewUnits
WorldPageFile | Returns the path of a teaching world's page in a language, the overlay's edition first. | a text; an empty text when that edition does not exist | pcWorld=the world's name; pcLang=the language code | WorldPageQ, WorldsWithPages
WorldPageQ | Opens a world's page in a language as a chapter, and refuses a missing edition instead of falling back to English. | a stzChapter | pcWorld=the world's name; pcLang=the language code | WorldPageFile, RunWorldPageQ | raises an error, World has no page in that language, for a missing edition | the page is the world itself, questioned, in the chapter format; the fr, ar and ha pages are draft translations
WorldsWithPages | Returns the worlds that have a page in at least one of the program's languages. | a list of text, such as [ "cooperative", "school", "workplace" ] | | WorldIds, WorldPageFile
RunWorldPageQ | Runs every cell of a world's page in one fresh process over that world, then observes where each cell can run. | a stzChapter, run and observed | pcWorld=the world's name; pcLang=the language code | RunWorldPageInQ, WorldPageQ | raises an error when the Ring executable path contains a space (EDU-RUNPATH-01); raises for a missing edition | the cells run on the desktop only, not in a browser; the school page in en took 4.5 s here
RunWorldPageInQ | Runs a world's page in several languages, each in its own fresh process, and observes where each cell can run. | a list of stzChapter, one per language, in the order asked | pcWorld=the world's name; pacLangs=the language codes, such as [ "en", "fr" ] | RunWorldPageQ, WorldPageQ | raises for a language with no page; raises when the Ring executable path contains a space | the cells run on the desktop only, not in a browser; the processes run side by side, up to four at a time
CourseQ | Opens a course of the program by its slug. | a stzCourse | pcSlug=the course's slug, one of Courses | Courses, WithOverlay | raises an error, No course in the program, for a slug whose folder has no course.zknw | the course holds a COPY of the program as it is now: lay the overlay and choose the world before taking the course
SkillIds | Returns the ids of the skills the core and the overlay bring, sorted. | a list of text, such as [ "cr-01", "cr-02" ] | | SkillQ, LevelIds
SkillQ | Opens a skill by its id, taking the overlay's file over the core's when both exist. | a stzSkill | pcId=the skill's id, one of SkillIds | SkillIds | raises an error, No skill under the skills folder, for an id with no file
LevelFacts | Returns the facts of levels.zknw as [ subject, relation, object ] triples. | a list of three-word facts; [ ] when the program has no levels file | | LevelIds, LevelFact
LevelIds | Returns the ids of the levels, lowest rank first. | a list of text, such as [ "s0", "s1", "s2", "s3", "s4" ] | | LevelFact, ChaptersForLevel
LevelFact | Returns the first object a level has for a relation, such as its name or the chapters it needs. | a text; an empty text when the level has none | pcLevel=the level's id, such as s1; pcRelation=the relation to read, such as named, rank or needs-chapters-through | LevelIds, LevelFacts
ProjectQ | Opens the project folder that earns a level, by its id. | a stzProject | pcId=the project's id, such as project-s0, compared in lower case | ProjectIds | raises an error, No project in the program, for an id with no folder
ChaptersForLevel | Returns the first chapters of a course that a level requires, as many as its needs-chapters-through fact says. | a list of text; [ ] when the level is unknown | poCourse=the stzCourse whose chapters are counted; pcLevel=the level's id, such as s0 | LevelFact, ProjectIds
ProjectIds | Returns the ids of the projects that the levels are earned by, in the order levels.zknw lists them. | a list of text, such as [ "project-s0", "project-s1" ] | | ProjectQ, LevelIds
