Save | Stores bytes under an object key, replacing the object when the key already exists, as an S3 PUT does. | 1 (TRUE), always | pcKey=the object key, any text up to 1024 bytes, such as "photos/2026/a.jpg"; pcBytes=the content to store, as text, binary included | Fetch, Exists, Remove, SaveFile | an empty key and a key over 1024 bytes raise an error | SaveQ is the same call and returns the store; the key is never used as a file name: the file is named by the SHA-256 of the key, so "photo.jpg" and "Photo.JPG" stay two objects and "../x" cannot leave the folder; the real key is kept in a .key file beside the .blob file
Fetch | Returns the bytes stored under a key. | a text; the empty text when the key is absent, which Exists tells apart from a stored empty object | pcKey=the object key to read | Exists, Size, FetchToFile | an empty key raises an error | an object stored empty and a missing one both give the empty text
Exists | TRUE if an object is stored under the key. | TRUE or FALSE | pcKey=the object key to look for | Fetch, Size | an empty key raises an error | keys are compared exactly, case included
Remove | Deletes the object stored under a key; deleting an absent key also succeeds, as an S3 DELETE does. | 1 (TRUE), always | pcKey=the object key to delete | Clear, Exists | an empty key raises an error | RemoveQ returns the store so calls chain
Size | Returns the number of bytes stored under a key. | a number; 0 when the key is absent | pcKey=the object key to measure | Fetch, TotalBytes | an empty key raises an error | an absent object and an empty one both give 0
Keys | Returns the real keys of every stored object, read back from the .key files. | a list of text, in the order the folder lists its files (not sorted, not the order saved) | | KeysWithPrefix, NumberOfBlobs | | a real store pages a long listing; this one returns everything in one call
KeysWithPrefix | Returns the keys that begin with a prefix, the way an S3 listing by prefix does. | a list of text; [ ] when none matches | pcPrefix=the beginning the keys must have, compared with case | Keys | | order is the folder's, as for Keys
NumberOfBlobs | Returns how many objects the store holds. | a number | | Keys, IsEmpty
IsEmpty | TRUE if the store holds no object. | TRUE or FALSE | | NumberOfBlobs
TotalBytes | Returns the sum of the sizes of all stored objects, in bytes. | a number | | Size, NumberOfBlobs
SaveFile | Stores the content of an existing file under a key. | 1 (TRUE) | pcKey=the object key to store under; pcPath=the file to read | Save, FetchToFile | a path that does not exist raises an error naming it | the whole file passes through memory, in spite of the name
