init | Builds a two-way table whose need for a change of scale is to be measured. | nothing; the object is built | paRows=the table as a list of rows, each a list of numbers; an empty table or a first row that is not a list raises an error | Ladder, Recommend
Threshold | Returns the measured limit that the slope at power 1 must pass for a re-expression to be recommended. | a number, 0.5 | | Recommend
NonAdditivity | Returns the slope of the residuals on the comparison values of the table as it stands, and the power it suggests. | a hash list with the keys slope, intercept, power and ok | | Ladder, Recommend | | a table of 1, 2, 4 / 2, 4, 8 / 4, 8, 16 / 8, 16, 32, a product of a row and a column factor, gives slope 1 and power 0
Ladder | Returns every rung of the ladder of powers, from -1 to 2, with the slope and the residual scale found after raising the table to it. | a list of rows [ power, slope, residual scale, ok ]; ok is 0 for a rung that cannot be taken | | Rung, LadderTable, Recommend | the engine is crossed once and the answer kept | for the product table above the log rung, power 0, has slope 0 and residual scale 0
Rung | Returns one row of the ladder. | a list [ power, slope, residual scale, ok ] | pnPower=one of -1, -0.5, 0, 0.5, 1 or 2; any other value raises an error | Ladder, Recommend
Recommend | Returns the verdict on the table: the power with the flattest slope when the slope at power 1 passes the threshold, else leave it as it is. | a hash list with the keys power, name, slope, fires and evidence | | Ladder, Threshold, Diagnostics | when the table holds a zero the negative powers and the log cannot be taken, and the verdict can come out as fires 1 with power 1, as is, which says to re-express and to leave it at once; seen on two tables | the product table gives power 0, log, fires 1; an additive table 1, 2, 3 / 2, 3, 4 / 3, 4, 5 / 4, 5, 6 gives power 1, fires 0
LadderTable | Returns the ladder as a text table with one line per rung, a star on the recommended one and the evidence beneath. | a text of several lines | | Ladder, Recommend
Diagnostics | Returns a warning when the table is not additive enough, with the evidence and the power to try. | a list of rows [ :rule, :subject, :where, :severity, :message ]; empty when the table is left as it is | pcSubject=what the table is called in the rows; an empty text gives table | Recommend, StzTukeyReportQ | | the rule is non_additive
Why | Returns one sentence on the table's size and the evidence for or against a re-expression. | a text | | Recommend
