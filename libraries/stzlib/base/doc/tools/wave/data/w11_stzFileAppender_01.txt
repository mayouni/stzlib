Write | Adds a text at the end of the file, with no line break. | 1 | cText=the text to add | WriteLine, WriteLines | warning: a number as argument ends the whole Ring process silently with exit code 1, checked with 5 and 1.5; a list or the empty text does not | pass a text; use "" + n for a number
