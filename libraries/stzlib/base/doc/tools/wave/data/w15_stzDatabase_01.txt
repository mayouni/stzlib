init | Opens a SQLite database, a file path or :memory: for a store that lives only in this process, and raises if it can not be opened. | nothing; the object is built | pcPath=the database file, or :memory: | Path, IsOpen, Close
Path | Returns the path the database was opened with. | a text such as :memory: | | IsOpen
IsOpen | TRUE if the database handle is still open, which Close ends. | 1 or 0, numbers | | Close, Path
Why | Returns the text of the last error that a failed call recorded, such as the table that was not found. | a text; empty before any error | | Exec, Rows | | after a failed Exec the text is the engine's bare message, after a failed query or bound call it starts with sql error:
Exec | Runs one DDL or DML statement and returns how many rows it changed; raises on a SQL error. | a number, 0 for a CREATE | pcSql=the statement text, with its values written in | ExecWith, Rows, Why | raises SQL error: with the engine's message, for a malformed statement and on a closed database | values spliced into the text are the caller's to escape; use ExecWith to bind them
Rows | Returns the rows of a query, each as a list of cells that are all text, NULL being an empty text. | a list of rows; [ ] when the query matches nothing | pcSql=the SELECT text | RowsWith, TypedRowsWith, Value | raises on a malformed query and on one that fails partway; a tab or a line break in a value stays inside its cell | a REAL cell reads 9.5 or 10.0, as SQLite writes it
Value | Returns the first cell of the first row of a query, an empty text when there is none. | a text | pcSql=the SELECT text | ValueWith, Rows
ExecWith | Runs one statement whose ? marks are bound to the given values and returns how many rows it changed. | a number | pcSql=the statement with ? marks; paParams=the values in order: a text binds as TEXT, a whole number as INTEGER, any other number as REAL | Exec, RowsWith | raises when the count of values does not fit, with a message that always says the statement has -1 parameters, whatever its real count | no value can change what the statement says, and none needs escaping
RowsWith | Returns the rows of a query whose ? marks are bound to the given values, every cell as text. | a list of rows of text cells | pcSql=the SELECT text with ? marks; paParams=the values in order, as for ExecWith | TypedRowsWith, ValueWith, Rows | raises on a count mismatch with the same -1 message as ExecWith | a value such as x' OR '1'='1 matches nothing, being data
TypedRowsWith | Returns the rows of a bound query with INTEGER and REAL cells as Ring numbers and TEXT and NULL cells as text. | a list of rows | pcSql=the SELECT text with ? marks; paParams=the values in order | RowsWith, Rows | | a NULL still comes back as an empty text, not as a number
ValueWith | Returns the first cell of the first row of a bound query, an empty text when there is none. | a text | pcSql=the SELECT text with ? marks; paParams=the values in order | Value, RowsWith
Begin | Starts a transaction and takes the write lock at once, so a busy database refuses here. | the database itself, so calls chain | | Commit, Rollback | raises when a transaction is already open and on a closed database, with the engine's reason | one transaction at a time; there is no nesting
Commit | Makes the changes of the open transaction permanent. | the database itself, so calls chain | | Begin, Rollback | raises when no transaction is active
Rollback | Undoes the changes of the open transaction. | the database itself, so calls chain | | Begin, Commit
LastInsertId | Returns the rowid of the last row inserted on this connection. | a number; 0 on a closed database | | ExecWith, Exec
Close | Closes the database; closing twice is harmless. | the database itself, so calls chain | | IsOpen, init | after Close every query raises no such database handle
