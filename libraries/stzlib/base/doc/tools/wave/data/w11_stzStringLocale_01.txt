init | Builds a locale-aware view of a text, given as plain text or as a stzString. | nothing; the object is built | pStrOrStzStrObj=the text, or a stzString object whose content is used; any other type raises an error | Content, ScriptName
Content | Returns the text the object holds. | a text | | NumberOfChars, IsEmpty
NumberOfChars | Returns how many characters the text has, counted in Unicode characters and not in bytes. | a number | | Content, IsEmpty | | a text of Hebrew or Arabic letters counts one per letter
IsEmpty | TRUE if the text has no character at all. | TRUE or FALSE | | NumberOfChars, ContainsOnlyWhitespace
LowercasedInLocale | Returns the text in lower case by the rules of a locale, so Turkish dotted and dotless i are handled. | a text; the object itself is not changed | pcLocale=a locale code such as tr_TR, en_US or de_DE | UppercasedInLocale, LocaleCompare | | in tr_TR the capital I becomes the dotless i, and in en_US the capital dotted I becomes i followed by a combining dot
UppercasedInLocale | Returns the text in upper case by the rules of a locale, so Turkish dotted and dotless i are handled. | a text; the object itself is not changed | pcLocale=a locale code such as tr_TR, en_US or de_DE | LowercasedInLocale | | in tr_TR the small i becomes the dotted capital I; in en_US it becomes I
DetectScript | Returns a number naming the writing system the text is written in. | a number: 0 unknown, 1 Latin, 2 Arabic, 3 Hebrew, 4 Cyrillic, 5 Greek, 6 CJK, 7 Devanagari, 8 Thai, 99 mixed | | ScriptName, ScriptCount | | digits, spaces and punctuation do not vote; a text made only of them answers 0
ScriptName | Returns the name of the writing system the text is written in. | a text: Latin, Arabic, Hebrew, Cyrillic, Greek, CJK, Devanagari, Thai, Mixed or Unknown | | DetectScript, IsMixedScript | | a text of digits, spaces or nothing answers Unknown
ScriptCount | Returns how many scripts the text uses, counting the common one that holds digits, spaces and punctuation. | a number | | ScriptCountExcludingCommon, IsMixedScript | | hello 123 gives 2, because Latin and common are both counted; an empty text gives 0
ScriptCountExcludingCommon | Returns how many real writing systems the text uses, leaving out digits, spaces and punctuation. | a number | | ScriptCount, IsMixedScript | | a text of digits only gives 0
IsMixedScript | TRUE if the text mixes two or more writing systems, such as Latin with Hebrew; digits and spaces do not count. | TRUE or FALSE | | ScriptCountExcludingCommon, ScriptName | | hello 123 is not mixed; a Latin word next to a Hebrew word is
IsLatinScript | TRUE if the text is written in Latin letters. | TRUE or FALSE | | ScriptName, ContainsOnlyLatinLetters | | hello 123 is Latin; a Latin word next to a Hebrew word is neither
IsArabicScript | TRUE if the text is written in Arabic letters. | TRUE or FALSE | | ScriptName, ContainsArabicLetters
IsHebrewScript | TRUE if the text is written in Hebrew letters. | TRUE or FALSE | | ScriptName, IsRightToLeft | | the script test is right for Hebrew, but the direction tests are not: see IsRightToLeft
IsCyrillicScript | TRUE if the text is written in Cyrillic letters. | TRUE or FALSE | | ScriptName, IsGreekScript
IsGreekScript | TRUE if the text is written in Greek letters. | TRUE or FALSE | | ScriptName, IsCyrillicScript
IsCJKScript | TRUE if the text is written in Chinese, Japanese or Korean ideographs. | TRUE or FALSE | | ScriptName
IsDevanagariScript | TRUE if the text is written in the Devanagari script, used for Hindi and Sanskrit. | TRUE or FALSE | | ScriptName
IsThaiScript | TRUE if the text is written in Thai letters. | TRUE or FALSE | | ScriptName
DetectDirection | Returns a number naming the reading direction of the text. | a number: 0 left to right, 1 right to left, 2 mixed, 3 neutral | | DirectionName, IsRightToLeft | Hebrew letters are not seen as right to left: a Hebrew text answers 3, neutral, and a Hebrew word next to a Latin one answers 0; Arabic, Syriac and Thaana answer 1 | digits and punctuation do not vote; a text of them answers 3
DirectionName | Returns the reading direction of the text as a name. | a text: LTR, RTL, Mixed or Neutral | | DetectDirection, IsLeftToRight | Hebrew letters are not seen as right to left: a Hebrew text answers Neutral | a text with no letter answers Neutral
IsRightToLeft | TRUE if the text reads from right to left, as Arabic does. | TRUE or FALSE | | DetectDirection, HasRTL | answers FALSE for Hebrew text today, as the direction is Neutral for it; it answers TRUE for Arabic, Syriac and Thaana; a text mixing Arabic and Latin is Mixed and answers FALSE | IsRTL is the same call
IsLeftToRight | TRUE if the text reads from left to right, as Latin does. | TRUE or FALSE | | DetectDirection, IsRightToLeft | a Hebrew text answers FALSE here because it is read as Neutral; a Hebrew word next to a Latin word answers TRUE | IsLTR is the same call
HasRTL | TRUE if the text contains at least one right-to-left letter. | TRUE or FALSE | | IsRightToLeft, IsBidiMixed | answers FALSE for Hebrew text today; it answers TRUE for Arabic, Syriac and Thaana, alone or next to Latin letters
IsBidiMixed | TRUE if the text mixes left-to-right and right-to-left letters, so a bidirectional display is needed. | TRUE or FALSE | | DetectDirection, HasRTL | Latin next to Hebrew answers FALSE, as the Hebrew is not counted; Latin next to Arabic answers TRUE | digits and punctuation do not make a text mixed
IsBidiNeutral | TRUE if the text has no letter that gives it a direction, as a text of digits or punctuation. | TRUE or FALSE | | DetectDirection, IsBidiMixed | answers TRUE for a Hebrew text today, because Hebrew letters are not counted as directional | an empty text is neutral
LocaleCompare | Compares the text with another, ignoring case, and returns -1, 0 or 1. | a number: -1 if the text comes first, 0 if equal, 1 if it comes after | pcOther=the text to compare with | LocaleEquals, LocaleLessThan, LocaleGreaterThan | behaves as an order of characters that ignores case, not as the collation of a language: a with a diaeresis, or an accented e, sorts after z; the digits compare as text, so 10 comes before 9 | apple and Apple are equal; Hebrew letters follow their alphabet
LocaleEquals | TRUE if the text is equal to another when case is ignored. | TRUE or FALSE | pcOther=the text to compare with | LocaleCompare | | apple equals Apple; apple does not equal banana
LocaleLessThan | TRUE if the text sorts before another, ignoring case. | TRUE or FALSE | pcOther=the text to compare with | LocaleCompare, LocaleGreaterThan | | apple comes before banana
LocaleGreaterThan | TRUE if the text sorts after another, ignoring case. | TRUE or FALSE | pcOther=the text to compare with | LocaleCompare, LocaleLessThan | | apple comes after Aardvark
ContainsLatinLetters | TRUE if the text has at least one Latin letter, accented or not. | TRUE or FALSE | | ContainsArabicLetters, ContainsOnlyLatinLetters
ContainsArabicLetters | TRUE if the text has at least one Arabic letter. | TRUE or FALSE | | ContainsLatinLetters, IsArabicScript
ContainsDigits | TRUE if the text has at least one digit. | TRUE or FALSE | | ContainsOnlyDigits
ContainsOnlyDigits | TRUE if every character of the text is a digit; an empty text answers FALSE. | TRUE or FALSE | | ContainsDigits | | 12.5 is not only digits, because of the point
ContainsOnlyLetters | TRUE if every character is a letter of any script; digits, spaces and punctuation make it FALSE. | TRUE or FALSE | | ContainsOnlyLatinLetters | | an empty text answers FALSE
ContainsOnlyLatinLetters | TRUE if every character is a Latin letter, accented letters included. | TRUE or FALSE | | ContainsOnlyLetters, IsAscii | | an accented Latin word is TRUE; an Arabic word is FALSE
IsAscii | TRUE if every character is in the 7-bit ASCII range; an empty text answers TRUE. | TRUE or FALSE | | ContainsOnlyLatinLetters | | an accented letter makes it FALSE
ContainsPunctuation | TRUE if the text has at least one punctuation mark. | TRUE or FALSE | | ContainsWhitespace | | the point of 12.5 counts
ContainsWhitespace | TRUE if the text has at least one space. | TRUE or FALSE | | ContainsOnlyWhitespace, ContainsPunctuation
ContainsOnlyWhitespace | TRUE if the text is made of spaces only; an empty text answers FALSE. | TRUE or FALSE | | ContainsWhitespace, IsEmpty
