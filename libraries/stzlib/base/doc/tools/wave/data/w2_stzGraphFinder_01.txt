init | Builds a finder over the nodes or the edges of a graph, with no filter yet; any target other than nodes or edges finds nothing. | nothing; the object is built | _oGraph_=the stzGraph to search; _cTarget_=what to search, "nodes" or "edges", case ignored | Run | | stzGraph.FindQ builds one for you
Where | Adds a filter that keeps the elements whose key meets a comparison with the value, and returns the finder so calls chain. | the finder itself | pcKey=the key to test: id, label, from, to or a property name, with dots for nested values; pCondition=the comparison: "=", ">", "<", "contains", "between" or the :equals, :greaterthan, :lessthan, :insection forms; pValue=the value to compare with, or a pair [ low, high ] for between | Having, WithProperty, Run | | filters accumulate, and an element must pass all of them; an unknown comparison matches nothing
Having | Adds a filter that keeps the elements whose key equals the value, and returns the finder so calls chain. | the finder itself | pcKey=the key to test, such as a property name; pValue=the value it must equal | Where, WithProperty, Run | | a key that the element does not have fails the filter
WithProperty | Adds a filter that keeps the elements that carry the given property, and returns the finder so calls chain. | the finder itself | pcKey=the property name that must be present | Having, Where, Run
WithTag | Adds a filter that keeps the elements whose :tags property lists the tag, and returns the finder so calls chain. | the finder itself | | WithProperty, Where, Run | | the tags must be a list stored in a property called tags
Run | Applies the filters and returns the matches: node ids for a node search, [ from, to ] pairs for an edge search. | a list of ids or of [ from, to ] pairs | | Where, Having | | the filters stay in the finder, so a filter added after one Run narrows the next Run
