init | Loads a sound from an audio file, or builds an empty sound that holds nothing when the path is empty. | nothing; the object is built | pcPath=the file to decode, or an empty text for an empty sound | MakeSilence, StzSoundQ | a missing or undecodable file leaves the sound empty and sets LastError instead of raising; a library without the sound engine does the same | the sample rate and channel count are those of the file
MakeSilence | Replaces whatever the sound holds with a buffer of silence of the given length, channels and rate. | nothing; use MakeSilenceQ to chain | pnSeconds=the length in seconds, rounded down to whole frames; pnChannels=the number of channels, 1 for mono and 2 for stereo; pnRate=the sample rate in hertz | StzSoundOfSilenceQ, Release | the old buffer is freed first | the rate is kept in the buffer and travels into SaveAs files
AdoptBuffer | Makes the sound hold a sample buffer that the engine already owns, freeing the buffer held before. | nothing | pnBufferId=the engine's id of the buffer to adopt | BufferId, StzSoundFromBufferQ | the sound then owns the id, so freeing it twice is the caller's fault
BufferId | Returns the engine's id of the held sample buffer, to hand to a graph or a mixer. | a number; 0 when the sound holds nothing | | AdoptBuffer, Release
Release | Frees the held sample buffer and leaves the sound empty. | nothing | | IsEmpty, MakeSilence | calling it again on the empty sound does nothing
IsEmpty | TRUE if the sound holds no buffer or a buffer of no frames. | TRUE or FALSE | | Frames, Release
LastError | Returns the text of the last failure the sound recorded, or an empty text. | a text | | init, SaveAs | an error stays until the next failure replaces it; a success does not clear it
Frames | Returns how many frames, one sample per channel each, the sound holds. | a number; 0 for an empty sound | | Duration, SampleRate
Channels | Returns the number of channels the sound holds. | a number; 0 for an empty sound | | ChangeChannelsTo, ToMono
SampleRate | Returns the sample rate of the held buffer, in hertz. | a number; 0 for an empty sound | | ResampleTo, Duration | the rate is read from the buffer, not guessed from a file name
Duration | Returns the length of the sound in seconds, from its frames and its rate. | a number of seconds; 0 for an empty sound | | Frames, SampleRate
Peak | Returns the largest absolute sample value across all channels, 1 being full scale. | a number from 0 to 1 or more; 0 for an empty sound | | Rms, Loudness
Rms | Returns the root-mean-square level of the samples, a measure of average strength. | a number; 0 for an empty sound | | Peak, Loudness
SampleAt | Returns one sample value, by 1-based frame and channel. | a number between -1 and 1; 0 for an empty sound | pnFrame=the frame to read, counted from 1; pnChannel=the channel to read, counted from 1 | SetSampleAt, ToList
SetSampleAt | Writes one sample value at a 1-based frame and channel. | nothing; use SetSampleAtQ to chain | pnFrame=the frame to write, counted from 1; pnChannel=the channel to write, counted from 1; pnValue=the sample value, between -1 and 1 | SampleAt | an empty sound ignores the call
ToList | Returns the samples of one channel as a list of numbers, one per frame. | a list of numbers; [ ] for an empty sound | pnChannel=the channel to read, counted from 1 | SampleAt, ToSpectrum | one engine call per sample: fine for a few thousand frames, slow for a whole song
ResampleTo | Converts the sound in place to a new sample rate with the high-quality sinc method. | nothing; use ResampleToQ to chain | pnRate=the new sample rate in hertz | ResampleToFast, SampleRate | the frame count changes in proportion to the rate, and the old buffer is freed | a failure sets LastError and keeps the old buffer
ResampleToFast | Converts the sound in place to a new sample rate with the cheaper linear method. | nothing; use ResampleToFastQ to chain | pnRate=the new sample rate in hertz | ResampleTo, SampleRate | less accurate than ResampleTo | the frame count changes in proportion to the rate
ChangeChannelsTo | Converts the sound in place to the given number of channels. | nothing; use ChangeChannelsToQ to chain | pnChannels=the number of channels wanted | ToMono, ToStereo | the old buffer is freed | the engine also accepts counts above 2 and builds them without complaint
ToMono | Converts the sound in place to one channel. | nothing; use ToMonoQ to chain | | ToStereo, ChangeChannelsTo
ToStereo | Converts the sound in place to two channels. | nothing; use ToStereoQ to chain | | ToMono, ChangeChannelsTo
ToWavBytes | Returns the whole sound encoded as a 16-bit WAV file, held in memory. | a text of bytes starting with RIFF; an empty text for an empty sound | | SaveAs, init | no file is written
MixIn | Adds another sound into this one, starting at a time offset and scaled by a gain. | the sound itself, so calls chain | poSound=the sound to add; pnSeconds=the time in this sound where the other starts, in seconds; pnGain=the factor the added samples are multiplied by | StzSoundOfSilenceQ | refused, with LastError set, when the two sample rates differ, since the note would change pitch; an empty receiver or a non-object argument is ignored
SaveAs | Writes the sound to a WAV file with 16-bit samples. | nothing; use SaveAsQ to chain | pcPath=the file to write, overwritten | SaveAsFloat, ToWavBytes | the rate and channel count are stored in the file | a failure sets LastError
SaveAsFloat | Writes the sound to a WAV file with 32-bit float samples, for handing to another stage. | nothing; use SaveAsFloatQ to chain | pcPath=the file to write, overwritten | SaveAs | the file is twice the size of the 16-bit one
Play | Plays the sound on the default audio device and waits until it has ended, plus a quarter second. | nothing | | PlayFor, SaveAs | not run in this reference: it opens an audio device; with no device tier or no device it sets LastError and returns silently | it builds a one-node graph, so for background play use a stzSoundGraph
PlayFor | Plays the sound on the default audio device for a stated time, then closes the device. | nothing; use PlayForQ to chain | pnSeconds=how long to keep the device open, in seconds | Play | not run in this reference: it opens an audio device; with no device it sets LastError and returns silently | a time shorter than the sound cuts it off
ToSpectrum | Returns the magnitude spectrum of the first 4096 frames of channel 1 as a grid of numbers. | a stzSoundGrid of 1 row and 2049 columns; an empty text for an empty sound | | ToSpectrumOf, DominantFrequency
ToSpectrumOf | Returns the magnitude spectrum of one window of one channel as a grid of numbers. | a stzSoundGrid of 1 row and pnFftSize / 2 + 1 columns; an empty text when the window cannot be taken | pnChannel=the channel to analyse, counted from 1; pnStartFrame=the first frame of the window, counted from 1; pnFftSize=the window length in frames | ToSpectrum, ToSpectrogramOf | a failure sets LastError
ToSpectrogram | Returns frequency against time for channel 1, one grid row per 2048-frame window moving 512 frames. | a stzSoundGrid with one row per window and 1025 columns; an empty text for an empty sound | | ToSpectrogramOf, ToSpectrum | uses 4 threads
ToSpectrogramOf | Returns frequency against time for one channel, one grid row per window, with the window, hop and thread count chosen. | a stzSoundGrid with one row per window and pnFftSize / 2 + 1 columns; an empty text on failure | pnChannel=the channel to analyse, counted from 1; pnFftSize=the window length in frames; pnHop=the frames between two window starts; pnThreads=how many threads share the windows | ToSpectrogram | a failure sets LastError
DominantFrequency | Returns the strongest frequency present in channel 1, in hertz, from an 8192-frame window. | a number of hertz; -1 for an empty sound | | ToSpectrum | the answer is the centre of a bin about 6 Hz wide, so a 440 Hz sine reads 439.45 or 440.43
ToOnsets | Returns the times at which notes start in channel 1, in seconds, with the default sensitivity of 0.35. | a stzSoundGrid of 1 row, one column per onset; an empty text for an empty sound | | ToOnsetsOf, Tempo
ToOnsetsOf | Returns the times at which notes start in one channel, in seconds, with a chosen sensitivity. | a stzSoundGrid of 1 row, one column per onset; an empty text on failure | pnChannel=the channel to analyse, counted from 1; pnSensitivity=how easily a rise in energy counts as an onset, a larger number accepting fewer rises, so fewer onsets | ToOnsets | a failure sets LastError
Tempo | Returns the speed of the beat in channel 1, in beats per minute. | a number; -1 when there are too few onsets to say, or the sound is empty | | ToOnsets | a pulse of 16 clicks at 0.5 s reads 119.68, not exactly 120
Loudness | Returns the integrated loudness in LUFS, resampling a copy to 48 kHz first when the sound has another rate. | a number of LUFS; -1000 for silence, for an empty sound and for a sound shorter than one 400 ms block | | MomentaryLoudness, LoudnessOfSupport | the caller's sound is not changed
MomentaryLoudness | Returns the loudest 400 ms window of the sound in LUFS, the measure that works for a short cue. | a number of LUFS; -1000 for an empty sound, for silence and for a sound shorter than 400 ms | | Loudness, ShortTermLoudness | resamples a copy to 48 kHz when needed; a 200 ms sound reads -1000, which LoudnessOfSupport measures instead
ShortTermLoudness | Returns the loudest 3 s window of the sound in LUFS. | a number of LUFS; -1000 for an empty sound, silence or a sound shorter than 3 s | | MomentaryLoudness, Loudness | resamples a copy to 48 kHz when needed
LoudnessOfSupport | Returns the K-weighted level over the sound's whole length, which is not a standard LUFS figure. | a number of decibels; -1000 for an empty sound or silence | | LoudnessMetric, MomentaryLoudness | resamples a copy to 48 kHz when needed
