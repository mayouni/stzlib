# w15 stzKnowParser
init | Builds a parser for knowledge files; it keeps no state between parses. | nothing; the object is built | | Parse, ParseFile | | one parser can read any number of texts and files
ParseFile | Reads a .zknw knowledge file from disk and builds the knowledge graph it describes. | a stzKnowledgeGraph; an empty text for a file with no content | pcFilename=the path of the file to read | Parse, ImportKnow | a path that cannot be opened raises error R35 Can't create/open the file; a file with no knowledge header raises error R13 Object is required, as Parse does | the file is read whole and handed to Parse; it does not check the extension
Parse | Reads the text of a knowledge file and builds the knowledge graph it describes. | a stzKnowledgeGraph named by the quoted id in the header; an empty text when the text has no content | pcContent=the text, a header line such as knowledge "name" followed by sections facts, ontology, provenance and contradictions | ParseFile, ExportToKnow | text with facts but no knowledge header raises error R13 Object is required, because the graph is only made when the header is met; a fact line with other than three parts is skipped without a message | blank lines and lines starting with # are ignored; the text of an empty or comment-only file answers an empty text, not a graph
