init | Builds a TOTP generator with a fresh random 160-bit secret and the settings every authenticator app expects: SHA1, 6 digits, 30 seconds. | nothing; the object is built | | Secret, ProvisioningUri, Verify
Generate | Replaces the secret with a fresh random one from the engine's secure generator. | nothing; use GenerateQ to chain | | Secret, SetSecret | | every code made with the old secret stops verifying
SetSecret | Sets the shared secret from the base32 text a user types into an app, ignoring case, spaces and dashes. | nothing; use SetSecretQ to chain | pcBase32=the secret in base32, such as GEZDGNBVGY3TQOJQ | Secret, Generate | | the characters are not checked, so a wrong secret gives an empty code and a verification that always fails
SetDigits | Sets how many digits a code has. | nothing; use SetDigitsQ to chain | pnDigits=the code length, 1 to 9; 6 by default | Digits | raises an error outside 1 to 9 | an authenticator app expects the value in the provisioning address
SetPeriod | Sets how many seconds a code stays valid. | nothing; use SetPeriodQ to chain | pnSeconds=the length of a step, 1 or more; 30 by default | Period | raises an error below 1
SetSkew | Sets how many steps of clock drift, in each direction, Verify tolerates. | nothing; use SetSkewQ to chain | pnSteps=the tolerance in steps, 0 or more; 1 by default | Skew, Verify | raises an error below 0 | with 0 only the current step passes
SetAlgo | Chooses the hash that makes the codes. | nothing; use SetAlgoQ to chain | pnAlgo=1 for SHA1, the default every app supports, or 2 for SHA256 | Algo, AlgorithmName | raises an error for any other number | SHA256 works only with apps that honour the algorithm parameter
Secret | Returns the shared secret in base32, unpadded and in upper case. | a text | | SetSecret, ProvisioningUri | | it is the whole secret: keep it out of logs and screens
Digits | Returns the number of digits in a code. | a number | | SetDigits
Period | Returns the length of a step in seconds. | a number | | SetPeriod
Skew | Returns the number of steps of clock drift Verify tolerates. | a number | | SetSkew
Algo | Returns the hash number: 1 for SHA1, 2 for SHA256. | a number | | SetAlgo, AlgorithmName
AlgorithmName | Returns the name of the hash in use, as the provisioning address spells it. | the text SHA1 or SHA256 | | Algo
ProvisioningUri | Returns the otpauth address that an authenticator app reads, usually from a QR code, with the secret, issuer, algorithm, digits and period. | a text starting with otpauth://totp/ | pcAccount=the account name shown in the app; pcIssuer=the service name shown in the app | Secret, Show | | the account and the issuer are percent-encoded, so quotes, angle brackets and ampersands cannot add parameters; the address holds the secret, so show it once, to its owner
CodeAt | Returns the code valid at an instant, computed in the engine from the secret by RFC 6238. | a text of the configured digits; empty when the secret is empty or invalid | pnUnixSecs=the instant in epoch seconds | Code, VerifyAt | | the RFC 6238 test secret gives 94287082 at second 59 with 8 digits
Code | Returns the code valid now. | a text of the configured digits | | CodeAt, Verify
Verify | TRUE if a submitted code matches the current step or one within the skew. | TRUE or FALSE | pcCode=the code typed by the user | VerifyAt, Code | | the comparison is constant-time; a code is not consumed, so the same code verifies again until its step leaves the window: remember the last accepted step to refuse a reuse
VerifyAt | TRUE if a submitted code matches the step of an instant, or one within the skew; the deterministic form. | TRUE or FALSE | pcCode=the code typed by the user, trimmed; pnUnixSecs=the instant to judge at, in epoch seconds | Verify, CodeAt | | an empty, non-numeric or wrong-length code gives FALSE; the same code verifies repeatedly within the window
Show | Prints one line with the algorithm, digits, period and the shared secret in clear. | nothing; it prints | | ProvisioningUri | the output contains the secret itself | do not call it in a log or a shared terminal
