init | Builds a score, empty or filled from space-separated note names of one beat each. | nothing; the object is built | pcNotes=space-separated note names, ~ for a rest, or an empty text for an empty score | AddNotes, StzSoundScoreOfQ | a name that is not a note is skipped and counted in Refusals | the octave carries from one name to the next
Note | Appends one pitched note after everything already in the score. | the score itself, so calls chain | pNote=a note name such as A4, C#3, Bb2 or D4+50, or a frequency in hertz; pnBeats=the length of the note in beats | NoteAt, AddNotes, Rest | a name or length that is refused leaves the score unchanged, counts in Refusals and sets LastError | the note takes the instrument named by On and the velocity set by SetVelocity
GlideAt | Adds a note whose pitch slides from one pitch to another over its whole length, at an explicit beat. | the score itself, so calls chain | pnBeat=the beat where the glide starts, 0 or later; pFrom=the starting pitch, a note name or a frequency; pTo=the ending pitch, a note name or a frequency; pnBeats=the length of the glide in beats | NoteAt, Note | refused, with LastError set, for a bad pitch, beat or length; a pluck or an FM instrument (guitar, harp) refuses to render a glide, so that note is missing from ToSound | the score length grows to cover the glide
NoteAt | Adds a pitched note at an explicit beat without moving where the next appended note goes. | the score itself, so calls chain | pnBeat=the beat where the note starts, 0 or later; pNote=a note name or a frequency in hertz; pnBeats=the length of the note in beats | Note, StrokeAt | refused, with LastError set, for a bad pitch, beat or length | the score length grows to cover the note
StrokeAt | Adds a drum stroke at an explicit beat without moving where the next appended note goes. | the score itself, so calls chain | pnBeat=the beat where the stroke starts, 0 or later; pStroke=the stroke name: dum, tak, ka, kick, snare, hihat, hat, crash, ride, hightom, midtom, floortom or openhat; pnBeats=the length of the stroke in beats | Stroke, NoteAt | an unknown stroke name is refused, with LastError set | the stroke's pitch is 0, so the drum instrument decides it
SetLength | Sets the length of the score in beats outright, whatever its last note does. | the score itself, so calls chain | pnBeats=the new length in beats, 0 or more | Beats, Rest | a negative or non-numeric value is ignored without a refusal | it can shorten the score below its last note
Rest | Adds silence of the given length after everything already in the score. | the score itself, so calls chain | pnBeats=the length of the silence in beats | Note, SetLength | a length that is not positive is refused, with LastError set
Stroke | Appends one drum stroke after everything already in the score. | the score itself, so calls chain | pStroke=the stroke name: dum, tak, ka, kick, snare, hihat, hat, crash, ride, hightom, midtom, floortom or openhat; pnBeats=the length of the stroke in beats | StrokeAt, On | an unknown stroke name is refused, with LastError set | which drum strikes it is decided by the instrument named in On
AddNotes | Appends space-separated note names of one beat each, where the octave carries and ~ is a rest. | the score itself, so calls chain | pcNotes=the note names, such as c e g c5, with ~ for a one-beat rest | Note, init | a word that is not a note is skipped, counted in Refusals and named in LastError | in c e g c5 the first three are octave 4 and a following e would be e5
Then | Appends another score so that it starts where this one ends. | the score itself, so calls chain | poScore=the stzSoundScore to play after this one | Together, Repeat | anything but a stzSoundScore is refused, with LastError set | the other score is copied, so changing it later does not change this one
Together | Overlays another score so that it starts where this one starts. | the score itself, so calls chain | poScore=the stzSoundScore to play at the same time | Then | anything but a stzSoundScore is refused, with LastError set | the length becomes the longer of the two
Repeat | Plays the score so many times in sequence, by copying its events. | the score itself, so calls chain | pnTimes=how many times in all, a whole number of 1 or more | Then | zero, a fraction or a non-number is refused, with LastError set | the length is multiplied by pnTimes
On | Sets the instrument of every event that is still unnamed, and of notes added afterwards. | the score itself, so calls chain | pInstrument=the instrument name, such as harp, guitar, bell, flute or drumkit | Stroke, StzSoundInstruments | an unknown instrument is refused and LastError lists the instruments this engine has | an inner naming wins over an outer one, since only unnamed events are named; a score joined by Then or Together keeps its own naming
Transpose | Shifts the pitch of every pitched note by a number of semitones. | the score itself, so calls chain | pnSemitones=the shift in semitones, fractions allowed, 0.5 being a quarter tone | Note | a non-number is refused, with LastError set | drum strokes keep their pitch, and the end of a glide moves too
SetVelocity | Sets the velocity of the notes added from now on. | the score itself, so calls chain | pnVelocity=the velocity above 0 and at most 1 | Note, Stroke | a value outside the range is refused, with LastError set | notes already in the score keep their velocity
Tempo | Sets the speed of the performance in beats per minute. | the score itself, so calls chain | pnBpm=the speed in beats per minute, from 20 to 400 | TempoInBpm, Seconds | a value outside the range is refused, with LastError set | events stay in beats, so the same score can be rendered at two speeds
Quantize | Snaps every start to the nearest multiple of a grid of beats when frames are computed. | the score itself, so calls chain | pnGrid=the grid in beats, 0.25 being a sixteenth, or 0 for no grid | Swing, FrameOf | a negative or non-numeric value is refused, with LastError set | durations are left alone
Swing | Makes the first of each pair of eighth notes last a given share of the pair. | the score itself, so calls chain | pnRatio=the share strictly between 0 and 1, 0.5 being straight and 2/3 a triplet swing | SwingOn, SwingRatio | a value outside the range is refused, with LastError set | every position is warped, not only those on the grid
SwingOn | Makes the first of each pair of subdivisions last a given share of the pair, on a chosen subdivision. | the score itself, so calls chain | pnRatio=the share strictly between 0 and 1, 0.5 being straight; pnGrid=the length of one subdivision in beats, 0.5 for eighth notes | Swing, FrameOf | a bad ratio or a grid that is not positive is refused, with LastError set | Swing is this call with a grid of 0.5
Events | Returns the events in order of start beat, as a copy. | a list of events, each [ startBeat, beats, hz, instrument, velocity, stroke, glideEndHz ] | | NumberOfEvents, PitchedEvents | changing the returned list changes nothing in the score; events that start together keep the order they were written in | the instrument is an empty text until On or the performance default names one
NumberOfEvents | Returns how many events the score holds. | a number | | Events, Beats
PitchedEvents | Returns the events that have a pitch, in order of start beat, leaving the drum strokes out. | a list of events as Events gives them | | Events, Contour
RangeInCents | Returns the distance from the lowest to the highest pitch in cents, 100 being a semitone. | a number of cents; 0 when no note has a pitch | | PitchedEvents, Contour
Density | Returns how many pitched notes there are per beat of the score. | a number; 0 for a score of no length | | PitchedEvents, Beats
Contour | Returns a text of U, D or S for each step from one pitched note to the next, S meaning within 5 cents. | a text of letters separated by spaces; an empty text for fewer than two pitched notes | | PitchedEvents, RangeInCents
BestModes | Ranks the declared modes of every sound universe by how well their degrees fit the pitched notes, best first. | a list of [ universe, mode, tonicHz, meanCentsOff ] rows, at most pnTop of them; [ ] when no note has a pitch | pnTop=how many rows to keep | StzSoundUniverses, Contour | a tie is reported as a tie, so several modes may show 0 cents off; each pitch is tried as the tonic | it ranks the declarations, it does not say what the music is
Beats | Returns the length of the score in beats, which is where an appended score would start. | a number | | Seconds, SetLength
TempoInBpm | Returns the speed set for the performance, in beats per minute. | a number, 120 until set | | Tempo, Seconds
SwingRatio | Returns the swing share set for the performance. | a number, 0.5 when straight | | Swing, SwingOn
Seconds | Returns the length of the score in seconds at the current speed, without any note tail. | a number of seconds | | Beats, SecondsOf | a rendered sound is longer than this by the tail of its last note
FrameOf | Returns the 0-based frame at which a beat falls, after the grid and the swing and at the current speed. | a number of frames | pnBeat=the beat to place; pnRate=the sample rate in hertz | SecondsOf, Quantize | the offline render and the live scheduler both place notes with it, so they cannot disagree
SecondsOf | Returns how long a number of beats lasts at the current speed. | a number of seconds | pnBeats=the number of beats | Seconds, FrameOf
ToSound | Renders the whole performance offline into one stereo sound at 48000 Hz, held in memory. | a stzSound; one frame long for an empty score | | StzSoundScoreRenderer, LastError | no audio device is opened; a note an instrument refuses is missing from the sound and named in LastError | the sound has not been heard by a person; it is checked by its frame count, rate and peak
Play | Plays the score live through the scheduler and waits for the end. | the score itself | | ToSound, StzSoundSchedulerQ | not run in this reference: it opens an audio device through stzSoundScheduler | LastError holds what the scheduler reported
LastError | Returns the reason the last refused call gave, or an empty text. | a text | | Refusals
Refusals | Returns how many calls the score has refused so far. | a number | | LastError | a refused call leaves the score unchanged
