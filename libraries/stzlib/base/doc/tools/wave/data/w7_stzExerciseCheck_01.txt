SetKind | Sets whether the check judged a program or a declaration that a harness court examined, which changes the wording of Why. | nothing | pcKind=decl for a submission a harness judged, an empty text for a program | WhyIn, Passed | the exercise sets it itself for a harness exercise; a kind other than decl reads as a program
init | Builds the verdict on a learner's program: matches the promises against its run and stamps the code's SHA-256 and the time. | nothing; the object is built | pcId=the exercise's id; pacPromises=the promised values, in order; pcCode=the learner's program, hashed for the evidence; paRun=the list [ stdout, exit code, stderr ] of a run already made, or [ ] to run pcCode now in a fresh process | Passed, Evidence | the promises must appear in order; a promise written error: followed by a text is kept by an error that contains the text, and then a non-zero exit still passes
Id | Returns the id of the exercise this verdict belongs to. | a text such as ex-01-01 | | Evidence
Passed | TRUE if every promise was kept in order and the program exited cleanly, or the exercise promises an error. | TRUE or FALSE | | Why, Report, ExitCode
Output | Returns everything the program printed, one line per print, each ended by a line break. | a text; an empty text when it printed nothing | | Error, Report, Why | for a program that stopped with an error the text also holds the error report, including the name of the temporary file it ran from: show a learner Why, not this
Error | Returns the first line of the run that reports an error. | a text such as Line 5 Error (R14) : Calling Method without definition: withouttwins; an empty text when the exit code was 0; "the program stopped (exit code not 0)" when the exit was not 0 and no line reports an error | | Why, ExitCode | the line number counts the two library lines placed before the learner's code, so it is 2 more than the line the learner wrote
ExitCode | Returns the exit code of the run. | a number; 0 for a clean run | | Error, Passed
Report | Returns, for every promise in order, whether it was kept. | a list of pairs of the promised text and 1 or 0 | | Passed, Why | each pair holds the expected value, the teacher's side: never show it to a learner
Hash | Returns the SHA-256 of the checked code, as 64 hexadecimal characters. | a text | | Evidence, CheckedAtMs
CheckedAtMs | Returns the wall-clock time at which the verdict was built. | a number of milliseconds since the epoch | | Evidence, Hash
Evidence | Returns the evidence a progress fact carries: what was run, and when. | a hash list with exercise, sha256, checkedatms and passed | | Hash, CheckedAtMs, Passed
Why | Returns, in English and in the learner's own terms, what went well or what to look at, never the expected value. | a text a learner reads: a statement that every promise was kept, the error the program raised, or the first three lines it printed joined with a slash | | WhyIn, Passed | a program that printed nothing reads as (nothing), in English also in fr, ar and ha
WhyIn | Returns the same message as Why, in one language. | a text in that language: the passed message, the error line, or the first three printed lines, normalized with their spaces removed | pcLang=en, fr, ar or ha | Why, SetKind | raises an error, saying a missing translation is red and never English, for any other language; the fr, ar and ha messages are drafts, 0 of 35 units reviewed by a person
