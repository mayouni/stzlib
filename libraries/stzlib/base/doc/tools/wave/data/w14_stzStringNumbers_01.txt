# w14 stzStringNumbers -- Name | brief | returns | params | see | warning | note
init | Builds a number extractor over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the text to read numbers from, or a stzString that the object then edits; any other value raises an error | Numbers, Content | RemoveNumbers and ReplaceNumbers on an object built from a stzString leave that stzString EMPTY while the extractor holds the new text; confirmed twice, so pass a text, not a stzString, when the edit matters | stzString does not build one: its own Numbers is a different method; build one with new stzStringNumbers("text")
Content | Returns the text held, with the edits made so far. | a text | | NumberOfChars, Numbers
NumberOfChars | Returns how many characters the text holds, a Hebrew letter or an emoji counting as one. | a number | | Content, IsEmpty
IsEmpty | TRUE if the text holds no character at all. | TRUE or FALSE, as 1 or 0 | | NumberOfChars
Numbers | Returns the numbers written in the text, in order, as numbers; a sign directly before a digit belongs to the number. | a list of numbers; [ ] when there are none | | NumbersAsStrings, PositionsOfNumbers | a run with two decimal points such as 1.2.3 or 192.168.0.1 raises R41 Invalid numeric string, and so does every method built on Numbers; only ASCII digits count, so the Arabic-Indic ١٢٣ is skipped | ExtractNumbers is the same call, NumbersQ returns a stzList; Invoice 12 costs -3.5 and +7 gives 12, -3.5, 7; 5-10 gives 5 and 10, the dash after a digit is not a sign; 1,000 gives 1 and 0; a figure beyond 15 digits loses precision
NumberOfNumbers | Returns how many numbers the text holds. | a number | | Numbers, ContainsNumbers | | CountNumbers and HowManyNumbers are the same call; it raises like Numbers on a run such as 1.2.3
ContainsNumbers | TRUE if the text holds at least one number. | TRUE or FALSE, as 1 or 0 | | NumberOfNumbers, ContainsOnlyNumbers | raises like Numbers on a run such as 1.2.3
ContainsOnlyNumbers | TRUE if every character of the text is a digit, a point, a minus or a plus. | TRUE or FALSE, as 1 or 0; TRUE for an empty text | | ContainsNumbers | it tests characters, not number syntax: -.+ and 1-2-3 give 1, and abc gives 0 | 42 gives 1, 42abc gives 0
RemoveNumbers | Deletes every ASCII digit from the text, in place. | nothing; the text changes. RemoveNumbersQ returns the object for chaining | | NumbersRemoved, ReplaceNumbers | the signs and points around the digits stay: x 5 y 10 z 5.5 gives x  y  z .; on an object built from a stzString the original stzString is left empty | a1b22c333 gives abc
NumbersRemoved | Returns the text with every ASCII digit deleted, leaving the object as it is. | a text | | RemoveNumbers, NumbersReplaced | the signs and points stay: Invoice 12 costs -3.5 gives Invoice  costs -. | works on a copy, so it is safe on an object built from a stzString
SumOfNumbers | Returns the sum of the numbers in the text. | a number; 0 when there are none | | AverageOfNumbers, MaxNumber | raises like Numbers on a run such as 1.2.3 | 10 20 30 gives 60; 10-5 and 3+4 gives 22
MaxNumber | Returns the largest number in the text. | a number | | MinNumber, SumOfNumbers | raises No numbers found in the string! when the text holds none | Invoice 12 costs -3.5 and +7, total 10 gives 12
MinNumber | Returns the smallest number in the text. | a number | | MaxNumber, SumOfNumbers | raises No numbers found in the string! when the text holds none | the same text gives -3.5
AverageOfNumbers | Returns the mean of the numbers in the text. | a number | | SumOfNumbers, MaxNumber | raises No numbers found in the string! when the text holds none | 1 2 gives 1.5
NthNumber | Returns the nth number of the text. | a number | n=which number, counting from 1 | FirstNumber, LastNumber, Numbers | raises Index out of range! for 0, a negative n or a count beyond the last | in 12, -3.5, 7, 10 the second is -3.5
FirstNumber | Returns the first number of the text. | a number | | LastNumber, NthNumber | raises Index out of range! when the text holds none | Invoice 12 costs gives 12
LastNumber | Returns the last number of the text. | a number | | FirstNumber, NthNumber | raises Index out of range! when the text holds none | Invoice 12 costs -3.5 and +7, total 10 gives 10
ReplaceNumbers | Replaces every run of ASCII digits with a value, in place. | nothing; the text changes. ReplaceNumbersQ returns the object for chaining | nNewValue=the value written in place of each run; it is joined as text, so a text such as # works and 2.5 gives 2.50 | NumbersReplaced, RemoveNumbers | each run of digits is replaced on its own, so 5.5 becomes two replacements around the point and -3.5 keeps its sign; on an object built from a stzString the original stzString is left empty | x 5 y 10 z 5.5 with 9 gives x 9 y 9 z 9.9
NumbersReplaced | Returns the text with every run of ASCII digits replaced by a value, leaving the object as it is. | a text | nNewValue=the value written in place of each run, joined as text | ReplaceNumbers, NumbersRemoved | the signs and points stay: Invoice 12 costs -3.5 with 0 gives Invoice 0 costs -0.0 | works on a copy, so it is safe on an object built from a stzString
NumbersAsStrings | Returns each number of the text written as a text. | a list of texts | | Numbers | the numbers are converted with Ring's two-decimal text form, so 3.14159 comes out as 3.14 although Numbers holds the full value; raises like Numbers on a run such as 1.2.3 | 12 and -3.5 give 12 and -3.50 when printed through a list
PositionsOfNumbers | Returns the position where each run of ASCII digits starts, counted in characters. | a list of numbers; [ ] when there are none | | Numbers, ScanInteger | | 5.5 is two runs, so x 5 y 10 z 5.5 gives 3, 7, 12 and 14; Hebrew and emoji text count by characters: a😀1😀22 gives 3 and 5
ScanInteger | Returns the first integer written in the text, skipping any text before it. | a number; 0 when the text has no digit | | Numbers, FirstNumber | an integer above 2147483647, or the value -2147483648, stops the Ring process with an integer overflow panic in stz_string.dll; confirmed with 99999999999, 3000000000 and a 30 digit figure | 42abc gives 42, a1b99 gives 1, -17x gives -17, abc gives 0
