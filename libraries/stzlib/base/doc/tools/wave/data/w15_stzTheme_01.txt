# w15 stzTheme
init | Builds a theme by name, keeping its name in lower case. | nothing; the object is built | pcName=the theme name, in any letter case, one of neutral, light, dark, vibrant, pro, access, print, gray, lightgray or darkgray | Name, Roles | an empty name raises error stzTheme: name a theme, and an unknown name such as nope raises error stzTheme: ... is not a theme, with the list of the ten themes, so a misspelt theme never exports plausible wrong colours | StzThemeQ builds the same object
Name | Returns the lower-case name of the theme. | the name as text, such as pro | | Roles | |
Roles | Returns the roles a theme fills in: primary, success, warning, danger, info, muted, neutral and background. | a list of eight role names as text | | ColorOf, Tokens | | background is a surface: it has a colour but no steps and no on-colour
ColorOf | Returns the colour a theme gives to a role, as a hex code. | the colour as text such as #4D4DC9; an empty text for a role the theme does not have | pcRole=the role, as a symbol or a text such as :Danger | StepOf, OnColorOf, Tokens | | it is always resolved to hex, never left as an expression, because the far side of an export has no resolver
StepOf | Returns one of the four steps of a role's colour, Surface, Border, Solid or Text, as a hex code. | the colour as text; an empty text for an unknown role or step | pcRole=the role, such as :Danger; pcStep=the step, one of :Surface, :Border, :Solid or :Text | ColorOf, OnColorOf | | the steps are the same hue at four lightnesses, from palest to deepest text
OnColorOf | Returns the colour that reads best as text on the solid step of a role. | the colour as a hex code chosen for contrast; an empty text for an unknown role | pcRole=the role whose solid step is the background | StepOf, ColorOf | | the choice is measured against the solid step, not guessed
Tokens | Returns the whole theme flattened to name and colour pairs, the list every export is written from. | a list of [ name, hex ] pairs: 43 for a theme, each role as role, role-surface, role-border, role-solid, role-text and on-role, and background alone | | ToCSS, ToJSON, ToRing | | CSS, JSON and Ring all read this one list, so the three cannot disagree about which tokens exist
ToCSS | Returns the theme as CSS custom properties in a :root block, every token under the --stz- prefix. | a text starting with a comment naming the theme | | Tokens, ToJSON | | StzThemeFromCSS reads the text back as [ name, hex ] pairs, and StzThemeTokenOf reads one token from them
ToJSON | Returns the theme as a JSON object with the theme name and a tokens table, for design tools. | a text holding a theme key and a tokens object | | Tokens, ToCSS | |
ToRing | Returns the theme as the source of a Ring list literal that can be written to a file and loaded. | a text starting with a comment and an assignment named aTheme followed by the capitalised name | | Tokens, ToCSS | | a dash in a token name becomes an underscore, as in :primary_surface
