init | Builds a corpus from one text or a list of texts; empty and non-text entries are dropped without a message. | nothing; the object is built | p=a text, or a list of texts, each one a document | AddDocument | | the engine model is not built here but at the first question
AddDocument | Appends one text to the corpus as a new document, and feeds it to the engine model if that model already exists. | nothing; use AddDocumentQ to chain | pcText=the text of the new document; an empty or non-text value is ignored | AddDocumentQ, Documents | | newlines in the text are turned into spaces when it reaches the model, so a document stays one document
Documents | Returns the documents of the corpus as they were given, in order. | a list of texts | | NumberOfDocuments, AddDocument | | documents are numbered from 1 in TfOf, TfIdfOf and TopTermsOf
NumberOfDocuments | Returns how many documents the corpus holds. | a number | | Documents | |
FreeModel | Frees the engine model of the corpus. The next question builds it again from all the documents. | nothing | | FreeLm | | Ring has no destructors, so a program that is done with a large corpus calls it; nothing is lost, since the texts stay in the object
FreeLm | Frees the engine model of the corpus, under the name the language model part of this class used to have. | nothing | | FreeModel | |
NumberOfWords | Returns how many words, repeats included, the whole corpus has. | a number | | VocabularySize, FreqOf | | words are cut and lowercased by the engine, with Unicode rules
Vocabulary | Returns every distinct word of the corpus, lowercased. | a list of texts, in no particular order | | VocabularySize, MostFrequent | | for the words by rank use MostFrequent
VocabularySize | Returns how many distinct words the corpus has. | a number | | Vocabulary, NumberOfWords | |
FreqOf | Returns how many times a word occurs in the whole corpus, ignoring case; 0 when it is absent. | a number | pcWord=the word to count | MostFrequent, NumberOfDocumentsWith | | counted in every document together; for one document use TfOf
MostFrequent | Returns the n commonest words with their counts, the highest first. | a list of [ word, count ] pairs; [ ] when n is 0 | n=how many words to return | FreqOf, Vocabulary | | words with equal counts come in no fixed order
BigramProbability | Returns the chance that pcW2 follows pcW1 in this corpus, smoothed so that a pair never seen still gets a small chance. | a number between 0 and 1 | pcW1=the first word of the pair; pcW2=the word that should follow it | LogProbability, Perplexity | | the smoothing is Laplace: (count of the pair + 1) / (count of pcW1 + vocabulary size)
LogProbability | Returns the natural logarithm of the chance of a whole text under the bigram model; it is 0 or negative, and nearer 0 means likelier. | a number, 0 or negative | pcText=the text to score | Perplexity, BigramProbability | |
Perplexity | Returns how surprising a text is to the corpus, as exp of minus the average log chance per word pair; lower means more like the corpus. | a number, 1 or more; 0 when the text has fewer than two words | pcText=the text to score | LogProbability | | a text of 0 or 1 word answers 0, which reads as the best score and means no score
NumberOfDocumentsWith | Returns in how many documents a word occurs at least once (its document frequency). | a number | pcWord=the word to look for | IdfOf, FreqOf | |
TfOf | Returns how many times a word occurs in one document, counted from 1. | a number; 0 when the word is absent or the document number is out of range | pcWord=the word to count; nDoc=the document number, from 1 | TfIdfOf, FreqOf | | a document number that does not exist (0 or too large) answers 0 and raises nothing
IdfOf | Returns the smoothed inverse document frequency of a word: log of (1 + documents) / (1 + documents holding it), plus 1. | a number; the largest for a word that is in no document | pcWord=the word whose rarity is asked | TfIdfOf, NumberOfDocumentsWith | |
TfIdfOf | Returns the weight of a word in one document: its count there times its inverse document frequency. | a number | pcWord=the word to weigh; nDoc=the document number, from 1 | TfOf, IdfOf, TopTermsOf | |
TopTermsOf | Returns the n most distinctive words of one document, the highest TF-IDF weight first. | a list of [ word, weight ] pairs; [ ] when the document number does not exist | nDoc=the document number, from 1; n=how many words to return | TfIdfOf | | fewer than n pairs when the document has fewer distinct words
