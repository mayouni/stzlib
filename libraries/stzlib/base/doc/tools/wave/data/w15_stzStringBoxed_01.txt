init | Builds a boxed-text helper over a text or over a stzString object. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, to draw in a box | Boxed, BoxedChars | any other kind of value raises "Can't create stzStringBoxed! Parameter must be a string or stzString object." |
Content | Returns the text the helper holds, unchanged by drawing. | a text | | NumberOfChars | | Boxed and BoxedChars only return drawings, they never change it
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | |
Boxed | Returns the whole text drawn inside one box of Unicode lines, one row per line of the text, padded to the longest line. | a text of several lines, with no newline at the end | | BoxedChars, Content | | a text with no content draws an empty box of two lines; the width is counted in characters, so Hebrew, Arabic and emoji are measured by letter, and a wide emoji may still look misaligned on a console
BoxedChars | Returns the text drawn with each character in its own cell of a single row. | a text of three lines: top border, the cells, bottom border | | Boxed | The borders do not match the cells today: each border cell is 4 dashes wide while each text cell is 3 characters wide, so the top and bottom lines are longer than the middle one and the dividers do not line up; an empty text falls back to Boxed | the drawing needs a UTF-8 console
