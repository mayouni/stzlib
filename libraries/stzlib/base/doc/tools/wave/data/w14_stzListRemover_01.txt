# w14 stzListRemover -- Name | brief | returns | params | see | warning | note
init | Builds a remover over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to edit, or a stzList whose content is copied, any other value raises an error | Content, RemoveAll | | the remover works on its own copy: editing it never changes the list or the stzList you passed in, so read the result with Content
Content | Returns the list as it stands now, after the removals made so far. | a list | | NumberOfItems, AllOccurrencesRemoved
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsEmpty
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
RemoveAll | Deletes every occurrence of an item from the list, in place. | nothing; the content changes. RemoveAllQ returns the remover for chaining | pItem=the item to delete, a text, a number or a sublist | AllOccurrencesRemoved, RemoveFirstOccurrence, RemoveNthOccurrence | | case counts; RemoveAllCS(pItem, 0) ignores case; a number never matches the same digits written as a text, so removing 1 keeps "1"
Remove | Deletes every occurrence of an item from the list, in place. | nothing; the content changes. RemoveQ returns the remover for chaining | pItem=the item to delete, a text, a number or a sublist | RemoveAll, RemoveFirstOccurrence | | the same call as RemoveAll
AllOccurrencesRemoved | Returns the list without any occurrence of an item, leaving the remover as it was. | a list | pItem=the item to leave out | RemoveAll, NthItemRemoved
RemoveItemAtPosition | Deletes the item at a position, counting from 1, in place. | nothing; the content changes. RemoveItemAtPositionQ returns the remover for chaining | _n_=the position to delete, from 1; the words First and Last are accepted | RemoveFirstItem, RemoveLastItem, RemoveItemsAtPositions, NthItemRemoved | a position past the end deletes nothing and says nothing; 0 raises Incorrect param! n must be a number different from zero; a negative position kills the whole Ring process with panic: integer part of floating point value out of bounds in stz_list.dll (RemoveItemAtPosition(-1) on a b c, and (-2) on 10 20) | RemoveAt, RemoveAtPosition and RemoveNthItem are the same call
RemoveAt | Deletes the item at a position, counting from 1, in place. | nothing; the content changes | _n_=the position to delete, from 1 | RemoveItemAtPosition, RemoveAtPositions | | the same call as RemoveItemAtPosition, so the same warnings: a negative position kills the Ring process
RemoveAtPosition | Deletes the item at a position, counting from 1, in place. | nothing; the content changes | _n_=the position to delete, from 1 | RemoveItemAtPosition, RemoveAtPositions | | the same call as RemoveItemAtPosition, so the same warnings: a negative position kills the Ring process
RemoveNthItem | Deletes the item at a position, counting from 1, in place. | nothing; the content changes | _n_=the position to delete, from 1 | RemoveItemAtPosition, NthItemRemoved | | the same call as RemoveItemAtPosition, so the same warnings: a negative position kills the Ring process
NthItemRemoved | Returns the list without the item at a position, leaving the remover as it was. | a list | _n_=the position to leave out, from 1 | RemoveItemAtPosition, FirstItemRemoved | | a position past the end leaves the list whole
RemoveFirstItem | Deletes the first item of the list, in place. | nothing; the content changes. RemoveFirstItemQ returns the remover for chaining | | FirstItemRemoved, RemoveLastItem, RemoveFirstAndLastItems | | on an empty list nothing happens
FirstItemRemoved | Returns the list without its first item, leaving the remover as it was. | a list | | RemoveFirstItem, LastItemRemoved
RemoveLastItem | Deletes the last item of the list, in place. | nothing; the content changes. RemoveLastItemQ returns the remover for chaining | | LastItemRemoved, RemoveFirstItem, RemoveFirstAndLastItems | on an empty list it raises Incorrect param! n must be a number different from zero, because it asks for position 0 | RemoveFirstItem on an empty list is silent
LastItemRemoved | Returns the list without its last item, leaving the remover as it was. | a list | | RemoveLastItem, FirstItemRemoved | | on an empty list it raises the same error as RemoveLastItem
RemoveFirstAndLastItems | Deletes both ends of the list, in place. | nothing; the content changes. RemoveFirstAndLastItemsQ returns the remover for chaining | | RemoveFirstItem, RemoveLastItem, RemoveSection | on a list of one item it raises Incorrect param! n must be a number different from zero, because the first removal leaves nothing for the second; a list of two items becomes [ ]
RemoveItemsAtPositions | Deletes the items at several positions in one call, in place. | nothing; the content changes. RemoveItemsAtPositionsQ returns the remover for chaining | panPositions=the positions to delete, each from 1, in any order | RemoveItemAtPosition, RemoveSection | a position listed twice deletes two different items: [ 2, 2 ] on a b c leaves a, because the second 2 is read after the first deletion; a position past the end is ignored | the positions are taken from the last to the first, so they all refer to the original list
RemoveAtPositions | Deletes the items at several positions in one call, in place. | nothing; the content changes | panPositions=the positions to delete, each from 1, in any order | RemoveItemsAtPositions, RemoveSection | a position listed twice deletes two different items, as in RemoveItemsAtPositions | the same call as RemoveItemsAtPositions
RemoveSection | Deletes the items from one position to another, both included, in place. | nothing; the content changes. RemoveSectionQ returns the remover for chaining | n1=the first position to delete; n2=the last position to delete | RemoveItemsAtPositions, RemoveAllItems | | a start below 1 becomes 1 and an end past the list becomes the last position, but a start larger than the end deletes nothing: RemoveSection(4, 2) leaves the list whole
RemoveAllItems | Empties the list, in place. | nothing; the list becomes [ ]. RemoveAllItemsQ returns the remover for chaining | | Clear, RemoveAll
Clear | Empties the list, in place. | nothing; the list becomes [ ] | | RemoveAllItems, RemoveAll | | the same call as RemoveAllItems
RemoveNthOccurrence | Deletes the nth occurrence of an item, leaving its other occurrences, in place. | nothing; the content changes. RemoveNthOccurrenceCSQ returns the remover for chaining | _n_=which occurrence to delete, counting from 1; pItem=the item to look for | RemoveFirstOccurrence, RemoveLastOccurrence, RemoveAll | | an n larger than the number of occurrences deletes nothing; RemoveNthOccurrenceCS(n, pItem, 0) ignores case
RemoveFirstOccurrence | Deletes only the first occurrence of an item, in place. | nothing; the content changes | pItem=the item to look for | RemoveLastOccurrence, RemoveNthOccurrence, RemoveAll | | an item that is absent deletes nothing; RemoveFirstOccurrenceCS(pItem, 0) ignores case
RemoveLastOccurrence | Deletes only the last occurrence of an item, in place. | nothing; the content changes | pItem=the item to look for | RemoveFirstOccurrence, RemoveNthOccurrence, RemoveAll | | an item that is absent deletes nothing; RemoveLastOccurrenceCS(pItem, 0) ignores case
