init | Builds an untrained decision tree over a training set of categorical features. | nothing; the object is built | poTrainingSet=a stzTrainingSet; the tree keeps its own copy | Train, TrainingSetQ
TrainingSetQ | Returns the training set the tree holds, the one to grow if more examples are wanted. | a stzTrainingSet | | Train | growing the set you passed to the constructor does not reach the tree, because it keeps a copy; grow it here and call Train again
SetFeatureNames | Sets a name for each feature, so that Why and ToGraph can speak of outlook instead of f1. | the tree itself, so calls chain | pacNames=a list of text, one name per feature in the order of the examples | Why, ToGraph | | an unnamed feature is called f1, f2 and so on
Train | Builds the tree by ID3, choosing at each node the feature with the greatest information gain; the build runs in the engine. | the tree itself, so calls chain | | Classify, Tree | raises an error for an empty set, for examples with no features, and for an example whose width differs from the first one, naming it | values compare without regard to case; calling it again rebuilds the tree from the set
Tree | Returns the learned tree as nested lists: [ :feature, :branches, :default ] for a decision and [ :leaf ] for an answer. | a nested list; :feature is the position of the feature, :branches a list of [ value, subtree ] pairs, :default the majority label | | ToGraph, Classify | | an untrained tree answers an empty list
Classify | Returns the label the tree gives to a feature list, and keeps the path it followed for Why. | a text, the label | paFeatures=the feature values, in the order of the training examples | Why, Train | raises an error telling to call Train first; a value never seen at a node falls to that node's majority label, which Why says | values compare without regard to case
Why | Returns the path of the last classification as text, such as humidity='high' -> outlook='sunny' -> 'no'. | a text; empty before the first Classify | | Classify, SetFeatureNames | | an unseen value is marked in the path with unseen value and the default it fell to
ToGraph | Returns the learned tree as a real graph of decision nodes, value edges and leaf nodes. | a stzGraph; nodes n1, n2 and so on, each with a kind (decision or leaf) and a label | | Tree, SetFeatureNames | raises an error telling to call Train first | the graph can be queried like any other graph
