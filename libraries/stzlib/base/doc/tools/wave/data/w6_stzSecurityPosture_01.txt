init | Builds an empty posture audit of a project's security surface, with no store, no sites, no actors and no service registry. | nothing; the object is built | pcName=the project's name, shown in the report and in findings | SetStore, AddSite, AddActor
SetStore | Sets the project's central secret store, so the audit can see its refused reveals and tell a store-backed site from an inline key. | the posture itself, so calls chain | poStore=the stzSecretStore of the project | AddSite, Findings | the posture keeps a COPY of the store: reveals refused after this call are not seen, so set the store last, just before asking | without a store, secret-bearing sites raise the no-central-store warning
AddSite | Adds a deployment site to audit for a secret it holds inline instead of through the store. | the posture itself, so calls chain | poSite=the stzDeploymentSite to audit | AddActor, SetStore | the posture keeps a COPY of the site | an inline secret raises the inline-key warning
AddActor | Adds an actor to audit for the load-bearing rule that a sandboxed actor must never hold the effectful capability. | the posture itself, so calls chain | poActor=the actor to audit, such as HumanActor or LLMActor | AddSite, Findings | the posture keeps a COPY of the actor: a posture or capability changed after this call is not seen | a sandboxed actor that holds effectful is an ERROR finding
SetServices | Attaches the project's service registry, so findings about fakes and unbound services join the same audit. | the posture itself, so calls chain | poReg=the stzServiceRegistry of the project | ServicesQ, HasServices, Findings | | the audit asks the registry in the production frame and restores its phase, so a sandbox still bound is reported while there is time to act
ServicesQ | Returns the attached service registry. | the stzServiceRegistry, or an empty text when none was attached | | SetServices, HasServices
HasServices | TRUE if a service registry was attached with SetServices. | TRUE or FALSE | | SetServices, ServicesQ
Findings | Runs every invariant over the described surface and returns the findings as one flat list. | a list of [ :invariant, :severity, :where, :message ] findings; [ ] when nothing is flagged | | IsSound, NumberOf, Report, StzSecurityInvariantNames | | the severity is the symbol error or warn, not the word warning that stzDetection uses; the findings are recomputed at each call
IsSound | TRUE if no finding is an error; warnings are advisory and do not block. | TRUE or FALSE | | IsClean, NumberOf, Findings
IsClean | TRUE if nothing at all is flagged, neither an error nor a warning. | TRUE or FALSE | | IsSound, NumberOfFindings
NumberOfFindings | Returns how many findings the audit raises, errors and warnings together. | a number | | Findings, NumberOf
NumberOf | Returns how many findings have one severity. | a number | pcSeverity=error or warn, as the findings spell it | Findings, NumberOfFindings | warning does not match: the findings say warn, so NumberOf with the word warning answers 0, and the match is case-sensitive | NumberOf(:error) and NumberOf(:warn) are the two that count
Report | Prints a verdict line for the project, then one line per finding with its severity, invariant, place and message. | nothing; it prints | | Findings, IsSound | | the verdict reads SOUND or UNSOUND (errors present)
