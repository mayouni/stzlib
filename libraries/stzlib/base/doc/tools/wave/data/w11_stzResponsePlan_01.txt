init | Builds an empty containment plan with a name, to be proposed into and committed by an effectful actor. | nothing; the plan is built | pcName=the name of the plan, such as the incident it answers | Propose, ExecuteOn
Name | Returns the name the plan was built with. | a text | | init
Propose | Adds one containment action to the plan; the action is only recorded, nothing is performed. | the plan itself, so calls chain | pcAction=the kind of action, one of :RevokeSession, :LockAccount, :RotateSecret, :RevokeCapability, :ShedSource, :QuarantinePart; pcTarget=what the action is about, such as an account, a secret name or an address; pcRationale=the reason, kept with the action in the audit | ProposeForIncident, Actions, ExecuteOn | an action outside the closed catalog raises an error that lists the catalog | the kind is folded to lower case
ProposeForIncident | Adds the actions an incident calls for: lock and revoke for its actor, a rotation per secret it implicates. | the plan itself, so calls chain | poIncident=the stzIncident to read; nothing is added that the incident does not hold | Propose, Actions, MayCommit | | it only proposes; the actions are performed by ExecuteOn
Actions | Returns the proposed actions, in the order proposed. | a list of [ kind, target, rationale ] rows, the kind in lower case | | Propose, NumberOfActions
NumberOfActions | Returns how many actions the plan holds. | a number | | Actions, Propose
MayCommit | TRUE if the actor may commit a plan: it must be effectful and not sandboxed. | TRUE or FALSE; always FALSE for a language-model actor | poActor=the actor asking to commit | WhyNot, ExecuteOn | | answered before any attempt, and nothing is audited
WhyNot | Returns the reason an actor may not commit, in words. | a text; an empty text when the actor may commit | poActor=the actor to explain | MayCommit, ExecuteOn
ExecuteOn | Performs the actions on a responder when the actor may commit, auditing each; otherwise performs none and audits refusals. | the number of actions committed; 0 when the actor may not, or when no responder owns an action | poResponder=the object that answers the six verbs, a rehearsal double or a responder over in-memory objects; poActor=the actor committing, effectful and not sandboxed | MayCommit, AuditTrail, StzResponderSet | a responder that answers Owns is asked about every action first, and one action nobody owns refuses the whole plan before any is performed; a plan executed twice performs its actions twice | each outcome also reaches the security ledger as response.action.committed or response.action.refused
WasExecuted | TRUE if a commit has gone through for this plan. | TRUE or FALSE | | ExecuteOn, CommittedCount | | a refused attempt does not set it
AuditTrail | Returns every outcome recorded, committed and refused alike, in the order they happened. | a list of [ number, verdict, kind, target, actor, why ] rows | | CommittedCount, RefusedCount, ExecuteOn
CommittedCount | Returns how many actions were committed over the life of the plan. | a number | | RefusedCount, AuditTrail
RefusedCount | Returns how many actions were refused over the life of the plan, a signal worth watching. | a number | | CommittedCount, AuditTrail
Explain | Returns the plan as lines of text: each proposed action with its reason, then the audit. | a list of text lines | | Show, AuditTrail
Show | Prints the lines of the plan. | nothing; it prints | | Explain
