init | Builds an encoder over a text, given as a string or as a stzString object. | nothing; the object is built | pStrOrStzStrObj=the text to encode or decode, or a stzString whose content is used, any other value raises an error | Content, ToHex | with a stzString argument, the first in-place edit (UrlEncode, HtmlDecode, FromHex, Reverse, NormalizeNFC...) leaves the stzString you passed reading as an empty text; the encoder itself keeps the right text | pass a plain text and read the result with Content; stzString does it safely by writing the encoder result back with Update

ToHex | Returns the UTF-8 bytes of the text as lower-case hexadecimal digits, two per byte, with no separator. | a text; empty for an empty text |  | ToHexWithPrefix, FromHex, ToBinary |  | a Hebrew letter is two bytes and an emoji four, so the result is longer than twice the character count; ToHexQ returns a new encoder over the result
ToHexWithPrefix | Returns the same hexadecimal digits as ToHex, preceded by 0x. | a text |  | ToHex |  | the prefix is always added, even for an empty text
FromHex | Replaces the held text by the text that hexadecimal digits spell, in place, taking each pair of digits as one character. | nothing; the text changes. FromHexQ returns the encoder for chaining | cHex=the hexadecimal digits, two per character, a trailing odd digit is dropped | ToHex, FromBinary | each byte becomes its own character, so only pairs below 80 give the expected text: FromHex("c3a9") answers the two characters that spell Ã© and FromHex("d7a9d795") answers four, where ToHex of é and of a Hebrew word gave those digits; the UTF-8 bytes are not joined back into characters, so ToHex and FromHex do not round-trip for text outside ASCII | for ASCII text it round-trips with ToHex
UrlEncoded | Returns the text percent-encoded for a URL, each byte of a non-ASCII character as %XX in upper case. | a text |  | UrlEncode, UrlDecoded, HtmlEncoded |  | a space becomes %20 and an ampersand %26

UrlDecoded | Returns the text with every %XX sequence turned back into its character, reading the bytes as UTF-8. | a text |  | UrlDecode, UrlEncoded |  | decoded Hebrew, Arabic and emoji come back whole
UrlDecode | Replaces the held text by its percent-decoded form, in place. | nothing; the text changes |  | UrlDecoded, UrlEncode
AsciiCodes | Returns the Unicode code point of each character, in order. | a list of numbers; a list of one number per character |  | Unicodes, ToCharCodes |  | despite its name it gives code points, not only ASCII codes: a Hebrew letter answers 1513 and an emoji 128512; Unicodes is the same call
Unicodes | Returns the Unicode code point of each character, in order. | a list of numbers; a list of one number per character |  | AsciiCodes, ToCharCodes
ToBinary | Returns the text as one group of eight binary digits per character, groups separated by a space. | a text such as 01001000 01101001 for Hi |  | FromBinary, ToOctal, ToCharCodes | a character whose code point is above 255 is cut to its low eight bits: the Hebrew shin (1513) answers 11101001, which is also what the code point 233 answers, and an emoji (128512) answers 00000000; ToBinary is not the UTF-8 bytes either, which ToHex gives | exact for Latin-1 text, so use ToHex for the bytes of other scripts

ToCharCodes | Returns the code point of each character as decimal numbers in one text, separated by a space. | a text such as 72 105 for Hi |  | FromCharCodes, AsciiCodes |  | AsciiCodes gives the same numbers as a list
