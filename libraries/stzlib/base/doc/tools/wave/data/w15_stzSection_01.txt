init | Builds a section, a pair of start and end positions, checked against the size of the list or string it is meant for. | nothing; the object is built | _n1_=the start position, from 1, or a keyword such as :First, :Start or a named place such as [ :From, 3 ]; _n2_=the end position, from 1, or :Last, :End or [ :To, 6 ]; _nSize_=the number of items or chars of the host, or [ :Size, 10 ] | Content, IsSection | A start or end of 0, or not a number, raises "Incorrect params! n1 and n2 must be numbers different from zero"; an end past the size, or a negative position, raises "Out of range! nSize must between n1 and n2"; a start past the size is accepted when the end is inside it: new stzSection(12, 3, 10) answers [ 12, 3 ], and a start after the end is kept as given | negative positions that count from the end are refused here, unlike stzList.Section
