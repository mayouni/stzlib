init | Builds a service provider that knows who it is and where the identity provider should post its answers. | nothing; the object is built | pcEntityId=this provider's own entity id, the audience an assertion must name; pcAcsUrl=the assertion consumer URL, written into each sign-in request | TrustIdp, ConsumeResponse | raises an error when pcEntityId is empty or only spaces | the object trusts nobody until TrustIdp, TrustIdpFromCertificate or TrustIdpFromMetadata is called
EntityId | Returns this provider's own entity id, the audience an assertion must be minted for. | a text | | AcsUrl, IdpEntityId
AcsUrl | Returns the assertion consumer URL given at construction. | a text | | EntityId, AuthnRequest
TrustIdp | Trusts exactly one identity provider, named by its entity id and its signing key given as raw components. | nothing; use TrustIdpQ to chain | pcIdpEntityId=the entity id the assertion issuer must equal; pcKty=the key type, RSA or EC; pcK1=the first key part in base64url (the modulus n, or x); pcK2=the second key part in base64url (the exponent e, or y) | TrustIdpFromCertificate, TrustIdpFromMetadata, TrustsAnIdp | a second call replaces the first identity provider; the key parts are not checked until an assertion is consumed | the entity id is trimmed
TrustIdpFromCertificate | Trusts an identity provider by its X.509 certificate, from which the signing key is read. | nothing; use TrustIdpFromCertificateQ to chain | pcIdpEntityId=the entity id the assertion issuer must equal; pcCert=the certificate as PEM text or as the bare base64 DER that metadata carries | TrustIdp, TrustIdpFromMetadata, IdpCertificateFingerprint | raises an error when the certificate cannot be read | the certificate is kept, so IdpCertificate, IdpCertificateFingerprint and IdpCertificateInfo answer afterwards
TrustIdpFromMetadata | Trusts an identity provider from the metadata document it publishes, taking entity id, sign-on URL and certificate from it. | nothing; use TrustIdpFromMetadataQ to chain | pcXml=the identity provider's metadata document as XML text | TrustIdpFromCertificate, SetIdpSsoUrl, IdpSsoUrl | raises an error when the document holds no entity id with a signing certificate, or when the certificate cannot be read | the signing certificate is the one used, not an encryption certificate
IdpCertificate | Returns the certificate trust was configured from, or an empty text when trust was set with raw key parts. | a text | | IdpCertificateFingerprint, TrustIdpFromCertificate
IdpCertificateFingerprint | Returns the SHA-256 fingerprint of the trusted certificate in hex, for an operator to compare with what the identity provider published. | a text of 64 hex characters; empty when no certificate was given | | IdpCertificateInfo, IdpCertificate
IdpCertificateInfo | Returns who the trusted certificate was issued to and when it is valid. | a hash list with the keys subject, notbefore and notafter; an empty list when trust was not set from a certificate | | IdpCertificateFingerprint | | the keys are lower case: notbefore, notafter
SetIdpSsoUrl | Sets the identity provider's single sign-on URL, the destination of the sign-in request. | nothing; use SetIdpSsoUrlQ to chain | pcUrl=the identity provider's sign-on endpoint | IdpSsoUrl, AuthnRequest | | TrustIdpFromMetadata sets it from the document; the URL is not checked
IdpEntityId | Returns the entity id of the trusted identity provider, or an empty text when none is trusted. | a text | | TrustIdp, TrustsAnIdp
IdpSsoUrl | Returns the sign-on URL set for the identity provider, or an empty text. | a text | | SetIdpSsoUrl
TrustsAnIdp | TRUE if an identity provider and a signing key have been configured. | TRUE or FALSE | | TrustIdp, TrustIdpFromCertificate
SetClockSkew | Sets, in seconds, how far outside its validity window an assertion is still accepted. | nothing; use SetClockSkewQ to chain | pnSecs=the allowance in seconds, applied on both sides of the window | ClockSkew, ConsumeResponseAt | | the default is 120 seconds
ClockSkew | Returns the clock-skew allowance in seconds. | a number | | SetClockSkew
Why | Returns the reason the last consumed assertion was refused, or an empty text after an accepted one. | a text | | ConsumeResponse, ConsumeXml
AuthnRequest | Returns the sign-in request XML to send the user to the identity provider, stamped with the current time. | a text holding the XML of a samlp:AuthnRequest | pcRequestId=the request id, which must not start with a digit | AuthnRequestAt, NewRequestId, SetIdpSsoUrl | the IssueInstant attribute holds the clock in milliseconds as digits, not an ISO date; the request id, the destination and the URLs are written into attribute values without XML escaping, so a quote in pcRequestId closes the attribute | the caller encodes the XML for the HTTP binding
AuthnRequestAt | Returns the sign-in request XML for a given moment. | a text holding the XML of a samlp:AuthnRequest | pcRequestId=the request id, which must not start with a digit; pnNow=the moment in epoch seconds | AuthnRequest, NewRequestId | pnNow is ignored today: IssueInstant is always the current clock in milliseconds as digits, not an ISO date; the request id is written into an attribute without XML escaping, so the id _a"b<c gives ID="_a"b<c" | two calls with different pnNow give the same IssueInstant
NewRequestId | Returns a fresh random request id that starts with an underscore, so it is a valid XML id. | a text of an underscore and 32 hex characters | | AuthnRequest
ConsumeResponse | Judges the base64 SAMLResponse a browser posted back and answers with the claims or the reason for refusing. | a hash list with the keys ok, nameid, issuer, audience, notbefore, notonorafter and why; ok is 1 when accepted, 0 when refused | pcBase64=the SAMLResponse form field as posted, standard or url-safe base64, spaces and line breaks allowed | ConsumeResponseAt, ConsumeXml, Why | raises an error when no identity provider is trusted; every refusal is also noted in the refusal record under sso.assertion.rejected and a replay under sso.assertion.replayed | an accepted assertion is remembered for 600 seconds, so presenting it again is refused as a replay
ConsumeResponseAt | Judges a base64 SAMLResponse as of a given moment. | a hash list with the keys ok, nameid, issuer, audience, notbefore, notonorafter and why | pcBase64=the SAMLResponse form field as posted; pnNow=the moment to judge at, in epoch seconds | ConsumeResponse, ConsumeXmlAt | raises an error when no identity provider is trusted; a text that is not base64 is refused with the reason, not raised | the signature, issuer, audience, validity window and replay are all checked
ConsumeXml | Judges an assertion given as XML text, at the current time. | a hash list with the keys ok, nameid, issuer, audience, notbefore, notonorafter and why | pcXml=the signed assertion or response as XML text | ConsumeXmlAt, ConsumeResponse | unlike ConsumeResponse it does not raise when no identity provider is trusted: it answers a refusal | the same checks as ConsumeXmlAt
ConsumeXmlAt | Verifies the signature of an assertion, then accepts it only for the trusted issuer, this audience, a valid window and a first use. | a hash list with the keys ok, nameid, issuer, audience, notbefore, notonorafter and why | pcXml=the signed assertion or response as XML text; pnNow=the moment to judge at, in epoch seconds | ConsumeXml, ConsumeResponseAt, SetClockSkew | the nameid comes back still XML-escaped by the engine: a subject x&y is returned as x&amp;y, and a<b as a&lt;b; the window is checked with the clock skew on both sides | a signature from the wrong identity provider, an altered assertion, a wrong audience, an expired window and a replay each give ok 0 with their own reason in why
NumberOfConsumedAssertions | Returns how many accepted assertions are still remembered for replay protection. | a number | | PurgeSeenAt
PurgeSeenAt | Forgets the accepted assertions whose replay window has passed and returns how many were forgotten. | a number | pnNow=the moment to judge at, in epoch seconds | NumberOfConsumedAssertions | | an assertion is kept until 600 seconds after it was accepted
Show | Prints the provider's entity id and the identity provider it trusts. | nothing; it prints a line | | EntityId, IdpEntityId
