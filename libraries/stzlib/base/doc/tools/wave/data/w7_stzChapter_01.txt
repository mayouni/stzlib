init | Reads a chapter's markdown file and splits it at once into prose, runnable cells, exercise references and stored-output fences. | nothing; the object is built | pcFile=the path of the chapter file, NN-<id>.<lang>.md; pcLang=the language code of this edition, used only to read the chapter's id from the file name and to report Language | Blocks, Run | raises error R35 (the file cannot be opened) when pcFile does not exist; the cells are not run here | the chapter's title is its first line that starts with "# "
File | Returns the path the chapter was read from, exactly as given. | a text | | Id, Language
Id | Returns the chapter's id, read from its file name by removing the NN- number prefix and the .<lang>.md tail. | a text such as find-then-apply | | File, Language | a file name that does not end with .<lang>.md for the language given keeps the .md tail: 99-plain.en.md opened as fr gives plain.en.md
Language | Returns the language code this edition of the chapter was opened with. | a text such as en | | Id
Title | Returns the chapter's title, the text of its first "# " line. | a text; an empty text when the file has no such line | | Id, RecapAchieved
Blocks | Returns the chapter in reading order as pairs of a kind and a value: prose, cell, exercise or fence. | a list of pairs; a cell pair holds the cell's number, an exercise pair its id, a prose or fence pair its text | | Cells, ExerciseIds
Cells | Returns the source of every runnable cell, the ring fences, with their #--> lines. | a list of text, in reading order | | Cell, NumberOfCells
NumberOfCells | Returns how many runnable ring cells the chapter holds. | a number | | Cells, NumberOfPromises
Cell | Returns the source of one runnable cell, with its #--> lines. | a text | n=the cell's number, from 1 | Cells, CellPromises | raises an index error (R2) for a number below 1 or above NumberOfCells
CellPromises | Returns the values a cell promises, the text after each #--> line. | a list of text; [ ] when the cell carries no promise | n=the cell's number, from 1 | Cell, NumberOfPromises | raises an index error (R2) for a number below 1 or above NumberOfCells
ExerciseIds | Returns the ids of the exercises the chapter points to with {{exercise:id}} lines. | a list of text, in reading order | | Blocks
NumberOfStoredOutputs | Returns how many fenced blocks of stored output the chapter holds: fences marked output, text, console or out. | a number; a guard refuses a chapter where it is above 0, because a chapter must show no output it did not just produce | | HasStoredOutput
HasStoredOutput | TRUE if the chapter holds at least one fenced block of stored output. | TRUE or FALSE | | NumberOfStoredOutputs
CalledNames | Returns the names the chapter's cells call, read from the code: what the chapter teaches. | a list of text without repeats, in order of first use; a name is a word of four characters or more written right before "(", so a class name after new is included and sort is not | | Cells, RecapAchieved
RecapAchieved | Returns the first bullet of the chapter's last "## " section, without its bold label, joined on one line. | a text; an empty text when the file has no "## " section | | Title, CalledNames | the last "## " section is taken whatever its title, so a chapter that does not end with its recap returns the first bullet of that other section
RunProgram | Returns the Ring program that Run executes, for a runner that batches several chapters. | a text: it loads the library by absolute path, prepares Hausa, optionally uses a world, then runs every cell inside its own try/catch between @@EDU-CELL markers | pcWorldFile=the path of a world file to use, or an empty text for none | Run, WhereProgram | nothing is run by this call
WhereProgram | Returns the plain-Ring program that ObserveWhere executes: the same cells, without the library and without a world. | a text | | ObserveWhere, RunProgram | nothing is run by this call
Run | Runs every cell in one fresh process with the library loaded and records each cell's output, error and promise verdict. | nothing; RunQ is the same call and returns the chapter | pcWorldFile=the path of a world file for the cells that read the world, or an empty text for none | AcceptRun, CellKept, AllPromisesKept | a failing cell does not stop the others; with no world, a cell that asks for one fails with "No world is in use" and the chapter is then not AllCellsRan; the child process loads the whole library, so a run takes seconds | the cells run on the desktop only
AcceptRun | Takes the result of RunProgram run elsewhere, [ stdout, exit code, stderr ], and records each cell's output, error and promise verdict. | nothing | paRun=the list [ stdout, exit code, stderr ] of the run | Run, RunProgram | a cell the output never reached keeps the error "(not reached)" and an empty output; the exit code is not read
HasRun | TRUE if Run or AcceptRun has been called on this chapter. | TRUE or FALSE | | Run, AcceptRun
CellOutput | Returns what one cell printed in the last run, one line per print, each ended by a line break. | a text | n=the cell's number, from 1 | CellError, CellKept | raises an index error (R2) before any run, and for a number out of range
CellError | Returns the error one cell raised in the last run. | a text; an empty text when the cell ran cleanly, and "(not reached)" for a cell the run never got to | n=the cell's number, from 1 | CellRan, CellOutput | raises an index error (R2) before any run
CellRan | TRUE if one cell raised no error in the last run. | TRUE or FALSE | n=the cell's number, from 1 | CellError, AllCellsRan | raises an index error (R2) before any run
CellKept | Returns whether one cell kept its promises in the last run. | 1 when every #--> value was printed in order, 0 when one was not, -1 when the cell carries no promise | n=the cell's number, from 1 | CellPromises, AllPromisesKept | raises an index error (R2) before any run
AllCellsRan | TRUE if no cell raised an error in the last run. | TRUE or FALSE | | CellRan, AllPromisesKept | raises an index error (R2) before any run
AllPromisesKept | TRUE if no cell broke a promise in the last run; cells without a promise do not count. | TRUE or FALSE; TRUE before any run, because nothing is broken yet | | AllCellsRan, CellKept | call HasRun first: before a run the answer says nothing about the chapter
NumberOfPromises | Returns how many #--> promises the chapter's cells hold in all. | a number; it needs no run | | CellPromises, WorldDependentCells
WorldDependentCells | Returns the numbers of the cells that carry no promise, whose output depends on the world and so may not be shown on a page. | a list of numbers; [ ] before any run | | CellKept, NumberOfPromises | a cell that carries no promise is listed whether or not it ran
ObserveWhere | Runs the cells in plain Ring, without the library, and marks each one browser or desktop from what happened. | nothing | | AcceptWhere, RunsWhere, Where | a cell is marked browser when it raised no error and either carries no promise or keeps its promises; a cell that calls any library class is therefore marked desktop, which is every cell of chapter 1 | the mark is observed, never typed by an author; the cells run on the desktop only
AcceptWhere | Takes the result of WhereProgram run elsewhere, [ stdout, exit code, stderr ], and marks each cell browser or desktop. | nothing | paRun=the list [ stdout, exit code, stderr ] of the plain-Ring run | ObserveWhere, WhereProgram | the exit code is not read
RunsWhere | Returns where one cell was observed to run. | browser or desktop, as text | n=the cell's number, from 1 | Where, ObserveWhere | raises an error saying where a cell runs is observed, never assumed, when ObserveWhere or AcceptWhere has not been called
Where | Returns the observed place of every cell, in order. | a list of text, browser or desktop; [ ] before ObserveWhere | | RunsWhere, ObserveWhere
