init | Builds an empty pool of worker profiles, with its own copy of the standard facet catalog. | nothing; the object is built | | StzWorkerPoolQ, CatalogQ
CatalogQ | Returns the facet catalog this pool draws its facets from. | a stzFacetCatalog | | SetCatalog, DefineFacet, AddFacet
SetCatalog | Replaces the pool's facet catalog with a catalog you built; do it before adding facets. | the pool itself, so calls chain | poCatalog=the stzFacetCatalog to use from now on | CatalogQ, DefineFacet
DefineFacet | Adds or overrides an engine-native facet in the pool's own catalog. | the pool itself, so calls chain | pcName=the facet's name; paCaps=the capabilities it serves, as a list; paModules=the library modules realizing it, as a list | AddFacet, DefinePolyglotFacet
DefinePolyglotFacet | Adds a facet to the pool's own catalog that is served by an outside tool. | the pool itself, so calls chain | pcName=the facet's name; paCaps=the capabilities it serves, as a list; pcTool=the name of the external tool | DefineFacet, AddFacet
AddFacet | Adds a profile for a facet of the pool's catalog, taking its capabilities, modules and tool from there. | nothing; use AddFacetQ to get the pool back | pcName=the facet's name, as defined in the catalog; nBudget=the number of concurrent slots | AddProfile, SeedAllFacets, DefineFacet | a facet that is not in the catalog raises an error; a tag already in the pool raises an error too
SeedAllFacets | Adds one profile for every facet of the catalog, each with the same budget. | the pool itself, so calls chain | nBudget=the slots given to every profile; a value below 1 is taken as 1 | AddFacet, Tags | the standard catalog holds 18 facets, from text to vision
AddProfile | Adds a profile of your own, outside the catalog, under a tag. | nothing; use AddProfileQ to get the new profile back | pcTag=the profile's tag, compared without regard to case; paCapabilities=the capabilities it serves, as a list; pnBudget=the number of concurrent slots | AddProfileQ, AddFacet | a tag already in the pool raises an error saying the profile already exists
ProfileQ | Returns the profile with a tag, to read it or to call it in a chain. | a stzWorkerProfile; an empty text when the tag is unknown | pcTag=the profile's tag, without regard to case | HasProfile, Tags | an object kept in a variable is a copy: change a profile by calling ProfileQ again each time, not through the variable
HasProfile | TRUE if the pool has a profile under that tag. | TRUE or FALSE | pcTag=the tag to look for, without regard to case | ProfileQ, Tags
NumberOfProfiles | Returns how many profiles the pool holds. | a number | | Tags, HasProfile
Tags | Returns the tags of the profiles, in the order they were added. | a list of text, in lower case | | NumberOfProfiles, ProfileFor
ProfileFor | Returns the tag of the first profile that serves a capability, to route work by what it needs. | a text; empty when no profile serves it | pcCapability=the capability to route, as a text or a symbol | Tags, Dispatch
SetReactorPool | Attaches a reactor pool, kept for the later fleet wiring; nothing in the pool uses it yet. | the pool itself, so calls chain | poReactorPool=the reactor pool to keep | ReactorPoolQ
ReactorPoolQ | Returns the reactor pool attached to this pool. | the attached object; an empty text when none | | SetReactorPool
Dispatch | Runs a function now if the profile has a free slot, else queues it, or sheds it when the queue is full. | a hashlist: admitted 1 with result and tag when it ran; admitted 0 with queued 1 when queued; admitted 0 with shed 1 when refused | pcTag=the tag of the profile that takes the work; fWork=the function to call, with no argument | Drain, Acquire, Results | an unknown tag raises an error; the function runs in this process, no worker process is started; a full profile never touches another profile's slots
Acquire | Reserves a slot of a profile without running any work, to model a long job in flight. | TRUE when a slot was taken, FALSE when the profile is over budget | pcTag=the tag of the profile | Release, Dispatch | an unknown tag raises an error
Release | Frees one reserved slot of a profile. | the pool itself, so calls chain | pcTag=the tag of the profile | Acquire, Drain | an unknown tag raises an error
Drain | Runs the queued work of every profile as far as its free slots allow. | a number: how many queued items ran in this pass | | Dispatch, QueueDepth
InFlight | Returns how many slots a profile holds now. | a number; 0 for an unknown tag | pcTag=the tag of the profile | QueueDepth, Metrics
QueueDepth | Returns how many pieces of work wait in a profile's queue. | a number; 0 for an unknown tag | pcTag=the tag of the profile | Drain, Dispatch
ShedCount | Returns how many pieces of work a profile has shed because its queue was full. | a number; 0 for an unknown tag | pcTag=the tag of the profile | Dispatch
Results | Returns the values produced by the work that ran, in the order it ran. | a list of [ tag, value ] pairs | | Dispatch, Drain
Metrics | Returns a snapshot of every profile for a health console or an autoscaler. | a list of hashlists with the keys tag, budget, inflight, queue, admitted and rejected | | InFlight, QueueDepth
Narrate | Returns a text that describes the pool: one line per profile with its slots and queue. | a text with lines separated by a new line | | Metrics
