init | Creates an empty declaration of a node topology, under a name; nothing is started. | nothing; the object is built | pcName=the application's name, stored in lower case | Node, Describe
Name_ | Returns the application's name, in lower case. | a text | | init
Node | Declares a node by name, or makes the existing one current, so that the next On, Requires, Boot, AtHost and AtPort calls apply to it. | the app itself, so calls chain | pcName=the node's name, stored in lower case | On, Requires, AtHost | declarations are plain data; nothing starts until RunLocal
On | Declares a handler on the current node: a message tag and the Ring code that computes the reply. | the app itself, so calls chain | pcTag=the message tag, stored in lower case; pcRingCode=Ring code as text, in which the message list aMsg is in scope and which returns the reply | Node, Describe | the handler is a code string, not a function, so that it can cross a process boundary; called before any Node it raises R2 Array Access (Index out of range)
Requires | Declares the facets the current node needs. | the app itself, so calls chain | paList=a list of facet names, or one name as text | Node | called before any Node it raises R2 Array Access (Index out of range)
Boot | Sets the code that runs at the top level of the node's process on every start and restart, before it serves. | the app itself, so calls chain | pcRingCode=Ring code as text that builds the node's resident state | On, RunLocal | a supervised restart gives a fresh process, so the boot code is what rebuilds its state
AtHost | Sets the host the current node binds, so that Deploy-style moves are one line. | the app itself, so calls chain | pcHost=the host or interface address, stored in lower case | AtPort, Deploy
AtPort | Sets the port the current node listens on. | the app itself, so calls chain | pnPort=the port; 0 lets RunLocal pick one | AtHost
InboxOf | Declares the bounded inbox of a node: its capacity and what to do when it is full. | the app itself, so calls chain | pcName=the node's name, made current; nCap=the most messages the inbox holds; cPolicy=the overflow policy, :DropOldest, :DropNewest or :Refuse | Node, On
Supervise | Declares a group of nodes to supervise and the restart strategy that applies. | the app itself, so calls chain | paNames=the node names in the group; pcStrategy=the restart strategy, such as :OneForOne | RestartBudget, RunLocal | only the first group's strategy is used today, and every node is supervised
RestartBudget | Sets how many restarts the supervisor may do within a time window before it escalates. | the app itself, so calls chain | nMax=the restarts allowed, 5 by default; nWindowMs=the window length in milliseconds, 30000 by default | Supervise, Escalated
NodeTtl | Sets how long each node process serves before it ends by itself. | the app itself, so calls chain | nMs=the time to live in milliseconds, 120000 by default | RunLocal
Describe | Returns the whole declaration as plain lists: [ app, name, nodes, groups, budget ]. | a list | | RunLocal | a node row is [ node, name, host, port, handlers, requires, inbox capacity, inbox policy, boot code ]; StzNodeAppFromDescription rebuilds an identical app from it, which was checked by comparing both descriptions
RunLocal | Starts every declared node as a real child process on this machine, on loopback, under a real supervisor. | the app itself, so calls chain | | Cycle, StopAll, Describe | spawns processes, binds ports and writes generated scripts into the working folder; calling it a second time while running changes nothing | not run: it starts child processes and listens on ports
Cycle | Lets the supervisor check its children and restart the dead ones; does nothing before RunLocal. | the app itself, so calls chain | | RunLocal, RestartsOf | the call that lets an agent host tick the app | run only before RunLocal, where it does nothing
RestartsOf | Returns how many times the supervisor restarted a node; -1 before RunLocal. | a number | pcName=the node's name | Escalated, Cycle | run only before RunLocal
Escalated | Returns how many times the supervisor gave up on a restart budget and escalated; 0 before RunLocal. | a number | | RestartBudget, RestartsOf | run only before RunLocal
KillNode | Kills a node's process, for chaos tests; supervision restarts it on its next Cycle. | the app itself, so calls chain | pcName=the node's name | Cycle, RestartsOf | does nothing before RunLocal | run only before RunLocal, where it does nothing
Deploy | Moves a node to another host with one line; while running, it also restarts the node there and re-points the registry. | the app itself, so calls chain | pcName=the node's name; pcHost=the host to move it to | AtHost, RunLocal | before RunLocal it only records the new host | run only before RunLocal, where it only changes the declaration; the running case is read from the code and not run
StopAll | Sends stz.stop to every node, destroys the supervisor, deletes the generated scripts and marks the app stopped. | the app itself, so calls chain | | RunLocal | sends messages over the node plane | not run: it talks to nodes
