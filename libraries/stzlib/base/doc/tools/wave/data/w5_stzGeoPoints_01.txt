# stzGeoPoints -- probed on three patterns of 150-200 invented places in Niger's window (8 regions, 1183624 km2) whose truth is known
init | Builds a pattern from places and their window; raises an error for an odd list, a window that is not a stzGeoFeatures, or an empty one. | nothing; the pattern is built | paLonLat=the places as one flat list lon, lat, lon, lat, ...; poWindow=the stzGeoFeatures of the region the places were observed in | StzGeoPoints, With | | Computes the window's area and perimeter and counts the places that fall outside it
Points | Returns the places of the pattern. | a flat list lon, lat, lon, lat, ... | | Count, With
Count | Returns how many places the pattern holds. | a number | | Points, Outside
Window | Returns the features that make the window. | a stzGeoFeatures | | WindowRings, AreaKm2
WindowRings | Returns the outer ring of every part of the window, the shape the engine takes. | a list of flat lon, lat lists, 8 for Niger | | Window, WindowBox | | Holes are not carried, so a lake inside the window counts as window
AreaKm2 | Returns the area of the window in square kilometres, on WGS84. | a number of km2; 1183623.9 for Niger's eight regions | | BoxAreaKm2, DensityPerKm2
WindowBox | Returns the box around the window, in longitude and latitude. | a list [ lonMin, latMin, lonMax, latMax ] in degrees | | BoxAreaKm2, WindowRings | | The simulations place candidates in this box and keep those inside the window
BoxAreaKm2 | Returns the area of the window's box in square kilometres: more than the window, and what a cluster process needs. | a number of km2; 2207102.6 for Niger | | AreaKm2, WindowBox | | Parents are drawn in the box so the window's edge is not emptier than its middle
PerimeterKm | Returns the total length of the window's outer rings, in kilometres. | a number of km; 12734.1 for Niger | | AreaKm2 | | Donnelly's edge correction of Clark-Evans needs it. Internal borders between regions count too
Outside | Returns how many places fall outside the window they were said to be observed in. | a number, 0 for a clean pattern | | Findings, Count | | Reported, never dropped: they stay in the count and the density
DensityPerKm2 | Returns the places per square kilometre of the window. | a number, 0.000127 for 150 places in Niger; 0 for a window with no area | | AreaKm2, Count
NearestNeighbourKm | Returns, for every place, the distance in km to its nearest other place. | a list of numbers, one per place | | ClarkEvans, G
ClarkEvans | Returns the Clark-Evans nearest-neighbour index, corrected for the edge by Donnelly, with its z and a verdict. | a hash list [ :r, :z, :observed, :expected, :verdict ]; r below 1 is closer than chance, the verdict is "clustered", "dispersed" or "random" at z beyond 1.96 | | ClarkEvansUncorrected, RipleyK, Envelope | | Needs a few dozen places to mean anything: Findings warns below 30
ClarkEvansUncorrected | Returns the naive Clark-Evans index with no edge correction, for comparison with the older literature. | a hash list [ :r, :z, :observed, :expected, :verdict ] | | ClarkEvans | | Leans toward "dispersed" on every real window: 150 uniform places read dispersed at z 2.26
RipleyK | Returns Ripley's K at each radius, not corrected for the edge. | a list of numbers in km2, one per radius | paRadiiKm=the distances in km, ascending and not empty | L, Envelope | | Raises an error for radii that do not ascend. K falls short at large radii near the window's border; Envelope is the answer, not a formula
L | Returns sqrt(K / pi) minus the radius, at each radius: about 0 for random places, above 0 for clusters, below 0 for dispersion. | a list of numbers in km, one per radius | paRadiiKm=the distances in km, ascending and not empty | RipleyK, EnvelopeL | | Raises an error for radii that do not ascend
G | Returns the share of places whose nearest neighbour lies within each radius. | a list of numbers from 0 to 1, one per radius | paRadiiKm=the distances in km, ascending and not empty | F, NearestNeighbourKm | | 0 below a hard-core distance and near 1 quickly for clusters
F | Returns the share of random test places in the window that have a pattern place within each radius, the empty-space distribution. | a list of numbers from 0 to 1, one per radius | paRadiiKm=the distances in km, ascending and not empty; pnTests=how many random test places to throw; pnSeed=the seed of the random draw | G, Envelope | | Slow to rise for clusters, which leave much ground empty
Envelope | Returns the null band of K by simulation: the lowest, highest and mean K of pnSims uniform patterns of the same count in the same window. | a list of [ lo, hi, mean ], one per radius | paRadiiKm=the distances in km, ascending and not empty; pnSims=how many simulated patterns, 39 being the classic count; pnSeed=the seed of the random draw | EnvelopeL, RipleyK | | The nulls have the same edge as the data, so no correction is needed. The band widens with pnSims
EnvelopeL | Returns the same null band in the form of L, so it plots against L. | a list of [ lo, hi, mean ] in km, one per radius | paRadiiKm=the distances in km, ascending and not empty; pnSims=how many simulated patterns, 39 being the classic count; pnSeed=the seed of the random draw | Envelope, L | | An observed L above hi is clustering at that radius, below lo is dispersion
MeanCentre | Returns the centre of mass of the places, on the sphere. | a list [ lon, lat ] in degrees | | SpatialMedian, Ellipse | | For a clustered pattern it can fall in empty ground between the clusters
SpatialMedian | Returns the point of least total distance to all the places. | a list [ lon, lat ] in degrees | | MeanCentre | | Sits in the biggest cluster where the mean centre sits between them
Ellipse | Returns the standard deviational ellipse: centre, standard distance, semi-axes and the bearing of the major axis. | a hash list [ :lon, :lat, :sd, :major, :minor, :bearing ]; km, and degrees clockwise from north | | EllipseRing, MeanCentre
EllipseRing | Returns the standard deviational ellipse as a ring a projection can draw. | a flat list lon, lat, ... of pnPoints points | pnPoints=how many points the ring has | Ellipse, stzGeoProjection.Ring | | Draw it with Ring, so a seam cuts it correctly
Sample | Returns pnHowMany places thrown uniformly on the sphere inside the window. | a flat list lon, lat, lon, lat, ... | pnHowMany=how many places; pnSeed=the seed of the random draw | SampleClustered, SampleDispersed, With | | Seeded: the same seed gives the same pattern, so a picture does not move
SampleClustered | Returns a Matern cluster pattern: parents thrown in the window's box, children thrown in a disc round each and kept inside the window. | a flat list lon, lat, lon, lat, ... | pnParents=how many cluster centres; pnChildren=the mean number of children per parent; pnRadiusKm=the radius of each cluster's disc in km; pnSeed=the seed of the random draw | Sample, SampleDispersed | | The children count is a mean, so the total varies: 8 parents of 25 gave 182 places
SampleDispersed | Returns a hard-core pattern: no two places closer than pnMinKm. | a flat list lon, lat, lon, lat, ...; fewer than asked when the window cannot hold that many discs | pnHowMany=how many places to try for; pnMinKm=the least distance between two places in km; pnSeed=the seed of the random draw | Sample, SampleClustered | | Read the count it gives back
With | Returns a new pattern of other places in the same window. | a stzGeoPoints | paLonLat=the places as one flat list lon, lat, lon, lat, ... | Points, Sample | | The usual way to turn Sample's answer into something measurable
Findings | Returns what is wrong with the pattern: places outside the window, too few places to judge, a window with no area. | a list of [ :rule, :subject, :where, :severity, :message ]; [ ] when clean | | IsSound | | Fewer than 30 places is a warning, a window without area is an error
IsSound | TRUE if the pattern has no finding of severity error. | TRUE or FALSE | | Findings | | Warnings do not count: a pattern with a place outside the window is still sound
