init | Builds a trimmer over a text or over a stzString object, to strip spaces or a chosen character from its ends. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, to trim | Trim, TrimChar | Given a stzString object, the first in-place trim (Trim, TrimLeft, TrimRight, TrimStart, TrimEnd, TrimChar and the other TrimChar forms) leaves that stzString EMPTY while the trimmer holds the result; the passive forms (Trimmed ...) do not. Pass the text, os.Content(), to be safe | any other kind of value raises "Can't create stzStringTrimmer! Parameter must be a string or stzString object."
Content | Returns the text the trimmer holds, after any in-place trim. | a text | | Trimmed | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | |
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | | a text of spaces is not empty
Trim | Removes the white space at both ends of the text, in place. | nothing; use TrimQ to chain | | Trimmed, TrimLeft, TrimRight | | spaces, tabs and line breaks count as white space; spaces inside are kept
Trimmed | Returns the text without white space at both ends, leaving the trimmer unchanged. | a text | | Trim | | "  hello world  " gives "hello world"; a text of spaces gives ""
TrimLeft | Removes the white space at the start of the text, in place. | nothing; use TrimLeftQ to chain | | TrimmedLeft, TrimStart | | TrimStart is the same method
TrimmedLeft | Returns the text without white space at its start, leaving the trimmer unchanged. | a text | | TrimLeft | | TrimmedFromStart is the same method
TrimRight | Removes the white space at the end of the text, in place. | nothing; use TrimRightQ to chain | | TrimmedRight, TrimEnd | | TrimEnd is the same method
TrimmedRight | Returns the text without white space at its end, leaving the trimmer unchanged. | a text | | TrimRight | | TrimmedFromEnd is the same method
TrimStart | Removes the white space at the start of the text, in place, exactly as TrimLeft does. | nothing; use TrimStartQ to chain | | TrimLeft | |
TrimEnd | Removes the white space at the end of the text, in place, exactly as TrimRight does. | nothing; use TrimEndQ to chain | | TrimRight | |
TrimChar | Removes every repeat of one character from both ends of the text, in place, comparing case-sensitively. | nothing; use TrimCharQ to chain | _c_=the one character to strip | CharTrimmed, TrimCharFromStart, TrimCharFromEnd | | "--a-b--" gives "a-b"; a text of only that character becomes empty; a padding of more than one character, such as "ab", removes nothing; TrimCharCS(c, 0) ignores case
CharTrimmed | Returns the text without that character repeated at both ends, leaving the trimmer unchanged. | a text | _c_=the one character to strip | TrimChar | | "xXaXx" with "x" gives "XaX"; CharTrimmedCS("x", 0) gives "a"
TrimCharFromStart | Removes every repeat of one character from the start of the text, in place, comparing case-sensitively. | nothing; use TrimCharFromStartCSQ to chain | _c_=the one character to strip | TrimCharFromEnd, TrimChar | | "--a--" becomes "a--"
RemoveThisCharFromStart | Removes every repeat of one character from the start of the text, in place, exactly as TrimCharFromStart does. | nothing | _c_=the one character to strip | TrimCharFromStart | |
TrimCharFromEnd | Removes every repeat of one character from the end of the text, in place, comparing case-sensitively. | nothing; use TrimCharFromEndCSQ to chain | _c_=the one character to strip | TrimCharFromStart, TrimChar | | "--a--" becomes "--a"
RemoveThisCharFromEnd | Removes every repeat of one character from the end of the text, in place, exactly as TrimCharFromEnd does. | nothing | _c_=the one character to strip | TrimCharFromEnd | |
TrimCharFromLeft | Removes a character repeated at the left end of the text, in place: the start for left-to-right text, the end for right-to-left. | nothing | _c_=the one character to strip | TrimCharFromRight, TrimCharFromStart | It always takes the start today: the direction test answers TRUE for Hebrew and Arabic, so for "ببمرحباب" TrimCharFromLeft("ب") strips the leading ones, the same as TrimCharFromStart |
TrimCharFromRight | Removes a character repeated at the right end of the text, in place: the end for left-to-right text, the start for right-to-left. | nothing | _c_=the one character to strip | TrimCharFromLeft, TrimCharFromEnd | It always takes the end today, for the same reason as TrimCharFromLeft: right-to-left text is treated as left-to-right |
