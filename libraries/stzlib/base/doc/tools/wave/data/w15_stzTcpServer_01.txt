init | Builds a TCP server that is not listening and has no callbacks. | nothing; the object is built | | Listen
Listen | Starts listening on a port and returns at once, firing the error callback on failure. | the server itself, so calls chain | nPort=the port number; cHost=the address to listen on, where an empty text means 0.0.0.0, every network interface | AcceptOne, StopListening, IsListening | a failure does not raise: IsListening stays FALSE and LastError says why; a second listener on a port already bound reported listening too on this Windows machine, with no error | for a local test pass 127.0.0.1, since an empty host opens the port to the network
AcceptOne | Blocks until a client connects and returns it wrapped as a connected stzTcpClient. | a stzTcpClient; an empty text when the server is not listening or the accept failed, with LastError saying why | | AcceptOneWithin, Listen | it waits for ever when nobody connects; keep each accepted client and close it | the client is kept in the server's list as well
AcceptOneWithin | Waits at most that many milliseconds for a client and returns it, or an empty text if none came. | a stzTcpClient; an empty text on timeout or error | nMs=the longest wait in milliseconds | AcceptTimedOut, AcceptOne | | after a timeout LastError is accept timed out, which AcceptTimedOut tests
AcceptTimedOut | TRUE if the last wait for a client ended by timeout and not by failure. | TRUE or FALSE | | AcceptOneWithin
StopListening | Closes the listening socket; calling it on a server that is not listening does nothing. | the server itself, so calls chain | | Listen, IsListening | | accepted clients stay open until they are closed
OnClientConnect | Sets the function called each time a client is accepted. | the server itself, so calls chain | cCallback=the name of a function that takes no parameter | AcceptOne, OnError | | choose a function name of your own: a name the library already defines as a function with parameters fails with a wrong-parameter error
OnClientDisconnect | Stores a function name meant to run when a client disconnects. | the server itself, so calls chain | cCallback=the name of a function | OnClientConnect | the server never calls it today | it is kept but not used
OnClientMessage | Stores a function name meant to run when a client sends a message. | the server itself, so calls chain | cCallback=the name of a function | OnClientConnect | the server never calls it today | read each client's data with its own Receive
OnError | Sets the function called when Listen or an accept fails. | the server itself, so calls chain | cCallback=the name of a function that takes no parameter | Listen, LastError
IsListening | TRUE if the server is listening. | TRUE or FALSE | | Listen, StopListening
NumberOfClients | Returns how many clients the server has accepted. | a number | | AcceptOne
