ToStzTable | Returns the comparison as a stzTable with one column per variation and one row per metric, such as NodesAdded and HasCycles. | a stzTable | | Show, Data
Show | Prints the comparison table, one column per variation, in the console. | nothing; a table is printed | | ToStzTable, Display
Display | Prints the comparison table; another spelling of the display call. | nothing; a table is printed | | Show
Data | Returns the whole comparison as a hash list holding the rows, the baseline id and the count of variations. | a hash list [ :comparisons, :baseline, :count ] | | Comparisons, Summary
Content | Returns nothing today instead of the comparison data. | nothing today | | Data | known defect: the body is empty, so the call answers empty text; Data returns the comparison
Comparisons | Returns one hash list per variation with its name and its counts of nodes and edges added and removed. | a list of hash lists [ :name, :nodesadded, :nodesremoved, :edgesadded, :edgesremoved, :densitychange, :hascycles, :bottleneckchange, :explanation ] | | Data, Summary
Summary | Returns a text report naming the baseline and the count of variations, with one bulleted line per variation explaining its change. | text, one line per variation | | Comparisons, Recommend
MostImpactful | Returns the name of the variation with the most node and edge changes, added plus removed; empty when none changed anything. | text; empty when every variation is unchanged | | LeastImpactful, ByMetric
LeastImpactful | Returns the name of the variation with the fewest node and edge changes, the first one on a tie. | text | | MostImpactful, ByMetric
WithCycles | Returns an empty list today instead of the names of the variations that contain a cycle. | [ ] today, even when a variation has a cycle | | WithoutCycles, Recommend | known defect: the rows hold the text TRUE or FALSE in the cycle field, and the body tests it against the number 1
WithoutCycles | Returns an empty list today instead of the names of the variations that stay acyclic. | [ ] today, even when a variation is acyclic | | WithCycles, Recommend | known defect: the rows hold the text TRUE or FALSE in the cycle field, and the body tests it against the number 0
ByMetric | Returns the variation names from the highest to the lowest value of one column, such as :nodesAdded; an unknown column raises an error. | a list of text | | Comparisons, MostImpactful | | on a text column such as the density change the order is the text order
Recommend | Scores each variation and returns the best with a reason; the score rewards fewer bottlenecks, denser links and added nodes over removed. | a hash list [ :recommended, :reason ] | | WithoutCycles, MostImpactful | the acyclic bonus of 10 points is never awarded because the cycle field holds text, so a variation with a cycle can win, and the reason text is the same for every answer
