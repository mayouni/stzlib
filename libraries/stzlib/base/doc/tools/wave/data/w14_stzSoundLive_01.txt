init | Builds a live session at 120 beats per minute with no loops, started on a sound card unless capture is chosen. | nothing; the object is built | | StzSoundLiveQ, CaptureInsteadOfDevice | build it with StzSoundLiveQ to set the speed in the same call; a cycle is one bar of 4 beats
SetTempo | Sets the speed of the session in beats per minute. | the session itself, so calls chain | pnBpm=the speed in beats per minute, from 20 to 400 | Tempo, CycleFrames | refused, with LastError set and the refusal counted, once the session runs, once any loop is defined, or for a value outside the range | it builds a new renderer, because the notes of a loop are rendered at the speed in force
Tempo | Returns the speed of the session in beats per minute. | a number, 120 until set | | SetTempo
SetDefaultInstrument | Sets the instrument given to loops that name none and are made of pitched notes. | the session itself, so calls chain | pcName=the instrument name, such as piano or harp, kept in lower case | LiveLoop, LiveLoopOn | a loop of strokes ignores it and takes the drum kit, or the darbouka for dum, tak and ka | an unknown name is refused later, when a loop is defined with it
CaptureInsteadOfDevice | Chooses to drain the sound into a buffer instead of a sound card, for at most a number of seconds. | the session itself, so calls chain | pnSeconds=the length of the buffer that keeps what came out; pbPaced=TRUE to drain at the pace of the wall clock, FALSE to drain as fast as WaitCycles asks | Capture, OnDevice | refused once the loops have started; the buffer is silent beyond what was heard; WaitCycles for longer than pnSeconds never returns, see the defects file | this is the only way to run the session without opening an audio device; a device drains on its own thread, so a render in capture mode stalls the drain and proves nothing about late notes
Capture | Returns the buffer that capture mode fills with what has been heard. | a stzSound of the length given to CaptureInsteadOfDevice, with the same rate and channels as the session; an empty text before the loops start or when capture was not chosen | | CaptureInsteadOfDevice | read it after WaitCycles; the sound has not been heard by a person
OnCycle | Sets the function called each time a cycle boundary is heard, with the console line of that cycle. | the session itself, so calls chain | f=the function, or its name, to call with one text argument | ConsoleLog, HeardCycle | it fires when the frames consumed cross a cycle boundary, not when the cycle is posted, so the console never runs ahead of the sound
LiveLoop | Defines or redefines a loop from a pattern, naming the instrument itself. | the cycle the loop lands on, counted from 0; -1 when refused | pName=the loop's name, kept in lower case; pcPattern=a pattern of note names and strokes, such as c5 e5 g5 e5 or bd hh sn hh | LiveLoopOn, LiveLoopOf, Silence | a bad pattern, an unknown instrument, strokes on an instrument that is not struck or notes on a drum are refused with LastError set and the old version goes on playing; before the loops start a redefinition replaces and lands on cycle 0 | a redefinition lands on the first cycle boundary the producer has not reached
LiveLoopOn | Defines or redefines a loop from a pattern, played on a chosen instrument. | the cycle the loop lands on, counted from 0; -1 when refused | pName=the loop's name, kept in lower case; pcPattern=a pattern of note names and strokes; pInstrument=the instrument name, or an empty text for the session's default | LiveLoop, LiveLoopOf | refused like LiveLoop; every distinct note is rendered before anything already posted is touched | while running, the notes of the loop from the landing cycle on are withdrawn and posted again
LiveLoopOf | Defines or redefines a loop from a pattern object that has already been transformed. | the cycle the loop lands on, counted from 0; -1 when refused | pName=the loop's name, kept in lower case; poPattern=a valid stzSoundPattern; pInstrument=the instrument name, or an empty text for the default | LiveLoopOn | anything but a valid stzSoundPattern is refused, with LastError set
Every | Redefines a loop as itself transformed every so many cycles. | the cycle the loop lands on; -1 when refused | pnN=the period of the transform in cycles; pName=the name of an existing loop; pXform=the transform to apply, such as rev | LiveLoop, Silence | an unknown loop, a silenced loop or a transform the pattern refuses is refused with LastError set; the playing version is not touched | the change lands on a cycle boundary like any redefinition
Silence | Stops one loop from the first cycle boundary it can land on. | the cycle on which the loop falls silent; -1 for an unknown loop | pName=the name of the loop to silence | Hush, LiveLoop | the loop stays defined and can be redefined later
Hush | Silences every loop at the first cycle boundary each can land on. | the cycle of the last loop's landing; -1 when there are no loops | | Silence
Start | Posts the first window of notes and starts the performance, on a sound card or into the capture buffer. | TRUE if running; FALSE with LastError set when there are no loops or the engine refused | | WaitCycles, DriveWith, Stop | without CaptureInsteadOfDevice it opens an audio device through a transport, which was not run in this reference | asking again while running answers TRUE
Tick | Posts what is due, drains the ring in paced capture mode and reports the cycles heard. | the session itself, so calls chain | | WaitCycles, DriveWith | does nothing unless the session runs | a reactive loop calls it every 20 ms for a driven session
WaitCycles | Lets the session run for a number of heard cycles, starting it first when needed, and then returns. | the session itself, so calls chain | pnCycles=how many cycles of heard time to wait | Start, Tick | in capture mode it never returns when the wait is longer than the capture buffer, see the defects file; without capture it plays on a device, which was not run in this reference | the wait counts heard frames, not posted ones
DriveWith | Starts the session when needed and registers it so that a reactive loop steps it every 20 ms. | the session itself, so calls chain | poReactive=the stzReactive whose loop should call the session | Tick, Stop | anything but a stzReactive is refused, with LastError set; the reactive loop itself was not run in this reference | the session is registered by pointer in a global list and Stop removes it
Stop | Takes the session out of any reactive loop and stops the performance, keeping the loops and the logs. | the session itself, so calls chain | | Release, Start | does nothing to a session that is not running
Release | Stops the session, then frees the graph and the rendered notes. | nothing | | Stop | call it once nothing is playing, since the timeline reads the note samples directly
IsRunning | TRUE if the performance has started and not been stopped. | TRUE or FALSE | | Start, Stop
CycleFrames | Returns how many frames one cycle of 4 beats lasts at the session's speed. | a number of frames; 96000 at 120 beats per minute and 48000 Hz | | FrameOfCycle, Tempo
FrameOfCycle | Returns the frame at which a cycle begins. | a number of frames, counted from 0 | pnCycle=the cycle number, counted from 0 | CycleFrames | computed with the same function the offline render uses
HeardFrames | Returns the frames the listener has been given: those the device consumed, or those capture mode drained. | a number of frames; 0 before the loops start | | HeardCycle, RenderFrames | it can pass a cycle boundary by a few hundred frames, since draining is done in chunks
HeardCycle | Returns the number of the last cycle whose boundary has been heard. | a number counted from 0; -1 before any | | ConsoleLog, OnCycle
RenderFrames | Returns how far the producer has rendered the timeline, in frames. | a number of frames; 0 before the loops start | | HeardFrames | it runs ahead of HeardFrames by about a ring, a cycle and half a second
ConsoleLog | Returns one row per cycle as it was heard. | a list of [ cycle, heardFrame, text ] rows, the text such as cycle 1 and each loop with its version | | Ledger, OnCycle | the text reports what was posted for that cycle, not the latest definition
Ledger | Returns what was posted for each cycle. | a list of [ cycle, loop name, version ] rows | | ConsoleLog, Landings | rows for cycles from a landing cycle on are dropped when a loop is redefined and posted again
Landings | Returns where each definition of a loop took effect. | a list of [ loop name, version, landing cycle, cycle heard when it was asked ] rows | | Ledger, LiveLoop | before the loops start every landing is cycle 0 and the heard cycle is -1; a loop redefined twice before the start and once while running is numbered v3 and then v2, so version numbers can go back, see the defects file
Late | Returns how many notes reached the timeline after the producer had rendered their frame. | a number; 0 is the answer to want | | Cancelled, MidCycleChanges | 0 before the loops start
Cancelled | Returns how many notes were withdrawn before they sounded, by a redefinition. | a number | | MidCycleChanges | measured: redefining a four-note loop at heard cycle 1 withdrew 4 notes
MidCycleChanges | Returns the withdrawals the engine refused because the note was already sounding, which would be a change in the middle of a cycle. | a number; it should stay 0 | | Cancelled | it is the kill criterion of the live design
NotesRenderedLive | Returns how many notes were rendered while the session was playing, because a pattern ran past its first period. | a number | | SecondsRendering
SecondsRendering | Returns the wall time spent rendering the notes of the loops, in seconds. | a number | | NotesRenderedLive
DrainShortfall | Returns the frames that paced capture was due to drain and the ring did not yet hold. | a number; 0 outside paced capture | | CaptureInsteadOfDevice, Underruns
Underruns | Returns the frames the sound card asked for and did not get, as of the last step. | a number; 0 in capture mode | | DrainShortfall
OnDevice | TRUE if the session plays on a sound card, FALSE if capture was chosen. | TRUE or FALSE; TRUE for a new session | | CaptureInsteadOfDevice
Renderer | Returns the renderer that holds the notes of the loops. | a stzSoundScoreRenderer | | stzSoundScoreRenderer
