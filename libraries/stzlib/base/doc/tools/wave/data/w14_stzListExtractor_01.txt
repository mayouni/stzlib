# w14 stzListExtractor -- Name | brief | returns | params | see | warning | note
init | Builds an extractor over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to take items out of, or a stzList whose content is copied, any other value raises an error | Content, ExtractFirst | | the extractor works on its own copy: taking items out never changes the list or the stzList you passed in, so read what is left with Content
Content | Returns the items still in the list, after the extractions made so far. | a list | | List, ExtractAll
List | Returns the items still in the list, after the extractions made so far. | a list | | Content, NumberOfItems | | the same answer as Content
NumberOfItems | Returns how many items are still in the list. | a number | | Content, IsEmpty
IsEmpty | TRUE if no item is left in the list. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
Extract | Takes an item out of the list and returns it, removing every occurrence of it. | the item that was taken out | pItem=the item to take out | ExtractNthOccurrence, ExtractFirstOccurrence, ExtractNth | an item that is absent raises Can't extract the item! It does not exist in the list; it removes all the occurrences and not just one: a b c b d e loses both b | case counts: ExtractCS(pItem, 0) ignores case; ExtractMany(paItems) does the same for several items and returns the list it was given
ExtractAll | Takes every item out of the list and returns them, leaving it empty. | a list, the items that were in the list | | Take, Content
ExtractNth | Takes out the item at a position, counting from 1, and returns it. | the item that was taken out | n=the position of the item to take out | ExtractFirst, ExtractLast, ExtractSection | a position outside the list raises Index outside the list! naming the position and the size | the list closes up over the gap
ExtractFirst | Takes out the first item of the list and returns it. | the item that was taken out | | ExtractLast, ExtractNth | on an empty list it raises Index outside the list! | PopFirst is the same call
ExtractLast | Takes out the last item of the list and returns it. | the item that was taken out | | ExtractFirst, ExtractNth | on an empty list it raises Index outside the list! | Pop is the same call
ExtractSection | Takes out the items from one position to another, both included, and returns them. | a list, the items that were taken out | n1=the first position; n2=the last position | ExtractRange, Take, ExtractNth | a position outside the list raises Indexes out of range!, where Section of stzListGetter would clip | the items that stay close up over the gap
ExtractRange | Takes out a run of items given its first position and how many items it holds, and returns them. | a list, the items that were taken out | pnStart=the first position; pnRange=how many items to take out | ExtractSection, Take | a run that goes past the end raises Indexes out of range! (ExtractRange(2, 9) on three items) instead of being cut at the end
ExtractNthOccurrence | Takes out the nth occurrence of an item, leaving its other occurrences, and returns it. | the item that was taken out, or an empty text when there is no nth occurrence | n=which occurrence to take out, counting from 1; pItem=the item to look for | ExtractFirstOccurrence, ExtractLastOccurrence, Extract | | an empty text from a missing occurrence cannot be told from an item that is an empty text; ExtractNthOccurrenceCS(n, pItem, 0) ignores case and returns the item as it is spelt in the list
ExtractFirstOccurrence | Takes out the first occurrence of an item, leaving the others, and returns it. | the item that was taken out, or an empty text when it is absent | pItem=the item to look for | ExtractLastOccurrence, ExtractNthOccurrence | | ExtractFirstOccurrenceCS(pItem, 0) ignores case and returns the item as it is spelt in the list
ExtractLastOccurrence | Takes out the last occurrence of an item, leaving the others, and returns it. | the item that was taken out, or an empty text when it is absent | pItem=the item to look for | ExtractFirstOccurrence, ExtractNthOccurrence | | ExtractLastOccurrenceCS(pItem, 0) ignores case and returns the item as it is spelt in the list
ExtractDuplicates | Takes out every repeat, that is each occurrence after the first of its item, and returns them. | a list, the repeats that were taken out; [ ] when nothing repeats | | ExtractNthOccurrence, Extract | | the first occurrence of each item stays: a b a c b a gives a b a and leaves a b c; case counts, and ExtractDuplicatesCS(0) also treats a and A as one item
ExtractStrings | Takes out every item that is a text and returns them, in their order. | a list, the texts that were taken out | | ExtractNumbers, ExtractLists | | the other items stay in their order
ExtractNumbers | Takes out every item that is a number and returns them, in their order. | a list, the numbers that were taken out | | ExtractStrings, ExtractLists | | the other items stay in their order
ExtractLists | Takes out every item that is a list and returns them, in their order. | a list, the sublists that were taken out | | ExtractStrings, ExtractNumbers | | the other items stay in their order
Take | Takes out the first n items and returns them. | a list, the items that were taken out | n=how many items to take from the start | TakeLast, ExtractSection | | an n of 0 or larger than the list raises Indexes out of range!
TakeLast | Takes out the last n items and returns them. | a list, the items that were taken out | n=how many items to take from the end | Take, ExtractSection | | an n of 0 or larger than the list raises Indexes out of range!
