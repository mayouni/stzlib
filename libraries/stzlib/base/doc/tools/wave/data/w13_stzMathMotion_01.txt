init | Builds a motion over a function figure with named parameters, or over a solved diagram that declared states will move. | nothing; the object is built | pcKind=Function or Diagram, in any case; paSpec=for Function a declaration like a figure's, with {name} where a parameter goes, such as [ :f = "{a} * sin(x)", :on = [ -6, 6 ] ], and optionally :livesamples between 16 and 4000; for Diagram an stzMathDiagram, which is laid out first | Param, State, StzMathMotionQ, StzMathMotionOverQ | Raises an error for any other kind, for an empty or missing declaration, and for a Diagram given something that is not a stzMathDiagram | the motion over a diagram takes its own copy of the picture
Param | Declares a slider: a name the declaration writes as {name}, its range and its starting value. | the motion itself, so calls chain | pcName=the parameter's name, letters only such as a; pnFrom=the lowest value; pnTo=the highest value, above pnFrom; pnValue=the starting value, clamped into the range, and the range's start when it is not a number | Set, Value, Params | raises an error for a name with digits, a range that is not from below to, and a name that the declaration never writes as {name}; declaring the same name again replaces it | it marks the motion as moved, so the next frame settles
Params | Returns the declared sliders, each with its name, range and current value. | a list of [ name, from, to, value ] | | Param, Value
Value | Returns the current value of a slider. | a number | pcName=the parameter's name, in any case | Set, Params | raises an error naming a parameter that was not declared
Set | Moves a slider to a value, clamped to its range, the curve following on the next frame and the solved figure at the next Settle. | the motion itself, so calls chain | pcName=the parameter's name, in any case; pnValue=the new value, a number | Value, Settle, IsDirty | raises an error for a parameter that was not declared and for a value that is not a number
IsDirty | TRUE if a parameter moved since the figure was last settled, which is also the state of a new motion. | 1 or 0 | | Settle, Set
Resolved | Returns the declaration with every {name} replaced by the slider's current value in brackets. | a list of key and value pairs such as [ "f", "(2) * sin(x)" ] | | Settle, Param
Settle | Rebuilds the figure and solves it for the parameters as they stand, and keeps what that cost. | the motion itself, so calls chain | | SettleMs, IsDirty, Figure | | it takes about a second for a figure with marks, which is why it waits for a release rather than running every frame
SettleMs | Returns how many milliseconds the last Settle took. | a number; 0 before the first Settle | | Settle
Figure | Returns the settled figure, settling first if it never was. | the figure object, a stzMathFigure | | Settle, Picture
LiveCurve | Samples the curve at the current slider values as pieces of pixel coordinates, broken where it leaves the window. | a list of pieces, each a flat list of x, y, x, y ... | | LiveSamples, DrawLiveOn | | it settles the figure first if needed; each call adds the sample count to the tape calls of Counts
LiveSamples | Samples the curve at the current slider values in the author's own units. | a list of pairs [ x, y ], 240 of them by default | | LiveCurve, LiveSampleCount
DrawLiveOn | Clears a canvas and draws the live curve on it, the overlay a window shows over the settled picture, and keeps what it cost. | the motion itself, so calls chain | poCanvas=the stzCanvas that becomes the overlay, which is cleared first | FrameMs, Frame, Play
Counts | Returns how many settles, tape calls and canvas flushes the motion has made, so a test can assert the structure of a frame. | a hash-list with settles, tapecalls and flushes | | FrameMs
FrameMs | Returns how many milliseconds the last live frame took, overlay only. | a number; 0 before any live frame | | DrawLiveOn, Counts
LiveSampleCount | Returns how many points each live frame samples. | a number; 240 by default | | LiveSamples
Frame | Composes the settled picture and the live curve into one new canvas, the offscreen twin of what the window shows. | a stzCanvas that the caller must free | | FrameSVG, FramePNG
FrameSVG | Returns the composed frame as SVG text, without needing a window. | a text starting with the svg tag | | Frame, FramePNG
FramePNG | Writes the composed frame to a PNG file and returns the PNG bytes. | the PNG as a binary text; empty when this machine has no graphics device | pcPath=the file to write | Frame, FrameSVG | the returned text is the picture itself, so do not print it
Play | Runs the live window loop, moving the first parameter on left and right and the second on up and down, until Escape. | the motion itself | poWindow=an open stzWindow to draw in | PlayStates, DrawLiveOn | raises an error when the argument is not an object | blocks until Escape or the window is closed
State | Declares a state: a caption and the acts that bring the picture to it from the previous state. | the motion itself, so calls chain | pcCaption=what the reader is told, which may write {hole} for a fact; paActs=a list of acts, each a list led by its verb: DragTo, DragBy, SetData, SetTheme (for a diagram) or Set (for a function motion) | StateFact, Apply, ExportTo | raises an error for an empty caption, an unknown verb, a verb that does not fit the kind of motion, a drag of a shape with no free centre, and a missing parameter; a single act not wrapped in a list raises an operator error today instead of being accepted (confirmed with two different acts) | a state with no act is the picture as it stands
StateFact | Binds a fact that the caption of the last declared state shows as {hole}, computed on the picture at that state. | the motion itself, so calls chain | pcHole=the name written as {name} in the caption; pcKind=the kind of fact, such as expr, angle, value or datum; paArgs=the arguments of that fact, such as [ expression, unit ] | State, FactsOf | raises an error when no state is declared or when the caption never writes the hole
States | Returns every declared state as its caption, its acts and its facts. | a list of [ caption, acts, facts ] | | NumberOfStates, CaptionOf
NumberOfStates | Returns how many states are declared. | a number | | States
CaptionOf | Returns the caption of one state. | a text | pnState=the position of the state, from 1 | ActsOf, States | raises an error naming the count when the state is not declared
ActsOf | Returns the acts of one state, each led by its verb in lowercase. | a list of acts such as [ "dragby", "A.icon", 60, -30 ] | pnState=the position of the state, from 1 | CaptionOf | raises an error when the state is not declared
FactsOf | Returns the facts bound to one state, each as hole, kind and arguments. | a list of [ hole, kind, args ] | pnState=the position of the state, from 1 | StateFact | raises an error when the state is not declared
Applied | Returns the number of the state the picture stands in. | a number; 0 before any Apply | | Apply, ApplyAll
ApplyMs | Returns how many milliseconds the last Apply took. | a number; 0 before any Apply | | Apply | | the graph plane's drag budget is 100 ms
Story | Returns the storyboard made by the last export. | the stzStoryboard; empty text before any export | | ExportTo
Picture | Returns the picture as it stands: the motion's own copy for a diagram, the settled figure's diagram for a function. | the diagram object | | Apply, Figure
Apply | Performs the acts of one state on the motion's own picture, so the picture then stands in that state. | the motion itself, so calls chain | pnState=the position of the state, from 1 | ApplyAll, Applied, ApplyMs | raises an error when the state is not declared | the acts are applied from wherever the picture stands, so jumping over states skips their acts
ApplyAll | Applies every declared state in order. | the motion itself, so calls chain | | Apply
ExportTo | Writes every state as a PNG frame in a folder with its facts computed, plus a narration file, through a storyboard. | the stzStoryboard of the export | pcFolio=the folder to write into, current folder when empty; pcName=the name of the storyboard, which prefixes name_01.png, name_02.png and so on | Story, Apply, PlayStates | raises an error when no state is declared, when the name is empty, when a function motion draws its curve live, and when the machine has no graphics device; the parameters of a function motion are put back afterwards | the folder must exist
PlayStates | Shows each state on a window in turn, holding each for a time; Right or Space advance early, Escape closes, and the last state holds. | the motion itself | poWindow=an open stzWindow to draw in; pnDwellMs=how long to hold each state in milliseconds, 2000 when not a number | Play, Apply | raises an error when the argument is not an object or no state is declared | blocks until Escape or the window is closed
Why | Describes the motion in one sentence: its kind, its parameters and where they stand, whether it is settled, and its states. | a text | | Settle, Apply
