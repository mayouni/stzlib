VerifyIdToken | Decides whether an id-token may be believed, at the present time: signature, issuer, audience, expiry, not-before and nonce. | a list [ :ok, :subject, :email, :claims, :why ]: ok is 1 with the identity, or 0 with why naming the first check that failed | pcToken=the id-token returned by the provider; pcExpectedNonce=the nonce this login sent; the empty text skips that check | VerifyIdTokenAt, Why, AuthorizationUrl | a refusal is returned, never raised, and each one is also noted in the security ledger by issuer and reason, never with the token | the key is chosen by the token's kid (the only key when the token names none) and the algorithm comes from that key, never from the token
VerifyIdTokenAt | Decides whether an id-token may be believed at a given time, so that expiry can be tested without waiting. | a list [ :ok, :subject, :email, :claims, :why ], as for VerifyIdToken | pcToken=the id-token to check; pcExpectedNonce=the nonce this login sent; the empty text skips that check; pnNow=the time to judge by, in seconds since 1970 | VerifyIdToken, SetClockSkew | the checks run in order and stop at the first failure: shape, key, signature, issuer, audience, exp, nbf, nonce; a token with no exp is refused | the token is expired when pnNow is past exp plus the clock allowance
