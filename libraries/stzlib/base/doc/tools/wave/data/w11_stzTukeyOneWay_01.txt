init | Builds a one-way table of groups of numbers, to be fitted by median polish. | nothing; the object is built | paGroups=at least two groups, each a non-empty list of numbers, of lengths that may differ; otherwise an error is raised | Polish, NumberOfGroups
NumberOfGroups | Returns how many groups the table has. | a number | | Polish
Polish | Fits the groups by medians: a common value, an effect per group and a residual per value. | the fit itself, so calls chain | | Common, Effects, Residuals, Check | Common, Effects, Residuals and Check raise an error until Polish has run | for 1, 2, 3 / 4, 5, 9 / 10, 12, 20, 30 the common value is 5 and the effects are -3, 0 and 11
Common | Returns the median of the group medians. | a number | | Effects, Polish | Raises an error until Polish has run | 5 for the groups above
Effects | Returns each group's median minus the common value. | a list of numbers, one per group | | Common, Residuals | Raises an error until Polish has run | -3, 0, 11 for the groups above
Residuals | Returns each value minus the median of its group. | a list of lists, one per group, in the order given | | Effects, Check | Raises an error until Polish has run | [ -1, 0, 1 ], [ -1, 0, 4 ], [ -6, -4, 4, 14 ] for the groups above
Check | Returns the largest gap between a value and common plus effect plus residual, which is 0 when Data equals Fit plus Residual. | a number, 0 up to rounding | | Why, Residuals | Raises an error until Polish has run
Diagnostics | Returns a warning when the spread of the groups grows with their level, from the slope of log fourth-spread on log median. | a list of rows [ :rule, :subject, :where, :severity, :message ]; empty when the slope is within 0.5 | pcSubject=what the groups are called in the rows; an empty text gives groups | StzTukeySpreadLevel, stzTukeyReexpression | it does not need Polish; the rule is spread_tracks_level and the message gives the suggested power | spreads that double with the level, as 10 to 12, 20 to 24, 40 to 48 and 80 to 96, give slope 1 and the power 0, the log
Why | Returns one sentence on the fit: the common value, the effects, and how well Data equals Fit plus Residual. | a text; before Polish it says the table is not yet polished | | Check, Common
