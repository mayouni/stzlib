init | Creates a deployment of a delivery plan, with a structured trace log that records everything it does. | nothing; the object is built | poDelivery=the stzDelivery whose parts are to be deployed | SetTarget, Run
Log | Returns the structured log of the deployment, filled by Run. | a stzLog | | Run | entries carry a sequence number, a time, a level, a category and fields
SetTarget | Binds a part of the solution to the site it will be stored on and launched from. | the deployment itself, so calls chain | pcPart=the part's name, stored in lower case; poSite=the stzDeploymentSite that receives the part | SetTargets, Plan | binding a part twice keeps both bindings, and SiteFor answers the first
SetTargets | Binds many parts at once. | the deployment itself, so calls chain | paList=a list of [ part, site ] pairs | SetTarget | a value that is not a list changes nothing
RunAfter | Orders the plan: a part is stored only after another part has been verified. | the deployment itself, so calls chain | pcPart=the part that must wait; pcDependsOn=the part that must be verified first | Steps | the edge appears in Steps as the first step of pcPart waiting on verify of pcDependsOn
Artifact | Attaches a real build output to ship with a part, under a name at the destination. | the deployment itself, so calls chain | pcPart=the part that ships it; pcRelName=its name at the destination; pcPath=the built file on disk | ArtifactsAttached, AttachBundle | the file is not read here: a path that does not exist is recorded as given
ArtifactsAttached | Returns the attached artifacts as [ part, name, path ] rows. | a list of lists | | Artifact
AttachBundle | Attaches a whole emulator bundle folder as a part's production artifact, so the tree that was emulated is what ships. | the deployment itself, so calls chain | pcPart=the part that ships it; pBundle=a stzEmulator, which is built on demand, or the folder path of a built bundle | AttachSlice, Artifact | the bundle is shipped under the delivery's name | with a folder path it only records the folder; with an emulator it writes the bundle
AttachSlice | Attaches only a part's own slice of a bundle: its app as index.html, its engine subset and the bridge, those that exist. | the deployment itself, so calls chain | pcPart=the part whose slice is shipped; pBundle=a stzEmulator or the folder path of a built bundle | AttachBundle | files that are missing are skipped silently: a folder with no app_<part>.html attaches nothing
SetActor | Sets the actor under whose authority the deployment acts; only an effectful actor commits. | the deployment itself, so calls chain | poActor=a stzSystemActor, such as a human or a language-model actor | MayCommit, Run | without an actor, or with a language-model actor, every action is a rehearsal that touches nothing
Bindings | Returns the part-to-site bindings as [ part, site ] rows. | a list of lists | | SetTarget
NumberOfBindings | Returns how many bindings there are. | a number | | Bindings
SiteFor | Returns the site bound to a part; an empty text when the part is unbound. | a stzDeploymentSite, or an empty text | pcPart=the part's name, matched without regard to case | SetTarget, Plan
MayCommit | TRUE if the actor is effectful, so that Store, Launch and Run would really act. | TRUE or FALSE | | SetActor | FALSE without an actor
Plan | Returns each part of the delivery with its binding: [ part, kind, target, site name, site kind, protocol ]. | a list of lists | | Steps, Explain | an unbound part shows (unbound) for its site
Explain | Returns the rehearsal as lines of text: the actor, each part with its site, reach and storage, the host feasibility and the ordered steps. | a list of strings | | Show, Plan | pure reading: nothing runs
Show | Prints the lines that Explain returns. | nothing; it prints | | Explain
Store | Stores each bound part's artifact on its site when the actor may commit, else only rehearses. | a list [ committed, rows ], each row [ part, site, outcome ] with stored, store-failed or rehearsed (not committed) | | Launch, Run | effectful with an effectful actor: it writes into the site's storage; it was run here only without an actor and with a language-model actor, where every row read rehearsed (not committed) and nothing was written
Launch | Launches each bound part on its site when the actor may commit, else only rehearses. | a list [ committed, rows ], each row [ part, site, outcome ] with launched, launch-failed or rehearsed (not committed) | | Store, Run | effectful with an effectful actor: it starts the part on its site; it was run here only without an actor and with a language-model actor, where nothing was launched
Status | Returns the state of each bound site as [ part, site, state ] rows. | a list of lists | | Run | asks each site for its state: a local site reads its folder, a git site runs git, any other kind answers absent; it was run on local sites whose folder does not exist, where every state read absent
Steps | Returns the ordered plan as [ name, op, part, site, needs ] rows: provision if scriptable, then store, launch and verify. | a list of lists | | Run, RunAfter | the order is topological; a cycle of RunAfter edges is appended unordered instead of refused
WasRun | TRUE if Run was called, whether it committed or only rehearsed. | TRUE or FALSE | | Run, WasCommitted | a deployment refused upstream stays FALSE
WasCommitted | TRUE if Run really committed, which is not so for a rehearsal or a failed and rolled back run. | TRUE or FALSE | | Run, WasRun
Run | Executes the ordered plan under the actor's authority, with a verify gate and rollback on failure, and returns each step's outcome. | a list [ committed, rows ], each row [ step, outcome ] with done, rehearsed, FAILED or skipped | | Steps, Store, Launch | effectful with an effectful actor: it stores, launches and may provision hosts and roll back; it was run here only without an actor and with a language-model actor, where every step read rehearsed and nothing happened; a part whose requirement declares a GPU is checked before its first step, and on a local site that probes this machine's GPU, which was not exercised | a failed step makes the later steps skipped
Feasibility | Returns, per site, whether it can host the parts bound to it: [ site, required, capacity, fits, note ] rows. | a list of lists, fits being 1 or 0 | | Feasible, Explain | the requirements of the parts on one site are added up; a site with no declared capacity is assumed to fit, and a scriptable site is assumed to be provisioned
Feasible | TRUE if every site can host its parts, by its capacity or by being provisioned. | TRUE or FALSE | | Feasibility | Run does not check it: a deployment with a shortfall still rehearses
