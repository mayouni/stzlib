# w14 stzListClassifier -- Name | brief | returns | params | see | warning | note
init | Builds a classifier over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to analyse, or a stzList whose content is copied, any other value raises an error | Content, Classify | | the classifier never changes the list or the stzList you passed in
Content | Returns the list the classifier works on. | a list | | NumberOfItems, Copy
NumberOfItems | Returns how many items the list holds. | a number | | Content, NumberOfClasses
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
Copy | Returns a new classifier over a copy of the list. | a stzListClassifier | | Content, Classify
Classify | Groups the positions of equal items together, one class per distinct item. | a list of [ item, positions ] pairs, in order of first appearance | | Classes, Parts, Frequencies, ClassifyBy | a list made of numbers answers [ ] ([ 1, 2, 2, 3, 3, 3 ] and [ 1, 2, 2.5, 2, 3, 3, 3, 1 ] were tried), while a list of texts or of sublists is grouped; capital and small ASCII letters fall into one class, so a and A group under the first spelling met, while é and É stay apart | the items are the keys, so a text keeps its spelling; ClassifyQ returns the answer as a stzList and Classified is the same call
Classes | Returns the distinct items of the list, one per class, in order of first appearance. | a list | | Classify, NumberOfClasses | a list of numbers answers [ ], as Classify does | capital and small ASCII letters count as one class
ClassifyBy | Groups the positions of the items by the value an expression gives for each item. | a list of [ key, positions ] pairs, the key being the value written as a text | pcExpr=an expression of the current item, written with @item, such as "len(@item)" | Classify, Frequencies | | on [ 1, 2, 2, 3, 3, 3 ] the expression "@item % 2" gives the classes "1" and "0"; on texts "len(@item)" groups by length; keys are texts, so 10 comes back as "10"; GroupBy is the same call
Parts | Groups the positions of equal items together, one part per distinct item. | a list of [ item, positions ] pairs | | Classify, Chunks | | the same answer as Classify; PartsCS(pCaseSensitive) takes the flag but ignores it
NumberOfClasses | Returns how many distinct items the list holds. | a number | | Classes, Classify | | a list of numbers answers 0, as Classify does
Frequencies | Returns each distinct item with how many times it occurs. | a list of [ item, count ] pairs, in order of first appearance | | FrequencyOf, Mode, MostFrequent | | the items come back as texts, so the number 3 is "3", a text 1 and a number 1 count together, and a sublist is written as text; capital and small ASCII letters are counted together under the first spelling; Histogram is the same call
MostFrequent | Returns the item that occurs most often. | the item, as a text, or an empty text for an empty list | | LeastFrequent, Mode, Frequencies | | with a tie it answers the one that appeared first; for all the tied items use Mode
LeastFrequent | Returns the item that occurs least often. | the item, as a text, or an empty text for an empty list | | MostFrequent, Frequencies | | with a tie it answers the one that appeared first
Partition | Cuts the list into consecutive groups of equal size, the last one possibly shorter. | a list of lists | n=the number of groups wanted | Chunks, Bisect | n = 0 raises error R1 Can't divide by zero | the group size is the count divided by n, rounded up, so the answer can hold fewer than n groups; an empty list gives [ ]
ItemsAppearingNTimes | Returns the distinct items that occur exactly n times. | a list | n=the exact number of occurrences | ItemsAppearingMoreThanNTimes, Frequencies | | the items keep their type, so a number stays a number, unlike Frequencies; ItemsWithFrequency is the same call; capital and small ASCII letters are counted together
ItemsAppearingMoreThanNTimes | Returns the distinct items that occur more than n times. | a list | n=the number of occurrences to exceed | ItemsAppearingLessThanNTimes, ItemsAppearingNTimes | | the items keep their type, as in ItemsAppearingNTimes
ItemsAppearingLessThanNTimes | Returns the distinct items that occur fewer than n times. | a list | n=the number of occurrences to stay under | ItemsAppearingMoreThanNTimes, ItemsAppearingNTimes | | the items keep their type, as in ItemsAppearingNTimes
FrequencyOf | Returns how many times one item occurs in the list. | a number | pItem=the item to count | Frequencies, Mode | | unlike Frequencies it compares with case and with type: in a b A a, A counts 1 and a 2, and a number 1 does not count a text 1; HowMany is the same call
Mode | Returns every item that ties for the highest count. | a list, [ ] for an empty list | | MostFrequent, Frequencies | | the items come back as texts, as in Frequencies
Bisect | Cuts the list into a first half and a second half. | a list of two lists | | FirstHalf, SecondHalf, Partition | | with an odd count the first half is the larger; BisectQ returns a stzList
FirstHalf | Returns the first half of the list. | a list | | SecondHalf, Bisect | | with an odd count the first half holds the extra item
SecondHalf | Returns the second half of the list. | a list | | FirstHalf, Bisect | | with an odd count it holds one item fewer than the first half
Chunks | Cuts the list into consecutive groups of n items, the last one possibly shorter. | a list of lists | n=how many items each group holds | Partition, Bisect | | an n larger than the list gives one group, and 0 gives [ ]; SplitToPartsOfNItems is the same call and ChunksQ returns a stzList
