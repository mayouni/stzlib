init | Builds a handle on the process-wide registry of measurements; it holds no state of its own. | nothing; the object is built | | StzModelRegistryQ, Measurements | | every handle reads the same measurements, the same model trace and the same policy, so there is one registry per process
Resolve | Resolves a requirement to the implementation that should run and returns the plan as data. | a plan: a list of [ key, value ] pairs faculty, chosen, kind, why, rejected, floor, refusal, findings, pinned and needle | pReq=a faculty name, an stzRequirement, or the list its Data returns | ResolveQ, MeasurementOf, stzRequirement | an unknown faculty, or one with no floor, gives a plan with refusal 1 and its findings, not an error; with no measurement the floor is chosen, because an unmeasured model is unknown and never good | a model is chosen only when its measured score strictly beats the floor's and reaches the requested quality, and the floor stays as the fallback; under StzModelPolicy(:deterministic) or STZ_MODELS=off every faculty resolves to its floor; ResolveQ returns the same plan as an stzModelPlan, ready to explain
Measurements | Returns every measurement recorded in the process, in the order recorded. | a list of rows, each a list of [ key, value ] pairs: faculty, impl, golden, score, n, conformance, date, note | | MeasurementOf, RunGoldens, SaveMeasurements | | a new measurement of the same implementation on the same golden version replaces the old row and goes to the end
MeasurementOf | Returns the measurement recorded for one implementation under the faculty's current golden version. | a row of [ key, value ] pairs faculty, impl, golden, score, n, conformance, date, note; [ ] when none | pcFaculty=the faculty's name; pcImpl=the id of the implementation | Measurements, RunGoldens | an unknown faculty gives [ ] and not an error; after SetGoldenVersion the earlier rows are not found | score is the share of golden inputs whose answer the checker accepted, and conformance the share the court accepted: both are computed by the class, not judged by a person
RunGoldens | Runs the faculty's golden set through every installed implementation, the floor first, and records the scores. | the rows recorded: one measurement per implementation run | pcFaculty=the name of the faculty to measure | RunGoldensFor, Measurements, Resolve | raises an error for an unknown faculty; a model whose file is not in the models directory is skipped and a service is never run; an answer that stated a probability also enters the calibration ledger; the golden loop writes the merged defaults back into the list it passes, so a faculty whose default params are not [ key, value ] pairs is scored on grown params; not exercised with a real model: the answer shape is read from the code | the floor is run first because its score is the bar a model must strictly beat
RunGoldensFor | Measures the floor and the named implementations on the golden set and records the scores. | the rows recorded: the floor and each named implementation that is installed | pcFaculty=the name of the faculty to measure; pacImplIds=the ids of the non-floor implementations to measure | RunGoldens, Measurements | raises an error for an unknown faculty; ids that are not installed, and services, are skipped; not exercised with a real model: the answer shape is read from the code | the floor is always measured, because it is the bar; implementations not named keep their earlier rows
SaveMeasurements | Writes every measurement to a text file, one line per row after a header, overwriting the file. | nothing; the file is written | pcPath=the file to write | LoadMeasurements, Measurements | | each line holds faculty, impl, golden, score, n, conformance, date and note separated by vertical bars, so a note containing a bar would not read back whole
LoadMeasurements | Reads a file written by SaveMeasurements back into the registry and returns how many rows it took. | a number: the rows loaded; 0 for a missing file | pcPath=the file to read | SaveMeasurements, Measurements | | a row for an implementation already measured on the same golden version replaces it, the saved date is kept, and lines with fewer than six fields are skipped
