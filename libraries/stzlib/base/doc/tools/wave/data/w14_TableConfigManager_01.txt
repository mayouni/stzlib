init | Builds a manager that changes the settings of a table layout and fires a callback on change. | nothing; the object is built | oTableConfig=the TableDisplayConfig to manage | UpdateSettings, ImportConfig | the manager keeps a COPY of the config: every change it makes lands on that copy, readable as its oConfig attribute, and your own config stays as it was
SetChangeCallback | Stores a function meant to run after each settings change. | the manager itself, so calls chain | fCallback=the function to call, with no argument | UpdateSettings, ImportConfig | the callback never runs today: the check compares the type of the stored function with BLOCK, and Ring answers STRING for a function value; confirmed on UpdateSettings, ImportConfig and OptimizeLayout
UpdateSettings | Applies several settings at once, then recomputes the layout. | the manager itself, so calls chain | aNewSettings=a list of [ name, value ] pairs, such as [ [ :MinCellWidth, 9 ] ] | ImportConfig, SetChangeCallback | it changes the manager's own copy of the config, not yours
OptimizeLayout | Rebalances the computed widths towards their average and scales them down when the table is wider than MaxTableWidth. | the manager itself, so calls chain | | UpdateSettings | it has no lasting effect today: the last step recomputes the whole layout and overwrites the adjusted widths, so the widths after it are the ones a plain recomputation gives, with a MaxTableWidth of 20 as with the default; it works on the manager's own copy of the config
ExportConfig | Returns the current settings and the computed layout as one list. | a list [ Settings, Layout ] holding the aSettings and aCalculatedLayout of the managed config | | ImportConfig
ImportConfig | Applies the settings found in a list made by ExportConfig, then recomputes the layout. | the manager itself, so calls chain | _aConfig_=the list, with a Settings entry holding [ name, value ] pairs; one without it changes nothing but still recomputes | ExportConfig, UpdateSettings | it changes the manager's own copy of the config, not yours
