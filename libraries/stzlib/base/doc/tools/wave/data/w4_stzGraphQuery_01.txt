init | Builds a query over a graph and keeps a reference to it; anything but a stzGraph raises an error. | nothing; the query is built | oGraph=The stzGraph the query runs against | GraphQ, Graph
Graph | Returns the name of the graph the query runs against. | text | | GraphQ
Query | Returns the query definition: a hash list of the 11 parts, from match to distinct, built so far. | a hash list of 11 pairs | | SetDefinition, ResetDefinition | | Definition, AST, QueryDefinition and Structure return the same list
SetDefinition | Replaces the whole query definition with a list given by hand, and forgets any earlier result. | nothing; the query changes | aNewDef=A definition in the shape Query returns | Query, ResetDefinition | the list is stored as given, with no check of its keys; a definition that lacks one of the 11 keys fails when the query runs | anything but a list raises an error; LoadDefinition and ImportDefinition are the same call
ResetDefinition | Empties the query definition and the earlier result, so the same object can take a new query. | nothing; the query changes | | SetDefinition, Query | | ClearDefinition is the same call
ThenApplyRule | Queues a derivation rule to run on the matched elements when the query executes; the rule name is folded to uppercase. | nothing; the query changes | pcRuleName=The name of a derivation rule registered on the graph | DeriveUsing, EnforceRule | the rule is looked up only at execution: an unknown name or a rule that is not a derivation raises an error then | after the run the rule's new edges are in the graph, not in the result; see ThenApplyRuleQ to chain
EnforceRule | Queues a constraint rule to be checked against every match when the query executes; the rule name is folded to uppercase. | nothing; the query changes | pcRuleName=The name of a constraint rule registered on the graph | ThenApplyRule, ValidateWith | the rule is looked up only at execution: an unknown name raises an error then, and so does a match that breaks the rule
ValidateWith | Queues a validation of the matched subgraph against rule groups; a single text raises error R21 when the query runs today. | nothing; the query changes | paValidators=Rule group names such as :DAG, :Reachability or :Completeness, as a list | EnforceRule, DeriveUsing | known defect: a single text is wrapped with paValidators = [ paValidators ], which stores [ [ [ ] ] ] and the run then raises R21; a list of names works, and a failing group raises Validation failed | pass a list, ValidateWith([ :DAG ])
DeriveUsing | Queues a derivation rule to run on the matched elements when the query executes; the rule name is folded to uppercase. | nothing; the query changes | pcRuleName=The name of a derivation rule registered on the graph | ThenApplyRule, EnforceRule | the rule runs on the nodes of the matches, and the edges it derives are added to the graph, so a second execution can derive them again if they are missing | an unknown name raises an error at execution
Match | Adds a node pattern to the query: every node, or those with a given alias, label, properties or condition. | nothing; the query changes | paParams=:nodes for every node, or a list such as [ :node = "n", :labeled = "Person", :props = [ ... ], :where = [ ... ] ] | MatchEdge, Where, Select | the alias defaults to node; a list starting with :nodes takes :labeled, :props and :where as pairs after it | several Match calls make a join: the rows are the compatible combinations
MatchEdge | Adds an edge pattern to the query, binding its two end nodes to the aliases given by from and to. | nothing; the query changes | paParams=A list of pairs [ :from = "a", :to = "b", :labeled = "KNOWS", :props = [ ... ], :where = [ ... ] ] | Match, Where | the aliases default to from_node and to_node; a pair that is not a list is ignored | reuse the alias of an earlier Match to join an edge to a node pattern
Where | Adds a filter to the last pattern, or to the whole query before any pattern; a function gets each binding and answers TRUE or FALSE. | nothing; the query changes | paCondition=A list [ field, operator, value ], joined with :and or :or for a compound filter, or a function that takes a binding | Match, MatchEdge | operators are =, !=, <, >, <=, >=, :contains, :startswith, :endswith, :in and :not_in; a field without a dot is read from the pattern's alias | only the last pattern keeps a filter: a second Where replaces the first one on that pattern
Select | Adds fields to the projection, runs the query at once, and returns the rows; "*" selects every alias. | a list of rows, each a list of [ field, value ] pairs, or of [ alias, node ] pairs for "*" | paFields=A field as text such as "n.name", "*" for every alias, [ "n.city", :as = "town" ] for a renamed field, or a list of fields | SelectXT, Result, Distinct | calling it twice adds the fields of both calls and runs the query each time, so a Create, Set or Delete part takes effect again; the rows hold the value of each field, a node record for a bare alias | the :as renaming is accepted as [ "n.city", [ :as, "town" ] ]
Distinct | Asks that duplicate rows be dropped from the result of the query. | nothing; the query changes | | Select, Result | | takes effect when the query runs, so call it before Select
OrderBy | Leaves the rows in match order for ascending and reverses them for descending today, instead of sorting by a field. | nothing; the query changes | pcField=The field to sort by, such as "n.age"; pcDirection=asc, desc, ascending, descending, inascending or indescending, as text | Skip, Limit, Select | known defect: the sort call @SortOn returns the sorted list and the method drops it, so nothing is sorted; asc keeps the match order and desc reverses it; only the first OrderBy is read; both arguments are required, with one Ring raises R19 | a direction word it does not know means asc
Limit | Keeps at most this many rows of the result; 0 means no limit. | nothing; the query changes | pnLimit=The greatest number of rows to keep | Skip, OrderBy | applied after the skip
Skip | Drops this many rows from the start of the result, after the sort. | nothing; the query changes | pnSkip=The number of rows to drop | Limit, OrderBy | with Limit it pages through the rows
Set | Queues the change of a property on every matched node, applied when the query runs; the new value may be given as [ :to = value ]. | nothing; the query changes | pcProperty=The target as alias.property, such as "n.age"; paValue=The new value, or a pair list holding it under :to | Match, Execute | a property written without an alias dot changes nothing, silently | the graph itself changes when the query runs, not when Set is called
Create | Queues the creation of a node or of an edge between two matched aliases, applied when the query runs. | nothing; the query changes | paParams=[ :node, :labeled = "Thing", :props = [ ... ] ] for a node, or [ :edge, :from = "a", :to = "b", :labeled = "KNOWS" ] for an edge | Match, Execute | anything but a list is ignored; the graph changes when the query runs, and each run creates again | a created node gets the id node_
Delete | Queues the removal from the graph of the nodes bound to the given aliases, applied when the query runs. | nothing; the query changes | paTargets=An alias as text, or a list of aliases | Match, Execute | the graph changes when the query runs; its edges go with the nodes
Execute | Runs the query against the graph and keeps the rows in Result. | 1 always, even when nothing matched | | Result, Select | Run, Exec, Executed and Runned are the same call | a query with Create, Set or Delete changes the graph on every run
Result | Returns the rows of the last run, [ ] before any run. | a list of rows | | Execute, Select
ToGraphQ | Returns a new graph of the matched nodes and the edges joining them; the query runs first if it has not been executed. | a new stzGraph | | ToViewQ, Execute | ToStzGraph is the same call | the new graph is named query_result_ and shares nothing with the source; a call after Select runs the query again, since only Execute marks it executed
Explain | Returns the execution plan as a list of steps, each with the step kind and a sentence describing it. | a list of hash lists [ :step, :description ] | | ToOpenCypher, Query | | the description is held in a list of one text
ToOpenCypher | Returns the query written as openCypher text: MATCH, WHERE, RETURN, ORDER BY, SKIP, LIMIT, CREATE, SET and DELETE lines. | text, one clause per line | | Explain, Query | | the query is not run
