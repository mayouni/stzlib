Tempo | Sets the speed used by the next note strings, in beats per minute. | the music object itself, so calls chain | pnBpm=the speed in beats per minute, from 20 to 400 | With, Swing | a value outside the range is refused, with LastError set and the refusal counted | it does not reach the phrase verbs, whose speed comes from the universe, and a live session made later takes it
With | Chooses the instrument used by the next note strings. | the music object itself, so calls chain | pInstrument=the instrument name, such as Piano, Oud or Kora | Tempo, ScoreOf | an unknown instrument is refused, with LastError set and the refusal counted
Swing | Sets the swing share used by the next note strings. | the music object itself, so calls chain | pnRatio=the share of each pair of eighths taken by the first, 0.5 being straight | Tempo | it is stored without a check, and a bad value is refused later when a score is made
Play | Plays a string of note names live on the audio device, one beat each, and returns when the last note has sounded. | the music object itself, so calls chain | pcNotes=space-separated note names, with ~ for a rest, such as c e g c5 | ToSound, ScoreOf, PlayPhrase | not run in this reference: it opens an audio device through the score; an empty score plays nothing | LastError copies what the score reported
ToSound | Renders a string of note names to a sound in memory, with the chosen instrument, speed and swing. | a stzSound at 48000 Hz, two channels | pcNotes=space-separated note names, with ~ for a rest, such as d e f g a | ScoreOf, Play | no audio device is opened; a word that is not a note is skipped, counted and named in LastError | the sound has not been heard by a person; it is checked by frame count, rate and peak
ScoreOf | Returns the score that a string of note names makes here, so it can be looked at, changed and played later. | a stzSoundScore with the chosen instrument, speed and swing set | pcNotes=space-separated note names, with ~ for a rest | LastScore, ToSound | refusals of the score are added to this object's count | the same score is kept for LastScore
LastScore | Returns the score that the last Play, ToSound or ScoreOf made. | a stzSoundScore; an empty text before any | | ScoreOf
In | Chooses a musical universe, mode and tonic for the phrase verbs. | the music object itself, so calls chain | pUniverse=the universe name, such as Maqam, Raga or Western; pMode=the mode name, or an empty text for the universe's own; pTonic=the tonic as a note name, where a bare letter takes octave 4, or an empty text for the mode's own | PlayPhrase, PhraseToSound, Universe | an unknown universe or mode is refused, with LastError set, and the universe chosen before stays | phrases are written in degrees, so one phrase means something in every universe
Universe | Returns the universe chosen by In. | a stzSoundUniverse; an empty text before In | | In
PhraseToSound | Renders a phrase of degrees in the chosen universe to a sound in memory, as many cycles as asked. | a stzSound at 48000 Hz; an empty text with LastError set when no universe was chosen | pcDegrees=the phrase in degrees, such as 1 2 3 4 5 4 3 2; pnCycles=how many times the phrase is played through its rhythmic cycle | In, PlayPhrase | no audio device is opened; the speed and the instrument are the universe's own, not Tempo and With | the sound has not been heard by a person, and none of the shipped universes has been confirmed by a listener from its tradition
PlayPhrase | Plays a phrase of degrees live in the chosen universe for two cycles and returns when they have sounded. | the music object itself, so calls chain | pcDegrees=the phrase in degrees, such as 1 2 3 4 5 4 3 2 | PhraseToSound, In | not run in this reference: it opens an audio device; with no universe chosen it is refused, with LastError set |
Sing | Sings lyrics on notes with the retuned speech voice and returns the result as a sound. | a stzSound, mono at 48000 Hz; an empty text when the voice is not allowed to sing or cannot | pcLyrics=the syllables, space-separated, such as la la la; pcNotes=the note names to sing them on, such as c4 e4 g4 | ToSound | a refusal is counted and named in LastError; it renders to memory and plays nothing | the sound has not been heard by a person
LiveLoop | Defines or redefines a live loop from a pattern, creating the live session on first use. | the cycle the loop lands on, counted from 0; -1 when refused | pName=the loop's name; pcPattern=a pattern of note names and strokes, such as dum ~ tak ~ | LiveLoopOn, WaitCycles | it forwards to stzSoundLive and the session plays on a sound card when waited on, unless capture was set on Live() | the session takes the speed and the instrument set when it is made
LiveLoopOn | Defines or redefines a live loop on a chosen instrument, creating the live session on first use. | the cycle the loop lands on, counted from 0; -1 when refused | pName=the loop's name; pcPattern=a pattern of note names and strokes; pInstrument=the instrument name | LiveLoop | forwards to stzSoundLive
Every | Redefines a live loop as itself transformed every so many cycles. | the cycle the loop lands on; -1 when refused | pnN=the period of the transform in cycles; pName=the name of an existing loop; pXform=the transform to apply, such as Rev | LiveLoop | forwards to stzSoundLive; an unknown loop is refused
Silence | Stops one live loop at the first cycle boundary it can land on. | the cycle on which the loop falls silent; -1 for an unknown loop | pName=the name of the loop to stop | Hush | forwards to stzSoundLive
Hush | Stops every live loop at the first cycle boundary each can land on. | the cycle of the last loop's landing; -1 when there are no loops | | Silence | forwards to stzSoundLive
WaitCycles | Lets the live session run for a number of cycles, starting it first when needed. | the music object itself, so calls chain | pnCycles=how many cycles to wait | StopLive, Live | it plays on a sound card, which was not run in this reference except with capture set on Live(), where it returned after 2 cycles | a capture shorter than the wait never returns, see the defects file
StopLive | Stops and frees the live session, so the next live call makes a new one. | the music object itself, so calls chain | | WaitCycles, Live | does nothing when there is no session
Live | Returns the live session, creating it on first use, so its logs can be read and capture chosen. | a stzSoundLive | | StzSoundLiveQ | changing the returned session changes the one held here, so Live().CaptureInsteadOfDevice(6, FALSE) keeps the music object off the sound card
LastError | Returns the reason the last call was refused, or an empty text. | a text | | Refusals
