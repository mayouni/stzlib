Pass the text, os.Content(), to be safe | any other kind of value raises "Can't create stzStringSections! Parameter must be a string or stzString object."

Section | Returns the characters from one position to another, both included, as a text. | a text | _n1_=the first position, from 1, or [ :From, n ]; _n2_=the last position, from 1, or [ :To, n ] | Range, Sections, SectionRemoved | | a position outside the text raises "Indexes out of range!", where the removal methods clip it; a start after the end is swapped, so Section(4, 2) equals Section(2, 4)
Range | Returns a run of characters given by its start and its length, as a text. | a text | pnStart=the first position, from 1; pnRange=how many characters | Section, RangeRemoved | Range(2, 0), a length of 0, answers "ab" for "abcdefghij" instead of an empty text: it asks Section for the reversed pair 2 to 1, which is swapped | a run past the end raises "Indexes out of range!"
Sections | Returns several sections at once, one text per [ start, end ] pair, in the order given. | a list of texts | paSections=a list of [ start, end ] pairs | Section, AntiSections | | each pair is read as for Section
AntiSections | Returns the stretches of text that lie outside the given sections, in order. | a list of texts; [ ] when the sections cover everything | paSections=a list of [ start, end ] pairs, covered whatever their order or overlap | Sections, RemoveSections | | AntiSections([ [3,4] ]) on "abcdefghij" gives "ab" and "efghij"; a pair given backwards is swapped; no sections give the whole text as one piece
SectionBetween | Returns the text strictly between two positions, but a wrong piece when they are one apart or equal. | a text | _n1_=the position before the stretch; _n2_=the position after it | Section | Returns the wrong text when the positions are one apart or equal: SectionBetween(2, 3) on "abcdefghij" answers "bc" and SectionBetween(2, 2) answers "abc", instead of an empty text, because it asks Section for the reversed pair 3 to 2 or 3 to 1, which is swapped; it is right when the positions are two or more apart: (2, 6) gives "cde" |
RemoveSection | Removes the characters from one position to another, both included, in place. | nothing; use RemoveSectionQ to chain | _n1_=the first position; _n2_=the last position | SectionRemoved, RemoveRange | | positions outside the text are clipped to it (0 counts as 1, 99 as the length) and a start after the end is swapped, unlike Section which raises
SectionRemoved | Returns the text without the characters from one position to another, leaving the reader unchanged. | a text | _n1_=the first position; _n2_=the last position | RemoveSection | | clips out-of-range positions, like RemoveSection
RemoveSections | Removes several sections, in place, one [ start, end ] pair after the other from the last pair to the first. | nothing; use RemoveSectionsQ to chain | paSections=a list of [ start, end ] pairs, in ascending order | SectionsRemoved, RemoveSection | The pairs must be in ascending order of position: [ [7,8], [2,3] ] on "0123456789" gives "034567" instead of "034589", because each removal shifts the positions of the ones after it and the order is not checked or sorted |
SectionsRemoved | Returns the text without several sections, leaving the reader unchanged. | a text | paSections=a list of [ start, end ] pairs, in ascending order | RemoveSections | The same order requirement: [ [7,8], [2,3] ] gives the wrong text |
