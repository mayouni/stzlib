# Wave 10 -- stzNumbrex. Every root called on invented patterns and numbers. The grammar: tokens @Property(Prime), @Digit(1..5)3, @Factor4, @Relation(Mod:5=0), @Approx(~3.14), @Part(Integer), @Divisor(3), @Multiple(4); tokens joined by -> (all must hold), | (any) and & (all); @! negates.
init | Parses a number pattern such as {@Property(Prime)} into tokens, adding the braces when they are missing. | nothing; the object is built | pcPattern=the pattern as text | Match, Tokens, Pattern | raises Error: Pattern must be a string for anything but a text | a pattern with no token it can read still builds, with no tokens, and then matches every number
NormalizePattern | Returns the pattern trimmed and wrapped in braces when it is not already. | a text | _cPattern_=the pattern as text | ParsePattern, Pattern | | a pattern that starts with { but does not end with } is wrapped again
ParsePattern | Returns the token records of a pattern, one per piece separated by ->. | a list of token records | _cPattern_=the pattern with its braces | ParseSingleToken, SplitByOperator, Tokens | | each record holds type, value, constraints, min, max and negated; a piece it cannot read is dropped
SplitByOperator | Returns the parts of a text split at an operator, ignoring operators inside parentheses or braces. | a list of texts | _cStr_=the text to split; cOperator=the operator, for example -> or a vertical bar | ParsePattern, ParseAlternation | | a->b(c->d)->e gives a, b(c->d) and e
ParseAlternation | Returns an alternation token from pieces joined by a vertical bar, matched when any piece holds. | a token record of type alternation with its alternatives | _cTokenStr_=the pieces joined by a vertical bar, with or without outer parentheses | ParseConjunction, ParseSingleToken | | the pieces are read as single tokens
ParseConjunction | Returns a conjunction token from pieces joined by &, matched when every piece holds. | a token record of type conjunction with its conditions | _cTokenStr_=the pieces joined by &, with or without outer parentheses | ParseAlternation, ParseSingleToken | | the pieces are read as single tokens
ParseSingleToken | Returns the token record of one piece such as @Digit(1..5)+ or @!Property(Prime), or an empty list when it is not recognised. | a token record, or [ ] | _cTokenStr_=one piece: an optional @!, a type word, an optional parenthesis and an optional quantifier | ParsePattern, ParseConstraints | | the types are digit, factor, property, part, relation, approx, divisor and multiple, with or without the @; with no quantifier a digit or factor token means exactly one, so write @Digit3 or @Digit+; a quantifier is a count, a range 2-4, +, * or ?
ParseConstraints | Returns the constraint records inside the parentheses of a digit or factor token. | a list of constraint records; empty for an empty text | cConstraintStr=the text inside the parentheses; _cType_=digit or factor | ParseSingleToken, CheckDigits | | for digit: :unique, a range 1..5 or 1-5, a set {1;3;5}, :step, or a single number; for factor: prime, unique or a count
Match | Tests a whole number against the pattern, and on success records its digits, factors and properties. | TRUE or FALSE | pnNumber=the number to test | MatchTokens, MatchedParts, SetTarget | raises Incorrect param type! for anything but a number; a pattern with no readable token matches every number, so {@zzz} and {zzz} answer TRUE for 5 and -7 | the number is also kept as the target of Explain
MatchTokens | TRUE if every token in the list holds for the number, taking alternations and conjunctions into account. | TRUE or FALSE | _aTokens_=the token records, as from Tokens; _nNum_=the number to test | Match, MatchSingleToken | | an empty list answers TRUE
MatchSingleToken | TRUE if one token holds for the number, applying its negation. | TRUE or FALSE | _aToken_=one token record; _nNum_=the number to test | MatchTokens, CheckProperty | | a token of an unknown type answers FALSE, or TRUE when negated
CheckProperty | TRUE if the number has the named property such as prime, even, odd, square, positive or composite. | TRUE or FALSE | _cProperty_=the property name, without regard to case; _nNum_=the number to test | IsPrime, IsPerfect, Match | | the names are prime, even, odd, perfect, fibonacci, palindrome, square, positive, negative, zero, composite, abundant, deficient, triangular and cube; any other name answers FALSE
IsPrime | TRUE if the number is a prime. | TRUE or FALSE | _nNum_=the number to test | CheckProperty, IsPerfect | | 2 and 97 are prime; 1 and negatives are not
IsPerfect | TRUE if the number equals the sum of its proper divisors. | TRUE or FALSE | _nNum_=the number to test | IsAbundant, IsDeficient, GetProperDivisors | | 6 and 28 are perfect, 12 is not
IsFibonacci | TRUE if the number is in the Fibonacci sequence. | TRUE or FALSE | _nNum_=the number to test | CheckProperty | | 0, 1 and 13 are, 22 is not
IsSquare | TRUE if the number is a perfect square. | TRUE or FALSE | _nNum_=the number to test | IsCube, CheckProperty | | 16 and 0 are, 15 is not
IsPalindrome | TRUE if the digits read the same in both directions. | TRUE or FALSE | _nNum_=the number to test | GetDigits, CheckProperty | | 121 and 7 are, 123 is not
IsAbundant | TRUE if the proper divisors add up to more than the number. | TRUE or FALSE | _nNum_=the number to test | IsDeficient, IsPerfect | | 12 is, 6 and 7 are not
IsDeficient | TRUE if the proper divisors add up to less than the number. | TRUE or FALSE | _nNum_=the number to test | IsAbundant, IsPerfect | | 7 is, 6 and 12 are not
IsTriangular | TRUE if the number is a triangular number 1, 3, 6, 10... | TRUE or FALSE | _nNum_=the number to test | IsSquare, CheckProperty | | 10 and 1 are, 11 is not
IsCube | TRUE if the number is a perfect cube. | TRUE or FALSE | _nNum_=the number to test | IsSquare, CheckProperty | | 27 and 8 are, 28 is not, and the negative cube -8 is not either
GetProperDivisors | Returns the divisors of the number below itself, in increasing order. | a list of numbers | _nNum_=the number | GetFactors, IsPerfect | | 12 gives 1, 2, 3, 4, 6; 1 gives an empty list
CheckDigits | TRUE if the digits of the number satisfy a digit token's count and constraints. | TRUE or FALSE | _aToken_=a digit token record; _nNum_=the number to test | GetDigits, ParseConstraints | | the count of digits must lie between the token's min and max, and every digit must pass a range or a set constraint; an exact constraint compares the digit count to its value, so @Digit(7) with the default count of one digit matches nothing
GetDigits | Returns the digits of the number as a list of numbers, ignoring the sign and the decimal point. | a list of numbers | _nNum_=the number | CheckDigits, Digits | | 4052 gives 4, 0, 5, 2; -71 gives 7, 1
CheckFactors | TRUE if the factors of the number satisfy a factor token's count and constraints. | TRUE or FALSE | _aToken_=a factor token record; _nNum_=the number to test | GetFactors, ParseConstraints | | the factors include 1 and the number itself, so 6 has four; a prime constraint demands that every factor be prime, and 1 never is, so @Factor(prime) matched none of 1, 2, 3, 7, 15, 6 or 8 today
GetFactors | Returns every factor of the number, 1 and itself included, in increasing order. | a list of numbers; empty for 0 | _nNum_=the number, whose sign is ignored | GetProperDivisors, Factors | | 12 gives 1, 2, 3, 4, 6, 12
CheckRelation | TRUE if the number satisfies a modulo relation written Mod:divisor=remainder. | TRUE or FALSE | cRelation=the relation, for example Mod:5=0; _nNum_=the number to test | Match, CheckDivisor | | any other text answers FALSE
CheckApprox | TRUE if the number equals the target when both are cut to a number of decimals, 2 by default. | TRUE or FALSE | cApprox=the target after a tilde, for example ~3.14 or ~3.1:decimals1; _nNum_=the number to test | Match | | the number is cut, not rounded: 3.141 matches ~3.14, 3.2 does not; a text without the tilde answers FALSE
CheckPart | TRUE if the number has the named part: integer or fractional, or a pattern applied to that part. | TRUE or FALSE | _cPart_=integer, fractional, or integer:pattern or fractional:pattern; _nNum_=the number to test | Match | | a part name it does not know answers TRUE for every number, where FALSE would be safer; the fractional part is scaled by one million before the inner pattern is tried
CheckDivisor | TRUE if the number is divisible by the given value. | TRUE or FALSE | _cValue_=the divisor as text; _nNum_=the number to test | CheckMultiple, CheckRelation | | 0 and non-numeric text answer FALSE
CheckMultiple | TRUE if the number is a multiple of the given base. | TRUE or FALSE | _cValue_=the base as text; _nNum_=the number to test | CheckDivisor | | it tests the same thing as CheckDivisor, a remainder of 0
ExtractParts | Records the digits, factors, properties and value of a number as the matched parts. | nothing; read them with MatchedParts | _nNum_=the number | MatchedParts, Digits | | Match calls it after a success; 28 gives the properties Even, Perfect, Triangular and Composite
MatchedParts | Returns what the last successful match recorded, as [ name, value ] pairs. | a list of pairs; empty before a match | | Digits, Factors, Properties, Value | | a failed match leaves the earlier record untouched
Digits | Returns the digits recorded by the last successful match. | a list of numbers; empty before a match | | MatchedParts, GetDigits
Factors | Returns the factors recorded by the last successful match. | a list of numbers; empty before a match | | MatchedParts, GetFactors
Properties | Returns the names of the properties the last matched number has, such as Prime, Even or Square. | a list of texts; empty before a match | | MatchedParts, CheckProperty | | the possible names are Prime, Even, Odd, Perfect, Fibonacci, Palindrome, Square, Triangular, Cube, Abundant, Deficient and Composite
Value | Returns the number recorded by the last successful match, or 0. | a number | | MatchedParts
Tokens | Returns the parsed token records of the pattern. | a list of token records | | ParsePattern, Pattern, Explain
Pattern | Returns the pattern text, with its braces. | a text | | Tokens, NormalizePattern
SetTarget | Sets the number that Explain reports as the target, without testing it. | nothing | pnNumber=the number to report | Match, Explain
Explain | Returns the pattern, the token count, the tokens, the target and the matched parts as a list of pairs. | a list of [ name, value ] pairs | | Tokens, Match, SetTarget | | the target is the last number given to Match or SetTarget; the matched parts appear once a match has succeeded
MatchingNumberAfter | Returns the first number at or after a start that matches, searching up to 100000 steps. | a number; an empty text when none is found | _nStart_=the number to start from, included | MatchingNumberBefore, MatchingNumbersBetween | | MatchingNumberNextTo is the same call; 14 with Prime gives 17
MatchingNumberBefore | Returns the first number at or before a start that matches, searching down up to 100000 steps. | a number; an empty text when none is found | _nStart_=the number to start from, included | MatchingNumberAfter | | MatchingNumberPreviousTo is the same call; 14 with Prime gives 13, and 1 gives an empty text
MatchingNumbersBetween | Returns every matching whole number from a start to an end, both included. | a list of numbers | _nStart_=the first number; _nEnd_=the last number, or a pair such as [ and, 30 ] | CountMatchingBetween, MatchingNumberAfter | raises an error when a bound is not a number | Perfect between 1 and 500 gives 6, 28, 496; MatchingBetween is the same call
CountMatchingBetween | Returns how many whole numbers from a start to an end, both included, match. | a number | _nStart_=the first number; _nEnd_=the last number, or a pair such as [ and, 30 ] | MatchingNumbersBetween | raises an error when a bound is not a number | CountMatchingNumbersBetween, HowManyMatchingNumbersBetween and NumberOfMatchingNumbersBetween are the same call
EnableDebug | Switches on the trace that prints each match step to the console. | nothing | | DisableDebug, SetDebug | | the trace prints lines such as Checking token type and Final result
DisableDebug | Switches the trace off. | nothing | | EnableDebug, SetDebug
SetDebug | Switches the trace on with 1 or off with 0. | nothing | bFlag=1 for the trace, 0 for none | EnableDebug, DisableDebug
IsNumeric | TRUE if a text is made only of digits and dashes, which is how the parser reads counts and ranges. | TRUE or FALSE | _cStr_=the text to test | ParseSingleToken | | it is not a general number test: 3.5 and -3.5 answer FALSE, while -3 and 2-4 answer TRUE
