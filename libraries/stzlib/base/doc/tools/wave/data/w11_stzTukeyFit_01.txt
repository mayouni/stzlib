init | Builds a two-way table to be fitted by median polish, from rows of numbers. | nothing; the object is built | paRows=the table as a list of rows, each a list of numbers, all of the same length; an empty table, a ragged row or a cell that is not a number raises an error | Polish, SetTolerance
NumberOfRows | Returns how many rows the table has. | a number | | NumberOfColumns
NumberOfColumns | Returns how many columns the table has. | a number | | NumberOfRows
SetTolerance | Sets how small the change of the residual sum must be for the polish to stop; 0.01 is R's default. | the fit itself, so calls chain | pnEps=a positive fraction of the residual sum; any other value raises an error | SetMaxSweeps, Polish | | call it before Polish
SetMaxSweeps | Sets the largest number of sweeps the polish may make; 10 is R's default. | the fit itself, so calls chain | pnMax=the cap, at least 1; a smaller value raises an error | SetTolerance, IsConverged | a polish that stops at the cap is not converged and Diagnostics reports a warning |
Polish | Fits the table as common plus row effect plus column effect plus residual, using medians, as R's medpolish does. | the fit itself, so calls chain | | Common, Effects, Residuals, Check | every other read raises an error until Polish has run | on the 3 by 3 table 10, 12, 14 / 11, 13, 15 / 13, 15, 20 it gives common 13 and a single residual of 3, as R does
IsPolished | TRUE if Polish has run on this fit. | 1 or 0 | | Polish
Common | Returns the typical value of the whole table, the first term of the fit. | a number | | Effects, Fitted | Raises an error until Polish has run | 13 for the 3 by 3 table above
Effects | Returns the row effects or the column effects, the amount each row or column lies from the common value. | a list of numbers, one per row or per column | pcWhich=Row or Rows for the row effects; Col, Cols, Column or Columns for the column effects; any other text raises an error | Common, Fitted | Raises an error until Polish has run | rows -1, 0, 2 and columns -2, 0, 2 for the 3 by 3 table above
Residuals | Returns what is left of every cell after the fit is taken out. | a list of rows, each a list of numbers, like the table | | Residual, Check, Diagnostics | Raises an error until Polish has run | all zero but the corner, which is 3, for the 3 by 3 table above
Residual | Returns the residual of one cell. | a number | pnRow=the row, from 1; pnCol=the column, from 1; a position outside the table raises error R2 | Residuals, Fitted | Raises an error until Polish has run |
Fitted | Returns what the fit gives for one cell: common plus its row effect plus its column effect. | a number | pnRow=the row, from 1; pnCol=the column, from 1; a position outside the table raises error R2 | Residual, Common | Raises an error until Polish has run | 17 for the corner of the 3 by 3 table above, whose cell is 20
Sweeps | Returns how many sweeps the polish made. | a number | | IsConverged, SetMaxSweeps | Raises an error until Polish has run
IsConverged | TRUE if the polish stopped because the change fell under the tolerance, not because it hit the cap. | 1 or 0 | | Sweeps, SetTolerance | Raises an error until Polish has run
Check | Returns the largest gap between a cell and its fit plus residual over the table, which is 0 when Data equals Fit plus Residual. | a number, 0 up to rounding | | Why, Residuals | Raises an error until Polish has run | a check of the contract, not of the fit's quality
ResidualScale | Returns the fourth-spread of all the residuals, the scale a coded display bands by. | a number | | Residuals, Diagnostics | Raises an error until Polish has run | 1 for the 5 by 3 table 14, 15, 14 / 7, 4, 7 / 8, 2, 10 / 15, 9, 10 / 0, 2, 10
Diagnostics | Returns the verdicts on the fit in the house rule shape: far-out residuals are errors, a polish stopped at its cap a warning. | a list of rows [ :rule, :subject, :where, :severity, :message ]; empty when all is well | pcSubject=what the table is called in the rows; an empty text gives table | Residuals, StzTukeyReportQ | Raises an error until Polish has run | the rules are far_out and not_converged; when every other residual is 0 any residual counts as far out
Why | Returns one sentence on the fit: the common value, the sweeps, whether it converged, and how well Data equals Fit plus Residual. | a text; before Polish it says the table is not yet polished | | Check, Sweeps
