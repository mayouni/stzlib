# Wave 8 -- stzPaymentBatch. Name | brief | returns | params | see | warning | note
init | Builds an empty batch, to which orders or requests are added under one instructionId. | nothing; the object is built | | WithInstructionId, Add
WithInstructionId | Sets the one identifier of the whole batch, the key that makes a retry safe. | the batch itself, so calls chain | pcId=the platform's instructionId, unique for the batch | InstructionId, stzPaymentsPort | | each item still carries its own txId
FromAlias | Sets the platform's alias that is debited, for a batch of payments. | the batch itself, so calls chain | pcAlias=the platform's PI-SPI alias, a UUID | ToAlias, AsBody | | a batch of requests uses ToAlias instead
ToAlias | Sets the platform's alias that is paid, for a batch of requests to pay. | the batch itself, so calls chain | pcAlias=the platform's PI-SPI alias, a UUID | FromAlias, AsRequestBody | | a batch of payments uses FromAlias instead
InCategory | Sets the category of a batch of requests to pay; a batch starts at 401, an invoice. | the batch itself, so calls chain | pcCategory=the category code as text: 500, 521 or 401 | AsRequestBody | | a batch of payments does not send it
Motive | Sets the free text the other side sees on the whole batch. | the batch itself, so calls chain | pcMotif=the text shown with the batch | AsBody
WithConfirmation | Makes the hub hold the batch until the platform confirms it. | the batch itself, so calls chain | | WithoutConfirmation, ConfirmBulk | | the batch then starts as INITIE
WithoutConfirmation | Makes the hub send the batch at once, which is how a batch starts. | the batch itself, so calls chain | | WithConfirmation
Add | Adds one payment order or one request to pay to the batch, as the item the hub expects. | the batch itself, so calls chain | poItem=a stzPaymentOrder for a batch of payments, or a stzPaymentRequest for a batch of requests | NumberOfItems, TotalAmount | raises an error when the item lacks what an item needs: its txId, its amount, and its payee or payer | the item is copied in at once, so changing the order afterwards does not reach the batch
InstructionId | Returns the instructionId set on the batch. | a text; an empty text when none was set | | WithInstructionId
NumberOfItems | Returns how many items the batch holds. | a number | | Add
TotalAmount | Returns the sum of the items' amounts in whole francs, the figure a payout plan must authorise for the batch. | a number | | Add, stzPaymentsPort
AsBody | Returns the batch as the message body for a bulk payment, a list of pairs, once it is complete. | a list of [ key, value ] pairs: instructionId, payeurAlias, confirmation, motif when set, then transactions | | AsRequestBody, stzPaymentsPort | raises an error when the instructionId, the payer's alias or the items are missing | stzPaymentsPort PayInBulk calls it for you
AsRequestBody | Returns the batch as the message body for a bulk of requests to pay, a list of pairs, once it is complete. | a list of [ key, value ] pairs: instructionId, payeAlias, confirmation, motif when set, categorie, then transactions | | AsBody, stzPaymentsPort | raises an error when the instructionId, the platform's alias (ToAlias) or the items are missing | stzPaymentsPort RequestPaymentsInBulk calls it for you
