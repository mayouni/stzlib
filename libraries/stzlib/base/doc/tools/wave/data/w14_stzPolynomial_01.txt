init | Builds a polynomial in one variable from its coefficients, highest degree first, dropping leading zeros. | nothing; the object is built | paCoefficients=the coefficient list, highest degree first, numbers or numbers written as text; a value that is not a list, an empty list or a non-numeric item raises an error | Coefficients, ValueAt | | [1, -6, 11, -6] is x^3 - 6x^2 + 11x - 6; [0, 0, 1, -3] is x - 3; all zeros give the zero polynomial [ 0 ]; build one with StzPolynomialQ(list)

ValueAt | Returns the value of the polynomial at a number, by Horner's rule. | a number | pnX=the number to evaluate at; a text that is not a number raises R41 | Derivative, RealRoots | | At and Eval are the same call; x^3 - 6x^2 + 11x - 6 gives 6 at 4, 0 at 1 and -6 at 0

CompanionMatrix | Returns the companion matrix of the monic form, whose eigenvalues are the roots. | a list of rows, each a list of numbers | | ComplexRoots, Monic | a constant, of degree 0, raises CompanionMatrix: this needs a polynomial of degree 1 or more | CompanionMatrixQ returns a stzMatrix; x^3 - 6x^2 + 11x - 6 gives [6, -11, 6], [1, 0, 0], [0, 1, 0]; x^2 + 1 gives [0, -1], [1, 0]
ComplexRoots | Returns every root, real or complex, as a list of stzComplex, found as the eigenvalues of the companion matrix. | a list of stzComplex, one per degree; [ ] for a constant or the zero polynomial | | RealRoots, CompanionMatrix | a root repeated m times comes back as a cluster of nearby roots, not exactly: (x-2)^3 gives 2.00001 plus or minus 0.0000166i and 1.99998 | Roots is the same call; x^2 + 1 gives i and -i, x^2 + 2x + 5 gives -1 plus or minus 2i
RealRootsWithin | Returns the real roots in ascending order, counting a root as real when its imaginary part is at most a tolerance. | a list of numbers | pnTolerance=the largest absolute imaginary part still counted as real | RealRoots, HasComplexRoot | a repeated root only comes back whole with a loose tolerance: (x-2)^3 gives 2, 2, 2 with 0.001 and a single 2 with 0 | x^3 - 6x^2 + 11x - 6 gives 1, 2, 3 up to rounding
RealRoots | Returns the real roots in ascending order, with a tolerance of 0.000001. | a list of numbers; [ ] when all roots are complex | | RealRootsWithin, NumberOfRealRoots | a root repeated three times loses two of its copies, since their imaginary parts exceed the tolerance: (x-2)^3 gives a single 2 | x^3 - 6x^2 + 11x - 6 gives 1, 2, 3; x^2 + 1 gives [ ]; 2x^2 - 8x + 8 gives 2, 2; x^6 - 1 gives -1 and 1
NumberOfRealRoots | Returns how many real roots there are, counted with the tolerance of RealRoots. | a number | | RealRoots, HasRealRoot | | x^3 - 6x^2 + 11x - 6 gives 3; x^2 + 1 gives 0
HasRealRoot | TRUE if the polynomial has at least one real root. | TRUE or FALSE, as 1 or 0 | | RealRoots | | x^2 + 1 gives 0; the constant 5 gives 0
HasComplexRoot | TRUE if the polynomial has more roots than real ones, so some root has a non-negligible imaginary part. | TRUE or FALSE, as 1 or 0 | | ComplexRoots, HasRealRoot | a real polynomial with a repeated real root can answer TRUE: (x-2)^3 gives 1 | x^2 + 1 gives 1; x^3 - 6x^2 + 11x - 6 gives 0
Plus | Returns the coefficients of the sum with another polynomial, aligned at the lowest degree. | a list of numbers; the object is not changed | paOther=a stzPolynomial or a coefficient list | Minus, Times | the result keeps leading zeros: x^3 - 6x^2 + 11x - 6 minus itself gives [ 0, 0, 0, 0 ], which init would trim; any other value raises I need a polynomial or a coefficient list | PlusQ returns a stzPolynomial and trims; adding [1, 1] gives [ 1, -6, 12, -5 ]; adding x^2 + 1 gives [ 1, -5, 11, -5 ]
