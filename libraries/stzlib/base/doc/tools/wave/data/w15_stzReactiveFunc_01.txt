# w15 stzReactiveFunc
Init | Wraps a function so it can be called as a task that records its outcome. | nothing; the wrapper is built | f=the function to wrap; engine=the reactive engine the tasks are registered with | Call_, CallAsync | | the engine is kept as a copy, so a task added to it is not seen by the original engine
Call_ | Calls the wrapped function now with a list of parameters and returns the task holding the outcome. | a stzFunctionTask already executed: read its Status, Result and Error | params=the arguments, a list of up to 10 values; [ ] for none | CallAsync, Init | a params value that is not a list, or more than 10, leaves a task in error with the reason Reactive call params must be a list or Reactive call has too many params | the call is synchronous and is not run by the engine later: the task is executed here, which is what makes the result real; it is not Ring's call function
CallAsync | Calls the wrapped function with handlers for success and for failure, and returns the task. | a stzFunctionTask already executed | params=the arguments, a list of up to 10 values; onComplete=a function taking the result; onError=a function taking the error text | Call_, Init | a failure inside the function is passed to onError with its real reason, such as Error (R1) : Can't divide by zero, and the task is left in error | despite the name it runs the task at once on the calling thread, as Call_ does; the handlers run before it returns
