init | Opens the machine's local speech recognizer for a listener that hears only a closed list of phrases. | nothing; the object is built | | StzListenerQ, IsUsable | a machine with no recognizer leaves the object unusable and LastError says why; the recognizer runs in the process and reaches no network | no microphone is opened here
Release | Frees the recognizer handle held by the listener. | nothing | | IsUsable | afterwards the listener is not usable and every call is refused
IsUsable | TRUE if the machine has a recognizer and the listener opened it. | TRUE or FALSE | | init, LastError
LastError | Returns the reason the last call failed, or the engine's last recognizer error when none was recorded here. | a text | | Refusals | a successful call does not clear it, apart from Accept, which does
Refusals | Returns how many calls the listener refused. | a number, a no-match not being counted | | LastError, NoMatches
RecognizerCount | Returns how many speech recognizers are installed. | a number; 0 when the speech tier is missing | | Languages, ToRecognizerList
Languages | Returns the language tags the machine can hear, without repeats. | a list of text; fr-FR alone on this machine, which speaks en-US and fr-FR | | HasLanguage, ToRecognizerList | hearing and speaking differ, so ask stzVoice for what can be spoken
ToRecognizerList | Returns every installed recognizer with its language. | a list of [ name, language tag ] rows | | Languages, RecognizerCount
HasLanguage | TRUE if some recognizer hears the language, an exact tag or the same language with another region. | TRUE or FALSE | pcTag=a language tag such as fr-FR, or a bare language such as fr | Languages | the bare language fr matches fr-FR
Accept | Declares the closed list of phrases the listener may hear; anything else will be a no-match. | TRUE if the grammar was set; FALSE with LastError set | paPhrases=the list of phrases that count as commands | AcceptMeanings, HearSound | blank phrases are skipped; an empty list, or a listener that is not usable, is refused and counted | there is no free dictation by design: the measured free dictation reached 66.7 percent exact against 100 percent for a closed list
AcceptedPhrases | Returns the phrases last accepted, as they were given. | a list of text; [ ] before Accept | | Accept, PhraseCount
AcceptMeanings | Declares the phrases and the meaning each one carries in a single call. | TRUE if the grammar was set; FALSE with LastError set | paPairs=a list of [ phrase, meaning ] rows, each meaning one of danger, warning, info, success or muted | MeaningHeard, Accept | an empty list, a row that is not a pair or a sixth meaning is refused at once, with LastError set and the refusal counted | the author declares each meaning; nothing is inferred from the words
MeaningHeard | Returns the meaning declared for the phrase just heard. | a text such as success or danger; an empty text for a no-match, which is a result and not an error | | AcceptMeanings, HeardText | the phrase is matched without regard to case
AcceptedMeanings | Returns the phrase and meaning pairs last declared. | a list of [ phrase in lower case, meaning in lower case ] rows; [ ] before AcceptMeanings | | AcceptMeanings
PhraseCount | Returns how many phrases the grammar holds. | a number; 0 before Accept or when the listener is not usable | | Accept, AcceptedPhrases
HearSound | Recognises a sound against the accepted phrases, which needs no microphone. | TRUE if a phrase was recognised; FALSE for a no-match or a refusal | poSound=the stzSound to listen to, such as one made by stzVoice | HeardText, HearMicrophoneFor | a non-sound, an unusable listener and a sound with no WAV bytes are refused and counted; a no-match is not | the recognizer ran on a phrase spoken by the machine's own voice, not on a person
HearMicrophoneFor | Opens the microphone for a number of seconds and recognises what is said against the accepted phrases. | TRUE if a phrase was recognised; FALSE for a no-match or a refusal | pnSeconds=how long to listen, in seconds | HearSound, Confidence | not run in this reference: it opens an input device, which is this library's consent boundary | the operator should be told that the microphone is open; nothing leaves the machine
HeardText | Returns the text of the last recognised phrase. | a text; an empty text for a no-match and for a listener that is not usable | | Confidence, HeardSomething | it is one of the accepted phrases, as declared
Confidence | Returns how sure the recognizer was of the last phrase, from 0 to 1. | a number; 0 for a no-match | | HeardText | always read it with the text, since a phrase without its confidence is a guess dressed as a fact
HeardSomething | TRUE if the last hearing recognised a phrase. | TRUE or FALSE | | HeardText, WasNoMatch
WasNoMatch | TRUE if the last hearing found nothing in the grammar, which is a result and not an error. | TRUE or FALSE; FALSE before any hearing | | HeardSomething, NoMatches
Recognitions | Returns how many phrases the engine has recognised since it was loaded. | a number | | NoMatches | it is an engine-wide counter, shared by every listener of the process
NoMatches | Returns how many hearings found nothing in the grammar since the engine was loaded. | a number | | Recognitions, WasNoMatch | it is an engine-wide counter, shared by every listener of the process
