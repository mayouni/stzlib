# Wave 12 -- stzSecurityDrill. Name | brief | returns | params | see | warning | note
init | Builds a named drill with a default evidence file path in the current folder; nothing is started or contacted yet. | nothing; the object is built | pcName=the drill's name; it also names the default evidence file _drill_<name>_evidence.stzledger | SpawnTarget, SetEvidencePath | nothing is spawned or contacted until SpawnTarget | the evidence path is absolute, built from the current folder at construction
Name | Returns the drill's name. | a text | | init
SetKey | Sets the shared secret of the target's signed-request gate, which FireReplay also signs with. | the drill itself, so calls chain | pcKey=the secret, as text; the default is drill-shared-secret | FireReplay, SpawnTarget | the key is handed to the target at SpawnTarget, so set it before | an invented key only: it is a rehearsal secret, never a real one
SetEvidencePath | Sets the file where the target seals its ledger and from which the drill reads it back. | the drill itself, so calls chain | pcPath=the evidence file path, absolute because the target resolves paths in its own folder | EvidencePath, CollectEvidence, Destroy | Destroy deletes this file if it exists
EvidencePath | Returns the path of the evidence file. | a text | | SetEvidencePath, CollectEvidence
Port | Returns the port the target listens on, 0 before SpawnTarget. | a number | | SpawnTarget
SpawnTarget | Starts the application under attack as a child ring process on 127.0.0.1 and waits for it to answer. | 1 (TRUE) when the target answered within 20 seconds, else 0 | pnPort=the port to listen on; 0 picks a number between 38000 and 38899 | WaitReady, Destroy, CollectEvidence | not run here: it starts a second process, opens a port and writes a generated script .stzdrilltarget_gen.ring beside the security sources; a drill is for a machine set aside for it, and Destroy stops the child | the target has its own ledger, auth, signed-request gate and /seal route, and ends by itself after 60000 ms
WaitReady | Polls the target's /health route until it answers 200 OK or the time is up. | 1 (TRUE) when the target answered; 0 on timeout | pnTimeoutMs=how long to wait, in milliseconds | SpawnTarget | not run here: it sends requests to the target's port; on a drill that never spawned a target it can only time out
FireCredentialStuffing | Sends a number of login requests with wrong passwords for one account and expects the credential-stuffing detection to fire. | the drill itself, so calls chain | pcUser=the account to attack; pnTimes=how many wrong passwords to send, one request each | FireForgery, FireReplay, CollectEvidence, Expectations | the passwords are wrong-1, wrong-2 and so on; the expectation is recorded whether or not the target answered | the first attack sent stamps the start of TimeToDetectMs
FireForgery | Sends one signed request whose signature does not verify and expects the forged-request detection to fire. | the drill itself, so calls chain | | FireCredentialStuffing, FireReplay | | the request carries the current time and the nonce forge-1
FireReplay | Sends one validly signed request twice, so the second is a replay, and expects the replayed-request detection. | the drill itself, so calls chain | | FireForgery, SetKey | | it signs with the drill's key (SetKey) and assigns the global $oDrillServer, a stzRequestSigner, in the calling process
Expectations | Returns what the attacks fired so far expect to see detected. | a list of [ detection name, attack label ] rows, in the order fired; [ ] before any attack | | FiredDetections, Passed
CollectEvidence | Asks the target to seal its ledger, verifies the sealed file, rebuilds a working ledger from it and notes which detections fired in it. | 1 (TRUE) when the evidence was verified and acquired; 0 when the file is missing or fails verification, and AcquisitionWhy says why | | AcquiredLedger, FiredDetections, Passed, AcquisitionWhy | the drill believes only the sealed and verified file, never the target's memory | when every expectation is met, the time of detection is stamped; the rebuilt ledger recomputes its own chain
OpenVictimSession | Logs the victim in for real before the attack, so containment has a live session to end. | TRUE if the target returned a session token; FALSE when it refused | pcUser=the account to log in; pcPassword=its password | Contain, ContainmentHolds | the token is kept inside the drill for ContainmentHolds
Contain | Turns the acquired evidence into a response plan and performs on the target what the operator may commit. | the number of actions committed, 0 when the operator is refused | poOperator=the actor who commits, for example HumanActor("oncall"); an LLMActor is refused and commits nothing | ContainmentHolds, Containment, CollectEvidence | raises an error when no evidence was acquired yet; a refused operator commits nothing and the plan records the refusal | the plan holds one incident per credential-stuffing finding; when something was committed and ContainmentHolds is TRUE, the time of containment is stamped
ContainmentHolds | TRUE if the right password is refused and the pre-attack session is dead, checked from outside the target. | TRUE or FALSE; FALSE before containment | | Contain, OpenVictimSession | | it sends two requests to the target for the account named victim
TimeToDetectMs | Returns the milliseconds from the first attack sent to the evidence showing every expected detection. | a number; -1 when that point was not reached | | TimeToContainMs, Explain
TimeToContainMs | Returns the milliseconds from the detection to a containment that was applied and verified. | a number; -1 when that point was not reached | | TimeToDetectMs, Contain
Containment | Returns what Contain did: how many actions were planned, committed and refused. | a list of [ :planned, :committed, :refused ] rows, one list per Contain call; [ ] before any | | Contain
AcquiredLedger | Returns the ledger rebuilt from the verified evidence. | a ledger object; the empty text before a successful CollectEvidence | | CollectEvidence, Attestor
Attestor | Returns who attested the sealed evidence. | a text, such as target-process; the empty text before a successful CollectEvidence | | AcquiredLedger
AcquisitionWhy | Returns the verdict of the last evidence acquisition, in words. | a text such as "acquired 9 verified entr(ies)", or the reason it was refused, such as a missing file; empty before CollectEvidence | | CollectEvidence
FiredDetections | Returns the names of the detections found in the acquired evidence. | a list of text; [ ] before CollectEvidence | | Expectations, Passed, MissedDetections
Passed | TRUE if at least one attack was fired and every expected detection fired in the evidence. | TRUE or FALSE | | MissedDetections, Explain
MissedDetections | Returns the expected detections that did not fire. | a list of text; [ ] when none missed | | Passed, Expectations
Explain | Returns the drill's report as lines: verdict, evidence, one line per expected detection, and the timings. | a list of text lines | | Show, Passed | one line per expected detection is marked fired or MISSED, and the two timings follow when known; with an acquired ledger but no attack fired, the verdict reads "MISSED: ." with nothing after it
Show | Prints the lines of Explain. | nothing; it prints | | Explain
Destroy | Kills the child target if one was spawned and deletes the evidence file if it exists. | the drill itself, so calls chain | | SpawnTarget, SetEvidencePath | | on a drill that spawned nothing it only deletes the evidence file
