init | Builds a Ring code graph, scanning every .ring file of a folder, or an empty graph when the path is empty. | nothing; the object is built | pcRootPath=the folder to scan, below which every sub-folder is scanned too; an empty text builds an empty graph | ScanSource, StzRingCodeGraphFromSource | a path that is not a folder raises the file-system error of dir
Language | Returns the name of the language this graph models. | the text ring | | FileExtension
FileExtension | Returns the file extension of the source files it scans, with the dot. | the text .ring | | Language
ScanSource | Scans one Ring source text: class headers with their parent, methods, and the calls found in method bodies. | nothing | pcContent=the Ring source text; pcFile=the file name recorded for what it finds | init, CallEdges | | call edges appear only after BuildGraph and the private resolve step that StzRingCodeGraphFromSource and the folder constructor run, so a graph filled by hand through ScanSource shows none
CallEdges | Returns the resolved calls between defined methods, as the class, the calling method and the name called. | a list of [ class, method, callee ] triples, without repeats | | RawCallEntries, CallersOf, CalleesOf | | a call to something no class defines, such as a builtin, is not an edge
NumberOfCallEdges | Returns how many call edges were resolved. | a number | | CallEdges
RawCallEntries | Returns every call found in a method body, defined or not, builtins included, with the line of the call. | a list of [ class, method, callee, line ] rows | | CallEdges | | strings and comments are stripped first, so a name in a message is not a call; a definition is not a call
CallersOf | Returns the methods whose body calls the named method, by name. | a list of hash lists [ :class, :method ], without repeats | pcMethod=the name of the method that is called | CalleesOf, CallEdges | | the name is matched without regard to case
CalleesOf | Returns the names of the defined methods that one method calls. | a list of text | pcClass=the class of the calling method; pcMethod=the calling method | CallersOf, CallEdges | | the class and method are matched without regard to case; an unknown pair answers an empty list
DeadCode | Returns the private helpers, whose names start with an underscore, that no call in the scanned tree reaches. | a list of hash lists [ :class, :method, :file, :line ] | | CallersOf, CyclicCalls | | public methods are never reported, since they may be entry points called from outside the tree; calls through a variable are invisible to a name-based graph
CyclicCalls | Returns pairs of methods of one class that call each other, a mutual recursion. | a list of hash lists [ :class, :cycle = [ a, b ] ] | | CallersOf, DeadCode | | a method calling itself is legitimate and not reported
Stats | Returns the size of the graph: root, language, classes, methods, inheritance edges and call edges. | a hash list; its keys come back in lower case, such as inheritsedges and calledges | | NumberOfCallEdges
