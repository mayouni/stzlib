init | Builds a skill from the structure file and the per-language text files that share its id in one folder. | nothing; the object is built | pcFolder=the folder that holds the skill files, with or without a trailing slash; pcId=the skill's id, such as cr-01, matched without regard to case | StzSkillQ, Languages | raises an error naming the id and the folder when the folder has no file <id>.zknw | the text files are read once, here: a language file added later is not seen by this object
Id | Returns the skill's id in lower case, as it names its files. | a text, such as cr-01 | | Family, Title
Family | Returns the family the skill belongs to, as declared in its structure file. | a text such as craft; an empty text when no family is declared | | Anchors, Study
Study | Returns the names of the study material that teaches the skill. | a list of text; [ ] when none is declared | | Anchors, Evidence
Anchors | Returns the names of the workplace worlds that anchor the skill's examples. | a list of text, such as school and cooperative; [ ] when none is declared | | Family, Study
Evidence | Returns what the skill's structure file says proves one level: an exercise for foundation, a project for practitioner and expert. | a text such as elementary-introduction/ex-15-01 or project-s3; an empty text for an unknown level or a level with no evidence | pcLevel=foundation, practitioner or expert, matched without regard to case | Level, Study | the evidence is a claim about a guard; this call does not check that the exercise or project exists
Languages | Returns the language codes in which the skill has a text file. | a list of text, in the order the folder lists the files, such as ar, en, fr, ha; [ ] when the skill has no text file | | MissingIn, IsCompleteIn
Title | Returns the skill's title in one language, without its CR-01 style id prefix. | a text | pcLang=the language code, matched without regard to case | Question, Level, Languages | raises an error naming the skill and the language when the skill has no text file in that language
Question | Returns the guiding question of the skill in one language. | a text | pcLang=the language code, matched without regard to case | Title, Level | raises an error naming the skill and the language when the skill has no text file in that language
Level | Returns what a learner can do at one level of the skill, in one language. | a text; an empty text when the level is unknown or the text file leaves it empty | pcLang=the language code, matched without regard to case; pcLevel=foundation, practitioner or expert, matched without regard to case | Question, Evidence | raises an error naming the skill and the language when the skill has no text file in that language
MissingIn | Returns the languages, among those given, in which the skill has no text file or has a text with an empty field. | a list of the codes given, in the order given; [ ] when the skill is complete in all of them | pacLangs=the language codes to test, in lower case | IsCompleteIn, Languages | the codes are compared as written: "EN" is reported missing although en exists, while Title and Level accept "EN"; the translated texts (fr, ar, ha) are drafts, 0 of 35 units reviewed by a person
IsCompleteIn | TRUE if the skill has a text with a title, a question and all three levels in every language given. | TRUE or FALSE; TRUE for an empty list | pacLangs=the language codes to test, in lower case | MissingIn, Languages | same case rule as MissingIn: pass lower-case codes
