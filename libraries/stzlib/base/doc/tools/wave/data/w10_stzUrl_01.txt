init | Builds a URL object by parsing the text with the engine; nothing is fetched, and an empty text builds an empty object. | nothing; the object is built | pcUrl=the URL as text, for example https://example.com:8080/a/b.html?x=1#top | SetUrl, IsValid | the class is in network/stzUrl.ring but neither stzlib.ring nor stzBase.ring loads that file, so load it by hand before use | text that does not parse is kept as given: IsValid answers FALSE and the parts are empty
Content | Returns the URL as text; when the object is empty it is rebuilt from its parts. | a text | | SetContent, Copy, ReconstructUrl | | Url and ToString are the same call
SetContent | Replaces the URL by parsing new text; every part is read again from it. | nothing | pcUrl=the new URL as text | SetUrl, Content | | it does what SetUrl does
Copy | Returns a new independent stzUrl built from the current text. | a new stzUrl | | Content, Swap
SetUrl | Replaces the URL by parsing new text, freeing the previous parse and clearing every cached part. | nothing | pcUrl=the new URL as text | SetContent, Clear | | the new text is parsed at once, so Host, Path and the others answer for it
IsValid | TRUE if the engine parsed the text as an absolute URL with a scheme and a host. | TRUE or FALSE | | IsEmpty, IsRelative | | a relative reference such as d.html or /a/b?q=1 answers FALSE even though its path and query are read; the empty object and text such as :::: also answer FALSE
IsEmpty | TRUE if no URL text is held, which is the case for a new empty object and after Clear. | TRUE or FALSE | | Clear, IsValid | | it reads the held text, so an object built from garbage text is not empty
Clear | Forgets the URL and every part, leaving an empty object. | nothing | | IsEmpty, SetUrl
Scheme | Returns the scheme, the part before ://, as written in the URL. | a text; empty when there is none | | Protocol, IsHttp, IsHttps | | the case is kept: HTTP://h/ answers HTTP, while IsHttp compares without regard to case
SetScheme | Sets the scheme and rebuilds the URL text from the parts. | nothing | pcScheme=the new scheme, for example https | Scheme, ReconstructUrl | | IsHttps and the other type checks follow at once
Host | Returns the host name, without user information or port. | a text; empty when there is none | | Domain, Server, Authority | | Domain and Server are the same call
SetHost | Sets the host and rebuilds the URL text; the port, path and query are kept. | nothing | pcHost=the new host name | Host, SetAuthority
Port | Returns the port written in the URL, or -1 when none is written. | a number | | PortWithDefault, SetPort | | a URL without a port answers -1 even for http and https
PortWithDefault | Returns the port of the URL, or the given number when no port is written. | a number | nDefault=the number to answer when the URL has no port | Port | | 0 counts as no port
SetPort | Sets the port and rebuilds the URL text. | nothing | nPort=the new port number | Port, ReconstructUrl | | the text drops ports 80 and 443 whatever the scheme, so SetPort(80) on https removes the port from Content
Path | Returns the path, from the first slash after the host up to the query. | a text; empty when there is none | | Location, FileName, SetPath | | the engine reads a bare reference such as sub/d.html with sub as the host and /d.html as the path; d.html alone has an empty path
SetPath | Sets the path and rebuilds the URL text; a missing leading slash is added. | nothing | pcPath=the new path | Path, SetQuery
FileName | Returns the last segment of the path, the part after the final slash. | a text; empty when the path is empty | | Path | Raises error today when the path ends with a slash, on /a/b/ and on / alike: the section call is given an end before its start | Section(n + 1, n) is out of range; /a/b answers b and an empty path answers an empty text
Query | Returns the query, the text between ? and #, without the question mark. | a text; empty when there is none | | HasQuery, SetQuery
HasQuery | TRUE if the URL carries a query after a question mark. | TRUE or FALSE | | Query
SetQuery | Sets the query and rebuilds the URL text; give it without the question mark. | nothing | pcQuery=the new query, for example a=2&b=3 | Query, SetFragment
Fragment | Returns the fragment, the text after #, without the hash sign. | a text; empty when there is none | | HasFragment, SetFragment
HasFragment | TRUE if the URL carries a fragment after a hash sign. | TRUE or FALSE | | Fragment
SetFragment | Sets the fragment and rebuilds the URL text; give it without the hash sign. | nothing | pcFragment=the new fragment, for example end | Fragment, SetQuery
UserName | Returns the user name written before the @ of the authority. | a text; empty when there is none | | Password, UserInfo, SetUserName
Password | Returns the password written after the colon in the user information. | a text; empty when there is none | | UserName, UserInfo, SetPassword | | the password stays readable in Content and Authority: do not log a URL that carries one
UserInfo | Returns the user name and password joined by a colon, or the user name alone. | a text; empty when neither is set | | UserName, Password, SetUserInfo
SetUserName | Sets the user name and rebuilds the URL text with it before the host. | nothing | pcUserName=the new user name | UserName, SetUserInfo
SetPassword | Sets the password and rebuilds the URL text; it shows only when a user name or password is set. | nothing | pcPassword=the new password | Password, SetUserInfo
SetUserInfo | Sets the user name and password from text of the form user:password, or only the user name when there is no colon. | nothing | pcUserInfo=the user information, for example zed:pp | UserInfo, SetAuthority | | text without a colon clears an earlier password
Authority | Returns the user information, host and port joined as user:password@host:port, leaving out what is absent. | a text | | Host, Port, UserInfo, SetAuthority | | it prints a port of 80 or 443 when one is set, which Content leaves out
SetAuthority | Sets the user information, host and port from text such as kim:k1@host:9000 and rebuilds the URL text. | nothing | pcAuthority=the authority as text | Authority, SetHost | an authority with no user information or no port does not clear the old ones: SetAuthority("plain.net") on a URL that had kim:k1 and port 9000 leaves kim:k1@plain.net:9000 | the parts that are given replace the old ones; the others stay
