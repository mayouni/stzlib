init | Builds a delivery planner for a solution, to which parts, their targets and the capabilities each uses are then declared. | nothing; the planner is built | pcName=the name of the solution | AddPart, NeedsIn, Plan
Name | Returns the name of the solution. | a text | | init
Log | Returns the structured log of the delivery phases, which Deploy writes to. | a stzLog, queryable and renderable | | Deploy
SetAppTopology | Attaches the application model of the solution, so a part can be rendered from what it does. | nothing; SetAppTopologyQ is the form that chains | poApp=the stzAppTopology of the solution | AppTopology, HasAppTopology
AppTopology | Returns the attached application model. | the stzAppTopology; an empty text when none is attached | | SetAppTopology, HasAppTopology
HasAppTopology | TRUE if an application model is attached. | TRUE or FALSE | | SetAppTopology
UseCatalog | Replaces the capability catalog the planner reasons with. | the planner itself, so calls chain | poCat=the stzCapabilityCatalog to use in place of the default | Plan, stzCapabilityCatalog
AddPart | Adds a part of the solution with its kind and its target platform. | the planner itself, so calls chain | pcKind=the kind of part, such as app, backend or firmware; pcName=the part name; pcTarget=the target platform, such as Android, browser, Linux or ESP32 | NeedsIn, Parts | name, kind and target are stored in lower case; the target decides the class: mobile, browser, mcu or server, and a name it does not recognise counts as a server
AddApp | Adds a part of kind app. | the planner itself, so calls chain | pcName=the part name; pcTarget=the target platform | AddPart, AddSuperApp
AddSuperApp | Adds a part of kind superapp. | the planner itself, so calls chain | pcName=the part name; pcTarget=the target platform | AddPart, AddApp
AddBackend | Adds a part of kind backend. | the planner itself, so calls chain | pcName=the part name; pcTarget=the target platform | AddPart, AddServer
AddServer | Adds a part of kind server. | the planner itself, so calls chain | pcName=the part name; pcTarget=the target platform | AddPart, AddBackend
AddFirmware | Adds a part of kind firmware. | the planner itself, so calls chain | pcName=the part name; pcTarget=the target platform | AddPart, NeedsIn
Parts | Returns the parts declared, in order. | a list of [ name, kind, target, capabilities ] rows, all in lower case | | NumberOfParts, AddPart
NumberOfParts | Returns how many parts are declared. | a number | | Parts
NeedsIn | Declares the Softanza capabilities a part uses, which the plan then places. | the planner itself, so calls chain | pcPart=the part name, matched without regard to case; paCaps=a list of capability names such as :PivotTable, stored in lower case | InferNeedsIn, Plan | the list replaces the capabilities declared before rather than adding to them, and anything but a list clears them; an unknown part changes nothing
UseServices | Attaches the solution's service registry, so the plan can show every external dependency before anything runs. | nothing; UseServicesQ is the form that chains | poReg=the stzServiceRegistry to attach | ServicesQ, ExternalDependencies | the planner keeps a copy: finish configuring the registry before attaching it, or change it through ServicesQ
ServicesQ | Returns the attached service registry. | the stzServiceRegistry; an empty text when none is attached | | UseServices
HasServices | TRUE if a service registry is attached. | TRUE or FALSE | | UseServices
ServiceNeedsIn | Returns the external services a part calls. | a list of lower-case service names; an empty list when none are declared | pcPart=the part name | ServiceNeeds, ExternalDependencies
ServiceNeeds | Returns which part needs which service. | a list of [ part, services ] rows | | ServiceNeedsIn
ExternalDependencies | Returns the rehearsed external surface: per service, its posture, its secret name, whether it is bound and the parts needing it. | a list of [ :service, :posture, :secret, :bound, :parts ] records; empty when no registry is attached | | ProductionCredentials, ServicesAreProductionReady | | it names secrets and never reads their values
NumberOfExternalDependencies | Returns how many external services are declared or bound. | a number | | ExternalDependencies
ProductionCredentials | Returns the names of the credentials a production deploy will require. | a list of text, names only and never values | | ExternalDependencies
ServiceFindingsForProduction | Asks what shipping would say about the external surface, by judging it as if in production and then putting the phase back. | a list of finding records with an invariant, a severity, a place and a message; an empty list when no registry is attached | | ServicesAreProductionReady, WhyServicesNotReady | | the registry phase is restored afterwards, so asking is not declaring
ServicesAreProductionReady | TRUE if the external surface has no error-level finding for production. | TRUE or FALSE | | ServiceFindingsForProduction, WhyServicesNotReady
WhyServicesNotReady | Returns the first reason the external surface is not ready for production. | a text such as sandbox-in-production followed by the message; an empty text when it is ready | | ServicesAreProductionReady
AsRuleGraph | Projects the parts and the services into one graph, so a rule can ask whether a part destined for production depends on a fake. | a stzGraph with a node per part and per service, linked by depends-on edges | | stzServiceRuleSet, ServiceNeedsIn | | a part bound to a site is marked as destined for production, the others as unbound
InferNeedsIn | Reads a source file and sets the capabilities of a part from the markers found in it, such as Pivot, Solve, Regex or Json. | the planner itself, so calls chain | pcPart=the part name; pcSourcePath=the path of the source file to scan | NeedsIn, Plan | a lexical scan, not an analysis of calls; an unreadable file or an unknown part changes nothing
DeployTo | Binds a target site to the part it hosts, for a production deploy. | the planner itself, so calls chain | poSite=the stzDeploymentSite that hosts the part; pcPart=the part name | Bindings, Deploy
SetActor | Sets who deploys; only an effectful actor can commit a production deploy, the others get a rehearsal. | the planner itself, so calls chain | poActor=the stzSystemActor executing the deploy | DeploymentActor, Deploy
Bindings | Returns the sites bound to parts. | a list of [ part, site ] rows | | DeployTo
DeploymentActor | Returns the actor set to deploy. | the actor; an empty text when none is set | | SetActor
RequiresIn | Declares what a part needs from its host: memory, compute and storage. | the planner itself, so calls chain | pcPart=the part name; poSpec=the stzResourceSpec describing the footprint | RequirementFor, Requirements
RequirementFor | Returns the footprint declared for a part. | the stzResourceSpec; an empty text when none is declared | pcPart=the part name, matched without regard to case | RequiresIn
Requirements | Returns every footprint declared. | a list of [ part, spec ] rows | | RequiresIn
ShipBundle | Declares that a part ships the whole emulator bundle as its production artifact. | the planner itself, so calls chain | pcPart=the part name; pBundle=the stzEmulator or the folder path of the bundle | ShipSlice, Bundles
ShipSlice | Declares that a part ships only its own slice of the bundle: its app, its engine subset and the bridge. | the planner itself, so calls chain | pcPart=the part name; pBundle=the stzEmulator or the folder path of the bundle | ShipBundle, Bundles
Bundles | Returns the bundles declared for shipping. | a list of [ part, bundle, bundle or slice ] rows | | ShipBundle, ShipSlice
Plan | Rehearses the placement and scope plan without building a byte: per part and capability, a delivery vector and why. | a stzBuildPlan, readable with Explain or Show | | stzBuildPlan, Deploy | | it is the way to read what a build would do, and it changes nothing
Deploy | Commits the solution: :Emulated builds the web emulator bundle, :Production binds parts to sites and launches them if the actor may. | a stzEmulator for :Emulated, a stzDeployment for :Production, a stzBuildPlan for any other mode | pMode=:Emulated or :Production | Plan, SetActor, DeployTo | not run: it builds and, in production, stores and launches for real; read Plan first, and note that a production deploy is refused while a service is still bound to a fake | an actor that may not commit gets the deployment back as a rehearsal, and the Log says which gate refused
