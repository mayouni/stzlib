# Wave 9 -- stzSystemCall. Name | brief | returns | params | see | warning | note
init | Builds a call from a command line, splitting it into a program and arguments; nothing runs yet. | nothing; the object is built | pcCommandString=the command line, as text; a trailing @RETURN:list or @RETURN:number sets how the output is read | Run, SetArgs, SetReturnType | anything but a text raises the error Command must be a string! | on Windows a command that starts with a shell word such as echo, or holds a pipe, an ampersand or a redirection, is wrapped to run through cmd.exe /c, so Program answers cmd.exe
ParseCommandString | Splits a command line into the program and its arguments, keeping a double-quoted part as one argument. | nothing; Program and Args hold the result | _cCmd_=the command line, as text; a trailing @RETURN:type sets the return type | Program, Args | | the program is the first word, so a program path with spaces must be set with SetProgram
Run | Runs the command and keeps its output, error text and exit code in the object. | nothing; read Output, Error and ExitCode afterwards | | RunAndGetOutput, RunSilently, Succeeded | an empty program raises the error No program specified! | RunQ is the same call and returns the object; Execute and Exec are the same call; the Timeout is stored but not applied, see SetTimeout
Execute | Runs the command and keeps its output, error text and exit code in the object. | nothing; read Output, Error and ExitCode afterwards | | Run, Exec
Exec | Runs the command and keeps its output, error text and exit code in the object. | nothing; read Output, Error and ExitCode afterwards | | Run, Execute
SetReturnType | Chooses how the output is read after a run: as text, as a number or as a list of lines. | the object itself, so calls chain | _cType_=string, number or list; the case is ignored | ReturnType, Run | any other word raises the error Return type must be 'string', 'number', or 'list' | with list or number the output is turned into that type by Run, and then OutputAsLines raises an error; a number is read only from output made of digits, see ParseOutputAsNumber
ReturnType | Returns how the output is read after a run: string, number or list. | a text, "string" by default | | SetReturnType, ConvertOutputByType
ConvertOutputByType | Turns the text output into a list of lines or a number according to the return type; text stays as it is. | nothing; Output holds the converted value | | SetReturnType, ParseOutputAsLines, ParseOutputAsNumber | | Run calls it for you when the output is captured; calling it again on an already converted output does nothing
ParseOutputAsLines | Returns the output split into its non-empty lines, each trimmed. | a list of text; an empty list when there is no output | | OutputAsLines, ParseOutputAsNumber
ParseOutputAsNumber | Returns the first number found in the output. | a number; 0 when the output is empty | | ParseOutputAsLines, SetReturnType | raises the error R41 Invalid numeric string when the output holds a character that is not a digit, so "12" is read and "42 apples", "3.5", "-8" and "none" all raise (its character test compares each character with "0" and raises on a letter, a space after the digits, a sign or a point) | it works only on output made of digits
Program | Returns the program the call will run. | a text | | SetProgram, Args
SetProgram | Sets the program the call will run. | nothing; use SetProgramQ to chain | pcProgram=the program name or path, as text | Program, SetArgs
Args | Returns the arguments the call will pass to the program. | a list of text | | SetArgs, AddArg
SetArgs | Sets the argument list and, for a program that is not a shell, makes the call run them without any shell parsing. | nothing; use SetArgsQ to chain | pacArgs=the arguments, as a list of text | Args, AddArg, SetParam | a list holding a non-text raises the error Args must be a list of strings! when parameter checking is on | WithArgs is the same call; a shell program such as cmd.exe, sh, bash or powershell keeps shell parsing
SetParam | Replaces {name} in every argument by a value. | nothing | cParam=the placeholder name, written without braces; _cValue_=the text to put in its place | SetParams, SetArgs | | on Windows a value holding / or \ gets its slashes turned into backslashes
SetParams | Replaces several {name} placeholders in the arguments, one pair after another. | nothing; use SetParamsQ to chain | aParams=a list of [ name, value ] pairs | SetParam, SetArgs | | WithParams is the same call
AddArg | Appends one argument to the list. | nothing; use AddArgQ to chain | pcArg=the argument to append, as text | Args, SetArgs | | WithArg is the same call
ClearArgs | Empties the argument list. | nothing; use ClearArgsQ to chain | | Args, Reset
SetTimeout | Stores a timeout in milliseconds for the call. | nothing; use SetTimeoutQ to chain | nMilliseconds=the timeout, in milliseconds | Timeout | the value is only stored: nothing reads it when the command runs, so a call set to 1 ms still ran a 2-second command to its end (ping -n 3 on 127.0.0.1, 2083 ms, exit 0, tried also with echo) | WithTimeout is the same call
Timeout | Returns the stored timeout, in milliseconds; 30000 by default. | a number | | SetTimeout | | it is a stored value that Run does not apply
CaptureOutput | Asks for the output to be kept after a run, which is the default. | nothing; use CaptureOutputQ to chain | | DontCaptureOutput, Output
DontCaptureOutput | Asks for the output not to be kept after a run. | nothing; use DontCaptureOutputQ to chain | | CaptureOutput, Output | with the console hidden, which is the default, Output still holds the text (tried with echo, twice): only the conversion to a list or a number is skipped; with ShowConsole the output is really dropped |
CaptureError | Asks for the error text to be kept after a run, which is the default. | nothing; use CaptureErrorQ to chain | | DontCaptureError, Error
DontCaptureError | Asks for the error text not to be kept after a run. | nothing; use DontCaptureErrorQ to chain | | CaptureError, Error
ShowConsole | Makes the next run go through Ring's own system call, with the output and error redirected to temporary files. | nothing; use ShowConsoleQ to chain | | HideConsole, Run
HideConsole | Makes the next run use the engine, with no console window, which is the default. | nothing; use HideConsoleQ to chain | | ShowConsole, RunSilently | | Silent and Silently are the same call
Silent | Makes the next run use the engine, with no console window. | nothing; use SilentQ to chain | | HideConsole, RunSilently
Silently | Makes the next run use the engine, with no console window. | nothing; use SilentlyQ to chain | | HideConsole, RunSilently
RunEngineSilent | Runs the command through the engine and keeps only its exit code. | nothing; read ExitCode afterwards | | RunSilently, Run | | the command's own output is not kept but is not hidden either: it appears in the console that started the program
RunSilently | Runs the command and keeps only its exit code, with no output or error captured. | nothing; read ExitCode afterwards | | Run, RunEngineSilent | the command's own output is not kept but it still appears in the console that started the program (echo printed its text, tried 4 times) | RunSilentlyQ is the same call and returns the object; RunSilent is the same call
RunSilent | Runs the command and keeps only its exit code, with no output or error captured. | nothing; read ExitCode afterwards | | RunSilently, Run
Output | Returns the text the command wrote to its output, as read after the last run. | a text; an empty text before a run; a list or a number when the return type asked for one | | OutputAsLines, Error, RunAndGetOutput | | Result and StdOut are the same call; on Windows echo adds a line feed at the end
OutputAsLines | Returns the output as a list of its non-empty lines, each trimmed. | a list of text; an empty list when there is no output | | Output, ParseOutputAsLines | raises an error (Bad parameter type for list, Incorrect param type for number) when the return type is list or number, because the output was already converted | OutputAsList, ResultAsLines and ResultAsList are the same call
Error | Returns the text the command wrote to its error stream, as read after the last run. | a text; an empty text before a run | | HasError, Output | | StdErr is the same call
ExitCode | Returns the exit code of the last run; -1 before any run. | a number; 0 usually means success | | Succeeded, Failed
WasExecuted | TRUE if the command has been run since the call was built or reset. | TRUE or FALSE | | Run, Reset
Succeeded | TRUE if the command ran and ended with the exit code 0. | TRUE or FALSE; FALSE before any run | | Failed, ExitCode | | Success is the same call
Failed | TRUE if the command did not run or ended with an exit code other than 0. | TRUE or FALSE | | Succeeded, ExitCode
HasOutput | TRUE if the output is not empty. | TRUE or FALSE | | Output, HasError
HasError | TRUE if the error text is not empty. | TRUE or FALSE | | Error, HasOutput
RunAndGetOutput | Runs the command and returns its output in one step. | a text, or the converted value for the return type | | Run, Output | | GetOutput is the same call
Env | Returns the value of an environment variable of this process. | a text; an empty text when the variable does not exist | pcVarName=the name of the environment variable | EngineIsWindows | | GetEnv and EnvironmentVariable are the same call
EngineIsWindows | TRUE if the engine reports that this machine runs Windows. | TRUE or FALSE | | EngineIsLinux, EngineIsMacos
EngineIsLinux | TRUE if the engine reports that this machine runs Linux. | TRUE or FALSE | | EngineIsWindows, EngineIsMacos
EngineIsMacos | TRUE if the engine reports that this machine runs macOS. | TRUE or FALSE | | EngineIsWindows, EngineIsLinux
OpenFile | Opens a file in the program the system associates with it, by setting cmd.exe, open or xdg-open as the program and running it silently. | nothing; use OpenFileQ to chain | _cFilePath_=the file or folder to open | StzOpenInDefaultApp, RunSilently | not run here: it starts a viewer on the machine; it overwrites the program and arguments of the call, and StzOpenInDefaultApp is the safe form that refuses a path that does not exist |
Reset | Forgets the results of the last run and the arguments, so the call can be reused. | nothing; use ResetQ to chain | | Run, ClearArgs | | the program stays set, so after a Reset the call still holds the program (cmd.exe for a command that was wrapped)
UseShellIfNeeded | Wraps the command to run through the shell when it holds a shell operator or starts with a shell built-in such as echo or dir. | the object itself, so calls chain | | init, Run | | init and Run call it for you; the shell is cmd.exe /c on Windows and sh -c elsewhere; UseShellIfNeededQ is the same call
WithArgs | Sets the argument list, as SetArgs does. | nothing; use WithArgsQ to chain | pacArgs=the arguments, as a list of text | SetArgs, Args
WithParams | Replaces several {name} placeholders in the arguments, as SetParams does. | nothing; use WithParamsQ to chain | aParams=a list of [ name, value ] pairs | SetParams, SetArgs
