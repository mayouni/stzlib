# w15 stzPerfPlan
init | Builds an empty plan of tuning actions under a name. | nothing; the object is built | pcName=the name of the plan | Propose, ExecuteOn | | StzPerfPlan builds the same object; building and explaining a plan is free, only committing it is governed
Name | Returns the name the plan was built with. | the name as text | | Explain |
Propose | Adds one action to the plan, with the reason for it; nothing is executed. | the plan itself, so calls chain | pcAction=ScaleUp, ScaleDown or RestartDead, in any letter case; pcTag=the tag of the part of the fleet it concerns, kept in lower case; pcRationale=why, as a sentence, kept in the audit | Actions, ExecuteOn | an action outside the closed catalog, such as Reboot, raises error stzPerfPlan: unknown action ... The catalog is closed | the action is stored in lower case, such as scaleup
Actions | Returns the proposed actions in order. | a list of [ action, tag, rationale ] | | Propose, NumberOfActions | |
NumberOfActions | Returns how many actions the plan holds. | a number | | Actions, Propose | |
MayCommit | TRUE if an actor is admitted to commit the plan, asked before any attempt. | TRUE or FALSE, as 1 or 0 | poActor=the actor, such as LLMActor or HumanActor | ExecuteOn, AuditTrail | | an actor that is not effectful, or whose posture is sandboxed, is refused, so an inference-only advisor may build and explain a plan but never commit it
ExecuteOn | Applies the plan to a target when the actor may commit it, and audits every action as committed or refused. | the number of actions committed; 0 when the actor was refused, with one refused line for each action in the audit | poTarget=a stzAppCluster or any object answering ScaleUp(tag), ScaleDown(tag) and RestartDead(); poActor=the actor asking to commit | MayCommit, AuditTrail, WasExecuted | | a RestartDead heals every dead worker in one call, and a second RestartDead in the same plan is counted as committed without calling the target again; refused attempts stay in the trail beside later committed ones
WasExecuted | TRUE if the plan was committed at least once. | TRUE or FALSE, as 1 or 0 | | ExecuteOn, CommittedCount | | a refusal does not set it
AuditTrail | Returns every outcome so far, refusals included. | a list of [ n, verdict, action, tag, actor name, why ], verdict being committed or refused, n the action's position in the plan; [ ] before any attempt | | RefusedCount, CommittedCount | | a refusal says the actor is not effectful or sandboxed and that expression is free while admission is governed
RefusedCount | Returns how many audit lines are refusals. | a number | | CommittedCount, AuditTrail | | an attempt by a refused actor adds one for each action in the plan
CommittedCount | Returns how many audit lines are commits. | a number | | RefusedCount, AuditTrail | |
Explain | Returns the plan as lines of text: a header, each proposed action with its reason, then the audit if there is one. | a list of text lines | | Show, AuditTrail | |
Show | Prints the explanation to the console, one line per line. | nothing | | Explain | | it prints with the ? statement
