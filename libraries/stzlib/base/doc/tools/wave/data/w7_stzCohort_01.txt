init | Opens a cohort from its folder, which must hold cohort.zknw, the facts that name its course, its overlay and its learners. | nothing; the object is built | pcFolder=the cohort's folder: its last segment is the cohort's name | AddLearner, CourseSlug, ProgramQ | raises an error saying Not a cohort and naming the missing cohort.zknw when the folder lacks that file | a cohort is a folder of learners following one course under one overlay: each learner is a stzLearner folder inside it, and reports/ holds the generated narrations
Name | Returns the cohort's name, which is the last segment of its folder's path. | a text such as espa-2026 | | Folder, CourseSlug
Folder | Returns the cohort's folder path, without a trailing slash. | a text | | Name, LearnerQ
CourseSlug | Returns the id of the course the cohort follows, as its cohort.zknw says. | a text such as elementary-introduction | | OverlayName, ProgramQ | raises an error naming the cohort when the file has no follows fact
OverlayName | Returns the name of the overlay the cohort is under, or an empty text when it names none. | a text such as bank; an empty text for none | | CourseSlug, ProgramQ
LearnerIds | Returns the ids of the learners enrolled in the cohort, in the order they were added. | a list of text; [ ] for a cohort with no learner | | AddLearner, LearnerQ
LearnerQ | Opens the stzLearner whose folder is the cohort's folder plus the id, creating the folders on disk when they are absent. | a stzLearner | pcId=the learner's id | AddLearner, LearnerIds | | it does not enroll: an id never added is opened, and its folders are created, but it stays out of LearnerIds and of the report
AddLearner | Enrolls a learner by id, saving cohort.zknw, and returns that learner; an id already enrolled is not added twice. | the learner's stzLearner | pcId=the learner's id, with no space | LearnerQ, LearnerIds | | the learner's folder is created at once
ProgramQ | Returns the program the cohort is judged against: the core program, with the cohort's overlay laid on when it names one. | a stzProgram | pcProgramFolder=the core program's folder, beside which the overlays/<name> folders sit | ExerciseIds, Report, stzProgram | raises an error naming the cohort and the folder when the overlay it names is not a folder with overlay.zknw | the overlay is found at overlays/<name> beside the program folder
ExerciseIds | Returns the id of every exercise of every chapter of the cohort's course, those an overlay adds included, in course order. | a list of text | poProgram=the stzProgram given by ProgramQ, so that the overlay counts | PassedBy, ProgramQ | | with the bank reference overlay laid on, the elementary course has 24 exercises, one more than the core's 23
PassedBy | Returns the exercises of the cohort's course that a learner has passed, with evidence that still matches. | a list of exercise ids; [ ] when none | pcLearner=the learner's id; poProgram=the stzProgram given by ProgramQ | LevelsEarnedBy, ExerciseIds, stzLearner |
LevelsEarnedBy | Returns the levels a learner has earned in the cohort's course, in the program's order. | a list of level ids such as s0; [ ] when none | pcLearner=the learner's id; poProgram=the stzProgram given by ProgramQ | PassedBy, stzLearner | | no level is earned by one exercise: a level also needs the passes of its chapters and its project
Report | Returns the cohort's progress report as a narration: a table of its learners, then one cell of promises per learner. | a text, markdown with ring cells whose figures are #--> promises | pcProgramFolder=the core program's folder, as for ProgramQ | WriteReport, IsReportCurrent | the cells hold absolute paths of this machine and run on the desktop only, so a report copied elsewhere cannot be run | every figure is a promise beside the cell that computes it, so the report can say whether it is still true
WriteReport | Writes the progress report to a file and returns the path written. | a text, the path | pcProgramFolder=the core program's folder, as for ProgramQ; pcFile=the file to write, or an empty text for reports/progress.en.md under the cohort's folder | Report, IsReportCurrent
IsReportCurrent | TRUE if the report, run as the narration it is, still has every cell running and every promise kept. | TRUE or FALSE | pcFile=a written report, or any narration file | WriteReport, Report | | it runs the report's cells, so it takes seconds and runs on the desktop only; a report written before a learner passed one more exercise answers FALSE (shown), and writing it again makes it TRUE
