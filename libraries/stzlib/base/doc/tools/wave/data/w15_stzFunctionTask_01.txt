# w15 stzFunctionTask
Init | Builds a task that will call a function with a list of parameters, in the pending state. | nothing; the task is built and not run | id=the task's identifier; f=the function to call; params=the arguments, a list of up to 10 values; engine=the reactive engine it belongs to | Execute, stzReactiveFunc | | the error mode is the default, ERROR_LOG
Execute | Calls the function with the parameters and records the outcome on the task. | nothing; read the outcome with Status, Result and Error | | Init | a params value that is not a list records the error Reactive call params must be a list; more than 10 records Reactive call has too many params: N (the limit is 10); a failure inside the function records its real reason | on success the status is completed, the result is kept and Then_ is called; on failure the status is error, the reason is on the task, and the console prints it in the default mode
