init | Builds a clusterer over a list of numeric vectors; the number of clusters defaults to 2. | nothing; the object is built | paVectors=a list of lists of numbers; an item that is not a list is dropped | SetK, Run
SetK | Sets how many clusters to find. | the clusterer itself, so calls chain | n=the number of clusters, 1 or more | Run | | a value below 1 is ignored without a message and the earlier value stays
Run | Computes the clusters by Lloyd's k-means, seeding the centroids with the first k distinct points, and stops when no assignment changes. | the clusterer itself, so calls chain | nMaxIter=the most iterations allowed | Clusters, Centroids, Inertia | raises an error when there are fewer vectors than clusters, when the vectors differ in width, or when there are fewer distinct points than clusters | deterministic: two runs on the same data agree, and a point equidistant from two centroids goes to the lower-numbered one; with a poor seed the result can be a poor local minimum
Clusters | Returns the members of each cluster, as positions in the input list. | a list with one list of numbers per cluster; empty lists before Run | | Centroids, ClusterOf
Centroids | Returns the centre of each cluster. | a list of vectors, one per cluster; empty before Run | | Clusters, ClusterOf
ClusterOf | Returns the number of the nearest cluster for a new vector, by Euclidean distance to the centroids. | a number from 1 to k | paVector=the vector to place | Centroids, Run | raises an error telling to call Run first | a vector shorter or longer than the centroids is compared over their common length
Inertia | Returns the total squared distance of the points to their centroids, the quality number of the run. | a number; 0 before Run | | Iterations, Why
Iterations | Returns how many iterations the last Run took. | a number | | Run, Inertia
Why | Returns a sentence saying how the last Run ended, with the iteration count and the inertia. | a text; empty before Run | | Iterations, Inertia
