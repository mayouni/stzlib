init | Builds a requirement for a faculty, with the defaults: no quality bar, interactive, local, permissive licences. | nothing; the object is built | pcFaculty=the name of the faculty the requirement is for, folded to lower case | StzRequirementQ, Data | | a requirement states what is needed and never which model: the registry resolves it to an implementation
Faculty | Returns the name of the faculty the requirement is for, in lower case. | a text | | init, Data | |
Data | Returns the whole requirement as data, the form the registry resolves. | a list of [ key, value ] pairs: faculty, quality, latency, memory, languages, locality, licence, deterministic, refusebelow | | Resolve, RequireQuality | | defaults: quality 0, latency interactive, memory 0 (no budget), no languages, locality local, licence permissive, deterministic 0, refusebelow 0
RequireQuality | Sets the quality an implementation must have measured on the golden set to be chosen. | nothing; use RequireQualityQ to chain | pQuality=any (0), good (0.7), best (0.9) or a number | RefuseBelowQuality, MeasurementOf, RunGoldens | any other word raises an error, but a number is not checked against the range 0 to 1, so 1.5 is stored and no implementation can reach it | the bar is checked against the measured score, a figure computed by the class from the goldens, not judged by a person; the floor is never filtered by it
RequireLatency | Records the latency class wanted, interactive by default. | nothing; use RequireLatencyQ to chain | pcClass=the latency class as a word, folded to lower case, such as interactive or batch | Data, RequireMemory | it is recorded in Data but the registry does not read it today, so it changes no choice; the design lists latency as a ranking criterion that is not built | the word is kept as given and is not checked against a list
RequireMemory | Sets the memory budget, in MB, that an implementation may hold resident; 0 means no budget. | nothing; use RequireMemoryQ to chain | pnMB=the budget in megabytes | Data, RequireQuality | an implementation declaring more memory than the budget is rejected, and one declaring none always fits | the plan names each implementation rejected for size, with both figures
RequireLanguages | Sets the languages the chosen implementation must cover. | nothing; use RequireLanguagesQ to chain | pacLanguages=a list of language codes such as fr and ar; an implementation passes when it covers each of them or declares * | Data, RequireLicence | a text passed instead of a list is stored as given and read letter by letter, so give a list | an empty list asks for nothing
RequireLocality | Records whether a service may be used, local by default. | nothing; use RequireLocalityQ to chain | pcLocality=local or allow-service, folded to lower case | Data, RequireLicence | it is recorded in Data but the registry does not read it today: a service is never chosen implicitly whatever the value, and is reached only by pinning it by name | the word is kept as given and is not checked against a list
RequireLicence | Sets the licence policy: permissive keeps only permissive licences, any other word lifts the filter. | nothing; use RequireLicenceQ to chain | pcPolicy=permissive or any, folded to lower case | Data, RequireLanguages | any word other than permissive lifts the filter, spelling mistakes included; an implementation that never stated its licence counts as not permissive | permissive means apache-2.0, mit, bsd-3-clause, bsd-2-clause, isc, n/a and cc0-1.0
RequireDeterminism | Asks for implementations that reproduce their answer: a non-deterministic one is rejected. | nothing; use RequireDeterminismQ to chain | | RefuseBelowQuality, Data | | an implementation counts as deterministic unless its specification says :deterministic = 0
RefuseBelowQuality | Makes the resolution a refusal when no model qualifies, instead of letting the floor answer. | nothing; use RefuseBelowQualityQ to chain | | RequireQuality, Resolve | | the refusal carries a below-quality finding naming the faculty
