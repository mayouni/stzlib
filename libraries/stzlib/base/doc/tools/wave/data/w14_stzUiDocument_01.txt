init | Parses a .panel interface document, from its text or from a file path, and judges it. | nothing; the object is built, and its verdict is read with IsClean and Report | pcTextOrPath=the document itself, or the path of a file that holds it; a text shorter than 260 characters, with no line break, that names an existing file is read from the file, and any other text is parsed as is | IsClean, Report, ToPanel | a path that does not exist is parsed as text: the report then says Character ':' has no place in .panel; a document whose CHILDREN lists contain a cycle (a box that lists itself, or two boxes that list each other) ends the Ring process with Stack Overflow in the constructor, before the CHILD_CYCLE finding can be read, and the same for a panel that lists itself | the court checks that there is exactly one PANEL, that every name a CHILDREN list gives is declared, that no name is declared twice, that every field and every role is known, and that every element is placed by some CHILDREN list
Diagnostics | Returns every finding of the court, errors and warnings, in the order found. | a list of hashlists with the keys code, severity (error or warning), message, line, cites and language | | Errors, Report, IsClean | a colour written as a hex value is a LITERAL_COLOUR warning, accepted for now; it does not make the document unclean
Errors | Returns only the findings of severity error. | a list of hashlists, as Diagnostics gives; empty for a clean document | | Diagnostics, IsClean
IsClean | TRUE if the document has no finding of severity error; warnings do not count. | TRUE or FALSE | | Errors, Report | ToRml, ToHtml and ToPanel refuse a document that is not clean
Report | Returns the findings as text, one line each: severity, code, line number and message. | a text; empty when there is no finding | | Diagnostics, IsClean
Declarations | Returns every declaration of the document, in file order. | a list of hashlists with the keys kind (PANEL, BOX, TEXT or STYLE), name, fields, rationale and line | | DeclOf, Names
DeclOf | Returns the declaration with a name. | a hashlist with the keys kind, name, fields, rationale and line; an empty list when the name is not declared | pcName=the declared name; the match is case-sensitive | Declarations, PanelDecl
PanelDecl | Returns the declaration of the one PANEL, the root of the interface. | a hashlist as DeclOf gives; an empty list when there is no panel | | DeclOf, FontFamily
Names | Returns the names of all declarations, in file order. | a list of text | | Declarations, DeclOf
TextsToPaint | Returns, for every TEXT, what a caller needs to paint it: id, content, size, colour and whether it is right to left. | a list of [ id, content, size, colour, isRtl ] rows, with the defaults size 14 and colour #e8e8e8 | | DeclOf, IsRtl | isRtl is TRUE only for a text that declares TEXT_DIRECTION rtl itself: a text that inherits rtl from its box or panel is reported as 0 while IsRtl answers TRUE for it, on two different documents
ToText | Returns the canonical text of the document, which reads back to the same document. | a text: a header line taken from the panel's rationale, then every declaration with one field per line | | init, Declarations | the print of a document read from it is the same text, so printing is a fixpoint; it prints even a document that is not clean
ToRml | Returns the document as RmlUi markup, a style block and a body, with the divergences between engines already absorbed. | a text beginning <rml> | | ToHtml, ToPanel, IsClean | it raises an error, refusing to project a broken contract, when the document is not clean; a width or height you declare is a floor, written with flex-shrink 0
ToHtml | Returns the same document as a complete HTML page, the web projection of what ToRml gives RmlUi. | a text beginning <!doctype html> | | ToRml, ToFixture, IsClean | it raises an error when the document is not clean
ToFixture | Returns the document as an HTML page whose script compares the browser's boxes with the native ones and shows the verdict. | an HTML text | paNativeBoxes=the laid-out boxes of the native panel, as a list of [ name, x, y, w, h ] rows, such as those BoxOf answers | ToHtml, ToPanel, IsStrictWidth | only boxes with a declared size are compared strictly: the page marks each as strict in width, in height and in position
IsStrictWidth | TRUE if the element's width is declared, by itself or by its STYLE, rather than measured from its text. | TRUE or FALSE; FALSE for a name that is not declared | pcName=the declared name | IsStrictHeight, IsStrictlyPlaced
IsStrictHeight | TRUE if the element's height is declared, by itself or by its STYLE, rather than measured from its text. | TRUE or FALSE; FALSE for a name that is not declared | pcName=the declared name | IsStrictWidth, IsStrictlyPlaced
IsStrictlyPlaced | TRUE if the element's position is certain: its size is declared and so is the size of every earlier sibling. | TRUE or FALSE; FALSE for a name that is not declared | pcName=the declared name | IsStrictWidth, IsStrictHeight, ToFixture
DirectionOf | Returns the text direction in force for an element: its own TEXT_DIRECTION, or the nearest ancestor's. | the text rtl or ltr; ltr for a name the panel does not reach | pcName=the declared name | IsRtl, TextsToPaint | the map is built when the document is made, so it answers at once, before anything is rendered
IsRtl | TRUE if the element reads right to left. | TRUE or FALSE | pcName=the declared name | DirectionOf, TextsToPaint
UseFont | Records the font file that ToPanel loads for the document's FONT family. | nothing; use UseFontQ to chain | pcPathOrBytes=the path of a font file, kept as given | FontFamily, ToPanel | it must be called before ToPanel, which refuses a document that has a TEXT without it, even when no FONT is declared and the family is the default app | UseFontQ is the same call and returns the document
FontFamily | Returns the font family the panel declares. | a text; app when the panel declares none or the document has no panel | | UseFont, PanelDecl
ToPanel | Builds the laid-out stzPanel of the document, ready to be asked for the box of any element. | a stzPanel sized by the panel's SIZE, 800 by 600 when it gives none | | UseFont, ToRml, IsClean | it opens no window; it raises an error when the document is not clean, and when it has a TEXT but no UseFont was called, even with no FONT field, because the text would silently vanish; a panel of boxes only needs no font
Roles | Returns the closed vocabulary of roles a ROLE field may name, the accessibility terms. | a list of text, such as group, heading, button and textbox | | DeclOf | a role is a term for the accessibility tree, not a meaning
IntentsOf | Returns the intents an element says it satisfies, from its SATISFIES field. | a list of text, in the order written; empty when it names none or the name is not declared | pcName=the declared name | SatisfiedIntents, TracesToIntent, Orphans | the names are recorded and never resolved: this plane checks their shape and nothing else
SatisfiedIntents | Returns every intent named anywhere in the document, each once, in the order first seen. | a list of text | | IntentsOf, Orphans
Orphans | Returns the elements that trace to no intent, the test that every interface element must serve one. | a list of names; styles are never listed | | IntentsOf, TracesToIntent | the panel itself is an element and is listed when it names no intent; there is no warning for an orphan
TracesToIntent | TRUE if the element names at least one intent in SATISFIES. | TRUE or FALSE; FALSE for a name that is not declared | pcName=the declared name | IntentsOf, Orphans
