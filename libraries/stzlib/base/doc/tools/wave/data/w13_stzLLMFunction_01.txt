init | Builds a typed language-model function with a name, an empty prompt, string output and no budget. | nothing; the object is built | pcName=the function name, which keys its memo cache | SetPrompt, Budget, Call_
Name_ | Returns the name the function was built with. | a text | | SetPrompt
SetPrompt | Sets the prompt template, in which {input} marks where each call puts its input text. | the function itself, so calls chain | pcTemplate=the prompt text with an optional {input} marker | Call_, ReturnsStructure | | Call_ raises an error while no template is set
ReturnsNumber | Declares that the answer must be a number. | the function itself, so calls chain | | ReturnsBoolean, ReturnsOneOf, Call_ | the answer is read as the first word that parses as a number; a reply whose first word is not numeric (such as about 42 or none) raises a Ring error R41 inside the call instead of being refused or retried (w13 defect file) | a comma splits words, so 1,5 reads as 1
ReturnsBoolean | Declares that the answer must be yes or no, kept as 1 or 0. | the function itself, so calls chain | | ReturnsNumber, ReturnsOneOf, Call_ | the reply is searched for the letters yes or true, then no or false, as substrings, so a reply such as unknown reads as 0 (w13 defect file) | a reply with neither is refused
ReturnsString | Declares that the answer is free text, trimmed of surrounding whitespace. | the function itself, so calls chain | | ReturnsNumber, ReturnsOneOf, Call_ | | this is the default type
ReturnsOneOf | Declares that the answer must be one of a fixed set of choices, kept in lower case. | the function itself, so calls chain | pacChoices=the allowed answers as a list of text, compared without regard to case | ReturnsString, ReturnsStructure, Call_ | | a reply is accepted when it equals a choice, or contains exactly one of the choices
ReturnsStructure | Declares that the answer must be a record of the given fields, judged now, so a faulty declaration never reaches a model. | the function itself, so calls chain | paFields=the stzOutputSchema declaration, a list of field hash-lists with field, type and optional must, choices, of and optional | Schema, RefuseUnknownFields | raises an error on the spot for an unknown field type or a mistyped key | ReturnsStructureQ is the same call; one missing required field refuses the whole answer
HasSchema | TRUE if the function returns a declared structure. | TRUE or FALSE | | ReturnsStructure, Schema
Schema | Returns the stzOutputSchema of the declared structure, as a copy to read. | the stzOutputSchema object | | HasSchema, RefuseUnknownFields | raises an error when the function returns anything but a structure | changing the returned copy does not change the function; use RefuseUnknownFields for that
RefuseUnknownFields | Makes the declared structure closed, so that a field the model adds refuses the answer instead of being dropped. | the function itself, so calls chain | | Schema, LastFindings | raises an error when the function returns anything but a structure | an answer already memoized is still served from the cache
LastFindings | Returns the findings of the last validation, the reasons a reply was refused or trimmed. | a list of rule rows [ :rule, :subject, :where, :severity, :message ]; [ ] when nothing was found | | CallsMade, Why | | an open structure reports a dropped extra field here as a warning
Budget | Sets the most model calls the function may spend; it is mandatory before the first call. | the function itself, so calls chain | nMaxCalls=the number of model calls allowed in the life of the object | SetRetries, CallsMade, Call_ | | Call_ raises an error naming the budget when it is exhausted; a memo hit costs nothing
SetRetries | Sets how many further attempts follow a refused reply. | the function itself, so calls chain | n=the number of retries; each one spends a unit of budget | Budget, SetRetrySampling | | the default is 2, so up to 3 attempts
UseResponder | Puts a fake in the model place: a function that receives the prompt and the attempt number and returns raw reply text. | nothing; use UseResponderQ to chain | fResponder=the name of a function with two parameters, prompt text and attempt number | IsUsingResponder, SeedAnswer, Call_ | | for offline tests; it spends budget like a real call and Why says FAKE responder
IsUsingResponder | TRUE if a fake responder stands in for the model. | TRUE or FALSE | | UseResponder
CallsMade | Returns how many model or responder calls were spent. | a number | | Budget, Call_
Why | Returns how the last answer came about: memoized, generated, or from a fake responder. | a text; empty before the first call | | LastFindings, Call_
Call_ | Maps an input text to a value of the declared type, from the memo or from the model, or refuses. | the validated value: a text, a number, 1 or 0, a choice or a list of [ field, value ] rows | pcInput=the text that replaces {input} in the prompt | Of, Budget, SeedAnswer, Why | raises an error without a prompt, without a budget, when no generative model is loaded and nothing is memoized, when the budget is spent, and after the retries when no reply validates | the same input gives the same answer free from the memo; of is an alias for this call
SeedAnswer | Stores a known answer for an input in the memo, so a later call returns it without a model. | the function itself, so calls chain | pcInput=the input text the answer belongs to; pValue=the answer, judged against the declared structure first | Call_, UseResponder | raises an error when the answer does not satisfy the declared structure | the key covers name, type and the full prompt, so declare the type and prompt before seeding
ConstrainDecoding | Switches grammar-constrained decoding on or off for a structured function. | nothing; use ConstrainDecodingQ to chain | pbYesNo=1 to constrain decoding with the schema grammar, 0 to leave it unconstrained | IsConstrainingDecoding, WhyNotConstrained | | it is on by default; a grammar fixes the shape, never the value or the truth
IsConstrainingDecoding | TRUE if the next live call will constrain the sampler with the schema grammar. | TRUE or FALSE | | WhyNotConstrained, ConstrainDecoding | | FALSE for a scalar type, for ConstrainDecoding(0), for a nested structure and for a build without the sampler rung
WhyNotConstrained | Returns the reason the next live call will not be grammar-constrained. | a text; empty when it will be constrained | | IsConstrainingDecoding
WasLastAnswerConstrained | TRUE if the last live answer was drawn under a grammar. | TRUE or FALSE | | IsConstrainingDecoding | | 0 for a memo hit and for a fake responder, since neither decoded anything
SetRetrySampling | Sets the temperature and seed that retries sample with. | nothing; use SetRetrySamplingQ to chain | pnTemperature=the sampling temperature of attempts after the first; pnSeed=the base seed, to which the attempt number is added | RetryTemperature, SetRetries | | the first attempt is always greedy; defaults are 0.7 and 1000
SetMaxTokens | Sets the most tokens a model reply may hold. | nothing; use SetMaxTokensQ to chain | pnMax=the token budget of one reply | SetRetrySampling | | the default is 128
RetryTemperature | Returns the temperature that retries sample with. | a number; 0.7 by default | | SetRetrySampling
AddGolden | Adds an input with the answer it must give, for RunGoldens to check. | nothing; use AddGoldenQ to chain | pcInput=the input text; pExpected=the expected answer, a scalar or a structure | RunGoldens, Call_
RunGoldens | Calls the function on every golden input and compares each answer with the expected one. | a hash-list [ :total, :passed, :failed ]; each failure is a hash-list with input, expected, got and findings | | AddGolden, Call_ | | it spends budget like any call; a structure that differs lists the fields that moved
