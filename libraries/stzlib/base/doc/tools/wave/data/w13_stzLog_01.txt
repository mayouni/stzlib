init | Builds an empty log for one category, with the threshold info, no echo and no cap on the entries kept. | nothing; the object is built | pcName=the category stamped on every entry, such as deploy | SetLevel, SetCap, SetEcho
Name | Returns the category the log was built with, which every entry carries. | a text such as deploy | | Level
SetLevel | Sets the lowest level that is recorded, so that anything below it is dropped from now on. | nothing; use SetLevelQ to chain | pcLevel=one of trace, debug, info, warn, error or fatal, in any case | Level, Record, SetLevelQ | raises an error naming the unknown level for any other text, and keeps the old level | entries already recorded stay
Level | Returns the lowest level that is recorded, in lowercase. | a text such as info; info on a new log | | SetLevel
SetEcho | Turns on or off the printing of each entry to the console as it is recorded. | nothing; use SetEchoQ to chain | pbOn=1 to print every new entry, 0 to keep quiet | Record, Show | | the printed line is the same as one line of AsText
SetCap | Sets how many entries the log keeps, evicting the oldest first; 0 means no limit. | nothing; use SetCapQ to chain | pnCap=the most entries to keep, or 0 for no limit | NumberOfEntries, Clear | | the cap is applied when the next entry is recorded, so lowering it does not trim at once
Record | Records one entry with a level, a message and structured fields, unless the level is below the threshold. | the log itself, so writes chain | pcLevel=the level of the entry, such as warn; pcMsg=the message text; paFields=a list of key and value pairs such as [ [ :part, "api" ] ], or [ ] for none | Info, Where, Entries, SetLevel | the third argument is required (a call with two raises a missing-parameter error); a level that is not one of the six is dropped without a message; a third argument that is not a list is ignored | each entry is a hash-list with seq, ts, level, category, message and fields; inside a trace scope a traceId field is added
Trace | Records a message at the lowest level, trace, with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Debug
Debug | Records a message at level debug with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Info
Info | Records a message at level info with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Warn
Warn | Records a message at level warn with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Error
Error | Records a message at level error with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Fatal
Fatal | Records a message at the highest level, fatal, with no fields. | the log itself, so writes chain | pcMsg=the message text | Record, Error
Entries | Returns every entry kept, oldest first. | a list of hash-lists with seq, ts, level, category, message and fields | | NumberOfEntries, LastEntry, EntriesOfLevel | | ts is the epoch time in milliseconds, so it changes on every run
NumberOfEntries | Returns how many entries the log holds now. | a number | | Entries, SetCap
LastEntry | Returns the newest entry, or an empty list when the log holds none. | a hash-list with seq, ts, level, category, message and fields; [ ] for an empty log | | Entries
EntriesOfLevel | Returns the entries recorded at exactly the given level. | a list of entries; [ ] when none or when the level is unknown | pcLevel=the level to keep, in any case | CountOfLevel, Where | | it is an exact match, so asking for warn does not return error
CountOfLevel | Returns how many entries were recorded at exactly the given level. | a number; 0 for an unknown level | pcLevel=the level to count, in any case | EntriesOfLevel
Where | Returns the entries that carry a field with the given key and value. | a list of entries; [ ] when none match | pcKey=the field key to look for, such as part; pValue=the value that field must have | OfTrace, Record | | key and value are compared as text, so 2 and "2" match
OfTrace | Returns the entries stamped with the given trace id, which links a request's trace to its log lines. | a list of entries; [ ] when none carries that id | pcTraceId=the trace id text | Where, Record
Since | Returns the entries recorded at or after a time given in epoch milliseconds. | a list of entries, oldest first | pnMs=the earliest time to keep, in epoch milliseconds | Entries
Clear | Removes every entry and restarts the numbering at 1. | the log itself, so calls chain | | Entries, SetCap | | the level, the cap and the echo flag are kept
AsText | Renders the entries as lines of timestamp, level, category and message, followed by the fields in braces. | a text with one line per entry, no final line break; empty text for an empty log | | AsJson, Show, WriteToFile
Show | Prints the entries as text on the console, one line each. | nothing | | AsText, SetEcho
AsJson | Renders the entries as a JSON array, with the fields placed beside ts, level, category and message. | a text holding the array | | OtelJson, WriteJsonToFile | | field values come out as JSON text, so 2 is written as "2"
WriteToFile | Writes the text rendering of the entries to a file, replacing its contents. | the log itself, so calls chain | pcPath=the file to write | AsText, WriteJsonToFile
WriteJsonToFile | Writes the JSON rendering of the entries to a file, replacing its contents. | the log itself, so calls chain | pcPath=the file to write | AsJson, WriteToFile
OtelJson | Renders the entries as the OpenTelemetry logs envelope that a collector accepts, with the category as the service name. | a text holding the JSON; the trace id of an entry is promoted to the record's own traceId | | AsJson | | field values are written as strings; severity numbers are 9 for info, 13 for warn and 17 for error
