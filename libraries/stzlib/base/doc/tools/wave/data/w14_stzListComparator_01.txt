# w14 stzListComparator -- Name | brief | returns | params | see | warning | note
init | Builds a comparator over a list, given as a list or as a stzList object. | nothing; the object is built | pListOrObj=the list to compare from, or a stzList whose content is copied, any other value raises an error | Content, IsEqualTo | | the comparator never changes the list or the stzList you passed in
Content | Returns the list the comparator holds. | a list | | NumberOfItems, IsEqualTo
NumberOfItems | Returns how many items the list holds. | a number | | Content, IsSameSizeAs
IsEmpty | TRUE if the list holds no item. | TRUE or FALSE, as 1 or 0 | | NumberOfItems, Content
IsEqualTo | TRUE if another list has the same size and the same items, in any order. | TRUE or FALSE, as 1 or 0 | paOtherList=the list to compare with | IsStrictlyEqualTo, IsPermutationOf, IsNotEqualTo | it ignores order and repeats: [ 1, 2, 3, 4 ] equals [ 4, 3, 2, 1 ], and [ 1, 1, 2 ] equals [ 1, 2, 2 ], since only the size and the set of items are compared; a value that is not a list answers FALSE | case counts: IsEqualToCS(paOtherList, 0) ignores it; use IsStrictlyEqualTo when the order matters
CommonItems | Returns the items found in both lists, without repeats. | a list | paOtherList=the list to match against | Union, Difference, SymmetricDifference | | case counts: CommonItemsCS(paOtherList, 0) ignores it, and then the items keep the spelling of the held list
Union | Returns the items of the list followed by those of another list not already present, without repeats. | a list | paOtherList=the list whose new items are added | CommonItems, SymmetricDifference | | case counts: UnionCS(paOtherList, 0) ignores it
Difference | Returns the items of the list that are not in another list. | a list | paOtherList=the list whose items are taken away | CommonItems, SymmetricDifference | | case counts: DifferenceCS(paOtherList, 0) ignores it; the items that stay keep their repeats; ItemsNotIn is the same call
IsReverseOf | TRUE if the list is another list read backwards. | TRUE or FALSE, as 1 or 0 | paOtherList=the list to compare with, read in reverse | IsStrictlyEqualTo, IsEqualTo | raises error R3 Calling Function without definition: listreversed today, with the case flag or without (tried on [ 1, 2, 3, 4 ] against [ 4, 3, 2, 1 ] and against itself, and on texts) | the function it calls to reverse the other list does not exist
IsNotEqualTo | TRUE if another list differs in size or in its set of items. | TRUE or FALSE, as 1 or 0 | paOtherList=the list to compare with | IsEqualTo, IsStrictlyEqualTo | | it is the opposite of IsEqualTo, so it also ignores order and repeats
IsStrictlyEqualTo | TRUE if another list holds the same items at the same positions. | TRUE or FALSE, as 1 or 0 | paOtherList=the list to compare with | IsEqualTo, IsReverseOf | | case counts: IsStrictlyEqualToCS(paOtherList, 0) ignores it; IsIdenticalTo and IsEqualToXT are the same call
SymmetricDifference | Returns the items found in only one of the two lists. | a list | paOtherList=the list to compare with | Difference, Union, CommonItems | | the held list's own items come first, then the other list's; items keep their repeats, so [ 1, 1, 2 ] against [ 2, 3, 3 ] gives [ 1, 1, 3, 3 ]; case counts unless SymmetricDifferenceCS(paOtherList, 0) is used
IsSubsetOf | TRUE if every item of the list is also in another list. | TRUE or FALSE, as 1 or 0 | paOtherList=the list that may contain them all | IsSupersetOf, Contains | | the order and the repeats do not matter; case counts unless IsSubsetOfCS(paOtherList, 0) is used
IsSupersetOf | TRUE if every item of another list is also in this list. | TRUE or FALSE, as 1 or 0 | paOtherList=the list whose items must all be present | IsSubsetOf, ContainsAllOfThese | | the order and the repeats do not matter; case counts unless IsSupersetOfCS(paOtherList, 0) is used
Contains | TRUE if the list holds an item. | TRUE or FALSE, as 1 or 0 | pItem=the item to look for | ContainsAllOfThese, ContainsOneOfThese | | case counts: ContainsCS(pItem, 0) finds b in a B c
ContainsAllOfThese | TRUE if the list holds every item of a given list. | TRUE or FALSE, as 1 or 0 | paItems=the items that must all be present | ContainsOneOfThese, IsSupersetOf | | case counts unless ContainsAllOfTheseCS(paItems, 0) is used; an empty list of items answers TRUE
ContainsOneOfThese | TRUE if the list holds at least one item of a given list. | TRUE or FALSE, as 1 or 0 | paItems=the items to look for | ContainsAllOfThese, Contains | | case counts unless ContainsOneOfTheseCS(paItems, 0) is used; an empty list of items answers FALSE
IsSameSizeAs | TRUE if another list holds as many items as this one. | TRUE or FALSE, as 1 or 0 | paOtherList=the list whose size is compared | IsEqualTo, NumberOfItems | | HasSameLengthAs is the same call
IsSortedLike | Returns TRUE for any two lists of the same size, whatever their order, though it is meant to compare their orderings. | TRUE or FALSE, as 1 or 0 | paOtherList=the list whose ordering is compared | IsStrictlyEqualTo, IsSameSizeAs | it answers TRUE for any two lists of the same size, whatever their order: [ 1, 2, 3, 4 ] is "sorted like" [ 10, 30, 20, 40 ] and [ 40, 30, 20, 10 ], and [ b, a, c ] like [ x, y, z ]; only a different size answers FALSE | the test inside it, a find that is compared with greater-or-equal-zero, is true whatever the items are
StartsWith | TRUE if the list begins with the given items, in that order. | TRUE or FALSE, as 1 or 0 | paItems=the items the list must begin with | EndsWith, IsStrictlyEqualTo | | case counts unless StartsWithCS(paItems, 0) is used; an empty list of items answers TRUE
EndsWith | TRUE if the list ends with the given items, in that order. | TRUE or FALSE, as 1 or 0 | paItems=the items the list must end with | StartsWith, IsStrictlyEqualTo | | case counts unless EndsWithCS(paItems, 0) is used
IsPermutationOf | TRUE if another list has the same size and the same set of items, in any order. | TRUE or FALSE, as 1 or 0 | paOtherList=the list to compare with | IsEqualTo, IsStrictlyEqualTo | it ignores repeats, so [ 1, 1, 2 ] is called a permutation of [ 1, 2, 2 ], which is not one; it is the same test as IsEqualTo | case counts unless IsPermutationOfCS(paOtherList, 0) is used
