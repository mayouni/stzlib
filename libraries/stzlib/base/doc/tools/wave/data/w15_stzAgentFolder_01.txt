init | Builds a folder reader on a path; nothing is read until ReadAgents is called. | nothing; the object is built | pcPath=the folder that holds the agent files (.pia declarations and .ring agents) | ReadAgents, Path
Path | Returns the folder path given at construction, unchanged. | a text | | init, ReadAgents
Why | Returns a one-line account of the last read or mount: how many agents were loaded or mounted, or why nothing was. | a text; empty before the first ReadAgents | | ReadAgents, MountOn, Describe
ReadAgents | Reads and gates every .pia and .ring file of the folder, and returns how many were accepted; the rest go to Refusals. | a number, the agents accepted; 0 when the folder does not exist, with the cause in Why | | Refusals, Rescan, MountOn | a .ring file is not executed: the program must already have loaded it, or the file is refused with rule ring-agent-entry; a second file claiming a loaded name is refused as pia-duplicate-name | every call starts from empty, so it is also the way to reload
NumberOfAgents | Returns how many agents the last read accepted. | a number | | ReadAgents, Names
NumberOfRefusedFiles | Returns how many files the last read refused. | a number | | RefusedFiles, Refusals
Names | Returns the names of the accepted agents, in lower case, in file-name order. | a list of text | | Has, AgentQ
Has | TRUE if an agent of that name was loaded; the match ignores case and surrounding blanks. | TRUE or FALSE | pcName=the agent's name | Names, AgentQ
AgentQ | Returns the live agent object loaded under that name, so it can be configured before it is mounted. | an agent object | pcName=the agent's name, matched without regard to case | MountOn, Has | raises an error naming the folder for a name that was not loaded | after MountOn the host ticks its own copy, so configure through this face before mounting
ScheduleOf | Returns when the agent runs, as declared in its file. | a list [ :mode, :timer, :channel ]; mode, timer and channel are empty or 0 for an unknown name | pcName=the agent's name | NotationOf, MountOn | | a Ring agent without a Schedule method gets mode timer, 50
NotationOf | Returns which notation the agent was written in. | the text pia or ring; an empty text for an unknown name | pcName=the agent's name | ScheduleOf, Names
Refusals | Returns every reason a file was refused, in the library's finding shape. | a list of [ :rule, :subject, :where, :severity, :message ] rows; where names the file | | CiteRefusals, RefusedFiles | | a rescan adds a ring-agent-restart row for a changed .ring file
RefusedFiles | Returns the refused files with how many findings each one carries. | a list of [ file, number ] pairs | | Refusals, NumberOfRefusedFiles
CiteRefusals | Returns the refusals as printable lines, one per finding, as [rule @ where] message. | a text; empty when the folder loaded whole | | Refusals, Describe | | printing it after every read keeps a partly loaded folder from passing for a healthy one
Describe | Returns a multi-line summary: the folder, the counts, each agent with its notation and kind, then the refusals. | a text | | CiteRefusals, Why
Changes | Returns what differs on disk since the last read, without loading it; files are compared by the SHA-256 of their bytes, not by time. | a list [ :added, :changed, :removed ], each a list of file names | | HasChanged, Rescan | | a file that was refused and has not changed is not reported as added again; a missing folder reports every loaded file as removed
HasChanged | TRUE if any file was added, changed or removed since the last read. | TRUE or FALSE | | Changes, Rescan
Rescan | Reads the folder again whole and returns what moved since the previous read, so a host can mount what arrived and retire what left. | a list [ :added, :changed, :removed ], as Changes answered before the read | | Changes, MountOn | a changed .ring file is not re-evaluated, because Ring cannot unload a function: the old code keeps running and a ring-agent-restart refusal names the file | a changed .pia file is re-read
MountOn | Supervises every loaded agent on a host, each on the schedule its own file declared, and returns how many were mounted. | a number | poHost=an agent host; it receives Declare and then Supervise or SuperviseOnEvent for each agent | ReadAgents, AgentQ | | the agents' own coverage statement and reversibility class are declared on the host first
