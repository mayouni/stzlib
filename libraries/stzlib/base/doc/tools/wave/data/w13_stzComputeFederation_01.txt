init | Builds an empty federation of compute hosts with its own governance, reactor and request signer. | nothing; the object is built | pcName=the federation name, also the name of its governance and signer | Join, FederatedCall
Name_ | Returns the name the federation was built with. | a text | | Join
Why | Returns the reason of the last federated call: why it was allowed, or why it was refused. | a text; empty before the first call | | FederatedCall, CallLastStatus
GovernanceQ | Returns the stzGovernance object that holds the permissions, risk tiers and authorities. | the stzGovernance object | | GovDeclareRisk, GovGrant
ReactorQ | Returns the stzReactor object that carries the calls on the wire. | the stzReactor object | | FederatedCall, Shutdown
Join | Registers a member host with its endpoint and the facets it offers; the host starts active. | the federation itself, so calls chain | pcName=the host name; pcEndpoint=the host:port address of the host; paFacets=a list of facet names, or one name, kept in lower case | MembersOffering, Retire, EndpointOf | raises an error when a host of that name already joined | the endpoint is stored, not contacted
NumberOfMembers | Returns how many hosts have joined, retired ones included. | a number | | MemberNames, IsActive
MemberNames | Returns the names of the joined hosts, in order of joining. | a list of text | | NumberOfMembers, EndpointOf
IsActive | TRUE if the host joined and is not retired. | TRUE or FALSE; FALSE for an unknown host | pcName=the host name | Retire, Revive
Retire | Takes a host out of discovery without forgetting it. | the federation itself, so calls chain | pcName=the host name | Revive, MembersOffering | raises an error for a host that never joined
Revive | Puts a retired host back into discovery. | the federation itself, so calls chain | pcName=the host name | Retire, MembersOffering | raises an error for a host that never joined
MembersOffering | Returns the active hosts that offer a facet, in order of joining. | a list of host names; [ ] when none | pcFacet=the facet name, compared without regard to case | Join, FederatedCall
EndpointOf | Returns the host:port address a host registered. | a text; empty for an unknown host | pcName=the host name | Join, MemberNames
GovDeclareRisk | Declares the risk tier of an action in the governance lattice. | the federation itself, so calls chain | pcAction=the action name, use- followed by the facet; nTier=the risk tier number | GovGrant, GovSetAuthority, FederatedCall | | a federated call is governed as the action use-facet
GovGrant | Grants a caller the permission to perform an action. | the federation itself, so calls chain | pcCaller=the caller name; pcAction=the action name, use- followed by the facet | GovDeclareRisk, GovSetAuthority, Bond | | a call also needs a bond: the permission alone does not let it through
GovSetAuthority | Sets the kind of authority a caller holds, which is weighed against the risk tier. | the federation itself, so calls chain | pcCaller=the caller name; pcType=the authority, such as :Delegated | GovDeclareRisk, GovGrant
Bond | Declares that a caller may request a facet across the grid. | the federation itself, so calls chain | pcCaller=the caller name; pcFacet=the facet name, kept in lower case | AreBonded, GovGrant, FederatedCall | | the bond is still checked against governance at call time
AreBonded | TRUE if a bond lets the caller request the facet. | TRUE or FALSE | pcCaller=the caller name; pcFacet=the facet name, compared without regard to case | Bond, FederatedCall
FederatedCall | Finds a host that offers a facet, lets the bond and governance clear the caller, then sends the request to the first such host. | the response body, a text; an empty text on refusal, with CallLastStatus below 0 and Why saying why | pcCaller=the caller name; pcFacet=the facet to request; pcPath=the path on the host, which must start with a slash and hold no line break; pcBody=the request body, or an empty text | Bond, GovGrant, CallLastStatus, Why | refuses an unsafe path, a facet no active host offers, a caller with no bond and a caller governance refuses, and notes each refusal to the security ledger as federation.call.refused; only the refusals were run, since a cleared call contacts the host | with a registered key the request is signed, and with SetMutualTls it goes over a mutually authenticated TLS channel instead of plain HTTP
CallLastStatus | Returns the status of the last federated call. | a number: the HTTP status of a transported call, -1 for a refusal, 0 before any call | | FederatedCall, Why
LastCallMs | Returns how long the last federated call took, gates and transport included, in milliseconds. | a number | | FederatedCall | | a refusal costs only what the gates cost
RegisterKey | Shares a secret with a caller so that its federated calls are signed. | the federation itself, so calls chain | pcCaller=the caller name; pcSecret=the shared signing secret | LastSignature, VerifyInbound, SignerQ | | signing is opt in for each caller; with no key a call goes unsigned
SignerQ | Returns the stzRequestSigner object that signs and verifies requests. | the stzRequestSigner object | | RegisterKey, VerifyInbound
SetMutualTls | Makes every federated call run over a mutually authenticated, encrypted TLS channel. | the federation itself, so calls chain | pcCert=the path of this node certificate, presented to the peer; pcKey=the path of its private key; pcCa=the path of the trust anchor that validates the peer certificate | IsMtls, FederatedCall | | the paths are only stored here; they are read when a call is made
IsMtls | TRUE if calls are set to run over mutual TLS. | TRUE or FALSE | | SetMutualTls
LastSignature | Returns the signature envelope of the last signed call. | a hash-list [ :kid, :ts, :nonce, :sig ]; [ ] when the last call was unsigned or none was made | | RegisterKey, VerifyInboundEnvelope
VerifyInbound | TRUE if an inbound request is authentic, untampered, fresh and not a replay, as the receiving side checks it. | TRUE or FALSE | pcCaller=the caller the request claims to be from; pcMethod=the HTTP method, such as GET; pcPath=the request path; pcBody=the request body; pnTs=the timestamp from the envelope; pcNonce=the nonce from the envelope; pcSig=the signature from the envelope; pnMaxSkewMs=the clock skew and replay window in milliseconds | VerifyInboundEnvelope, RegisterKey | | a changed path or body gives FALSE
VerifyInboundEnvelope | TRUE if an inbound request is authentic, untampered, fresh and not a replay, judged from its whole envelope. | TRUE or FALSE | pcMethod=the HTTP method; pcPath=the request path; pcBody=the request body; paEnvelope=the envelope as LastSignature gives it; pnMaxSkewMs=the clock skew and replay window in milliseconds | VerifyInbound, LastSignature | | verifying the same envelope a second time gives FALSE, since its nonce was used
Shutdown | Destroys the reactor that carries the calls. | the federation itself, so calls chain | | ReactorQ | | calling it again changes nothing
