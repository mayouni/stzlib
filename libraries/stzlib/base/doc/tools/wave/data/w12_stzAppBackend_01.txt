# Wave 12 -- stzAppBackend. Name | brief | returns | params | see | warning | note
init | Builds a backend for a solution model, not yet started, with an empty crossing ledger. | nothing; the object is built | pcName=the backend's name; poTopology=the stzAppTopology whose datasets and part roles it will serve | Start, ConnectTo | | the topology is copied on purpose: it is a snapshot of the model, and only the live state is shared
Start | Turns the model's datasets into live sqlite tables and serves them over a real server bound to the loopback, in this process. | the backend itself, so calls chain | pnPortNum=the port to listen on; 0 picks a free one, read back with Port | StartOn, Stop, Create, Rows | raises an error when the backend is already live | the tables start from the model's rows and then live on independently of the model
StartOn | Starts the backend bound to a chosen interface; the loopback is allowed freely, any other address only once a signing key is set. | the backend itself, so calls chain | pcHostAddr=the interface to bind, "127.0.0.1" for this machine only, or the empty text for the loopback; pnPortNum=the port, 0 for a free one | Start, SetSigningKey, BindHost | a bind outside the loopback without SetSigningKey raises an error and binds nothing; raises an error when already live | with a key set, every request must carry a valid signature
BindHost | Returns the interface the backend is bound to. | a text such as 127.0.0.1; the empty text before it is started | | StartOn
Serve | Runs the server loop for a number of milliseconds, answering whoever connects; what a hosting process does after Start. | the backend itself, so calls chain | pnMs=how long to serve, in milliseconds | Start, SpawnRemote | raises an error when the backend is not live and when it is a connected client | a local backend does not need it: it answers one request per crossing by itself
ConnectTo | Turns the backend into a client of a backend already running at an address, creating no database and no server. | the backend itself, so calls chain | pcHostAddr=the host of the far backend; pnPortNum=its port | ReachAt, IsReachable, SetSigningKey, Stop | raises an error when the backend is already live | nothing is sent until the first crossing; the remote client can only read and create, not update or delete
SetSigningKey | Sets the shared secret that signs every crossing, so a host requires signatures and a client produces them. | nothing; use SetSigningKeyQ to chain | pcKeyId=the identifier of the key; pcSecret=the shared secret, delivered out of band and never in the model file | IsSigned, SetMaxSkew, StartOn | raises an error when either value is empty | set it on both sides, before Start or ConnectTo
IsSigned | TRUE if a signing key is set. | TRUE or FALSE | | SetSigningKey
SetMaxSkew | Sets how far, in milliseconds, a signed request's time may differ from the host's clock; 30000 by default. | nothing; use SetMaxSkewQ to chain | pnMs=the freshness window in milliseconds | SetSigningKey | a value below 1 raises an error | it matters only with a signing key
LastStatus | Returns the HTTP status of the last crossing. | a number such as 200, 201, 404 or 401; 0 when none completed | | LastMs, Traffic | | 401 means the far side refused the signature
IsRemote | TRUE if this backend is a client of a backend elsewhere. | TRUE or FALSE | | ConnectTo
Endpoint | Returns the address the backend is reached at, host and port joined by a colon. | a text such as 127.0.0.1:65253 | | Port, ReachAt
IsReachable | TRUE if the backend answers: a live local one always does, a remote one is probed on /health with a signed request. | TRUE or FALSE; FALSE when the backend is not live | pnTimeoutMs=how long to wait for the far answer, in milliseconds | ConnectTo, WaitReady | the remote probe sends a request over the network: not run here
SpawnRemote | Starts this model as a backend in a child ring process on the loopback and returns its endpoint. | a text, the endpoint such as 127.0.0.1:38050 | pnPortNum=the port the child listens on; pnTtlMs=how long the child lives before it ends itself, in milliseconds | SpawnRemoteOn, WaitReady, Stop | not run here: it starts a second process and writes a model file and a host script beside the library sources; raises an error when the backend is already live | read the code: the secret travels in an environment variable, never in the command line
SpawnRemoteOn | Starts the model as a child backend bound to a chosen interface, so other machines can reach it. | a text, the endpoint | pcBindHost=the interface to bind, "0.0.0.0" for every interface; pnPortNum=the port; pnTtlMs=the child's lifetime in milliseconds | SpawnRemote, SetSigningKey | not run here, as for SpawnRemote; a bind outside the loopback without SetSigningKey raises an error before anything starts | it is the only call here that can expose a port to the network
RemoteLaunchCommands | Returns the shell commands that would start this backend on another machine, without running any. | a list of four command texts: make the folder, copy the model, copy the host script, start it | pcSshTarget=the user and host to reach by ssh; pcRemoteDir=the folder on that machine; pnPortNum=the port; pnTtlMs=the lifetime in milliseconds | ExplainRemoteLaunch, SetSigningKey | raises an error without a signing key and when the target or folder is empty; not run to completion here, since it writes a model file and a host script beside the library sources | the secret is named by an environment variable and is never in a command
ExplainRemoteLaunch | Returns a readable account of what a remote launch would do and need, with its commands. | a list of text lines | pcSshTarget=the user and host to reach by ssh; pcRemoteDir=the folder on that machine; pnPortNum=the port; pnTtlMs=the lifetime in milliseconds | RemoteLaunchCommands | the same errors and the same file writes as RemoteLaunchCommands, so not run here | the last line says nothing has run yet
ReachAt | Points a client at another address for the same backend, such as a routable address of a host bound to every interface. | nothing; use ReachAtQ to chain | pcHostAddr=the new host address | ConnectTo, Endpoint | | the port is kept
WaitReady | Polls a spawned host with signed health requests until it answers or the time is up. | 1 (TRUE) once it answers, 0 on timeout | pnTimeoutMs=how long to wait, in milliseconds | SpawnRemote, IsReachable | not run here: it sends requests to the host's port
Stop | Stops the server and closes the live state, or releases a client or a spawned-host manager. | the backend itself, so calls chain | | Start, ConnectTo | | calling it on a backend that is not live does nothing; a spawned child ends by itself at its lifetime
IsLive | TRUE if the backend is started or connected. | TRUE or FALSE | | Start, Stop
Port | Returns the port the backend listens on, or the far port for a client. | a number; 0 before Start | | Endpoint, Start
Name | Returns the backend's name. | a text | | init
Create | Writes one record into a dataset by a real HTTP POST, on behalf of a part. | TRUE when the backend answered 201, else FALSE, for example 0 for an unknown dataset | pcPart=the part that writes, recorded in lower case; pcDataset=the dataset to insert into; paFields=the record as [ [ column, value ], ... ] | Rows, RowCount, SetActor | raises an error when the backend is not live, and when it is governed by an actor that is not effectful, in which case a 403 is noted and nothing crosses | a dataset that does not exist gives a 404 in LastStatus and no error
Rows | Reads every record of a dataset by a real HTTP GET, on behalf of a part. | a list of rows, each a list of cell texts; [ ] for an unknown dataset | pcPart=the part that reads, recorded in lower case; pcDataset=the dataset to read | RowCount, Create, Dashboard | raises an error when the backend is not live; a cell holding a comma is split into two cells, because the reply is cut on commas | cells come back as text, numbers included; the order is the insertion order
RowCount | Returns how many records a dataset holds, by a real HTTP GET. | a number; 0 for an unknown dataset | pcPart=the part that reads; pcDataset=the dataset to count | Rows | raises an error when the backend is not live | it is noted in the ledger as <dataset>/count
Dashboard | Computes a part's dashboard over the live rows of its dataset. | a list [ rows, total, top dish, its revenue ]; each row is [ dish, quantity, revenue ] | pcPart=the part whose dataset is aggregated; its role names the dataset, orders when it has none | Rows, Create | raises an error when the backend is not live and, for a dataset that is not two columns of a name and a quantity, error R41 invalid numeric string | the total changes as other parts write, because it is computed on every call
SetActor | Binds the actor on whose behalf parts act, so a write needs an effectful one. | nothing; use SetActorQ to chain | poActor=the acting actor, such as HumanActor("manager") or LLMActor("planner") | IsGoverned, Create | reads stay open to every actor; an actor that is not effectful makes Create raise an error | until it is called the backend is ungoverned
IsGoverned | TRUE if an actor was bound, so writes are governed. | TRUE or FALSE | | SetActor
Traffic | Returns every crossing in order: part, verb, dataset, status and duration in milliseconds. | a list of [ part, verb, dataset, status, ms ] rows | | TrafficOf, RefusedCrossings, Explain | | the ledger is kept in the object, not in the shared state
LastMs | Returns how long the last crossing took, in milliseconds, on a monotonic clock. | a number | | LastRoundtripMs, MeanCrossingMs
LastRoundtripMs | Returns how long the last crossing took, in milliseconds, on a monotonic clock. | a number | | LastMs
MeanCrossingMs | Returns the mean duration of the crossings that really crossed. | a number; 0 when none | | LastMs, Traffic | | refused writes, which cost 0 ms, are left out
TrafficCount | Returns how many crossings the ledger holds. | a number | | Traffic
TrafficOf | Returns the crossings one part made. | a list of [ part, verb, dataset, status, ms ] rows | pcPart=the part's name, matched without regard to case | Traffic
RefusedCrossings | Returns the writes the governance refused. | a list of crossings with status 403 | | Traffic, SetActor
Explain | Returns a readable account of the backend: its state, port, number of crossings and each crossing. | a list of text lines | | Show, Traffic
Show | Prints the lines of Explain. | the backend itself, so calls chain | | Explain
SaveModelTo | Writes the model, never the live state, to a text file that a host process can rebuild it from. | the backend itself, so calls chain | pcPath=the file to write | StzLoadAppTopologyFrom | | each cell keeps its type, number or text, and the separators are percent-escaped
