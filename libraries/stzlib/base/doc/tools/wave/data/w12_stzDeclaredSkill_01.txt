# Wave 12 -- stzDeclaredSkill. Name | brief | returns | params | see | warning | note
SetClauses | Gives the skill its three clauses as data: when it may run, what it does and how it is verified. | the skill itself, so calls chain | paWhen=the precondition clause, a list [ :verb, :args ] such as [ :verb = "fact", :args = [ "stock", "level", "low" ] ]; paDoes=the action clause, for example learn or forget; paVerify=the check clause, or [ ] for none | WhenClause, Apply, PreconditionHolds | the clauses are not checked here: the declaration court already did
WhenClause | Returns the precondition clause. | a list [ :verb, :args ]; [ ] when none was given | | SetClauses, PreconditionHolds
DoesClause | Returns the action clause. | a list [ :verb, :args ] | | SetClauses, Apply
VerifyClause | Returns the verification clause. | a list [ :verb, :args ]; [ ] when none was given | | SetClauses, Apply
PreconditionHolds | TRUE if the skill may run on a memory: no precondition at all, or the precondition clause is true there. | TRUE or FALSE | poMemory=the agent memory the clause is judged against | WhenClause, Apply | the verbs always, fact, no-fact and recall are judged; a ring clause calls the named function
Apply | Runs the skill on a memory when its precondition holds, then checks the verification. | a list [ :ran, :verified, :why ]: ran is 1 or 0, verified is 1 or 0 and why says what happened | poMemory=the agent memory to read and to write; learn and forget write into it | PreconditionHolds, VerifyClause | when the precondition fails nothing is written and ran is 0; a skill with no verification clause counts as verified | the three outcomes read "ran and VERIFIED", "ran but FAILED verification" and "skipped: precondition not met"
