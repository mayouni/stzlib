init | Builds a part of a solution with a name, the kind app, no language, no source and no deployment target. | nothing; the object is built | pcName=the part's name, kept in lower case | To, SetKind, stzPlatformProfile | | usually made by WithPart of the profile that owns it
Name | Returns the part's name, in lower case. | a text | | SetName

Kind | Returns the kind of part: app, server, superapp or another word. | a text, app by default | | SetKind

Language | Returns the language of the part's code. | a text; the empty text when none is set | | SetLanguage, HasLanguage
HasLanguage | TRUE if a language is set. | TRUE or FALSE | | SetLanguage
AddSource | Adds one source file to the part. | the part itself, so calls chain | pcFile=the source file path | AddSources, Sources
AddSources | Adds several source files to the part. | the part itself, so calls chain | paFiles=a list of file paths; anything but a list is ignored | AddSource, Sources
Sources | Returns the part's source files, in the order added. | a list of text | | AddSource
To | Declares the system the part deploys to. | the part itself, so calls chain | pTarget=a token such as :ESP32, :Android, :iOS, :LinuxServer or :Windows, or a stzSystemProfile | DeploymentSystem, DeploymentOSName | an unknown token is taken as an operating-system name with default capabilities | DeployedTo is the same call

Scope | Returns the retained scope, or the empty text before System was called. | a stzSystemScope or the empty text | | System, HasScope

Show | Prints one line: the kind, the name and the deployment operating system. | nothing; it prints | | DeploymentOSName
