init | Builds a resistant summary of a batch of numbers, kept in the order given. | nothing; the object is built | paNumbers=the batch, a non-empty list of numbers; an empty list or an item that is not a number raises an error | Median, Fourths, Why
Numbers | Returns the batch as it was given, in the same order. | a list of numbers | | Count, Outside
Count | Returns how many values the batch holds. | a number | | Numbers
SetConvention | Chooses which pair of hinges the summary uses: Tukey's fourths, or percentile quartiles. | the summary itself, so calls chain | pcConvention=Fourths, Tukey or Hinges for Tukey's fourths, the default; Percentile or Quartiles for percentile quartiles; any other text raises an error | Convention, Hinges, Fourths, Quartiles | it changes Hinges, FourthSpread, Fences, Outside and FarOut; Fourths and Quartiles always answer their own pair | on 2, 4, 4, 5, 7, 9, 12, 25 the upper hinge is 10.5 under fourths and 9.75 under percentile
Convention | Returns the convention in force for the hinges. | fourths or percentile | | SetConvention, Why
Median | Returns the middle value of the batch, or the mean of the two middle values for an even count. | a number | | Fourths, Trimean | | 6 for 2, 4, 4, 5, 7, 9, 12, 25
Fourths | Returns Tukey's two hinges, the medians of the lower and the upper half including the middle value. | a list [ lower, upper ] | | Quartiles, Hinges, FourthSpread | | always Tukey's pair whatever the convention in force; [ 4, 10.5 ] for 2, 4, 4, 5, 7, 9, 12, 25
Quartiles | Returns the percentile quartiles, read at rank p/100 times n minus 1 with linear interpolation. | a list [ lower, upper ] | | Fourths, Hinges | | always the percentile pair; [ 4, 9.75 ] for 2, 4, 4, 5, 7, 9, 12, 25
Hinges | Returns the pair of hinges the convention in force names. | a list [ lower, upper ]: the fourths by default, the quartiles under Percentile | | SetConvention, Fourths, Quartiles
FourthSpread | Returns the distance between the two hinges, the spread that the fences are measured in. | a number | | Hinges, Fences | | 6.5 for 2, 4, 4, 5, 7, 9, 12, 25 under fourths
Fences | Returns the lower and upper limits at a multiple of the fourth-spread beyond the hinges, under the convention in force. | a list [ lower, upper ] | pnMult=a positive multiplier of the fourth-spread; 1.5 marks outside values and 3 far-out ones; any other value raises an error | OutsideFences, FarOutFences, Outside | | for 2, 4, 4, 5, 7, 9, 12, 25 the 1.5 fences are -5.75 and 20.25
OutsideFences | Returns the fences at 1.5 fourth-spreads beyond the hinges. | a list [ lower, upper ] | | Fences, Outside
FarOutFences | Returns the fences at 3 fourth-spreads beyond the hinges. | a list [ lower, upper ] | | Fences, FarOut | | -15.5 and 30 for 2, 4, 4, 5, 7, 9, 12, 25
Outside | Returns the values beyond the outside fences, in the order given. | a list of numbers; empty when none is outside | | OutsideFences, FarOut | | 25 for 2, 4, 4, 5, 7, 9, 12, 25
FarOut | Returns the values beyond the far-out fences, in the order given. | a list of numbers; empty when none is far out | | FarOutFences, Outside | | none for 2, 4, 4, 5, 7, 9, 12, 25, and 100 when the last value is 100
LetterValues | Returns the ladder of letter values from the median outward: depth, lower, upper, mid and spread at each level. | a list of rows [ letter, depth, lower, upper, mid, spread ] with letters M, F, E, D, C and on | pnLevels=how many levels, from 1 for the median alone; below 1 raises an error | LetterValueTable, Hinges, Skewness | the ladder stops when the depth reaches 1, so a batch of 8 gives 4 rows even when 10 are asked | for 2, 4, 4, 5, 7, 9, 12, 25: M is 6 at depth 4.5, F is 4 and 10.5, E is 3 and 18.5
Trimean | Returns Tukey's trimean, the mean of the lower hinge, twice the median and the upper hinge. | a number | | Median, Fourths | | 6.625 for 2, 4, 4, 5, 7, 9, 12, 25
LetterValueTable | Returns the letter values laid out as a text table with one line per level and a note on how depths are found. | a text of several lines | pnLevels=how many levels, from 1 | LetterValues
Mad | Returns the median absolute deviation from the median, not scaled to estimate a standard deviation. | a number | | Biweight, FourthSpread | | 2.5 for 2, 4, 4, 5, 7, 9, 12, 25
Biweight | Returns the biweight midvariance, a resistant variance that gives distant values little or no weight. | a number in squared units, a variance and not a standard deviation | pnC=the tuning constant in units of the MAD; a value that is not a positive number gives 9, the usual | Mad | | 16.52 with 9 and 13.5 with 6 for 2, 4, 4, 5, 7, 9, 12, 25; its square root is a spread
Skewness | Returns how far the mid-summaries drift from the median, in fourth-spreads; positive leans right. | a number; 0 when the fourth-spread is 0 | | TailWeight, Shape, LetterValues | Raises error R2 (index out of range) for a batch of fewer than 5 values, because it needs four letter values | 0.69 for 2, 4, 4, 5, 7, 9, 12, 25; a shape verdict is made from 100 values
TailWeight | Returns the sixteenth-spread over the fourth-spread, divided by the Gaussian ratio 2.2745; 1 is Gaussian. | a number; 1 when the fourth-spread is 0 | | Skewness, Shape | Raises error R2 (index out of range) for a batch of fewer than 5 values, as Skewness does | above 1.2 counts as heavy tails once there are 100 values
Shape | Returns the shape in numbers and in words: count, skewness, tail weight, which way it leans and whether its tails are heavy. | a hash list with the keys count, skewness, tailweight, leans, tails and because | | Skewness, TailWeight, Diagnostics | Raises error R2 (index out of range) for a batch of fewer than 5 values | under 100 values leans and tails are unjudged, and because says so; from 100, leans is right, left or neither and tails is heavy or not heavy
Diagnostics | Returns the verdicts on the batch in the house rule shape: each far-out value is an error, a lean or heavy tails a warning. | a list of rows [ :rule, :subject, :where, :severity, :message ]; empty when all is well | pcSubject=what the batch is called in the rows; an empty text gives batch | Shape, FarOut, StzTukeyReportQ | Raises error R2 (index out of range) for a batch of fewer than 5 values, through Shape | the rules are far_out, skewed and heavy_tailed, and each message names the measurement and its threshold
Why | Returns one sentence naming the convention in force, with the hinges, median, fourth-spread and the counts outside and far out. | a text | | Convention, Hinges
