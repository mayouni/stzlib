init | Builds a request signer with a name and an empty keyring and replay cache. | nothing; the object is built | pcName=the signer's name, recorded as the actor of webhook refusals | AddKey, Sign
Name_ | Returns the name the signer was built with. | a text | | init
Why | Returns the reason for the last refusal, or an empty text after a success. | a text | | Verify, VerifyBody, VerifyWebhook | the reason quotes the key id of an unknown caller as it arrived, without escaping, so show it as text and never as markup
AddKey | Registers a caller's shared secret under a key id, replacing the secret when the id is already there. | the signer itself, so calls chain | pcKeyId=the caller's key id; pcSecret=the shared secret, held in memory as given | HasKey, RemoveKey, Sign | | use an invented or generated secret in examples and tests, and keep real ones in a secret store
HasKey | TRUE if a secret is registered under that key id. | TRUE or FALSE | pcKeyId=the key id to look for | AddKey, Keys
RemoveKey | Removes a caller's secret from the keyring; an unknown key id changes nothing. | the signer itself, so calls chain | pcKeyId=the key id to remove | AddKey, Keys
Keys | Returns the registered key ids; never the secrets. | a list of text | | HasKey, AddKey
Sign | Makes the HMAC-SHA256 envelope of a request from an explicit timestamp and nonce, the deterministic form for tests. | a hash list [ :kid, :ts, :nonce, :sig ]; sig is 64 hexadecimal characters | pcKeyId=the caller's key id; pcMethod=the HTTP method; pcPath=the path with its query; pcBody=the body text; pnTs=the time in milliseconds; pcNonce=a value never used before for this key | SignNow, Verify | raises an error naming the key id when no secret is held for it | the signed text is length-prefixed, so two different requests never produce the same bytes
SignNow | Signs a request with the engine clock and a fresh 32-character random nonce. | a hash list [ :kid, :ts, :nonce, :sig ] | pcKeyId=the caller's key id; pcMethod=the HTTP method; pcPath=the path with its query; pcBody=the body text | Sign, VerifyEnvelope | raises an error naming the key id when no secret is held for it
Verify | Judges a signed request against an explicit current time: known key, fresh timestamp, matching signature, and a nonce not seen before. | TRUE if every check passed, else FALSE with the reason in Why | pcKeyId=the caller's key id; pcMethod=the HTTP method; pcPath=the path with its query; pcBody=the body text; pnTs=the signed time; pcNonce=the signed nonce; pcSig=the signature received; pnMaxSkewMs=the freshness window in milliseconds, both ways; pnNowMs=the current time in milliseconds | VerifyNow, VerifyEnvelope, Sign | every refusal is noted in the process security ledger when one is open, as sig.key.unknown, sig.timestamp.stale, sig.signature.forged or sig.nonce.replayed; the note holds the path with its query string, so a token placed in a query string reaches the ledger, and an unknown key id is written as received, line breaks included, which a text view of the ledger shows as a forged extra line | a valid request is accepted once: its nonce is remembered for the window; the signature is compared in constant time
VerifyNow | Judges a signed request as Verify does, taking the current time from the engine clock. | TRUE or FALSE, with the reason in Why | pcKeyId=the caller's key id; pcMethod=the HTTP method; pcPath=the path with its query; pcBody=the body text; pnTs=the signed time; pcNonce=the signed nonce; pcSig=the signature received; pnMaxSkewMs=the freshness window in milliseconds | Verify, VerifyEnvelope | the notes written to the ledger are those of Verify
VerifyEnvelope | Judges a request together with the envelope that Sign or SignNow made for it, against the engine clock. | TRUE or FALSE, with the reason in Why | pcMethod=the HTTP method; pcPath=the path with its query; pcBody=the body text; paEnvelope=the hash list [ :kid, :ts, :nonce, :sig ]; pnMaxSkewMs=the freshness window in milliseconds | Verify, SignNow | | a second use of the same envelope is refused as a replay
SignBody | Signs the raw body of a webhook delivery alone, with no method, path, time or nonce. | a text, the HMAC-SHA256 in 64 hexadecimal characters | pcKeyId=the key id whose secret signs; pcBody=the body text | VerifyBody, VerifyWebhook | raises an error naming the key id when no secret is held for it | without a time or a nonce the signature alone does not prevent a replay: use VerifyWebhook for that
VerifyBody | Judges a webhook body against the signature a given key would give it, with no replay check. | TRUE or FALSE, with the reason in Why | pcKeyId=the key id to verify with; pcBody=the body text; pcSig=the signature received | SignBody, VerifyWebhook | a missing signature is noted as webhook.unsigned and a mismatch as webhook.signature.forged | an unknown key id is refused without a ledger note
VerifyWebhook | Finds which registered key signed a webhook body, refusing a forged, missing or repeated delivery; the key may be the old or the new one. | a text, the key id that signed it; an empty text when refused, with the reason in Why | pcBody=the raw body; pcSig=the signature received; pnNowMs=the current time in milliseconds; pnWindowMs=how long a believed body counts as a replay | VerifyBody, SignBody | a refusal is one ledger note, webhook.unsigned, webhook.signature.forged or webhook.replayed | outside the window the same body is accepted again as a fresh delivery
