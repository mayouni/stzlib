init | Loads one of the shipped musical traditions, declared as data, and chooses its default mode and rhythmic cycle. | nothing; the object is built | pName=the tradition: western, maqam, tunisian, niger, raga, gamelan, westafrican or flamenco, in any case | StzSoundUniverseQ, StzSoundUniverses | an unknown tradition leaves the object unusable, with LastError listing those declared | the universe's own speed and instrument are taken first, so a rhythm-only universe keeps its speed
IsUsable | TRUE if a declaration was loaded. | TRUE or FALSE | | init
Name | Returns the short identifier of the loaded tradition, in lower case. | a text such as maqam; an empty text when unusable | | Title
Title | Returns the declaration's full heading. | a text such as Arabic maqam | | Name, Sources
Declaration | Returns the whole declaration as a list of key and value pairs. | a list | | ModeNames, Sources | the data a tradition's theorists wrote down; nothing in it is logic
Listener | Returns who has heard this universe, or UNPERCEIVED. | a text; UNPERCEIVED until a person from the tradition has heard it, then their verdict | | Sources | none of the shipped universes has a listener's verdict yet
Sources | Returns where the declaration comes from. | a list of text, the references of the declaration | | Listener, Declaration
ModeNames | Returns the modes the tradition declares. | a list of text in lower case; [ ] for a rhythm-only tradition | | Mode, CycleNames
CycleNames | Returns the rhythmic cycles the tradition declares. | a list of text in lower case | | Cycle, ModeNames
Mode | Chooses a mode, taking its tonic, instrument and speed from the declaration. | the universe itself, so calls chain | pName=the mode's name, in any case; an empty text keeps the current one | ModeNames, Tonic | an unknown mode is refused, with LastError listing those declared | it overrides a Tonic, Tempo or On given before
Cycle | Chooses a rhythmic cycle. | the universe itself, so calls chain | pName=the cycle's name, in any case; an empty text keeps the current one | CycleNames, NoCycle | an unknown cycle is refused, with LastError listing those declared
NoCycle | Replaces the rhythmic cycle by a bare one with no layers and no accents, to hear a mode without its rhythm. | the universe itself, so calls chain | pnBeats=the length of the bare cycle in beats | Cycle, PerformQ | the cycle is then called none
Tonic | Sets the note from which the degrees are counted. | the universe itself, so calls chain | pcNote=a note name with its octave, such as D4 | TonicName, Mode | anything that is not a note name is refused, with LastError set, and the old note stays
Tempo | Sets the speed of the performance, in beats per minute. | the universe itself, so calls chain | pnBpm=the speed in beats per minute | PerformQ | the value is stored without a check, and a score refuses a bad one when it is made
On | Sets the instrument that plays the melody. | the universe itself, so calls chain | pInstrument=the instrument name, kept in lower case | Melody, Mode | an unknown instrument is refused only later, when the notes are rendered
ModeName | Returns the chosen mode. | a text in lower case; an empty text for a rhythm-only tradition | | Mode, ModeNames
CycleName | Returns the chosen rhythmic cycle. | a text in lower case | | Cycle, NoCycle
TonicName | Returns the note from which degrees are counted. | a text such as C4 | | Tonic
Melody | Returns the instrument that plays the melody. | a text in lower case; an empty text for a rhythm-only tradition | | On
HasScale | TRUE if the chosen mode declares degrees, so phrases can be written in it. | TRUE or FALSE | | ModeNames, PerformQ | FALSE for a rhythm-only tradition such as westafrican
LadderQ | Returns the chosen mode drawn as a ladder with a rung per degree, spaced by cents. | a stzSoundLadder at the current tonic | | CentsOf | the ladder has not been seen by a person from the tradition
CentsOf | Returns the distance of a degree above the tonic, in cents, going up or coming down. | a number of cents; -1 when the mode declares no scale | pcDegree=the degree as text: 5, 5_ for the octave below, 9 for the next octave up; pbDown=TRUE to take the descending form of the mode where it declares one | HzOf, Check | a degree past the mode's size wraps up an octave; 5_ is 1200 cents lower | measured in maqam hijaz: degree 3 is 400 cents, 5 is 700, 8 is 1200 and 5_ is -500
HzOf | Returns the frequency of a degree, from the tonic and the declared cents. | a number of hertz; 0 when the mode declares no scale | pcDegree=the degree as text, such as 5 or 5_; pbDown=TRUE to take the descending form of the mode where it declares one | CentsOf | measured: with the tonic D4, degree 1 is 293.66 Hz, degree 5 is 440 and degree 8 is 587.33
Check | Holds a phrase of degrees against the movement rules of the chosen mode and lists what breaks them. | a list of text, one per broken rule; [ ] for a phrase the declaration allows | pcPhrase=the phrase in degrees, such as 1 2 3 4 5 | PerformQ, CentsOf | a phrase that is not made of degrees gives one text, the parser's reason; an empty list is not a verdict by a musician of the tradition
PerformQ | Plays a phrase of degrees through the rhythmic cycle, for a number of cycles, as a score. | a stzSoundScore with the universe's speed; an empty score with LastError set when the mode has no scale or the phrase is bad | pcPhrase=the phrase in degrees, such as 1 2 3 4 5 4 3 2, where 5_ is an octave down; pnCycles=how many times the phrase is repeated | ToSound, PlayedNotes, Check | the cycle's accents raise the velocity, the mode's ornaments become slides and graces, and the cycle's own layers play beneath; for a rhythm-only tradition the rhythm is still returned, with the refusal recorded | no audio device is opened; the score has not been heard by a person from the tradition
Sentences | Returns the sentences the tradition declares for its talking drum. | a list of text; [ ] when it declares none | | SentenceQ, ToneSyllables
SentenceQ | Returns a declared sentence as a score of drum notes, each syllable at the pitch of its tone. | a stzSoundScore; an empty score with LastError set for an unknown sentence | pcText=the sentence, as listed by Sentences | Sentences, DrumTonesQ | a high tone, a low tone or a falling glide per syllable, a long vowel lasting two units | no audio device is opened; the drum has not been heard by a Hausa speaker
SonifyQ | Turns a series of numbers into a melody in the chosen mode, the lowest value on degree 1 and the highest two octaves up. | a stzSoundScore; an empty score with LastError set when the mode has no scale, the series is shorter than two, holds a non-number or does not move | paValues=the numbers to turn into notes | SonifiedDegrees, PerformQ | the top degree is lowered when the melody instrument cannot play it | no audio device is opened
SonifiedDegrees | Returns the degrees the last SonifyQ chose, one per value. | a list of numbers; [ ] before SonifyQ | | SonifyQ, SonifiedPhrase
SonifiedTop | Returns the highest degree the last SonifyQ allowed. | a number: twice the mode's size, or fewer when the instrument's range is short; 0 before SonifyQ | | SonifyQ
SonifiedPhrase | Returns the degree phrase the last SonifyQ built, one bracket per cycle. | a text such as <[3 7 5 9] [1 8 ~ ~]>; an empty text before SonifyQ | | SonifyQ, PerformQ
ToneSyllables | Reads Hausa text with tone marks into syllables, each with its tone and length. | a list of [ syllable, tone, units ] rows, the tone H, L or F; [ ] when refused | pcText=Hausa text in UTF-8 with Newman's tone marks: no mark is high, a grave low, a circumflex falling | DrumTonesQ, Sentences | text with no tone mark at all is refused, with LastError set, since reading it as all high would be a confident lie | LastError keeps that reason after a later successful call, which does not clear it
DrumTonesQ | Returns marked Hausa text as a score of drum notes, each syllable at the pitch of its tone. | a stzSoundScore; an empty score with LastError set when the text has no tone marks or the tradition has no talking drum | pcText=Hausa text in UTF-8 with tone marks | ToneSyllables, SayOnDrum | no audio device is opened; it draws the contour of the tones and does not claim to be speech | the drum has not been heard by a Hausa speaker
SayOnDrum | Gives marked Hausa text on the talking drum, once a Hausa speaker has confirmed that the drum speaks. | a stzSoundScore when the declaration's verdict is SPEAKS; an empty text otherwise | pcText=Hausa text in UTF-8 with tone marks | DrumTonesQ | refused today, with LastError naming the missing verdict, because the verdict is UNPERCEIVED | the gate is the declaration's talking drum verdict, not a flag in code
ToSound | Renders a phrase of degrees through the rhythmic cycle to a sound in memory. | a stzSound at 48000 Hz, two channels | pcPhrase=the phrase in degrees, such as 1 2 3; pnCycles=how many times the phrase is repeated | PerformQ | no audio device is opened; a bad phrase gives a sound of one frame, with LastError set | the sound has not been heard by a person from the tradition
PlayedNotes | Returns every melody note that the last PerformQ placed. | a list of [ beat, degree, cents, hertz, ornament ] rows; [ ] before any | | PerformQ, SonifyQ | the drum verbs fill it with [ beat, syllable, tone, hertz, ornament ] rows instead
LastError | Returns the reason the last call was refused, or an empty text. | a text | | Refusals | it is never cleared by a later success
Refusals | Returns how many calls the universe has refused. | a number | | LastError
