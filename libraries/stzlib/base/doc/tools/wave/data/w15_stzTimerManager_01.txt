# w15 stzTimerManager
init | Builds a manager with no timers, a 10 ms wait between ticks and no patience for an idle loop. | nothing; the object is built | | AddTimer, RunLoop | | the manager's loop keeps copies of the timers it is given
SetCheckFrequency | Sets how long the loop waits between ticks, in milliseconds. | the manager itself, so calls chain | freq=the wait in milliseconds, above 0; a value that is not a number, or 0 or less, is ignored and the old one is kept | SetPatience, RunLoop | | the wait is a real timer on the reactor when SetReactor gave one, and a sleep otherwise
SetPatience | Sets how many idle passes the loop tolerates before it stops. | the manager itself, so calls chain | patience=a count of passes with no timer, no pending request and no detached timer, 0 or more; a negative or a non-number is ignored | SetCheckFrequency, RunLoop | | the default 0 stops as soon as there is no work, like libuv; a count, not a duration
SetReactor | Gives the manager a reactor to wait on between ticks. | the manager itself, so calls chain | poReactor=a stzReactor, or an empty text for the plain sleep | SetCheckFrequency, RunLoop | | the stored reactor is a copy that shares the engine handle
AddTimer | Adds a timer to the manager's list. | nothing; the timer is added | _timer_=a stzReactiveTimer or stzRingTimer, started by the caller | RemoveTimer, RunLoop | | the manager stores a copy, so later changes to the caller's timer do not reach it; the timer must have been started or it never fires
RemoveTimer | Stops a timer by its id and removes it. | nothing | timerId=the id the timer was built with | AddTimer, StopAllTimers | | an unknown id does nothing; when no timer is left the loop is told to stop
RunLoop | Runs the loop that ticks the timers and drains requests until no work is left or Stop is called. | nothing; it returns when the loop has stopped | poHttpDrain=the live stzReactiveHttp whose pending requests are drained each pass, or an empty text for none | Stop, SetPatience, AddTimer | | it ends when no timer remains, no request is pending and the patience is used up, or when Stop is called; a callback that stops a repeating timer copy does not stop the manager's own copy, so a loop with a repeating timer runs until Stop or StopAllTimers is called on the manager itself
Stop | Tells the loop to end and stops every timer in it. | nothing | | RunLoop, StopAllTimers | | once stopped, RunLoop returns at once
StopAllTimers | Stops every timer, empties the list and stops the loop. | nothing | | Stop, RemoveTimer |
