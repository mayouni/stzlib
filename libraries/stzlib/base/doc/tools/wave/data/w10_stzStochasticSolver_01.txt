init | Builds an empty stochastic problem, with no variable, constraint, objective or scenario. | nothing; the object is built | | clear, addVariable, addScenario, solve
clear | Empties the problem and restores the defaults: solver type expected, robustness factor 0.1 and confidence level 0.95. | nothing; the problem is empty again | | init, setSolverType
addVariable | Adds a continuous variable with a lower and an upper bound, in declaration order. | the solver itself, so calls chain | _varName_=the variable's name, as text; lowerBound=the smallest value the variable may take; upperBound=the largest value it may take, never below the lower bound | addIntegerVariable, addBinaryVariable, variableNames | all three arguments must be given (R19 otherwise) and the bounds must be numbers; a name that is not text and an upper bound below the lower bound raise an error |
addIntegerVariable | Adds a variable marked integer, with the same arguments and checks as a continuous one. | the solver itself, so calls chain | _varName_=the variable's name, as text; lowerBound=the smallest value the variable may take; upperBound=the largest value it may take | addVariable, addBinaryVariable | the mark is only recorded in the variable list, no solver enforces it |
addBinaryVariable | Adds a variable bounded between 0 and 1 and marked binary. | the solver itself, so calls chain | _varName_=the variable's name, as text | addVariable, addIntegerVariable | the mark is only recorded, no solver enforces it |
variables | Returns the declared variables in order, each as a list of name, lowerbound, upperbound and type pairs. | a list with one list of [ key, value ] pairs per variable; [ ] when none is declared | | variableNames, addVariable | | the keys are lower case
variableNames | Returns the names of the declared variables, in declaration order. | a list of text | | variables, addVariable
SetVariableNames | Replaces the whole variable list with the list given, without reshaping it. | nothing | pacNames=the new variable records, each a list holding a name pair such as [ "name", "q" ] | variables, variableNames, addVariable | despite its name it replaces the variable records, not only their names: SetVariableNames([ "a", "b" ]) makes variables() answer [ "a", "b" ] and variableNames() then raises R5, and any bounds are lost; the code carries a TODO for more checks |
addScenario | Adds one future state of the world, with the parameter values that define it and its probability. | the solver itself, so calls chain | name=the scenario's name, as text; description=a sentence describing it, as text; parameters=a list of [ name, value ] pairs, such as [ [ "d", 4 ] ], replaced as text inside expressions and constraint values; probability=a number from 0 to 1 | scenarios, validateScenarios, applyScenarioParameters | a name or description that is not text, parameters that are not a list, and a probability that is not a number between 0 and 1 each raise an error; probabilities are only checked together when the problem is solved |
scenarios | Returns the declared scenarios in order, each as a list of name, description, parameters and probability pairs. | a list of lists of [ key, value ] pairs; [ ] when none is declared | | addScenario
validateScenarios | Raises an error unless the probabilities of the scenarios add up to 1, within 0.001. | nothing; it raises when the check fails | | addScenario, solve | | with no scenario the total is 0 and it raises as well
addConstraint | Adds a constraint that holds in every scenario: an expression, a comparison and a number or a text to evaluate per scenario. | the solver itself, so calls chain | expression=the left side, as text; operator=the comparison: "<=", ">=" or "="; value=a number, or a text such as "d * 2" in which scenario parameters are replaced and one arithmetic operation is evaluated | addScenarioConstraint, addChanceConstraint, constraints | an expression that is not text, another operator, or a value that is neither a number nor text raise an error | the stored constraint has scenario all and chance 1
addScenarioConstraint | Adds a constraint that applies in one named scenario only. | the solver itself, so calls chain | expression=the left side, as text; operator=the comparison: "<=", ">=" or "="; value=a number or a text to evaluate; scenarioName=the name of the scenario it applies to, as text | addConstraint, addScenario | the expression and the operator are not checked, unlike addConstraint |
addChanceConstraint | Adds a constraint that must hold with a given probability, to be read when the solver type is chance. | the solver itself, so calls chain | expression=the left side, as text; operator=the comparison: "<=", ">=" or "="; value=a number or a text to evaluate; confidenceLevel=the probability, from 0 to 1, with which it must hold | addConstraint, setConfidenceLevel | a confidence level outside 0 to 1, or not a number, raises an error; the expression and the operator are not checked |
constraints | Returns the declared constraints in order, each as a list of expression, operator, value, scenario and chance pairs. | a list of lists of [ key, value ] pairs; [ ] when none is declared | | addConstraint
maximize | Sets the objective to an expression to make as large as possible, replacing any earlier objective. | the solver itself, so calls chain | expression=the objective, as text, which may name scenario parameters | minimize, objective, solve
minimize | Sets the objective to an expression to make as small as possible, replacing any earlier objective. | the solver itself, so calls chain | expression=the objective, as text, which may name scenario parameters | maximize, objective, solve
objective | Returns the objective expression as text. | a text; "" before an objective is set | | maximize, minimize, objectiveType
objectiveType | Returns whether the objective is to be made larger or smaller. | the text "maximize" or "minimize"; "maximize" before any objective is set | | maximize, minimize
setSolverType | Chooses how solve treats the uncertainty: expected, robust, chance or montecarlo. | the solver itself, so calls chain | cType=one of "expected", "robust", "chance" or "montecarlo", in lower case | solverType, solve | any other name raises an error |
setRobustnessFactor | Sets the fraction, from 0 to 1, by which the robust solver shrinks every scenario limit; 0.1 by default. | the solver itself, so calls chain | nFactor=a number from 0 to 1 | setSolverType, calculateRobustMaxValue | a value outside 0 to 1, or not a number, raises an error |
setConfidenceLevel | Sets the probability, from 0 to 1, that the chance solver aims to cover; 0.95 by default. | the solver itself, so calls chain | nLevel=a number from 0 to 1 | addChanceConstraint, calculateChanceMaxValue | a value outside 0 to 1, or not a number, raises an error |
evaluateConstraintValue | Returns a constraint's right side for one scenario: a number as it is, a text after its parameters are replaced and evaluated. | a number | value=a number or a text such as "d * 2"; _scenario_=a scenario, as returned by scenarios | applyScenarioParameters, evaluateExpression | | with d = 4 the text "d * 2" gives 8 and "d + 3" gives 7
evaluateExpression | Returns the value of a text holding a single number or one operation between two numbers: *, /, + or -. | a number | cExpression=the text, such as "6 / 3" | evaluateConstraintValue | a text with two operations, such as "2 * 3 + 1", raises R41 Invalid numeric string, and a division by zero raises an error | 6 / 3 gives 2, 7 - 2 gives 5, 2 + 3 gives 5
solve | Validates the problem and runs the solver chosen with setSolverType, then stores its solution. | the solver itself, so calls chain | | setSolverType, solution, status, expectedObjectiveValue | no variable, no objective, no scenario, or probabilities that do not add up to 1 raise an error; the solvers expected, robust and chance leave every variable at its lower bound today, and no solver respects the constraints (see solveExpectedValue and calculateScenarioMaxValue); the status is set to optimal in every case |
solveExpectedValue | Returns a solution from the probability-weighted objective, giving each variable in turn the largest value its limits allow. | a list of [ name, value ] pairs, one per variable | | solve, solveRobust, calculateExpectedMaxValue | it answers every variable at its lower bound: the update writes to a copy of the pair (_sol_ is a copy of the list item), so the solution never changes; with one variable x in 0..3, x <= 2 and maximize x it answers 0, and in a two-variable problem it answers 0 and 0; its limits are also broken, see calculateScenarioMaxValue |
solveRobust | Returns a solution built from the first scenario's objective, with each limit shrunk by the robustness factor. | a list of [ name, value ] pairs, one per variable | | solve, setRobustnessFactor, getWorstCaseObjective | it answers every variable at its lower bound, for the same reason as solveExpectedValue (a copy of the pair is updated), on two problems |
solveChanceConstrained | Returns a solution built from the expected objective, with limits read at the confidence level. | a list of [ name, value ] pairs, one per variable | | solve, setConfidenceLevel, calculateChanceMaxValue | it answers every variable at its lower bound, for the same reason as solveExpectedValue (a copy of the pair is updated), on two problems |
solveMonteCarlo | Returns the best of 100 per-scenario solutions, each for a scenario drawn at random by probability. | a list of [ name, value ] pairs, one per variable | | solve, solveForScenario | the draws are random; the constraints do not limit anything today, so every variable comes back at its upper bound (with x in 0..3 and x <= 2 it answered 3; with x + y <= d it answered 10 and 10) |
applyScenarioParameters | Returns the expression with every parameter name replaced by its value, as text. | a text | cExpression=the expression, as text; aParameters=a list of [ name, value ] pairs | evaluateConstraintValue, addScenario | | the replacement is plain text: 2*d + x with d = 4 gives 2*4 + x, and dd + 2*d gives 44 + 2*4
extractCoefficient | Returns the coefficient of one variable in an expression. | a number; 0 when the variable does not appear | cExpression=the expression, as text; _cVarName_=the variable's name | parseObjectiveCoefficients | | in 3*x + 2*y the coefficient of y is 2
parseObjectiveCoefficients | Returns the coefficient of each declared variable in an expression, in declaration order. | a list of numbers | cExpression=the expression, as text | extractCoefficient, variableNames | | 3*x + 2*y gives [ 3, 2 ]
calculateExpectedResourceCost | Returns the probability-weighted sum, over the scenarios, of the absolute coefficients of a variable in the constraints that apply. | a number | _cVarName_=the variable's name | calculateWorstCaseResourceCost, calculateChanceResourceCost
calculateWorstCaseResourceCost | Returns the largest, over the scenarios, of the summed absolute coefficients of a variable in the constraints that apply. | a number | _cVarName_=the variable's name | calculateExpectedResourceCost, solveRobust
calculateChanceResourceCost | Returns the probability-weighted resource cost of a variable, each constraint weighted by its chance against the confidence level. | a number | _cVarName_=the variable's name | calculateExpectedResourceCost, setConfidenceLevel
calculateExpectedMaxValue | Returns the smallest probability-weighted scenario limit on a variable, never below 0. | a number | _cVarName_=the variable's name; _aSolution_=a list of [ name, value ] pairs for the other variables | calculateScenarioMaxValue, solveExpectedValue | built on calculateScenarioMaxValue, so it answers 399999.6 for a variable whose scenario limit is really 4 and 6: the weighting multiplies the 999999 that means no limit | the weighting by probability makes the limit smaller than any single scenario allows
calculateRobustMaxValue | Returns the smallest scenario limit on a variable, reduced by the robustness factor, never below 0. | a number | _cVarName_=the variable's name; _aSolution_=a list of [ name, value ] pairs for the other variables | calculateScenarioMaxValue, setRobustnessFactor | built on calculateScenarioMaxValue, so it answers 899999.1 where the limit is really 4 and 6
calculateChanceMaxValue | Returns the scenario limit on a variable at which the cumulated probability, from the smallest limit up, reaches the confidence level. | a number, never below 0 | _cVarName_=the variable's name; _aSolution_=a list of [ name, value ] pairs for the other variables | calculateScenarioMaxValue, setConfidenceLevel | built on calculateScenarioMaxValue, so it answers 999999 where the limit is really 4 and 6
calculateScenarioMaxValue | Returns the largest value a variable can take in one scenario, given the values of the others, from the constraints that apply. | a number | _cVarName_=the variable's name; _aSolution_=a list of [ name, value ] pairs for the other variables; _scenario_=a scenario, as returned by scenarios | calculateExpectedMaxValue, solveForScenario | it answers 999999, meaning no limit, for every constraint with "<=", ">=" or "=": the switch labelled on "=" or "<=" matches none of the operators; one variable x with x <= 6, x >= 6 or x = 6 gives 999999 each time |
getWorstCaseObjective | Returns the objective expression of the first scenario, with its parameters replaced. | a text | | solveRobust, applyScenarioParameters | it does not look for a worst case: it keeps the first scenario's objective, as its comment says |
solveForScenario | Returns a solution for one scenario, filling the variables in declaration order with the largest value the limits and the upper bound allow. | a list of [ name, value ] pairs, one per variable | _scenario_=a scenario, as returned by scenarios | solveMonteCarlo, calculateScenarioMaxValue | the constraints do not limit anything today (calculateScenarioMaxValue), so every variable comes back at its upper bound: with x + y <= d it answered 10 and 10 |
calculateScenarioObjectiveValue | Returns the objective's value for a solution under one scenario's parameters. | a number | _aSolution_=a list of [ name, value ] pairs; _scenario_=a scenario, as returned by scenarios | expectedObjectiveValue, analyzeScenarios | | 3*x + 2*y with x = 1 and y = 2 gives 7
getSolutionValue | Returns the value of one variable in a list of [ name, value ] pairs. | a number; 0 when the name is not in the list | _aSolution_=a list of [ name, value ] pairs; _cVarName_=the variable's name | calculateScenarioObjectiveValue
analyzeScenarios | Returns, for each scenario, the objective value and the feasibility of the stored solution. | a list of lists of scenario, probability, objectivevalue and feasible pairs | | checkScenarioFeasibility, expectedObjectiveValue, exportScenarioAnalysis | raises an error when no solution is stored, so call solve first |
checkScenarioFeasibility | TRUE if a solution satisfies every constraint that applies in one scenario, within 0.001. | TRUE or FALSE | _aSolution_=a list of [ name, value ] pairs; _scenario_=a scenario, as returned by scenarios | analyzeScenarios, addScenarioConstraint | | with 2*x + y <= d, d = 4, x = 1 and y = 2 it is TRUE and with x = 2 and y = 2 it is FALSE
expectedObjectiveValue | Returns the probability-weighted objective value of the stored solution over all scenarios. | a number; 0 before any solve | | analyzeScenarios, calculateScenarioObjectiveValue
solution | Returns the solution stored by the last solve. | a list of [ name, value ] pairs; [ ] before any solve | | solve, getSolutionValue
status | Returns how the last solve ended. | the text optimal after a solve; "" before | | solve
iterations | Returns the work counted by the last solve: the number of variables, set by the expected solver only. | a number; 0 before any solve or for the other solver types | | solve
solveTime | Returns the time the last solve took, in seconds. | a number; 0 before any solve | | solve
solverType | Returns the solver type in force. | the text expected, robust, chance or montecarlo; expected by default | | setSolverType
show | Prints the problem, its scenarios and, once solved, the solution, the expected objective and the analysis of every scenario. | nothing; it prints to the console | | exportToCSV, exportScenarioAnalysis, analyzeScenarios
exportToCSV | Writes the stored solution to a file, one Variable,Value line per variable. | nothing; the file is written | cFileName=the path of the file to write | exportScenarioAnalysis, solution
exportScenarioAnalysis | Writes the objective value and feasibility of the stored solution for each scenario to a file. | nothing; the file is written | cFileName=the path of the file to write | exportToCSV, analyzeScenarios | | the first line is Scenario,Probability,ObjectiveValue,Feasible; it raises when nothing is solved
