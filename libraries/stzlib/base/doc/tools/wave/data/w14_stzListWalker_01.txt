WalkNForward | Returns the positions reached by stepping forward n items at a time from the first one. | a list of positions | n=the step between two positions | WalkNBackward, WalkEveryNth, WalkSkipping | an n of 0 never ends, since the loop does not advance (read from the code, not run, because it would fill the memory) | the answer lists positions, not items: 7 items with n = 2 give 1, 3, 5, 7; WalkForwardNSteps is the same call
WalkNBackward | Returns the positions reached by stepping backward n items at a time from the last one. | a list of positions | n=the step between two positions | WalkNForward, WalkZigZag | an n of 0 never ends, as in WalkNForward (read from the code, not run) | 7 items with n = 3 give 7, 4, 1; WalkBackwardNSteps is the same call
WalkBetween | Returns the positions from one to another, stepping by a given amount, forward or backward. | a list of positions | n1=the first position; n2=the last position; nStep=the size of each step, always positive | WalkFromTo, WalkNForward | | a start larger than the end walks backward; the positions are not clipped to the list, so WalkBetween(1, 99, 3) on 7 items goes on to 97
WalkForthAndBack | Returns the positions reached going forward n at a time and then backward n at a time. | a list of positions | n=the step between two positions | WalkZigZag, WalkNForward, WalkNBackward | an n of 0 never ends, as in WalkNForward (read from the code, not run) | the forward walk ends where the backward walk begins, so that position appears twice: 7 items with n = 3 give 1, 4, 7, 7, 4, 1

WalkWhen | Returns the positions from the first item that satisfies a condition to the end of the list. | a list of positions | pcCondition=the test, written with @item for the current item | WalkUntil, WalkWhile, WalkW | | nothing satisfying the test gives [ ]; on 5, 12, 7, 20, 3, 18, 9 the test "@item > 10" gives 2 to 7

WalkEveryNth | Returns the positions n, 2n, 3n and so on. | a list of positions | n=the step between two positions | WalkNForward, WalkSkipping | | the first position is not included unless n is 1; an n of 0 gives [ ]; WalkEach is the same call
