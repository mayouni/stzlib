# w15 stzMesh
init | Builds a mesh in the engine from a primitive, an OBJ text or a custom vertex layout, and keeps its handle. | nothing; the object is built | pWhat=a kind as a symbol, :Cube, :Sphere, :Torus or :Plane, or a list such as [ :Cube, nSize ], [ :Sphere, nRadius, nSegments, nRings ], [ :Torus, nRingRadius, nTubeRadius, nSegments, nSides ], [ :Plane, nSize ], [ :Obj, cObjText ] or [ :Custom, aComponentCounts, aVertices, aIndices ] | Kind, Format, Free | an empty list raises error stzMesh: nothing to build; an unknown kind raises error stzMesh: unknown kind ... use :Cube, :Sphere, :Torus, :Plane, :Obj or :Custom; an OBJ text with no v and f lines, or a custom layout whose vertex count does not divide evenly or whose index is out of range, raises an error saying the engine refused it | omitted numbers take defaults: size 1, sphere 24 segments and 12 rings, torus 0.35 tube radius, 64 segments and 32 sides; StzMeshQ and StzMeshFromObjQ build the same object
Id_ | Returns the engine handle of the mesh. | a number above 0, or 0 after Free | | IsAlive, Free | |
Kind | Returns the kind the mesh was built as, in lower case. | the kind as text, such as cube, sphere, obj or custom | | Format | |
IsAlive | TRUE if the engine still holds the mesh. | TRUE or FALSE, as 1 or 0; 0 after Free | | Free, Id_ | |
VertexCount | Returns how many vertices the mesh holds. | a number; -1 after Free | | IndexCount, TriangleCount | | a cube has 24, not 8, because a shared corner cannot carry three face normals; a sphere of 8 segments and 4 rings has (8 + 1) x (4 + 1) = 45
IndexCount | Returns how many indices the mesh holds, three per triangle. | a number; -1 after Free | | TriangleCount, VertexCount | | a cube has 36
TriangleCount | Returns how many triangles the mesh draws. | a number, the index count divided by three; a negative fraction after Free | | IndexCount, VertexCount | | a cube has 12 and a plane 2
AttributeCount | Returns how many attributes each vertex carries. | a number such as 3 for position, normal and texture coordinates; -1 after Free | | Stride, Format | | a custom layout of [ 3 ] has one
Stride | Returns how many floats make up one vertex. | a number such as 8; -1 after Free | | AttributeCount, Format | | the sum of the components in Format
Format | Returns the vertex layout as text, the components of each attribute, from which the pipeline is built. | text such as 3,3,2 for position, normal and texture coordinates; an empty text after Free | | Stride, AttributeCount | | extending the mesh with an attribute extends this text and nothing else
Free | Releases the mesh in the engine and zeroes the handle. | nothing; Id_ then answers 0 | | IsAlive, Id_ | | freeing twice does nothing the second time
