init | Opens a window of the given size and title on the screen, and prepares a drawing surface on it when a graphics device exists. | nothing; the object is built | pnW=the width in pixels, at least 1; pnH=the height in pixels, at least 1; pcTitle=the title text, and Softanza when it is not a text | StzWindowingAvailable, Draw, Free | Raises an error when the width or height is not a positive number, when this build has no windowing (the windowing module is absent) and when the machine cannot open a window, such as a headless one; ask StzWindowingAvailable first when a window is optional | without a graphics device the window opens but CanDraw is 0 and Draw does nothing
Id_ | Returns the engine's number for this window, or 0 when it was freed. | a number | | NativeHandle, Free
NativeHandle | Returns the operating system's own handle of the window, which accessibility tools attach to. | a number: the window handle on Windows, the window object on macOS, the window id on Linux; 0 once freed | | NativeDisplay | | it crosses as a floating-point number, exact up to 2 to the power 53
NativeDisplay | Returns the X11 display pointer that accessibility tools need beside the window id. | a number; 0 on Windows and macOS and once freed | | NativeHandle
IsOpen | TRUE if the window is still open, which holds until the user closes it or Close is called, so it is the condition of a frame loop. | 1 or 0; 0 once freed | | Close, Poll
CanDraw | TRUE if the window has a drawing surface, which needs a usable graphics device. | 1 or 0 | | Draw, init
Width | Returns the current width of the window in pixels. | a number; 0 once freed | | Height, SetSize
Height | Returns the current height of the window in pixels. | a number; 0 once freed | | Width, SetSize
Title | Returns the title the window was given or last set. | a text | | SetTitle
SetTitle | Changes the title shown on the window. | nothing; SetTitleQ returns the window for chaining | pcTitle=the new title as text | Title | ignored when the window was freed or the title is not a text
SetSize | Asks the window to take a new size, which lands at the next Poll and reconfigures the surface there. | 1 when the request was accepted, 0 when refused or ignored; SetSizeQ returns the window | pnW=the new width in pixels; pnH=the new height in pixels | WasResized, Poll | raises an error for a width or height below 1; numbers that are not numbers are ignored | it drives the same path as dragging an edge
WasResized | TRUE if the size changed during the last frame, so the picture can be laid out again before drawing. | 1 or 0 | | SetSize, Poll
Poll | Reads the pending events and samples the keys, the mouse, the size and the time of this frame, and reconfigures the surface after a resize. | nothing; PollQ returns the window | | DeltaTime, KeyPressed, IsOpen | | call it once at the top of every frame so that all reads describe the same instant
DeltaTime | Returns the seconds that passed between the last two Poll calls, the number to multiply speeds by. | a number of seconds; 0 once freed | | FPS, Poll
FrameCount | Returns how many frames Draw has put on the screen so far. | a number | | Draw, FPS
FPS | Returns the frame rate implied by the last frame alone, one divided by DeltaTime. | a number; 0 when no time has passed | | DeltaTime | | it is an instant rate that jitters; average it for a steady figure
Draw | Draws a canvas or a 3D scene into the window and shows it, resizing the drawable to the window if their sizes differ. | 1 when a frame reached the screen, 0 when the swapchain refused it, there is no surface or the object is neither a canvas nor a scene | poThing=a stzCanvas or a stzScene to render | EachFrame, Show, CanDraw | a refused frame is a normal event in a loop (a minimised window) and raises nothing; to put a second canvas over the first in one frame, use the extended form with an overlay | the frame is presented even if drawing failed, as the swapchain needs it
KeyDown | TRUE if the key is held down, on every frame of the hold, which suits movement. | 1 or 0 | pKey=a key name such as :Escape or :Space, or a GLFW key code | KeyPressed | raises an error naming a key it does not know; returns 0 once freed
KeyPressed | TRUE if the key went down during the last frame, once for each physical press, which suits commands. | 1 or 0 | pKey=a key name such as :Escape or :Space, or a GLFW key code | KeyDown | raises an error naming a key it does not know; returns 0 once freed
MouseX | Returns the horizontal position of the mouse in the window, in pixels, as sampled at the last Poll. | a number; 0 once freed | | MouseY, MousePosition
MouseY | Returns the vertical position of the mouse in the window, in pixels, as sampled at the last Poll. | a number; 0 once freed | | MouseX, MousePosition
MousePosition | Returns the mouse position as a pair, sampled at the last Poll. | a list [ x, y ] | | MouseX, MouseY
MouseDown | TRUE if the mouse button is held down, counting the buttons the way a person does. | 1 or 0 | pnButton=1 for left, 2 for right, 3 for middle | MouseClicked | a value that is not a number, or below 1, is read as the left button
MouseClicked | TRUE if the mouse button went down during the last frame. | 1 or 0 | pnButton=1 for left, 2 for right, 3 for middle | MouseDown
SetVSync | Turns synchronisation with the screen refresh on or off, off being the way to measure the true cost of a frame. | 1 when the mode changed, 0 when the card refused or there is no surface | pbOn=1 to cap the loop at the screen refresh, 0 to run as fast as the card allows | VSync | the setting is kept only when the card accepted it
VSync | Returns whether synchronisation with the screen refresh is on. | 1 or 0; 1 on a new window | | SetVSync
SurfaceFormat | Returns the pixel format name of the drawing surface. | a text such as bgra8; empty text when there is no surface | | Stats, CanDraw
Stats | Returns the surface's counters: width, height, frames presented, reconfigurations, frame held and present mode. | a list of six numbers; [ ] when there is no surface | | SurfaceFormat, FrameCount
Show | Shows a still picture in the window and waits until Escape is pressed or the window is closed. | the number of frames drawn | poThing=a stzCanvas or a stzScene to show | Draw, EachFrame | blocks until the user closes the window
EachFrame | Runs a frame loop that polls, then calls a function with this window, until the window closes; Escape closes it. | the number of frames drawn | pFunc=a function taking the window, which updates and draws one frame | Show, Poll, Draw | raises an error when the argument is not a function | blocks until the user closes the window
Close | Asks the window to close, which makes IsOpen answer 0 at the next check. | nothing | | IsOpen, Free | | it does not release the window; call Free for that
Free | Releases the drawing surface and the window, after which every query answers 0 or empty. | nothing | | Close | | call it when done, as the engine holds the window until then
