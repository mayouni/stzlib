# w15 stzAccessibilityTree
init | Builds the accessibility tree of a screen from its declared document and, if given, its laid-out panel. | nothing; the tree is built when the object is made | poDoc=the stzUiDocument, which must be clean; poPanel=the stzPanel made from it by ToPanel, or NULL when bounds and focus are not known | NodeOf, ToJSON | a value that is not a document raises error stzAccessibilityTree: give an stzUiDocument; a document that is not clean raises error ... the document is not clean -- ask Report() why | there is no flag to switch it off; with NULL for the panel every bounds is empty and no node is focused
Nodes | Returns every node of the tree in reading order, depth first, in the order the author declared them. | a list of hash lists with the keys id, role, name, description, bounds, focusable, focused, actions, depth and children | | NodeOf, NodeCount | | the first node is the panel itself, as a window
NodeCount | Returns how many nodes the tree holds. | a number | | Nodes, HasNode | | one node for each declaration, the panel included
NodeOf | Returns one node by its id. | a hash list with the keys id, role, name, description, bounds, focusable, focused, actions, depth and children; [ ] for an id the tree does not hold | pcId=the name of the declaration, matched as written | HasNode, RoleOf, Nodes | | bounds is [ x, y, width, height ] from the laid-out panel, or [ ] when no panel was given; actions is focus and click for a focusable node and empty otherwise
HasNode | TRUE if the tree holds a node with an id. | TRUE or FALSE, as 1 or 0 | pcId=the name of the declaration, matched as written | NodeOf, NodeCount | |
RoleOf | Returns what a screen reader announces a node as. | the role as text such as button, heading or label; the panel is window, a text defaults to label and any other box to group; an empty text for an unknown id | pcId=the name of the declaration | NameOf, NodeOf | | the role comes from the ROLE field of the declaration or from the style it uses
NameOf | Returns what a screen reader says for a node. | the name as text: the LABEL, else a text's own content, else for a button, link, heading, label, list item, tab, checkbox or radio the text of its descendants; an empty text for a window, group, textbox or unknown id | pcId=the name of the declaration | RoleOf, DescriptionOf | | name from content is gated by role, as ARIA gates it, so a window is not named after the whole screen
DescriptionOf | Returns the sentence saying why a node exists, taken from the declaration's RATIONALE. | the description as text; an empty text for an unknown id | pcId=the name of the declaration | NameOf, RoleOf | | every declaration carries a rationale, so every node has a description
FocusableIds | Returns the ids of the nodes a keyboard can reach, in reading order. | a list of text; [ ] when none | | ReadingOrder, NodeOf | | it comes from the same FOCUSABLE field that builds the tab ring, so reading order and keyboard order cannot drift
ReadingOrder | Returns what a reader would announce, one line per node, as role and then the quoted name. | a list of text such as button "Confirm"; a node with no name gives its role alone | | Nodes, NameOf | | the lines follow the order of Nodes
ToJSON | Returns the whole tree as JSON text, one object per node, for a tool or an agent to read. | a JSON text; bounds is null when unknown, never a zero rectangle | | SaveTo, Nodes | | the children are stated explicitly, and depth stays so the flat list reads in order
SaveTo | Writes the tree as JSON to a file. | nothing; the file is written | pcPath=the path of the file to write | ToJSON | | an existing file is overwritten
