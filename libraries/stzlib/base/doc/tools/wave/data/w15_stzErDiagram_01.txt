# w15 stzErDiagram -- Name | brief | returns | params | see | warning | note
init | Builds an empty entity-relationship diagram that reads left to right with the er notation, under a title. | nothing; the object is built | pcTitle=the title of the diagram | AddEntity, Relate | | relations are drawn undirected and with orthogonal lines
AddEntity | Declares an entity, a table drawn as a box with a name band and a compartment of attributes. | the diagram itself, so calls chain | pcId=the entity's identifier, which must be new in the diagram; pcName=the name shown in the box | AddJunction, AddKey, Relate | an identifier already in the diagram, in any letter case, raises error stzErDiagram: ... is already an entity of this diagram | AddEntityQ returns the diagram too
AddJunction | Declares an entity drawn for a many-to-many, which is meant to hold a key to each side. | the diagram itself, so calls chain | pcId=the junction's identifier, which must be new in the diagram; pcName=the name shown in the box | AddEntity, AddKeyReferencing | an identifier already in the diagram raises the same error as AddEntity | the rules treat a junction like any entity; only the drawing tells it apart
AddNote | Adds a free note to the drawing; it is not an entity and owes no key. | the diagram itself, so calls chain | pcId=the note's identifier; pcText=the text of the note | AddEntity | | the rules skip a note, and it is not in Entities()
AddKey | Adds a primary-key column to an entity, shown prefixed PK. | the diagram itself, so calls chain | pcEntity=the identifier of an entity already added; pcAttr=the name of the column | AddAttribute, AddKeyReferencing, AddForeignKey | an entity that was not added first raises error stzErDiagram: ... is not an entity of this diagram -- add it first | primary-key columns are listed before the others in the box
AddAttribute | Adds an ordinary column to an entity, neither key nor reference. | the diagram itself, so calls chain | pcEntity=the identifier of an entity already added; pcAttr=the name of the column | AddKey, AddForeignKey | an entity that was not added first raises error stzErDiagram: ... is not an entity of this diagram -- add it first |
AddForeignKey | Adds a column to an entity that refers to another entity, shown as FK column -> target. | the diagram itself, so calls chain | pcEntity=the identifier of the entity that holds the column; pcAttr=the name of the column; pcTarget=the identifier of the entity it refers to | AddKeyReferencing, Relate | an entity that was not added first raises error stzErDiagram: ... is not an entity of this diagram -- add it first; a target that is not an entity is accepted here and reported by the rule foreign_key_resolves | AddForeignKeyXT takes a fourth option [ :Nullable = 1 ] for a column that may be empty
AddKeyReferencing | Adds a column that is both part of the primary key and a reference, as a junction holds. | the diagram itself, so calls chain | pcEntity=the identifier of the entity that holds the column; pcAttr=the name of the column; pcTarget=the identifier of the entity it points at | AddForeignKey, AddJunction | an entity that was not added first raises error stzErDiagram: ... is not an entity of this diagram -- add it first | it is shown as PK FK column -> target
Relate | Draws a relation between two entities with a cardinality read from the first one. | the diagram itself, so calls chain | pcFrom=the identifier of the first entity; pcTo=the identifier of the second entity; pcKind=OneToMany, ManyToOne, OneToOne or ManyToMany, in any letter case | RelateXT, AddForeignKey, GovernanceFindings | a kind such as ManyToFew raises error stzErDiagram: ... is not a cardinality; an identifier that is not an entity raises error stzErDiagram: a relation joins two entities of this diagram | RelateXT takes a fourth option [ :from = :Optional, :to = :Mandatory ] for the participation of each end
Entities | Returns the entities declared so far, each with its id, name and attributes. | a list of hash lists with the keys id, name and attrs; notes are not in it | | Relations, AsRuleGraph | | each attribute carries name, key, fk and nullable
Relations | Returns the relations declared so far, each with its two ends, its kind and its participations. | a list of hash lists with the keys from, to, kind, frompart and topart | | Entities, Relate | | the kind is stored in lower case, such as onetomany; a participation is optional, mandatory or an empty text when nothing was declared
AsRuleGraph | Returns the diagram projected onto a plain stzGraph that the rules read, with keys and foreign keys as node properties. | a stzGraph with one node per entity and note, and one edge per relation | | GovernanceFindings, Entities | | a second relation between the same two entities adds no second edge
GovernanceFindings | Returns every finding of the four schema rules, such as a missing key or a relation no foreign key backs. | a list of findings, each a hash list with rule, subject, where, severity and message; [ ] when there is none | | GovernanceIsSound, AsRuleGraph | | CheckRules gives the same list; a many-to-many with no junction is a warning, an entity with no key is an error
GovernanceIsSound | TRUE if the schema rules report no finding of severity error. | TRUE or FALSE, as 1 or 0 | | GovernanceFindings | | warnings do not make it false: a many-to-many with no junction still answers 1, an entity with no key answers 0; RulesAreSound is the same call
