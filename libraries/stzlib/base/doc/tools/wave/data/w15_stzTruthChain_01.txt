init | Opens a truth narrative about a value, with no atom yet. | nothing; the object is built | pValue=the value the narrative is about, a text, a number or a list | IsA, Holds
IsA | Starts the narrative with the claim that the value is of a kind, named by a descriptor such as Lowercase, Latin or Positive. | the chain itself, so calls chain | pDesc=the descriptor, matched to a predicate named @is followed by it | AndIsA, OrIsA, Holds | an unknown descriptor raises Unknown constraint descriptor when Holds runs, not here; a second IsA does not extend the narrative but starts it again, so only the last starter and what follows decide, while Why still lists both | IsAn is the same call
IsNotA | Starts the narrative with the claim that the value is not of a kind. | the chain itself, so calls chain | pDesc=the descriptor that must fail | IsA, AndIsNotA, Holds
AndIsA | Adds a claim that must hold too: the verdict so far and this kind. | the chain itself, so calls chain | pDesc=the descriptor that must also hold | IsA, OrIsA | | the chain is folded from left to right, so a and b or c reads as (a and b) or c; AndIsAn is the same call
AndIsNotA | Adds a claim that must hold too: the verdict so far and not this kind. | the chain itself, so calls chain | pDesc=the descriptor that must also fail | AndIsA, OrIsNotA
OrIsA | Adds an alternative: the verdict so far or this kind. | the chain itself, so calls chain | pDesc=the descriptor that may hold instead | OrIsNotA, AndIsA | | OrIsAn is the same call
OrIsNotA | Adds an alternative: the verdict so far or not this kind. | the chain itself, so calls chain | pDesc=the descriptor that may fail instead | OrIsA, AndIsNotA
Containing | Starts the narrative with the claim that the text contains a part, or that the list contains an item. | the chain itself, so calls chain | pArg=the part of the text or the item of the list to look for | AndContaining, OrContaining, Holds | the search is case-sensitive; a number as the value never contains anything | the same starting rule as IsA
AndContaining | Adds a claim that must hold too: the verdict so far and the value contains the part. | the chain itself, so calls chain | pArg=the part or item that must be present | Containing, AndNotContaining
OrContaining | Adds an alternative: the verdict so far or the value contains the part. | the chain itself, so calls chain | pArg=the part or item that may be present instead | Containing, OrNotContaining
AndNotContaining | Adds a claim that must hold too: the verdict so far and the value lacks the part. | the chain itself, so calls chain | pArg=the part or item that must be absent | AndContaining, OrNotContaining
OrNotContaining | Adds an alternative: the verdict so far or the value lacks the part. | the chain itself, so calls chain | pArg=the part or item that may be absent instead | OrContaining, AndNotContaining
Holds | Folds the claims once from left to right and returns the verdict; the reason is kept for Why and the verdict is certain. | 1 or 0, numbers; 0 with no claim at all | | Why, IsA | raises when a descriptor names no predicate | IsTrue and Verdict are the same call
Why | Returns the narrated verdict, deciding it first if Holds has not run. | a text such as yes: "ring" is lowercase and is latin | | Holds
NumberOfAtoms | Returns how many claims the narrative holds. | a number | | Content
Content | Returns the claims, each as [ combinator, negated, kind, argument ], the first being the seed. | a list of four-item lists | | NumberOfAtoms, Holds
