# Wave 12 -- stzDrillRemoteResponder. Name | brief | returns | params | see | warning | note
init | Builds the responder that carries a containment plan's actions to a drill's target. | nothing; the object is built | poDrill=the stzSecurityDrill whose target performs the actions; it is held by reference, so keep it alive | LockAccount, stzResponsePlan | | each verb below is one call to the drill's _ContainRemote with the verb in lower case
LockAccount | Asks the drill's target to lock an account, closing its logins and sessions. | nothing | pcTarget=the account to lock | RevokeSession, Contain | the drill raises an error when the target does not answer that it contained it | the target wires this verb and RevokeSession only
RevokeSession | Asks the drill's target to end the sessions of an account. | nothing | pcTarget=the account whose sessions to end | LockAccount | same error as LockAccount when the target does not contain it
RotateSecret | Asks the drill's target to rotate a secret. | nothing | pcTarget=the name of the secret | LockAccount | read from the code, not run: the stock target does not wire this verb and the drill raises an error | the verb is sent as rotatesecret
RevokeCapability | Asks the drill's target to revoke a capability. | nothing | pcTarget=the capability or actor to cut | LockAccount | read from the code, not run: the stock target does not wire this verb and the drill raises an error
ShedSource | Asks the drill's target to block a source, such as a client address. | nothing | pcTarget=the source to block | LockAccount | read from the code, not run: the stock target does not wire this verb and the drill raises an error
QuarantinePart | Asks the drill's target to quarantine a part, such as an agent. | nothing | pcTarget=the part to quarantine | LockAccount | read from the code, not run: the stock target does not wire this verb and the drill raises an error
