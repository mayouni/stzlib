init | Builds a binary logistic regression over a training set; the set must hold exactly two labels. | nothing; the object is built | poTrainingSet=a stzTrainingSet of numeric features with two labels | Train, TrainingSetQ | raises an error naming the count when the set has one label or more than two | the second label to appear is the positive class that Probability measures
TrainingSetQ | Returns the training set the model holds. | a stzTrainingSet | | Train
SetLearningRate | Sets the step size of the gradient descent. | the model itself, so calls chain | n=the learning rate, above 0; 0.1 by default | Train | | a value of 0 or less is ignored without a message
Train | Fits the weights and the bias by gradient descent in the engine, for a fixed number of epochs. | the model itself, so calls chain | nEpochs=the number of passes over the examples | Probability, TrainingAccuracy | raises an error for an empty set and for an example whose width differs from the first | training again refits from zero; with 0 epochs the weights stay 0 and every probability is 0.5
Probability | Returns the model's probability that a feature list belongs to the positive class, the second label. | a number from 0 to 1 | paFeatures=the numbers describing the thing to score, as many as the model was fitted on | Probabilities, Classify | raises an error telling to call Train first, and one naming the width when the query does not match
Probabilities | Returns the probability for many feature lists in one call into the engine. | a list of numbers, one per row; an empty list for no rows | paRows=a list of feature lists, each as wide as the fitted model | Probability | raises an error telling to call Train first, and one naming the row of the wrong width
Classify | Returns the label the model predicts: the second label when its probability reaches 0.5, else the first. | a text, the label | paFeatures=the numbers describing the thing to classify | Probability, Why | raises the errors of Probability
Weights | Returns the fitted weights, one per feature. | a list of numbers; empty before Train | | Bias
Bias | Returns the fitted bias, the term added to the weighted sum. | a number; 0 before Train | | Weights
TrainingAccuracy | Returns the share of the training examples the model labels correctly. | a number from 0 to 1; 0 before Train | | Classify, Train
Why | Returns the last answer of Classify as text: the probability, the epochs, the label chosen, the weights and the bias. | a text; empty before the first Classify | | Classify
