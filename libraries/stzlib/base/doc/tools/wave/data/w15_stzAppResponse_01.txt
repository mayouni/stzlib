init | Builds an empty response with status 200 OK and no headers, ready to be filled and sent. | nothing; the object is built | oClientRef=a legacy slot from before the reactor, kept and never used | Status, Send
Status | Sets the status code and, when text is given, the reason phrase that HttpBytes writes. | the response itself, so calls chain | nCode=the status code, such as 404; cText=the reason phrase; an empty text keeps the previous one | StatusCode, NotFound | an empty cText keeps the previous phrase, so Status(202, "") after Status(201, "Created") reads 202 Created
Header | Adds a header to the response; the same name added twice is written twice, never replaced. | the response itself, so calls chain | cName=the header name; cValue=the header value | Headers, Text
Headers | Returns the headers added so far as a list of [ name, value ] pairs, in order. | a list of [ text, text ] pairs | | Header
StatusCode | Returns the status code, 200 until Status changes it. | a number | | Status
IsSent | TRUE if a body has been buffered by Send, Text, Html or Json. | 1 or 0, numbers | | Send, Body
Body | Returns the buffered body, an empty text before anything is sent. | a text | | Send, HttpBytes
Json | Serializes a value to JSON, adds the application/json content type and buffers it as the body. | nothing | aData=the value: a flat list [ key, value, key, value ] becomes an object, any other list an array | ObjectToJson, Text, Send | a Ring hash list of pairs such as [ :a = 1 ] becomes an array of one-pair objects, not an object; a list of two texts becomes an object; a list of an odd number of texts raises R2; texts are not escaped, so a quote inside one gives invalid JSON; an object inside the data becomes "" | build the object as a flat list and the output is what a client expects
Text | Adds the text/plain content type and buffers the text as the body. | nothing | cText=the text to send | Html, Json, Send
Html | Adds the text/html content type and buffers the markup as the body. | nothing | cHtml=the HTML text to send | Text, Json, Send
Send | Buffers the body and marks the response sent; nothing is written to a socket, and a second call changes nothing. | nothing | cContent=the body, a text or a number, kept as text | HttpBytes, IsSent | once sent, the body can not be replaced, though Status and Header still change the object | the server writes HttpBytes through the reactor
HttpBytes | Renders the whole HTTP/1.1 response: status line, headers, a Content-Length counted in bytes, a blank line, then the body, all with CRLF. | a text | | Send, Status | | a text with an accented e counts 2 bytes in Content-Length
NotFound | Sets status 404 and sends the message as plain text, Not Found when the message is empty. | nothing | cMessage=the text of the page, or an empty text for the default | InternalError, Status
InternalError | Sets status 500 and sends the message as plain text, Internal Server Error when the message is empty. | nothing | cMessage=the text of the page, or an empty text for the default | NotFound, Status
ObjectToJson | Returns the JSON text of a text, a number or a list; this is the simple serializer behind Json. | a text such as {"id":7} | obj=the value to serialize | Json | the same limits as Json: a list that starts with a text is read as key and value pairs, a text is not escaped and an object becomes "" | numbers keep the library's own formatting, so 3.5 reads 3.50
