Init | Builds a runner for one external language: python, r, julia, c, prolog or nodejs, in any letter case. | nothing; the object is built | cLang=the language name | IsLanguageSupported, SetCode | raises error Language 'x' is not supported for any other name
IsLanguageSupported | TRUE if the runner knows the language, whatever the letter case. | TRUE or FALSE | cLang=the language name to test | Init
SetRuntimePath | Sets the program that runs this object's language, in place of the configured path such as d:/nodejs/nodejs-22.20/node.exe. | nothing | cPath=the full path of the interpreter or compiler | RuntimePath, Execute | the path is not checked, so a wrong one shows only when Execute fails | the path is used inside a batch file unquoted, so a folder name with a space breaks the run (use the short 8.3 form)
SetCode | Stores the source text to run, in memory only; nothing is written to disk until Prepare or Execute. | nothing | cNewCode=the program text in the external language, which must assign its answer to the result variable | Code, SetResultVar, Execute
@ | Stores the source text to run, in memory only, exactly as SetCode does. | nothing | cNewCode=the program text in the external language | SetCode, Code
SetVerbose | Turns on or off the report that Execute prints after a run: command, log, working folder and file checks. | nothing | bVerbose=1 to print the report, 0 to keep quiet | IsVerbose, Execute
SetResultVar | Chooses the name of the variable that your external code must fill with its answer; res unless changed. | nothing | cResVar=the variable name in the external language, an empty text being ignored | ResultVar, SetCode
Prepare | Deletes the files of an earlier run, then writes the source file: the translator, your code and the lines that save the answer. | nothing | | PrepareSourceCode, Execute, Code
Execute | Writes the source, runs it with the language's program in the current folder and records the run; the answer is then read with Result. | nothing; the answer is kept in a result file | | Result, Log, CallTrace, Duration | it runs real code with a real program, so run only code you trust; with no code set it writes the source and returns without running; it raises an error naming the log when the program produced no result file, which a syntax error in your code or a missing program also causes; the run script is started by its bare name, so where the environment variable NoDefaultCurrentDirectoryInExePath is 1 the command shell refuses it and the log is missing; the R translator is itself rejected by R 4.5.1, so the language r always fails | files are created in the current folder: temp plus the language's extension, a run script, the result file and log.txt
Run | Writes the source and runs it, exactly as Execute does. | nothing; the answer is kept in a result file | | Execute, Result | same as Execute
Exec | Writes the source and runs it, exactly as Execute does. | nothing; the answer is kept in a result file | | Execute, Result | same as Execute
CleanupFiles | Deletes the source file, the result file and the log file of this object from the current folder. | nothing | | Cleanup, CleanupRequired | a file that is not there is skipped without an error | the run script is deleted by Execute itself
Cleanup | Deletes the source file, the result file and the log file of this object, as CleanupFiles does. | nothing | | CleanupFiles
CleanupRequired | TRUE if the language's settings ask for the files to be deleted once Result has read them. | TRUE or FALSE; FALSE for all six languages as shipped | | CleanupFiles, Result
LastCallDuration | Returns how long the last run took, in seconds. | a number; 0 before any run | | Duration, CallTrace
Duration | Returns how long the last run took, in seconds. | a number; 0 before any run | | LastCallDuration, CallTrace
CallTrace | Returns the history of runs made by this object, oldest first. | a list of hash lists with language, timestamp, duration, log, exitcode and mode | | Trace, LastCallDuration | the exit code is always recorded as 0, even for a run that failed
Trace | Returns the history of runs made by this object, oldest first. | a list of hash lists with language, timestamp, duration, log, exitcode and mode | | CallTrace | same as CallTrace
Result | Reads the answer the external code saved and turns it into a Ring value: a number, a text or a list. | the value; an empty text when the result file is empty | Execute, ResultVar, Log | it evaluates the text of the result file as Ring code, so only run external code you trust; it raises an error quoting the log when the result file does not exist; when the text cannot be evaluated it prints Eval error and returns the raw text | the files are deleted afterwards only if CleanupRequired is TRUE
FileName | Returns the name of the file that holds the answer, such as jsresult.txt for nodejs. | a text | | Result, ResultVar
ResultVar | Returns the name of the variable the external code must assign its answer to. | a text; res by default | | SetResultVar
RuntimePath | Returns the program that runs this object's language, such as d:/nodejs/nodejs-22.20/node.exe. | a text | | SetRuntimePath
IsVerbose | TRUE if Execute prints its report after each run. | TRUE or FALSE | | SetVerbose
SetLogFile | Sets the name of the file that receives the program's printed output and errors; the default is log.txt. | nothing | cFileName=the file name, in the current folder | LogFile, Execute
LogFile | Returns the text the program printed during the last run, errors included. | a text; empty when there is no log file | | Log, SetLogFile
Code | Returns the source text you set, or, when none is set, the text of the source file on disk. | a text; empty when neither exists | | SetCode, PrepareSourceCode | it returns your own code, not the wrapped source that is written to disk
WriteToFile | Writes a text to a file, replacing any earlier content. | nothing | cFile=the path of the file to write; _cContent_=the text to write | ReadFile
ReadFile | Returns the whole text of a file. | a text; empty when the file does not exist or cannot be opened | cFile=the path of the file to read | WriteToFile
BuildCommand | Returns the command line that would start the source file, for example the program path followed by temp.njs. | a text | | Execute, RuntimePath | Execute does not use it and builds its own run script
RecordExecution | Appends one entry to the call trace, taking the duration from the clocks of the last run. | nothing | _cLog_=the text printed by the run to keep in the entry; nExitCode=the exit code to keep in the entry | CallTrace
PrepareSourceCode | Returns the full program text that would be run: the translator, your code and the lines that save the answer. | a text | | Prepare, Code | for prolog it looks for a predicate named compute_result, get_factorials or res and calls the first one it finds
