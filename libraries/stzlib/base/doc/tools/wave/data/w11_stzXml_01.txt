# Wave 11 -- stzXml, stzXmlNode, stzXmlBuilder. Every line was run on invented documents; SaveTo ran in a scratch folder.
init | Builds a document object from XML text; the text is kept as given and parsed again at every read. | nothing; the object is built | pcText=the XML document as text | IsValid, Content, StzXmlQ | | text that is not XML is accepted too: the object is built and IsValid answers 0
Content | Returns the XML text the object was built from, unchanged. | a text | | Pretty, Size
Text | Returns the XML text the object was built from, unchanged. | a text | | Content, Pretty | | it is the same text as Content, not the text inside the elements; use TextAt for that
IsValid | Returns TRUE if the engine accepts the text as one well-formed XML document. | TRUE or FALSE | | Root, Pretty | | a document with a DOCTYPE or an ENTITY declaration is refused on purpose (it closes XXE), so it answers FALSE, as does an unclosed tag or plain text
Root | Returns the name of the root element, or the empty text when the document is not valid. | a text | | RootQ, IsValid
Size | Returns the length of the XML text in bytes. | a number | | Content
TextAt | Returns the text of the element at a path; the empty text when there is no such element or it holds only child elements. | a text | pcPath=a path of element names joined by /, with an optional [n] index counted from 1, such as library/book[2]/title | NumberAt, TextsAt, AttributeAt | | without an index the first match is read; a namespace prefix is not written in a path (use note, not ns:note); &amp; is read back as &
NumberAt | Returns the text of the element at a path read as a number; 0 when there is no element or it is empty. | a number | pcPath=a path, as for TextAt | TextAt, NumberOf | | text that is not a number raises the error Invalid numeric string
AttributeAt | Returns the value of one attribute of the element at a path; the empty text when it is absent. | a text | pcPath=a path, as for TextAt; pcName=the attribute name | TextAt, NamespaceAt | | library/book reads the first book, library/book[2] the second
NamespaceAt | Returns the namespace URI that applies to the element at a path; the empty text when there is none. | a text | pcPath=a path, as for TextAt | AttributeAt, TextAt | | a path is written without the prefix: library/note finds an element written ns:note and answers its URI
NumberOf | Returns how many elements match a path. | a number; 0 when none | pcPath=a path, as for TextAt | Has, TextsAt, NodesQ | | library/book counts the books under library; library/book/title counts only the titles of the first book
Has | Returns TRUE if at least one element matches the path. | TRUE or FALSE | pcPath=a path, as for TextAt | NumberOf, NodeQ
ChildrenOf | Returns the names of the child elements of the element at a path, in document order, repeats included. | a list of texts; empty when there is none | pcPath=a path, as for TextAt | NodesQ, NumberOf | | library with two books and a note gives ["book","book","note"]; a prefix is dropped from the names
TextsAt | Returns the text of each element matching a path, as a list. | a list of texts | pcPath=the path of a repeated element, without an index | TextAt, NumberOf | | it indexes the LAST step, so library/book/title gives only the first book's title; to read all titles walk NodesQ("library/book"); a path with [n] gives one item; elements that hold only children give empty texts
NodeQ | Returns a node object for the element at a path, to read it and its descendants with shorter paths. | a stzXmlNode | pcPath=a path, as for TextAt | NodesQ, RootQ | | the node only remembers the document and the path, so it is also built for a path that matches nothing (Exists answers 0)
NodesQ | Returns one node object for each element matching a path, in document order. | a list of stzXmlNode; empty when none | pcPath=the path of a repeated element, without an index | NodeQ, NumberOf | | library/book gives nodes with paths library/book[1] and library/book[2]
Pretty | Returns the document laid out with two spaces of indent per level and one element per line. | a text; empty when the document is not valid | | PrettyQ, Show | | it ends with a line break; text and attributes are kept, and &amp; stays escaped
SaveTo | Writes the XML text, as given, to a file and returns the object. | the object itself | pcPath=the file to write, which is replaced if it exists | Content, Pretty | | it writes the original text, not the pretty form; the folder must exist
Show | Prints the document, laid out as Pretty does, to the console. | nothing | | Pretty
ToStzString | Returns the XML text as a stzString object, to use the string methods on it. | a stzString | | Content
