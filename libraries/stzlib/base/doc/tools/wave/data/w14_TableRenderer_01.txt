init | Builds a renderer over a table layout, to print the pivot table as text. | nothing; the object is built | oTableConfig=the TableDisplayConfig that holds the data, the settings and the computed widths | RenderTable, TableDisplayConfig | the renderer keeps a COPY of the config: a setting changed on your own config afterwards does not reach it, so build the renderer after the settings are final
RenderTable | Prints the whole table: the headers, the data rows and the footer. | nothing; it prints | | RenderTableHeaders, RenderDataRows, RenderTableFooter | the printed table does not line up today: the top border and the two header lines are as wide as the column groups alone, narrower than the data rows, the separators of the headers do not sit above those of the rows, and the grand-total row is printed under the bottom border; the same on two different pivots
RenderTableHeaders | Prints the top border, the two header lines (first and second column dimension), and the separator above the data rows. | nothing; it prints | | RenderTable, RenderDataRows | the widths used for each data column come from a lookup that always falls back to MinCellWidth, so these lines are narrower than the data rows under them
RenderDataRows | Prints one line per data row, with the first row label shown only when it changes and an empty line between two groups. | nothing; it prints | | RenderTable, RenderEmptyRow | it shows at most two row labels per line, and groups by the first
RenderEmptyRow | Prints one blank line inside the table's side borders, used between two groups of rows. | nothing; it prints | | RenderDataRows
RenderTableFooter | Prints the bottom border, then the total row when the config shows it. | nothing; it prints | | RenderTable, RenderDataRows | the total row is printed below the bottom border, without a left border
