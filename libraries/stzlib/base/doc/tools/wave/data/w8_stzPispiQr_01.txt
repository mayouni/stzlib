WithAlias | Sets the PI-SPI alias of the receiver, the one account the code pays. | the builder itself, so calls chain | pcAlias=the receiver's PI-SPI alias, a UUID of 36 characters such as the twin's BusinessAlias() | InCountry, Payload | an alias that is not in the shape of a UUID is not refused here but when Payload is asked for | the UUID shape is checked, not the version
InCountry | Sets the country of the receiver, in capitals whatever case is given. | the builder itself, so calls chain | pcCountry=the country code, one of BJ BF CI GW ML NE SN TG | WithAlias, Payload | a country outside the union is not refused here but when Payload is asked for
AsStatic | Makes the code a static one, printed once and read for many payments, with channel 000. | the builder itself, so calls chain | | AsDynamic, WithAmount | | in a static code the payer types the amount unless WithAmount fixes it; the last of AsStatic and AsDynamic called wins
AsDynamic | Makes the code a dynamic one, made for one sale, with channel 400. | the builder itself, so calls chain | | AsStatic, WithAmount | | the last of AsStatic and AsDynamic called wins
WithReference | Sets the label the payer's application shows and the receiver reconciles the payment on. | the builder itself, so calls chain | pcLabel=the reference label, 1 to 25 printable ASCII characters | WithAlias, Payload | a label that is empty, over 25 characters or outside printable ASCII is not refused here but when Payload is asked for | the payment received carries it as its motif
WithAmount | Fixes the amount the payer is asked for, which must be whole francs in XOF. | the builder itself, so calls chain | poAmount=the stzAmount to ask for, in XOF, above zero and of at most 13 digits | AsDynamic, Payload | raises an error at once for an amount in another currency or an amount that is not above zero; without it the payer types the amount
WithPurpose | Sets the optional purpose text carried in the additional data of the code. | the builder itself, so calls chain | pcPurpose=the purpose, in printable ASCII | WithReference, WithCustom | a purpose outside printable ASCII is not refused here but when Payload is asked for
WithCustom | Adds an additional-data tag of the receiver's own to the code. | the builder itself, so calls chain | pcTag=the tag, exactly two characters, digits or capital letters; pcValue=the tag's value, as text | WithPurpose, Payload | a tag that is not two characters of digits or capital letters is not refused here but when Payload is asked for | the receiver's tags are written after the standard ones, in the order of their names
Payload | Returns the QR string, whose last four characters are its checksum, after refusing any value that would print a bad code. | a text: the payload string, not a picture | | StzPispiQrParse, WithReference | raises an error naming the cause when AsStatic or AsDynamic was not called, or the alias is not a UUID shape, or the country is outside the union, or the label is missing, over 25 characters or not printable ASCII, or a custom tag is malformed, or the amount has more than 13 digits | the library builds this string and does not draw the picture, and no code it made has been scanned by any wallet or bank app: StzPispiQrParse reads it back and checks the checksum, which proves the string is well formed and not that a phone accepts it
