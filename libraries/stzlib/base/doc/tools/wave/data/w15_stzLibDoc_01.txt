init | Reads the methods and doc blocks of several classes, with those they inherit, into one searchable index, and adds the intent recipes. | nothing; the object is built | paClasses=a list of class names; anything that is not a list builds an empty index | Ask, NumberOfEntries | the recipes are added even for an empty list, but not when the argument is not a list | each method is filed under the class that defines it, so a question can tell which class has it
NumberOfEntries | Returns how many entries the index holds, methods, recipes and test samples together. | a number | | NumberOfClasses, NumberOfRecipes, NumberOfSamples
NumberOfClasses | Returns how many distinct classes own the harvested methods, ancestors that define some included. | a number | | NumberOfEntries
AddTestSamples | Adds the verified calls of the given test topics to the index, so a question can surface a call that is known to run. | nothing; use AddTestSamplesQ to chain | paTopics=a list of test topic names, such as agentic | NumberOfSamples, Ask | | a topic that does not exist adds nothing; the index is rebuilt at the next question
NumberOfSamples | Returns how many test samples were added. | a number | | AddTestSamples
NumberOfRecipes | Returns how many intent recipes are in the index. | a number | | NumberOfEntries
Ask | Returns the five entries that best match a plain-English question across all the classes, best first. | a list of [ class, method, score, description ] rows; the class is (recipe), (example) or (world) for those kinds of entry | pcQuestion=the question in plain English | AskFor, BestMethodFor | | a question with no content word, or no shared word, gives an empty list
AskFor | Returns the entries that best match a question across all the classes, up to a number asked for, best first. | a list of [ class, method, score, description ] rows | pcQuestion=the question in plain English; n=how many entries to return, 5 when below 1 | Ask, BestMethodFor | | a question about an entity of the world, such as what is X, puts a (world) row first; a loaded embedding or reranker model is used when present, and otherwise the word match runs alone
BestMethodFor | Returns the single best match for a question as class.method. | a text such as stzAgentMemory.Fact; empty when nothing matches | pcQuestion=the question in plain English | Ask | | a recipe or a sample can come first, and then the text is its class kind and its title
Show | Prints one line with the number of classes and entries. | the index itself | | NumberOfEntries
