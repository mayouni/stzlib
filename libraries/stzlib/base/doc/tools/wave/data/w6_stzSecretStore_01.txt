init | Builds an empty store, the one registry in which a project governs its secrets. | nothing; the object is built | pcName=the store's name, bound into sealed files as their authenticated context | Register, Reveal
Name | Returns the store's name. | a text | | init
Register | Adds a secret under its own name, in lower case; a name already registered is replaced, which is rotation. | the store itself, so calls chain | poSecret=the stzSecret, or a kind of one such as stzApiKey, to register | Rotate, Revoke, Reveal | a non-object raises an error; the store keeps a COPY of the secret, so changing the original afterwards does not reach it; replacing a name leaves no entry in the access log and none in the ledger | secrets are enumerable by Names and show only their descriptor
Rotate | Replaces the secret registered under the new secret's name, or adds it when the name is new. | nothing; use RotateQ to chain | poNewSecret=the stzSecret that takes the place of the registered one | Register, RotateToFresh | the replacement leaves no entry in the access log and none in the ledger | RotateQ is the same call and returns the store
RotateToFresh | Replaces the value of a secret the store owns with 32 fresh random bytes as 64 hex characters, keeping its kind and name. | the store itself, so calls chain | pcName=the name of the registered secret to renew; poActor=the actor that performs the rotation, which must be effectful and not sandboxed | Rotate, Reveal, Revoke | raises an error for an unknown name, for a refused actor and for a secret whose source is an environment variable, a file or a vault, naming where to rotate it; an actor that is not an object also fails closed, but with R13 Object is required and no refusal is recorded | the access log gets a rotated entry and the ledger a secret.rotated grant; a token's expiry is cleared (rotate_secret_narrated)
Revoke | Removes a secret by name; an unknown name changes nothing. | the store itself, so calls chain | pcName=the name of the secret to remove | Register, Has | the removal leaves no entry in the access log and none in the ledger | the name is matched without regard to case
Has | TRUE if a secret of that name is registered. | TRUE or FALSE | pcName=the secret's name, matched without regard to case | Secret, Names
NumberOfSecrets | Returns how many secrets are registered. | a number | | Names, Has
Names | Returns the names of the registered secrets, in lower case, in the order registered: the project's whole credential surface. | a list of text | | Has, DescriptorOf | | safe to show or log, because no value is in it
Secret | Returns the stored secret object, which is still self-redacting. | a stzSecret, or an empty text when the name is unknown | pcName=the secret's name, matched without regard to case | DescriptorOf, Reveal | | holding it reveals nothing, and it is a copy: changing it does not change the store
DescriptorOf | Returns the redacted descriptor of a registered secret, never its value. | a text such as <secret 'stripe' (apikey) from env:STRIPE_KEY>, or <no secret 'name'> when unknown | pcName=the secret's name, matched without regard to case | Secret, Names
Reveal | Returns a secret's plaintext through the store's governed door: only an effectful, non-sandboxed actor passes, and each try is audited. | a text, the secret's value | pcName=the name of the secret to read; poActor=the actor asking, an object that must be effectful and not sandboxed | RevealVia, IsRevealableBy, AccessLog | raises an error for an unknown name, which is not logged, and for a refused actor, which is logged as refused and recorded in the ledger as secret.reveal.refused | a granted read is logged and recorded as secret.reveal.granted, with the secret's name and never its value
RevealVia | Reveals a secret through a vault resolver for a vault-sourced secret, still gated and audited; for any other secret the resolver is ignored. | a text, the secret's value | pcName=the name of the secret to read; poResolver=the vault resolver object, or an empty text when the secret is not vault-sourced; poActor=the actor asking, an object that must be effectful and not sandboxed | Reveal, IsRevealableBy | an unknown name and a refused actor raise errors, as for Reveal | a superset of Reveal, which calls it with no resolver
IsRevealableBy | TRUE if the actor could reveal that secret; asking changes nothing and leaves no audit entry. | TRUE or FALSE; FALSE for an unknown name or an actor that is not an object | pcName=the secret's name; poActor=the actor to test | Reveal, Secret
SaveSealedTo | Writes the whole store to a file as one encrypted blob keyed by a key secret; literal values are sealed, other sources by pointer only. | the store itself, so calls chain | pcPath=the file to write, overwritten; poKeySecret=the stzSecret whose 64-hex value keys the seal; poActor=the actor performing the seal, effectful and not sandboxed | StzSecretStoreFromSealedFile, SaveSealedToVia, Reveal | a refused actor raises an error and is recorded; an actor that is not an object also fails closed, but with R13 Object is required and no refusal is recorded | an environment, file or vault secret is saved as its pointer, so its plaintext never leaves its source; the store's name is bound as context, so a file cannot pass for another store's
SaveSealedToVia | Writes the sealed store as SaveSealedTo does, with the key secret fetched through a vault resolver. | the store itself, so calls chain | pcPath=the file to write, overwritten; poKeySecret=the stzSecret that keys the seal; poResolver=the vault resolver object, or an empty text; poActor=the actor performing the seal, effectful and not sandboxed | SaveSealedTo, StzSecretStoreFromSealedFileVia | same as SaveSealedTo | the file reads back with StzSecretStoreFromSealedFile
AccessLog | Returns the audit trail: who read, or was refused, which secret, in order. | a list of [ number, actor, secret, outcome ] rows, outcome granted, refused or rotated | | NumberOfAccesses, RefusedAccesses | | an unknown name is not logged; the log lives in the object and dies with it, which is why each entry also reaches the ledger
NumberOfAccesses | Returns how many entries the audit trail holds. | a number | | AccessLog, RefusedAccesses
RefusedAccesses | Returns how many reveals were refused, a misuse signal worth watching. | a number | | AccessLog, stzSecurityPosture
Show | Prints a summary line of the store, then the redacted descriptor of each secret. | nothing; it prints | | DescriptorOf, AccessLog | | no value is printed
