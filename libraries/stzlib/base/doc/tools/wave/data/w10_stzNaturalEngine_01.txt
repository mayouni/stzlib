# Wave 10 -- stzNaturalEngine. Every root called on English narrations (and one Hausa and one SOV check) with invented values. Internal steps of Execute are marked in the note.
init | Builds an engine for one narration in a language and runs it at once, so Result and Answers are ready after the call. | nothing; the object is built | cLang=the language code or name, for example en or hausa, where an unknown one falls back to en and a first argument that is not a language is read as the narration; _cCode_=the narration, or an empty text when the narration comes last; aContext=the context list of [ key, value ] pairs, or an empty list; cContextCode=the narration with {key} holes to fill from the context | Execute, Naturally, NaturallyIn | raises an error when the narration creates no object, for example Naturally("flibber flobber"): the code generator ends with Unsupported object type! | Naturally(code), NaturallyIn(lang, code) and NaturallyXT(context, code) are the functions that build it
InterpolateContext | Returns the narration with every {key} hole replaced by its context value written in Ring form. | a text | _cCode_=the narration with {key} or {a.b.c} holes; aContext=the list of [ key, value ] pairs | GetContextValue, FindContextPlaceholders | a hole with no value does not stay: {zip} became the quoted text not_found, because the lookup answer is compared in its written form with the not-found marker | text values arrive quoted, so write {name} without quotes: '{name}' makes the narration fail to evaluate; keys are matched without regard to case
FindContextPlaceholders | Returns the {...} holes of a narration, but today only when the text starts with the hole. | a list of texts; empty when none is found | _cCode_=the narration to scan | InterpolateContext | Returns [ ] today for a hole that is not at the very start: {a} answers {a}, but x{a}, {a} x and Hello {name} from {c} all answer [ ]; the scan tests the character at i with StzMid(text, i, i) where the third argument is a length, so it can match only at the first character | InterpolateContext does not use it; it finds its holes by its own scan
GetContextValue | Returns the value of a key in the context, following dotted paths such as user.profile.city. | the value, or the marker not_found when the key or a step of the path is missing | _cKey_=the key or the dotted path; aContext=the list of [ key, value ] pairs, nested for paths | NormalizeKey, FindInList, InterpolateContext | | keys are matched without regard to case; the marker is the symbol :NOT_FOUND, which is the text not_found, so a value that is that text cannot be told from a miss
NormalizeKey | Returns a context key in its canonical form: trimmed, first letter upper case, the rest lower case. | a text | _cKey_=the key as written | GetContextValue, FindInList | | uSER with spaces becomes User; an empty text stays empty
FindInList | Returns the value of the first [ key, value ] pair whose normalised key equals the given one. | the value, or the marker not_found | aList=the list of [ key, value ] pairs; _cKey_=the key, already normalised | NormalizeKey, GetContextValue | | the key must be given in normalised form (Name, not name); the source marks it for review
Execute | Reads a narration, turns it into Ring code and runs it, replacing what an earlier run left. | nothing; read the outcome with Result, Answers and Understood | _cCode_=the narration | Process, Result, Analyze | a text that is empty or not a text is ignored and the earlier state stays; a narration that creates no object raises an error | Result is the last thing produced; the code is written by GenerateCodeFromSemantics and run with eval
TokenizeCode | Splits a narration into its raw tokens and clears the state of any earlier run. | nothing; read the tokens with Values | _cCode_=the narration | SmartSplit, Values, Execute | | internal step of Execute; it also maps foreign digits when the language declares a digit map
SmartSplit | Splits a narration into words, keeping a quoted string as one token and a bracketed list as one real list. | a list of tokens | _cCode_=the narration | TokenizeCode, PairedQuoteSections | | internal step of TokenizeCode; Create a list with [1, 2, 3] and 'x y' gives the words, one list [ 1, 2, 3 ] and the text x y without its quotes
LooksEvalSafeList | TRUE if a token is bracketed, or is two digit runs joined by a colon, so it may be evaluated as a list. | 1 or 0 | _cVal_=the token text | SmartSplit | | [1,2] and 3:4 answer 1, abc answers 0
PairedQuoteSections | Returns the start and end positions of the quoted sections, pairing quotes first with second, third with fourth. | a list of [ start, end ] pairs, quotes included | _cCode_=the narration; cQuote=the quote character, a single or a double quote | SmartSplit | | an apostrophe between two letters, as in it's, is part of a word and opens nothing; an unmatched last quote is ignored
NormalizeForeignDigits | Returns the narration with the language's own digits turned into ASCII digits outside quoted text. | a text | _cCode_=the narration | MapDigits, LoadLanguageData | | an Arabic-Indic three becomes 3 when the engine runs ar; the same text for English, which declares no digit map
MapDigits | Returns a piece of text with each digit of the language's digit map replaced. | a text | _cChunk_=the unquoted piece of text | NormalizeForeignDigits | | internal step of NormalizeForeignDigits; the same text for English
StripEdgePunct | Returns a word without the punctuation that clings to its end, such as ? ! . , ; : and the Arabic question mark and comma. | a text; a non-text is returned unchanged | cWord=the word | PhraseResolve | | empty? becomes empty
PhraseResolve | Reads up to three words from a position and returns the method they name together, when no single word is known. | a list [ semantic id, index of the next token, matched phrase ], or [ "", 0, "" ] | nStart=the index of the first word in Values | ToSemantic, ConvertToSemanticTokens | | internal step; after tokenising Create a string with abc Remove its duplicates, position 6 answers METHOD_REMOVEDUPLICATES, 9 and remove duplicates; ignored words such as its are skipped
LoadLanguageData | Reads the language pack of the engine's language: its ignored words, mappings, word-order flags and digit map. | nothing | | FindLanguageDefinition, IgnoredWords, Mappings | | init calls it; an unknown language name was already replaced by en
LangResolvable | TRUE if words the language does not list may still be resolved through the shared lexicon. | 1 or 0 | | LoadLanguageData | | always 1 for English; for another language it is whether a language pack exists
SetStrict | Switches strict mode on or off; when on, a narration with a word the language does not understand raises an error. | nothing | pbOn=1 to be strict, 0 to degrade unknown words to literals | SetAllowedOperations, Unresolved | | the error names each word and the nearest known one, for example Strict natural mode: not understood: 'Flibber'; set it before Execute
SetAllowedOperations | Sets the list of operations a narration may use; anything else raises an error. | nothing | pacIds=the operation ids allowed, for example METHOD_TRIM, where an empty list allows everything | SetStrict, GetSemanticOperation | | a forbidden operation raises Operation not permitted in this world: METHOD_UPPERCASE; set it before Execute
FindLanguageDefinition | Returns the language pack whose code or name matches, or an empty list. | a list; [ ] when no pack matches | _cCode_=the language code or name, for example ha or hausa | LoadLanguageData, Language
Process | Turns the tokens into semantic tokens, raises in strict mode for unknown words, then generates the code and runs it. | nothing | | Execute, GenerateCodeFromSemantics | | internal step of Execute; calling it again runs the generated code again
ConvertToSemanticTokens | Returns the tokens as semantic records and notes which action words could not be understood. | a list of records with type, value and original | | ToSemantic, Unresolved | | internal step of Process; the records are typed semantic or literal, and a literal also carries word, 1 for a bare word and 0 for a quoted text or a list
ShouldTreatAsLiteral | TRUE if the next word must stay data because of the token before it, as after called, use, keep or a method that needs parameters. | 1 or 0 | _aTokens_=the semantic tokens read so far; _cSemantic_=the meaning found for the word; _cValue_=the word | FallbackEligible, ConvertToSemanticTokens | | internal step; it answers 0 for an empty list and 1 after a NAME_INDICATOR
FallbackEligible | TRUE if an unknown word here may be guessed as an action; not right after an object, a value marker or a method awaiting parameters. | 1 or 0 | _aTokens_=the semantic tokens read so far | ShouldTreatAsLiteral | | internal step; it answers 1 for an empty list and 0 after an OBJECT_ token
IsIgnoredWord | TRUE if the word is one the language skips, such as the, it or please, compared without regard to case. | 1 or 0 | cWord=the word | LoadLanguageData, IgnoredWords
ToSemantic | Returns the meaning id of a word in the language, for example METHOD_UPPERCASE, or an empty text if it has none. | a text | cWord=the word | PhraseResolve, Mappings | | a leading @ marks a definition and a trailing @ a recall, giving @METHOD_BOX and METHOD_BOX@; English plurals and verb forms are found, so creates gives CREATE_OBJECT
GenerateCodeFromSemantics | Returns the Ring code the semantic tokens stand for, ending with the line that sets @result. | a text of Ring lines | | Execute, Process | raises Unsupported object type! when the narration created no object, as on an engine that has run nothing | Code is the same call
FindDefineIndex | Returns the token index where a @-marked definition of a method began, or 0 when there is none. | a number | _cSemantic_=the semantic id, for example METHOD_BOX | ToSemantic | | internal; it serves the @Box ... box@ define and recall form
ProcessObjectCreation | Turns a create-object token and its type and value into the line that builds the object. | a list [ :code = Ring line, :next_index = the next token ] | nIndex=the index of the CREATE_OBJECT token | ProcessMethod, GenerateCodeFromSemantics | | internal step; index 1 of Create a string with a.b.c gives oStr = StzStringQ("a.b.c") and next index 4
ProcessObjectNaming | Turns a called or named token into the line that aliases the live object under that name. | a list [ :code, :next_index ] | nIndex=the index of the NAME_INDICATOR token | ProcessObjectSwitch, NamedObjects | | internal step; the alias is o_ followed by the name, and the name is also registered in NamedObjects
ProcessObjectSwitch | Makes a previously named object the live one and returns the index after the name. | a number, the next token index | nIndex=the index of the SWITCH_OBJECT token | ProcessObjectNaming, NamedObjects | | internal step; an unknown name is skipped
ProcessValueKeep | Turns a keep token into the line that binds the current result to a named variable. | a list [ :code, :next_index ] | nIndex=the index of the KEEP_INDICATOR token; pbFromQuery=1 when a query line just set the result, else 0 | ValueRefOf | | internal step; the variable is v_ followed by the name, bound to the live content or to the last answer
ValueRefOf | Returns the variable that a bare word recalls, or an empty text. | a text | paToken=a literal token record with type, value and word | ProcessValueKeep | | only a bare word recalls; a quoted text never does
SanitizedName | Returns a name in lower case, keeping only ASCII letters, digits and underscore. | a text | _cValue_=the name as written | ProcessObjectNaming | | My Basket-1 becomes mybasket1
NamedObjects | Returns the objects named so far with called, as [ name, variable, type ] rows. | a list of rows | | ProcessObjectNaming, ProcessObjectSwitch | | rebuilt each time the code is generated
ProcessMethod | Turns a method token and its parameters into the line that calls it on the live object. | a list [ :code, :next_index ] | nIndex=the index of the METHOD_ token; _cSemantic_=the semantic id of the method | ExtractMethodParameters, GetSemanticOperation | | internal step; METHOD_REPLACE at the right index gives oStr.Replace(".", "_"); an unknown id gives an empty code and the next index
ExtractMethodParameters | Collects the literals that follow a method word as its parameters. | a list [ :params = the values, :next_index ] | nIndex=the index of the METHOD_ token; nParamCount=how many parameters the method takes | ProcessMethod, ExtractParamsBackward | | internal step; in a language whose parameters come before the verb it reads backwards
ExtractParamsBackward | Collects the unused literals before a verb as its parameters, for languages that put them first. | a list [ :params, :next_index ] | nIndex=the index of the verb token; nParamCount=how many parameters the verb takes | ExtractMethodParameters | | internal step; for English it finds none
ProcessMethodWithModifiers | Turns a method token and its modifiers, such as rounded for a box, into the line that calls it. | a list [ :code, :next_index ] | nIndex=the index of the METHOD_ token; _cSemantic_=the semantic id of the method | ProcessMethod, FindDefineIndex | | internal step; Box with the modifier rounded gives BoxXT with Rounded = 1
GetSemanticOperation | Returns the record that tells how a semantic id is turned into Ring code, or an empty list. | a list; [ ] for an unknown id | cSemanticId=the semantic id, for example METHOD_TRIM | ProcessMethod, SetAllowedOperations | | the record carries the method name, the call signature and the types it applies to
Result | Returns the last thing the narration produced: the live object's content, or the answer of a trailing question. | the value; empty before any run | | Answers, Execute
Answers | Returns the answer of every question in the narration, in order. | a list | | AllYes, AnyYes, Result | | Is it lowercase ? Does it contain 'g' ? on ring gives [ 1, 1 ]
AllYes | TRUE if the narration asked at least one question and every answer is yes. | 1 or 0 | | AnyYes, Answers | | a number is yes when not 0, a text when not empty, a list when not empty; 0 when no question was asked
AnyYes | TRUE if at least one answer of the narration is yes. | 1 or 0 | | AllYes, Answers
OriginalCode | Returns the narration as it was given. | a text | | NaturalCode | | with a context it is the text with its {key} holes
NaturalCode | Returns the narration that was run, after the context was filled in. | a text | | OriginalCode, InterpolateContext
Understood | Returns what the engine understood, in plain words and in order, as steps joined by arrows. | a text | | Unresolved, UnderstoodAll | | Create a string with 'ring' Uppercase it reads create a string with ring -> uppercase; read it before trusting a loosely worded narration
SuggestNext | Returns what could be said next after a partial narration, completing a half-typed last word. | a list of texts; empty for anything but a text | _cPartial_=the narration so far | StzNaturalSuggest | | after Create a string with 'abc' it offers uppercase, lowercase, reverse and more; the prefix upp completes to uppercase and its kin
Unresolved | Returns the action words the engine could not understand, each with the nearest known word. | a list of [ word, suggestion ] pairs | | UnderstoodAll, Analyze | | the suggestion is an empty text when nothing is near; the words keep the case they were written in
UnderstoodAll | TRUE if every action word of the narration was understood. | TRUE or FALSE | | Unresolved, Analyze
Analyze | Reads a narration without running it and reports which words would not be understood. | a list [ :understood = 1 or 0, :unresolved = pairs of word and suggestion ] | _cCode_=the narration to check, where an empty or non-text one is reported as understood | Unresolved, StzNaturalLint | | it replaces the engine's narration and tokens but runs no code
Context | Returns the context list the engine was built with. | a list; empty without a context | | InterpolateContext, NaturalCode
EnableDebug | Switches the debug log on and empties it. | nothing | | DisableDebug, DebugLog, AddToDebugLog
DisableDebug | Switches the debug log off, keeping what it holds. | nothing | | EnableDebug, ClearDebugLog
AddToDebugLog | Appends a message with a clock reading to the debug log, only while debug is on. | nothing | cMessage=the message | EnableDebug, DebugLog | | when debug is off the call does nothing
DebugLog | Returns the debug log as records of timestamp and message. | a list of records | | EnableDebug, ClearDebugLog | | a run with debug on logs about twenty lines, starting with Executing natural code
ClearDebugLog | Empties the debug log. | nothing | | DebugLog, ClearDebug
ClearDebug | Empties the debug log. | nothing | | ClearDebugLog | | the same effect as ClearDebugLog
Language | Returns the language the engine runs, as given and lower-cased, or en for an unknown one. | a text | | LoadLanguageData, FindLanguageDefinition | | a name such as hausa stays hausa; it is not turned into the code
IgnoredWords | Returns the words the language skips. | a list of texts | | IsIgnoredWord, LoadLanguageData
Mappings | Returns the language's word-to-meaning table. | a list of [ :natural = word, :semantic = id ] records | | ToSemantic, LoadLanguageData
Values | Returns the raw tokens of the last narration read. | a list of tokens | | TokenizeCode, Tokens
Tokens | Returns the semantic tokens of the last narration, as records of type, value and original. | a list of records | | Values, ConvertToSemanticTokens
Object | Returns the type name of the object the narration is working on, such as stzString. | a text | | NamedObjects | | empty before any object is created
