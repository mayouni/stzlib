init | Builds an empty maker of levelled patterns, with named recursion switched on. | nothing; the object is built | | AddLevel, Reset | | named recursion is on at birth and off after Reset
AddLevel | Adds a top level, a named piece of pattern with no parent, after the levels already added. | nothing | cName=the level's name; _cPattern_=the pattern text of the level | AddChildLevel, AddQuantifier, LevelNames | a name that already exists is added again; the name is matched with case, and the first one is found by the other calls
AddChildLevel | Adds a level inside an existing level, which becomes its parent. | nothing | cParentName=the name of an existing level; cChildName=the name of the new level; _cPattern_=the pattern text of the new level | AddLevel, LevelChildren, LevelParent | an unknown parent raises Parent level 'name' not found!
AddQuantifier | Sets the repeat suffix of a level, such as + or *, replacing the one it had. | nothing | cLevelName=the name of an existing level; cQuant=the suffix text, such as + or {2,3} | AddLevel, Info | an unknown level raises Level 'name' not found!
EnableNamedRecursion | Makes each level a named capture group when the pattern is built. | nothing | | DisableNamedRecursion, Pattern
DisableNamedRecursion | Stops wrapping each level in a named capture group when the pattern is built. | nothing | | EnableNamedRecursion, Pattern
Pattern | Raises error R19 today when a level exists, instead of returning the pattern joined from the root levels. | nothing when it raises; an empty text when there is no level | | SubPattern, LevelNames | tested with one level, with three levels and with a quantifier, and each raised error R19 Calling function with less number of parameters, because the helper calls HasKey with one argument
SubPattern | Raises error R19 today for an existing level, instead of returning the pattern built from that level; an unknown level gives an empty text. | nothing when it raises; an empty text for an unknown level | cLevelName=the name of a level | Pattern, LevelChildren | tested with a top level and with a child level, and both raised error R19, for the same cause as Pattern
LevelNames | Returns the names of all the levels, in the order they were added. | a list of text | | NumberOfLevels, HasLevel
NumberOfLevels | Returns how many levels were added. | a number | | LevelNames
HasLevel | TRUE if a level of that name exists. | 1 or 0 | cName=the level's name, matched with case | LevelNames
LevelParent | Returns the name of the level a level sits inside; an empty text for a top level or an unknown level. | a text | cName=the level's name | LevelChildren, AddChildLevel
LevelChildren | Returns the names of the levels added inside a level, in order; an empty list for an unknown or childless level. | a list of text | cName=the level's name | LevelParent, AddChildLevel
Info | Returns one hashlist per level, with its name, pattern, parent, children and quantifier. | a list of hashlists; the parent and the children are positions in the list, and the parent is an empty text for a top level | | LevelNames, AddQuantifier | | the keys are lower case when listed
Reset | Removes every level and switches named recursion off. | nothing | | init, AddLevel | | after Reset the levels are no longer wrapped in named groups until EnableNamedRecursion is called
pvtFindLevelByName | Returns the position of the first level with that name, or 0 when there is none. | a number | cName=the level's name, matched with case | HasLevel, AddChildLevel | | private
pvtBuildPattern | Raises error R19 today for any existing level, instead of returning its pattern with its children and its quantifier. | nothing when it raises; an empty text for a position out of range | _nLevel_=the position of the level | Pattern, SubPattern | the call HasKey(_level_[:quant]) lacks its second argument, which makes Pattern and SubPattern raise | private
