init | Builds a platform named for one solution, with an empty profile, no world, no governance, no Commons and a trace-level log. | nothing; the object is built | pcName=the platform's name | SetProfile, SetWorld, Log
Log | Returns the structured log in which Build and Deploy record each phase. | a stzLog; its AsText, CountOfLevel and Where read it | | Build, Deploy | | a refused build or deploy is logged at level error before it raises
Name_ | Returns the name the platform was given. | a text | | init
Why | Returns the reason of the last refusal by Granted, RegisterIdentity, OpenSession or CallAcross. | a text, empty before any refusal and emptied by a successful CallAcross | | Granted, CallAcross, OpenSession
SetProfile | Gives the platform the deployment profile whose parts it will build and deploy. | the platform itself, so calls chain | poProfile=a stzPlatformProfile, fully configured | Profile, Build | | the platform keeps a copy, so configure the profile before this call
Profile | Returns the deployment profile the platform owns. | a stzPlatformProfile; an empty text before SetProfile | | SetProfile, HasProfile
HasProfile | TRUE if a deployment profile was set. | TRUE or FALSE | | SetProfile
Build | Checks that the profile is sound and records, for each part, its language and the compiler command that would build it. | the platform itself, so calls chain | | Deploy, BuildReport, BuildCommandFor | it raises an error with no profile and when the profile is unsound, such as no development system or no apps | it does not run any compiler: only the commands are recorded, and a part with no language is recorded as no language declared
IsBuilt | TRUE if Build has completed. | TRUE or FALSE | | Build, IsDeployed
Deploy | Lowers each built part to a target artifact, firmware source for a microcontroller or a manifest otherwise, and records it. | the platform itself, so calls chain | | Build, DeployReport, ArtifactFor, DeployAs | it raises an error until Build has run | the artifact is a text kept in the report: nothing is flashed or uploaded
IsDeployed | TRUE if Deploy has completed. | TRUE or FALSE | | Deploy, IsBuilt
BuildReport | Returns what Build recorded for each part. | a list of lists, each with the part's name, kind, target system, language and compiler command; empty before Build | | Build, LanguageOf, BuildCommandFor
LanguageOf | Returns the language in which a part is built. | a text such as c or ring; empty for a part with no language and for an unknown part | pcName=the part's name, in any case | BuildReport, BuildCommandFor | | the name is matched without regard to case
BuildCommandFor | Returns the compiler command recorded for a part. | a text; no language declared for a part without a language, and empty for an unknown part | pcName=the part's name, in any case | BuildReport, LanguageOf | | the command names the compiler found on the machine of the run, so the text differs between machines
DeployReport | Returns what Deploy recorded for each part. | a list of lists, each with the part's name, kind, target system, the number of rehearsed operations lowered and the artifact text; empty before Deploy | | Deploy, ArtifactFor
ArtifactFor | Returns the artifact that Deploy produced for a part. | a text; empty for an unknown part or before Deploy | pcName=the part's name, in any case | DeployReport, Deploy | | the firmware artifact of an ESP32 part was a small C source with an empty setup and loop
Parts | Returns the parts of the profile. | a list of stzAppProfile objects; empty with no profile | | NumberOfParts, App
NumberOfParts | Returns how many parts the profile holds. | a number; 0 with no profile | | Parts
App | Returns one part of the profile by name. | a stzAppProfile | pcName=the part's name | Parts | it raises an error when no profile was set |
DevelopmentSystem | Returns the system on which the solution is developed. | a stzSystemProfile; an empty text with no profile | | SetProfile
SetWorld | Reads a world's name, reaches, things and screens into the platform, which keeps no reference to the world. | the platform itself, so calls chain | poApp=the stzApp to envelop, already declared | Generate, ServeBody | | call it after the world is declared: later changes to the world do not reach the platform
Generate | Writes one shell file per declared reach of the world and returns their paths: a web page, a desktop launcher or a mobile page. | a list of the written file paths | pWhat=:all for every reach of the world, or one of web, desktop or mobile | SetWorld, ServeBody | it raises an error with no world, with a world that declares no reach, and for an unknown surface | the files go under .stzapp/shells in the current folder, which is created before an unknown surface is refused, and only the two error cases were run because the write is a change on disk
GovernedBy | Returns the name of the governance regime that decides capabilities. | a text; empty when none was set | | SetGovernedBy, Granted
SetGovernedBy | Wires a sealed governance regime and declares the risk tiers of the platform's capabilities into it where it has none. | the platform itself, so calls chain | poGov=the stzGovernance, fully configured, of which the platform keeps a copy | Granted, AddCapability | | the tiers are storage, notifications and offline 1, camera 2, location 3 and payments 4
AddCapability | Requests a device capability for the world and makes it the one SetPurposes fills. | nothing; use AddCapabilityQ to chain | pcCapability=the capability, such as camera or payments, kept in lower case | SetPurposes, Granted, Admissions | | AddCapabilityQ is the same call and returns the platform
SetPurposes | Records the purposes of the capability added last, as a list. | the platform itself, so calls chain | paPurposes=a list of purposes | AddCapability, Admissions | a single text, symbol or number is not wrapped: Admissions then shows [ [ [ ] ] ] for it today, so pass a list | with no capability added yet it does nothing
Granted | TRUE if governance lets the world use a requested capability, a decision of permission against the capability's risk tier. | TRUE or FALSE; Why gives the reason | pcCapability=the capability, in any case | AddCapability, SetGovernedBy, Why | it raises an error with no governance wired or no world attached | a capability never requested is refused with that reason, and a world without the use-<capability> permission is refused too
Admissions | Returns the capabilities requested so far with their purposes. | a list of lists, each a capability and its list of purposes | | AddCapability, SetPurposes
OpenCommonsOn | Wires an open database as the store of identities, sessions, messages and key-value pairs, creating its four tables if absent. | the platform itself, so calls chain | poDb=an open stzDatabase | RegisterIdentity, OpenSession | | the platform shares the database's handle, so keep the original open while the platform runs, and an in-memory database lasts only as long as it does
SetKdfRounds | Sets how many iterations the password hash uses for identities registered afterwards; it starts at 100000. | the platform itself, so calls chain | nRounds=the iteration count, at least 1 | KdfRounds, RegisterIdentity | it raises an error below 1 | lower it only in tests: each identity keeps the rounds it was made with, so raising it later does not lock anyone out
KdfRounds | Returns the iteration count that new identities are hashed with. | a number, 100000 by default | | SetKdfRounds
RegisterIdentity | Stores a user with a random salt and a PBKDF2 hash of the secret, never the secret itself. | TRUE if registered, FALSE if the user already exists (Why says so) | pcUser=the user name; pcSecret=the secret to hash | OpenSession, SetKdfRounds | it raises an error until OpenCommonsOn has run | the stored value reads rounds, salt and hash separated by colons
OpenSession | Checks a user's secret in constant time and opens a session. | a text, the session token beginning with sess_; empty when refused (Why says so) | pcUser=the user name; pcSecret=the secret to check | SessionUser, RegisterIdentity | it raises an error until OpenCommonsOn has run | an unknown user and a wrong secret give the same reason
SessionUser | Returns the user to whom a session token belongs. | a text; empty for an unknown token | pcToken=a token returned by OpenSession | OpenSession | it raises an error until OpenCommonsOn has run |
PostMessage | Stores a message from one user to another. | the platform itself, so calls chain | pcFrom=the sender; pcTo=the recipient; pcBody=the message text | Inbox | it raises an error until OpenCommonsOn has run | quotes in the text are stored correctly, and the sender is not checked against the identities
Inbox | Returns the messages sent to a user, oldest first. | a list of lists, each with the sender and the body; empty when there are none | pcUser=the recipient | PostMessage | it raises an error until OpenCommonsOn has run |
StorePut | Stores a value under a key, replacing any earlier value. | the platform itself, so calls chain | pcKey=the key; pcValue=the value text | StoreGet | it raises an error until OpenCommonsOn has run |
StoreGet | Returns the value stored under a key. | a text; empty for an unknown key | pcKey=the key | StorePut | it raises an error until OpenCommonsOn has run |
ServeBody | Starts the reactor host on 127.0.0.1 to serve the world and, when a Commons is wired, its sessions, messages and store over HTTP. | the platform itself, so calls chain | nPort=the port to listen on, 0 for any free one | HostQ, ServeOne, ServeFor, StopServing | it opens a listening port, so only the refusal with nothing to serve was run: it raises an error with neither a world nor a Commons | the routes are /world and /thing for the world, and /session, /whoami, /message, /inbox and /store for the Commons
HostQ | Returns the serving host, from which the port is read. | a stzAppServer; an empty text before ServeBody | | ServeBody | | only the answer before serving was run
ServeFor | Serves requests for a number of milliseconds. | the platform itself, so calls chain | nMs=how long to serve in milliseconds | ServeBody, ServeOne | it raises an error before ServeBody, which is the only case run | it occupies the thread while it serves
ServeOne | Serves at most one request, waiting up to the given time. | the result of the host's ServeOne | nTimeoutMs=how long to wait for a request in milliseconds | ServeBody, ServeFor | it raises an error before ServeBody, which is the only case run |
StopServing | Stops the serving host; it does nothing when not serving. | the platform itself, so calls chain | | ServeBody | | only the not-serving case was run
PushWorld | Registers a world and its version as active, or updates the version and reactivates it if it is already registered. | the platform itself, so calls chain | pcName=the world's name, matched exactly; pcVersion=its version text | RetireWorld, Worlds | |
RetireWorld | Marks a registered world as inactive; an unknown name changes nothing. | the platform itself, so calls chain | pcName=the world's name | PushWorld, IsActiveWorld | |
IsActiveWorld | TRUE if the world is registered and not retired. | 1 or 0 | pcName=the world's name, matched exactly | PushWorld, RetireWorld | |
Worlds | Returns the registry as a list of lists, each with a world's name, its version and 1 when active or 0 when retired. | a list of lists | | PushWorld
Bond | Declares that one world may attempt an action on another, subject to governance at call time. | the platform itself, so calls chain | pcFrom=the calling world's name, matched exactly; pcTo=the target world, lowered; pcAction=the action, lowered | CallAcross, PushWorld | | a bond is not a permission: CallAcross still asks governance
CallAcross | TRUE if a call from one world to another may go through: both active, a bond naming the action, and governance agreeing. | 1 if allowed, 0 if refused with Why giving the reason | pcFrom=the calling world; pcTo=the target world; pcAction=the action | Bond, PushWorld, Why | with governance wired, an action that has no declared risk tier is refused, so declare the risk of the action in the regime | the world names are matched exactly in the registry, while the action and the target are compared in lower case in the bonds
