init | Creates an empty word counter in the engine, case-insensitive by default, to be fed with chunks of text. | nothing; the counter now exists | | Feed, SetCaseSensitive, Free | the counter lives in the engine until Free is called, since Ring has no destructors |
SetCaseSensitive | Chooses whether words that differ only by case count as different words, and starts a fresh empty counter. | the same object, so calls chain | pCaseSensitive=1 to count The and the apart, 0 to fold them | Feed, StzWordStreamCS | Discards everything fed so far: call it before the first Feed; after it TotalWords answers 0 | StzWordStreamCS(1) builds a case-sensitive one in a single call
Engine | Returns the engine handle of the counter, for the engine functions that take it. | a handle, or "" after Free | | Free | | not meant for normal use
Feed | Adds the words of a chunk of text to the counts, which accumulate over all the chunks. | the same object, so calls chain | pcChunk=a text; a value that is not a text is ignored without a message | FeedMany, TotalWords | | FeedChunk and Add are the same method; words are cut by Unicode word rules, so punctuation is left out and emoji are not words
TopWords | Returns the n most frequent words fed so far, each with its count, the most frequent first. | a list of [ word, count ] pairs; [ ] before anything is fed | n=how many words to return; 0 or more than exist returns all of them | WordsAndTheirCounts, MostFrequentWords | | with case folding a word is shown as it first appeared: feeding the cat, then The, gives the with 2
WordsAndTheirCounts | Returns every different word fed so far with its count, in the order the words first appeared. | a list of [ word, count ] pairs | | TopWords, DistinctWords | | the counts add up to TotalWords
MostFrequentWords | Returns just the n most frequent words, without their counts, the most frequent first. | a list of texts | n=how many words to return | TopWords, MostFrequentWord | |
MostFrequentWord | Returns the single most frequent word fed so far. | a text; "" before anything is fed | | MostFrequentWords | | a tie goes to the word that appeared first
TotalWords | Returns how many words have been fed in all, repeats included. | a number | | DistinctWords | | NumberOfWords is the same method; it answers 0 after Free
DistinctWords | Returns how many different words have been fed. | a number | | TotalWords | | VocabularySize and NumberOfDistinctWords are the same method
Free | Releases the engine counter, which Ring cannot do by itself; safe to call twice. | nothing | | Release | | afterwards the queries answer 0 or [ ] and Feed has no effect: do not use the object again
Release | Releases the engine counter, exactly as Free does. | nothing | | Free | |
