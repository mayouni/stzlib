# Wave 12 -- stzLoweringBridge. Name | brief | returns | params | see | warning | note
init | Builds the bridge, which holds no state. | nothing; the object is built | | LowerOps, Lower
LowerOps | Turns rehearsed operations into the artifact text of a target: firmware source for a microcontroller, else a manifest. | a text; for espidf, esp32, arduino and rtos a firmware sketch where read_pin gives digitalRead and write_pin gives digitalWrite, else a manifest line per operation | paOps=a list of [ capability, verb, arguments, description ] rows; pcOs=the target's operating-system name | Lower, ExtensionFor, stzSystemScope | in firmware, an operation other than the two pin verbs becomes a comment | it takes plain data and builds nothing on the device: flashing is a separate act
Lower | Lowers the rehearsed operations of a scope straight into its target's artifact. | a text, as LowerOps returns; a header with no operations when none was rehearsed | poScope=the stzSystemScope whose rehearsed operations are lowered | LowerOps, RehearsedOperations | operations done on a copy of a scope are not in the scope the part retains | the target is read from the scope's operating-system name
ExtensionFor | Returns the file extension the artifact of a target takes. | a text: .ino for espidf, esp32, arduino and rtos, else .txt | pcOs=the target's operating-system name, matched without regard to case | LowerOps
