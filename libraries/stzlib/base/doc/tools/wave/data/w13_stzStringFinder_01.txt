StartsWith | TRUE if the text begins with the given fragment. | TRUE or FALSE, as 1 or 0 | pcSubStr=the fragment that must come first | EndsWith, StartsWithAny | an empty fragment answers FALSE | StartsWithCS(sub, 0) ignores case

FindAsSections | Returns each occurrence of a fragment as a [start, end] section. | a list of [ number, number ] pairs; [ ] when absent | pcSubStr=the fragment to look for | Find, FindBetweenAsSection | | banana split ANA gives [ [ 2, 3 ], [ 4, 5 ] ] for an
FindBetweenAsSection | Returns the one section lying between the first occurrence of the opening bound and the last occurrence of the closing bound. | a [start, end] pair, excluding the bounds; [ 0, 0 ] when either bound is absent | pcBound1=the opening bound; pcBound2=the closing bound | FindBoundedByAsSections, BetweenNth | it is greedy, so f(x) g(y) h(z) gives [ 3, 13 ], the whole run from the first ( to the last ); a closing bound found before the opening one returns a meaningless section (c then a on abc gives [ 0, 4 ]) | for each pair separately use FindBoundedByAsSections; FindAnyBetweenAsSection is the same call

SubStrings | Returns every substring of the text, one for each start and end position, in start-then-length order. | a list of text holding n times (n+1) divided by 2 items for n characters; [ ] for an empty text | | Duplicates, FindW | | repeated substrings are listed each time (abcab lists a, ab and b twice), and it grows quadratically, so keep it to short texts; SubStringsCS(0) lists the same items
Duplicates | Returns the substrings that occur more than once in the text, overlaps included. | a list of text, in no sorted order; [ ] when nothing repeats | | FindDuplicatesAsSections, SubStrings | | abcab gives a, ab and b; banana contains ana twice, overlapping
FindDuplicatesAsSections | Returns the [start, end] sections of the second and later occurrences of every repeated substring, sorted by start. | a list of [ number, number ] pairs; [ ] when nothing repeats | | Duplicates, FindAsSections | | abcab gives [ [ 4, 4 ], [ 4, 5 ], [ 5, 5 ] ]; a repeated long substring also reports its repeated pieces
FindCharsW | Returns the positions of the characters that satisfy a W condition written over @char. | a list of 1-based positions; [ ] when none | pcCondition=the condition as text, such as @char = 'b' or Q(@char).IsDigit() | FindW, FindSubStringsWCS | FindCharsWCS(cond, 0) ignores its case flag: the same positions come back for 0 and 1 | a1b22c333 with Q(@char).IsDigit() gives [ 2, 4, 5, 7, 8, 9 ]
FindSubStringsWCS | Returns the start positions of every substring that satisfies a W condition written over @substring. | a list of 1-based positions, each listed once; [ ] when none | pcCondition=the condition as text, such as @substring = 'ab'; pCaseSensitive=meant to switch case on or off | FindCharsW, SubStrings | the case flag is ignored: aAbAB with @substring = 'A' gives [ 2, 4 ] for 0 and for 1 | FindW picks this one when the condition names @substring, and FindCharsW otherwise; it tests every substring, so keep texts short
