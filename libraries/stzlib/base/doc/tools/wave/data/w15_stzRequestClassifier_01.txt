init | Creates a classifier with a standard facet catalog and a seeded keyword lexicon, and no rules. | nothing; the object is built | | Classify, SetCatalog
SetCatalog | Binds the classifier to a deployment's own facet catalog, so it only routes to facets that catalog knows. | the classifier itself, so calls chain | poCatalog=a stzFacetCatalog, or any object that answers Has(facet) | CatalogQ, Classify | a model's answer naming a facet the catalog lacks is ignored
CatalogQ | Returns the facet catalog the classifier routes against. | a stzFacetCatalog | | SetCatalog
Why | Returns the reason for the last decision, naming the rule, the lexical hits or the model; empty before the first call. | a text | | Classify, ClassifyText | for an undecidable request it says undecidable
RouteWhenPath | Adds a rule: a request whose path starts with a prefix goes to a facet. | the classifier itself, so calls chain | pcPrefix=the path prefix, matched at the start of the path without regard to case; pcFacet=the facet to route to, stored in lower case | RouteWhenContentType, Classify | rules are tried in the order content type, path, method, and the first match wins
RouteWhenContentType | Adds a rule: a request whose content type contains a text goes to a facet. | the classifier itself, so calls chain | pcType=the text the content type must contain, such as application/pdf; pcFacet=the facet to route to, stored in lower case | RouteWhenPath, Classify | a content type that carries parameters still matches
RouteWhenMethod | Adds a rule: a request with a given HTTP method goes to a facet. | the classifier itself, so calls chain | pcMethod=the method, such as DELETE, matched without regard to case; pcFacet=the facet to route to, stored in lower case | RouteWhenPath, Classify
AddKeyword | Teaches the lexical tier a word or phrase that hints at a facet. | nothing; use AddKeywordQ to chain | pcKeyword=the word that hints a facet, stored in lower case; pcFacet=the facet it hints at, stored in lower case | ClassifyText | capability names are matched automatically; keywords add natural phrasing
SetModelClassifier | Installs an optional classifier function, used only when the rules and the lexicon abstain. | the classifier itself, so calls chain | fClassify=a function that takes the text and returns a facet name, or an empty text | ClassifyText, Why | its answer is used only when the catalog knows the facet
Classify | Routes a request to a facet in three tiers: rules first, then capability-lexical scoring, then the model; returns the facet name. | the facet name as lower-case text; empty when undecidable | pcMethod=the HTTP method; pcPath=the request path; pcContentType=the content type, may be empty; pcBody=the request body text | ClassifyPath, ClassifyText, Why | Why says which tier decided
ClassifyPath | Routes a request known only by its path, as a GET without body. | the facet name; empty when undecidable | pcPath=the request path | Classify
ClassifyText | Routes free text to a facet, by the lexicon and then the model, with no rules. | the facet name; empty when undecidable | pcText=the text to route | Classify, AddKeyword, SetModelClassifier
ClassifyComputationalDomain | Routes a request object by its method, path and body. | the facet name; empty when undecidable | oRequest=an object that answers Method(), Path() and Body(), such as an HTTP request | Classify | the content type is not read, so content-type rules do not apply
