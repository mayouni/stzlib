init | Builds an aligner over a text or over a stzString object, to pad it on the left, on the right or on both sides. | nothing; the object is built | pStrOrStzStrObj=a text, or a stzString object, to align | AlignLeft, AlignedLeft | Given a stzString object, the first in-place edit (AlignLeft, AlignRight, AlignCenter, PadLeft ...) leaves that stzString EMPTY: after oa.AlignRight(8, ".") on a stzString "hello", oa holds "...hello" and the stzString holds ""; the passive forms (AlignedLeft ...) do not do it. Pass the text, os.Content(), to be safe | any other kind of value raises "Can't create stzStringAligner! Parameter must be a string or stzString object."
Content | Returns the text the aligner holds, after any edit made through it. | a text | | NumberOfChars | |
NumberOfChars | Returns how many characters the text holds, counting letters and not bytes. | a number | | Content | | "שלום" counts 4, and with two * on each side 8
IsEmpty | TRUE if the text is empty. | TRUE or FALSE | | NumberOfChars | |
AlignLeft | Pads the text on its right with a character up to a width, so the text sits at the left, in place. | nothing; use AlignLeftQ to chain | n=the width wanted, in characters; pcChar=the padding character, or [ :Using, "*" ] | AlignedLeft, AlignRight, PadRight | | a width not larger than the text changes nothing; an empty padding character changes nothing; a padding text of 2 characters is repeated once per missing character, so "abc" to 6 with ".." gives 9 characters
AlignedLeft | Returns the text padded on its right up to a width, leaving the aligner unchanged. | a text | n=the width wanted, in characters; pcChar=the padding character, or [ :Using, "*" ] | AlignLeft | | "abc" to 6 with "." gives "abc..."; it works with Hebrew and emoji padding too
AlignRight | Pads the text on its left with a character up to a width, so the text sits at the right, in place. | nothing; use AlignRightQ to chain | n=the width wanted, in characters; pcChar=the padding character, or [ :With, "*" ] | AlignedRight, AlignLeft, PadLeft | | a width not larger than the text changes nothing
AlignedRight | Returns the text padded on its left up to a width, leaving the aligner unchanged. | a text | n=the width wanted, in characters; pcChar=the padding character, or [ :With, "*" ] | AlignRight | | "abc" to 6 with "." gives "...abc"
AlignCenter | Pads the text on both sides up to a width, so the text sits in the middle, in place. | nothing; use AlignCenterQ to chain | n=the width wanted, in characters; pcChar=the padding character, or [ :Char, "*" ] | AlignedCenter, PadBoth | | when the padding is odd the extra character goes to the right: "abc" to 6 gives ".abc.."
AlignedCenter | Returns the text padded on both sides up to a width, leaving the aligner unchanged. | a text | n=the width wanted, in characters; pcChar=the padding character, or [ :Char, "*" ] | AlignCenter | | "abc" to 7 with "." gives "..abc.."
PadLeft | Pads the text on its left up to a width, in place, exactly as AlignRight does. | nothing; use PadLeftQ to chain | n=the width wanted, in characters; pcChar=the padding character | AlignRight, PaddedLeft | | "5" padded left to 3 with "0" gives "005"
PadRight | Pads the text on its right up to a width, in place, exactly as AlignLeft does. | nothing; use PadRightQ to chain | n=the width wanted, in characters; pcChar=the padding character | AlignLeft, PaddedRight | |
PadBoth | Pads the text on both sides up to a width, in place, exactly as AlignCenter does. | nothing; use PadBothQ to chain | n=the width wanted, in characters; pcChar=the padding character | AlignCenter, PaddedBoth | |
IsAlignedLeft | TRUE if the text is padded on its right with the character up to the width, or is already that wide or wider. | TRUE or FALSE | n=the width; pcChar=the padding character expected | IsAlignedRight, AlignLeft | | it also answers TRUE for a text already n characters long, whichever side it was padded: "abc..." is aligned left and right at width 6
IsAlignedRight | TRUE if the text is padded on its left with the character up to the width, or is already that wide or wider. | TRUE or FALSE | n=the width; pcChar=the padding character expected | IsAlignedLeft, AlignRight | | it also answers TRUE for a text already n characters long, whichever side it was padded
