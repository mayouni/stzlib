init | Builds the catalog of thirteen Softanza capabilities, each with its differential value as data, so placement decisions can be inspected. | nothing; the catalog is built | | VectorFor, stzDelivery
Records | Returns every capability record. | a list of [ key, display, unique, nature, weight, js, native, embedded, kb ] rows: the lower-case key, the readable name, 1 if Softanza-unique, compute or ergonomic, light, medium or heavy, then the platform support on a browser or mobile, on a server and on a microcontroller, and the engine size in KB | Record, Has
Has | TRUE if the catalog knows a capability of that name. | TRUE or FALSE | pcName=the capability name, such as :PivotTable, matched without regard to case | Record, Records
Record | Returns the record of one capability. | a record as Records lists them; a medium, compute, Softanza-unique record of 8 KB for a name the catalog does not know | pcName=the capability name, matched without regard to case | Has, DisplayOf | | an unknown name is not an error: it is assumed to be platform-weak
DisplayOf | Returns the readable name of a capability, for display. | a text such as PivotTable; the name as given when unknown | pcName=the capability name | Record, SizeOf
SizeOf | Returns the size the capability adds to an on-device engine. | a number of KB; 8 when unknown | pcName=the capability name | Record, VectorFor
VectorFor | Decides how a capability is delivered to a target class, and says why. | a list [ vector, reason ], the vector native, engine, construct or server | pcCap=the capability name; pcClass=the target class: server, mobile, browser or mcu | Record, stzBuildPlan | | a server always gets the engine; a heavy capability goes to the backend; a strong non-unique one defers to the platform
