# w15 stzSoundInstrument -- notes were rendered to memory only; no audio device was opened and nothing was heard by a person (UNPERCEIVED)
init | Looks one of the twenty instruments up by name and makes it ready to render notes. | nothing; the instrument is usable only if the name was found and the sound engine is loaded | pName=the instrument name in any letter case, such as :Oud, one of piano, guitar, harp, bell, epiano, brass, flute, oud, koto, kora, metallophone, drumkit, mezwed, zokra, darbouka, bendir, kakaki, sarewa, imzad or kalangu | IsUsable, ToSoundOfNote | an unknown name does not raise: the instrument is not usable, a refusal is counted and LastError lists the twenty names | StzSoundInstrumentQ builds the same object
IsUsable | TRUE if the instrument was found and can render. | TRUE or FALSE, as 1 or 0 | | init, LastError |
Name | Returns the instrument name as the engine spells it. | the name as text in lower case, such as oud; an empty text when it is not usable | | HonestName |
HonestName | Returns the name the instrument ships under if the ear says the real one is a lie. | the fallback name as text, such as darkpluck for the oud, talkingdrum for the kalangu or fmbell for the bell; an empty text when not usable | | Name | | decided in the engine table before anyone listened
Engine | Returns how the instrument makes its sound. | pluck, bow, wind, fm or membrane, as text; an empty text when not usable | | PitchClass | | the oud is a pluck and the kalangu and the drum kit are membranes
PitchClass | Returns how well the instrument has a pitch. | harmonic, inharmonic or none, as text; an empty text when not usable | | Engine, Range | | harmonic is held to 2 cents, inharmonic is a bar, a bell or a drum whose partials are not multiples, and none is a hi-hat or a snare; the oud is harmonic, the kalangu and the bell inharmonic, the drum kit none
Range | Returns the lowest and highest frequency the instrument plays, in hertz. | a list of two numbers; [ ] when not usable | | PitchClass | | the oud plays 70 to 700 hertz and the kalangu 70 to 400
Velocity | Returns the strength the notes are struck with. | a number above 0 and at most 1, 0.8 by default | | SetVelocity |
SetVelocity | Sets the strength the notes are struck with. | nothing; the velocity is stored. SetVelocityQ returns the instrument for chaining | pnVelocity=the strength, above 0 and at most 1 | Velocity | a value of 0 or less, above 1, or not a number counts a refusal, sets LastError to SetVelocity: a velocity is above 0 and at most 1 and leaves the old value | the next notes use it
ToSoundOf | Renders one note at a frequency as a mono sound at 48000 hertz. | a stzSound; an empty text when the instrument is not usable or the engine refused | pnHz=the frequency in hertz; pnSeconds=how long the note is written for, in seconds | ToSoundOfNote, ToSoundOfGlide | an unusable instrument gives an empty text and LastError says so | the note may ring past its written length: an oud of 0.5 s gave 36000 frames, 0.75 s; the engine tunes each plucked, bowed and wind model by measuring a probe
ToSoundOfNote | Renders one note, given by name, as a mono sound at 48000 hertz. | a stzSound; an empty text when the name is not a note or the instrument cannot render | pcNote=a note name such as A4, C#3, Bb2, D4+50 for a quarter tone above or E4-50 for one below; pnSeconds=how long the note is written for, in seconds | ToSoundOf, StzNoteToHz | a name that is not a note, such as H9, gives an empty text and the error ToSoundOfNote: ... is not a note name | an oud D4 of 1 s gave 60000 frames, 1.25 s, a peak of 0.56 and a pitch read back as 293.67 hertz, against 293.66; E4-50 read back as 320.26, against 320.24
ToSoundOfGlide | Renders one note whose pitch moves from one frequency to another while it sounds. | a stzSound; an empty text when the instrument cannot glide, with the reason in LastError | pnFromHz=the frequency it starts on; pnToHz=the frequency it ends on; pnSeconds=how long the glide lasts, in seconds | ToSoundOf | a pluck and an FM voice hold one pitch and refuse: an oud gave an empty text and the error this instrument cannot glide | a kalangu glide of 0.8 s gave exactly 38400 frames
ToSoundOfStroke | Renders one stroke of a drum, where it is struck, as a sound. | a stzSound; an empty text when the instrument is not struck, the stroke is unknown or this drum has not got it | pStroke=dum, tak or ka on a hand drum, or kick, snare, hihat, openhat, crash, ride, hightom, midtom or floortom on the kit, as a symbol or text; pnHz=the pitch of the drum in hertz; pnSeconds=how long it is written for, in seconds | ToSoundOfGlide, Engine | an instrument that is not a membrane, such as the oud, gives the error ... is not struck; an unknown stroke such as boom gives the error ... is not a stroke; a stroke the instrument does not have, such as crash on a darbouka, gives the error that stroke is not one this instrument has | cymbals ring past the length written: a crash is at least 2 seconds, a ride at least 1.2 and an open hi-hat at least 0.6, which the drum kit gave exactly as 96000, 57600 and 28800 frames

TuningCents | Returns the correction the tuner applied to the last note, in cents. | a number; 0 when none was needed | | RawCents | | the oud D4 needed none
LastError | Returns the reason of the last refusal. | the reason as text; an empty text when the last call went well | | Refusals |
