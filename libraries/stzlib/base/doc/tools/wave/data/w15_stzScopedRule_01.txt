# w15 stzScopedRule

Name_ | Returns the name the rule was built with. | the name as text | | Claim | |
Claim | Returns the sentence the rule asserts. | the sentence as text; an empty text until SetClaim is called | | SetClaim, Check | | the rule governance reports a rule with an empty claim as claim_unstated
Reads | Returns the quantities the rule reads, as it declared them. | a list of text; [ ] until SetReads is called | | SetReads, Writes | |
Writes | Returns the quantities the rule writes, as it declared them. | a list of text; [ ] until SetWrites is called | | SetWrites, Reads | |
Order | Returns when the rule runs relative to other rules. | a number; 0 until SetOrder is called | | SetOrder | | only the comparison with another rule's order means anything
Severity | Returns the severity the rule's findings carry. | the severity as text; error until SetSeverity is called | | SetSeverity, Check | |
SetClaim | Sets the sentence the rule asserts, in words a reader can disagree with. | the rule itself, so calls chain | pcClaim=the sentence, shown in the message of every finding | Claim, SetClaimCheck | |
SetScope | Sets the function that selects the subjects the rule governs in a case. | the rule itself, so calls chain | pFunc=a function of one parameter, the case, that returns a list of subject keys; an anonymous func or the name of a function | SubjectsIn, SetCounter | | with no scope the rule governs nothing and Check judges nothing
SetClaimCheck | Sets the function that judges one governed subject. | the rule itself, so calls chain | pFunc=a function of two parameters, the case and one subject, that returns a pair [ holds, why ] | Check, SetScope | | an answer that is not a pair is read as not holding, with an empty reason
SetCounter | Sets the function that selects the subjects the rule must NOT govern in a case. | the rule itself, so calls chain | pFunc=a function of one parameter, the case, that returns a list of subject keys | CounterSubjectsIn, SetScope | | a counter no case in the governance corpus contains is reported as boundary_unwitnessed
SetReads | Declares the quantities the rule reads, so a stale read can be found from declarations. | the rule itself, so calls chain | pacNames=the quantities read, a list of text | Reads, SetWrites | |
SetWrites | Declares the quantities the rule writes, so a stale read or a contest can be found from declarations. | the rule itself, so calls chain | pacNames=the quantities written, a list of text | Writes, SetReads | |
SetOrder | Sets when the rule runs, relative to the orders of the other rules. | the rule itself, so calls chain | pnOrder=the order, a number; a later rule has a higher number | Order, SetReads | | the governance compares orders and this class never does
SetSeverity | Sets the severity that the findings of the rule carry. | the rule itself, so calls chain | pcSeverity=the severity, such as error or warning | Severity, Check | | the text is not checked
SetUniversal | Declares that the rule has no boundary on purpose, and says why. | the rule itself, so calls chain | pcWhy=the reason, which is required: the rule is universal only while this text is not empty | IsUniversal, SetCounter | | the governance does not report a universal rule as vacuous or as having an unwitnessed boundary
IsUniversal | TRUE if the rule was declared universal with a reason. | TRUE or FALSE, as 1 or 0 | | SetUniversal, UniversalWhy | |
UniversalWhy | Returns the reason the rule was declared universal. | the reason as text; an empty text when it was not | | SetUniversal, IsUniversal | |
SubjectsIn | Returns the subjects the rule governs in a case, by calling its scope. | a list of subject keys; [ ] when no scope was set | poDg=the case to look at, such as a rendered diagram or any object the scope understands | CounterSubjectsIn, Check | |
CounterSubjectsIn | Returns the subjects the rule must not govern that a case contains, by calling its counter. | a list of subject keys; [ ] when no counter was set | poDg=the case to look at | SubjectsIn, SetCounter | |
Check | Judges every governed subject of a case and returns a finding for each that fails the claim. | a list of findings, each a hash list with rule, subject, where, severity and message; [ ] when all hold | poDg=the case to judge; pcWhere=the name of the case, put before the subject in the finding's where | SubjectsIn, SetClaimCheck | | the message is the claim, then the reason; with no claim check set it judges nothing and answers [ ]; subject is always plastic
