# Wave 11 -- stzListReplacer. Every line was run on invented lists; the object holds the list and the methods change it in place.
init | Builds a replacer over a list or over a stzList object; anything else raises an error. | nothing; the object is built | pListOrObj=a list, or a stzList object, whose items will be changed | Content, NumberOfItems | | a list is wrapped in a new stzList; the error text is Can't create stzListReplacer! Parameter must be a list or stzList object.
Content | Returns the list as it stands after the changes made so far. | a list | | NumberOfItems, AllOccurrencesReplaced
NumberOfItems | Returns how many items the list has. | a number | | Content, IsEmpty
IsEmpty | Returns TRUE if the list has no item. | TRUE or FALSE | | NumberOfItems
ReplaceAllItems | Sets every item of the list to the new item, whatever it was. | nothing; the list is changed in place | pNewItem=the item every position receives | ReplaceAllOccurrences, ReplaceAnyItemAtPositions | | ["a","b"] with "x" gives ["x","x"]
ReplaceAllOccurrences | Swaps every item equal to pItem for the new item; text is compared with case. | nothing; the list is changed in place | pItem=the item to look for; pNewItem=the item put in its place | ReplaceFirstOccurrence, ReplaceLastOccurrence, AllOccurrencesReplaced | | ["a","b","a","A"] with "a" -> "z" gives ["z","b","z","A"], and a list item such as [1] can be replaced by a list [7,8]
ReplaceAll | Swaps every item equal to pItem for the new item; text is compared with case. | nothing; the list is changed in place | pItem=the item to look for; pNewItem=the item put in its place | ReplaceAllOccurrences, ReplaceFirstOccurrence | | it does what ReplaceAllOccurrences does
Replace | Swaps every item equal to pItem for the new item; pItem can be written :Each = item. | nothing; the list is changed in place | pItem=the item to look for, or :Each = item; pNewItem=the item put in its place | ReplaceAllOccurrences, ReplaceFirstOccurrence | | text is compared with case
AllOccurrencesReplaced | Returns a copy of the list with every item equal to pItem swapped for the new item, leaving the object unchanged. | a list | pItem=the item to look for; pNewItem=the item put in its place | ReplaceAllOccurrences, Content | | unlike ReplaceAllOccurrences, Content still shows the old list afterwards
ReplaceAnyItemAtPosition | Puts the new item at position n, whatever is there; a position outside the list changes nothing. | nothing; the list is changed in place | n=the position, counted from 1; pNewItem=the item to put there | ReplaceThisItemAt, ReplaceAnyItemAtPositions | | no error is raised for a position such as 9 on a five-item list
ReplaceItemAtPosition | Puts the new item at position n, whatever is there; a position outside the list changes nothing. | nothing; the list is changed in place | n=the position, counted from 1; pNewItem=the item to put there | ReplaceAnyItemAtPosition, ReplaceAt | | it does what ReplaceAnyItemAtPosition does
ReplaceAt | Puts the new item at position n, whatever is there; a position outside the list changes nothing. | nothing; the list is changed in place | n=the position, counted from 1; pNewItem=the item to put there | ReplaceAnyItemAtPosition, ReplaceAnyItemAt | | it does what ReplaceAnyItemAtPosition does
ReplaceNthOccurrence | Swaps the n-th item equal to pItem for the new item, counting from the start; text is compared with case. | nothing; the list is changed in place | n=which occurrence, counted from 1; pItem=the item to look for; pNewItem=the item put in its place | ReplaceFirstOccurrence, ReplaceLastOccurrence, ReplaceNextNthOccurrence | | when there are fewer than n occurrences nothing changes
ReplaceFirstOccurrence | Swaps the first item equal to pItem for the new item; text is compared with case. | nothing; the list is changed in place | pItem=the item to look for; pNewItem=the item put in its place | ReplaceLastOccurrence, ReplaceNthOccurrence, ReplaceAllOccurrences | | when pItem is absent nothing changes
ReplaceLastOccurrence | Swaps the last item equal to pItem for the new item; text is compared with case. | nothing; the list is changed in place | pItem=the item to look for; pNewItem=the item put in its place | ReplaceFirstOccurrence, ReplaceNthOccurrence, ReplaceAllOccurrences | | when pItem is absent nothing changes
ReplaceSection | Cuts the items from position n1 to n2 and puts ONE new item in their place, even when that item is a list. | nothing; the list is changed in place | n1=the first position of the section; n2=the last position of the section; pNewItem=the single item that takes the section place, or :By = item | ReplaceSectionByMany, ReplaceAnyItemAtPositions | | [1,2,3,2,1] with positions 2 to 4 and [7,8] gives [1,[7,8],1]; n1 below 1 is read as 1 and n2 past the end as the last position
ReplaceSectionByMany | Cuts the items from position n1 to n2 and splices the given items in their place, one level flat. | nothing; the list is changed in place | n1=the first position of the section; n2=the last position of the section; paNewItems=the items to splice in, or :By = list | ReplaceSection, ReplaceManyByMany | | [1,2,3,2,1] with positions 2 to 4 and [7,8] gives [1,7,8,1]; n1 below 1 is read as 1 and n2 past the end as the last position
ReplaceManyByMany | Swaps each item of paItems for the item at the same place in paNewItems, everywhere in the list. | nothing; the list is changed in place | paItems=the items to look for; paNewItems=the items that replace them, one for one | ReplaceAllOccurrences, ReplaceByMany | | the two lists must have the same size, otherwise the error Incorrect values! paItems and paNewItems must have the same size. is raised; an empty list on either side does nothing
ReplaceAnyItemAtPositions | Puts the new item at every given position; positions outside the list are skipped. | nothing; the list is changed in place | panPos=the positions, counted from 1; pNewItem=the item to put there, or :With = item | ReplaceAnyItemAtPosition, ReplaceThisItemAtPositions | | [1,2,3,2,1] with [1,9] and 0 gives [0,2,3,2,1]
ReplaceAnyItemsAtPositions | Puts the new item at every given position; positions outside the list are skipped. | nothing; the list is changed in place | panPos=the positions, counted from 1; pNewItem=the item to put there, or :With = item | ReplaceAnyItemAtPositions, ReplaceAtPositions | | it does what ReplaceAnyItemAtPositions does
ReplaceItemsAtPositions | Puts the new item at every given position; positions outside the list are skipped. | nothing; the list is changed in place | panPos=the positions, counted from 1; pNewItem=the item to put there, or :With = item | ReplaceAnyItemAtPositions, ReplaceAtPositions | | it does what ReplaceAnyItemAtPositions does
ReplaceAtPositions | Puts the new item at every given position; positions outside the list are skipped. | nothing; the list is changed in place | panPos=the positions, counted from 1; pNewItem=the item to put there, or :With = item | ReplaceAnyItemAtPositions, ReplaceItemsAtPositions | | it does what ReplaceAnyItemAtPositions does
ReplaceAnyItemAt | Puts the new item at position n, whatever is there. | nothing; the list is changed in place | n=the position, counted from 1; pNewItem=the item to put there | ReplaceAnyItemAtPosition, ReplaceAnyItemAtPositions | | it is ReplaceAnyItemAtPositions with one position
ReplaceThisItemAtPositions | Puts the new item at the given positions, but only where the item now there equals pItem. | nothing; the list is changed in place | panPos=the positions to examine, counted from 1; pItem=the item that must be there; pNewItem=the item to put there, or :With = item | ReplaceTheseItemsAtPositions, ReplaceAnyItemAtPositions | | text is compared with case; [1,2,3,2,1] with [1,2,3], 2 and 0 gives [1,0,3,2,1]
ReplaceThisItemAt | Puts the new item at position n, but only if the item now there equals pItem. | nothing; the list is changed in place | n=the position, counted from 1; pItem=the item that must be there; pNewItem=the item to put there | ReplaceThisItemAtPositions, ReplaceAnyItemAt | | at a position holding another item nothing changes
ReplaceTheseItemsAtPositions | Puts the new item at the given positions, but only where the item now there is one of paItems. | nothing; the list is changed in place | panPos=the positions to examine, counted from 1; paItems=the items that may be replaced; pNewItem=the item to put there, or :With = item | ReplaceThisItemAtPositions, ReplaceAnyItemAtPositions | | text is compared with case; [1,2,3,2,1] with [1,2,3,4], [2,3] and 0 gives [1,0,0,0,1]
ReplaceByMany | Swaps the occurrences of pItem, in order, for the items of paNewItems, one each; extra occurrences are left alone. | nothing; the list is changed in place | pItem=the item to look for; paNewItems=the replacements, used in order | ReplaceItemByManyXT, ReplaceManyByMany, ReplaceOccurrencesByMany | | [1,2,3,2,1] with 2 and [7,8] gives [1,7,3,8,1] and with [7] gives [1,7,3,2,1]
ReplaceItemByManyXT | Swaps the occurrences of pItem, in order, for the items of paNewItems, starting over when they run out. | nothing; the list is changed in place | pItem=the item to look for; paNewItems=the replacements, reused round-robin | ReplaceByMany, ReplaceAtByManyXT | | [1,2,3,2,1] with 2 and [7] gives [1,7,3,7,1]; with 1 and [7,8,9] gives [7,2,3,2,8]
ReplaceOccurrencesByMany | Puts the items of paNewItems, in order, at the given positions; surplus positions are left alone. | nothing; the list is changed in place | panPos=the positions, counted from 1; paNewItems=the items, one per position | ReplaceByMany, ReplaceAnyItemAtPositionsByMany | | [1,2,3,2,1] with [1,3,5] and [7,8] gives [7,2,8,2,1]
ReplaceItemAtPositionsByMany | Puts the items of paNewItems, in order, at those given positions that hold pItem; surplus positions are left alone. | nothing; the list is changed in place | panPos=the positions to examine, counted from 1; pItem=the item that must be there; paNewItems=the replacements, used in order | ReplaceTheseItemsAtPositionsByMany, ReplaceByMany | | [1,2,3,2,1] with [2,4,5], 2 and [7,8] gives [1,7,3,8,1]
ReplaceTheseItemsAtPositionsByMany | Does ReplaceItemAtPositionsByMany for each item of paItems in turn, each time giving paNewItems from their start. | nothing; the list is changed in place | panPos=the positions to examine, counted from 1; paItems=the items that may be replaced; paNewItems=the replacements, restarted for each item | ReplaceItemAtPositionsByMany, ReplaceAnyItemAtPositionsByMany | | [1,2,3,2,1] with [1,2,3,4,5], [1,3] and [7,8,9] gives [7,2,7,2,8]
ReplaceAnyItemAtPositionsByMany | Puts the items of paNewItems at the given positions in order, whatever is there, stopping at the shorter of the two lists. | nothing; the list is changed in place | panPos=the positions, counted from 1; paNewItems=the items, one per position | ReplaceOccurrencesByMany, ReplaceAtByManyXT | | [1,2,3,2,1] with [1,3,5] and [7,8] gives [7,2,8,2,1]
ReplaceAnyItemsAtPositionsByMany | Puts the items of paNewItems at the given positions in order, whatever is there, stopping at the shorter of the two lists. | nothing; the list is changed in place | panPos=the positions, counted from 1; paNewItems=the items, one per position | ReplaceAnyItemAtPositionsByMany, ReplaceOccurrencesByMany | | it does what ReplaceAnyItemAtPositionsByMany does
ReplaceAtByManyXT | Puts the items of paNewItems at the given positions in order, starting over when they run out, whatever is there. | nothing; the list is changed in place | panPos=the positions, counted from 1; paNewItems=the items, reused round-robin | ReplaceAnyItemAtPositionsByMany, ReplaceItemByManyXT | | [1,2,3,2,1] with [1,2,3,4] and [7,8] gives [7,8,7,8,1]
ReplaceItemsW | Swaps every item that satisfies a condition written with @item for a new value. | nothing; the list is changed in place | pWhere=the condition, such as '@item > 1', or :Where = condition; pBy=the value put in place, or :By = value | ReplaceAllOccurrences, ReplaceAnyItemAtPositions | | [1,2,3,2,1] with '@item > 1' and 0 gives [1,0,0,0,1]
ReplaceNextNthOccurrence | Swaps the n-th item equal to pItem found at or after position pnStartingAt; text is compared with case. | nothing; the list is changed in place | n=which occurrence after the start, counted from 1; pItem=the item to look for; pNewItem=the item put in its place; pnStartingAt=the position where the search begins | ReplaceNthOccurrence, ReplaceFirstOccurrence | | [1,2,3,2,1] with 1, 2, 9 and 3 gives [1,2,3,9,1] because the 2 at position 2 lies before the start
