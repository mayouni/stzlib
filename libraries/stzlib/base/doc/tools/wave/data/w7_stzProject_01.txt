init | Opens a level project's folder, reading its guard and the promises the guard must keep when they are there. | nothing; the object is built | pcFolder=the project's folder: its last segment is the project's id | HasGuard, Check, ProveItself | | a project is a folder: brief.<lang>.md, guard.ring (the court, which reads the learner's folder and prints its findings), promise.ring (the #--> lines to print for a pass), and wrong/ and right/ sample folders
Id | Returns the project's identifier, which is the last segment of its folder's path. | a text such as project-s0 | | Folder
Folder | Returns the project's folder path, without a trailing slash. | a text | | Id, WrongSamples
HasGuard | TRUE if the project has a guard and at least one promise, so that a level can be earned by it. | TRUE or FALSE | | Check, Promises | | Check raises an error when it is FALSE
Brief | Returns what the project asks of the learner, from brief.<lang>.md, with line ends made LF. | a text, markdown | pcLang=the language of the brief: en, fr, ar or ha | HasBriefIn | raises an error naming the project and the language when that brief does not exist | the fr, ar and ha briefs are drafts, not yet reviewed by a native speaker (0 of 35 units reviewed in each language), and carry a draft notice at their head
HasBriefIn | TRUE if the project has a brief file for the language. | TRUE or FALSE | pcLang=the language code, such as fr | Brief
Promises | Returns the lines the guard must print for a pass, read from the #--> lines of promise.ring. | a list of text; [ ] when the project has no promise file | | HasGuard, Check
Check | Judges a learner's project folder by running the project's guard on it in a fresh process with Softanza loaded. | the stzExerciseCheck of the run: Passed(), Output() (what the guard printed) and Why() (a sentence for the learner) | pcLearnerFolder=the learner's project folder to judge | ProveItself, HasGuard, stzLearner | raises an error when the project has no guard; a folder that does not exist is not refused: the guard runs and prints its own missing line, so the check does not pass; the guard runs on the desktop only | the evidence it carries is the hash of every file in the folder, so a folder changed after a pass no longer counts; CheckMany(pacFolders) judges several folders in one run and returns the list of checks (it is not a root of its own in the record, ProveItself uses it)
WrongSamples | Returns the paths of the learner folders under wrong/ that the guard must refuse, sorted by name. | a list of text; [ ] when there is no wrong folder | | RightSamples, ProveItself
RightSamples | Returns the paths of the learner folders under right/ that the guard must accept, sorted by name. | a list of text; [ ] when there is no right folder | | WrongSamples, ProveItself
ProveItself | Runs the guard on every wrong and right sample and reports whether it refused each wrong one and accepted each right one. | a hash list [ :wrong, :wrongrefused, :right, :rightaccepted, :failures, :checks ]: counts, then sentences naming each sample misjudged, then [ path, check ] pairs | | Check, WrongSamples, RightSamples | | a project that accepts a wrong sample or refuses a right one is a red guard, and failures says which
