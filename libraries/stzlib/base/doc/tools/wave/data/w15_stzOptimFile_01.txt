init | Opens a .zopt model: reads and parses the file when a path is given, and builds an empty reader for an empty path. | nothing; the object is built | pcPath=the .zopt file to read, or an empty text to give the text later with SetText | SetText, ToModel | raises stzOptimFile: no file at the path when the file is missing; a file with faults does not raise, its faults are listed by Findings
SetText | Reads the model from a text instead of a file and parses it again, replacing what was read before. | the file reader itself, so calls chain | pcText=the whole .zopt text | Findings, ToModel, StzOptimModelFromZopt
Findings | Returns the faults found in the text, one sentence each, naming the line when there is one. | a list of text; [ ] for a valid model | | IsValid, CiteFindings | | a reader that has read nothing has no findings and so counts as valid
IsValid | TRUE if parsing found no fault, which says nothing yet about whether the model can be solved. | 1 or 0, numbers | | Findings, ToModel | a reader built with an empty path and no SetText also answers 1; ToModel then raises about the missing variables
CiteFindings | Returns the faults as one text, each on its own line after a dash, ready to print. | a text; empty for a valid model | | Findings
Name_ | Returns the model's name from its model: line, an empty text when there is none. | a text | | SetText
SetsDeclared | Returns the sets declared by set lines, with their members in lower case. | a list of [ name, [ members ] ] rows | | MembersOf
MembersOf | Returns the members of a declared set, in the order written, in lower case. | a list of text; [ ] for an unknown set | pcSet=the set's name, in any case | SetsDeclared, ParamValue
ParamValue | Returns the value an indexed parameter gives to one member of its set. | a number; 0 when the parameter or the member is unknown | pcParam=the parameter's name; pcMember=the member of the set it is indexed by, in any case | MembersOf, ToModel | an unknown name is not reported, it reads 0 | names and members are matched without regard to case
ToModel | Expands the families into ordinary variables and constraints and returns the model; a faulty file is refused. | a stzOptimModel | | Save, ToZopt, Findings | raises stzOptimFile: this model was REFUSED and the findings, when the text has faults | variable make[chairs] becomes make_chairs, a sum becomes its terms one by one and a forall one constraint per member
ToZopt | Returns the expanded model written back as a flat .zopt text with no families; reading it again gives the same model. | a text | | ToModel, Save | raises like ToModel for a faulty file | the text is the expansion, not a copy of the original file
Save | Writes the expanded model to a file, adding the .zopt extension when the path lacks it. | the path written | pcPath=where to write; .zopt is added when missing | ToZopt, init
