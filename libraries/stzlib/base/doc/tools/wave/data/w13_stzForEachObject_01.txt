init | Builds a loop over a list or a text that runs a piece of Ring code once per item, with one or several loop variables. | nothing; the object is built | p=the name of the loop variable as text, or a list of names when each item is itself a list; pIn=the data, written as a named parameter :In = ... holding a list (or a text, for a single variable) | Exec, ExecN, v | Raises an error unless pIn is written as :In = ...; with several names every item of the list must be a list with as many values as there are names; a text can only be used with a single name and is walked byte by byte, so a multi-byte letter splits into broken pieces; an empty list or text builds the loop, but running it raises an index error | use @ForEach(p, pIn) to build it
@Vars | Returns the names of the loop variables, in lowercase. | a list of text, such as [ "char", "number" ] | | @NumberOfVars, @Content
@VarNames | Returns the names of the loop variables, in lowercase. | a list of text, such as [ "item" ] | | @NumberOfVars, @Content
@NumberOfVars | Returns how many loop variables the loop has. | a number | | @Vars
@NumbersOfVarNames | Returns how many loop variables the loop has. | a number | | @Vars
@Values | Returns the data exactly as it was given in the :In = ... part. | the list, or the text, given at construction | | @Content, @NumberOfIterations
@Content | Returns each loop variable paired with the list of all its values, one pair per variable. | a list of pairs, such as [ [ "char", [ "A", "B" ] ], [ "number", [ 1, 2 ] ] ] | | @Values, @Vars
@VarValues | Returns each loop variable paired with the list of all its values. | a list of pairs such as [ [ "item", [ "a", "b" ] ] ] | | @Content
@VarsAndValues | Returns each loop variable paired with the list of all its values. | a list of pairs such as [ [ "item", [ "a", "b" ] ] ] | | @Content
@VarsAndTheirValues | Returns each loop variable paired with the list of all its values. | a list of pairs such as [ [ "item", [ "a", "b" ] ] ] | | @Content
@VarVal | Returns each loop variable paired with the list of all its values. | a list of pairs such as [ [ "item", [ "a", "b" ] ] ] | | @Content
@NumberOfIterations | Returns how many items the data holds, which is how many times a full run executes the code. | a number; the length in bytes for a text | | @Iterations, Exec
@NumberOfValues | Returns how many items the data holds. | a number | | @NumberOfIterations

@Iterations | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations
@Scope | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations
@SetScope | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations
@IterateOn | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations
@IterateOnThesePositions | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations
@IterateOnlyOn | Restricts the next runs of Exec to these positions, in this order. | nothing | panPos=a list of positions in the data | @SetIterations

Exec | Runs a piece of Ring code once for each item in scope, with the loop variables set to that item's values. | nothing | pcCode=the Ring code as text, such as '? v(:Item)'; or a pair [ n, code ] which is run like ExecN | ExecN, v, @SetIterations | with several variables each name is a variable inside the code (Char, Number); with a single variable the name is NOT bound and using it raises an uninitialized-variable error, so read the item with v; running over an empty list or text raises an index error | the code is evaluated in the method, so collect results in a global variable
Execute | Runs a piece of Ring code once for each item in scope, with the loop variables set to that item's values. | nothing | pcCode=the Ring code as text | Exec | with a single loop variable use v(:Name), as the name itself is not bound
