init | Builds an empty named set of governance predicates: code rules and agent-graph invariants. | nothing; the object is built | pcName=the set's name, written into a saved file | AddRule, AddInvariant, Save
SetName | Changes the name under which the set is saved, replacing the one it was built with. | the set itself, so calls chain | pcName=the new name | Name_ | | LoadFrom also replaces the name with the one in the file
Name_ | Returns the name of the set. | a text | | SetName
AddRule | Adds a code rule to the set by name; adding one already held changes nothing. | nothing; use AddRuleQ to chain | pcRule=the name of a house code rule, in any case, as StzCodeRuleNames lists them | Rules, EnforceOnCode | raises an error naming StzCodeRuleNames for a rule it does not know | names are stored in lower case
AddInvariant | Adds an agent-graph invariant to the set by name; adding one already held changes nothing. | nothing; use AddInvariantQ to chain | pcInv=the name of a governance invariant, in any case, as StzGovernanceInvariantNames lists them | Invariants, EnforceOnGraph | raises an error naming StzGovernanceInvariantNames for an invariant it does not know | names are stored in lower case
Rules | Returns the code rules in the set, in the order added. | a list of text | | AddRule, EnforceOnCode
Invariants | Returns the agent-graph invariants in the set, in the order added. | a list of text | | AddInvariant, EnforceOnGraph
Seal | Returns the SHA-256 digest of the set's body: its name, its rules and its invariants. | a text of 64 hexadecimal characters | | Verify, Save | the seal is a plain unkeyed digest: it shows that a file was edited without its seal line being redone, and it does not authenticate who wrote the file, since anyone who edits the body can recompute the seal | a reviewer's signature has to be added outside the file
LoadFrom | Reads a saved .zrlz file into this set: the name, the rules, the invariants and the seal recorded in it. | the set itself, so calls chain | pcFile=the full path of the file, extension included | Save, Verify | raises the file error when the file is missing, and the unknown-rule error when it names a rule or invariant that does not exist, so a file cannot add a rule the library lacks | rules and invariants are added to those already held, not substituted for them
Save | Writes the set to a .zrlz file as readable lines ending with its seal, adding the extension when it is missing. | a text, the path written | pcFile=the path of the file to write | LoadFrom, Seal | | LoadFrom does not add the extension, so pass it the returned path
Verify | TRUE if a seal was loaded and it matches the body now held. | TRUE or FALSE; FALSE for a set built in memory, which has loaded no seal | | Seal, LoadFrom | a file whose rules were edited without redoing the seal answers FALSE, and one edited with the seal recomputed answers TRUE | it checks integrity, not authorship
EnforceOnCode | Runs the house code checks on a source text and keeps only the findings of this set's rules. | a list of hash lists [ :rule, :line, :severity, :message ]; empty when the set holds no rules | pcSource=the Ring source text to check | AddRule, EnforceOnGraph | | a source that breaks a rule the set does not hold gives no finding
EnforceOnGraph | Runs the agent-graph checks on a graph and keeps only the findings of this set's invariants. | a list of hash lists [ :invariant, :node, :severity, :message ] | poGraph=the agent graph to check, such as the graph an stzAgentGraph holds | AddInvariant, EnforceOnCode | | an invariant the set does not hold gives no finding
