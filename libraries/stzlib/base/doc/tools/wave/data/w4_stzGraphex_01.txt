init | Compiles a graph pattern into a pattern graph and keeps the target graph; a non-text pattern or a non-graph raises an error. | nothing; the matcher is built | _cPattern_=The pattern, as text, such as "{@Node(a) -> @Edge(x) -> @Node(b)}"; the outer braces may be left out; oTargetGraph=The stzGraph the pattern is matched against | Match, NormalizePattern | | Match takes the graph again, so the target given here is only the default
NormalizePattern | Returns the pattern trimmed and wrapped in braces when it is not already. | text | _cPattern_=The pattern, as text | init, ParsePattern
BuildPatternGraph | Parses a pattern and adds one node per token to the pattern graph, joined by sequences edges; an alternation fans out to every branch. | nothing; the pattern graph changes | _cPattern_=The braced pattern, as text | ParsePattern, ListifyPatternGraph | the nodes are added to the graph already held, not in place of it, and their ids restart at :p1 | init calls it once; a second call grafts the new tokens onto the first pattern
ParsePattern | Splits a braced pattern at -> into token lists, one per part, with an alternation in parentheses becoming a single alternation token. | a list of tokens, each a hash list | _cPattern_=The pattern, as text, with its outer braces | ParseSingleToken, BuildPatternGraph | the first and last characters are removed without a check, so a pattern without braces loses its first and last letters | each token holds type, label, min, max, setvalues, unique, negated and cs
ParseSingleToken | Parses one token such as @Node(a)+ into a hash list of its type, label, quantifier, set values and flags; [ ] if unreadable. | a hash list, or [ ] | _cTokenStr_=One token, as text: @Node, @Edge, @Cycle or @Path, with an optional (label), {set}, quantifier and @! or @cs: prefix | ParsePattern, BuildPatternGraph | the quantifier gives min and max (+ is 1 to 999999, * is 0 to 999999, ? is 0 to 1) but matching never reads them
ListifyGraph | Returns every path of a graph as a list of alternating node and edge labels, with isolated nodes and @Cycle paths added. | a list of label lists | oGraph=The stzGraph to turn into label paths | Match, ListifyPatternGraph | paths run between every pair of distinct reachable nodes, so a chain of three nodes gives three branches
Match | Tells whether the pattern occurs in a graph: its labels in order along one path, no negated label on it, and the property constraints met. | TRUE or FALSE (1 or 0) | oTargetGraph=The stzGraph to look in | ListifyGraph, CacheStats | the result is cached under a signature made of the node and edge counts and the node ids, so a second graph with the same ids but other labels answers from the cache: call ClearCache between graphs; labelless tokens (a bare @Node or @Edge, @Cycle, @Path) match anything and quantifiers are not read | labels match without regard to case unless the token starts with @cs:; a negated label only rules out the path that holds it, so another path may still match
CacheStats | Returns how many target graphs are cached and how many matches were answered from the cache. | a hash list [ :entries, :hits ] | | CacheInfo, ClearCache
CacheEntries | Returns the number of target graphs held in the match cache. | a number | | CacheStats
ClearCache | Empties the match cache and sets its hit count back to 0. | nothing; the cache changes | | CacheStats, SetCacheSize
SetCacheSize | Sets how many results the match cache keeps, the oldest dropped first; a value that is not a number is ignored. | the matcher itself, so calls can be chained | nSize=The most results to keep; 100 by default | CacheInfo, ClearCache | with 0 or a negative number the cache is no longer trimmed and so has no bound
CacheInfo | Returns the cache state: entry count, size limit and hit count. | a hash list [ :entries, :maxsize, :hits ] | | CacheStats, SetCacheSize
ListifyPatternGraph | Returns the pattern graph as label paths from each root to each end, one path per branch of an alternation. | a list of label lists | | TraversePatternNode, ListifyGraph | the labels read node(Start) or edge(flows), with the token type and its label in parentheses
TraversePatternNode | Walks the pattern graph depth-first from a node and appends each complete label path to the list given as third argument. | nothing; the branches list is filled | _cNodeId_=The id of the pattern node to start from, such as :p1; aCurrentPath=The labels already on the path, as a list; _aBranches_=The list that receives each finished path; acVisited=Ids already visited, kept for the call and not read | ListifyPatternGraph | an id that is not a pattern node raises error Node does not exist, because the check after the lookup never runs | give [ ] for aCurrentPath and acVisited
MatchBranches | Tells whether any pattern branch has its labels in order inside any target branch, with none of its negated labels there. | TRUE or FALSE (1 or 0) | _aPatternBranches_=Pattern label paths, such as node(a) and edge(x) entries; _aTargetBranches_=Target label paths, as ListifyGraph gives them | Match, IsSubsequence | the case flags are read from the pattern graph held by the object, so branches that did not come from it are all matched without regard to case
IsSubsequenceSimple | TRUE if every pattern label appears in the target in the same order, not necessarily next to each other; labels are compared with case. | TRUE or FALSE (1 or 0) | _aPattern_=The labels to find, as a list; aTarget=The labels to look in, as a list | IsSubsequence, MatchBranches | an empty pattern is TRUE
IsSubsequence | TRUE if the pattern labels appear in order in the target; a flag per label marks it negated, and then only the next target item is checked. | TRUE or FALSE (1 or 0) | _aPattern_=The labels to find, as a list; aTarget=The labels to look in, as a list; aPatternNegations=One flag per pattern label, 1 for a negated label and 0 otherwise | IsSubsequenceSimple, MatchBranches | a negated label that occurs later in the target is not noticed, since the negation uses up the next target item and the scan goes on
TokensToListexPattern | Turns branch labels such as node(a) into their bare labels, with the text any for a label that has no parentheses or is not text. | a list of texts | _aBranch_=A list of labels such as node(a) and edge(x) | ListifyPatternGraph | the unmatched parenthesis case "bar(" also gives any
ShowPatternGraph | Prints the pattern graph as boxes and arrows, one box per token joined by sequences arrows; a negated token is shown between ! marks. | nothing; text is printed | | ListifyPatternGraph, Match
