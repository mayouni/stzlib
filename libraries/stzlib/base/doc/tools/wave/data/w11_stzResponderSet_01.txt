init | Builds a set of responders, each reached by reference, so one plan can span several owners. | nothing; the set is built | paResponders=a list of responders; a list literal copies the objects, so use Add for one whose state is read afterwards | Add, Owns
Add | Appends one responder to the set, keeping the object itself rather than a copy. | the set itself, so calls chain | poResponder=the responder to add, an object that answers Owns and the verbs it owns | Owns, StzResponderSet
Owns | TRUE if some member of the set owns the verb. | TRUE or FALSE | pcVerb=the verb, such as lockaccount, matched as each member matches it | Add, LockAccount
LockAccount | Passes an account lock to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the account to lock | Owns, RevokeSession | an unowned verb raises an error stating that the plan cannot be performed in full
RevokeSession | Passes a session revocation to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the actor whose sessions end | Owns, LockAccount | an unowned verb raises an error stating that the plan cannot be performed in full
RotateSecret | Passes a secret rotation to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the secret to rotate | Owns, StzSecretStoreResponder | an unowned verb raises an error stating that the plan cannot be performed in full
RevokeCapability | Passes a capability revocation to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the actor whose capability is cut | Owns, StzCapabilityResponder | an unowned verb raises an error stating that the plan cannot be performed in full
ShedSource | Passes a source block to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the source to block | Owns | an unowned verb raises an error stating that the plan cannot be performed in full
QuarantinePart | Passes a quarantine to the first member that owns it; raises an error when no member does. | nothing | pcTarget=the part to stop | Owns | an unowned verb raises an error stating that the plan cannot be performed in full
