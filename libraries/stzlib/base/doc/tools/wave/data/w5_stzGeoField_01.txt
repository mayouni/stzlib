# stzGeoField -- probed on a 4 x 3 grid of 1..12, an ESRI ASCII grid, IDW and kriged fields of invented gauges and a kernel density over Niger
init | Builds a field from a grid description and one value per node; raises an error when the grid or the number of values is wrong. | nothing; the field is built | paGrid=the grid as [ lon0, lat0, dlon, dlat, nx, ny ]: the first node, the spacing in degrees and the node counts; paValues=nx times ny numbers, row 0 the SOUTH row, "" for an unknown node | StzGeoField, StzGeoFieldFromAsciiGrid, StzGeoDensityField | | Needs at least 2 nodes each way. Prefer the three constructors named in See: they know where the values come from
Grid | Returns the grid description the field was built with. | a list [ lon0, lat0, dlon, dlat, nx, ny ] | | Values, Bounds, CellSizeDegrees| | 
Values | Returns the node values, row after row from the south row. | a list of numbers, with "" for an unknown node | | Grid, ValueAt| | 
ColumnCount | Returns the number of nodes from west to east. | a number | | RowCount, Grid| | 
RowCount | Returns the number of nodes from south to north. | a number | | ColumnCount, Grid| | 
CellSizeDegrees | Returns the spacing of the nodes in degrees. | a list [ dlon, dlat ] | | Grid, Bounds| | 
Bounds | Returns the ground the nodes cover, from the first node to the last. | a list [ lon0, lat0, lon1, lat1 ] in degrees | | Grid, CellSizeDegrees| | 
SetUnit | Sets the unit the legend and the density rule read, such as mm or places per km2. | nothing; the unit is stored | pcUnit=the unit as text; the text "per km2" anywhere in it makes the field a density | Unit, FindingsOn | | FindingsOn flags a density field drawn on a projection that does not preserve area
Unit | Returns the unit set for the field. | text, "" when none was set | | SetUnit| | 
SetSource | Sets the text that says where the numbers came from. | nothing; the source is stored | pcSource=the origin of the field as text | Source| | 
Source | Returns where the numbers came from. | text, "" when none was set | | SetSource| | 
Stats | Returns the lowest and highest known value and how many nodes are known and unknown. | a hash list [ :min, :max, :known, :unknown ]; all 0 when nothing is known | | Min, Max, Findings | | Read unknown first: a field that is nine tenths unknown draws as a handsome map of one tenth of the ground
Min | Returns the lowest known node value. | a number, 0 when nothing is known | | Max, Stats| | 
Max | Returns the highest known node value. | a number, 0 when nothing is known | | Min, Stats| | 
ValueAt | Returns the field's value at a place: bilinear between four known nodes, the nearest node where some are unknown. | a number, or "" off the grid or where nothing can be read | pnLon=longitude in degrees east; pnLat=latitude in degrees north | Values, Stats | Defect: a bilinear read of a constant field comes back one rounding step under the node value about 6 per cent of the time, so with SetClassesEvery a pixel at the first class edge draws as no data (white specks). | LONGITUDE FIRST. On 1..12 over a 4 x 3 grid, (1.5, 10.5) reads 4.5
LevelsEvery | Returns pnHowMany levels spread evenly between the field's lowest and highest value, the two ends left out. | a list of numbers, [ ] when pnHowMany is below 1 or nothing is known | pnHowMany=how many levels to return | ContourAt, SetClassesEvery | | A contour at the minimum is the map's border and at the maximum a point
ContourAt | Returns the contour of the field at one level, found on the grid by marching squares. | a list of polylines, each a flat list lon, lat, lon, lat, ...; [ ] when the level is outside the field | pnLevel=the value to follow | DrawContoursOn, LevelsEvery | | Longitude first in each pair
SetClasses | Sets the class edges that colour the field and gives a ramp of the right size when the number of classes changed. | nothing; the edges are stored | paEdges=a rising list of at least two edges | SetClassesEvery, SetRamp, Classes | | Raises an error for fewer than two edges or edges that do not rise. The default ramp is YlOrRd
SetClassesEvery | Sets pnHowMany equal classes between the field's lowest and highest value. | nothing; the edges are stored | pnHowMany=the number of classes | SetClasses, LevelsEvery | Defect: a bilinear read of a constant field comes back one rounding step under the node value about 6 per cent of the time, so with SetClassesEvery a pixel at the first class edge draws as no data (white specks). | Raises an error when nothing is known
SetRamp | Sets the colours of the classes from a named ramp, in as many steps as there are classes. | nothing; the palette is stored | pName=the name of a ramp, such as :Blues, :YlOrRd, :Viridis or :Earth | SetPalette, SetClasses | Defect: the error for an unknown name lists nine ramps although thirteen exist. | Raises an error before the classes are set
SetPalette | Sets the colour of each class by hand. | nothing; the palette is stored | paColours=one colour per class, as hex text or names | SetRamp, Palette | | Raises an error when the number of colours is not the number of classes
Classes | Returns the class edges. | a list of numbers, [ ] before they are set | | SetClasses| | 
SetClip | Sets the ground the picture is cut to, as rings, so the raster's edge is a coastline and not a staircase of cells. | nothing; the rings are stored | paRings=a list of rings, each a flat list lon, lat, lon, lat, ... | SetClipTo, Clip | | A density field takes its window at birth; a field read from a file has none until told
SetClipTo | Sets the clip ground from the outer rings of every part of every feature. | nothing; the rings are stored | poFeatures=a stzGeoFeatures whose outlines bound the picture | SetClip | | Holes are not carried
Clip | Returns the clip rings. | a list of flat lon, lat lists, [ ] when none | | SetClip| | 
Palette | Returns the colour of each class. | a list of colours, [ ] before the classes are set | | SetPalette, SetRamp| | 
DrawOn | Draws the field as one image on a canvas, resampled through a projection into a box, coloured by class. | nothing; the image is added to the canvas | poCanvas=the stzCanvas to draw on; poProjection=the stzGeoProjection that places the field; pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box | DrawXT, DrawLegendOn, DrawContoursOn | Defect: a bilinear read of a constant field comes back one rounding step under the node value about 6 per cent of the time, so with SetClassesEvery a pixel at the first class edge draws as no data (white specks). | Raises an error until classes are set. A value outside the classes, an unknown node and the ground outside the clip are left unpainted
DrawXT | Draws the field as one image like DrawOn, with an opacity so the map underneath can show through. | nothing; the image is added to the canvas | poCanvas=the stzCanvas to draw on; poProjection=the stzGeoProjection that places the field; pnX0=left edge of the box; pnY0=top edge of the box; pnX1=right edge of the box; pnY1=bottom edge of the box; pnAlpha=opacity from 0 to 255, 255 being opaque | DrawOn | Defect: a bilinear read of a constant field comes back one rounding step under the node value about 6 per cent of the time, so with SetClassesEvery a pixel at the first class edge draws as no data (white specks). | Raises an error until classes are set
DrawContoursOn | Strokes the contour of the field at each level on a canvas, one line per level and piece. | nothing; the lines are added to the canvas | poCanvas=the stzCanvas to draw on; poProjection=the stzGeoProjection that places the field; paLevels=the values to follow; pStroke=the line colour; pnWidth=the line width in pixels | ContourAt, LevelsEvery | | A contour is a line, never a fill
DrawLegendOn | Draws one row per class with its range, highest class first, under a title that defaults to the unit. | the y a caller can continue from | poCanvas=the stzCanvas to draw on; poFont=the stzFont to write with; pnX=left edge of the legend; pnY=baseline of the title; pcTitle=the title, or "" for the unit | DrawOn | | Draws only the title when no classes are set
Findings | Returns what the field has wrong with it, in the house rule shape, without looking at a projection. | a list of [ :rule, :subject, :where, :severity, :message ]; [ ] when clean | | FindingsOn, IsSound | | Rules: a known value exists, most nodes are measured, the classes reach the data
FindingsOn | Returns what the field has wrong with it, adding the rule that a density needs an equal-area projection. | a list of [ :rule, :subject, :where, :severity, :message ] | poProjection=the stzGeoProjection the field will be drawn on, or NULL | Findings, IsSound | | A field whose unit contains "per km2" on Mercator is an error
IsSound | TRUE if the field has no finding of severity error. | TRUE or FALSE | | Findings | | Warnings do not count
