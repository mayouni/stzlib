init | Opens the machine's speech engine for a voice that renders text to sound buffers. | nothing; the object is built | | StzVoiceQ, IsUsable | a machine with no speech engine is a supported configuration: the object is then not usable and LastError says why | no audio device is opened
Release | Frees the speech engine handle held by the voice. | nothing | | IsUsable | afterwards the voice is not usable and every render is refused
IsUsable | TRUE if the machine has a speech engine and the voice opened it. | TRUE or FALSE | | init, LastError | ask this first
LastError | Returns the reason the last call failed, or the engine's last voice error when none was recorded here. | a text | | Refusals | a render that succeeds does not clear it, so a stale message can outlive the failure that made it
Refusals | Returns how many calls the voice refused. | a number | | LastError
VoiceCount | Returns how many voices are installed on the machine. | a number; 0 when the speech tier is missing | | VoiceNames, Languages
VoiceNames | Returns the names of the installed voices, in the order UseVoice counts them. | a list of text | | VoiceCount, ToVoiceList
Languages | Returns the language tags the machine can speak, without repeats. | a list of text such as en-US and fr-FR | | HasLanguage, UseLanguage | this is what the machine can speak, which is not what it can hear
ToVoiceList | Returns every installed voice with its language. | a list of [ name, language tag ] rows | | VoiceNames, Languages
HasLanguage | TRUE if some installed voice speaks the language, an exact tag first and then the language alone. | TRUE or FALSE | pcTag=a language tag such as en-US, or a bare language such as fr | UseLanguage, Languages | the bare language fr matches fr-FR
CurrentVoiceName | Returns the name of the voice chosen with UseLanguage or UseVoice. | a text; an empty text while the platform default is in use | | CurrentLanguage, UseVoice
CurrentLanguage | Returns the language tag of the voice chosen with UseLanguage or UseVoice. | a text; an empty text while the platform default is in use | | CurrentVoiceName
UseLanguage | Chooses a voice that speaks a language, and refuses rather than substituting another language. | TRUE if a voice was chosen; FALSE with LastError naming the languages the machine has | pcTag=a language tag such as en-US, or a bare language such as fr | UseVoice, HasLanguage | an exact tag is tried first, then the same language with another region; a different language is a counted refusal | with no usable voice it is refused as well
UseVoice | Chooses an installed voice by its position. | TRUE if the voice was chosen; FALSE with LastError set when there is no such voice | pnIndex=the voice's position in VoiceNames, counted from 1 | UseLanguage, VoiceNames | choosing a voice makes the voice cold again, so WarmUp pays its start-up cost | the error text for a bad position counts from 0, one less than the number given
SetRate | Sets the speaking rate of later renders. | the voice itself, so calls chain | pnRate=the rate from -10 for slowest to 10 for fastest, 0 being normal | SetVolume | the engine clamps values outside the range; with no usable voice the call does nothing | measured: a rate of 5 shortened a 2.52 s phrase to 1.47 s
SetVolume | Sets the speaking volume of later renders. | the voice itself, so calls chain | pnVolume=the volume from 0 to 100 | SetRate | the engine clamps values outside the range; with no usable voice the call does nothing | measured: a volume of 30 lowered the peak of a phrase from 0.49 to 0.07
WarmUp | Pays the start-up cost of the voice now by synthesising and discarding one syllable. | the voice itself, so calls chain | | IsWarm, ToSoundOf | a cold synthesis costs about 4.3 times a warm one | no audio device is opened
IsWarm | TRUE if the voice has rendered something since it was opened or since its voice was changed. | TRUE or FALSE | | WarmUp
ToSoundOf | Renders text to a sound in memory with the current voice, playing nothing. | a stzSound mono at the speech engine's rate, 22050 Hz on this machine; an empty text with LastError set on refusal | pcText=the text to speak | ToSoundOfSsml, SampleRate | no audio device is opened; the rate is carried in the sound and in a saved file, and is not 48000, so resample before measuring loudness | the sound has not been heard by a person; the empty text is not refused and gives a sound
ToSoundOfSsml | Renders SSML markup to a sound in memory, after the engine has checked that the markup is well formed. | a stzSound as ToSoundOf gives; an empty text with LastError set on refusal | pcSsml=the SSML document, such as a speak element holding text and prosody elements | ToSoundOf | markup with an unclosed tag is refused by the engine, since the platform would discard it silently and speak the words | no audio device is opened
Say | Speaks the text on the audio device and waits until it has ended. | the voice itself | pcText=the text to speak | ToSoundOf, ToTransportOf | not run in this reference: it opens an audio device through the sound; a refused render makes it do nothing | for a script that has nothing else to do
ToTransportOf | Speaks the text on the audio device without waiting and returns the transport that is playing it. | a stzSoundTransport already started; an empty text when the render is refused | pcText=the text to speak | Say, ToSoundOf | not run in this reference: it opens an audio device through a transport | the transport stops by itself after the phrase's length, which Tick must see
SampleRate | Returns the sample rate of the sounds the speech engine produces, in hertz. | a number, 22050 on this machine; 0 without the speech tier | | Channels, ToSoundOf | not 48000, so loudness measures need a resample first
Channels | Returns the number of channels of the sounds the speech engine produces. | a number, 1 on this machine; 0 without the speech tier | | SampleRate
SynthesisIsTheBottleneck | Answers whether computing the speech is what makes it late, which it is not. | FALSE always | | WarmUp | synthesis is under 1 percent of the output latency; the audio path is long
