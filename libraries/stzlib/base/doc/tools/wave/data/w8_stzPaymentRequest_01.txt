# Wave 8 -- stzPaymentRequest. Name | brief | returns | params | see | warning | note
init | Builds an empty request to pay, which is then told who is asked, how much and for what. | nothing; the object is built | | WithTxId, AsBody
WithTxId | Sets the platform's own unique identifier of the request, the key that makes a retry safe. | the request itself, so calls chain | pcTx=the platform's id, unique | TxId, stzPaymentsPort | | a retry reuses this id: a new id is a new request
FromAlias | Sets the alias of the payer who is asked to pay. | the request itself, so calls chain | pcAlias=the payer's PI-SPI alias, a UUID | ToAlias | | in a bulk of requests, each item names its own payer this way
ToAlias | Sets the platform's own alias, where the money should land. | the request itself, so calls chain | pcAlias=the platform's PI-SPI alias, a UUID | FromAlias
WithAmount | Sets the amount asked, from an amount built with its currency, kept in whole francs. | the request itself, so calls chain | poAmount=an amount built with StzAmountQ, in XOF | StzAmountQ | raises an error for a bare number, which carries no currency, and for any currency but XOF, before a request exists | 350000 francs is stored as 350000
InCategory | Sets the kind of request: 500 on the spot, 521 e-commerce, 401 invoice. | the request itself, so calls chain | pcCategory=the category code as text: 500, 521 or 401 | PayableBy, AnswerableBy | | the twin refuses an invoice or e-commerce request that has no PayableBy date
PayableBy | Sets the last date on which the payer may pay the request. | the request itself, so calls chain | pcDate=the date as text, such as 2026-10-31 | AnswerableBy, InCategory | | required by the hub for an invoice or e-commerce request
AnswerableBy | Sets the last date on which the payer may accept or refuse the request. | the request itself, so calls chain | pcDate=the date as text, such as 2026-10-20 | PayableBy
Motive | Sets the free text the payer sees on the request, such as an invoice number. | the request itself, so calls chain | pcMotif=the text shown to the payer | Documented
Documented | Attaches a reference document to the request: its number and its type. | the request itself, so calls chain | pcNumber=the document's number, such as an invoice number; pcType=the document's type code | Motive
WithConfirmation | Makes the hub hold the request until the platform confirms it. | the request itself, so calls chain | | WithoutConfirmation, ConfirmRequest | | the request then starts as INITIE; either this or WithoutConfirmation must be set
WithoutConfirmation | Makes the hub send the request at once, with no confirmation step. | the request itself, so calls chain | | WithConfirmation | | either this or WithConfirmation must be set
TxId | Returns the txId set on the request. | a text; an empty text when none was set | | WithTxId
AsBody | Returns the request as the message body the hub expects, a list of pairs, once every required part is set. | a list of [ key, value ] pairs: txId, payeurAlias, payeAlias, montant, confirmation, categorie, the dates and motif when set | | AsItem, stzPaymentsPort | raises an error when the txId, payer, payee, amount or category is missing, or when the confirmation choice is not made | stzPaymentsPort RequestPayment calls it for you
AsItem | Returns the request as one item of a bulk of requests, which carries only its txId, payer and amount. | a list of [ key, value ] pairs: txId, payeurAlias, montant, then motif and the document when set | | AsBody, Add | raises an error when the txId, the payer or the amount is missing | stzPaymentBatch Add calls it for you
