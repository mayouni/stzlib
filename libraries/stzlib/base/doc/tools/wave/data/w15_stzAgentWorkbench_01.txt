init | Builds a face onto an open workbench, a rehearsal file system held in memory, reached by its numeric id. | nothing; the object is built | pnId=the id returned by StzOpenAgentWorkbench or by Id | Id, SetActor | an id with no open workbench raises an error naming the id at construction, not at the first write | the face holds only the id, so copies of it all reach the same one workbench
Id | Returns the number of the workbench this face reaches. | a number | | init
SetActor | Stamps the workbench with the name of whoever proposes the changes, so the history and the plan show an author. | the face itself, so calls chain | pcName=the actor's name, shown in brackets after each rehearsed operation | HistoryText, GenerateUpdatePlan
CreateFile | Rehearses creating a file with some text; nothing touches the disk. | the face itself, so calls chain | pcPath=the path of the file; pcContent=its text | WriteFile, Exists, ContentOf | | creating a path that already exists is accepted and replaces its content; a later Validate of the plan reports problems with reality
WriteFile | Rehearses writing text into a file; nothing touches the disk. | the face itself, so calls chain | pcPath=the path of the file; pcContent=the new text | CreateFile, ContentOf | | writing a path the workbench does not hold creates it
CreateFolder | Rehearses creating a folder; nothing touches the disk. | the face itself, so calls chain | pcPath=the path of the folder | DeleteFolder, Exists
DeleteFile | Rehearses deleting a file, leaving a mark that ReadThrough reads as an empty file. | the face itself, so calls chain | pcPath=the path of the file | DeleteFolder, WasDeleted | | deleting a path nobody holds is accepted; Validate on the plan reports that the target is absent in reality
DeleteFolder | Rehearses deleting a folder; nothing touches the disk. | the face itself, so calls chain | pcPath=the path of the folder | DeleteFile, WasDeleted
CopyFile | Rehearses copying a file inside the workbench. | the face itself, so calls chain | pcFrom=the source path; pcTo=the path of the copy | MoveFile, MirrorFile | | a source the workbench does not hold is accepted, and Validate on the plan reports it as absent in reality
MoveFile | Rehearses moving a file; the source path then counts as deleted. | the face itself, so calls chain | pcFrom=the source path; pcTo=the destination path | CopyFile, WasDeleted
MirrorFile | Copies a real file's text into the workbench so it can be changed there; the disk file is only read. | the face itself, so calls chain | pcPath=the path of a real file | ReadThrough, WriteFile | | a path that does not exist on disk is ignored and records nothing
Exists | TRUE if the workbench itself holds the path; the real disk is not asked. | TRUE or FALSE | pcPath=the path to test | ExistsThrough, ContentOf
ContentOf | Returns the text the workbench holds for a path; the real disk is not asked. | a text; empty when the workbench holds no such path | pcPath=the path of a rehearsed file | ReadThrough, Exists
NumberOfOperations | Returns how many operations have been rehearsed. | a number | | HistoryText, GenerateUpdatePlan
HistoryText | Returns the rehearsal as numbered lines, each with its actor, ready to read or log. | a multi-line text starting with Rehearsed operations (n): | | NumberOfOperations, SetActor
WasDeleted | TRUE if the rehearsal deleted or moved the path away and the workbench does not hold it now. | TRUE or FALSE | pcPath=the path to test | ReadThrough, ExistsThrough | | a path deleted and then created again is held, so the answer is FALSE
ReadThrough | Returns a file's text as the agent should see it: the workbench's own copy first, an empty text for a deleted path, otherwise the real disk. | a text | pcPath=the path to read | ExistsThrough, ContentOf, MirrorFile | | reading is free and never changes the workbench; only writes are confined to it
ExistsThrough | TRUE if the file exists as the agent should see it: held by the workbench, or not deleted and present on the real disk. | TRUE or FALSE | pcPath=the path to test | ReadThrough, Exists
GenerateUpdatePlan | Returns the rehearsal as an update plan, the one export toward reality, to be validated and committed by an actor that holds the authority. | a stzUpdatePlan listing every rehearsed operation | | NumberOfOperations, HistoryText | | the plan is built from the history: Validate on it reports operations that do not match the real files
