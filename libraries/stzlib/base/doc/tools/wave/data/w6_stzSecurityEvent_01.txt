init | Builds an event of one kind from the closed catalog, stamping both clocks and the active trace id at the moment of detection. | nothing; the object is built | pcKind=the event kind, a dotted catalog name such as auth.login.failed, matched without regard to case | StzSecurityEventKindNames, Kind | an unknown kind raises an error that lists every known kind: the catalog is closed | the outcome starts as refused; severity and technique start at the catalog values for the kind
Kind | Returns the catalog name of the event, in lower case. | a text | | Meaning, Severity
Severity | Returns the severity of the event: info, warning or error. | a text | | AsInfo, AsWarning, AsError | | it starts at the catalog default of the kind and the As calls override it
Technique | Returns the MITRE ATT&CK technique id of the kind, or an empty text where no honest mapping exists. | a text | | Kind
Meaning | Returns the catalog's one-line sentence saying what the kind stands for. | a text | | Kind, Explain
Actor | Returns the name of the actor that did it. | a text; empty until an actor is given | | ByActor, ByActorNamed
Posture | Returns the actor's posture in lower case, such as trusted, sandboxed or external. | a text; empty until an actor is given | | ByActor, ByActorNamed
ActorKinds | Returns the capability kinds the actor object held, as ByActor read them. | a list of text; [ ] for an actor given by name | | ByActor
Action | Returns the act that was attempted, trimmed and in lower case. | a text; empty until Doing sets it | | Doing
Risk | Returns the risk tier of the act that was attempted. | a number, 0 until AtRisk sets one | | AtRisk
Subject | Returns the descriptor of the thing acted on; the value of a secret is never in it. | a text; empty until About sets it | | About
Origin | Returns where the event came from, such as an address, a host or an endpoint. | a text; empty until FromOrigin sets it | | FromOrigin
Outcome | Returns how the attempt ended: granted, refused, failed or observed. | a text, refused for a new event | | Granted, Refused, Failed, Observed
Reason | Returns the gate's own words for a refused, failed or observed event. | a text; empty for a grant | | Refused, Failed, Observed
AtWall | Returns the wall-clock time of the event, in epoch milliseconds. | a number | | AtMono, OccurredAt | | stamped when the event was built, which is the moment of detection and not of recording
AtMono | Returns the monotonic-clock stamp of the event, in milliseconds, which keeps its ordering across a clock correction. | a number, which may have a fraction | | AtWall | | it orders the events of this process only and is not part of the canonical line
TraceId | Returns the id of the trace scope that was active when the event was built. | a text; empty outside a trace scope | | Record
IsRefusal | TRUE if the outcome is refused or failed; a granted or an observed event is not a refusal. | TRUE or FALSE | | Outcome, Refused
ByActor | Takes the actor's name, posture and capability kinds from an actor object, or only the name from a text. | the event itself, so calls chain | poActor=an actor object such as HumanActor, or the actor's name as text | ByActorNamed, Actor | | a text sets only the name, so a posture and kinds set earlier stay as they were; an object without Name records its class name
ByActorNamed | Sets the actor from a name and a posture, for a caller with no actor object yet, such as a login door. | the event itself, so calls chain | pcName=the actor name, as text; pcPosture=the actor's posture, stored in lower case, such as external | ByActor, Actor
About | Sets the subject: a text is taken as already safe, an object contributes its redacted descriptor and never its value. | the event itself, so calls chain | pSubject=a descriptor text such as user:admin, or an object such as a secret | Subject | the redaction law lives here: given a secret it records the descriptor and never reveals it | an object that has neither a descriptor nor a name records its class name
Doing | Sets the act that was attempted, trimmed and put in lower case. | the event itself, so calls chain | pcAction=the verb, such as reveal or login | Action, AtRisk
AtRisk | Sets the risk tier of the act that was attempted; a value that is not a number is ignored. | the event itself, so calls chain | pnTier=the risk tier, as a number | Risk, Doing
FromOrigin | Sets where the event came from. | the event itself, so calls chain | pcOrigin=an address, a host or an endpoint, as text | Origin
OccurredAt | Sets the wall time of an event that did not happen now, such as an imported one or a guard needing exact windows. | the event itself, so calls chain | pnWallMs=the event time, in epoch milliseconds | AtWall | | a value that is not a number is ignored; the monotonic stamp is left alone, because it cannot be borrowed
Granted | Sets the outcome to granted. | the event itself, so calls chain | | Refused, IsRefusal | | the reason is left as it was
Refused | Sets the outcome to refused, with the gate's own words as the reason. | the event itself, so calls chain | pcReason=the gate's own words, as text | Failed, IsRefusal
Failed | Sets the outcome to failed: the gate admitted the act and it still did not complete. | the event itself, so calls chain | pcReason=why it did not complete, as text | Refused, IsRefusal
Observed | Sets the outcome to observed, a fact that carries no verdict, such as a session reaching its expiry. | the event itself, so calls chain | pcReason=what was seen, as text | Refused, IsRefusal | | an observed event is not a refusal, so no pivot that counts refusals counts it
AsInfo | Sets the severity of the event to info, overriding the catalog default. | the event itself, so calls chain | | AsWarning, AsError | the ledger keeps the override, but the OCSF exports of the ledger read the catalog default again | OcsfSeverityId and ToOcsfJson on the event itself do use the override
AsWarning | Sets the severity of the event to warning, overriding the catalog default. | the event itself, so calls chain | | AsInfo, AsError | the ledger keeps the override, but the OCSF exports of the ledger read the catalog default again | OcsfSeverityId and ToOcsfJson on the event itself do use the override
AsError | Sets the severity of the event to error, overriding the catalog default. | the event itself, so calls chain | | AsInfo, AsWarning | the ledger keeps the override, but the OCSF exports of the ledger read the catalog default again | OcsfSeverityId and ToOcsfJson on the event itself do use the override
Record | Returns the event as its native record, every field including the actor's kinds and the monotonic stamp. | a list of [ key, value ] pairs: kind, severity, technique, actor, posture, actorKinds, action, risk, subject, origin, outcome, reason, atWall, atMono, traceId | | CanonicalString, AsLine
CanonicalString | Returns the event as one fixed-order line of twelve fields, the form the ledger hashes into its chain. | a text | | Record, AsLine | | a vertical bar inside a field is folded to a slash so the line splits back cleanly; two events with the same facts give the same line; the technique, the actor kinds and the monotonic stamp are not in it
OcsfSeverityId | Returns the OCSF severity id: 1 informational, 3 medium for a warning, 4 high for an error. | a number | | ToOcsfJson, Severity
OcsfStatusId | Returns the OCSF status id: 1 for a granted event, 2 for every other outcome. | a number | | ToOcsfJson, Outcome | an observed event also reads 2, so a fact with no verdict reaches a SIEM as a failure | refused and failed both read 2 as well
OcsfClassUid | Returns the OCSF class uid chosen from the kind: 3002 for auth, sso and oauth kinds, 4002 for http kinds, 6003 for the rest. | a number | | OcsfCategoryUid, ToOcsfJson | | a best-effort mapping: facts that map no field travel under unmapped
OcsfCategoryUid | Returns the OCSF category uid of the event's class: 3, 4 or 6. | a number | | OcsfClassUid
ToOcsfJson | Returns the event as one OCSF JSON object, with the facts that map no field riding under unmapped. | a text of JSON | | OcsfClassUid, AsLine | | the trace id appears as metadata_trace_id and the technique under unmapped; backslashes and quotes in the text are escaped
AsLine | Returns the event as one readable line: outcome, kind, actor with posture, subject, origin and reason. | a text, for example REFUSED auth.login.failed by bob (external) on route:/pay -- bad password | | Explain, CanonicalString
Explain | Returns the event told as lines of text: kind and severity, meaning, the readable line, both times and the ATT&CK id. | a list of text | | Show, AsLine
Show | Prints the lines Explain returns, one per line. | nothing; it prints | | Explain
