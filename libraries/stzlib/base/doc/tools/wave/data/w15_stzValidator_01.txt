init | Opens the engine's validation store, one list of named rules and one list of violations that every stzValidator object shares. | nothing; the object is built | | Clear | the rules and violations are global to the process, so call Clear first for a clean slate
AddRule | Adds a named rule of a given kind with a threshold and a message, and returns its index. | the index of the new rule, a number counted from 0 | cName=the rule's name, a non-empty text, used by the Check calls; nKind=the kind of rule, 0 required, 1 min value, 2 max value, 3 min length, 4 max length, 5 pattern, 6 custom; nThreshold=the limit the rule compares against; cMessage=the text reported when the rule is violated | AddMinValueRule, CheckInt, RuleMessage | a bad name, kind, threshold or message raises an error; a second rule with an existing name is stored, but the Check calls keep using the first | rule names are case-sensitive
AddMinValueRule | Adds a rule that a number must be at least nMin, and returns its index. | the index of the new rule, a number | cName=the rule's name, a non-empty text; nMin=the smallest number allowed; cMessage=the text reported when the rule is violated | AddMaxValueRule, CheckInt
AddMaxValueRule | Adds a rule that a number must be at most nMax, and returns its index. | the index of the new rule, a number | cName=the rule's name, a non-empty text; nMax=the largest number allowed; cMessage=the text reported when the rule is violated | AddMinValueRule, CheckInt
AddMinLengthRule | Adds a rule that a length must be at least nMin, and returns its index. | the index of the new rule, a number | cName=the rule's name, a non-empty text; nMin=the shortest length allowed; cMessage=the text reported when the rule is violated | AddMaxLengthRule, CheckLength
AddMaxLengthRule | Adds a rule that a length must be at most nMax, and returns its index. | the index of the new rule, a number | cName=the rule's name, a non-empty text; nMax=the longest length allowed; cMessage=the text reported when the rule is violated | AddMinLengthRule, CheckLength
AddRequiredRule | Adds a required-value rule, with the threshold 0, and returns its index. | the index of the new rule, a number | cName=the rule's name, a non-empty text; cMessage=the text reported when the rule is violated | AddRule, CheckLength | the rule answers 1 (passes) for a length of 0, for a length of 4 and for the numbers 0 and 7, so it never rejects an empty value today (checked with CheckLength, CheckInt and CheckStringLength)
CheckInt | Tests a number against a named rule and answers 1 if it passes, 0 if it does not. | 1 or 0 | cRuleName=the name of the rule to test against; nValue=the number to test | CheckLength, AddViolation | an unknown rule name raises an error; a failed test is not recorded: call AddViolation to record it | a rule of another kind than the value check answers 1
CheckLength | Tests a length against a named rule and answers 1 if it passes, 0 if it does not. | 1 or 0 | cRuleName=the name of the rule to test against; nLength=the length to test | CheckInt, CheckStringLength | an unknown rule name raises an error; a failed test is not recorded: call AddViolation to record it | a rule of another kind than the length check answers 1
CheckStringLength | Tests the length of a text, counted in characters, against a named rule. | 1 or 0 | cRuleName=the name of the rule to test against; cString=the text whose length is tested | CheckLength | counts characters, not bytes: 'Zoé' has length 3
AddViolation | Records that a rule was violated, by its index, so IsValid turns FALSE. | 1 if recorded, 0 if the index names no rule | nRuleIndex=the index of the rule that was violated, as AddRule returned it | NumberOfViolations, IsValid, RuleMessage
NumberOfViolations | Returns how many violations were recorded. | a number | | AddViolation, ClearViolations
IsValid | TRUE if no violation is recorded. | 1 or 0 | | AddViolation, ClearViolations
ClearViolations | Forgets the recorded violations and keeps the rules. | nothing | | AddViolation, Clear
RuleMessage | Returns the message of the rule at an index, counted from 0 in the order the rules were added. | a text; empty when no rule has that index | nIndex=the index of the rule | AddRule, AddViolation
NumberOfRules | Returns how many rules are stored. | a number | | AddRule, Clear
Clear | Removes every rule and every violation, for all objects that share the store. | nothing | | ClearViolations, NumberOfRules
