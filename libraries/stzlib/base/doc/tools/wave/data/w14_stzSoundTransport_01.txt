init | Builds a transport over a graph, with a master gain added for fades and a state machine that starts stopped. | nothing; the object is built | poGraph=the stzSoundGraph to start, pause and stop | StzSoundTransportOfQ, State | a non-graph is refused, with LastError set; the master gain is added to the graph before it is prepared, which is why the graph gains a node | nothing starts and no device is opened here
State | Returns what the transport is doing now. | a text: stopped, playing or paused | | IsPlaying, IsPaused, IsStopped | stopped for a transport that was built without a graph
IsPlaying | TRUE if the transport is in the playing state. | TRUE or FALSE | | State, Play
IsPaused | TRUE if the transport is in the paused state. | TRUE or FALSE | | State, Resume
IsStopped | TRUE if the transport is in the stopped state, as it is when built. | TRUE or FALSE | | State, Play
LastError | Returns the reason the last move was refused or failed, or an empty text. | a text such as cannot pause while stopped | | Refusals | a successful move clears it
Refusals | Returns how many moves the state machine refused. | a number | | LastError | a transport that is driven wrongly says so in this number instead of misbehaving
PositionInFrames | Returns the frames the device has consumed, not the frames the graph has produced. | a number of frames; 0 before any play | | PositionInSeconds, Underruns | the producer runs a ring ahead of the device, so the device's count is what has been heard
PositionInSeconds | Returns the device's position in seconds, from its frames and the graph's rate. | a number of seconds | | PositionInFrames, SampleRate
SampleRate | Returns the sample rate of the graph the transport drives, in hertz. | a number; 48000 when the transport was built without a graph | | PositionInSeconds
Underruns | Returns the frames the producer could not supply in time. | a number; 0 is the answer to want, and 0 when nothing is playing | | PositionInFrames
Play | Starts the graph on the audio device from the top and returns at once. | the transport itself, so calls chain | | PlayFor, Pause, Stop | not run in this reference: it opens an audio device; from any state but stopped it is refused by the state machine, counted, and LastError names the state | with no device the move is undone and LastError says there is no audio device
PlayFor | Starts the graph on the audio device and arranges for it to stop by itself after a number of seconds. | the transport itself, so calls chain | pnSeconds=how long to play before stopping | Play, RunFor | not run in this reference: it opens an audio device; the stop happens in Tick, so something must be ticking | a value of 0 or less means play until stopped
Pause | Fades the master gain to silence over 10 ms, closes the device and remembers the position. | the transport itself, so calls chain | | Resume, Stop | the move is refused and counted when the transport is not playing, which is the only case run in this reference | the fade comes first, because cutting the device dead is an audible click
Resume | Reopens the device after a pause, fades the master gain back up and goes on from where the graph was. | the transport itself, so calls chain | | Pause, Play | refused and counted unless the transport is paused, which is the only case run in this reference; its device path was not run | the graph is not rewound, so an envelope half way through its decay goes on
Stop | Fades the master gain to silence, closes the device, takes the transport out of any reactive loop and calls the finished handler. | the transport itself, so calls chain | | Rewind, OnFinished | refused and counted when already stopped, which is the only case run in this reference | a stopped transport that was driven is no longer ticked
Rewind | Takes the graph back to its top and the position back to 0, only while stopped. | the transport itself, so calls chain | | Stop, PositionInFrames | refused and counted when not stopped, since rewinding under a running device is a jump | there is no seek: the engine can only rewind to the start
Tick | Reads the device position, calls the tick handler and stops the transport once the stop time passed to PlayFor is reached. | the transport itself, so calls chain | | RunToEnd, DriveWith | does nothing unless the transport is playing, which is the only case run in this reference | cheap enough to call as often as you like
RunToEnd | Ticks every 20 ms until the transport is no longer playing. | the transport itself, so calls chain | | Tick, RunFor | returns at once when the transport is not playing | blocks the calling thread while it plays
RunFor | Plays for a number of seconds and waits, ticking, until the transport has stopped. | the transport itself, so calls chain | pnSeconds=how long to play | PlayFor, RunToEnd | not run in this reference: it opens an audio device | it occupies the thread, like RunToEnd
DriveWith | Registers the transport so that a reactive loop steps it every 20 ms, alongside its other timers. | the transport itself, so calls chain | poReactive=the stzReactive whose loop should call the transport | Tick, OnTick | a non-reactive argument is refused, with LastError set and the refusal counted; registering twice adds it once; the loop was not run in this reference | the transport is registered by pointer in a global list, and Stop or Release removes it
OnStarted | Sets the function to call when the transport has started. | the transport itself, so calls chain | f=the function to call, with no arguments | OnFinished, OnTick | a function that raises is swallowed silently
OnFinished | Sets the function to call when the transport has stopped. | the transport itself, so calls chain | f=the function to call, with no arguments | OnStarted | a function that raises is swallowed silently
OnTick | Sets the function to call at every step of a playing transport. | the transport itself, so calls chain | f=the function to call, with no arguments | Tick, DriveWith | a function that raises is swallowed silently
Release | Takes the transport out of any reactive loop, closes the device and discards the state machine. | nothing | | Stop | afterwards State answers stopped
