init | Builds an empty composition of agents, drawn as a colored graph that can be proved sound before anything runs. | nothing; the object is built | pcName=the composition's name, quoted in its verdicts | AddLLMActor, IsSound, Explain
GraphQ | Returns the underlying graph, for drawing or inspection. | the stzGraph that holds the nodes and edges | | Tampering, AddPIActor | | a property set on it directly changes the picture but not the decisions, which read a sealed record; Tampering reports the difference
AddPIActor | Adds a trusted actor that may produce effects, with the capabilities effectful, compute and sensing. | nothing; use AddPIActorQ to chain | pcId=the node's id, trimmed and lower-cased | AddLLMActor, AddEffect | declaring an id that already exists replaces its kind, capabilities and taint, and the sealed record follows: an llm actor declared again as a pi actor is accepted | the id is lower-cased, so Boss and boss are one node
AddLLMActor | Adds a language-model actor, which holds only the inference capability and whose output is tainted as open text. | nothing; use AddLLMActorQ to chain | pcId=the node's id, trimmed and lower-cased | AddPIActor, Grant, MayGrant | declaring an id that already exists replaces its kind and capabilities | an llm actor proposes and never commits: it cannot be granted the effectful capability
AddHybridActor | Adds an actor that mixes program and model, which holds the inference capability and whose output is tainted as open text. | nothing; use AddHybridActorQ to chain | pcId=the node's id, trimmed and lower-cased | AddLLMActor, Grant | | unlike an llm actor, it can be granted effectful through Grant
AddGuardian | Adds a guardian, the gate that validates what passes through it, with the capabilities compute and sensing. | nothing; use AddGuardianQ to chain | pcId=the node's id, trimmed and lower-cased | Guards, AddEffect
AddEffect | Adds an effect, a node that changes the world, with the capability effectful. | nothing; use AddEffectQ to chain | pcId=the node's id, trimmed and lower-cased | Guards, Traces | | every effect owes a guardian edge into it and a path to a trace sink
AddTool | Adds a tool, a node that computes, with the capability compute. | nothing; use AddToolQ to chain | pcId=the node's id, trimmed and lower-cased | Feeds, AddEffect
AddTraceSink | Adds a trace sink, the witness where effects leave a record, with the capability sensing. | nothing; use AddTraceSinkQ to chain | pcId=the node's id, trimmed and lower-cased | Traces, AddEffect
AddInput | Adds an external input, a node with no capability whose data is tainted as external. | nothing; use AddInputQ to chain | pcId=the node's id, trimmed and lower-cased | Feeds, AddGuardian | | external data that reaches an effect with no guardian or validated checkpoint on the path is a violation
AddCheckpoint | Adds a human checkpoint, a node where a person validates, with the capability sensing. | nothing; use AddCheckpointQ to chain | pcId=the node's id, trimmed and lower-cased | Escalates, AddGuardian
Tampering | Returns the nodes whose graph properties no longer match what the governed doors recorded. | a list of rows, each a list of the node, what changed (kind, capability or node), the recorded value and the value found; an empty list when untouched | | GraphQ, IsSound | | a kind flipped or a capability added through GraphQ shows here and makes IsSound answer FALSE
Proposes | Draws a proposes edge, from an actor to the node it submits its output to. | the graph itself, so calls chain | pcFrom=the id of the proposing node; pcTo=the id of the node it proposes to | Guards, Feeds | raises an error when either node was not added first, and does nothing when the edge already exists | ids are trimmed and lower-cased
Guards | Draws a guards edge, from a guardian to the effect it stands in front of. | the graph itself, so calls chain | pcGuardian=the id of the guardian; pcEffect=the id of the effect it guards | Proposes, Traces | raises an error when either node was not added first
Feeds | Draws a feeds edge, from a node to the node that takes its data. | the graph itself, so calls chain | pcFrom=the id of the node that supplies data; pcTo=the id of the node that consumes it | Proposes, AddInput | raises an error when either node was not added first
Traces | Draws a traces edge, from an effect to the sink that keeps its record. | the graph itself, so calls chain | pcEffect=the id of the effect; pcSink=the id of the trace sink | Guards, AddTraceSink | raises an error when either node was not added first
Escalates | Draws an escalates edge, from a node to the human checkpoint that takes over when it cannot decide. | the graph itself, so calls chain | pcFrom=the id of the node that escalates; pcCheckpoint=the id of the human checkpoint | Proposes, AddCheckpoint | raises an error when either node was not added first
MayGrant | TRUE if granting a capability to an actor would keep the graph sound, which is FALSE for effectful on an llm actor and for an unknown actor. | TRUE or FALSE | pcActor=the id of the actor, trimmed and lower-cased; pcCap=the capability, such as effectful | Grant | | it reads the sealed kind, so a kind flipped through GraphQ does not open the gate
Grant | Adds a capability to an actor through the governed door. | nothing; use GrantQ to chain | pcActor=the id of the actor; pcCap=the capability to add, such as compute | MayGrant, Tampering | raises an error for an actor that is not in the composition, and a refusal naming the rule for effectful on an llm actor; a hybrid actor may be granted effectful | granting a capability already held changes nothing
Violations | Returns every broken invariant of the composition, as a list of findings, empty when the composition is sound. | a list of hash lists with the keys invariant, node, severity and message | | IsSound, Explain, ViolationsViaRules | | the invariants are no-llm-effectful, effects-guarded, open-text-contained, external-data-contained and effects-traced, plus governed-property-tampered for a node edited around the gate
RulesAreSound | TRUE if the rule-set check finds no violation. | TRUE or FALSE | | ViolationsViaRules, IsSound
RuleSetQ | Returns a new agent rule set, to which a project can add its own invariants. | a stzAgentRuleSet holding the six built-in rules | | ViolationsViaRules | | the set is not bound to this graph: call its Check with the graph
ViolationsViaRules | Returns the broken rules in the unified finding shape, so one report can collect them with any other graph. | a list of hash lists with the keys rule, subject, where, severity and message | | Violations, RulesAreSound | | it also reports the effects-dominated rule and tampering; a tampering finding names the node in subject, the others name agentic
IsSound | TRUE if the composition breaks no invariant and no node was edited around the governed doors. | TRUE or FALSE | | Violations, Tampering, Explain | | it answers FALSE for an effect with no guardian or no trace, for an llm actor that reaches an effect unguarded, and after Tampering finds a change
Explain | Returns a readable verdict: one sentence when governed, or the list of violations when refused. | a text | | Violations, IsSound
