init | Reads an optimization problem written as a short sentence of maximize or minimize, where and keeping clauses. | nothing; the object is built | pcText=the sentence, one clause per line or clauses joined by and | Findings, ToModel | a faulty sentence does not raise here: its faults are listed by Findings; a where clause written on the same line as the objective is not split off, so write it on its own line or after and; a bare relation placed after a where clause is read as one more variable, so use a keeping clause or put the relation first
Findings | Returns the faults found in the sentence, one text each, empty when the sentence is understood. | a list of text; [ ] for a valid sentence | | IsValid, CiteFindings
IsValid | TRUE if the sentence has an objective, at least one variable and no clause the surface does not know. | 1 or 0, numbers | | Findings, ToModel
CiteFindings | Returns the faults as one text, each on its own line after a dash, ready to print. | a text; empty for a valid sentence | | Findings
ToModel | Builds the stzOptimModel the sentence says, through the same door a hand-written model uses; a faulty sentence is refused. | a stzOptimModel | | Findings, StzOptimNaturally | raises stzOptimSentence: this sentence was REFUSED and the findings for a faulty sentence | a variable declared twice, which a bare relation after where can cause, raises AddVar: declared twice | StzOptimNaturally(text) is the one-call form
