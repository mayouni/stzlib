init | Builds a manager of named looks, set of widths and border characters, for a table layout. | nothing; the object is built | oTableConfig=the TableDisplayConfig the themes are applied to | ApplyTheme, ListThemes | the manager keeps a COPY of the config: a theme applied lands on that copy, readable as its oConfig attribute, and your own config stays as it was
ApplyTheme | Applies a named theme's widths, padding and border characters to the config, then recomputes the layout. | the manager itself, so calls chain | _cThemeName_=the theme's name, such as Default, Simple, Compact, Elegant or one made by CreateTheme, without regard to case | ListThemes, CreateTheme | an unknown name prints Theme not found and applies Default; the theme lands on the manager's own copy of the config, not yours
CreateTheme | Adds a named theme, or replaces one, from a list of settings. | the manager itself, so calls chain | _cThemeName_=the new theme's name; aThemeSettings=a hashlist of settings, such as [ :MinCellWidth = 12 ], with an optional BorderChars hashlist | ApplyTheme, ListThemes
ListThemes | Returns the names of the themes available, the four built in and those created. | a list of text in lower case, such as default, simple, compact, elegant | | ApplyTheme, CreateTheme
