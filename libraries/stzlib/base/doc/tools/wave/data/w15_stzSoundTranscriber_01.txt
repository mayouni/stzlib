# w15 stzSoundTranscriber -- worked on sounds rendered to memory; no audio device or microphone was opened, nothing was heard (UNPERCEIVED)
init | Builds a transcriber with the piano as the instrument, a minimum clarity of 0.6 and no result yet. | nothing; the object is built | | TranscribeQ, SetInstrument | | StzSoundTranscriberQ builds the same object
SetInstrument | Sets the instrument the transcribed notes are given. | the transcriber itself, so calls chain | pcName=the instrument name, kept in lower case, such as piano or harp | TranscribeQ, SetMinClarity | | the name is not checked
SetMinClarity | Sets how clear a pitch must be for an onset to become a note. | the transcriber itself, so calls chain | pn=the least clarity, from 0 to 1; an onset below it goes to Unpitched | Confidences, Unpitched | | at 0.6 a rendered C4 E4 G4 C5 gave four notes, and at 0.99 only one was kept and three went to Unpitched
Confidences | Returns how sure the last transcription was of each note, in the order of the score. | a list of numbers from 0 to 1, the clarity of the pitch read; [ ] before a transcription | | Unpitched, SetMinClarity | | the values are measured from the sound, so assert ranges: rendered C4 E4 G4 C5 gave all four above 0.9
Unpitched | Returns the onsets the last transcription kept but could not give a pitch. | a list of [ seconds, clarity ]; [ ] when every onset had a pitch | | Confidences, SetMinClarity | | a drum hit lands here with its time: which stroke it was cannot be recovered, and it is not guessed
LastError | Returns why the last transcription produced nothing. | the reason as text; an empty text when nothing went wrong | | TranscribeQ | | for a missing sound it reads TranscribeQ: nothing to transcribe
TranscribeQ | Turns a sound into a stzSoundScore: finds the onsets, reads the pitch of each and keeps its clarity as the confidence. | a stzSoundScore at the given tempo with one note for each onset that had a clear pitch; an empty score when the sound is missing or empty, with the reason in LastError | poSound=the stzSound to read, which is not changed; pnBpm=the tempo, in beats a minute, that turns seconds into beats | Confidences, Unpitched, SetInstrument | | it is monophonic: two notes at once are not separated; a rendered C4 E4 G4 C5 at 96 beats a minute came back as notes starting at beats 0, 1, 2 and 3 at 261.63, 329.56, 391.83 and 523.19 hertz, against the true 261.63, 329.63, 392.00 and 523.25; the length of a note runs to the next onset, so the last one includes its ring-out; the sound is read in a mono copy made by the engine
