## 0. Findings that change the plan (read this first)

1. **whisper.cpp (MIT, v1.9.5 released 2026-10-06) now also runs NVIDIA Parakeet-TDT-0.6B-v3** (`src/parakeet.cpp` 149 KB + `parakeet-arch.h` 13 KB beside `src/whisper.cpp` 345 KB + `whisper-arch.h` 9 KB). Whole ASR core = ~520 KB of C++ source on top of ggml, which the engine already vendors. [github.com/ggml-org/whisper.cpp, api.github.com/.../contents/src, .../releases]
2. **llama.cpp `tools/mtmd/models/` now holds ggml graph code (MIT) for almost every model in this survey**: `whisper-enc.cpp` (4.7 KB), `qwen3a.cpp` (Qwen3-ASR audio encoder, 3.6 KB), `parakeet.cpp` (19.5 KB), `siglip.cpp` (4 KB), `qwen2vl.cpp`, `qwen3vl.cpp`, `internvl.cpp`, `deepseekocr.cpp` (18.6 KB), `paddleocr.cpp`, `dotsocr.cpp`, `pockettts-gen/seanet/spkenc.cpp`, `qwen3tts-gen.cpp` (36.6 KB), `mobilenetv5.cpp`, `granite-speech.cpp`, `voxtral-rt.cpp`. These are the reference for hand-writing the missing encoders in `neural_*.zig`. [api.github.com/repos/ggml-org/llama.cpp/contents/tools/mtmd/models]
3. **Granite-Docling-258M / SmolVLM-256M decoder is EXACTLY the geometry of the SmolLM2-135M the engine already ships**: `config.json` text_config = llama, hidden 576, 30 layers, 9 heads, 3 KV heads (vocab 100352 for Granite-Docling, 49280 for SmolVLM). Only the vision side is missing. [huggingface.co/ibm-granite/granite-docling-258M/raw/main/config.json, HuggingFaceTB/SmolVLM-256M-Instruct/raw/main/config.json]
4. **Qwen3-ASR-0.6B (Apache-2.0, 30 languages incl. French AND Arabic) has a Qwen3 decoder** -- an arch the engine runs -- plus a 214 MB (Q8) audio-encoder "mmproj". [huggingface.co/Qwen/Qwen3-ASR-0.6B, ggml-org/Qwen3-ASR-0.6B-GGUF]
5. **Licence traps found**: Piper repo ARCHIVED 2025-10-06, successor `OHF-Voice/piper1-gpl` is GPL-3.0 and embeds espeak-ng; `kokoro.cpp` source is MIT but espeak-ng (GPLv3+) is a hard link dependency so the binary is GPLv3+; Moonshine non-English models are non-commercial; Supertonic-3 weights are OpenRAIL-M and its repo is archived; Pocket-TTS weights CC-BY-4.0 and gated; MinerU2.5 weights AGPL-3.0; Qwen2.5-VL-3B is `qwen-research` licence (not Apache); Moondream 3 is BSL 1.1; Ultralytics YOLO is AGPL-3.0 (or paid Enterprise).
6. **C++ static-initialiser trap (engine-specific)**: `vendor/ggml/NOTICE` records that the Zig-built (mingw/gnu ABI) DLL does NOT run C++ static constructors on Windows. `whisper.cpp` has three file-scope `static const std::map<...>` (`g_model_name`, `g_lang`, `g_aheads`) and includes `<regex> <thread> <fstream>`. Vendoring it therefore needs the same ctor-independent patching the ggml vendoring already received (small: 3 maps -> switch/arrays) [verified by reading the first 100 KB of raw whisper.cpp; the remaining 245 KB were not read, so more statics may exist]. Same check is owed for parakeet.cpp and Tesseract.
7. **Engine facts that bound all of the work (read in `libraries/stzlib/engine/src`)**:
   - ONE global model slot: `neural_model_load()` calls `neural_model_free()` first (neural_embed.zig:46). A VLM/ASR needs two models (decoder + mmproj) -> needs a second slot.
   - Decoder input is token ids only: `ggml_get_rows(token_embd, tokens)` (neural_gen.zig:496). No path to inject precomputed embeddings -> required by every VLM and by Qwen3-ASR.
   - ggml ops used today (counted across neural_gen/embed/backbone): mul_mat, add, mul, norm, rms_norm, gelu, silu, soft_max_ext, rope_ext, get_rows, concat, permute, reshape, cont, view. NOT used: conv_1d, conv_2d, im2col, pool_2d, gelu_erf, transpose, repeat, swiglu_swapped, flash_attn_ext, upscale, win_part.
   - BUT the vendored ggml is recent and compiled with the CPU kernels for all of them (ggml.h declares `ggml_conv_1d`, `ggml_conv_2d`, `ggml_conv_2d_dw`, `ggml_conv_transpose_1d`, `ggml_im2col`, `ggml_pool_1d/2d`, `ggml_upscale`, `ggml_pad_reflect_1d`, `ggml_group_norm`, `ggml_gelu_erf`, `ggml_hardswish`, `ggml_swiglu_swapped`, `ggml_flash_attn_ext`, `ggml_win_part`; `ops.cpp` is 11,514 lines). So "missing op" = missing GRAPH CODE in Zig, not missing kernels. GPU backends were pruned away (no CUDA/Vulkan).
   - Optional GPU seam already exists: patched `traits.cpp` forwards big `GGML_OP_MUL_MAT` nodes to the wgpu plane (`neural_gpu.zig`); threshold is tuned to skip BERT-small but is designed for "multi-GFLOP nodes" -- exactly the shape of ViT-B/512 and Whisper encoders. Decode matvec stays CPU by design.

**Is whisper.cpp vendorable like ggml?** Yes in principle: MIT; core in `src/whisper.cpp` + `whisper-arch.h` + `include/whisper.h`; no external deps ("optional" BLAS/FFmpeg/SDL2 only in examples); its examples already decode with miniaudio (the engine has it). Costs: (a) three file-scope `std::map` ctors (see 0.6) plus `<regex>`; (b) version skew -- v1.9.5 bumped to ggml v0.26.0 and the engine's vendored ggml is a pruned snapshot of unknown commit (it does have `swiglu_swapped` and `conv_3d`, so it is recent); (c) the engine's DLL layout (one model slot, `needs_ggml` domains) means whisper should be its own domain DLL (`stz_speech`) rather than inside `stz_neural`; (d) CPU-only backend set (fine). Release cadence is monthly (v1.9.4 2026-09-11, v1.9.5 2026-10-06), so pin a tag.

**GPU (RTX 3050 6 GB) for ASR**: tiny/base/small and Silero are fine on CPU. large-v3-turbo (q5_0 574 MB) and Parakeet (q4_0 356 MB) fit easily in 6 GB and would gain from CUDA/Vulkan (whisper.cpp supports both, but the engine pruned them). Judgement, not measured. The wgpu MUL_MAT hook is the no-new-stack route for the Whisper/Parakeet encoders.

## 7. GOLDEN TASKS (propose only; nothing built)

Common rules: deterministic checker in Ring/Zig (`StzSplit`, `StzLen`, Levenshtein), thresholds fixed BEFORE any model number is taken (the plane's own kill-criterion discipline), each positive has a negative sibling (e.g. wrong-language input must be refused/low-confidence), and a **PERCEPTGATE record** (name + verdict) because these outputs reach a person: ASR transcript read by someone, TTS heard by someone, OCR'd render looked at by someone.

**G-ASR (16 items)**
- Item = `{wav path, language, reference text}`. Sources: 6 fr + 6 en utterances synthesised by the plane's own SAPI voices (Hortense / Zira) so references are exact; the same 4 re-mixed at 10 dB SNR white noise via the sound graph; 4 real public clips (LibriSpeech [CC-BY-4.0], FLEURS [CC-BY], Common Voice [CC0]) as fixtures incl. 2 Arabic -- **there is no Arabic SAPI voice here, so Arabic needs real clips**.
- Checker: normalise (lowercase, strip punctuation, strip Arabic diacritics/tatweel, NFC) -> word-level Levenshtein -> WER. Gates: mean WER <= 0.10 on clean synthetic, <= 0.20 noisy, <= 0.25 real fr/en, <= 0.35 ar (starting guesses to be ratified before running); per-item hard fail at 0.6.
- Anchor: reuse the VC3 nine-phrase set -- baseline to beat = SAPI free dictation 66.7% exact; target >= 80% exact.
- Also record RTF (not gated) and cold-start time.

**G-TTS (12 items)**
- Item = `{text, language}` (4 fr, 4 en, 4 ar if a model supports it). Objective checks with existing instruments: sample rate as declared (the "double speed" bug lesson), peak < 1.0 and > 0.05, integrated loudness inside a band via `stzSound.Loudness()`, duration within +-30% of chars/12 s, onset count (`ToOnsets`) inside [0.3, 1.2] x syllable estimate (VC0: 31 onsets on 5.42 s), no >1.5 s silent run; round-trip WER <= 0.15 through the reference ASR (Whisper-small) -- note both neural so also needs the human gate.
- PERCEPTGATE: one named listener plays the 12 WAVs (stored beside the guard) and records pass/fail per item. Instrumentation alone is refused as DONE.

**G-OCR (16 items)**
- Item = a PNG rendered by `stzCanvas` (fixed font, size, background) with known text: 6 fr (accents, apostrophes), 4 en, 6 ar (incl. the `مرحبا بالعالم` shaping-gap case; one with diacritics); sizes 12/16/24 px; two with Gaussian noise / JPEG-q40 degradation made by the library.
- Checker: CER = codepoint Levenshtein / reference length after NFC and Arabic normalisation, **comparing LOGICAL order** (Windows OCR returns visual order -- the checker must not forgive that). Gates: CER <= 0.02 Latin clean, <= 0.08 Arabic clean, <= 0.15 degraded; bounding boxes compared by IoU >= 0.5 against `RenderNodeRects`-style ground truth.
- Baseline row: `Windows.Media.Ocr` (fr exact; ar partial) must be beaten or matched.

**G-VISION (classification + detection, 20 items)**
- Classification (12): synthetic scenes rendered by Softanza (coloured shapes, digits in 3 fonts, simple icons) with a closed label set; zero-shot via SigLIP2/CLIP text prompts or a small linear head. Checker: top-1 equals label; 10/12 required. Plus 3 parity items: logits of the ggml port vs stored reference vectors, cosine >= 0.999 (this proves SAMENESS only, per PERCEPTGATE -- the 12 labelled items prove correctness).
- Detection (8): public-domain/CC0 photos with hand boxes (licence of each photo to be recorded), checker = IoU >= 0.5 and class match, recall >= 6/8, zero detections on 2 blank images (negative siblings).

**G-DOC (10 pages)**
- Item = a page rendered by Softanza from a known `stzTable` + headings + list + a paragraph, in en and fr (2 with Arabic cells). Ground truth = the source structure.
- Checker: parse the model's DocTags/Markdown -> compare table cell matrix (cell-wise exact-match F1 >= 0.9, TEDS-style structure equal), reading-order list of block types, per-block text CER <= 0.05. No LLM judge.
- Negative sibling: a page with no table must yield zero table blocks.
