Find

Returns the positions of every occurrence of the substring, as a list of numbers.written

Usage

Find(pcSubStr)

Parameters

NameTypeRole
pcSubStrtextthe text to look for, or a list of texts to look for togetherwritten

Returns

a list of numbers; [ ] when it is absentwritten

Notes

  • positions are in characters, not bytes
  • case-sensitive: FindCS takes the flag

Example

Every example is run by the library's own harness; the blue lines are what it printed.

o1 = new stzString("banana")
? @@( o1.Find("an") )
#--> [ 2, 4 ]
? @@( o1.Find("z") )
#--> [ ]
