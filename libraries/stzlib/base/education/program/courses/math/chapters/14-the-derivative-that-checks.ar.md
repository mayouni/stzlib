# المشتقة التي تفحص الصيغة

*الرياضيات · الفصل 14 · المهارة CR-02: «ما الذي سينكسر لو كنت مخطئًا؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

المشتقة ميل المنحنى عند موضع واحد: ما سرعة تغير القيمة حين يتحرك المدخل قليلًا. تعلّمها المدارس صيغةً تُشتق
يدويًا، والمشتقة المكتوبة يدويًا قد تكون خطأ. يحسب المحرك مشتقة أي تعبير صرّفه، بدقة، بالسير على شريط التعبير
نفسه، فتصبح الصيغة المكتوبة يدويًا ادعاءً يستطيع الشريط فحصه. يصرّف هذا الفصل دالة، ويقرأ مشتقتها من الشريط،
ويفحص صيغة صحيحة ويضبط صيغة خاطئة، ويؤكد علامات الفصل 4 بالميول.

## 1. صرّف دالة

الدالة تعبير على متغيرات مسمّاة، يُصرَّف مرة واحدة على شريط المحرك. اسأل عن قيمتها عند موضع.

```ring
oF = new stzMathFunction("x^3 - 2*x", [ "x" ])
? oF.ValueAt([ 2 ])
#--> 4
```

## 2. المشتقة، من الشريط

المشتقة عند اثنين عشرة. لم يُشتق شيء يدويًا: يحمل الشريط كيف تتغير كل عقدة مع x، ويقرأ المحرك الميل من جديد.

```ring
? oF.DerivativeAt("x", [ 2 ])
#--> 10
```

## 3. صيغة يدوية، مفحوصة

مشتقة الكتاب لمكعب x ناقص اثنين x هي ثلاثة x تربيع ناقص اثنين. عند اثنين تعطي عشرة، ويتفق الشريط. كانت الصيغة
ادعاءً؛ وهي الآن مفحوصة.

```ring
? 3 * 2 * 2 - 2
#--> 10
? fabs( (3 * 2 * 2 - 2) - oF.DerivativeAt("x", [ 2 ]) ) < 0.000001
#--> 1
```

## 4. صيغة خاطئة، مضبوطة

اكتب المشتقة ثلاثة x تربيع ناقص واحد، زلّة يد متعبة. عند اثنين تعطي أحد عشر، ويقول الشريط لا.

```ring
? 3 * 2 * 2 - 1
#--> 11
? fabs( (3 * 2 * 2 - 1) - oF.DerivativeAt("x", [ 2 ]) ) < 0.000001
#--> 0
```

## 5. شاهد ثالث: الفرق المنتهي

تحرك قليلًا على جانبي اثنين واقسم تغير القيمة على تغير المدخل. ذلك ميل مقيس لا مشتق، ويتفق مع الشريط في حدود
جزء من مليون.

```ring
h = 0.0001
nSlope = ( oF.ValueAt([ 2 + h ]) - oF.ValueAt([ 2 - h ]) ) / ( 2 * h )
? nSlope
#--> 10.00
? fabs( nSlope - 10 ) < 0.000001
#--> 1
```

## 6. متغيران، تدرّج واحد

مع متغيرين تكون المشتقة زوجًا، ميلًا لكل متغير. لـ x y زائد y تربيع عند اثنين وثلاثة، الميل على x ثلاثة وعلى y
ثمانية.

```ring
oG = new stzMathFunction("x*y + y^2", [ "x", "y" ])
? oG.ValueAt([ 2, 3 ])
#--> 15
? @@( oG.GradientAt([ 2, 3 ]) )
#--> [ 3, 8 ]
```

## 7. ميل الجيب عند الصفر

مشتقة الجيب هي جيب التمام. عند الصفر يقول الشريط واحدًا، ويقول جيب تمام الصفر في Ring واحدًا.

```ring
oS = new stzMathFunction("sin(x)", [ "x" ])
? oS.DerivativeAt("x", [ 0 ])
#--> 1
? fabs( oS.DerivativeAt("x", [ 0 ]) - cos(0) ) < 0.000000001
#--> 1
```

## 8. علامات الفصل 4، مؤكدة بالميول

وجد الفصل 4 القيمة القصوى لـ x تربيع ناقص اثنين عند الصفر بمراقبة انعطاف المنحنى. الميل هناك صفر، وهذا معنى
القيمة القصوى، وعند الصفر الآخر الميل ضعف الجذر التربيعي لاثنين.

```ring
oQ = new stzMathFunction("x^2 - 2", [ "x" ])
? oQ.DerivativeAt("x", [ 0 ])
#--> 0
? oQ.DerivativeAt("x", [ 1.41421356 ])
#--> 2.83
```

## الخلاصة

- **ما أنجزته:** صرّفت دالة على الشريط، وقرأت مشتقتها عند موضع، وفحصت صيغة مكتوبة يدويًا مقابلها وضبطت صيغة
  خاطئة، وقست الميل بفرق منتهٍ شاهدًا ثالثًا، وقرأت تدرّج متغيرين، وأكدت علامات الفصل 4 بالميول.
- **لماذا يهم:** الصيغة المشتقة يدويًا ادعاء. يحسب الشريط الميل نفسه بطريق آخر، فيُفحص الادعاء بشيء لم يعرف
  الصيغة.
- **ما التالي:** الفحص الذي لا يمكن أن يفشل ليس فحصًا. يميّز الفصل الأخير الفحص الذاتي من الفحص المستقل، ويبيّن
  لماذا يحتاج كل إيجاب إلى سلب بجانبه.
