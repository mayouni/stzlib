# لعبة الفوضى

*الرياضيات · الفصل 3 · المهارة PA-02: «ما شكل هذه القائمة أو هذه الأعداد؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

خذ أركان مثلث الثلاثة وقلمًا في أي مكان داخله. ارمِ نردًا: واحد أو اثنان يعني الركن الأول، وثلاثة أو أربعة
الثاني، وخمسة أو ستة الثالث. تحرك نصف الطريق من حيث أنت نحو ذلك الركن، وضع نقطة. ارمِ مرة أخرى. بعد ألفي رمية،
النقاط ليست لطخة: هي مثلث مليء بالثقوب، الشكل نفسه في كل حجم، لم يرسمه أحد. يلعب هذا الفصل اللعبة بأعداد المكتبة
العشوائية، ويعدّ ما يظهر بدل أن يتأمله.

## 1. ثلاثة أركان

الأركان ثلاثة مواضع على الصفحة. لا تتحرك أبدًا؛ القلم وحده يتحرك.

```ring
? @@( StzChaosGameCorners() )
#--> [ [ 320, 40 ], [ 40, 560 ], [ 600, 560 ] ]
```

## 2. الرميات الست الأولى

كل نقطة بيانات: موضع أنتجته القاعدة. البذرة تجعل الرميات هي نفسها في كل مرة تُشغَّل فيها هذه الخلية، فيمكن أن
يُقطع وعد حول الحظ.

```ring
oS = StzChaosGameSubstance(6, 7)
for i = 1 to 6
	? "" + oS.DataOf("d" + i, "x") + ", " + oS.DataOf("d" + i, "y")
next
#--> 320, 170
```

## 3. ألفا رمية

الصورة رسم لا شيء فيه يُحل: ألفا نقطة، كل واحدة مرسومة حيث تقول بياناتها.

```ring
oG = StzChaosGamePictureQ(StzMathFigureFont(), 2000, 7)
? oG.NumberOfShapes()
#--> 2000
? oG.NumberOfUnknowns()
#--> 0
```

## 4. ما يظهر، معدودًا

لمثلث سيربنسكي علامتان. كل نقطة تقع داخل المثلث الخارجي، ولا نقطة واحدة داخل الثقب الأوسط، المثلث الذي أركانه
منتصفات الأضلاع. تعدّ المكتبة الاثنتين باختبار مستقل على موضع كل نقطة: لم تُخبَر القاعدة قط عن الثقب.

```ring
aC = StzChaosGameCounts(oG, 2000)
? aC[1]
#--> 2000
? aC[2]
#--> 0
```

## 5. حظ، ومع ذلك الشكل نفسه

بذرة أخرى تعطي رميات أخرى ونقاطًا أخرى، ويخرج العددان كما هما. الشكل للقاعدة، لا للرميات.

```ring
oH = StzChaosGamePictureQ(StzMathFigureFont(), 500, 11)
? @@( StzChaosGameCounts(oH, 500) )
#--> [ 500, 0 ]
```

## 6. موضع النقطة هو بياناتها

لا تخفي الصورة شيئًا: تُرسم النقطة تمامًا حيث تضعها بياناتها، ويمكنك قراءة الاثنين.

```ring
? oG.ValueOf("d7.icon.cx") = oG.Substance().DataOf("d7", "x")
#--> 1
```

## الخلاصة

- **ما أنجزته:** لعبت لعبة الفوضى بأعداد عشوائية ذات بذرة، ورسمت ألفي نقطة دون أن يُحل شيء، وعددت علامتي مثلث
  سيربنسكي باختبار مستقل بدل الثقة بعينيك.
- **لماذا يهم:** النمط الذي يظهر من الحظ ادعاء كأي ادعاء. عدّ ما أنتجته القاعدة هو ما يجعل الصورة دليلًا.
- **ما التالي:** الدالة صورة أيضًا. الفصل التالي يرسم واحدة، ويعلّم أين تقطع الصفر وأين تنعطف، ويفحص كل علامة.
