# الإحصاء لغةً للتفكير

*الرياضيات · الفصل 9 · المهارة FO-01: «ما الذي أسأل عنه حقًّا، بأقل الكلمات؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

ثمانية أعداد ثماني حقائق. الإحصاء هو اللغة التي تقول ما يشتركون فيه بكلمات قليلة، ومخطط الصندوق تلك اللغة
مرسومة: أين الوسط، وما عرض النصف الأوسط، وأي قيمة تقف وحدها. يأخذ هذا الفصل ثماني قيم عبر الكلمات، ثم عبر
الصورة، ويتحقق من أن الاثنتين تقولان الشيء نفسه.

## 1. ثماني قيم، وسطان

المتوسط يجمع كل شيء ويقسم. الوسيط هو القيمة في الوسط بعد ترتيب القيم. قيمة كبيرة واحدة تشد المتوسط إلى الأعلى
وتترك الوسيط حيث كان.

```ring
aV = [ 2, 4, 4, 5, 7, 9, 12, 25 ]
oD = new stzDataSet(aV)
? oD.Mean()
#--> 8.50
? oD.Median()
#--> 6
```

## 2. الأرباع والقيمة التي تقف وحدها

تقطع الأرباع القيم المرتبة أربعة أجزاء. القيمة البعيدة عن النصف الأوسط قيمة شاذة، ومجموعة البيانات تسمّيها.

```ring
? @@( oD.Quartiles() )
#--> [ 4, 6, 9.75 ]
? @@( oD.Outliers() )
#--> [ 25 ]
```

## 3. الكلمات نفسها، مرسومة

يُعلن شكل مخطط الصندوق بقيمه. جملته تقول الأعداد نفسها التي قالتها مجموعة البيانات: الصندوق من الربع الأول إلى
الثالث، والوسيط داخله، والقيمة الشاذة معدودة.

```ring
oB = StzMathFigureQ(:BoxPlot, [ :of = aV, :label = "eight values" ])
? oB.Why()
#--> a box plot of 1 group(s): n = 8, box 4 | 6 | 9.75, 1 outlier(s)
? len( oB.Violations() )
#--> 0
```

## 4. الصورة نصًّا

يستطيع الشكل أن يقول نفسه نصًّا، لطرفية أو رسالة أو صفحة بلا صورة: الأعداد، ثم الصندوق والشاربان والقيمة
المنفردة.

```ring
? oB.Text()
#--> group 1  n=8  min 2  Q1 4  med 6  Q3 9.75  max 25  outliers 1
```

## 5. شاذة بقاعدة، لا برأي

القاعدة سياج: مرة ونصف عرض الصندوق، بعد الربع الثالث. خمسة وعشرون تقع بعده، فيتوقف الشارب عند اثني عشر، آخر قيمة
داخله.

```ring
aS = oD.BoxPlotStats()
? aS[:iqr]
#--> 5.75
? 9.75 + 1.5 * 5.75
#--> 18.38
? 25 > 18.375
#--> 1
? aS[:whisker_high]
#--> 12
```

## 6. مجموعتان جنبًا إلى جنب

تتقاسم مجموعتان محورًا واحدًا، فتقارن العين وسطيهما بلا عدد. للصباح قيمة شاذة؛ وللمساء لا شيء.

```ring
oG = StzMathFigureQ(:BoxPlot, [ :groups = [ [ "morning", [ 12, 15, 14, 18, 16, 15, 13, 40 ] ],
                                            [ "evening", [ 20, 22, 19, 25, 24, 21, 23, 22 ] ] ] ])
? oG.Why()
#--> a box plot of 2 group(s): morning n = 8, box 13.75 | 15 | 16.5, 1 outlier(s); evening n = 8, box 20.75 | 22 | 23.25, 0 outlier(s)
```

## 7. التشتت عددًا واحدًا

الانحراف المعياري يقول كم تبعد القيم عن المتوسط، في المتوسط. هو عدد واحد للتشتت كله، وهو أيضًا تشده القيمة
المنفردة.

```ring
? oD.StandardDeviation()
#--> 7.39
```

## 8. على عالمك

كم طلبًا من كل نوع تلقت مدرستك، مجموعةَ بيانات: متوسط العدد لكل نوع ووسيطه. ما يطبعه يتوقف على العالم الذي يجري
عليه هذا الدرس، ولذلك لا تعرض الصفحة أي نتيجة: شغّله.

```ring
aReq = EduWorldObjects("requested")
aKinds = StzListQ(aReq).DuplicatesRemoved()
aCounts = []
for i = 1 to len(aKinds)
	aCounts + StzListQ(aReq).NumberOfOccurrence(aKinds[i])
next
oK = new stzDataSet(aCounts)
? EduWorldName()
? oK.Mean()
? oK.Median()
```

## الخلاصة

- **ما أنجزته:** لخّصت ثماني قيم بكلمات، متوسطًا ووسيطًا وأرباعًا وقيمة شاذة، ثم رسمتها مخطط صندوق تقول جملته
  ونصه الأعداد نفسها، وطبّقت قاعدة السياج يدويًا، وقارنت مجموعتين، وقرأت التشتت عددًا واحدًا.
- **لماذا يهم:** الملخص ادعاء عن أعداد كثيرة. حين تتفق الكلمات والصورة والقاعدة يكون الادعاء مفحوصًا بثلاث طرق؛
  وحين يختلف أحدها تعرف أيّها.
- **ما التالي:** الحظ. الفصل التالي يرمي عملة ألف مرة ويقرأ النسبة على المتصل من القليل إلى الأكثر.
