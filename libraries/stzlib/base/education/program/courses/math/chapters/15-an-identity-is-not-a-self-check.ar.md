# المتطابقة ليست فحصًا ذاتيًا

*الرياضيات · الفصل 15 · المهارة CR-02: «ما الذي سينكسر لو كنت مخطئًا؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

يساوي الفحص بالضبط احتمال فشله. احسب عددًا من صيغة، ثم افحص الصيغة مقابل العدد الذي حسبته للتو، فيمر الفحص
مهما قالت الصيغة: هذه متطابقة، والمتطابقة لا تثبت شيئًا. الفحص الحقيقي يقارن طريقين مستقلين إلى حقيقة واحدة،
ويجب أن يكون قادرًا على الفشل. يبني هذا الفصل فحصًا لا يمكن أن يفشل، ثم الادعاء نفسه مفحوصًا بصورة لم تسمع
بالصيغة قط، وبخوارزمية ثانية، وبالشريط، ويبيّن السلب الذي يحتاجه كل إيجاب.

## 1. فحص لا يمكن أن يفشل

احسب الوتر من الضلعين بالصيغة، ثم «افحص» الصيغة مقابله. صفر، دائمًا.

```ring
a = 3
b = 4
c = sqrt( a*a + b*b )
? a*a + b*b - c*c
#--> 0
```

## 2. الصيغة الخاطئة تفحص نفسها بالجودة نفسها

أضف واحدًا تحت الجذر، وهو ما لا يسمح به مثلث قائم، وافحص الصيغة الخاطئة مقابل عددها هي. صفر ثانية. لم يلاحظ
الفحص شيئًا، لأنه لم يستطع.

```ring
c2 = sqrt( a*a + b*b + 1 )
? a*a + b*b + 1 - c2*c2
#--> 0.00
```

## 3. الصورة التي لم تسمع بالصيغة قط

حُلّت صورة بيرن في الفصل 6 من ثلاث نقاط وزاوية قائمة؛ ولم تكن مساواة المربعات قاعدة قط. قس أضلاعها الثلاثة
وافحص الصيغة مقابل قياسات لم تأتِ منها. الآن كان يمكن للفحص أن يفشل، ولم يفشل.

```ring
oP = StzPythagorasPictureQ( StzMathFigureFont() )
nAB = oP.Fact(:distance, [ "A.icon", "B.icon" ])[:value]
nAC = oP.Fact(:distance, [ "A.icon", "C.icon" ])[:value]
nBC = oP.Fact(:distance, [ "B.icon", "C.icon" ])[:value]
? fabs( nBC*nBC - nAB*nAB - nAC*nAC ) < 0.01
#--> 1
```

## 4. خوارزميتان لعدد واحد

يجد شكل الدالة صفر x تربيع ناقص ثلاثة بحصر تغيّر إشارة. ويجد جذر Ring التربيعي العدد نفسه بخوارزمية أخرى.
طريقان، حقيقة واحدة، في حدود جزء من مليون.

```ring
oFig = StzMathFigureQ(:Function, [ :f = "x^2 - 3", :on = [ -3, 3 ], :mark = [ :zeros ] ])
aZ = oFig.Zeros()
z = aZ[1][1]
? z
#--> 1.73
? fabs( z - sqrt(3) ) < 0.000001
#--> 1
```

## 5. السلب الذي يحتاجه كل إيجاب

الفحص الذي يقول نعم ليس دليلًا إلا إذا كان سيقول لا لجواب خاطئ. ناوله واحدًا: واحد ونصف ليس جذر الثلاثة،
ويرفضه الفحص نفسه.

```ring
? fabs( 1.5 * 1.5 - 3 ) < 0.000001
#--> 0
```

## 6. الشريط طريقًا ثالثًا

وجد الفصل 4 القيمة القصوى لـ x تربيع ناقص اثنين بمراقبة انعطاف المنحنى؛ وقرأ الفصل 14 الميل من الشريط. القيمة
القصوى حيث الميل صفر، ويتفق الشريط دون أن يكون قد راقب المنحنى.

```ring
oQ = new stzMathFunction("x^2 - 2", [ "x" ])
? oQ.DerivativeAt("x", [ 0 ])
#--> 0
? oQ.DerivativeAt("x", [ 1 ])
#--> 2
```

## 7. على عالمك

عدّ طلبات هذا الأسبوع في مدرستك بطريقتين: طول القائمة، ومجموع الأعداد بحسب النوع. طريقان إلى عدد واحد؛ لا تعرض
الصفحة نتيجة لأنها تتوقف على العالم: شغّله.

```ring
aReq = EduWorldObjects("requested")
aKinds = StzListQ(aReq).DuplicatesRemoved()
nSum = 0
for i = 1 to len(aKinds)
	nSum += StzListQ(aReq).NumberOfOccurrence(aKinds[i])
next
? EduWorldName()
? len(aReq)
? nSum
```

## الخلاصة

- **ما أنجزته:** بنيت فحصًا لا يمكن أن يفشل ورأيته يقبل صيغة خاطئة، ثم فحصت الادعاء نفسه مقابل صورة لم تسمع به
  قط، ومقابل خوارزمية ثانية، ومقابل الشريط، وأعطيت الفحص جوابًا خاطئًا ليرفضه.
- **لماذا يهم:** كل ادعاء في هذا الدرس حمل فحصه، وهذا الفصل يقول ما الذي أعطى تلك الفحوص قيمتها: قارنت طرقًا
  مستقلة، وكان يمكن لكل منها أن يفشل.
