# خط الأعداد

*الرياضيات · الفصل 1 · المهارة SE-01: «هل تجيب الصورة أسرع من العدد؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

العدد موضع. ثلاثة، وسالب اثنين، وسبعة ونصف، ثلاثة مواضع على خط واحد، وهذا الخط أول صورة في الرياضيات: كل ما
عليه له موقع وترتيب ومسافة. يعلن هذا الفصل خط أعداد على طريقة سوفتانزا. أنت تقول ما عليه؛ والشكل يحسب أين يقع
كل شيء، ويرسمه، ويحكم على صورته قبل أن تثق بها.

## 1. أعلن الخط

يُعلن خط الأعداد بمفاتيح: المدى الذي يغطيه، والنقاط التي عليه. يجيب الشكل بجملة واحدة عمّا حسبه.

```ring
oL = StzMathFigureQ(:NumberLine, [ :on = [ -5, 10 ], :points = [ 3, -2, 7.5 ] ])
? oL.Why()
#--> a number line from -5 to 10: 16 ticks, 3 point(s), 0 jump(s)
```

## 2. الصورة تحكم على نفسها

كل شكل يحمل قواعد. خط الأعداد يجب أن يحفظ نقاطه بترتيب أعدادها، وأن يُنزل القفزة حيث تقول القفزة، وأن يُبقي كل
اسم مقروءًا بجانب نقطته. اسأل الشكل هل خالفت صورته قاعدةً ما. الصفر هو الجواب الذي تريده، وهو محسوب لا موعود.

```ring
? len( oL.Violations() )
#--> 0
```

## 3. الترتيب سؤال يمكن طرحه

أيهما أبعد إلى اليسار، سالب اثنين أم ثلاثة؟ على الخط، اليسار يعني الأصغر. تجيب سوفتانزا بعدد: واحد للصواب، وصفر
للخطأ.

```ring
? -2 < 3
#--> 1
? 7.5 < 3
#--> 0
```

## 4. القفزة فرق

القفزة من موضع إلى آخر تُرسم قوسًا، ويتحقق الشكل من أن القوس ينزل حيث يقول. للقفزة طرفان، ويعدّهما الشكل نقطتين.
من تسعة إلى أربعة قفزة قدرها سالب خمسة: تتجه إلى اليسار.

```ring
oJ = StzMathFigureQ(:NumberLine, [ :on = [ 0, 12 ], :jumps = [ [ 9, 4 ] ], :step = 1 ])
? oJ.Why()
#--> a number line from 0 to 12: 13 ticks, 2 point(s), 1 jump(s)
? 4 - 9
#--> -5
```

## 5. المسافة بين موضعين

المسافة فرق نُزعت منه إشارته. بين سالب اثنين وسبعة ونصف تسع وحدات ونصف، من أي طرف بدأت.

```ring
? fabs( 7.5 - (-2) )
#--> 9.50
? fabs( -2 - 7.5 )
#--> 9.50
```

## 6. سمِّ موضعًا

يمكن للنقطة أن تحمل اسمًا، ويضع الشكل الاسم حيث يُقرأ دون أن يلمس الخط أو العلامات أو اسمًا آخر. النصف يقع في
منتصف الطريق بين الصفر والواحد.

```ring
oN = StzMathFigureQ(:NumberLine, [ :on = [ 0, 2 ], :step = 0.5,
                                   :points = [ [ 0.5, "half" ], [ 1.5, "one and a half" ] ] ])
? oN.Why()
#--> a number line from 0 to 2: 5 ticks, 2 point(s), 0 jump(s)
? len( oN.Violations() )
#--> 0
```

## 7. على عالمك

تعدّ هذه الخلية الطلبات التي تلقتها مدرستك هذا الأسبوع وتضع العدد على خط. ما تطبعه يتوقف على العالم الذي يجري
عليه هذا الدرس، ولذلك لا تعرض الصفحة أي نتيجة أبدًا: شغّلها.

```ring
aReq = EduWorldObjects("requested")
oW = StzMathFigureQ(:NumberLine, [ :on = [ 0, 10 ], :points = [ [ len(aReq), "requests" ] ] ])
? EduWorldName()
? oW.Why()
```

## الخلاصة

- **ما أنجزته:** أعلنت خط أعداد بمداه ونقاطه، وقرأت جملة الشكل عن نفسه عمّا حسبه، وطلبت منه أن يحكم على صورته،
  وقارنت بين موضعين، وقفزت بينهما، وقست المسافة بينهما.
- **لماذا يهم:** الصورة تُعلن وتُحسب ثم تُفحص. لم يُرسم عليها شيء باليد، فلا شيء عليها يمكن أن يكون خطأ في صمت:
  كل ادعاء في هذا الفصل سطر طبعه الشكل.
- **ما التالي:** الكسر جزء من كل، والفصل التالي يظلّله، ويقارن بين كسرين، ويقرأ الحكم من الصورة.
