# المصفوفات صورًا

*الرياضيات · الفصل 8 · المهارة PA-04: «أي الخلايا تجيب عن سؤالي؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

المصفوفة شبكة أعداد، وجداء مصفوفتين شبكة كل خلية فيها صف من الأولى يلتقي بعمود من الثانية. بوصفه صورة، الجداء
ثلاث شبكات جنبًا إلى جنب، مع الصف والعمود والخلية التي يصنعانها مضاءة معًا. يعلن هذا الفصل المصفوفات أشكالًا،
ويقرأ خلية من الشكل، ويفحص خلية جداء يدويًا، ويطلب من الشكل أن يرفض ما لا يمكن ضربه.

## 1. شبكة واحدة

يُعلن شكل المصفوفة بصفوفه. يعدّ الشكل خلاياه ويسمّيها بحرف الشبكة والصف والعمود: الشبكة الأولى a، وصفها الثاني
وعمودها الأول a2_1.

```ring
oA = StzMathFigureQ(:Matrix, [ :of = [ [ 1, 2 ], [ 3, 4 ] ], :label = "A" ])
? oA.Why()
#--> a matrix figure: A (2 x 2), 4 cells
? oA.Fact(:datum, [ "a2_1", "v" ])[:message]
#--> a2_1 carries v = 3
```

## 2. جداء، ثلاث شبكات

أعلن جداءً فيرسم الشكل A وB وA في B، ويحسب كل خلية من النتيجة، ويضيء الصف والعمود اللذين يصنعان الخلية التي
تطلب رؤيتها.

```ring
oP = StzMathFigureQ(:Matrix, [ :product = [ [ [ 2, 7, 1, 8 ], [ 2, 8, 1, 8 ], [ 2, 8, 4, 5 ] ],
                                            [ [ 1, 0 ], [ 0, 1 ], [ 2, 3 ], [ 1, 1 ] ] ], :show = [ 2, 1 ] ])
? oP.Why()
#--> a matrix figure: A (3 x 4) . B (4 x 2) = A . B (3 x 2), 26 cells
```

## 3. الصورة تحكم على نفسها

يحمل شكل المصفوفة ثلاث قواعد: خلية الجداء هي الجداء النقطي لصفها وعمودها، والأبعاد تتفق، وكل شبكة تحتوي خلاياها.
يفحصها الشكل على صورته.

```ring
? len( oP.Violations() )
#--> 0
```

## 4. خلية جداء، مفحوصة يدويًا

الخلية المضاءة هي الصف 2 من A يلتقي بالعمود 1 من B. اقرأها من الشكل، ثم احسبها بنفسك: اثنان في واحد، زائد ثمانية
في صفر، زائد واحد في اثنين، زائد ثمانية في واحد.

```ring
? oP.Fact(:datum, [ "c2_1", "v" ])[:message]
#--> c2_1 carries v = 12
? 2 * 1 + 8 * 0 + 1 * 2 + 8 * 1
#--> 12
```

## 5. ما لا يمكن ضربه

يجب أن يكون صف A بطول عمود B. الجداء الذي يخالف ذلك يُرفض بالاسم، مع العددين المختلفين.

```ring
try
	StzMathFigureQ(:Matrix, [ :product = [ [ [ 1, 2 ] ], [ [ 1, 2 ] ] ] ])
catch
	? "refused"
done
#--> refused
```

## 6. الأعداد لونًا

إذا طُلب عرض المصفوفة حرارةً، لوّن الشكل كل خلية على تدرج واحد من أصغر قيمة إلى أكبرها. موضع التدرج عدد يحمله
الشكل: أكبر قيمة عند الواحد.

```ring
oH = StzMathFigureQ(:Matrix, [ :of = [ [ 4, 1, 0 ], [ 1, 4, 1 ], [ 0, 1, 4 ] ], :as = :heat, :label = "A" ])
? oH.Why()
#--> a matrix figure: A (3 x 3), 9 cells on one ramp
? oH.Fact(:datum, [ "a2_2", "t" ])[:message]
#--> a2_2 carries t = 1
```

## 7. على عالمك

صف واحد: كم طلبًا من كل نوع تلقت مدرستك هذا الأسبوع، مرسومًا مصفوفة. ما يطبعه يتوقف على العالم الذي يجري عليه
هذا الدرس، ولذلك لا تعرض الصفحة أي نتيجة: شغّله.

```ring
aReq = EduWorldObjects("requested")
aKinds = StzListQ(aReq).DuplicatesRemoved()
aRow = []
for i = 1 to len(aKinds)
	aRow + StzListQ(aReq).NumberOfOccurrence(aKinds[i])
next
oW = StzMathFigureQ(:Matrix, [ :of = [ aRow ], :label = "requests by kind" ])
? EduWorldName()
? oW.Why()
```

## الخلاصة

- **ما أنجزته:** أعلنت مصفوفةً شكلًا، وقرأت خلية باسمها، وأعلنت جداءً ورأيت شبكاته الثلاث، وفحصت خلية جداء
  يدويًا مقابل قيمة الشكل نفسه، ورأيت جداءً مرفوضًا لأبعاده، ولوّنت مصفوفة على تدرج واحد.
- **لماذا يهم:** الجداء ست وعشرون خلية وقاعدة واحدة. يحسب الشكل كل خلية ويحمل القاعدة، فالخلية الواحدة التي
  تفحصها يدويًا تنوب عنها جميعًا.
- **ما التالي:** حفنة من الأعداد، والكلمات التي تلخصها. الفصل التالي يرسم مخطط صندوق ويقرأ الوسيط والأرباع والقيم
  الشاذة من الصورة.
