# الدالة صورة

*الرياضيات · الفصل 4 · المهارة SE-02: «أين، وكم؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

الدالة قاعدة تحوّل عددًا إلى عدد آخر، وصورتها مجموعة كل المواضع التي تبلغها القاعدة. تجيب الصورة عمّا تخفيه
الصيغة: أين تعطي القاعدة صفرًا، وأين تكفّ عن الصعود وتبدأ الهبوط، وأين تنكسر. يعلن هذا الفصل دالةً شكلًا.
المنحنى يحسبه المحرك؛ والعلامات عليه تُوجد وتوضع ثم تُفحص واحدة واحدة بالحساب.

## 1. أعلن الدالة

يُعلن شكل الدالة بصيغتها، والمدى الذي تُرسم عليه، والعلامات التي تريد إيجادها.

```ring
oF = StzMathFigureQ(:Function, [ :f = "x^2 - 2", :on = [ -3, 3 ], :mark = [ :zeros, :extrema ] ])
? oF.Why()
#--> a function figure: 400 samples in 1 piece(s), 3 mark(s)
```

## 2. أين تنعدم، وأين تنعطف

وجد الشكل صفرين وقيمة قصوى واحدة. كل علامة موضع: x وy.

```ring
? @@( oF.Zeros() )
#--> [ [ 1.41, -0.00 ], [ -1.41, -0.00 ] ]
? @@( oF.Extrema() )
#--> [ [ 0, -2 ] ]
```

## 3. العلامة ادعاء، والادعاء يُفحص

يقول الشكل إن المنحنى ينعدم عند 1.41. يفحص الحساب ذلك: ربّع هذا العدد واطرح اثنين، فما يبقى أصغر من جزء من
مليون. وجد الشكل الجذر التربيعي لاثنين دون أن يُقال له.

```ring
aZ = oF.Zeros()
z = aZ[1][1]
? z
#--> 1.41
? fabs( z * z - 2 ) < 0.000001
#--> 1
```

## 4. الصورة تحكم على نفسها

يحمل شكل الدالة قواعد: علامة الصفر تحصر تغيّر إشارة، وعلامة القيمة القصوى تحصر انعطافًا، وكل ملاحظة تُقرأ قرب
علامتها. الصفر مخالفات محسوب، لا موعود.

```ring
? len( oF.Violations() )
#--> 0
```

## 5. النافذة تُختار من المنحنى

ينظر الشكل إلى القيم التي حسبها ويترك هواءً فوقها وتحتها، فلا تلمس العلامات الإطار أبدًا. النافذة أربعة أعداد:
من وإلى على x، ثم على y.

```ring
? @@( oF.Window() )
#--> [ -3, 3, -3.33, 8.33 ]
```

## 6. طرق أخرى لقول المنحنى

ليس المنحنى بالضرورة y بدلالة x. الدائرة هي x وy بدلالة عدد ثالث t، والوردة مسافة r بدلالة زاوية t. لا شيء
معلَّم على هذين المنحنيين، فلا شيء يُحل: يقول الشكل ذلك.

```ring
oCircle = StzMathFigureQ(:Function, [ :x = "cos(t)", :y = "sin(t)", :t = [ 0, 6.2832 ], :label = "a circle" ])
? oCircle.Why()
#--> a function figure: 400 samples in 1 piece(s), 0 mark(s); nothing to lay out
oRose = StzMathFigureQ(:Function, [ :r = "cos(3*t)", :t = [ 0, 3.1416 ], :label = "a rose" ])
? oRose.Why()
#--> a function figure: 400 samples in 1 piece(s), 0 mark(s); nothing to lay out
```

## 7. مماس عند موضع تسمّيه

اطلب المماس عند x يساوي واحدًا فيضيف الشكل علامة معطاة هناك، مع ارتفاع المنحنى في ذلك الموضع: جيب الواحد
0.84.

```ring
oT = StzMathFigureQ(:Function, [ :f = "sin(x)", :on = [ -6.3, 6.3 ], :mark = [ :extrema ], :tangent = 1, :maxmarks = 4 ])
? @@( oT.Marks() )
#--> [ "given", 1, 0.84 ]
```

## 8. أين تنكسر القاعدة

واحد على x ناقص واحد لا قيمة له عند x يساوي واحدًا. لا يرسم الشكل عبر الانكسار: يرسم قطعتين ويقول أين لم
يستطع المضي.

```ring
oP = StzMathFigureQ(:Function, [ :f = "1 / (x - 1)", :on = [ -3, 4 ] ])
? oP.Why()
#--> a function figure: 400 samples in 2 piece(s), 0 mark(s), 1 place(s) not finite
? oP.PieceCount()
#--> 2
```

## 9. على عالمك

خط يمر بالأصل ميله عدد الطلبات التي تلقتها مدرستك هذا الأسبوع. ما يطبعه يتوقف على العالم الذي يجري عليه هذا
الدرس، ولذلك لا تعرض الصفحة أي نتيجة: شغّله.

```ring
aReq = EduWorldObjects("requested")
oW = StzMathFigureQ(:Function, [ :f = "" + len(aReq) + " * x", :on = [ -2, 2 ], :mark = [ :zeros ] ])
? EduWorldName()
? oW.Why()
```

## الخلاصة

- **ما أنجزته:** أعلنت دالةً شكلًا، وقرأت أين تنعدم وأين تنعطف، وفحصت صفرًا بالحساب، وقرأت النافذة التي اختارها
  الشكل، ورسمت دائرة ووردة، وطلبت مماسًا، ورأيت الشكل يتوقف عند انكسار بدل الرسم عبره.
- **لماذا يهم:** المنحنى محسوب والعلامات موجودة، فكل موضع تسمّيه الصورة ادعاء يمكنك فحصه بسطر واحد من الحساب،
  وهذا ما فعله هذا الفصل.
- **ما التالي:** ضع حرفًا في الصيغة فتصبح الصورة عائلة. الفصل التالي يحرّك الحرف ويراقب ما يتحرك معه.
