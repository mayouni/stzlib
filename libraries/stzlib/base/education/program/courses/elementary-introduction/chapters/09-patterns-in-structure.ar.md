# الأنماط في البنية

*مدخل أساسي · الفصل 9 · المهارة PA-02: «ما شكل هذه القائمة أو هذه الأرقام؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

للقائمة شكل: رقم، ثم نص. وللرقم شكل: أربعة أرقام، أو أولي، أو من مضاعفات الخمسة. تكتب سوفتانزا هذه الأشكال
أنماطًا أيضًا، بـ `Lx()` للقوائم و`stzNumbrex` للأرقام، وتختبر البيانات مقابلها كما اختبر الفصل 8 النص.

## 1. شكل القائمة

`@N` رقم، و`@S` نص. سطر الطلبية عدد حصص ثم طبق.

```ring
? Lx("[@N, @S]").Match([ 42, "hello" ])
#--> TRUE
? Lx("[@N, @S]").Match([ "hello", 42 ])
#--> FALSE
```

## 2. كم من كل نوع

`@N1-3` تعني من رقم إلى ثلاثة أرقام.

```ring
? Lx("[@N1-3, @S]").Match([ 1, 2, "end" ])
#--> TRUE
? Lx("[@N1-3, @S]").Match([ 4, 5, 6, 7, "extra" ])
#--> FALSE
```

## 3. شكل داخل شكل

```ring
? Lx("[@N, [@N2], @N]").Match([ 1, [ 2, 3 ], 4 ])
#--> TRUE
```

## 4. شكل الرقم

نمط الرقم يسمّي خاصية. `Prime` واحدة منها؛ لدى 17 هذه الخاصية وليست لدى 18.

```ring
oNx = new stzNumbrex("{@Property(Prime)}")
? oNx.Match(17)
#--> TRUE
? oNx.Match(18)
#--> FALSE
```

## 5. المضاعفات، وعدد الأرقام

```ring
oNx5 = new stzNumbrex("{@Relation(Mod:5=0)}")
? oNx5.Match(10)
#--> TRUE
? oNx5.Match(13)
#--> FALSE
oNx4 = new stzNumbrex("{@Digit4}")
? oNx4.Match(1234)
#--> TRUE
? oNx4.Match(123)
#--> FALSE
```

## الخلاصة

- **ما أنجزته:** اختبرت قوائم مقابل شكل من الأنواع والأعداد، وأدخلت شكلًا في شكل، واختبرت أرقامًا لخاصية
  ولمضاعف ولعدد أرقام.
- **لماذا يهم:** البيانات السيئة بيانات بشكل خاطئ. الشكل المكتوب مرة واحدة يرفض كل صف سيئ سيصل يومًا،
  ويقول لماذا.
- **ما التالي:** حين تكون للبيانات صفوف وأعمدة فهي جدول، وللجدول أسئلته الخاصة.
