# اكتب سردًا

*مدخل أساسي · الفصل 15 · المهارات CR-01 «هل ما زال كل مثال في وثيقتي يعمل؟» وCR-02 «ماذا سينكسر لو كنت مخطئًا؟» وCR-03 «لماذا قال لا؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

كل فصل قرأته فُحص بتشغيله، خليةً خلية، قبل أن يصلك. يسلّمك هذا الفصل الأخير الأدوات نفسها: سردًا تعمل كل
خلاياه، وحارسًا بحالة إيجابية وأخرى سلبية، وحكمًا يشرح نفسه.

## 1. السرد ملف نصي فيه وعود

الخلية تعد بما تطبعه. يشغّل مشغّل الفصول كل خلية في عملية جديدة ويقارن.

```ring
cDoc = "# Mini" + char(10) + "```ring" + char(10) + "? 1 + 1" + char(10) + "#--> 2" + char(10) + "```" + char(10)
cMini = "t_mini_" + ProcessId() + ".en.md"
write(cMini, cDoc)
oCh = StzChapterQ(cMini, "en")
oCh.Run("")
? oCh.NumberOfCells()
#--> 1
? oCh.AllPromisesKept()
#--> TRUE
```

## 2. الوعد المكسور يُضبط ولا يُخفى

الوثيقة نفسها بوعد خاطئ. لا تصير الوثيقة صحيحة بمجرد كتابتها.

```ring
cBroken = "# Mini" + char(10) + "```ring" + char(10) + "? 1 + 1" + char(10) + "#--> 3" + char(10) + "```" + char(10)
cMini2 = "t_mini2_" + ProcessId() + ".en.md"
write(cMini2, cBroken)
oCh2 = StzChapterQ(cMini2, "en")
oCh2.Run("")
? oCh2.AllPromisesKept()
#--> FALSE
? oCh2.CellKept(1)
#--> FALSE
```

## 3. للحارس حالة إيجابية وحالة سلبية

الفحص الذي لا يستطيع إلا النجاح لا يثبت شيئًا. الحارس أدناه يصير أحمر إن قبل المشغّل يومًا الوثيقة
المكسورة، وأحمر إن رفض يومًا الوثيقة الصحيحة.

```ring
? oCh.AllPromisesKept() = 1 and oCh2.AllPromisesKept() = 0
#--> TRUE
remove(cMini)
remove(cMini2)
```

## 4. الحكم يشرح نفسه

مدقّق تمارين هذا الدرس كائن واحد. أعطه وعدًا وبرنامجًا، فيقول ما حدث بألفاظ المتعلم نفسه، ولا يقول القيمة
المنتظرة أبدًا.

```ring
oNo = new stzExerciseCheck("demo", [ "3" ], "? 42", [])
? oNo.Passed()
#--> FALSE
? oNo.Why()
#--> Your program ran, but what it printed is not yet what the task asks. It printed: 42
oYes = new stzExerciseCheck("demo", [ "3" ], "? 1 + 2", [])
? oYes.Why()
#--> Every promise of the exercise was kept when your program ran.
```

## الخلاصة

- **ما أنجزته:** كتبت سردًا وشغّلته، ورأيت وعدًا خاطئًا يُضبط، وكتبت حارسًا بحالة إيجابية وأخرى سلبية،
  وقرأت حكمًا يسمّي ما طُبع لا ما كان منتظرًا.
- **لماذا يهم:** الوثيقة التي تعمل لا تنحرف عن الشفرة التي تصفها. هذا هو القانون الذي التزمته كل صفحة من
  هذا الدرس، وقد صار لك الآن.
- **ما التالي:** مشاريع المستويات. يُكتسب المستوى حين يجتاز مشروع من عندك حرّاسه.
