# اقرأ الاسم كجملة

*مدخل أساسي · الفصل 3 · المهارة EX-04: «هل يغيّر هذا الاسم الكائن، أم يعطيني نسخة، أم يكمل الجملة؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

اسم الدالة في سوفتانزا جملة تُقال لكائن. وقواعده تخبرك بما سيحدث قبل أن تشغّله. يعلّمك هذا الفصل الصيغ الثلاث
التي ستلقاها في كل صفحة: الفاعلة، والمفعولة، والمتصلة.

## 1. الصيغة الفاعلة تغيّر الكائن

`RemoveAll` أمر. يطيعه الكائن ويتغيّر.

```ring
o1 = new stzString("RIxxNxG")
o1.RemoveAll("x")
? o1.Content()
#--> RING
```

## 2. الصيغة المفعولة تعطيك نسخة

`Removed` اسم مفعول: *النص، وقد أزيلت منه x*. تجيب بقيمة جديدة وتترك الكائن كما كان.

```ring
o1 = new stzString("RIxxNxG")
? o1.Removed("x")
#--> RING
? o1.Content()
#--> RIxxNxG
```

## 3. الصيغة المتصلة تكمل الجملة

حرف `Q` في آخر الاسم يعني *ثم*. تستمر الجملة حتى تغلقها صيغة مفعولة.

```ring
? Q("rixxnxg").RemoveQ("x").UppercaseQ().Spacified()
#--> R I N G
```

## 4. الجملة المتصلة على كائن تغيّره

```ring
o1 = new stzString("rixxnxg")
? o1.RemoveQ("x").Uppercased()
#--> RING
? o1.Content()
#--> ring
```

## 5. قل «على نسخة» بـ QC

`QC` تعني *ثم، على نسخة*. الأصل لا يُمسّ.

```ring
o1 = new stzString("rixxnxg")
? o1.RemoveQC("x").Uppercased()
#--> RING
? o1.Content()
#--> rixxnxg
```

## 6. المعامل المسمّى يُقرأ كنثر

```ring
? Q("tea, rice, tea").Replaced("tea", :With = "coffee")
#--> coffee, rice, coffee
```

## 7. السؤال اسم يبدأ بـ Is

```ring
? Q("bread").IsLowercase()
#--> TRUE
```

## الخلاصة

- **ما أنجزته:** صرت تعرف، من الاسم وحده، هل يغيّر الكائن (`RemoveAll`)، أم يجيب بنسخة (`Removed`)، أم يكمل
  الجملة (`RemoveQ`، و`RemoveQC` على نسخة).
- **لماذا يهم:** لن تحتاج أبدًا إلى تشغيل دالة لتعرف هل ستنجو بياناتك منها. الاسم يقول ذلك.
- **ما التالي:** الجملة نفسها، مقولة بالفرنسية أو العربية أو الهوسا.
