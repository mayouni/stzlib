# سِر، اسأل، أنتِج، افعل

*مدخل أساسي · الفصل 6 · المهارة FO-02: «أيّ الحركات الأربع هذه الخطوة؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

كل برنامج مكوّن من أربع حركات. فهو **يسير** عبر المواضع، و**يسأل** أسئلة، و**ينتج** قيمًا جديدة، و**يفعل**
في البيانات. تسمّي سوفتانزا كل حركة، فتتفكك المهمة إلى حركات لا إلى حلقات.

## 1. السير: المواضع، ثم ما فيها

يفحص المطبخ كل طلبية ثالثة. أولًا المواضع، ثم الطلبيات في تلك المواضع.

```ring
aOrders = [ "tea", "rice", "tea", "fish", "rice", "tea", "soup", "tea", "rice" ]
? @@( StzListQ([ 1, 2, 3, 4, 5, 6, 7, 8, 9 ]).FindW("@item % 3 = 1") )
#--> [ 1, 4, 7 ]
? @@( StzListQ(aOrders).ItemsAtPositions([ 1, 4, 7 ]) )
#--> [ "tea", "fish", "soup" ]
```

## 2. السؤال: يجيب السؤال بـ TRUE أو FALSE

```ring
? StzListQ(aOrders).Contains("soup")
#--> TRUE
? Q("cold").IsLowercase()
#--> TRUE
```

## 3. الإنتاج: المنتِج يصنع قيمًا جديدة من القديمة

إيراد اليوم، وقد كُتب الاسترداد رقمًا سالبًا. المنتِج يرشّح ويحوّل ويختزل دون كتابة حلقة واحدة.

```ring
oY = new stzYielder([ 12, 0, 30, -5, 18 ])
? @@( oY.Filter(:IsPositive) )
#--> [ 12, 30, 18 ]
? @@( oY.Map(:Double) )
#--> [ 24, 0, 60, -10, 36 ]
? oY.Reduce(:Sum)
#--> 55
```

## 4. الحركات تتسلسل

رشّح، ثم اختزل: مجموع المبيعات الحقيقية.

```ring
? oY.FilterQ(:IsPositive).Reduce(:Sum)
#--> 60
```

## 5. الفعل: الفعل يغيّر البيانات

```ring
oL = new stzList(aOrders)
oL.RemoveAll("tea")
? @@( oL.Content() )
#--> [ "rice", "fish", "rice", "soup", "rice" ]
```

## 6. يمكن تسليم الشرط كبيانات

`ItemsW` تأخذ السؤال نفسه معاملًا لها. الفصل التالي عن هذا.

```ring
? @@( StzListQ([ 12, 0, 30, -5, 18 ]).ItemsW("@item > 0") )
#--> [ 12, 30, 18 ]
```

لسوفتانزا أيضًا كائن سائر مخصص، `stzWalker`، له خطوات واتجاهات وتاريخ. يسكن في طبقة `max` من المكتبة، التي
لا يحمّلها هذا الدرس، فلا يُعرض هنا.

## الخلاصة

- **ما أنجزته:** صنّفت مهمة إلى سير (مواضع) وسؤال (أسئلة) وإنتاج (منتِج) وفعل (فعل)، وسلسلتها دون حلقة.
- **لماذا يهم:** الحلقة تخفي أيّ حركة تؤديها. تسمية الحركة تجعل البرنامج مقروءًا لمن لم يكتبه.
- **ما التالي:** التصريح بما تريد وترك المحرك يقرر كيف.
