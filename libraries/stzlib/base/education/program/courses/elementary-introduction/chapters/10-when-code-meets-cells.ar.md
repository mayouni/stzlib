# حين يلتقي الكود بالخلايا

*مدخل أساسي · الفصل 10 · المهارة PA-04: «أيّ الخلايا تجيب عن سؤالي؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

قائمة طعام المطعم جدول: صف لكل طبق، وعمود لكل معلومة عنه. `stzTable` يحمله ويرسمه ويجيب عن الأسئلة بالعمود
والصف والخلية. والعمود قائمة، فكل ما سألته قائمةً في الفصول الأولى تستطيع أن تسأله عمودًا.

## 1. ابنِ الجدول، وانظر إليه

الصف الأول يسمّي الأعمدة. شغّل الخلية لترى الجدول مرسومًا.

```ring
oT = new stzTable([
	[ :DISH, :PRICE, :ORDERS ],
	[ "tea",  200, 6 ],
	[ "rice", 500, 3 ],
	[ "fish", 900, 2 ]
])
oT.Show()
```

## 2. شكله

```ring
? oT.NumberOfRows()
#--> 3
? oT.NumberOfCols()
#--> 3
? @@( oT.ColNames() )
#--> [ "dish", "price", "orders" ]
```

## 3. عمود، وصف

```ring
? @@( oT.Col(:PRICE) )
#--> [ 200, 500, 900 ]
? @@( oT.Row(2) )
#--> [ "rice", 500, 3 ]
```

## 4. خلية، وأين قيمة ما

```ring
? oT.Cell(:PRICE, 3)
#--> 900
? @@( oT.FindInCol(:DISH, "fish") )
#--> [ 3 ]
```

## 5. العمود قائمة: اسأله أسئلة القوائم

```ring
? StzListQ(oT.Col(:ORDERS)).Sum()
#--> 11
? @@( StzListQ(oT.Col(:PRICE)).FindW("{ @item > 400 }") )
#--> [ 2, 3 ]
```

## الخلاصة

- **ما أنجزته:** بنيت جدولًا من صفوف، وقرأت شكله، وأخذت عمودًا وصفًا وخلية، ووجدت قيمة في عمود، وسألت عمودًا
  أسئلة الفصل 7.
- **لماذا يهم:** معظم بيانات العالم تصل جداول. معرفة أن العمود قائمة تعني أنك تعرف من قبلُ كيف تسأله.
- **ما التالي:** بعض الإجابات يحسن رسمها لا طبعها.
