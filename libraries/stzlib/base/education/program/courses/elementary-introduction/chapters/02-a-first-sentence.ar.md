# جملة أولى

*مدخل أساسي · الفصل 2 · المهارتان FO-01 «ما الذي أسأل عنه حقًا؟» وEX-01 «أيّ كائن يحمل بياناتي؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

في الفصل الأول جاءت الطلبات قائمةً. اليوم تأتي جملةً: شكوى زبون. قبل أي شفرة، يطلب منك النموذج الذهني أن تقول
المشكلة بالكلمات وتستخرج كلماتها المفتاحية، لأن الكلمات المفتاحية هي التي تسمّي الكائن الذي ستختاره.

## 1. قل المشكلة

*«هل تكرر هذه الشكوى كلمة، وأيّ كلمة؟»*

ثلاث كلمات مفتاحية. **الشكوى** نص، فالكائن إذن `stzString`. **الكلمة** شيء يستطيع النص أن يعطيك إياه.
**التكرار** سؤال عن التكرارات، والتكرارات تسكن في قائمة.

## 2. اختر الكائن

```ring
o1 = new stzString("the bread was cold and the tea was cold")
? o1.NumberOfWords()
#--> 9
```

## 3. اسأل النص عن كلماته

```ring
? @@( o1.Words() )
#--> [ "the", "bread", "was", "cold", "and", "the", "tea", "was", "cold" ]
```

## 4. الكلمة المفتاحية «تكرار» تنتمي إلى قائمة

صارت الكلمات قائمة الآن، فتنطبق عليها أسئلة الفصل الأول دون تغيير.

```ring
oW = new stzList( o1.Words() )
? oW.ContainsDuplicates()
#--> TRUE
? oW.NumberOfDuplicates()
#--> 3
```

## 5. ابحث، ثم طبّق

```ring
? @@( oW.FindDuplicates() )
#--> [ 6, 8, 9 ]
? @@( oW.DuplicatesRemoved() )
#--> [ "the", "bread", "was", "cold", "and", "tea" ]
```

## 6. مكان عملك، في جملة

الطلبات التي تلقاها مكان عملك اليوم، مجموعةً في جملة واحدة. ما يُطبع يتوقف على العالم الذي يجري عليه هذا
الدرس: شغّل الخلية.

```ring
aReq = EduWorldObjects("requested")
? Q(aReq).Joined(", ")
? Q( Q(aReq).Joined(" ") ).NumberOfWords()
```

## الخلاصة

- **ما أنجزته:** قلتَ مشكلة بالكلمات، وأخذت كلماتها المفتاحية، وتركتها تختار الكائن: نصًا للشكوى، وقائمة
  للكلمات المكررة.
- **لماذا يهم:** الكائن الذي تختاره يقرر الأسئلة التي تستطيع طرحها. النص يجيب «كم كلمة»؛ والقائمة تجيب
  «أيّها مكرر».
- **ما التالي:** أسماء الأسئلة نفسها جمل. يعلّمك الفصل التالي قراءتها.
