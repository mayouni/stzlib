# ارسم الجواب

*مدخل أساسي · الفصل 11 · المهارتان SE-01 «هل تجيب صورة عن هذا أسرع من رقم؟» وSE-02 «أين، وكم؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

`[ 3, 9, 15 ]` جواب صحيح عن «أين ring؟». لكنه ليس جوابًا سريعًا. الصورة تضع الجواب حيث العين أصلًا. ترسم
سوفتانزا الأجوبة نصًا، فالرسم شيء يستطيع البرنامج طبعه، والصفحة حمله، والحارس التحقق منه سطرًا سطرًا.

## 1. أظهر أين، لا الموضع فقط

```ring
o1 = new stzString("fjringljringdjringg")
? @@( o1.FindAll("ring") )
#--> [ 3, 9, 15 ]
? o1.vizFind("ring")
#--> fjringljringdjringg
#--> --^-----^-----^----
```

## 2. مع الأرقام تحت العلامات

```ring
? o1.vizFindXT("ring", [ :Numbered = TRUE ])
#--> fjringljringdjringg
#--> --^-----^-----^----
#--> 3     9     15
```

## 3. الرسم البياني صورة للعلاقات

الطلبية تصل إلى المطبخ، والمطبخ يصل إلى الطاولة. يجيب الرسم عن الأسئلة، ثم يرسم نفسه.

```ring
oG = new stzGraph("kitchen")
oG {
	AddNodeXT("order", "Order")
	AddNodeXT("kitchen", "Kitchen")
	AddNodeXT("table", "Table")
	Connect("order", "kitchen")
	Connect("kitchen", "table")
}
? oG.PathExists("order", "table")
#--> TRUE
? @@( oG.Neighbors("kitchen") )
#--> [ "table" ]
oG.Show()
#--> │ Order │
#--> │ Table │
```

## 4. كم: عمود لكل طبق

```ring
oP = new stzHBarPlot([ :tea = 6, :rice = 3, :fish = 2 ])
oP.Show()
#--> Tea │ ▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇▇
#--> Fish │ ▇▇▇▇▇▇
```

## 5. الأعمدة نفسها، واقفة

```ring
oP2 = new stzVBarPlot([ :tea = 6, :rice = 3, :fish = 2 ])
oP2.SetHeight(4)
oP2.Show()
#--> Tea Rice Fish
```

## الخلاصة

- **ما أنجزته:** رسمت أين توجد كلمة، ورسمت رسمًا لثلاث علاقات وسألته سؤالًا، ورسمت طلبيات ثلاثة أطباق
  أعمدةً، مضطجعة ثم واقفة.
- **لماذا يهم:** العرض هو الأداة. قد يكون الرقم صحيحًا ويبقى غير مقروء؛ والصورة تُقرأ فورًا، والصورة المصنوعة
  من نص ما زال الحارس يستطيع التحقق منها.
- **ما التالي:** تعليم سوفتانزا ما يعرفه مكان عملك، لتستدل عليه.
