# صرّح بما لا بكيف

*مدخل أساسي · الفصل 7 · المهارتان FO-04 «هل أستطيع أن أقول ما أريد وأترك المحرك يقرر كيف؟» وPA-03 «هل أستطيع تسليم الشرط بدلًا من كتابة التفريع؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

إلى الآن كنت تسمّي شيئًا ثابتًا: «tea»، التكرارات، الموضع 4. يسمّي هذا الفصل **شرطًا**، ويسلّمه كبيانات. أنت
تقول *ما* الذي يُقبل؛ والمحرك يقرر *كيف* يسير في القائمة ويختبر كل عنصر ويجمع الجواب. حرف `W` في آخر الاسم
يعني *where*، «حيث».

## 1. ابحث حيث يصدق الشرط

`@item` يمثّل كل عنصر بدوره. الشرط قطعة نص بين قوسين معقوفين.

```ring
o = new stzList([ 4, 7, 10, 3, 8 ])
? @@( o.FindW("{ @item > 5 }") )
#--> [ 2, 3, 5 ]
? @@( o.ItemsW("{ @item > 5 }") )
#--> [ 7, 10, 8 ]
? o.CountW("{ @item > 5 }")
#--> 3
```

## 2. أيّ سؤال يصلح شرطًا

```ring
? @@( o.FindW("{ IsEven(@item) }") )
#--> [ 1, 3, 5 ]
? o.CheckW("{ isNumber(@item) }")
#--> TRUE
```

## 3. القاعدة بيانات: احفظها، وطبّقها في أي مكان

تسكن القاعدة في متغير. قائمتان، وقاعدة واحدة، ولم تعرف القاعدة قط أيّ قائمة ستلقى.

```ring
cRule = "{ @item > 20 }"
oA = new stzList([ 12, 0, 30, -5, 18, 25 ])
oB = new stzList([ 3, 40, 9 ])
? oA.CountW(cRule)
#--> 2
? oB.CountW(cRule)
#--> 1
```

## 4. تصرّف حيث تصدق القاعدة

```ring
? @@( oA.ItemsW(cRule) )
#--> [ 30, 25 ]
oA.RemoveW(cRule)
? @@( oA.Content() )
#--> [ 12, 0, -5, 18 ]
```

## 5. الكلمة نفسها على كلمات

```ring
oS = new stzList([ "ring", "PHP", "C#", "ruby", "GO" ])
? @@( oS.FindW("{ IsUppercase(@item) }") )
#--> [ 2, 3, 5 ]
? @@( oS.ItemsW("{ Q(@item).IsLowercase() }") )
#--> [ "ring", "ruby" ]
```

## الخلاصة

- **ما أنجزته:** وجدت وعددت وأبقيت وأزلت عناصر بشرط كتبته مرة واحدة نصًا، وطبّقت قاعدة واحدة على قائمتين
  دون تغييرها.
- **لماذا يهم:** الشرط الذي هو بيانات يمكن حفظه في ملف، وإرساله إلى زميل، وتطبيقه على بيانات لم تكن موجودة
  حين كُتب. والتفريع داخل حلقة لا يستطيع شيئًا من ذلك.
- **ما التالي:** للشروط على النص لغتها الخاصة، واسمها النمط.
