# ابحث، ثم طبّق

*مدخل أساسي · الفصل 1 · المهارة EX-03: «أين هو، وماذا أفعل هناك؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

كل مكان عمل يتلقى طلبات: المطعم يتلقى طلبيات، والبنك يتلقى تذاكر، وكثيرًا ما يصل الطلب نفسه أكثر من مرة. يعالج هذا
الفصل الطلبات المكررة بطريقة سوفتانزا. أولًا نختار الكائن. ثم نسأل هل يحتوي على ما نبحث عنه، ونعدّه، ونجده. وبعد ذلك
فقط نتصرّف.

## 1. اختر الكائن

قائمة الطلبات هي `stzList`.

```ring
o1 = new stzList([ "tea", "rice", "tea", "fish", "rice", "tea" ])
? o1.NumberOfItems()
#--> 6
```

## 2. اطرح سؤال الاحتواء

قبل أن تتصرّف، اسأل هل هناك ما يستحق التصرّف.

```ring
? o1.ContainsDuplicates()
#--> TRUE
```

## 3. اطرح سؤال العدد

```ring
? o1.NumberOfDuplicates()
#--> 3
```

## 4. اسأل عن المواضع

```ring
? @@( o1.FindDuplicates() )
#--> [ 3, 5, 6 ]
```

## 5. تصرّف في المواضع

أنت تعرف أين توجد الطلبات المكررة، فتستطيع إزالتها.

```ring
o1.RemoveItemsAtPositions( o1.FindDuplicates() )
? @@( o1.Content() )
#--> [ "tea", "rice", "fish" ]
```

ولسوفتانزا كلمة واحدة للحركة كلها. اقرأها كجملة: *القائمة، وقد أزيلت منها التكرارات*.

```ring
? @@( StzListQ([ "tea", "rice", "tea" ]).DuplicatesRemoved() )
#--> [ "tea", "rice" ]
```

## 6. الأسئلة نفسها، على مكان عملك

تقرأ هذه الخلية الطلبات التي تلقاها مكان عملك اليوم. ما تطبعه يتوقف على العالم الذي يجري عليه هذا الدرس، ولذلك لا
تعرض الصفحة أي نتيجة أبدًا: شغّلها.

```ring
o2 = new stzList( EduWorldObjects("requested") )
? EduWorldName()
? o2.ContainsDuplicates()
? o2.NumberOfDuplicates()
? @@( o2.DuplicatesRemoved() )
```

## 7. قلها بكلماتك

تفهم سوفتانزا الطلب نفسه مكتوبًا بالعربية أيضًا.

```ring
? @@( NaturallyIn("ar", "أنشئ قائمة مع [ 5, 3, 5, 1 ] أزل التكرارات").Result() )
#--> [ 5, 3, 1 ]
```

## الخلاصة

- **ما أنجزته:** مررتَ بقائمة عبر النموذج الذهني. اخترتها، وسألت هل تحتوي على تكرارات، وعددتها ووجدتها، ثم أزلتها.
- **لماذا يهم:** التصرّف يأتي في النهاية. كل سؤال تطرحه أولًا يجعل التصرّف دقيقًا، وكل جواب يمكن التحقق منه.
- **ما التالي:** الأسئلة الخمسة نفسها تصلح للنصوص والجداول والرسوم البيانية. يطرحها الفصل التالي على نص.
