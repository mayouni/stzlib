# كائن واحد، أي بنية

*مدخل أساسي · الفصل 5 · المهارة FO-03: «هل هذا هو السؤال نفسه الذي طرحته على قائمة، وأطرحه الآن على نص؟»*

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

طرح الفصل الأول ثلاثة أسئلة على قائمة: هل تحتوي، وكم، وأين. يطرح هذا الفصل الأسئلة الثلاثة نفسها على نص،
بالكلمات نفسها. تتغير البنية؛ ولا يتغير التفكير.

## 1. الأسئلة الثلاثة، مطروحة على نص

```ring
oS = new stzString("tea rice tea fish")
? oS.Contains("tea")
#--> TRUE
? oS.NumberOfOccurrence("tea")
#--> 2
? @@( oS.FindAll("tea") )
#--> [ 1, 10 ]
```

## 2. الأسئلة الثلاثة نفسها، مطروحة على قائمة

```ring
oL = new stzList([ "tea", "rice", "tea", "fish" ])
? oL.Contains("tea")
#--> TRUE
? oL.NumberOfOccurrence("tea")
#--> 2
? @@( oL.FindAll("tea") )
#--> [ 1, 3 ]
```

## 3. الكلمات نفسها، والوحدات مختلفة

الموضع في النص يعدّ الحروف؛ والموضع في القائمة يعدّ العناصر. السؤال واحد، والمسطرة ليست واحدة.

```ring
? StzLen("tea rice tea fish")
#--> 17
? oL.NumberOfItems()
#--> 4
```

## 4. دالة واحدة لكليهما

`StzFind` تأخذ أولًا ما تبحث عنه، ثم المكان الذي تبحث فيه.

```ring
? @@( StzFind("tea", "tea rice tea fish") )
#--> [ 1, 10 ]
? @@( StzFind("tea", [ "tea", "rice", "tea", "fish" ]) )
#--> [ 1, 3 ]
```

## 5. تصرّف بالطريقة نفسها، واقرأ النتيجة بعناية

إزالة كلمة من نص تترك المسافات التي كانت تحيط بها. وإزالة عنصر من قائمة لا تترك شيئًا. الفعل نفسه، وفرق
صادق.

```ring
? @@( oS.Removed("tea") )
#--> " rice  fish"
oL.RemoveAll("tea")
? @@( oL.Content() )
#--> [ "rice", "fish" ]
```

## 6. مكان عملك، بالطريقتين

أكثر شيء مطلوب في مكان عملك، معدودًا في قائمة الطلبات وفي الطلبات نفسها مجموعةً في جملة واحدة. شغّل
الخلية: الجواب يتوقف على العالم.

```ring
aReq = EduWorldObjects("requested")
? StzListQ(aReq).NumberOfOccurrence(aReq[1])
? Q( Q(aReq).Joined(" ") ).NumberOfOccurrence(aReq[1])
```

## الخلاصة

- **ما أنجزته:** طرحت «هل تحتوي» و«كم» و«أين» على نص وعلى قائمة بالكلمات نفسها، ورأيت أين تختلف
  الإجابات في الوحدة وفيما تتركه الإزالة وراءها.
- **لماذا يهم:** طريقة تفكير واحدة تغطي كل بنية. حين يصل جدول أو رسم، تكون قد عرفت الأسئلة.
- **ما التالي:** الحركات الأربع التي يتكون منها كل برنامج: سير، وسؤال، وإنتاج، وفعل.
