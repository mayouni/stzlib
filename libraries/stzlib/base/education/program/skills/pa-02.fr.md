# PA-02 · Reconnaître les motifs de structure

> Traduction provisoire, en attente de relecture par un locuteur natif.

question: Quelle est la forme de cette liste ou de ces nombres ?
foundation: confronte une liste à un motif listex
practitioner: décrit une suite de nombres avec numbrex
expert: écrit un motif qui rejette les mauvaises lignes d'un vrai jeu de données et dit pourquoi
