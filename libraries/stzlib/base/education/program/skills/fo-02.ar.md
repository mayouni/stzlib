# FO-02 · التفكيك إلى سير وسؤال وإنتاج وفعل

> ترجمة أولية، في انتظار مراجعة متحدث أصلي.

question: أيّ الحركات الأربع هذه الخطوة: سير أم سؤال أم إنتاج أم فعل؟
foundation: يصنّف خطوات مهمة إلى سير وسؤال وإنتاج وفعل
practitioner: يكتب مهمة بسائر ومتحقّق ومنتِج ومنفّذ
expert: يستبدل برنامجًا مثقلًا بالحلقات بالاستعارات الأربع ويشرح لماذا صار أوضح قراءةً
